    For 3x+2y=163x + 2y = 163x+2y=16 and 2x+3y=192x + 3y = 192x+3y=19, the solution pair is:

    Answer choices for question 1

    Solution

    Correct answer: B

    Back-substitute y=5y = 5y=5 into 3x+2y=163x + 2y = 163x+2y=16.

    3x+2(5)=16  ⇒  3x=6  ⇒  x=23x + 2(5) = 16 \;\Rightarrow\; 3x = 6 \;\Rightarrow\; x = 23x+2(5)=16⇒3x=6⇒x=2

    So the solution pair is (2,5)(2, 5)(2,5).

    Solve 4x+2y=54x + 2y = 54x+2y=5 and 2x−2y=12x - 2y = 12x−2y=1 by adding. What is xxx?

    Answer choices for question 9

    Solution

    Correct answer: B

    The +2y+2y+2y and −2y-2y−2y are opposites, so adding cancels yyy.

    (4x+2y)+(2x−2y)=5+1  ⇒  6x=6  ⇒  x=1(4x + 2y) + (2x - 2y) = 5 + 1 \;\Rightarrow\; 6x = 6 \;\Rightarrow\; x = 1(4x+2y)+(2x−2y)=5+1⇒6x=6⇒x=1

    So x=1x = 1x=1.
