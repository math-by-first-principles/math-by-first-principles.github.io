Sequences and Series: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Sequence
An ordered list of numbers, each one a term. Order matters: changing the order can give a different sequence, as reversing 2, 5, 8 does.
Position and the subscript ana_nan​
ana_nan​ is the term in position nnn. The subscript counts position, never a multiplication; nnn is always a counting number.
Series, partial sum SnS_nSn​
A series is the sum of a sequence's terms, a single number rather than a list. SnS_nSn​, the nnnth partial sum, sums just the first nnn terms.
Arithmetic sequence, common difference ddd
Each term is the one before it plus a fixed ddd, which may be positive, negative, fractional, or zero (a constant sequence).
Geometric sequence, common ratio rrr
Each term is the one before it times a fixed rrr. Every rrr but 000 is allowed, and with a1≠0a_1 \neq 0a1​=0 no term is ever 000.
Explicit form and recursive form
Explicit (closed) form gives a term straight from its position; recursive form builds each term from the one before it.
Summation (sigma) notation
In ∑k=1nak\sum_{k=1}^{n} a_k∑k=1n​ak​, kkk is the index, 111 and nnn the lower and upper limits, aka_kak​ the summand. The index is a dummy variable: the letter never changes the value.
Converge, diverge
An infinite series converges when its partial sums SnS_nSn​ approach one fixed value as nnn grows, which becomes the infinite sum; otherwise it diverges and has no finite sum.
Telescoping sum
A sum whose terms are differences of shifted values of one sequence bkb_kbk​ (consecutive values are the gap-1 case), so the interior cancels and a fixed number of boundary values survive.

Formulas and theorems

  • Testing arithmetic against geometric

    Arithmetic when every ak+1−aka_{k+1} - a_kak+1​−ak​ gives the same ddd; geometric when every ak+1ak\frac{a_{k+1}}{a_k}ak​ak+1​​ gives the same rrr.

    Use when One mismatched pair disqualifies it. Subtract or divide a term by the one BEFORE it; the ratio test needs nonzero terms.

    e.g. 2,4,8,162, 4, 8, 162,4,8,16: differences 2,4,82, 4, 82,4,8 vary, but every ratio is 222, so geometric.

  • nnnth term of an arithmetic sequence

    an=a1+(n−1)da_n = a_1 + (n-1)dan​=a1​+(n−1)d

    Use when Any arithmetic sequence, any n≥1n \ge 1n≥1. The step count is n−1n - 1n−1, not nnn, because the first term takes no step; at n=1n = 1n=1 it returns a1a_1a1​.

  • nnnth term of a geometric sequence

    an=a1r n−1a_n = a_1 r^{\,n-1}an​=a1​rn−1

    Use when Any geometric sequence, any n≥1n \ge 1n≥1, with r≠0r \neq 0r=0. The exponent is n−1n - 1n−1, not nnn, and r0=1r^0 = 1r0=1 returns a1a_1a1​.

    e.g. a1=7a_1 = 7a1​=7, r=3r = 3r=3: a4=7⋅33=189a_4 = 7 \cdot 3^3 = 189a4​=7⋅33=189.

  • What the common ratio does

    r>1r > 1r>1: the terms grow in size without bound. 0<r<10 < r < 10<r<1: they shrink toward 000, never reaching it. r<0r < 0r<0: they alternate in sign. r=1r = 1r=1: every term equals a1a_1a1​.

    Use when Any geometric sequence with a1≠0a_1 \neq 0a1​=0; r=0r = 0r=0 is excluded outright. Size follows the powers of ∣r∣|r|∣r∣, so a negative rrr with ∣r∣>1|r| > 1∣r∣>1 alternates AND grows.

  • Moving between any two terms

    ak=am+(k−m)dak=am r k−m\begin{gathered} a_k = a_m + (k-m)d \\ a_k = a_m\,r^{\,k-m} \end{gathered}ak​=am​+(k−m)dak​=am​rk−m​

    Use when Any positions mmm and kkk, arithmetic above and geometric below; a negative k−mk - mk−m steps backward. An EVEN gap leaves an even power of rrr, hiding a sign: r2=4r^2 = 4r2=4 allows both 222 and −2-2−2.

    e.g. a3=20a_3 = 20a3​=20 and a7=44a_7 = 44a7​=44: 44=20+4d44 = 20 + 4d44=20+4d, so d=6d = 6d=6.

  • Recursive rules

    an=an−1+d,an=r an−1a_n = a_{n-1} + d, \qquad a_n = r\,a_{n-1}an​=an−1​+d,an​=ran−1​

    Use when Both for n≥2n \ge 2n≥2, each needing a stated a1a_1a1​.

  • Expanding summation notation

    ∑k=1nak=a1+a2+⋯+an\sum_{k=1}^{n} a_k = a_1 + a_2 + \cdots + a_nk=1∑n​ak​=a1​+a2​+⋯+an​

    Use when The index steps by one from the lower limit through the upper, both included.

    e.g. ∑k=14(2k+1)=3+5+7+9=24\sum_{k=1}^{4} (2k + 1) = 3 + 5 + 7 + 9 = 24∑k=14​(2k+1)=3+5+7+9=24.

  • Finite arithmetic series

    Sn=n(a1+an)2=n2(2a1+(n−1)d)\begin{gathered} S_n = \frac{n(a_1 + a_n)}{2} \\ = \frac{n}{2}\big(2a_1 + (n-1)d\big) \end{gathered}Sn​=2n(a1​+an​)​=2n​(2a1​+(n−1)d)​

    Use when nnn a positive whole number of arithmetic terms; the two forms give the same total.

    e.g. a1=1a_1 = 1a1​=1, an=na_n = nan​=n gives 1+2+⋯+n=n(n+1)21 + 2 + \cdots + n = \frac{n(n+1)}{2}1+2+⋯+n=2n(n+1)​, so 1+2+⋯+100=50501 + 2 + \cdots + 100 = 50501+2+⋯+100=5050.

  • Counting and summing a range of terms

    The terms from position mmm to position nnn number n−m+1n - m + 1n−m+1, and their total is Sn−Sm−1S_n - S_{m-1}Sn​−Sm−1​.

    Use when 1≤m≤n1 \le m \le n1≤m≤n, reading S0=0S_0 = 0S0​=0 when m=1m = 1m=1. Both endpoints count, hence the +1+1+1.

    e.g. Rows 777 through 191919 number 19−7+1=1319 - 7 + 1 = 1319−7+1=13.

  • Finite geometric series

    Sn=a1(1−r n)1−r=a1(r n−1)r−1S_n = \frac{a_1(1 - r^{\,n})}{1 - r} = \frac{a_1(r^{\,n} - 1)}{r - 1}Sn​=1−ra1​(1−rn)​=r−1a1​(rn−1)​

    Use when r≠1r \neq 1r=1: there the denominator is zero, and since every term equals a1a_1a1​ the sum is simply n a1n\,a_1na1​. The two forms agree everywhere, the first tidier when r<1r < 1r<1, the second when r>1r > 1r>1.

  • Infinite geometric series

    S=a11−rS = \frac{a_1}{1 - r}S=1−ra1​​

    Use when ∣r∣<1|r| < 1∣r∣<1 ONLY, a condition on size, so it covers negative ratios like r=−12r = -\tfrac{1}{2}r=−21​. When ∣r∣≥1|r| \ge 1∣r∣≥1 there is no finite sum: r=1r = 1r=1 runs off, r=−1r = -1r=−1 flips between a1a_1a1​ and 000 forever, and ∣r∣>1|r| > 1∣r∣>1 grows in size past every bound.

  • Telescoping collapse

    ∑k=1n(bk−bk+1)=b1−bn+1∑k=1n(bk+1−bk)=bn+1−b1\begin{gathered} \sum_{k=1}^{n} (b_k - b_{k+1}) = b_1 - b_{n+1} \\ \sum_{k=1}^{n} (b_{k+1} - b_k) = b_{n+1} - b_1 \end{gathered}k=1∑n​(bk​−bk+1​)=b1​−bn+1​k=1∑n​(bk+1​−bk​)=bn+1​−b1​​
    Text description

    The four brackets of a telescoping sum are stacked in a staircase so that each subtracted term sits directly above the identical added term in the row below; every one of those interior pairs is struck through, leaving only the first term and the last subtracted term, whose difference is the whole sum.

    Use when Every term must be a difference of SHIFTED values of one bkb_kbk​: consecutive values (bk−bk+1b_k - b_{k+1}bk​−bk+1​) are the gap-1 case, and a wider gap leaves more survivors per end. In the gap-1 case the back survivor is bn+1b_{n+1}bn+1​, not bnb_nbn​. The infinite version is finite exactly when the complete surviving boundary expression settles at one fixed value, not necessarily zero.

  • The two standard fraction telescopes

    1k(k+1)=1k−1k+11k(k+2)=12(1k−1k+2)\begin{gathered} \frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1} \\ \frac{1}{k(k+2)} = \frac{1}{2}\left(\frac{1}{k} - \frac{1}{k+2}\right) \end{gathered}k(k+1)1​=k1​−k+11​k(k+2)1​=21​(k1​−k+21​)​

    Use when Verify a split by recombining over a common denominator; the gap-222 split needs the 12\tfrac{1}{2}21​, since 1k−1k+2=2k(k+2)\frac{1}{k} - \frac{1}{k+2} = \frac{2}{k(k+2)}k1​−k+21​=k(k+2)2​. Collapsed they total 1−1n+1=nn+11 - \frac{1}{n+1} = \frac{n}{n+1}1−n+11​=n+1n​ (infinite value 111) and 34−12(1n+1+1n+2)\frac{3}{4} - \frac{1}{2}\left(\frac{1}{n+1} + \frac{1}{n+2}\right)43​−21​(n+11​+n+21​) (two survivors each end; infinite value 34\tfrac{3}{4}43​).

  • Square-root and consecutive-square telescopes

    ∑k=1n(k+1−k)=n+1−1∑k=1n(2k+1)=(n+1)2−1\begin{gathered} \sum_{k=1}^{n} \left(\sqrt{k+1} - \sqrt{k}\right) = \sqrt{n+1} - 1 \\ \sum_{k=1}^{n} (2k+1) = (n+1)^2 - 1 \end{gathered}k=1∑n​(k+1​−k​)=n+1​−1k=1∑n​(2k+1)=(n+1)2−1​

    Use when Mirror-direction telescopes, bk=kb_k = \sqrt{k}bk​=k​ and bk=k2b_k = k^2bk​=k2, the second from (k+1)2−k2=2k+1(k+1)^2 - k^2 = 2k+1(k+1)2−k2=2k+1. Rationalizing turns 1k+k+1\frac{1}{\sqrt{k} + \sqrt{k+1}}k​+k+1​1​ into k+1−k\sqrt{k+1} - \sqrt{k}k+1​−k​, and log⁡ ⁣(k+1k)\log\!\left(\frac{k+1}{k}\right)log(kk+1​) telescopes to log⁡(n+1)\log(n+1)log(n+1). The square-root sum has NO finite infinite value: n+1\sqrt{n+1}n+1​ runs off.

Problem types, step by step

Find a chosen term of a sequence

  1. Read a1a_1a1​, then get ddd by subtracting consecutive terms or rrr by dividing them.
  2. Substitute into an=a1+(n−1)da_n = a_1 + (n-1)dan​=a1​+(n−1)d or an=a1r n−1a_n = a_1 r^{\,n-1}an​=a1​rn−1, writing the count as n−1n - 1n−1, and evaluate the product or power first.

e.g. 2,9,16,…2, 9, 16, \ldots2,9,16,… has d=7d = 7d=7, so a20=2+19×7=135a_{20} = 2 + 19 \times 7 = 135a20​=2+19×7=135.

Recover ddd or rrr, and a1a_1a1​, from two known terms

  1. Count the positions apart, k−mk - mk−m, and substitute into ak=am+(k−m)da_k = a_m + (k-m)dak​=am​+(k−m)d or ak=amr k−ma_k = a_m r^{\,k-m}ak​=am​rk−m.
  2. Solve: divide out the coefficient for ddd, or isolate the power and take the root for rrr.
  3. An even number of positions apart fits both signs of rrr; pin it with another fact.
  4. Step back to a1a_1a1​ by subtracting ddd or dividing by rrr the right number of times.

e.g. a2=6a_2 = 6a2​=6 and a5=48a_5 = 48a5​=48 give 6r3=486r^3 = 486r3=48, so r=2r = 2r=2 and a1=3a_1 = 3a1​=3.

Decide whether a value is a term, and which one

  1. Set the explicit formula equal to the target value and solve for nnn: linear for arithmetic; geometric needs the power isolated, then matching powers of rrr directly, or a logarithm when r>0r > 0r>0, r≠1r \neq 1r=1, and Va1>0\tfrac{V}{a_1} > 0a1​V​>0.
  2. Accept only a positive whole nnn; a fraction or a non-whole exponent means the value is not a term at all.

e.g. For 5,8,11,…5, 8, 11, \ldots5,8,11,…: 5+3(n−1)=985 + 3(n-1) = 985+3(n−1)=98 gives n=32n = 32n=32, while 100100100 gives n−1=953n - 1 = \tfrac{95}{3}n−1=395​, so 100100100 never appears.

Total the first nnn terms of an arithmetic series

  1. Read a1a_1a1​, ddd, and how many terms the question wants.
  2. Knowing the last term, use Sn=n(a1+an)2S_n = \frac{n(a_1 + a_n)}{2}Sn​=2n(a1​+an​)​; knowing only a1a_1a1​ and ddd, use Sn=n2(2a1+(n−1)d)S_n = \frac{n}{2}\big(2a_1 + (n-1)d\big)Sn​=2n​(2a1​+(n−1)d).
  3. Simplify inside the bracket, then divide by 222.

e.g. 3,7,11,…3, 7, 11, \ldots3,7,11,… with n=25n = 25n=25: S25=252(6+96)=1275S_{25} = \tfrac{25}{2}(6 + 96) = 1275S25​=225​(6+96)=1275.

Total a range of terms, the mmmth through the nnnth

  1. Compute the end terms ama_mam​ and ana_nan​, and count n−m+1n - m + 1n−m+1 terms, both ends included.
  2. Apply the series formula to that run with its own first term, last term, and count.
  3. Check with Sn−Sm−1S_n - S_{m-1}Sn​−Sm−1​, which strips everything before position mmm.

e.g. With a1=4a_1 = 4a1​=4, d=3d = 3d=3, terms 101010 to 303030 run 313131 to 919191 over 212121 terms: 21(31+91)2=1281\frac{21(31 + 91)}{2} = 1281221(31+91)​=1281.

Total a geometric series, finite or infinite

  1. Read a1a_1a1​ as the first term written, rrr by dividing consecutive terms.
  2. Finite: confirm r≠1r \neq 1r=1 (if r=1r = 1r=1 the total is n a1n\,a_1na1​), then substitute a1a_1a1​, rrr, and nnn, evaluating r nr^{\,n}rn first.
  3. Infinite: test ∣r∣<1|r| < 1∣r∣<1 first and report no finite sum if it fails; otherwise substitute into S=a11−rS = \frac{a_1}{1 - r}S=1−ra1​​.

e.g. 8+4+2+⋯=81−12=168 + 4 + 2 + \cdots = \frac{8}{1 - \tfrac{1}{2}} = 168+4+2+⋯=1−21​8​=16, while the 646464-square chessboard totals 264−12^{64} - 1264−1.

Turn a repeating decimal into an exact fraction

  1. Identify the repeating block and its length bbb in digits, with the block starting right after the decimal point.
  2. Write the decimal as place-value copies of that block, so a1a_1a1​ is the block over 10 b10^{\,b}10b and r=110 br = \frac{1}{10^{\,b}}r=10b1​.
  3. Apply S=a11−rS = \frac{a_1}{1 - r}S=1−ra1​​, then reduce to lowest terms.

e.g. 0.48‾=48/1001−1/100=4899=16330.\overline{48} = \frac{48/100}{1 - 1/100} = \frac{48}{99} = \frac{16}{33}0.48=1−1/10048/100​=9948​=3316​.

Collapse a telescoping sum

  1. Rewrite each term as a difference of shifted values (consecutive values are the simplest, gap-1, case), splitting the fraction or rationalizing the radical denominator.
  2. Confirm the split by recombining it, inserting any correcting constant it reveals.
  3. Write out enough brackets to see which pieces fail to cancel; a wider gap leaves more survivors per end, and every one of them must be kept.
  4. For a gap-1 telescope, read the total as b1−bn+1b_1 - b_{n+1}b1​−bn+1​, or bn+1−b1b_{n+1} - b_1bn+1​−b1​ in mirror direction; for a wider gap, combine all the surviving boundary values instead of applying the gap-1 formula. For the infinite version, use that combination's limit if it settles at one fixed value (not necessarily zero), otherwise there is no finite sum.

e.g. ∑k=1991k+k+1=100−1=9\sum_{k=1}^{99} \frac{1}{\sqrt{k} + \sqrt{k+1}} = \sqrt{100} - \sqrt{1} = 9∑k=199​k​+k+1​1​=100​−1​=9.

Set up a word problem about a repeating pattern

  1. Decide what repeats: a fixed AMOUNT added makes it arithmetic with that ddd, a fixed MULTIPLE makes it geometric with that rrr.
  2. Name a1a_1a1​ as the value at position 111, and decide whether the question wants one term or a total.
  3. Apply the matching formula and answer what was actually asked, with units.

e.g. 121212 rows from 181818 seats with d=2d = 2d=2 end at a12=40a_{12} = 40a12​=40, so S12=12(18+40)2=348S_{12} = \frac{12(18 + 40)}{2} = 348S12​=212(18+40)​=348 seats.

Exam traps

  • Trap Reporting a term when the question asked for a sum, or the reverse: for 2,5,8,112, 5, 8, 112,5,8,11, answering "the sum of the first four terms" with 111111.

    Fix 111111 is a4a_4a4​, the fourth TERM; the series is 2+5+8+11=262 + 5 + 8 + 11 = 262+5+8+11=26. Check for the word term or sum before picking a formula.

  • Trap Off-by-one on an index: writing an=a1+nda_n = a_1 + ndan​=a1​+nd, counting the 101010th through the 303030th terms as 30−10=2030 - 10 = 2030−10=20 terms, or stopping a gap-111 telescope at bnb_nbn​.

    Fix Each is one item out. a1+nda_1 + nda1​+nd is really an+1a_{n+1}an+1​, since the first term takes no step; the range holds 30−10+1=2130 - 10 + 1 = 2130−10+1=21 terms because both ends count; a gap-111 telescope's last survivor is bn+1b_{n+1}bn+1​, not bnb_nbn​ (a wider gap leaves more back survivors still).

  • Trap Reaching for n(a1+an)2\frac{n(a_1 + a_n)}{2}2n(a1​+an​)​ to total a geometric series.

    Fix That averages the first and last terms, exact only for evenly spaced ones. Geometric terms are scaled, not stepped, so use a1(1−r n)1−r\frac{a_1(1 - r^{\,n})}{1 - r}1−ra1​(1−rn)​.

  • Trap Hunting for rrr by subtracting consecutive terms, or by dividing a term by the one AFTER it.

    Fix The ratio is a term over the one before it, r=a2a1r = \frac{a_2}{a_1}r=a1​a2​​; the other way gives the reciprocal. In 3,6,12,243, 6, 12, 243,6,12,24 every ratio is 222 while the differences never settle.

  • Trap Dropping the minus sign of a negative ratio inside a11−r\frac{a_1}{1 - r}1−ra1​​.

    Fix With a1=9a_1 = 9a1​=9 and r=−13r = -\tfrac{1}{3}r=−31​ the denominator is 1−(−13)=431 - \left(-\tfrac{1}{3}\right) = \tfrac{4}{3}1−(−31​)=34​, so the sum is 274\tfrac{27}{4}427​, not the 272\tfrac{27}{2}227​ that 1−131 - \tfrac{1}{3}1−31​ would give.

  • Trap Dividing an inequality by log⁡r\log rlogr without flipping it: reading 300⋅0.6 n−1<20300 \cdot 0.6^{\,n-1} < 20300⋅0.6n−1<20 as n−1<log⁡(1/15)log⁡0.6n - 1 < \frac{\log(1/15)}{\log 0.6}n−1<log0.6log(1/15)​, then rounding down.

    Fix For 0<r<10 < r < 10<r<1 that logarithm is negative, so dividing reverses the sign: n−1>5.30n - 1 > 5.30n−1>5.30, and a position rounds UP, giving n=7n = 7n=7. The 666th rebound is 23.323.323.3 cm, still above 202020.

  • Trap Totalling a bouncing ball's travel as one series: dropped from 121212 m and rebounding to half, answering 121−12=24\frac{12}{1 - \tfrac{1}{2}} = 241−21​12​=24 m.

    Fix The drop is travelled once, every rebound twice, up and down: 12+2(61−12)=12+24=3612 + 2\left(\frac{6}{1 - \tfrac{1}{2}}\right) = 12 + 24 = 3612+2(1−21​6​)=12+24=36 m.

  • Trap Dropping a number into the wrong slot: reading "the 121212th term is 404040" as n=40n = 40n=40, or putting the term count where rrr belongs.

    Fix nnn is only ever a position or a count, rrr is the multiplier, ana_nan​ and SnS_nSn​ are values. Here n=12n = 12n=12 goes in and 404040 is what the formula must produce.

  • Trap Leaving one survivor at each end of a gap-222 telescope, so ∑k=1n1k(k+2)\sum_{k=1}^{n} \frac{1}{k(k+2)}∑k=1n​k(k+2)1​ is read as 12(1−1n+2)\frac{1}{2}\left(1 - \frac{1}{n+2}\right)21​(1−n+21​).

    Fix With a gap of 222 each piece cancels two brackets later, so inside the 12\tfrac{1}{2}21​ bracket the survivors are 111 and 12\tfrac{1}{2}21​ in front, 1n+1\frac{1}{n+1}n+11​ and 1n+2\frac{1}{n+2}n+21​ at the back. At n=2n = 2n=2 the correct 1124\tfrac{11}{24}2411​ beats the wrong 38\tfrac{3}{8}83​.
