    An arithmetic sequence has a1=−2a_1=-2a1​=−2 and common difference d=6d=6d=6. Find a13a_{13}a13​.

    1. Hint 1

      Reaching a position costs one fewer equal steps than the position number, because the first term is already there.

    2. Hint 2

      Write the explicit rule from the first term and the common difference, then substitute the requested position.

    Answer

    a13=70a_{13}=70a13​=70.

    Full solution

    Reaching position 131313 takes 121212 steps of 666 from the first term, so

    a13=−2+12(6)a_{13}=-2+12(6)a13​=−2+12(6)

    which is 707070.

    Answer

    a13=70a_{13}=70a13​=70.

    Key idea

    The nnnth term sits n−1n-1n−1 equal steps from the first term.

  2. Problem 2 The covered digit

    The three numbers 525252, 4□4\square4□, and 383838, in that order, form an arithmetic sequence, where the square hides the ones digit of the middle number. Find the middle number.

    1. Hint 1

      The first and last numbers are separated by two equal steps.

    2. Hint 2

      Find the signed change per step, then add one such step to the first number.

    Answer

    454545, so the covered digit is 555.

    Full solution

    Two steps together change 525252 to 383838.

    The total change is

    38−52=−1438-52=-1438−52=−14

    so each step changes the value by

    d=−142d=\frac{-14}{2}d=2−14​

    which is −7-7−7.

    The middle number is

    52−7=4552-7=4552−7=45

    so the covered digit is 555.

    Checking, 45−52=−745-52=-745−52=−7 and 38−45=−738-45=-738−45=−7, so both consecutive differences agree.

    Answer

    454545, so the covered digit is 555.

    Key idea

    Equal steps between known terms can recover a missing term and its digits.

  5. Problem 5 The matching entry

    A sequence is given by an=17−3(n−1)a_n=17-3(n-1)an​=17−3(n−1) for positive integers nnn. Find every position where the term value equals its own position number.

    1. Hint 1

      The position number is also the value required at that position.

    2. Hint 2

      Set the term expression equal to nnn, then check that the resulting position is a positive integer.

    Answer

    Position 555, where a5=5a_5=5a5​=5.

    Full solution

    The required equality is an=na_n=nan​=n, so

    17−3(n−1)=n20−3n=n20=4nn=5\begin{aligned}17-3(n-1)&=n\\20-3n&=n\\20&=4n\\n&=5\end{aligned}17−3(n−1)20−3n20n​=n=n=4n=5​

    The solution is a positive integer, and

    17−3(5−1)=517-3(5-1)=517−3(5−1)=5

    confirms that the term at position 555 is 555.

    The equation has only this solution, so there is no other matching position.

    Answer

    Position 555, where a5=5a_5=5a5​=5.

    Key idea

    A term that equals its own position is found by equating the term rule with the position variable.

  6. Problem 6 The tile panels

    The figure shows the first three panels of a tile pattern. Each later panel repeats the shaded column unchanged and adds one more column of the same size as the columns already beside it, with no overlaps. Write the tile count ana_nan​ for Panel nnn as an explicit rule in the form an=pn+qa_n=pn+qan​=pn+q, and find the count in Panel 121212.

    Text description of this figure

    Three tile panels stand side by side, labeled Panel 1, Panel 2 and Panel 3 from left to right. Every panel begins on the left with the same lightly shaded column of five equal square tiles. To the right of that column, Panel 1 has one unshaded column of three tiles, Panel 2 has two unshaded columns of three tiles, and Panel 3 has three unshaded columns of three tiles.     1. Hint 1

      Compare the three panels tile by tile: one part never changes.

    2. Hint 2

      Each added column contributes the same count, while the left column contributes once.

    Full solution

    In every panel the shaded column holds five tiles.

    Answer

  7. Problem 7 The reversed strip

    A strip has nine labels in order, with values an=−3+2.5(n−1)a_n=-3+2.5(n-1)an​=−3+2.5(n−1) for integers 1≤n≤91\le n\le91≤n≤9. Give bnb_nbn​ in the form bn=b1+(n−1)Db_n=b_1+(n-1)Dbn​=b1​+(n−1)D, and find the new position of the label 9.59.59.5.

    1. Hint 1

      The old last term becomes the new first, and each step now travels backward through the old list.

    2. Hint 2

      Find the old ninth value and reverse the sign of the old difference.

    3. Hint 3

    bn=17−2.5(n−1)b_n=17-2.5(n-1)bn​=17−2.5(n−1)

    17−2.5(n−1)=9.52.5(n−1)=7.5n−1=3n=4\begin{aligned}17-2.5(n-1)&=9.5\\2.5(n-1)&=7.5\\n-1&=3\\n&=4\end{aligned}17−2.5(n−1)2.5(n−1)n−1n​=9.5=7.5=3=4​

    The original sixth label is

  8. Problem 8 The seven entries

    A list has seven real entries a1a_1a1​ through a7a_7a7​ and satisfies a3+a7=2a5a_3+a_7=2a_5a3​+a7​=2a5​. Jo says this guarantees that the whole list is arithmetic. Decide whether Jo is right, and justify your decision.

    1. Hint 1

      A condition on a few entries need not control every consecutive difference.

    2. Hint 2

      Keep the three entries in the displayed equality compatible, then consider changing an entry absent from that equality.

    Answer

    No; one example is 1,2,3,4,5,9,71,2,3,4,5,9,71,2,3,4,5,9,7.

    Full solution

    For the example 1,2,3,4,5,9,71,2,3,4,5,9,71,2,3,4,5,9,7, the required entries satisfy

    3+7=2(5)3+7=2(5)3+7=2(5)

    so the stated condition holds.

    But the first difference is 2−1=12-1=12−1=1, while the change from the fifth entry to the sixth is 9−5=49-5=49−5=4.

    Since these differences disagree, the list is not arithmetic.

    This example disproves the guarantee.

    Answer

    No; one example is 1,2,3,4,5,9,71,2,3,4,5,9,71,2,3,4,5,9,7.

    Key idea

    An equality involving selected entries does not by itself guarantee a constant difference throughout a list.

  9. Problem 9 The stack of cups

    Measured heights of a stack of nested cups are: one cup, 9.59.59.5 centimeters; two cups, 11.111.111.1 centimeters; three cups, 12.712.712.7 centimeters; four cups, 14.314.314.3 centimeters.   10. Problem 10 The constant record

    For positive integers nnn, a sequence has an=8+0(n−1)a_n=8+0(n-1)an​=8+0(n−1). Setting an=8a_n=8an​=8, Ivo reaches 0=0(n−1)0=0(n-1)0=0(n−1).     Answer

    No. Every positive integer position has value 888; no position has value 999.

    Full solution

    For every allowed nnn, 0(n−1)=00(n-1)=00(n−1)=0, so

    an=8a_n=8an​=8

    The equation asking for value 888 becomes 8=88=88=8 and holds at every positive integer position.

    Asking for value 999 would require 8=98=98=9, which is false at every position.

    Canceling the zero from 0=0(n−1)0=0(n-1)0=0(n−1) divides both sides by zero, which is undefined, so that step cannot restrict the positions to n=1n=1n=1.

    Answer

    No. Every positive integer position has value 888; no position has value 999.

    Key idea

    A zero common difference produces a constant sequence, whose membership questions must be settled without dividing by that difference.
