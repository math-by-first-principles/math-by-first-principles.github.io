    A student claims a÷b=b÷aa \div b = b \div aa÷b=b÷a for all nonzero numbers. Which values disprove it?

    Answer choices for question 2

    Solution

    Correct answer: A

    Division is not commutative, so look for values where the two sides differ. Try a=8a = 8a=8, b=2b = 2b=2.

    8÷2=4,2÷8=148 \div 2 = 4, \qquad 2 \div 8 = \frac{1}{4}8÷2=4,2÷8=41​

    The sides differ, so the claim is false. The other choices use a=ba = ba=b, where both sides equal 111 and hide the difference.

    Solution

  9. 9

    A claim states that n2=n+nn^2 = n + nn2=n+n for all nnn. Which statement is true?

    Answer choices for question 9

    Solution

    Correct answer: D

    Test values, the way this lesson checks a claim, instead of solving.

    02=0=0+0,22=4=2+2,32=9≠3+3=60^2 = 0 = 0 + 0, \qquad 2^2 = 4 = 2 + 2, \qquad 3^2 = 9 \neq 3 + 3 = 602=0=0+0,22=4=2+2,32=9=3+3=6

    The two sides agree at n=0n = 0n=0 and n=2n = 2n=2 but disagree at n=3n = 3n=3. So the claim is not an identity (it fails at n=3n = 3n=3) and is not never true (it holds at n=0n = 0n=0); it is true for some numbers and false for others. Of the four options, only "true at n=0n = 0n=0 and n=2n = 2n=2" fits.

  10. 10

    Which equation shows the distributive law?

    Answer choices for question 10

    Solution

    Correct answer: B

    The distributive law spreads a factor over a sum.

    a(b+c)=ab+aca(b + c) = ab + aca(b+c)=ab+ac

    The others are the associative, commutative, and identity laws.

    A student says "5x5x5x means 555 next to xxx, so if x=2x = 2x=2 then 5x=525x = 525x=52." What is the mistake?

    Answer choices for question 12

    Solution

    Correct answer: B

    A number written next to a variable means multiply, not place the digits side by side.

    5x=5×2=105x = 5 \times 2 = 105x=5×2=10

    Substituting in parentheses, 5(2)=105(2) = 105(2)=10, keeps the multiplication clear and avoids the trap.
