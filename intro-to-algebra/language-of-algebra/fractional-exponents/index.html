Fractional Exponents and Radicals

Intuition

You have watched the exponent laws survive one extension after another. They were built for counting factors, where ana^nan means nnn copies of aaa multiplied together, yet the same rules kept working. They held even when the exponent dropped to zero and then went negative, because we defined a0a^0a0 and a−na^{-n}a−n to be exactly the values the laws demanded. Now ask the next question: what could an exponent like a1/2a^{1/2}a1/2 possibly mean? Multiplying aaa by itself “half a time” is nonsense, so once again we refuse to guess. We insist the laws keep holding and let them tell us what the symbol must be. The answer turns out to be something you already know well, the square root. Carrying the same idea upward ties roots of every kind to a single, tidy notation.

Learning goals

  • Explain how the exponent laws make a1/2a^{1/2}a1/2 a square root, and why the principal-root convention then selects a\sqrt{a}a​
  • Read the denominator as the root index and the numerator as the power
  • Switch between a radical and a fractional exponent in either direction
  • Pull perfect-power factors out, so 72\sqrt{72}72​ is 626\sqrt{2}62​
  • Combine like radicals only, matching index and radicand
  • Require a nonnegative radicand for an even index, unlike an odd one

What a one-half power must mean

The product rule for exponents says that to multiply two powers of the same base you add the exponents: am⋅an=am+na^m \cdot a^n = a^{m+n}am⋅an=am+n. That rule was proved for whole-number exponents, but insisting it keeps holding for a fractional one is exactly the choice this lesson makes. Try it on a number first, with m=n=12m = n = \tfrac{1}{2}m=n=21​ and a=9a = 9a=9:

91/2⋅91/2=912+12=91=9.9^{1/2} \cdot 9^{1/2} = 9^{\frac{1}{2} + \frac{1}{2}} = 9^1 = 9.91/2⋅91/2=921​+21​=91=9.

Whatever 91/29^{1/2}91/2 means, it has to square to give 999. Nothing about that argument used the number 999 in particular, so the same reasoning holds for any base aaa:

a1/2⋅a1/2=a12+12=a1=a.a^{1/2} \cdot a^{1/2} = a^{\frac{1}{2} + \frac{1}{2}} = a^1 = a.a1/2⋅a1/2=a21​+21​=a1=a.

Read that general line the same way. It says the number a1/2a^{1/2}a1/2, multiplied by itself, gives back aaa. A number that squares to aaa is exactly what a square root of aaa is. So if the product rule is to keep holding, a1/2a^{1/2}a1/2 must be a square root of aaa, and the next block pins that down to a single value.

Why a1/2a^{1/2}a1/2 must equal a\sqrt{a}a​#

The paragraph above narrows a1/2a^{1/2}a1/2 down to being some square root of aaa. It does not yet say which one.

There are two numbers that square to a positive aaa, one positive and one negative. So to give the symbol a single value we make the same choice the radical sign already makes: a1/2a^{1/2}a1/2 is the non-negative one. With that agreement,

a1/2=a.a^{1/2} = \sqrt{a}.a1/2=a​.

The base must be zero or positive for this to describe a real number, because no real number squares to a negative. So a1/2a^{1/2}a1/2 is defined only for a≥0a \ge 0a≥0, and it is the principal (non-negative) square root, exactly the a\sqrt{a}a​ you already know.

∎

The picture behind this is the one you met when square roots were introduced. A square of area aaa has side length a\sqrt{a}a​, because the side multiplied by itself is the area. The fractional exponent just records that same fact, since a1/2a^{1/2}a1/2 is the number you multiply by itself to reach aaa.

The nth root

The same move works for any root. Instead of splitting the exponent into two halves, split 111 into nnn equal pieces of size 1n\tfrac{1}{n}n1​. The rule you need now is the power-of-a-power rule, (ap)q=apq(a^p)^q = a^{pq}(ap)q=apq, which lets you raise a1/na^{1/n}a1/n to the nnnth power by multiplying the exponents:

(a1/n)n=a1n⋅n=a1=a.\left(a^{1/n}\right)^n = a^{\frac{1}{n} \cdot n} = a^1 = a.(a1/n)n=an1​⋅n=a1=a.

So a1/na^{1/n}a1/n is a number whose nnnth power is aaa. That number is called the nnnth root of aaa, and it gets its own symbol, an extension of the radical sign you already use for square roots.

Why a1/na^{1/n}a1/n is the nnnth root of aaa#

The line above already shows that raising a1/na^{1/n}a1/n to the nnnth power returns aaa, so a1/na^{1/n}a1/n is some nnnth root of aaa. Whether that root is unique, and what it equals, depends on whether nnn is even or odd.

When nnn is even, a positive aaa has two real nnnth roots, one positive and one negative, so exactly as with the square root we take the non-negative one; a=0a = 0a=0 has the single root 000. Either way we require a≥0a \ge 0a≥0:

a1/n=an(a≥0, n even).a^{1/n} = \sqrt[n]{a} \qquad (a \ge 0,\ n \text{ even}).a1/n=na​(a≥0, n even).

When nnn is odd there is exactly one real nnnth root and no sign worry, because an odd number of negative factors stays negative, so a1/n=ana^{1/n} = \sqrt[n]{a}a1/n=na​ for every real aaa. For instance −83=−2\sqrt[3]{-8} = -23−8​=−2, since (−2)3=−8(-2)^3 = -8(−2)3=−8. Contrast that with an even index on the same kind of number: −164\sqrt[4]{-16}4−16​ has no real value at all, since no real number raised to the fourth power is negative.

∎

In the symbol an\sqrt[n]{a}na​, the small number nnn is the index of the root and the number aaa underneath is the radicand. A square root is the case n=2n = 2n=2, and its index is left unwritten: a\sqrt{a}a​ means a2=a1/2\sqrt[2]{a} = a^{1/2}2a​=a1/2. A cube root has index 333, written a3=a1/3\sqrt[3]{a} = a^{1/3}3a​=a1/3. You read an\sqrt[n]{a}na​ as “the nnnth root of aaa.”

Keep the even-odd rule from above in mind for every root in this lesson: an even index needs a radicand that is zero or positive, and an odd index accepts any real radicand.

Just as knowing the perfect squares makes square roots quick, knowing the small perfect cubes makes cube roots quick:

nnn111222333444555
n3n^3n3111888272727646464125125125

Reading the bottom row back to the top gives the cube root directly. Since 272727 sits under 333, you know 273=3\sqrt[3]{27} = 3327​=3.

Worked example 1 Evaluate 273\sqrt[3]{27}327​ and 164\sqrt[4]{16}416​

For each one, find the number whose repeated power lands on the radicand.

For 273\sqrt[3]{27}327​, the index is 333, so search for the number whose cube is 272727. Since 33=273^3 = 2733=27,

273=3.\sqrt[3]{27} = 3.327​=3.

For 164\sqrt[4]{16}416​, the index is 444, so search for the number whose fourth power is 161616. Since 24=162^4 = 1624=16,

164=2.\sqrt[4]{16} = 2.416​=2.

A quick check confirms each: raise the answer to the index and you should return to the radicand, and indeed 33=273^3 = 2733=27 and 24=162^4 = 1624=16.

Raising to a fraction like two-thirds

A fractional exponent whose top is not 111, such as a2/3a^{2/3}a2/3, combines a root and a power in one symbol. Try it first on a number before asking what the rule is in general.

Try both orders on 82/38^{2/3}82/3 to see why root-first is easier. Root-first gives (83)2=22=4\left(\sqrt[3]{8}\right)^2 = 2^2 = 4(38​)2=22=4, working with the small number 888. Power-first gives 823=643=4\sqrt[3]{8^2} = \sqrt[3]{64} = 4382​=364​=4, the same answer but by way of the larger 646464. Same result, less arithmetic on the first route.

That pattern holds for every fractional exponent, not just 23\tfrac{2}{3}32​. Because mn=m⋅1n=1n⋅m\tfrac{m}{n} = m \cdot \tfrac{1}{n} = \tfrac{1}{n} \cdot mnm​=m⋅n1​=n1​⋅m, the power-of-a-power rule lets you read am/na^{m/n}am/n in two equivalent ways, one for each order you just tried.

Why am/n=(an)m=amna^{m/n} = \left(\sqrt[n]{a}\right)^m = \sqrt[n]{a^m}am/n=(na​)m=nam​#

Take a≥0a \ge 0a≥0, as in the last two proofs, so every root below names a real number, and let mmm and nnn be positive whole numbers. Start from the exponent mn\tfrac{m}{n}nm​ and apply (ap)q=apq(a^p)^q = a^{pq}(ap)q=apq, splitting the fraction in each direction.

Taking the 1n\tfrac{1}{n}n1​ first, so that the root is done before the power,

am/n=a1n⋅m=(a1/n)m=(an)m.a^{m/n} = a^{\frac{1}{n} \cdot m} = \left(a^{1/n}\right)^m = \left(\sqrt[n]{a}\right)^m.am/n=an1​⋅m=(a1/n)m=(na​)m.

Taking the mmm first, so that the power is done before the root,

am/n=am⋅1n=(am)1/n=amn.a^{m/n} = a^{m \cdot \frac{1}{n}} = \left(a^m\right)^{1/n} = \sqrt[n]{a^m}.am/n=am⋅n1​=(am)1/n=nam​.

Both describe the number am/na^{m/n}am/n, so they are equal. In either reading the denominator nnn is the index of the root and the numerator mmm is the power. For a≥0a \ge 0a≥0 the two orders always agree, but taking the root first usually keeps the numbers small, since you root the base before it grows.

∎

Worked example 2 Evaluate 82/38^{2/3}82/3 and 323/532^{3/5}323/5

Take the root of index equal to the denominator first, then raise to the numerator.

For 82/38^{2/3}82/3, the denominator 333 calls for a cube root and the numerator 222 for a square. Cube-root 888, then square:

82/3=(83)2=22=4.8^{2/3} = \left(\sqrt[3]{8}\right)^2 = 2^2 = 4.82/3=(38​)2=22=4.

For 323/532^{3/5}323/5, the denominator 555 calls for a fifth root and the numerator 333 for a cube. Since 25=322^5 = 3225=32, the fifth root of 323232 is 222, then cube it:

323/5=(325)3=23=8.32^{3/5} = \left(\sqrt[5]{32}\right)^3 = 2^3 = 8.323/5=(532​)3=23=8.

Rooting first kept both bases small, 888 and 323232, instead of jumping to 82=648^2 = 6482=64 or 323=3276832^3 = 32768323=32768 before rooting.

Radicals and fractional exponents are the same idea

Everything so far can be read in one sentence: a radical and a fractional exponent are two names for the same number. Collecting the results, for a≥0a \ge 0a≥0 and positive whole numbers mmm and nnn,

an=a1/n,(an)m=am/n=amn.\sqrt[n]{a} = a^{1/n}, \qquad \left(\sqrt[n]{a}\right)^m = a^{m/n} = \sqrt[n]{a^m}.na​=a1/n,(na​)m=am/n=nam​.

This is a dictionary you can read in either direction. A radical becomes a fractional exponent by putting the index in the denominator, and a fractional exponent becomes a radical by making the denominator the index. Switching to exponent form is often what makes a messy expression obey the familiar exponent laws. Switching to radical form is often what makes a value easy to evaluate.

Worked example 3 Rewrite 734\sqrt[4]{7^3}473​ with a fractional exponent, and evaluate 95/29^{5/2}95/2

Use the dictionary in each direction.

For 734\sqrt[4]{7^3}473​, the index 444 becomes the denominator and the inside power 333 becomes the numerator:

734=73/4.\sqrt[4]{7^3} = 7^{3/4}.473​=73/4.

For 95/29^{5/2}95/2, read it back as a radical to evaluate it. The denominator 222 is a square root and the numerator 555 is the power, so square-root 999 first, then raise to the fifth:

95/2=(9)5=35=243.9^{5/2} = \left(\sqrt{9}\right)^5 = 3^5 = 243.95/2=(9​)5=35=243.

Rooting first turned the base into the small number 333 before the power made it grow. That route is far easier than computing 95=590499^5 = 5904995=59049 and then taking its square root.

Simplifying radicals

Roots split across a product exactly the way powers do. The rule is abn=an⋅bn\sqrt[n]{ab} = \sqrt[n]{a} \cdot \sqrt[n]{b}nab​=na​⋅nb​, and the fractional-exponent form shows why in one line.

Why abn=an bn\sqrt[n]{ab} = \sqrt[n]{a}\,\sqrt[n]{b}nab​=na​nb​#

Write the root as a fractional exponent, then use the rule for a power of a product, (xy)p=xp yp(xy)^p = x^p\,y^p(xy)p=xpyp. That rule holds for a fractional exponent for the same reason it holds for a whole one: raising the right-hand side to the nnnth power returns ababab. With p=1np = \tfrac{1}{n}p=n1​,

abn=(ab)1/n=a1/n b1/n=an bn.\sqrt[n]{ab} = (ab)^{1/n} = a^{1/n}\,b^{1/n} = \sqrt[n]{a}\,\sqrt[n]{b}.nab​=(ab)1/n=a1/nb1/n=na​nb​.

For even indices, take aaa and bbb to be zero or positive so every root is a real number. This is the same product rule you proved directly for square roots, now seen as one more consequence of the exponent laws. With that restriction, the rule holds for roots of every index.

∎

Division splits the same way, and for the same reason: writing the root as a fractional exponent and using the matching rule for a power of a quotient, (ab)p=apbp\left(\tfrac{a}{b}\right)^{p} = \tfrac{a^p}{b^p}(ba​)p=bpap​,

abn=(ab)1/n=a1/nb1/n=anbn,\sqrt[n]{\frac{a}{b}} = \left(\frac{a}{b}\right)^{1/n} = \frac{a^{1/n}}{b^{1/n}} = \frac{\sqrt[n]{a}}{\sqrt[n]{b}},nba​​=(ba​)1/n=b1/na1/n​=nb​na​​,

with b≠0b \neq 0b=0 and, for an even index, both aaa and bbb zero or positive. For instance, 502=502=25=5\dfrac{\sqrt{50}}{\sqrt{2}} = \sqrt{\dfrac{50}{2}} = \sqrt{25} = 52​50​​=250​​=25​=5: one root instead of two.

The product rule earns its keep when you simplify a radical, meaning you pull out any factor that is a perfect power for the index. For a square root you hunt for a perfect-square factor; for a cube root, a perfect-cube factor. Split the radicand into that factor times whatever is left, then root the part that comes out cleanly.

Worked example 4 Simplify 72\sqrt{72}72​ and 803\sqrt[3]{80}380​

In each case pull out the largest perfect-power factor that matches the index.

For 72\sqrt{72}72​, the largest perfect-square factor of 727272 is 363636, since 72=36⋅272 = 36 \cdot 272=36⋅2. Split the root and evaluate the part that comes out:

72=36⋅2=36 2=62.\sqrt{72} = \sqrt{36 \cdot 2} = \sqrt{36}\,\sqrt{2} = 6\sqrt{2}.72​=36⋅2​=36​2​=62​.

For 803\sqrt[3]{80}380​, look for the largest perfect-cube factor. Since 80=8⋅1080 = 8 \cdot 1080=8⋅10 and 8=238 = 2^38=23 is a perfect cube,

803=8⋅103=83 103=2103.\sqrt[3]{80} = \sqrt[3]{8 \cdot 10} = \sqrt[3]{8}\,\sqrt[3]{10} = 2\sqrt[3]{10}.380​=38⋅10​=38​310​=2310​.

The leftover radicands are 222 under the square root and 101010 under the cube root. Neither has a further factor that is a perfect power for its index, so each expression is fully simplified.

Adding and subtracting radicals

Two radicals are like radicals when they have the same index and the same radicand, such as 232\sqrt{3}23​ and 535\sqrt{3}53​. Like radicals add and subtract the same way like terms do, because the shared radical behaves as a common factor. Pulling it out is just the distributive law from the last lesson:

23+53=(2+5)3=73.2\sqrt{3} + 5\sqrt{3} = (2 + 5)\sqrt{3} = 7\sqrt{3}.23​+53​=(2+5)3​=73​.

Unlike radicals do not combine. There is no rule that adds the radicands: 2+3\sqrt{2} + \sqrt{3}2​+3​ is not 5\sqrt{5}5​, because roots split across products, never across sums. Once each term is in simplest form and the radicands still differ, the sum stays as two terms. Sometimes two radicals only look unlike until you simplify them, and then they turn out to match.

Worked example 5 Simplify 12+27\sqrt{12} + \sqrt{27}12​+27​

The two radicands are different, so the terms are not like radicals yet. Simplify each one first by pulling out its largest perfect-square factor.

Since 12=4⋅312 = 4 \cdot 312=4⋅3,

12=4 3=23,\sqrt{12} = \sqrt{4}\,\sqrt{3} = 2\sqrt{3},12​=4​3​=23​,

and since 27=9⋅327 = 9 \cdot 327=9⋅3,

27=9 3=33.\sqrt{27} = \sqrt{9}\,\sqrt{3} = 3\sqrt{3}.27​=9​3​=33​.

Now both terms carry the same radical 3\sqrt{3}3​, so they are like radicals and combine:

12+27=23+33=53.\sqrt{12} + \sqrt{27} = 2\sqrt{3} + 3\sqrt{3} = 5\sqrt{3}.12​+27​=23​+33​=53​.

The hidden common radical only appeared once each root was simplified, which is why simplifying first is the habit to build.

Negative fractional exponents

A negative fractional exponent asks nothing new. It just stacks two ideas you already have: the negative sign means take the reciprocal, and the fraction means take a root and a power. One bookkeeping rule keeps the domain from getting ambiguous: always write mn\tfrac{m}{n}nm​ in lowest terms, with no factor shared by mmm and nnn, so that an exponent has one settled index to check, not several equivalent fractions that could disagree. (Unreduced, (−8)2/6(-8)^{2/6}(−8)2/6 would look like it needs a sixth root, which rejects a negative base; reduced to (−8)1/3(-8)^{1/3}(−8)1/3, the same exponent plainly allows one.) With m/nm/nm/n in lowest terms, the domain is the same am/na^{m/n}am/n domain from before, with one extra condition: since am/na^{m/n}am/n becomes a denominator, it also cannot be zero. So am/na^{m/n}am/n itself must be defined and nonzero: for even nnn that means a>0a > 0a>0 (an even root needs a≥0a \ge 0a≥0, and 000 cannot be a denominator), while for odd nnn any nonzero aaa, positive or negative, still works. Then

a−m/n=1am/n=1(an)m.a^{-m/n} = \frac{1}{a^{m/n}} = \frac{1}{\left(\sqrt[n]{a}\right)^m}.a−m/n=am/n1​=(na​)m1​.

Handle the two jobs in order. First the minus sign flips the power into its reciprocal, then the fraction is evaluated as a root and a power just as before. A negative exponent moves the power to the denominator; taking a reciprocal never changes the sign of a nonzero number, so a−m/na^{-m/n}a−m/n is positive whenever am/na^{m/n}am/n is positive, and negative whenever am/na^{m/n}am/n is negative (which needs an odd nnn and a negative aaa, as in (−8)−1/3=1−83=1−2=−12(-8)^{-1/3} = \tfrac{1}{\sqrt[3]{-8}} = \tfrac{1}{-2} = -\tfrac{1}{2}(−8)−1/3=3−8​1​=−21​=−21​).

Worked example 6 Evaluate 8−2/38^{-2/3}8−2/3 and 16−3/416^{-3/4}16−3/4

Take the reciprocal that the minus sign calls for, then evaluate the fractional power.

For 8−2/38^{-2/3}8−2/3, flip to a reciprocal, then read 82/38^{2/3}82/3 as a cube root followed by a square:

8−2/3=182/3=1(83)2=122=14.8^{-2/3} = \frac{1}{8^{2/3}} = \frac{1}{\left(\sqrt[3]{8}\right)^2} = \frac{1}{2^2} = \frac{1}{4}.8−2/3=82/31​=(38​)21​=221​=41​.

For 16−3/416^{-3/4}16−3/4, flip first, then take the fourth root and cube:

16−3/4=1163/4=1(164)3=123=18.16^{-3/4} = \frac{1}{16^{3/4}} = \frac{1}{\left(\sqrt[4]{16}\right)^3} = \frac{1}{2^3} = \frac{1}{8}.16−3/4=163/41​=(416​)31​=231​=81​.

Both values are positive fractions. With a positive base, the minus sign in the exponent produces a reciprocal, not a negative number.

Common mistakes

Common mistakes

  • Reading a1/2a^{1/2}a1/2 as half of aaa. A one-half power is a square root, not a division: 91/2=9=39^{1/2} = \sqrt{9} = 391/2=9​=3, not 9÷2=4.59 \div 2 = 4.59÷2=4.5. The denominator of the exponent is a root index, not a divisor of the base.
  • Confusing a fractional exponent with a negative one. a1/3a^{1/3}a1/3 is the cube root a3\sqrt[3]{a}3a​, while a−3a^{-3}a−3 is the reciprocal 1a3\tfrac{1}{a^3}a31​. A fraction in the exponent means a root; a minus sign in the exponent means a reciprocal. Only a−1/3=1a3a^{-1/3} = \tfrac{1}{\sqrt[3]{a}}a−1/3=3a​1​ does both.
  • Swapping the numerator and denominator in am/na^{m/n}am/n. The denominator is the index of the root and the numerator is the power. For 82/38^{2/3}82/3 take the cube root and then square, giving (83)2=4\left(\sqrt[3]{8}\right)^2 = 4(38​)2=4; do not take a square root and cube.
  • Splitting a root across a sum. a+b\sqrt{a + b}a+b​ is not a+b\sqrt{a} + \sqrt{b}a​+b​. For example 9+16=25=5\sqrt{9 + 16} = \sqrt{25} = 59+16​=25​=5, but 9+16=3+4=7\sqrt{9} + \sqrt{16} = 3 + 4 = 79​+16​=3+4=7. The product rule splits a product, never a sum.
  • Adding unlike radicals. 2+3\sqrt{2} + \sqrt{3}2​+3​ is not 5\sqrt{5}5​; no rule adds the radicands. Only like radicals, with the same index and radicand, add: 23+53=732\sqrt{3} + 5\sqrt{3} = 7\sqrt{3}23​+53​=73​.
  • Thinking a negative fractional exponent gives a negative value. 8−2/3=148^{-2/3} = \tfrac{1}{4}8−2/3=41​, a positive fraction, not −4-4−4. The minus sign moves the power into the denominator; it does not touch the sign of the result.

Key takeaways

  • Insisting the exponent laws keep holding makes a1/2a^{1/2}a1/2 a square root of aaa, since a1/2⋅a1/2=aa^{1/2} \cdot a^{1/2} = aa1/2⋅a1/2=a. The principal-root convention then picks the non-negative one, so a1/2=aa^{1/2} = \sqrt{a}a1/2=a​ for a≥0a \ge 0a≥0.
  • a1/n=ana^{1/n} = \sqrt[n]{a}a1/n=na​, the nnnth root: the number whose nnnth power is aaa. In an\sqrt[n]{a}na​ the index is nnn and the radicand is aaa.
  • am/n=(an)m=amna^{m/n} = \left(\sqrt[n]{a}\right)^m = \sqrt[n]{a^m}am/n=(na​)m=nam​ for a≥0a \ge 0a≥0: the denominator is the root index, the numerator is the power. Rooting first keeps the numbers small.
  • A radical and a fractional exponent are two names for one number, and you can switch between them in either direction.
  • abn=an bn\sqrt[n]{ab} = \sqrt[n]{a}\,\sqrt[n]{b}nab​=na​nb​ lets you pull out perfect-power factors, so 72=62\sqrt{72} = 6\sqrt{2}72​=62​ and 803=2103\sqrt[3]{80} = 2\sqrt[3]{10}380​=2310​.

A bit of history (optional)

A fractional power is something you can hear.

Climb twelve semitones up a piano and you arrive at the same note an octave higher. Its frequency is exactly double the original. Twelve equal steps, and together they double the frequency. So a single semitone cannot be an addition. It has to be a multiplication by some number rrr with r12=2r^{12} = 2r12=2. That number is the twelfth root of two, which this lesson would write as 21/122^{1/12}21/12.

Somebody had to calculate it. In 1584 a prince of the Ming court in China, Zhu Zaiyu, computed it to twenty-five digits on an enormous abacus. He arrived there by exactly the route this lesson recommends. He took the square root of two. He repeated that operation on the answer. Then he took the cube root of the result.

Read those three operations as exponents and you are reading the power-of-a-power rule. A square root of a square root delivers 21/42^{1/4}21/4. A cube root of that delivers 21/122^{1/12}21/12, since a third of a quarter is a twelfth. Seven semitones above a note, the interval musicians call a fifth, is therefore 27/122^{7/12}27/12. The denominator chooses the root and the numerator chooses the power, exactly as you read 82/38^{2/3}82/3.
