The Language of Algebra: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Variable
A letter standing for a number: one particular unknown to be found, as in x+3=7x + 3 = 7x+3=7, or every number, no matter which one, as in a+b=b+aa + b = b + aa+b=b+a.
Expression and equation
An expression names a value and has no equals sign, so you evaluate or simplify it; an equation states that two expressions are equal. Depending on which values make it true, an equation may be one to solve, an identity, or one with no solution at all.
Identity
An equation true for every value of its variables, such as a+0=aa + 0 = aa+0=a. An equation like x+3=7x + 3 = 7x+3=7, true at only one value, is one you solve rather than an identity.
Equivalent expressions
Two expressions giving the same value for every input, so they are exactly the two sides of an identity.
Counterexample
A single value at which the two sides of a claimed identity disagree. One disproves the claim; no finite list of agreements can prove one.
Term, coefficient, and variable part
A term is a signed piece of an expression added to the others; its coefficient is the numerical factor, its variable part the rest. In −5x-5x−5x these are −5-5−5 and xxx; a lone xxx has coefficient 111.
Like terms
Terms with the same variable part: the same letters at the same powers. So 4xy4xy4xy and 7yx7yx7yx are like terms, 3x23x^23x2 and 5x5x5x are not.
Index and radicand of an\sqrt[n]{a}na​
In an\sqrt[n]{a}na​ the index is nnn and the radicand is aaa. A square root is the case n=2n = 2n=2, with the index left unwritten.
Like radicals
Radicals sharing both an index and a radicand, such as 232\sqrt{3}23​ and 535\sqrt{3}53​.
Greatest common factor (GCF)
The largest factor every term shares: the greatest common divisor of the coefficients times each common variable at its lowest power. For 4x2+6x4x^2 + 6x4x2+6x it is 2x2x2x.
Algebraic fraction (rational expression)
A ratio of two expressions built only from addition, subtraction, and multiplication, such as x+1x−2\dfrac{x + 1}{x - 2}x−2x+1​. The bar still means divide top by bottom.
Excluded value
A value of the variable making a denominator zero, where the fraction is undefined: x2x−6\dfrac{x}{2x - 6}2x−6x​ excludes x=3x = 3x=3.
Least common denominator (LCD)
The smallest expression every denominator divides into. Adding or subtracting needs a common denominator, and the LCD is the one that keeps the work smallest. For 3x\dfrac{3}{x}x3​ and 12\dfrac{1}{2}21​ it is 2x2x2x.

Formulas and theorems

  • The laws of arithmetic, as identities

    a+b=b+aab=ba(a+b)+c=a+(b+c)(ab)c=a(bc)a+0=aa⋅1=aa+(−a)=0a⋅1a=1\begin{gathered} a + b = b + a \\ ab = ba \\ (a + b) + c = a + (b + c) \\ (ab)c = a(bc) \\ a + 0 = a \\ a \cdot 1 = a \\ a + (-a) = 0 \\ a \cdot \tfrac{1}{a} = 1 \end{gathered}a+b=b+aab=ba(a+b)+c=a+(b+c)(ab)c=a(bc)a+0=aa⋅1=aa+(−a)=0a⋅a1​=1​

    Use when Every real number, with the single restriction a≠0a \neq 0a=0 in the multiplicative inverse. Subtraction and division are neither commutative nor associative: 5−3≠3−55 - 3 \neq 3 - 55−3=3−5 and 8÷2≠2÷88 \div 2 \neq 2 \div 88÷2=2÷8.

  • The distributive law

    a(b+c)=ab+aca(b + c) = ab + aca(b+c)=ab+ac
    Text description

    A rectangle of height a and width b plus c, cut once into a piece of area a times b and a piece of area a times c.

    Use when Any real numbers, and any number of terms inside: a(b+c+d)=ab+ac+ada(b + c + d) = ab + ac + ada(b+c+d)=ab+ac+ad. The factor reaches every term, sign included.

    e.g. −3(x−4)=−3x+12-3(x - 4) = -3x + 12−3(x−4)=−3x+12.

  • Combining like terms

    mv+nv=(m+n)vmv + nv = (m + n)vmv+nv=(m+n)v

    Use when Only when the variable part vvv is identical in both terms; this is the distributive law read in reverse, and it combines like radicals too, with the shared radical playing the part of vvv.

    e.g. 4x2−2x2=2x24x^2 - 2x^2 = 2x^24x2−2x2=2x2, while 2x2+3x2x^2 + 3x2x2+3x is already finished.

  • Subtracting a whole expression

    −(a+b)=−a−b-(a + b) = -a - b−(a+b)=−a−b

    Use when Any expression. A leading minus is the factor −1-1−1 waiting to be distributed, so it flips every term's sign, not only the first.

    e.g. (7x+2)−(3x−5)=7x+2−3x+5=4x+7(7x + 2) - (3x - 5) = 7x + 2 - 3x + 5 = 4x + 7(7x+2)−(3x−5)=7x+2−3x+5=4x+7.

  • Product of two expressions

    (a+b)(c+d)=ac+ad+bc+bd(a + b)(c + d) = ac + ad + bc + bd(a+b)(c+d)=ac+ad+bc+bd

    Use when Written for two two-term factors, whose four products (First, Outer, Inner, Last) give the mnemonic FOIL. Longer factors need the general rule instead: every term of the first times every term of the second, then combine like terms.

    e.g. (2x−1)(x+4)=2x2+8x−x−4=2x2+7x−4(2x - 1)(x + 4) = 2x^2 + 8x - x - 4 = 2x^2 + 7x - 4(2x−1)(x+4)=2x2+8x−x−4=2x2+7x−4.

  • Two special products

    (a+b)(a−b)=a2−b2(a+b)2=a2+2ab+b2\begin{gathered} (a + b)(a - b) = a^2 - b^2 \\ (a + b)^2 = a^2 + 2ab + b^2 \end{gathered}(a+b)(a−b)=a2−b2(a+b)2=a2+2ab+b2​
    Text description

    Square of side (a+b) cut into a², two equal ab rectangles, b².

    Use when Optional: these are the Go Deeper shortcut shapes from Expanding and Factoring Expressions, not a separate rule to memorize. Both come from the same every-term-times-every-term expansion; in the first the two middle terms cancel, in the second they double.

    e.g. (x+5)(x−5)=x2−25(x + 5)(x - 5) = x^2 - 25(x+5)(x−5)=x2−25, while (x+3)2=x2+6x+9(x + 3)^2 = x^2 + 6x + 9(x+3)2=x2+6x+9.

  • Factoring out a common factor

    ab+ac=a(b+c)ab + ac = a(b + c)ab+ac=a(b+c)

    Use when aaa must be a factor of every term. Fully factored means aaa is the GCF.

    e.g. 12x2−8x=4x(3x−2)12x^2 - 8x = 4x(3x - 2)12x2−8x=4x(3x−2).

  • Unit-fraction exponent: the nnnth root

    a1/n=ana^{1/n} = \sqrt[n]{a}a1/n=na​

    Use when nnn a positive integer. Even nnn needs a≥0a \ge 0a≥0 and gives the non-negative (principal) root; odd nnn allows a negative aaa, with one negative root.

    e.g. 641/3=643=464^{1/3} = \sqrt[3]{64} = 4641/3=364​=4, and −83=−2\sqrt[3]{-8} = -23−8​=−2.

  • General fractional exponent

    am/n=(an)m=amna^{m/n} = \left(\sqrt[n]{a}\right)^m = \sqrt[n]{a^m}am/n=(na​)m=nam​

    Use when Write m/nm/nm/n in lowest terms first, so the exponent has one settled index. Same domain rules as a1/na^{1/n}a1/n: nnn a positive integer, and even nnn needs a≥0a \ge 0a≥0. Rooting first keeps the numbers small.

    e.g. 323/5=(325)3=23=832^{3/5} = \left(\sqrt[5]{32}\right)^3 = 2^3 = 8323/5=(532​)3=23=8.

  • Negative fractional exponent

    a−m/n=1am/na^{-m/n} = \frac{1}{a^{m/n}}a−m/n=am/n1​

    Use when With m/nm/nm/n in lowest terms: a>0a > 0a>0 when nnn is even, any nonzero aaa when nnn is odd. The minus sign moves the power into the denominator and does not change the result's sign.

    e.g. 16−3/4=1(164)3=1816^{-3/4} = \dfrac{1}{\left(\sqrt[4]{16}\right)^3} = \dfrac{1}{8}16−3/4=(416​)31​=81​.

  • Product and quotient rules for radicals

    abn=an bn,abn=anbn\sqrt[n]{ab} = \sqrt[n]{a}\,\sqrt[n]{b}, \qquad \sqrt[n]{\frac{a}{b}} = \frac{\sqrt[n]{a}}{\sqrt[n]{b}}nab​=na​nb​,nba​​=nb​na​​

    Use when One index throughout, b≠0b \neq 0b=0 in the quotient, and radicands zero or positive when nnn is even. Roots split across products and quotients, never across a sum.

    e.g. 72=36 2=62\sqrt{72} = \sqrt{36}\,\sqrt{2} = 6\sqrt{2}72​=36​2​=62​, and 502=25=5\dfrac{\sqrt{50}}{\sqrt{2}} = \sqrt{25} = 52​50​​=25​=5.

  • Cancelling a common factor

    acbc=ab\frac{ac}{bc} = \frac{a}{b}bcac​=ba​

    Use when b≠0b \neq 0b=0 and c≠0c \neq 0c=0, and ccc must be a factor of the whole numerator and whole denominator, never one term of a sum.

    e.g. 6x29x=3x⋅2x3x⋅3=2x3\dfrac{6x^2}{9x} = \dfrac{3x \cdot 2x}{3x \cdot 3} = \dfrac{2x}{3}9x6x2​=3x⋅33x⋅2x​=32x​ for x≠0x \neq 0x=0.

  • Multiplying and dividing algebraic fractions

    ab⋅cd=acbd,ab÷cd=ab⋅dc\frac{a}{b} \cdot \frac{c}{d} = \frac{ac}{bd}, \qquad \frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c}ba​⋅dc​=bdac​,ba​÷dc​=ba​⋅cd​

    Use when b≠0b \neq 0b=0 and d≠0d \neq 0d=0; division also needs c≠0c \neq 0c=0. No common denominator is involved.

    e.g. x4÷x28=x4⋅8x2=2x\dfrac{x}{4} \div \dfrac{x^2}{8} = \dfrac{x}{4} \cdot \dfrac{8}{x^2} = \dfrac{2}{x}4x​÷8x2​=4x​⋅x28​=x2​ for x≠0x \neq 0x=0.

  • Adding and subtracting over a common denominator

    ad+bd=a+bd,ad−bd=a−bd\frac{a}{d} + \frac{b}{d} = \frac{a + b}{d}, \qquad \frac{a}{d} - \frac{b}{d} = \frac{a - b}{d}da​+db​=da+b​,da​−db​=da−b​

    Use when d≠0d \neq 0d=0, and the denominators must be made equal first, over the LCD.

    e.g. 5xx+1+2xx+1=7xx+1\dfrac{5x}{x + 1} + \dfrac{2x}{x + 1} = \dfrac{7x}{x + 1}x+15x​+x+12x​=x+17x​.

Problem types, step by step

Translate a word phrase or statement into algebra

  1. Name the unknown with a letter and write every other quantity in terms of it.
  2. Convert each phrase: more than adds, less than subtracts, times or product multiplies, divided by or per divides.
  3. Look for a claim that two amounts are equal. A phrase with none becomes an expression, which you evaluate; a statement with is or equals supplies the equals sign and becomes an equation, which may be one to solve, an identity, or one with no solution.

e.g. Twice a number decreased by five is 2n−52n - 52n−5, while the sum of a number and eight is twenty is n+8=20n + 8 = 20n+8=20.

Test whether a claimed identity or equivalence holds

  1. To prove it, derive one side from the other by the laws, so the result holds no matter which value is substituted.
  2. To disprove it, hunt a counterexample: substitute a number, in parentheses where the letter stood, and evaluate each side by the order of operations.
  3. One value where they differ settles it; agreement at several proves nothing, so prefer awkward inputs like −1-1−1.

e.g. n+n=n⋅nn + n = n \cdot nn+n=n⋅n holds at n=0n = 0n=0 and n=2n = 2n=2, but 3+3=63 + 3 = 63+3=6 while 3⋅3=93 \cdot 3 = 93⋅3=9.

Simplify an expression with parentheses or nested brackets

  1. Clear the innermost grouping symbol first, then work outward.
  2. Distribute each outside factor across every term inside, carrying its sign.
  3. Collect like terms by adding coefficients.
  4. Check by substituting a value into the original and the result.

e.g. 8x−2[3x−(x−4)]=8x−2[2x+4]=8x−4x−8=4x−88x - 2[3x - (x - 4)] = 8x - 2[2x + 4] = 8x - 4x - 8 = 4x - 88x−2[3x−(x−4)]=8x−2[2x+4]=8x−4x−8=4x−8.

Evaluate a fractional or negative fractional power

  1. If the exponent is negative, take the reciprocal and continue with the positive exponent.
  2. Read the exponent's denominator as a root index and take that root of the base.
  3. Raise the result to the numerator.

e.g. 8−2/3=182/3=1(83)2=148^{-2/3} = \dfrac{1}{8^{2/3}} = \dfrac{1}{\left(\sqrt[3]{8}\right)^2} = \dfrac{1}{4}8−2/3=82/31​=(38​)21​=41​.

Simplify radicals and combine them

  1. Split each radicand into its largest perfect-power factor for the index, times the rest.
  2. Root that factor and bring it outside; leave the rest under the radical.
  3. Combine only radicals now sharing an index and a radicand, adding their coefficients.

e.g. 12+27=23+33=53\sqrt{12} + \sqrt{27} = 2\sqrt{3} + 3\sqrt{3} = 5\sqrt{3}12​+27​=23​+33​=53​.

Expand a product of two expressions

  1. Multiply every term of the first factor by every term of the second, keeping signs.
  2. Multiply coefficients and add exponents wherever the same base meets itself.
  3. Combine the like terms, usually the middle ones.

e.g. (x+2)(x2+3x−1)=x3+3x2−x+2x2+6x−2=x3+5x2+5x−2(x + 2)(x^2 + 3x - 1) = x^3 + 3x^2 - x + 2x^2 + 6x - 2 = x^3 + 5x^2 + 5x - 2(x+2)(x2+3x−1)=x3+3x2−x+2x2+6x−2=x3+5x2+5x−2.

Factor out the greatest common factor

  1. Take the greatest common divisor of the coefficients.
  2. Take each variable common to every term, at its lowest power.
  3. Write that product outside a parenthesis, dividing each original term by it to fill the inside.
  4. Check by expanding: the product must return the original.

e.g. 6x3−15x2=3x2(2x−5)6x^3 - 15x^2 = 3x^2(2x - 5)6x3−15x2=3x2(2x−5).

Simplify an algebraic fraction and state its restriction

  1. Set the original denominator equal to zero and record the excluded values.
  2. Factor top and bottom completely.
  3. Cancel only a factor shared by the whole top and bottom.
  4. Report the result with those excluded values, which cancelling does not remove.

e.g. 4x+8x+2=4(x+2)x+2=4\dfrac{4x + 8}{x + 2} = \dfrac{4(x + 2)}{x + 2} = 4x+24x+8​=x+24(x+2)​=4 for x≠−2x \neq -2x=−2.

Multiply or divide algebraic fractions

  1. For division, multiply by the reciprocal of the divisor only.
  2. Factor every top and bottom.
  3. Cancel shared factors before multiplying, which keeps the numbers small.
  4. Multiply what remains straight across and state the excluded values.

e.g. 3x+6x÷x+24x=3(x+2)x⋅4xx+2=12\dfrac{3x + 6}{x} \div \dfrac{x + 2}{4x} = \dfrac{3(x + 2)}{x} \cdot \dfrac{4x}{x + 2} = 12x3x+6​÷4xx+2​=x3(x+2)​⋅x+24x​=12 for x≠0x \neq 0x=0 and x≠−2x \neq -2x=−2.

Add or subtract algebraic fractions

  1. Find the LCD of the denominators.
  2. Multiply each fraction's top and bottom by whatever its denominator is missing.
  3. Put the numerators over the shared denominator, bracketing any numerator being subtracted.
  4. Distribute the minus, collect like terms, then cancel any shared factor.

e.g. 3x+12=62x+x2x=6+x2x\dfrac{3}{x} + \dfrac{1}{2} = \dfrac{6}{2x} + \dfrac{x}{2x} = \dfrac{6 + x}{2x}x3​+21​=2x6​+2xx​=2x6+x​ for x≠0x \neq 0x=0.

Exam traps

  • Trap Cancelling a term rather than a factor: x+33=x+1\dfrac{x + 3}{3} = x + 13x+3​=x+1.

    Fix Only a factor of the whole top and bottom cancels, and the 333 on top is added, not multiplied. The honest split is x3+1\dfrac{x}{3} + 13x​+1: at x=3x = 3x=3 the fraction is 222, not 444.

  • Trap Splitting a root across a sum, or merging unlike radicals: 9+16=3+4\sqrt{9 + 16} = 3 + 49+16​=3+4, or 2+3=5\sqrt{2} + \sqrt{3} = \sqrt{5}2​+3​=5​.

    Fix Roots split across products and quotients only: 9+16=25=5\sqrt{9 + 16} = \sqrt{25} = 59+16​=25​=5, not 777, and 2+3\sqrt{2} + \sqrt{3}2​+3​ does not combine.

  • Trap Squaring a sum term by term: (x+3)2=x2+9(x + 3)^2 = x^2 + 9(x+3)2=x2+9.

    Fix (x+3)2(x + 3)^2(x+3)2 is the product (x+3)(x+3)(x + 3)(x + 3)(x+3)(x+3), whose two cross products supply the middle 6x6x6x.

  • Trap Dropping the restriction once a factor cancels, because the simplified form looks harmless.

    Fix Excluded values come from the original denominator and survive cancelling, so 3x+6x+2=3\dfrac{3x + 6}{x + 2} = 3x+23x+6​=3 still requires x≠−2x \neq -2x=−2.

  • Trap Treating agreement at a few substituted values as proof that an equation is an identity.

    Fix A finite list leaves infinitely many values untested, so agreement only raises confidence; certainty comes only from a derivation by the laws.

  • Trap Swapping the roles of mmm and nnn in am/na^{m/n}am/n.

    Fix The denominator is always the root index and the numerator the power, so 82/3=(83)2=48^{2/3} = \left(\sqrt[3]{8}\right)^2 = 482/3=(38​)2=4, not (8)3\left(\sqrt{8}\right)^3(8​)3.

  • Trap Reading a negative exponent as a negative answer: 8−2/3=−48^{-2/3} = -48−2/3=−4.

    Fix The minus sign builds a reciprocal rather than changing a sign, so 8−2/3=148^{-2/3} = \dfrac{1}{4}8−2/3=41​.

  • Trap Stopping at a partial common factor: 8x2+12x=2x(4x+6)8x^2 + 12x = 2x(4x + 6)8x2+12x=2x(4x+6).

    Fix Fully factored means the GCF came out. A shared 222 is still inside, so the answer is 4x(2x+3)4x(2x + 3)4x(2x+3).

  • Trap Adding fractions by combining the denominators: 3x+12=42x\dfrac{3}{x} + \dfrac{1}{2} = \dfrac{4}{2x}x3​+21​=2x4​.

    Fix Numerators combine only over a shared denominator: over the LCD 2x2x2x, 62x+x2x=6+x2x\dfrac{6}{2x} + \dfrac{x}{2x} = \dfrac{6 + x}{2x}2x6​+2xx​=2x6+x​.

  • Trap Letting a subtraction reach only the first term of a numerator: 4x+1x−x−2x=3x−1x\dfrac{4x + 1}{x} - \dfrac{x - 2}{x} = \dfrac{3x - 1}{x}x4x+1​−xx−2​=x3x−1​.

    Fix The minus is a factor −1-1−1 over the whole numerator, so bracket it first: (4x+1)−(x−2)x=4x+1−x+2x=3x+3x\dfrac{(4x + 1) - (x - 2)}{x} = \dfrac{4x + 1 - x + 2}{x} = \dfrac{3x + 3}{x}x(4x+1)−(x−2)​=x4x+1−x+2​=x3x+3​.
