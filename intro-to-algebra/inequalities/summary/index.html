Inequalities: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Inequality
A comparison using <<<, >>>, ≤\le≤, or ≥\ge≥.
Strict and inclusive
Strict symbols <<< and >>> exclude equality. Inclusive symbols ≤\le≤ and ≥\ge≥ allow it.
Solution set
All values or ordered pairs that make a condition true. A set can be an interval, several pieces, one point, all allowed inputs, or empty. In two variables, it can be a region of the plane, such as a half-plane.
Half-plane
One of the two pieces a line cuts the plane into. The line itself is the border between them, called the boundary.
Constraint (Advanced)
A restriction on the choices in an optimization problem. Nonnegative amounts require x≥0x\ge0x≥0 and y≥0y\ge0y≥0 too.
Objective function (Advanced)
The quantity to maximize or minimize. The rule P=ax+byP=ax+byP=ax+by assigns one value to each pair (x,y)(x,y)(x,y).
Level line (Advanced)
For a nonconstant objective P=ax+byP=ax+byP=ax+by, the line ax+by=cax+by=cax+by=c contains points with value ccc. Changing ccc moves this line parallel to itself.
Feasible region
The points satisfying every inequality of a system. It may enclose an area, be unbounded, shrink to a line or point, or be empty. A bounded region fits inside some box.
Vertex (corner)
A corner of a feasible region. Find candidate corners where boundary lines cross, then check every inequality.

Formulas and theorems

  • The four symbols

    <<< less than; >>> greater than; ≤\le≤ at most; ≥\ge≥ at least.

    Use when The symbol opens toward the larger amount and points at the smaller. Only ≤\le≤ and ≥\ge≥ let the two sides be equal.

  • Turning an inequality end for end

    a≤b  ⟺  b≥aa \le b \iff b \ge aa≤b⟺b≥a

    Use when Swap the sides and reverse the symbol. This keeps the meaning for all four comparisons.

    e.g. 7>x7 > x7>x says the same thing as x<7x < 7x<7.

  • Adding or subtracting keeps the direction

    a<b  ⟹  a+c<b+ca < b \implies a + c < b + ca<b⟹a+c<b+c

    Use when Any real ccc, positive, negative, or zero. Adding or subtracting the same amount does not reverse the symbol.

  • Multiplying or dividing by a positive keeps the direction

    a<b,c>0⟹ac<bc\begin{gathered} a<b,\quad c>0\\ \Longrightarrow ac<bc \end{gathered}a<b,c>0⟹ac<bc​

    Use when For c>0c>0c>0. Division by positive ccc also preserves order. Multiplication by zero loses the original comparison; division by zero is undefined.

  • Multiplying or dividing by a negative reverses the direction

    a<b,c<0⟹ac>bc\begin{gathered} a<b,\quad c<0\\ \Longrightarrow ac>bc \end{gathered}a<b,c<0⟹ac>bc​

    Use when For c<0c<0c<0. Division by negative ccc also reverses order. A negative elsewhere in the expression does not cause a flip.

    e.g. −12x<4-\tfrac{1}{2}x < 4−21​x<4 times −2-2−2 gives x>−8x > -8x>−8.

  • Transitivity

    a<b and b<c  ⟹  a<ca < b \text{ and } b < c \implies a < ca<b and b<c⟹a<c

    Use when The middle quantity must connect the comparisons: a<ba<ba<b and b<cb<cb<c. The rule also holds with ≤\le≤ throughout.

    e.g. 2<52 < 52<5 and 5<95 < 95<9 give 2<92 < 92<9.

  • Endpoint conventions, in all three pictures

    Strict (<<<, >>>): open circle, parenthesis, dashed boundary. Inclusive (≤\le≤, ≥\ge≥): filled circle, bracket, solid boundary.

    Use when Use the final symbol after solving. Infinity is not a real endpoint, so ∞\infty∞ and −∞-\infty−∞ always take a parenthesis.

    e.g. x≤5x \le 5x≤5 is (−∞,5](-\infty, 5](−∞,5]; x>2x > 2x>2 is (2,∞)(2, \infty)(2,∞).

  • Which way a number line shades

    A "greater" relation (>>>, ≥\ge≥) shades right, toward the larger numbers; a "less" relation (<<<, ≤\le≤) shades left.

    Use when Isolate the variable on the left first. Changing strict to inclusive keeps the shaded side and fills the endpoint.

    e.g. x≥−2x \ge -2x≥−2: filled circle on −2-2−2, shaded right, the interval [−2,∞)[-2, \infty)[−2,∞).

  • Compound inequalities: and versus or

    "And" means intersection: keep values satisfying both conditions. "Or" means union: keep values satisfying at least one, including both.

    Use when For a band written as a chain, both symbols point the same way; a mixed chain such as −2<x>3-2<x>3−2<x>3 is not a band. The band a<x<ba<x<ba<x<b requires a<ba<ba<b; 3<x<−23<x<-23<x<−2 has no solutions. For inclusive equal bounds, 0≤x≤00\le x\le00≤x≤0 contains just 000. The two pieces of a union need not be separate.

    e.g. x<−1x < -1x<−1 or x≥2x \ge 2x≥2 is (−∞,−1)∪[2,∞)(-\infty, -1) \cup [2, \infty)(−∞,−1)∪[2,∞).

  • When the variable cancels

    A true remaining statement gives every originally allowed input. A false one gives no solutions.

    Use when All variable terms have canceled. For these linear expressions, all real numbers are originally allowed, so a true statement gives (−∞,∞)(-\infty,\infty)(−∞,∞).

    e.g. 2x+5<2x+12x + 5 < 2x + 12x+5<2x+1 collapses to 5<15 < 15<1, which is false, so there is no solution.

  • Boundary of a two-variable inequality

    Replace the comparison symbol with === to find the boundary line. Select one half-plane and include the line exactly when the symbol is inclusive.

    Use when For Ax+By<CAx+By<CAx+By<C and its other comparison forms, require AAA and BBB not both zero. A bound on xxx alone has a vertical boundary; a bound on yyy alone has a horizontal one.

  • Test-point rule

    Substitute a point off the boundary into the original inequality. True means shade that point's side; false means shade the opposite side.

    Use when Use (0,0)(0,0)(0,0) if it is off the line. Otherwise try another point, checking that it too is off the boundary. A boundary point only checks equality, not which side works.

    e.g. 3x+2y≤63x + 2y \le 63x+2y≤6 at (0,0)(0, 0)(0,0) gives 0≤60 \le 60≤6, true, so shade the origin's side.

  • Corner-point principle (Advanced)

    On a nonempty, bounded feasible polygon with its boundary included, a linear objective attains its maximum and minimum at corners. For a nonconstant objective, a whole edge can tie when it lies on the last level line.

    Use when The constraints are linear and inclusive. If a=b=0a=b=0a=b=0, every point ties. On an unbounded region, do not assume both extremes exist: inspect feasible directions. For the nonempty regions here with x,y≥0x,y\ge0x,y≥0, any extreme that exists is found at a corner.

Problem types, step by step

Translate a worded condition into an inequality

  1. Match the wording to the symbol: "at least" is ≥\ge≥, "at most" is ≤\le≤, "more than" is >>>, "less than" is <<<.
  2. Put the variable on the left, swapping the sides and reversing the symbol if it arrived on the right.

e.g. A rider must be at least 484848 inches tall: n≥48n \ge 48n≥48.

Solve a one-variable linear inequality

  1. Distribute parentheses, multiplying every inside term by the outside factor, sign included. A negative factor reverses each nonzero term's sign.
  2. Collect variable terms on one side and constants on the other. Choosing a positive final coefficient avoids negative division; if the variables cancel, judge the remaining statement.
  3. Divide by the nonzero coefficient, reversing the symbol if it is negative.
  4. Write the solution as an inequality, a number-line graph, and interval notation. Check a value inside and one outside the set in the original inequality when both exist.

e.g. 5−3x≥115 - 3x \ge 115−3x≥11 gives −3x≥6-3x \ge 6−3x≥6, then dividing by −3-3−3 and flipping, x≤−2x \le -2x≤−2.

Solve a compound inequality

  1. For an "and" chain, perform each operation on all three parts. For separately written conditions, solve each and keep their intersection.
  2. Dividing by a negative reverses both symbols. Then reorder the chain to put the smaller bound first, keeping each endpoint's inclusion.
  3. For "or", solve each piece and take their union with ∪\cup∪; overlapping pieces can combine.

e.g. −5≤−3x+1<7-5 \le -3x + 1 < 7−5≤−3x+1<7 gives −6≤−3x<6-6 \le -3x < 6−6≤−3x<6, then 2≥x>−22 \ge x > -22≥x>−2, the interval (−2,2](-2, 2](−2,2].

Graph a two-variable linear inequality

  1. Replace the symbol with === and graph that boundary from its intercepts or its slope and yyy-intercept.
  2. Draw the line dashed for <<< or >>>, solid for ≤\le≤ or ≥\ge≥.
  3. Substitute an off-line test point into the original inequality.
  4. Shade that point's side if the statement is true, the other side if it is false.

e.g. y>2x+1y > 2x + 1y>2x+1: dashed boundary, and (0,0)(0, 0)(0,0) gives 0>10 > 10>1, false, so shade above.

Decide whether a point is a solution

  1. Substitute both coordinates and evaluate each side.
  2. True puts the point in the shaded region; false puts it outside.
  3. Sides coming out equal means the point sits on the boundary, where it counts only if the boundary is solid.

e.g. (1,−2)(1, -2)(1,−2) in 3x−y<53x - y < 53x−y<5: 3+2=53 + 2 = 53+2=5, and 5<55 < 55<5 is false, so it is not a solution.

Graph a system and find its feasible region

  1. Graph each boundary dashed or solid and shade its half-plane using an off-boundary test point.
  2. Keep only the common part. It may be empty or have no area, such as a line or a point.
  3. Find corners by solving boundary pairs; discard crossings that fail any constraint. Check proposed solution points against every inequality.

e.g. x≥0x \ge 0x≥0, y≥0y \ge 0y≥0, x+y≤4x + y \le 4x+y≤4 overlap in the triangle with corners (0,0)(0, 0)(0,0), (4,0)(4, 0)(4,0), (0,4)(0, 4)(0,4).

Use the corner-point method (Advanced)

  1. Graph the constraints. Check that the feasible region is nonempty; for a bounded polygon, confirm its boundary is included.
  2. Find every vertex by solving boundary pairs. Discard any crossing that fails another constraint.
  3. Evaluate the objective at every vertex and compare. Name both the extreme value and an attaining point; tied endpoint values can indicate an optimal edge.
  4. If the region is unbounded, check whether an allowed direction makes the objective grow or decrease without limit before reporting a maximum or minimum.

e.g. P=3x+2yP = 3x + 2yP=3x+2y at (0,0)(0, 0)(0,0), (3,0)(3, 0)(3,0), (2,2)(2, 2)(2,2), (0,3)(0, 3)(0,3) gives 000, 999, 101010, 666: maximum 101010 at (2,2)(2, 2)(2,2).

Model an optimization problem (Advanced)

  1. Name the variables and their units.
  2. Translate each upper resource limit into a ≤\le≤ constraint and each lower requirement into a ≥\ge≥ constraint.
  3. Add nonnegative conditions and any whole-number restrictions. Write the objective using the per-unit values.
  4. Optimize over the real feasible region. An optimal point with whole-number coordinates also solves the whole-item problem; otherwise, rounding alone is not justified.
  5. State the result with units and check the original limits.

e.g. Chairs xxx, tables yyy: 2x+y≤82x + y \le 82x+y≤8, x+3y≤9x + 3y \le 9x+3y≤9, P=30x+50yP = 30x + 50yP=30x+50y, x,yx, yx,y whole numbers.

Exam traps

  • Trap Forgetting to reverse the symbol after dividing by a negative, turning −5x>20-5x > 20−5x>20 into x>−4x > -4x>−4.

    Fix Dividing by negative −5-5−5 reverses the direction, giving x<−4x<-4x<−4. In the wrong answer, the bound −4-4−4 is right; only the direction is wrong.

  • Trap Flipping for the wrong reason: a negative sits somewhere in the problem, you subtracted, or the answer came out negative.

    Fix Of adding, subtracting, multiplying and dividing both sides, only scaling by a negative reverses order. Solving 2x>−102x>-102x>−10 gives x>−5x>-5x>−5: the divisor is positive.

  • Trap Solving something like −2y>4x-2y > 4x−2y>4x for yyy without flipping, then shading the wrong half-plane.

    Fix Dividing by −2-2−2 reverses the symbol to y<−2xy<-2xy<−2x. Both forms describe the same region below the line. Testing a point in the original inequality checks the rearrangement.

  • Trap Shading a two-variable inequality straight from its symbol, reading 2x−y>42x - y > 42x−y>4 as "greater, so shade above".

    Fix Solve for yyy or use a test point. Here −y>−2x+4-y>-2x+4−y>−2x+4 gives y<2x−4y<2x-4y<2x−4, so shade below. The origin gives 0>40>40>4, false, confirming which side to exclude.

  • Trap Treating an empty solution set as the number zero, or writing "x=x =x=" something when the variable cancels.

    Fix No solution means no input works, not x=0x=0x=0. After all variables cancel, a true statement instead accepts every originally allowed input.

  • Trap Reading (2,5)(2, 5)(2,5) as a point in the plane when it is an interval, or the other way round.

    Fix The notations are identical, so the surrounding words decide: an interval is a set of numbers on one axis, a coordinate pair one location in the plane.

  • Trap Shading a system's union instead of its overlap, keeping every point that satisfies at least one inequality.

    Fix The feasible region is the intersection: a point belongs only if it satisfies every inequality of the system at once.

  • Trap Advanced: checking only axis corners and missing the crossing of two slanted constraints.

    Fix List every feasible corner before comparing objective values. A crossing counts only if it satisfies all the other constraints.
