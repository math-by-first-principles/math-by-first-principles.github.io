Inequalities: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Inequality
A comparison of two quantities that need not be equal, using <<<, >>>, ≤\le≤, or ≥\ge≥ in place of an equals sign.
Strict and inclusive
<<< and >>> are strict and exclude the boundary value; ≤\le≤ and ≥\ge≥ are inclusive and admit it. That one bar is the whole difference.
Solution set
Every value, or ordered pair, making the inequality true. In one variable it is almost always a whole range, infinitely many numbers, so it is drawn or written as an interval, not listed. In two variables it is instead a region of the plane, a half-plane or, for a system, the overlap of several. Either kind can be an empty solution set, where nothing works.
Half-plane
One of the two pieces a line cuts the plane into. The line itself is the border between them, called the boundary.
Constraint
One hard limit of an optimization problem, written as a linear inequality. x≥0x \ge 0x≥0 and y≥0y \ge 0y≥0 are constraints too, whenever the variables count real things.
Objective function
The single linear quantity P=ax+byP = ax + byP=ax+by being pushed as high or as low as it will go, such as a profit to maximize or a cost to minimize.
Level line
The line ax+by=cax + by = cax+by=c on which the objective holds the one value ccc. All level lines of an objective are parallel, so changing ccc slides the line without turning it.
Feasible region
The overlap of every constraint's half-plane, the points satisfying all of them at once. It may be a bounded polygon (one fitting inside some box), an unbounded region running off forever, or empty, when no point satisfies every constraint.
Vertex (corner)
A point of the feasible region where two boundary lines cross.

Formulas and theorems

  • The four symbols

    <<< less than; >>> greater than; ≤\le≤ at most; ≥\ge≥ at least.

    Use when The symbol opens toward the larger amount and points at the smaller. Only ≤\le≤ and ≥\ge≥ let the two sides be equal.

  • Turning an inequality end for end

    a≤b  ⟺  b≥aa \le b \iff b \ge aa≤b⟺b≥a

    Use when Swap the sides AND reverse the symbol; the meaning is untouched. All four symbols. This is how you move a variable to the left.

    e.g. 7>x7 > x7>x says the same thing as x<7x < 7x<7.

  • Adding or subtracting keeps the direction

    a<b  ⟹  a+c<b+ca < b \implies a + c < b + ca<b⟹a+c<b+c

    Use when Any real ccc. Addition and subtraction NEVER reverse the symbol, not even when ccc is negative or the result is negative.

  • Multiplying or dividing by a positive keeps the direction

    a<b and c>0  ⟹  ac<bca < b \text{ and } c > 0 \implies ac < bca<b and c>0⟹ac<bc

    Use when c>0c > 0c>0 strictly. c=0c = 0c=0 is barred: it collapses both sides to 000 and destroys the comparison.

  • Multiplying or dividing by a negative reverses the direction

    a<b and c<0  ⟹  ac>bca < b \text{ and } c < 0 \implies ac > bca<b and c<0⟹ac>bc

    Use when c<0c < 0c<0 strictly. The reversal happens once, at that step only.

    e.g. −12x<4-\tfrac{1}{2}x < 4−21​x<4 times −2-2−2 gives x>−8x > -8x>−8.

  • Transitivity

    a<b and b<c  ⟹  a<ca < b \text{ and } b < c \implies a < ca<b and b<c⟹a<c

    Use when Both comparisons must point the same way. It holds with ≤\le≤ throughout.

    e.g. 2<52 < 52<5 and 5<95 < 95<9 give 2<92 < 92<9.

  • Endpoint conventions, in all three pictures

    Strict (<<<, >>>): open circle, parenthesis, dashed boundary. Inclusive (≤\le≤, ≥\ge≥): filled circle, bracket, solid boundary.

    Use when Read it off the FINAL symbol after solving, not the one you started with. Infinity is not a number, so ∞\infty∞ and −∞-\infty−∞ always take a parenthesis.

    e.g. x≤5x \le 5x≤5 is (−∞,5](-\infty, 5](−∞,5]; x>2x > 2x>2 is (2,∞)(2, \infty)(2,∞).

  • Which way a number line shades

    A "greater" relation (>>>, ≥\ge≥) shades right, toward the larger numbers; a "less" relation (<<<, ≤\le≤) shades left.

    Use when Get the variable alone on the left first, so rewrite 7>x7 > x7>x as x<7x < 7x<7 before drawing. Switching strict to inclusive never moves the shading, it only closes the circle.

    e.g. x≥−2x \ge -2x≥−2: filled circle on −2-2−2, shaded right, the interval [−2,∞)[-2, \infty)[−2,∞).

  • Compound inequalities: and versus or

    An "and" compound a<x<ba < x < ba<x<b is the intersection, one band between the bounds. An "or" compound is the union of two separate solution sets, joined with ∪\cup∪.

    Use when In a<x<ba < x < ba<x<b both symbols must point the same way with the smaller bound on the left; 3<x<−23 < x < -23<x<−2 describes nothing at all.

    e.g. x<−1x < -1x<−1 or x≥2x \ge 2x≥2 is (−∞,−1)∪[2,∞)(-\infty, -1) \cup [2, \infty)(−∞,−1)∪[2,∞).

  • When the variable cancels

    A true leftover means all real numbers, (−∞,∞)(-\infty, \infty)(−∞,∞). A false leftover means no solution, an empty solution set.

    Use when Applies only when EVERY copy of the variable cancels, leaving no variable behind. Those two are the only outcomes, and each is a complete answer.

    e.g. 2x+5<2x+12x + 5 < 2x + 12x+5<2x+1 collapses to 5<15 < 15<1, which is false, so there is no solution.

  • Boundary of a two-variable inequality

    Replace the symbol with ===: that line is the boundary, and the solutions are exactly one of the two half-planes it separates, never a mix of both, together with the boundary line itself when the symbol is inclusive.

    Use when Any linear inequality in xxx and yyy. A missing variable is no special case: x>cx > cx>c gives a vertical boundary and y≤cy \le cy≤c a horizontal one, method unchanged.

  • Test-point rule

    Substitute any point NOT on the boundary into the original inequality. True: shade that point's side. False: shade the other.

    Use when The origin (0,0)(0, 0)(0,0) is easiest, unless the boundary runs through it, when (1,0)(1, 0)(1,0) or (0,1)(0, 1)(0,1) serves. One substitution settles the whole side, since every point of a side gives the same verdict.

    e.g. 3x+2y≤63x + 2y \le 63x+2y≤6 at (0,0)(0, 0)(0,0) gives 0≤60 \le 60≤6, true, so shade the origin's side.

  • Corner-point principle

    On a bounded feasible region, a linear objective P=ax+byP = ax + byP=ax+by attains both its maximum and its minimum, each at a vertex. On an unbounded region, an extreme that does exist is still found at a vertex, but only when the region has at least one; a region with no vertex at all has none to check, and any existing extreme must instead be reasoned out directly from the level lines or constraints. If a level line runs parallel to an edge, every point of that edge is optimal, so the corners at its ends tie.

    Use when aaa and bbb not both zero. A nonempty, bounded region with every constraint inclusive (≤\le≤ or ≥\ge≥, never strict), so the boundary belongs to the region, GUARANTEES both extremes exist and occur at vertices. On an unbounded region, vertex-checking only finds an existing extreme where the region has a vertex; report only the extremes that exist, and fall back to direct level-line or constraint reasoning where there is no vertex to check.

Problem types, step by step

Translate a worded condition into an inequality

  1. Match the wording to the symbol: "at least" is ≥\ge≥, "at most" is ≤\le≤, "more than" is >>>, "less than" is <<<.
  2. Put the variable on the left, swapping the sides and reversing the symbol if it arrived on the right.

e.g. A rider must be at least 484848 inches tall: n≥48n \ge 48n≥48.

Solve a one-variable linear inequality

  1. Distribute to clear parentheses, watching the sign on a negative multiplier.
  2. Collect variable terms on the side that leaves the coefficient positive and constants on the other, adding and subtracting only.
  3. Divide by the variable's coefficient, reversing the symbol only if that number is negative.
  4. Test one value inside the solution set and one outside, against the ORIGINAL inequality.

e.g. 5−3x≥115 - 3x \ge 115−3x≥11 gives −3x≥6-3x \ge 6−3x≥6, then dividing by −3-3−3 and flipping, x≤−2x \le -2x≤−2.

Solve a compound inequality

  1. For an "and" compound, keep the variable in the middle and apply every operation to all three parts at once.
  2. Dividing all three parts by a negative reverses BOTH symbols and swaps the ends, so rewrite with the smaller number on the left.
  3. For an "or" compound, solve each piece alone and take the union with ∪\cup∪.

e.g. −5≤−3x+1<7-5 \le -3x + 1 < 7−5≤−3x+1<7 gives −6≤−3x<6-6 \le -3x < 6−6≤−3x<6, then 2≥x>−22 \ge x > -22≥x>−2, the interval (−2,2](-2, 2](−2,2].

Graph a two-variable linear inequality

  1. Replace the symbol with === and graph that boundary from its intercepts or its slope and yyy-intercept.
  2. Draw the line dashed for <<< or >>>, solid for ≤\le≤ or ≥\ge≥.
  3. Substitute an off-line test point into the original inequality.
  4. Shade that point's side if the statement is true, the other side if it is false.

e.g. y>2x+1y > 2x + 1y>2x+1: dashed boundary, and (0,0)(0, 0)(0,0) gives 0>10 > 10>1, false, so shade above.

Decide whether a point is a solution

  1. Substitute both coordinates and evaluate each side.
  2. True puts the point in the shaded region; false puts it outside.
  3. Sides coming out equal means the point sits on the boundary, where it counts only if the boundary is solid.

e.g. (1,−2)(1, -2)(1,−2) in 3x−y<53x - y < 53x−y<5: 3+2=53 + 2 = 53+2=5, and 5<55 < 55<5 is false, so it is not a solution.

Graph a system and find its feasible region

  1. Graph each inequality's boundary in its own dashed or solid style, shading each half-plane by its own test point.
  2. Keep only the part every half-plane shares: that overlap is the feasible region.
  3. Confirm with one interior point, checked against every inequality of the system.

e.g. x≥0x \ge 0x≥0, y≥0y \ge 0y≥0, x+y≤4x + y \le 4x+y≤4 overlap in the triangle with corners (0,0)(0, 0)(0,0), (4,0)(4, 0)(4,0), (0,4)(0, 4)(0,4).

Maximize or minimize with the corner-point method

  1. Graph the feasible region, including x≥0x \ge 0x≥0 and y≥0y \ge 0y≥0 when the variables count real things.
  2. List every vertex, each found by solving the two boundary lines crossing there as a 2×22 \times 22×2 system, never by reading the grid; discard any crossing point that fails one of the other constraints, since it is not a corner of the region.
  3. Evaluate P=ax+byP = ax + byP=ax+by at every vertex on the list.
  4. Take the largest value for a maximum or the smallest for a minimum, and name the point achieving it.

e.g. P=3x+2yP = 3x + 2yP=3x+2y at (0,0)(0, 0)(0,0), (3,0)(3, 0)(3,0), (2,2)(2, 2)(2,2), (0,3)(0, 3)(0,3) gives 000, 999, 101010, 666: maximum 101010 at (2,2)(2, 2)(2,2).

Set up an optimization word problem

  1. Name one variable per quantity being chosen, saying what each counts.
  2. Turn each limited resource into an inequality, amount used ≤\le≤ amount available, and each requirement into a ≥\ge≥.
  3. Add x≥0x \ge 0x≥0 and y≥0y \ge 0y≥0, then write the objective from the per-unit values. If the variables count separate items, add that each must be a whole number.
  4. Run the corner-point method. When whole numbers are required, that continuous optimum solves the discrete problem outright only if its coordinates are already whole numbers; otherwise the best whole-number point takes more care than simply rounding to the nearest one, since the true answer need not be nearby.
  5. Answer in a sentence with units.

e.g. Chairs xxx, tables yyy: 2x+y≤82x + y \le 82x+y≤8, x+3y≤9x + 3y \le 9x+3y≤9, P=30x+50yP = 30x + 50yP=30x+50y, x,yx, yx,y whole numbers.

Exam traps

  • Trap Forgetting to reverse the symbol after dividing by a negative, turning −5x>20-5x > 20−5x>20 into x>−4x > -4x>−4.

    Fix The divisor −5-5−5 is negative, so the direction reverses: x<−4x < -4x<−4. It hides well: the bound comes out right and only the direction is wrong.

  • Trap Flipping for the wrong reason: a negative sits somewhere in the problem, you subtracted, or the answer came out negative.

    Fix Only the sign of the number you scale BOTH sides by matters. Solving 2x>−102x > -102x>−10 gives x>−5x > -5x>−5 with no flip, because the divisor 222 is positive.

  • Trap Solving something like −2y>4x-2y > 4x−2y>4x for yyy without flipping, then shading the wrong half-plane.

    Fix Dividing by −2-2−2 reverses the symbol to y<−2xy < -2xy<−2x, which moves the shading to the other side. Testing a point in the ORIGINAL inequality avoids the trap entirely.

  • Trap Shading a two-variable inequality straight from its symbol, reading 2x−y>42x - y > 42x−y>4 as "greater, so shade above".

    Fix That reflex is only safe once the inequality is solved for yyy, and solving reverses it here: −y>−2x+4-y > -2x + 4−y>−2x+4 gives y<2x−4y < 2x - 4y<2x−4, so the solutions lie BELOW the boundary. Testing (0,0)(0, 0)(0,0) gives 0>40 > 40>4, false, which settles the side without the reflex.

  • Trap Treating an empty solution set as the number zero, or writing "x=x =x=" something when the variable cancels.

    Fix No solution means nothing satisfies the inequality, which is not the value 000; a true leftover means every value does. Neither outcome is a single number.

  • Trap Reading (2,5)(2, 5)(2,5) as a point in the plane when it is an interval, or the other way round.

    Fix The notations are identical, so the surrounding words decide: an interval is a set of numbers on one axis, a coordinate pair one location in the plane.

  • Trap Shading a system's union instead of its overlap, keeping every point that satisfies at least one inequality.

    Fix The feasible region is the intersection: a point belongs only if it satisfies every inequality of the system at once.

  • Trap Leaving the inside corner, where two slanted constraints cross, off the vertex list.

    Fix That corner often wins, being the point where both limits are used up completely. Every corner goes on the list before you compare values.
