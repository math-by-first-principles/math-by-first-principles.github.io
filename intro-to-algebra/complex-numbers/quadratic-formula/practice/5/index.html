    Solution

    Correct answer: A

    A repeated root needs the discriminant to be 000, so b2−4ac=0b^2 - 4ac = 0b2−4ac=0 with a=1a = 1a=1, b=−8b = -8b=−8.

    (−8)2−4(1)c=64−4c=0⇒c=16(-8)^2 - 4(1)c = 64 - 4c = 0 \quad\Rightarrow\quad c = 16(−8)2−4(1)c=64−4c=0⇒c=16
