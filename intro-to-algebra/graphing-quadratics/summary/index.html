Graphing Quadratics and Inequalities: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Parabola
The smooth curve every quadratic graphs as, U-shaped opening upward or downward. It bends everywhere, so its points join into one curve, never straight segments.
Vertex
The parabola's turning point, where it stops falling and starts rising or the reverse: the one point with no mirror twin.
Axis of symmetry
The vertical line the parabola folds onto itself along: inputs equally far either side of it give the same height.
Root of a quadratic
A value of xxx making the quadratic 000. On the graph it is an xxx-intercept; on the number line, a boundary where the sign can change.
Circle
The set of all points a fixed distance rrr (the radius) from a fixed point (h,k)(h, k)(h,k) (the center). Nothing else qualifies.
Quadratic inequality
A quadratic compared to 000 by <<<, >>>, ≤\le≤, or ≥\ge≥, solved for one variable, so the answer is a set on the number line, not a region.
Sign chart
The intervals the roots cut the number line into, each labeled with the quadratic's sign, from a test point or the parabola's shape.
Optimizing input and optimal value
The vertex's two coordinates, kept apart: the input is WHERE the best happens, the value is HOW GOOD it is. Rarely the same number.

Formulas and theorems

  • Standard form of a quadratic

    y=ax2+bx+cy = ax^2 + bx + cy=ax2+bx+c

    Use when a≠0a \neq 0a=0; with a=0a = 0a=0 the graph is the line y=bx+cy = bx + cy=bx+c. Read aaa, bbb, ccc with their signs only from this form.

  • What the sign and size of aaa tell you

    a>0a > 0a>0: opens upward, vertex is a minimum. a<0a < 0a<0: opens downward, vertex is a maximum. Large ∣a∣\lvert a \rvert∣a∣: narrow. Small ∣a∣\lvert a \rvert∣a∣: wide.

    Use when Only the leading coefficient decides these; bbb and ccc do not. Width compares against y=x2y = x^2y=x2: ∣a∣>1\lvert a \rvert > 1∣a∣>1 narrower, ∣a∣<1\lvert a \rvert < 1∣a∣<1 wider.

  • Axis of symmetry and the vertex

    x=−b2ax = -\frac{b}{2a}x=−2ab​

    Use when a≠0a \neq 0a=0. This is both the axis of symmetry and the vertex's xxx-coordinate; the yyy-coordinate comes only from substituting it back.

  • Vertex form

    y=a(x−h)2+ky = a(x - h)^2 + ky=a(x−h)2+k

    Use when Vertex (h,k)(h, k)(h,k), same aaa as standard form. The form SUBTRACTS hhh, so y=(x+3)2+2y = (x + 3)^2 + 2y=(x+3)2+2 has h=−3h = -3h=−3. Matching standard form gives h=−b2ah = -\tfrac{b}{2a}h=−2ab​, k=c−b24ak = c - \tfrac{b^2}{4a}k=c−4ab2​.

  • The intercepts, and the discriminant that counts them

    The yyy-intercept is (0,c)(0, c)(0,c), from setting x=0x = 0x=0; the xxx-intercepts come from setting y=0y = 0y=0 and solving ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0. D=b2−4acD = b^2 - 4acD=b2−4ac counts them: D>0D > 0D>0 two, D=0D = 0D=0 one (the vertex on the axis), D<0D < 0D<0 none.

    Use when Zero the OTHER variable for each: always exactly one yyy-intercept, but two, one, or no xxx-intercepts. Coefficients from standard form with their signs; only real solutions land on the graph, and the count holds either way the parabola opens.

    e.g. y=x2−4x+7y = x^2 - 4x + 7y=x2−4x+7: D=16−28=−12D = 16 - 28 = -12D=16−28=−12, so it never meets the xxx-axis.

  • Completing the square

    x2+bx+(b2)2=(x+b2)2x^2 + bx + \left(\tfrac{b}{2}\right)^2 = \left(x + \tfrac{b}{2}\right)^2x2+bx+(2b​)2=(x+2b​)2

    Use when Needs leading coefficient 111: factor aaa out of a quadratic's xxx-terms, or divide a circle by the shared coefficient of x2x^2x2 and y2y^2y2. In an expression add and subtract it; in an equation add it to both sides.

  • Distance between two points

    d=(x2−x1)2+(y2−y1)2d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}d=(x2​−x1​)2+(y2​−y1​)2​

    Use when Any two points: the Pythagorean theorem on the two gaps, squared and added, never just added. Either point may come first, since squaring erases each difference's sign. The root is part of it, so stopping early leaves d2d^2d2; simplify it as a radical.

    e.g. (−1,2)(-1, 2)(−1,2) to (3,5)(3, 5)(3,5): d=42+32=5d = \sqrt{4^2 + 3^2} = 5d=42+32​=5, not 4+34 + 34+3.

  • Standard (center-radius) form of a circle

    (x−h)2+(y−k)2=r2(x - h)^2 + (y - k)^2 = r^2(x−h)2+(y−k)2=r2

    Use when Center (h,k)(h, k)(h,k), radius r>0r > 0r>0; the form SUBTRACTS each center coordinate, and the right side is r2r^2r2, not rrr. A right side that is not a perfect square leaves the radius as a radical. At the origin it becomes x2+y2=r2x^2 + y^2 = r^2x2+y2=r2, meeting the axes at (±r,0)(\pm r, 0)(±r,0) and (0,±r)(0, \pm r)(0,±r).

  • General form of a circle

    x2+y2+Dx+Ey+F=0x^2 + y^2 + Dx + Ey + F = 0x2+y2+Dx+Ey+F=0

    Use when D=−2hD = -2hD=−2h, E=−2kE = -2kE=−2k, F=h2+k2−r2F = h^2 + k^2 - r^2F=h2+k2−r2, so the center and radius stay buried until you complete the square on each variable. The x2x^2x2 and y2y^2y2 coefficients must be EQUAL, or it is not a circle. This DDD is the xxx-coefficient, not the discriminant.

  • When a circle collapses

    For (x−h)2+(y−k)2=R(x - h)^2 + (y - k)^2 = R(x−h)2+(y−k)2=R: R>0R > 0R>0 is a circle of radius R\sqrt{R}R​, R=0R = 0R=0 is the single point (h,k)(h, k)(h,k), and R<0R < 0R<0 has no graph at all.

    Use when Completing the square on a general form always produces this shape, and RRR is not guaranteed positive: check its sign before announcing a radius.

  • Inside, on, or outside a circle

    Compare a point's squared distance from the center, (x−h)2+(y−k)2(x - h)^2 + (y - k)^2(x−h)2+(y−k)2, against r2r^2r2: less means the point is inside the circle, equal means it is on the circle, and greater means it is outside.

    Use when No square root is needed: squaring never changes the order of two nonnegative numbers, so the squared comparison gives the same verdict as comparing the actual distance to rrr.

  • Sign of a quadratic across its roots

    With a>0a > 0a>0 and distinct real roots r<sr < sr<s: positive for x<rx < rx<r, negative for r<x<sr < x < sr<x<s, positive for x>sx > sx>s. With a<0a < 0a<0 every one of those signs reverses.

    Use when Needs D>0D > 0D>0 (two distinct real roots) and one side already 000. At a root the value is exactly 000, which joins the solution only for ≤\le≤ or ≥\ge≥.

  • Optimization models: area, revenue, projectile

    Fence FFF, four sides: A=x(F2−x)A = x\left(\tfrac{F}{2} - x\right)A=x(2F​−x). Fence FFF, three sides against a wall: A=x(F−2x)A = x(F - 2x)A=x(F−2x). Revenue: R=(price)(quantity)R = (\text{price})(\text{quantity})R=(price)(quantity). Height in feet: h=−16t2+v0t+h0h = -16t^2 + v_0 t + h_0h=−16t2+v0​t+h0​.

    Use when Each has a<0a < 0a<0, so each peaks at its vertex, the four-sided pen at a square. A length needs 0<x<F20 < x < \tfrac{F}{2}0<x<2F​; revenue is quadratic only when the quantity falls linearly as the price rises. For height, ttt is in seconds, v0v_0v0​ the initial upward speed in feet per second, and h0h_0h0​ the launch height in feet; the vertex input is the peak's time.

    e.g. 200200200 tickets at 101010 dollars, losing 101010 sales per 111 dollar rise: R=(10+x)(200−10x)R = (10 + x)(200 - 10x)R=(10+x)(200−10x).

Problem types, step by step

Sketch a parabola from y=ax2+bx+cy = ax^2 + bx + cy=ax2+bx+c

  1. Read the direction from the sign of aaa.
  2. Compute x=−b2ax = -\tfrac{b}{2a}x=−2ab​ for the axis, then substitute it back for the vertex height.
  3. Mark the yyy-intercept at (0,c)(0, c)(0,c).
  4. Set y=0y = 0y=0 for the xxx-intercepts, or compute DDD if you only need how many.
  5. Reflect the yyy-intercept across the axis for an extra point, then draw one smooth curve.

e.g. y=x2−2x−3y = x^2 - 2x - 3y=x2−2x−3: x=−−22=1x = -\tfrac{-2}{2} = 1x=−2−2​=1 and y=−4y = -4y=−4, plus (0,−3)(0, -3)(0,−3), (−1,0)(-1, 0)(−1,0), (3,0)(3, 0)(3,0).

Convert between standard form and vertex form

  1. Factor aaa out of the x2x^2x2 and xxx terms, leaving a(x2+bax)+ca\left(x^2 + \tfrac{b}{a}x\right) + ca(x2+ab​x)+c.
  2. Halve the coefficient of xxx inside, square it, and add and subtract that constant inside.
  3. Fold the perfect square, multiply the subtracted constant by aaa as it leaves the parentheses, and combine with ccc to get kkk.
  4. Read the vertex (h,k)(h, k)(h,k), remembering x+px + px+p inside means h=−ph = -ph=−p. To go back, expand and collect.

e.g. y=x2−6x+5y = x^2 - 6x + 5y=x2−6x+5 becomes y=(x−3)2−4y = (x - 3)^2 - 4y=(x−3)2−4, vertex (3,−4)(3, -4)(3,−4).

Graph a circle from its equation

  1. Read the center by flipping the sign of each number inside: y+2y + 2y+2 is y−(−2)y - (-2)y−(−2), so k=−2k = -2k=−2.
  2. Square-root the right side for the radius, and simplify it.
  3. Plot the center, step out rrr right, left, up, and down for four anchors, and curve through them.

e.g. (x+1)2+(y−3)2=9(x + 1)^2 + (y - 3)^2 = 9(x+1)2+(y−3)2=9: center (−1,3)(-1, 3)(−1,3), radius 333, anchors (2,3)(2, 3)(2,3), (−4,3)(-4, 3)(−4,3), (−1,6)(-1, 6)(−1,6), (−1,0)(-1, 0)(−1,0).

Write the equation of a circle

  1. Get the center: given, or the midpoint of a diameter (average the endpoints' coordinates).
  2. Get r2r^2r2, not rrr: square a given radius, or take the squared distance from center to a point on the circle.
  3. Substitute, letting a negative center coordinate turn the subtraction into a plus.

e.g. Center (2,1)(2, 1)(2,1) through (5,5)(5, 5)(5,5): r2=32+42=25r^2 = 3^2 + 4^2 = 25r2=32+42=25, so (x−2)2+(y−1)2=25(x - 2)^2 + (y - 1)^2 = 25(x−2)2+(y−1)2=25.

Convert a circle from general form to standard form

  1. Divide through if the x2x^2x2 and y2y^2y2 coefficients are equal but not 111.
  2. Group the xxx-terms and the yyy-terms, moving the lone constant right.
  3. Complete the square on each group, adding BOTH new constants to the right side.
  4. Write the two squares, total the right side, check its sign, and read the center and radius.

e.g. x2+y2−6x+8y−11=0x^2 + y^2 - 6x + 8y - 11 = 0x2+y2−6x+8y−11=0 becomes (x−3)2+(y+4)2=36(x - 3)^2 + (y + 4)^2 = 36(x−3)2+(y+4)2=36: center (3,−4)(3, -4)(3,−4), radius 666.

Solve a quadratic inequality

  1. Move every term to one side so the other side is 000.
  2. Find the roots by factoring or by the quadratic formula.
  3. If a<0a < 0a<0, reverse the pattern, or multiply by −1-1−1 and reverse the symbol.
  4. Test one number inside each interval the roots create, or read signs off the shape.
  5. Keep the intervals whose sign the inequality asks for, with endpoints only for ≤\le≤ and ≥\ge≥.

e.g. x2+5≤6xx^2 + 5 \le 6xx2+5≤6x becomes x2−6x+5≤0x^2 - 6x + 5 \le 0x2−6x+5≤0, roots 111 and 555, so 1≤x≤51 \le x \le 51≤x≤5.

Solve an inequality with a repeated root or no real roots

  1. Compute D=b2−4acD = b^2 - 4acD=b2−4ac once one side is 000.
  2. If D<0D < 0D<0 it keeps the sign of aaa everywhere: all real numbers or no solution, whichever the direction matches.
  3. If D=0D = 0D=0 it is 000 at the repeated root and has the sign of aaa elsewhere: decide whether that single point belongs.

e.g. x2+2x+5>0x^2 + 2x + 5 > 0x2+2x+5>0: D=4−20=−16D = 4 - 20 = -16D=4−20=−16 and a>0a > 0a>0, so all real numbers.

Maximize or minimize a quadratic quantity

  1. Name the variable you choose and write every other quantity in terms of it.
  2. Write the quantity being optimized as a quadratic and expand it into standard form.
  3. Read the sign of aaa to confirm a maximum or a minimum, then compute the input x=−b2ax = -\tfrac{b}{2a}x=−2ab​.
  4. Substitute back for the optimal value, or into the other expressions for any dimensions asked.
  5. Answer exactly what was asked, with units, and check the input is possible.

e.g. 606060 metres against a wall: A=x(60−2x)A = x(60 - 2x)A=x(60−2x) peaks at x=15x = 15x=15.

Exam traps

  • Trap Reading (x+3)2+(y−4)2=36(x + 3)^2 + (y - 4)^2 = 36(x+3)2+(y−4)2=36 as center (3,4)(3, 4)(3,4) with radius 363636.

    Fix The form subtracts each center coordinate: x+3x + 3x+3 is x−(−3)x - (-3)x−(−3), so h=−3h = -3h=−3; the right side is r2r^2r2. Center (−3,4)(-3, 4)(−3,4), radius 666.

  • Trap Answering −2<x<3-2 < x < 3−2<x<3 for x2−x−6>0x^2 - x - 6 > 0x2−x−6>0.

    Fix That is where the upward parabola sits BELOW the axis. Above 000 is outside the roots: x<−2x < -2x<−2 or x>3x > 3x>3. Test x=0x = 0x=0, which gives −6-6−6.

  • Trap Answering x≤−1x \le -1x≤−1 or x≥3x \ge 3x≥3 for −x2+2x+3≥0-x^2 + 2x + 3 \ge 0−x2+2x+3≥0, because ≥0\ge 0≥0 means "outside the roots".

    Fix Outside the roots is the a>0a > 0a>0 pattern, and here a=−1a = -1a=−1. A downward parabola is above the axis BETWEEN its roots, so the answer is −1≤x≤3-1 \le x \le 3−1≤x≤3. Test x=0x = 0x=0: 3≥03 \ge 03≥0 holds. Or multiply by −1-1−1 and reverse the symbol: x2−2x−3≤0x^2 - 2x - 3 \le 0x2−2x−3≤0.

  • Trap Answering 333 to "what is the minimum value of y=x2−6x+1y = x^2 - 6x + 1y=x2−6x+1".

    Fix 333 is only where the minimum happens. Substitute back: y=9−18+1=−8y = 9 - 18 + 1 = -8y=9−18+1=−8, the minimum value.

  • Trap Writing an outside-the-roots answer as one band, such as 3<x<−23 < x < -23<x<−2.

    Fix Two separate rays joined by "or": x<−2x < -2x<−2 or x>3x > 3x>3, that is (−∞,−2)∪(3,∞)(-\infty, -2) \cup (3, \infty)(−∞,−2)∪(3,∞). A band from the larger number down to the smaller names nothing.

  • Trap Dropping the leading minus in −b2a-\tfrac{b}{2a}−2ab​, so y=x2−4x+1y = x^2 - 4x + 1y=x2−4x+1 looks like it has its axis at x=−2x = -2x=−2.

    Fix The formula flips the sign of bbb: −−42(1)=2-\tfrac{-4}{2(1)} = 2−2(1)−4​=2, so the axis is x=2x = 2x=2 and the vertex (2,−3)(2, -3)(2,−3).

  • Trap Solving x2<4xx^2 < 4xx2<4x by dividing both sides by xxx to get x<4x < 4x<4.

    Fix Dividing by a variable assumes its sign and corrupts the solution set: x=−1x = -1x=−1 passes x<4x < 4x<4 but fails 1<−41 < -41<−4. Move everything over: x2−4x<0x^2 - 4x < 0x2−4x<0, roots 000 and 444, so 0<x<40 < x < 40<x<4.

  • Trap Using the full perimeter when a wall supplies the fourth side, so 606060 metres of fence gives a 151515 by 151515 pen.

    Fix Three sides only: 2x+y=602x + y = 602x+y=60, so A=x(60−2x)A = x(60 - 2x)A=x(60−2x), peaking at x=15x = 15x=15 with y=30y = 30y=30, a 450450450 square metre garden. The four-sided model double-counts the free wall and lands on 225225225.
