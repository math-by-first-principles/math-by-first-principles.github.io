  1. Problem 1 The input instruction

    A rule adds 222 to its real input xxx, raises the fixed number 333 to that sum, and halves the value obtained. Write the rule in the form f(x)=a⋅bxf(x)=a\cdot b^xf(x)=a⋅bx.

    1. Hint 1

      The entered quantity becomes an exponent rather than a base.

    2. Hint 2

      Split the power at the addition in its exponent, then apply the halving to the constant factor that appears.

    Answer

    f(x)=92⋅3xf(x)=\tfrac92\cdot3^xf(x)=29​⋅3x, or 4.5⋅3x4.5\cdot3^x4.5⋅3x.

    Full solution

    The instructions give

    f(x)=12⋅3x+2f(x)=\tfrac12\cdot3^{x+2}f(x)=21​⋅3x+2

    The exponent rule separates the added part:

    3x+2=9⋅3x3^{x+2}=9\cdot3^x3x+2=9⋅3x

    Halving that constant gives

    f(x)=92⋅3xf(x)=\tfrac92\cdot3^xf(x)=29​⋅3x

    so a=92a=\tfrac92a=29​ and b=3b=3b=3.

    At x=0x=0x=0 the instructions give 12⋅32=92\tfrac12\cdot3^2=\tfrac9221​⋅32=29​, which matches.

    Answer

    f(x)=92⋅3xf(x)=\tfrac92\cdot3^xf(x)=29​⋅3x, or 4.5⋅3x4.5\cdot3^x4.5⋅3x.

    Key idea

    An addition inside an exponent becomes a constant multiplier, which then combines with whatever multiplier sits outside the power.

  2. Problem 2 The base setting

    A device uses f(x)=(k−2)xf(x)=(k-2)^xf(x)=(k−2)x as a genuine exponential function, defined for every real xxx and not a constant. Find all allowed real settings kkk.

    1. Hint 1

      The proposed base must meet both restrictions for a real exponential function.

    2. Hint 2

      An exponential base must be positive and must not equal 111; apply each restriction to the expression k−2k-2k−2.

    Answer

    k>2k>2k>2, with k≠3k\ne3k=3.

    Full solution

    Positivity of the base requires

    k−2>0k-2>0k−2>0

    or k>2k>2k>2.

    The base is not allowed to equal 111, so

    k−2≠1k-2\ne1k−2=1

    excludes k=3k=3k=3.

    Every remaining setting supplies a positive base different from 111, so the function is defined at all real inputs and is not constant.

    Answer

    k>2k>2k>2, with k≠3k\ne3k=3.

    Key idea

    A parameter used inside an exponential base must satisfy the base restrictions after its expression is evaluated.

    Key idea

    For a base power, an input difference is represented by a quotient of positive outputs.

  5. Problem 5 The revised time unit

    A model is N(t)=18⋅3tN(t)=18\cdot3^tN(t)=18⋅3t, where ttt is time in hours. Another display uses sss, the number of half-hours since the same start. Write the same model as N=a⋅csN=a\cdot c^sN=a⋅cs, and state the exact reading when s=3s=3s=3.

    1. Hint 1

      Changing the time unit changes how many input steps fit in an hour.

    2. Hint 2

      One hour contains two half-hours, so substitute t=s/2t=s/2t=s/2 in the exponent.

    Answer

    N=18(3)sN=18(\sqrt3)^sN=18(3​)s; at s=3s=3s=3, N=543N=54\sqrt3N=543​, about 93.593.593.5.

    Full solution

    The time inputs satisfy t=s/2t=s/2t=s/2.

    Substitute this into the original rule:

    N=18⋅3s/2N=18\cdot3^{s/2}N=18⋅3s/2

    The power rule writes the same function as

    N=18(3)sN=18(\sqrt3)^sN=18(3​)s

    Two steps in sss multiply the output by (3)2=3(\sqrt3)^2=3(3​)2=3, matching one hour.

    At s=3s=3s=3 the cube of 3\sqrt33​ is 333\sqrt333​, so

    N=543N=54\sqrt3N=543​

    about 93.593.593.5.

    That input is t=1.5t=1.5t=1.5 hours, and 18⋅31.518\cdot3^{1.5}18⋅31.5 gives the same reading.

    Answer

    N=18(3)sN=18(\sqrt3)^sN=18(3​)s; at s=3s=3s=3, N=543N=54\sqrt3N=543​, about 93.593.593.5.

    Key idea

    When input units change, the exponential base changes so the multipliers over equal physical intervals still agree.

  6. Problem 6 The display offset

    A reserve follows R(t)=abtR(t)=ab^tR(t)=abt, with a>0a>0a>0 and 0<b<10<b<10<b<1, where ttt counts days. A display adds a fixed offset of 666 units to every true amount. Its readings at days 000, 111, and 222 are 707070, 383838, and 222222 units. Find the true rule and the display reading at day 333.

    1. Hint 1

      Remove the fixed offset before looking for the multiplying pattern.

    2. Hint 2

      Compare the true amounts at equal day steps, then restore the offset only after predicting a true amount.

    Answer

    R(t)=64(12)tR(t)=64(\frac12)^tR(t)=64(21​)t; day 333 display: 141414 units.

    Full solution

    Removing the offset gives true amounts 646464, 323232, and 161616 units.

    Both ratios equal one half, so

    R(t)=64(12)tR(t)=64\left(\frac12\right)^tR(t)=64(21​)t

    The true amount at day 333 is

    R(3)=8R(3)=8R(3)=8

    units.

    Restoring the display offset gives

    8+6=148+6=148+6=14

    units.

    Adding the offset back to 646464, 323232, and 161616 reproduces the readings 707070, 383838, and 222222, so the rule fits.

    Answer

    R(t)=64(12)tR(t)=64(\frac12)^tR(t)=64(21​)t; day 333 display: 141414 units.

    Key idea

    A fixed display offset must be removed before testing an exponential ratio and restored after predicting the underlying amount.

  7. Problem 7 The two counters

    For whole-number inputs n≥0n\ge0n≥0, counter A reports 2⋅3n2\cdot3^n2⋅3n and counter B reports 10+4n10+4n10+4n. Find the first input at which A exceeds B. Explain why seeing B larger at the start does not contradict exponential growth eventually outgrowing linear growth.

    1. Hint 1

      Compare the two actual outputs at successive whole-number inputs.

    2. Hint 2

      One counter multiplies by a fixed factor while the other adds a fixed amount.

    Answer

    n=3n=3n=3; A reports 545454 and B reports 222222.

    Full solution

    At n=0n=0n=0, A and B give 222 and 101010.

    At n=1n=1n=1, they give 666 and 141414.

    At n=2n=2n=2,

    2⋅32=182\cdot3^2=182⋅32=18

    and 10+4(2)=1810+4(2)=1810+4(2)=18, so neither exceeds the other yet.

    At n=3n=3n=3, A gives 545454 and B gives 222222, so the first strict exceedance is n=3n=3n=3.

    The claim about eventual growth concerns sufficiently large inputs, not which value is larger initially.

    Answer

    n=3n=3n=3; A reports 545454 and B reports 222222.

    Key idea

    Eventual exponential dominance permits a linear quantity to be larger at early inputs.

  8. Problem 8 Two outputs multiplied

    Full solution

    The exponent rule combines the two powers:

    16bsbt=16bs+t16b^sb^t=16b^{s+t}16bsbt=16bs+t

    Answer

  10. Problem 10 The two bases
