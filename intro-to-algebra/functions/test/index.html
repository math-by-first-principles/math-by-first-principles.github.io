    A rule's graph is drawn below, crossed by one dashed vertical line and one dashed horizontal line. Taken together, what do the two line tests say about this graph?

    Answer choices for question 7

    Solution

    Correct answer: B

    You chose A: Uses the horizontal line to decide whether the graph is a function at all; two horizontal crossings say the rule is not one-to-one, and it is the vertical line that answers the function question.

    You chose C: Reads the single vertical crossing as settling both questions, as if being a function also guaranteed that each output came from just one input.

    You chose D: Counts any meeting as a failure, though a vertical line meeting the graph exactly once is the vertical line test being passed.

    The two tests answer two different questions. The horizontal line gathers every point sharing one output, and it meets the curve twice, so two different inputs land on the same output.

    one vertical crossing⇒a function,two horizontal crossings⇒not one-to-one.\text{one vertical crossing} \Rightarrow \text{a function}, \qquad \text{two horizontal crossings} \Rightarrow \text{not one-to-one}.one vertical crossing⇒a function,two horizontal crossings⇒not one-to-one.

    A rule that is not one-to-one cannot be reversed, because the shared output would have to be sent back to two different inputs at once.
