Inverse Functions Advanced. This lesson goes beyond core Algebra I. You can skip it.

Intuition

You have spent two lessons building functions and running them forward: put in an input, and read off the output. Many functions describe a process that flows one way, like a phone plan that turns a number of minutes into a bill. Sooner or later you know the result and want the starting value back: you have the bill and want the minutes. Running a function backward like this, sending each output to the input it came from, is called taking its inverse. Every undo you already trust is a first example, since subtracting reverses adding and dividing reverses multiplying. This lesson makes the idea precise, shows how to find an inverse, and uses composition from the last lesson to confirm that two functions really do undo each other.

Learning goals

  • Swap input and output, algebraically and in a diagram, to build the inverse
  • Read f−1f^{-1}f−1 as the inverse, never the reciprocal
  • Trade domain for range between a function and its inverse
  • Apply the horizontal line test to spot a one-to-one rule
  • Verify a pair by composing both ways to xxx

Undoing what a function does

Start with a rule simple enough to see straight through: f(x)=x+3f(x) = x + 3f(x)=x+3, the rule “add three.” Feed it 555 and it returns 888; feed it 101010 and it returns 131313. To send those outputs back where they came from, you do the obvious thing and subtract three: 888 goes back to 555, and 131313 goes back to 101010. The rule “subtract three,” written g(x)=x−3g(x) = x - 3g(x)=x−3, reverses everything “add three” did. That reversing rule is the inverse of fff.

Look at what happens to a single input-output pair. The function fff ties the input 555 to the output 888, a pairing we can write as (5,8)(5, 8)(5,8). Its inverse ties 888 back to 555, the pair (8,5)(8, 5)(8,5). The inverse takes every pair of fff and swaps its two entries: whatever was the input becomes the output, and whatever was the output becomes the input. That one sentence, swap the input and the output, is the whole idea of an inverse, and everything else in this lesson follows from it.

The inverse of fff has its own symbol, f−1f^{-1}f−1, read aloud as ”fff inverse.” It is defined to undo fff, and “undo” can be stated precisely in two directions. If you run fff and then run f−1f^{-1}f−1, you return to the input you started with:

f−1(f(x))=x.f^{-1}(f(x)) = x.f−1(f(x))=x.

Reading from the inside out, fff turns xxx into f(x)f(x)f(x), and f−1f^{-1}f−1 turns that back into xxx. The reverse order must work too. If you run f−1f^{-1}f−1 first and then fff, you again come back to the start:

f(f−1(x))=x.f(f^{-1}(x)) = x.f(f−1(x))=x.

Both equations say the same thing from opposite ends: fff and f−1f^{-1}f−1 cancel each other, whichever one you apply first. For f(x)=x+3f(x) = x + 3f(x)=x+3 and f−1(x)=x−3f^{-1}(x) = x - 3f−1(x)=x−3, check both directions:

f−1(f(x))=(x+3)−3=x,f(f−1(x))=(x−3)+3=x.f^{-1}(f(x)) = (x + 3) - 3 = x, \qquad f(f^{-1}(x)) = (x - 3) + 3 = x.f−1(f(x))=(x+3)−3=x,f(f−1(x))=(x−3)+3=x.

Adding three and then subtracting three lands you back where you began, and so does subtracting first and then adding.

The superscript that is not a reciprocal

The symbol f−1f^{-1}f−1 carries a trap, and it is worth defusing before you use it. The raised −1-1−1 everywhere else in algebra makes a reciprocal, so f−1(x)f^{-1}(x)f−1(x) looks like it should mean 1f(x)\dfrac{1}{f(x)}f(x)1​. It does not. Here f−1f^{-1}f−1 is the name of the inverse function, and it has nothing to do with dividing 111 by anything.

Why reuse a symbol that invites the confusion? For a nonzero number, its reciprocal is the number that multiplies with it to give 111: the reciprocal of 555 is 15\dfrac{1}{5}51​, and 5⋅15=15 \cdot \dfrac{1}{5} = 15⋅51​=1. Functions borrow the same idea with composition in place of multiplication: f−1f^{-1}f−1 is the function that, composed with fff, gives back the input unchanged, the same job 111 does for multiplication. The notation is a deliberate echo of that pattern, one inverse for each operation. Because the operations are different, the two inverses are different objects.

Make the difference concrete. For f(x)=x+3f(x) = x + 3f(x)=x+3, the inverse function is f−1(x)=x−3f^{-1}(x) = x - 3f−1(x)=x−3, while the reciprocal is 1f(x)=1x+3\dfrac{1}{f(x)} = \dfrac{1}{x + 3}f(x)1​=x+31​. These are not close. At x=5x = 5x=5,

f−1(5)=5−3=2,1f(5)=18.f^{-1}(5) = 5 - 3 = 2, \qquad \frac{1}{f(5)} = \frac{1}{8}.f−1(5)=5−3=2,f(5)1​=81​.

One returns the input that produced the output 555; the other is a small fraction with nothing to do with undoing fff. Whenever you see f−1f^{-1}f−1, read “the function that reverses fff,” never “one over fff.”

Finding an inverse: swap, then solve

Guessing the inverse works for “add three,” but you need a method that works for any rule you are handed. The swap principle hands you one directly. The pairs of fff are (input, output), and the inverse’s pairs are (output, input). So to build the inverse you interchange the input and the output and then rearrange. In symbols, write y=f(x)y = f(x)y=f(x), swap xxx and yyy, and solve the new equation for yyy. The recipe is not a ritual; each step is the input-output swap written in algebra. It always produces a candidate inverse; the section “When a function has no inverse” comes back to when that candidate is a genuine function.

Watch it work on f(x)=2x+3f(x) = 2x + 3f(x)=2x+3. A few input-output pairs show the pattern before the algebra does:

input xxx000111222
output yyy333555777

The inverse takes each output back to its input, so its pairs run the other way: 3→03 \to 03→0, 5→15 \to 15→1, 7→27 \to 27→2. Write the output as yyy:

y=2x+3.y = 2x + 3.y=2x+3.

Here xxx is the input and yyy is the output. Swap them, so that the letter standing for the output now plays the role of the input we feed in. The letter standing for the input is then the value we want back:

x=2y+3.x = 2y + 3.x=2y+3.

Solve this for yyy by subtracting three and dividing by two:

x−3=2y⟹y=x−32.x - 3 = 2y \quad\Longrightarrow\quad y = \frac{x - 3}{2}.x−3=2y⟹y=2x−3​.

Rename the result, and the inverse is f−1(x)=x−32f^{-1}(x) = \dfrac{x - 3}{2}f−1(x)=2x−3​. The rule “double, then add three” is undone by “subtract three, then halve,” with the steps reversed and each one turned around, exactly as an undo should be.

This rule subtracts three and then takes the reciprocal, and it accepts every input except x=3x = 3x=3, where the denominator would be zero. Find its inverse the same way. Start from

Domain and range trade places

The forbidden-input swap you just saw is one instance of a rule that always holds: an inverse turns the domain and range of fff around. It follows straight from swapping input and output. Every pair of fff has the form (input from the domain, output from the range). The inverse swaps each pair into (output, input). So the numbers that were outputs are now the inputs of f−1f^{-1}f−1, and the numbers that were inputs are now its outputs. Therefore

  • the domain of f−1f^{-1}f−1 is the range of fff (the old outputs are the new inputs), and
  • the range of f−1f^{-1}f−1 is the domain of fff (the old inputs are the new outputs).

Return to f(x)=1x−3f(x) = \dfrac{1}{x - 3}f(x)=x−31​ from the last example. Its domain is every number except 333, and its range is every number except 000, because the reciprocal of a nonzero quantity is never 000. Its inverse f−1(x)=1x+3f^{-1}(x) = \dfrac{1}{x} + 3f−1(x)=x1​+3 has domain every number except 000 and range every number except 333. Line them up and the trade is exact: the domain of one is the range of the other, both ways.

Check your understanding

Suppose fff has domain all numbers except 222 and range all numbers except 777. What are the domain and range of f−1f^{-1}f−1?

Answer choices

The domain of f−1f^{-1}f−1 is the range of fff, and the range of f−1f^{-1}f−1 is the domain of fff: the two trade places. Since fff excludes 222 from its domain and 777 from its range, f−1f^{-1}f−1 excludes 777 from its domain and 222 from its range.

When a function has no inverse

Every example so far has had a clean inverse, but some functions have none, and it is important to see why. The trouble starts when two different inputs produce the same output. Consider the squaring rule on all numbers, f(x)=x2f(x) = x^2f(x)=x2. It sends both 333 and −3-3−3 to 999:

32=9and(−3)2=9.3^2 = 9 \qquad \text{and} \qquad (-3)^2 = 9.32=9and(−3)2=9.

Now ask the inverse to do its job. It must send the output 999 back to the input it came from, but here 999 came from two inputs. Should f−1(9)f^{-1}(9)f−1(9) be 333 or −3-3−3? There is no honest answer. A function is allowed only one output per input, and this would force the single input 999 to have two outputs. So squaring on all numbers has no inverse function.

The property that avoids this trap has a name. A function is one-to-one when different inputs always give different outputs, that is, when no two inputs share an output. Squaring fails to be one-to-one because 333 and −3-3−3 collide. A line like f(x)=4x−7f(x) = 4x - 7f(x)=4x−7 is one-to-one, because two different inputs, stretched and shifted the same way, stay different. In fact a function has an inverse function exactly when it is one-to-one: two colliding inputs always block a reversal, the way 333 and −3-3−3 just did, and no collision always allows one.

That claim can be proved directly, in both directions. Read it in the Go deeper section at the end of this lesson.

The horizontal line test

One-to-one has a picture, and it is the mirror image of a test you already know. In the lesson on functions you met the vertical line test: a graph represents a function when no vertical line crosses it more than once. The reason is that a vertical line gathers all the points with a single input, and a function may not give that input two outputs. One-to-one asks the reverse question, so it uses the reverse line.

A horizontal line gathers all the points that share a single output, since every point on the line y=cy = cy=c sits at the same height ccc. If some horizontal line meets the graph in two points, those two points have the same output but different inputs, and the function is not one-to-one. So a graph belongs to a one-to-one function exactly when no horizontal line crosses it more than once. The vertical line test checks “one output per input,” which makes the graph a function. The horizontal line test checks “one input per output,” which makes that function invertible.

The rising line on the left passes: every height is reached exactly once, so it is one-to-one and has an inverse. The parabola y=x2y = x^2y=x2 on the right fails: the horizontal line hits it twice, at x=3x = 3x=3 and x=−3x = -3x=−3 for the height 999, the same collision that blocked its inverse.

Two crossings mean two different inputs share the output 555, so f(x)=∣x∣f(x) = |x|f(x)=∣x∣ on all real numbers is not one-to-one and has no inverse function, the same kind of collision squaring has at every positive output.

A function that fails the test can often be repaired by shrinking its domain until it is one-to-one. Squaring collides because every positive output has two inputs that reach it, a positive one and its negative; only the output 000 is different, since it comes from the single input 000. Throw away the negative inputs, keeping f(x)=x2f(x) = x^2f(x)=x2 for x≥0x \ge 0x≥0, and every output now comes from a single nonnegative input. On that restricted domain squaring is one-to-one, and its inverse is the square root.

Worked example 2 An inverse on a restricted domain

Find the inverse of f(x)=x2f(x) = x^2f(x)=x2 with the domain restricted to x≥0x \ge 0x≥0.

With the domain restricted, the rule is one-to-one, so an inverse function exists. Swap and solve, watching the restriction travel with the variable. Start from

y=x2,x≥0.y = x^2, \qquad x \ge 0.y=x2,x≥0.

Swap xxx and yyy. The condition x≥0x \ge 0x≥0 was a statement about the input of fff, which becomes the output of f−1f^{-1}f−1, so it attaches to yyy:

Solve x=y2x = y^2x=y2 for yyy. When x>0x > 0x>0, two numbers square to xxx, namely x\sqrt{x}x​ and −x-\sqrt{x}−x​; when x=0x = 0x=0, the only number that squares to it is 000 itself. Either way, the restriction y≥0y \ge 0y≥0 keeps only the nonnegative choice:

So f−1(x)=xf^{-1}(x) = \sqrt{x}f−1(x)=x​. The restriction is what rescued the inverse. Without it, x=y2x = y^2x=y2 would hand back two values of yyy for each positive xxx, which is no function at all. This is the general fix for a rule that fails the horizontal line test. Cut the domain down to a piece on which the rule is one-to-one, then invert that piece.

Verifying an inverse by composition

You now have a way to find an inverse. But how do you check that a proposed answer is right, or test whether two functions handed to you are really inverses? The definition already said it: fff and ggg are inverses exactly when they undo each other in both directions,

f(g(x))=xandg(f(x))=x.f(g(x)) = x \qquad \text{and} \qquad g(f(x)) = x.f(g(x))=xandg(f(x))=x.

These are compositions, the operation from the last lesson, so verifying an inverse is just building the two composite functions and checking that each one collapses to xxx, on every input the inside function actually accepts. Both directions are required, and the reason goes back to one-to-one. A single direction can hold while the other fails, and when it does the two functions are not inverses.

Worked example 3 Checking a pair in both directions

Build both compositions. For g(f(x))g(f(x))g(f(x)), drop the whole rule for fff into ggg:

g(f(x))=(2x−6)+62=2x2=x.g(f(x)) = \frac{(2x - 6) + 6}{2} = \frac{2x}{2} = x.g(f(x))=2(2x−6)+6​=22x​=x.

For f(g(x))f(g(x))f(g(x)), drop the whole rule for ggg into fff:

f(g(x))=2⋅x+62−6=(x+6)−6=x.f(g(x)) = 2 \cdot \frac{x + 6}{2} - 6 = (x + 6) - 6 = x.f(g(x))=2⋅2x+6​−6=(x+6)−6=x.

which is not xxx for negative inputs. At x=−3x = -3x=−3 it gives (−3)2=9=3\sqrt{(-3)^2} = \sqrt{9} = 3(−3)2​=9​=3, not −3-3−3. The square root cannot recover the sign that squaring destroyed. Running a process backward

An inverse earns its keep whenever a function models a process and you need to run that process in reverse. If a rule turns a starting value into a result, its inverse turns the result back into the starting value, which answers a question the forward rule cannot.

Worked example 4 Recovering the input from the output

A phone plan charges a fixed 202020 dollars per month plus 0.100.100.10 dollars for each minute of calls, so the monthly cost for mmm minutes, m≥0m \ge 0m≥0, is C(m)=20+0.1mC(m) = 20 + 0.1mC(m)=20+0.1m. The cost function runs forward, minutes in and dollars out. You want the reverse, dollars in and minutes out, which is the inverse. Write the cost as ccc and solve for mmm:

c=20+0.1m⟹c−20=0.1m⟹m=c−200.1=10(c−20).c = 20 + 0.1m \quad\Longrightarrow\quad c - 20 = 0.1m \quad\Longrightarrow\quad m = \frac{c - 20}{0.1} = 10(c - 20).c=20+0.1m⟹c−20=0.1m⟹m=0.1c−20​=10(c−20).

Common mistakes

Common mistakes

  • Reading f−1f^{-1}f−1 as a reciprocal. f−1(x)f^{-1}(x)f−1(x) is the function that undoes fff, not 1f(x)\dfrac{1}{f(x)}f(x)1​. For f(x)=x+3f(x) = x + 3f(x)=x+3 the inverse is x−3x - 3x−3, while 1f(x)=1x+3\dfrac{1}{f(x)} = \dfrac{1}{x+3}f(x)1​=x+31​ is something else entirely.
  • Checking only one direction. Confirming f(g(x))=xf(g(x)) = xf(g(x))=x does not prove an inverse on its own; you also need g(f(x))=xg(f(x)) = xg(f(x))=x. Squaring and the square root pass one direction and fail the other.
  • Inverting a rule that is not one-to-one. A function with two inputs sharing an output, like x2x^2x2 on all numbers, has no inverse function until you restrict its domain to make it one-to-one.
  • Swapping but forgetting to solve. After interchanging xxx and yyy you still have to solve the new equation for yyy. Stopping at x=2y+3x = 2y + 3x=2y+3 leaves the inverse half-found.
  • Copying the domain and range straight across. The domain of f−1f^{-1}f−1 is the range of fff, and the range of f−1f^{-1}f−1 is the domain of fff. They trade places, so do not carry them over unchanged.
  • Dropping a domain restriction. When you invert a restricted function, the restriction moves to the other variable. Losing it turns x=y2, y≥0x = y^2,\ y \ge 0x=y2, y≥0 back into a two-valued rule that is not a function.

Key takeaways

  • The inverse f−1f^{-1}f−1 reverses fff: it sends each output back to the input it came from. That is the same as swapping the input and output in every pair.
  • Inverses are defined by undoing in both directions: f−1(f(x))=xf^{-1}(f(x)) = xf−1(f(x))=x and f(f−1(x))=xf(f^{-1}(x)) = xf(f−1(x))=x.
  • The notation f−1f^{-1}f−1 names the inverse function, not the reciprocal 1f\dfrac{1}{f}f1​.
  • To find an inverse, write y=f(x)y = f(x)y=f(x), swap xxx and yyy, solve for yyy, and rename it f−1(x)f^{-1}(x)f−1(x).
  • A function has an inverse function exactly when it is one-to-one (no two inputs share an output), which on a graph is the horizontal line test. A rule that fails, like x2x^2x2 on all numbers, can be inverted after restricting its domain, giving x\sqrt{x}x​ on x≥0x \ge 0x≥0.
  • The domain and range swap: the domain of f−1f^{-1}f−1 is the range of fff, and its range is the domain of fff.
  • To verify that fff and ggg are inverses, check both f(g(x))=xf(g(x)) = xf(g(x))=x and g(f(x))=xg(f(x)) = xg(f(x))=x.

Why an inverse needs a one-to-one function

Why an inverse needs a one-to-one function#

Suppose fff is not one-to-one, so two different inputs aaa and bbb, with a≠ba \ne ba=b, share an output: f(a)=f(b)=cf(a) = f(b) = cf(a)=f(b)=c. Any inverse of fff has one required job, to send each output back to the input that produced it. Applied to ccc, that job is contradictory, because ccc was produced by aaa and also by bbb. The inverse would need f−1(c)=af^{-1}(c) = af−1(c)=a and f−1(c)=bf^{-1}(c) = bf−1(c)=b at the same time, giving the single input ccc two different outputs. That is precisely what the definition of a function forbids, so no function can undo fff.

Now suppose instead that fff is one-to-one. Then every output of fff comes from exactly one input, never two. Sending each output back to that one input is therefore an unambiguous rule, with a single result each time. Producing a single result for each input is exactly what it means to be a function. So the reversal is a genuine function, the inverse f−1f^{-1}f−1.

Putting the two halves together, fff has an inverse function if and only if fff is one-to-one. The condition is not an extra hoop to clear; it is the exact price of demanding that the reversal be single-valued.

A bit of history (optional)

A raised −1-1−1 already had a job before anyone attached it to a function. On a number it makes a reciprocal, so 5−15^{-1}5−1 is one fifth. The English astronomer John Herschel explained a new use for that same small symbol in a paper published in 1813, though an analyst named Burmann is reported to have used a similar notation earlier in Germany. It was Herschel’s explanation that reached English mathematics and stuck, so his name is the one usually attached to it.

Herschel wanted a compact way to name the angle with a given sine. He wrote sin⁡−1\sin^{-1}sin−1 for it. He also wrote f−1f^{-1}f−1 for the function that undoes fff. The borrowing was deliberate. Some writers of his day used a raised 222 on a function to mean applying it twice, so f2(x)f^2(x)f2(x) stood for f(f(x))f(f(x))f(f(x)), alongside other competing uses of the same mark. Herschel leaned on that reading: if a raised 222 can say do it twice, a raised −1-1−1 saying undo it fits the pattern neatly.

Mathematics never tidied the clash away. We still write f−1f^{-1}f−1 for the inverse function. We also still write sin⁡2x\sin^2 xsin2x for (sin⁡x)2(\sin x)^2(sinx)2, so one small superscript points in two directions depending on its sign.

Knowing where the notation came from is the surest way to keep it straight. Negative superscripts on a function were already being used for inverse and repeated operations before the meaning settled the way it has today, and the echo with the reciprocal is a likely reason −1-1−1 won out. Either way, f−1f^{-1}f−1 does not mean one over fff. It names the rule that sends every output back to the input it came from, the pairing you built here and then confirmed by composing both ways to xxx.
