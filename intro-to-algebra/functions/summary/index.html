Functions: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Function
A rule assigning exactly one output to each allowed input. Different inputs may share an output.
Function notation f(x)f(x)f(x)
fff names the rule, xxx is the input, and f(x)f(x)f(x) is the output. Thus f(3)=7f(3)=7f(3)=7 means input 333 produces output 777.
Domain
The set of inputs a function is allowed to take.
Range
The set of outputs the function actually produces.
Composition f∘gf \circ gf∘g (Advanced)
Feeding the output of ggg into fff, read "fff after ggg". The circle denotes composition, not multiplication.
Inner and outer function (Advanced)
In f(g(x))f(g(x))f(g(x)), the inner function ggg runs first. The outer function fff then acts on that output.
Inverse function f−1f^{-1}f−1 (Advanced)
The function that reverses every pair of a one-to-one function: (5,8)(5,8)(5,8) becomes (8,5)(8,5)(8,5). Its inputs are the outputs of the original function.
One-to-one function (Advanced)
A function whose different inputs always give different outputs, so no two inputs share an output.
Binary operation (Advanced)
A rule taking an allowed pair of inputs to one output, such as addition or a defined symbol ⋆\star⋆. The pair together is the input to a function.
Commutative operation (Advanced)
Swapping inputs never changes the result: a⋆b=b⋆aa\star b=b\star aa⋆b=b⋆a for every allowed pair.
Associative operation (Advanced)
Regrouping inputs never changes the result: (a⋆b)⋆c=a⋆(b⋆c)(a\star b)\star c=a\star(b\star c)(a⋆b)⋆c=a⋆(b⋆c) for every allowed triple.

Formulas and theorems

  • Vertical line test

    A graph represents a function exactly when no vertical line crosses it more than once.

    Text description

    The curve x equals y squared, with a dashed vertical line at x equals 4 crossing it twice, at the outputs 2 and negative 2.

    Use when Put inputs on the horizontal axis and outputs on the vertical axis. A line missing the graph corresponds to a value outside the domain.

    e.g. x=y2x = y^2x=y2 fails: at x=4x = 4x=4 both 222 and −2-2−2 appear.

  • Arithmetic combinations of two functions (Advanced)

    (f+g)(x)=f(x)+g(x)(f−g)(x)=f(x)−g(x)(fg)(x)=f(x)⋅g(x)(fg)(x)=f(x)g(x)\begin{gathered} (f + g)(x) = f(x) + g(x) \\ (f - g)(x) = f(x) - g(x) \\ (fg)(x) = f(x) \cdot g(x) \\ \left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)} \end{gathered}(f+g)(x)=f(x)+g(x)(f−g)(x)=f(x)−g(x)(fg)(x)=f(x)⋅g(x)(gf​)(x)=g(x)f(x)​​

    Use when Both functions must accept the input. A quotient also needs g(x)≠0g(x)\ne0g(x)=0; cancellation does not remove this restriction.

  • Composition (Advanced)

    (f∘g)(x)=f(g(x))(f \circ g)(x) = f(g(x))(f∘g)(x)=f(g(x))
    Text description

    Follow the downward arrows: x enters g first; its output g(x) enters f next, producing f(g(x)).

    Use when Run ggg first, then fff. Check that both steps are allowed.

    e.g. f(x)=x2f(x) = x^2f(x)=x2, g(x)=x+4g(x) = x + 4g(x)=x+4: (f∘g)(x)=(x+4)2=x2+8x+16(f \circ g)(x) = (x + 4)^2 = x^2 + 8x + 16(f∘g)(x)=(x+4)2=x2+8x+16.

  • Composition is not commutative (Advanced)

    In general f∘gf \circ gf∘g and g∘fg \circ fg∘f are different functions.

    Use when Some pairs do agree, such as adding 222 and adding 777 in either order. Equality requires the same domain as well as the same outputs at every allowed input.

    e.g. f(x)=x2f(x) = x^2f(x)=x2, g(x)=x+4g(x) = x + 4g(x)=x+4: f(g(3))=49f(g(3)) = 49f(g(3))=49 but g(f(3))=13g(f(3)) = 13g(f(3))=13.

  • Domain of a composition (Advanced)

    An input is in the domain of f∘gf \circ gf∘g exactly when it is allowed into ggg AND the output g(x)g(x)g(x) is allowed into fff.

    Use when Check the inner input and the intermediate output. Simplifying the formula does not erase either restriction.

  • Defining property of an inverse (Advanced)

    f−1(f(x))=xf(f−1(x))=x\begin{gathered} f^{-1}(f(x)) = x \\ f(f^{-1}(x)) = x \end{gathered}f−1(f(x))=xf(f−1(x))=x​
    Text description

    Two ovals: an arrow labeled f carries x across to f of x, and a return arrow labeled f inverse carries it back to x.

    Use when The first identity holds on the domain of fff; the second holds on the range of fff, which is the domain of f−1f^{-1}f−1. The inverse is not the reciprocal.

  • Domain and range trade places (Advanced)

    The domain of f−1f^{-1}f−1 is the range of fff, and its range is the domain of fff.

    Use when This applies when an inverse exists: every original output becomes an inverse input, and every original input becomes an inverse output.

    e.g. f(x)=1x−3f(x)=\dfrac1{x-3}f(x)=x−31​ has domain excluding 333 and range excluding 000. Its inverse 1x+3\dfrac1x+3x1​+3 exchanges those two sets.

  • One-to-one, and the horizontal line test (Advanced)

    A function has an inverse function exactly when it is one-to-one, which on a graph means no horizontal line crosses it more than once.

    Use when Apply the horizontal line test to a graph already known to be a function. Restricting the domain may remove repeated outputs.

    e.g. f(x)=x2f(x) = x^2f(x)=x2 fails (333 and −3-3−3 both give 999); on x≥0x \ge 0x≥0 its inverse is x\sqrt{x}x​.

  • Evaluating a defined operation (Advanced)

    Substitute the first input for every aaa and the second for every bbb in the defining rule, then simplify.

    Use when Keep whole expression inputs in parentheses and respect any restrictions in the definition.

    e.g. With a⋆b=2a+b−1a \star b = 2a + b - 1a⋆b=2a+b−1: 3⋆5=2(3)+5−1=103 \star 5 = 2(3) + 5 - 1 = 103⋆5=2(3)+5−1=10.

  • Identity element of an operation (Advanced)

    a⋆e=ae⋆a=a\begin{gathered} a \star e = a \\ e \star a = a \end{gathered}a⋆e=ae⋆a=a​

    Use when The same fixed eee must work in both positions for every allowed input. Some operations have no identity.

    e.g. a⊕b=a+b+aba \oplus b = a + b + aba⊕b=a+b+ab has identity 000; a⋆b=2a+b−1a \star b = 2a + b - 1a⋆b=2a+b−1 has none.

Problem types, step by step

Evaluate a function

  1. Replace every input variable with the whole given input, using parentheses.
  2. Use the ordinary order of operations and record the output.

e.g. f(x)=x2−2f(x)=x^2-2f(x)=x2−2: f(−3)=(−3)2−2=7f(-3)=(-3)^2-2=7f(−3)=(−3)2−2=7. For an expression input, f(x+1)=(x+1)2−2=x2+2x−1f(x+1)=(x+1)^2-2=x^2+2x-1f(x+1)=(x+1)2−2=x2+2x−1, whereas f(x)+1=x2−1f(x)+1=x^2-1f(x)+1=x2−1.

Decide whether a relationship is a function

  1. For a complete list or table, check that no input has two different outputs.
  2. For a graph, check every vertical line: each must meet the graph at most once.
  3. For an equation, two outputs at one input disprove the function claim. To establish it, show each allowed input has exactly one output.

e.g. {(4,1),(4,2),(5,3)}\{(4, 1), (4, 2), (5, 3)\}{(4,1),(4,2),(5,3)} fails: the input 444 has both 111 and 222.

Find a domain and a range

  1. Start with any stated or real-world input restriction.
  2. For the rules in this chapter, exclude denominator zeros and require each square-root radicand to be nonnegative. All restrictions must hold together.
  3. For the range, rule out impossible outputs and show every claimed output can be reached.

e.g. f(x)=1x−3f(x)=\dfrac1{x-3}f(x)=x−31​ excludes input 333. For g(x)=x2+1g(x)=x^2+1g(x)=x2+1, every output is at least 111, and any y≥1y\ge1y≥1 is reached by x=y−1x=\sqrt{y-1}x=y−1​.

Combine two functions by arithmetic (Advanced)

  1. Use inputs accepted by both functions. Substitute the rules and simplify; put the subtracted rule in parentheses.
  2. For a quotient, also exclude every input with g(x)=0g(x)=0g(x)=0, even if a factor cancels.

e.g. f(x)=3xf(x) = 3xf(x)=3x, g(x)=x+2g(x) = x + 2g(x)=x+2: (f−g)(x)=3x−(x+2)=2x−2(f - g)(x) = 3x - (x + 2) = 2x - 2(f−g)(x)=3x−(x+2)=2x−2.

Compose two functions (Advanced)

  1. Identify the inner function. At a number, evaluate it first and pass its output to the outer function.
  2. For a formula, substitute the whole inner expression at every input position of the outer rule.
  3. Simplify without dropping domain restrictions or a squared binomial’s middle term.

e.g. f(x)=x2f(x) = x^2f(x)=x2, g(x)=x−1g(x) = x - 1g(x)=x−1: f(g(4))=f(3)=9f(g(4)) = f(3) = 9f(g(4))=f(3)=9.

Find the domain of a composition (Advanced)

  1. Require the input to be in the inner function’s domain.
  2. Require the inner output to satisfy the outer function’s input restrictions. This may give an equation or an inequality.
  3. Report exactly the inputs passing both checks, even if the final formula looks simpler.

e.g. f(x)=1xf(x) = \dfrac{1}{x}f(x)=x1​, g(x)=x−7g(x) = x - 7g(x)=x−7: g(7)=0g(7) = 0g(7)=0, so exclude 777.

Model a two-step process as a composition (Advanced)

  1. Identify what each step takes in and produces, including units.
  2. Put the first step inside the second: its output must be a suitable input for that second rule.
  3. Substitute, simplify and evaluate at the requested input.

e.g. A discount d(p)=0.8pd(p) = 0.8pd(p)=0.8p then a 555 fee s(x)=x+5s(x) = x + 5s(x)=x+5: s(d(40))=0.8(40)+5=37s(d(40)) = 0.8(40) + 5 = 37s(d(40))=0.8(40)+5=37.

Find the inverse of a function (Advanced)

  1. Check that fff is one-to-one on its stated domain. Write y=f(x)y=f(x)y=f(x) and carry that domain restriction with it.
  2. Swap xxx and yyy; the original input restriction becomes a condition on yyy.
  3. Solve for yyy. When a squared equation gives two choices, keep the choice allowed by that condition.
  4. Name the result f−1(x)f^{-1}(x)f−1(x), state its domain, and check both compositions.

e.g. f(x)=5x−2f(x) = 5x - 2f(x)=5x−2: from x=5y−2x = 5y - 2x=5y−2, f−1(x)=x+25f^{-1}(x) = \dfrac{x + 2}{5}f−1(x)=5x+2​.

Verify that two functions are inverses (Advanced)

  1. Build and simplify f(g(x))f(g(x))f(g(x)) and g(f(x))g(f(x))g(f(x)).
  2. The first must equal xxx for every input of ggg, and the second for every input of fff.
  3. A failure in either direction rules out the proposed inverse pair.

Test a defined operation for commutativity or associativity (Advanced)

  1. For commutativity, compare both orders. One unequal pair disproves it; a matching pair alone is not a proof.
  2. To prove commutativity, show the two general expressions agree for every allowed pair.
  3. For associativity, compare both groupings from the inside out. One unequal triple disproves it; a proof must cover every allowed triple.

e.g. a⋄b=a2−ba \diamond b = a^2 - ba⋄b=a2−b: 3⋄1=83 \diamond 1 = 83⋄1=8 but 1⋄3=−21 \diamond 3 = -21⋄3=−2.

Find an identity element, or show there is none (Advanced)

  1. Write a⋆e=aa\star e=aa⋆e=a using the rule and find every candidate that could work for all aaa.
  2. A requirement such as e=1−ae=1-ae=1−a cannot hold for one fixed eee at every input.
  3. Check each surviving candidate in both positions for every allowed input.

Solve an equation containing a defined operation (Advanced)

  1. Replace the symbol with its defining rule, putting the unknown in its stated slot.
  2. Solve the resulting equation, keeping every allowed solution.
  3. Check each candidate in the original operation.

e.g. x⋄3=22x \diamond 3 = 22x⋄3=22 with a⋄b=a2−ba \diamond b = a^2 - ba⋄b=a2−b: x2=25x^2 = 25x2=25, so x=5x = 5x=5 or x=−5x = -5x=−5.

Exam traps

  • Trap Reading f−1f^{-1}f−1 as a reciprocal: for f(x)=x+3f(x) = x + 3f(x)=x+3, calling f−1(5)f^{-1}(5)f−1(5) the value 1f(5)=18\dfrac{1}{f(5)} = \dfrac{1}{8}f(5)1​=81​. (Advanced)

    Fix Read f−1f^{-1}f−1 as the undoing function. Here f−1(x)=x−3f^{-1}(x)=x-3f−1(x)=x−3, so f−1(5)=2f^{-1}(5)=2f−1(5)=2: input 222 produces output 555.

  • Trap Reading f(3)f(3)f(3) as "fff times 333": for f(x)=2x+1f(x) = 2x + 1f(x)=2x+1, writing f(3)=3(2x+1)=6x+3f(3) = 3(2x + 1) = 6x + 3f(3)=3(2x+1)=6x+3.

    Fix The parentheses select an input. Substitute: f(3)=2(3)+1=7f(3)=2(3)+1=7f(3)=2(3)+1=7.

  • Trap Substituting only the variable: for f(x)=x2f(x) = x^2f(x)=x2 and g(x)=x+4g(x) = x + 4g(x)=x+4, writing f(g(x))=x2+4f(g(x)) = x^2 + 4f(g(x))=x2+4. (Advanced)

    Fix The entire inner rule goes in: f(g(x))=(x+4)2=x2+8x+16f(g(x)) = (x + 4)^2 = x^2 + 8x + 16f(g(x))=(x+4)2=x2+8x+16. The answer x2+4x^2 + 4x2+4 is really g(f(x))g(f(x))g(f(x)), the other order.

  • Trap Answering "which input gives an output of 777?" by computing f(7)f(7)f(7).

    Fix f(7)f(7)f(7) uses input 777. To find the input giving output 777, solve f(x)=7f(x)=7f(x)=7. With f(x)=2x+1f(x)=2x+1f(x)=2x+1, the answer is x=3x=3x=3, whereas f(7)=15f(7)=15f(7)=15.

  • Trap Rejecting {(1,5),(2,5),(3,5)}\{(1,5),(2,5),(3,5)\}{(1,5),(2,5),(3,5)} because the output repeats, or rejecting f(x)=x2f(x)=x^2f(x)=x2 for the same reason.

    Fix Shared outputs are allowed. A function forbids one input with two outputs. On a graph, use vertical lines to test that condition.

  • Trap Reading the domain of f∘gf \circ gf∘g off the simplified formula: with f(x)=x2f(x) = x^2f(x)=x2 and g(x)=xg(x) = \sqrt{x}g(x)=x​, (x)2=x\left(\sqrt{x}\right)^2 = x(x​)2=x looks defined everywhere. (Advanced)

    Fix The inner function must accept the input first. Since ggg rejects every negative, the domain is x≥0x \ge 0x≥0, though the simplified rule shows no trace of the root.

  • Trap Declaring two functions inverses after checking one direction only. (Advanced)

    Fix Let f(x)=x2f(x)=x^2f(x)=x2 on all real numbers and g(x)=xg(x)=\sqrt{x}g(x)=x​. Then f(g(x))=xf(g(x))=xf(g(x))=x for x≥0x\ge0x≥0, but g(f(−3))=3≠−3g(f(-3))=3\ne-3g(f(−3))=3=−3. The other direction fails.

  • Trap Letting the invented symbol override the order of operations: reading 3⋆53 \star 53⋆5 with a⋆b=2a+b−1a \star b = 2a + b - 1a⋆b=2a+b−1 as 2(3+5)−1=152(3 + 5) - 1 = 152(3+5)−1=15. (Advanced)

    Fix Substitution changes nothing about how the expression is read. Only aaa is doubled: 2(3)+5−1=102(3) + 5 - 1 = 102(3)+5−1=10.

  • Trap Substituting only part of an expression input: with a⋄b=a2−ba \diamond b = a^2 - ba⋄b=a2−b, writing (k+1)⋄4=k2+1−4=k2−3(k + 1) \diamond 4 = k^2 + 1 - 4 = k^2 - 3(k+1)⋄4=k2+1−4=k2−3. (Advanced)

    Fix The whole expression drops into the slot as one block: (k+1)2−4=k2+2k−3(k + 1)^2 - 4 = k^2 + 2k - 3(k+1)2−4=k2+2k−3. The middle term 2k2k2k is exactly what dropping the parentheses loses.
