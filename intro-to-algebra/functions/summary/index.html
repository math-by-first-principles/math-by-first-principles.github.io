Functions: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Function
A rule that assigns to each input exactly one output, so one input can never yield two different results.
Function notation f(x)f(x)f(x)
fff names the rule, xxx records the input, and the whole symbol is the output: f(3)=7f(3) = 7f(3)=7 says the input 333 gave the output 777.
Domain
The set of inputs a function is allowed to take.
Range
The set of outputs it actually produces: what comes out, where the domain is what may go in.
Composition f∘gf \circ gf∘g
Feeding one function's output straight into another, read "fff after ggg". The ring is neither multiplication nor the letter o.
Inner and outer function
In f(g(x))f(g(x))f(g(x)), ggg is inner and runs first on the raw input; fff is outer and runs last, so it decides what kind of answer comes out.
Inverse function f−1f^{-1}f−1
The function that reverses fff, sending each output back to the input it came from. It swaps every pair: (5,8)(5, 8)(5,8) becomes (8,5)(8, 5)(8,5).
One-to-one function
A function whose different inputs always give different outputs, so no two inputs share an output.
Binary operation
A rule taking two inputs to one output: ordinary +++, or an invented symbol such as ⋆\star⋆, ⋄\diamond⋄, or ⊕\oplus⊕ given a defining formula. The pair of inputs together counts as the one input a function receives.
Commutative operation
One with a⋆b=b⋆aa \star b = b \star aa⋆b=b⋆a for every aaa and bbb, so the two inputs may trade places freely.
Associative operation
One where the grouping never matters: (a⋆b)⋆c=a⋆(b⋆c)(a \star b) \star c = a \star (b \star c)(a⋆b)⋆c=a⋆(b⋆c) always.

Formulas and theorems

  • Vertical line test

    A graph represents a function exactly when no vertical line crosses it more than once.

    Text description

    The curve x equals y squared, with a dashed vertical line at x equals 4 crossing it twice, at the outputs 2 and negative 2.

    Use when Input on the horizontal axis. A line that misses the graph is fine, since an input outside the domain has no point above it.

    e.g. x=y2x = y^2x=y2 fails: at x=4x = 4x=4 both 222 and −2-2−2 appear.

  • Arithmetic combinations of two functions

    (f+g)(x)=f(x)+g(x)(f−g)(x)=f(x)−g(x)(fg)(x)=f(x)⋅g(x)(fg)(x)=f(x)g(x)\begin{gathered} (f + g)(x) = f(x) + g(x) \\ (f - g)(x) = f(x) - g(x) \\ (fg)(x) = f(x) \cdot g(x) \\ \left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)} \end{gathered}(f+g)(x)=f(x)+g(x)(f−g)(x)=f(x)−g(x)(fg)(x)=f(x)⋅g(x)(gf​)(x)=g(x)f(x)​​

    Use when Defined wherever both fff and ggg are. The quotient also needs g(x)≠0g(x) \neq 0g(x)=0, even where fff is happy.

  • Composition

    (f∘g)(x)=f(g(x))(f \circ g)(x) = f(g(x))(f∘g)(x)=f(g(x))
    Text description

    A chain: x enters the inner function g first, and the output g of x then enters the outer function f, giving f of g of x.

    Use when The inner function ggg runs first on the raw input; fff runs second on its output, so f∘gf \circ gf∘g is read right to left, not left to right.

    e.g. f(x)=x2f(x) = x^2f(x)=x2, g(x)=x+4g(x) = x + 4g(x)=x+4: (f∘g)(x)=(x+4)2=x2+8x+16(f \circ g)(x) = (x + 4)^2 = x^2 + 8x + 16(f∘g)(x)=(x+4)2=x2+8x+16.

  • Composition is not commutative

    In general f∘gf \circ gf∘g and g∘fg \circ fg∘f are different functions.

    Use when "In general" is exact: particular pairs can agree, as a function and its inverse do. Never assume the swap is free.

    e.g. f(x)=x2f(x) = x^2f(x)=x2, g(x)=x+4g(x) = x + 4g(x)=x+4: f(g(3))=49f(g(3)) = 49f(g(3))=49 but g(f(3))=13g(f(3)) = 13g(f(3))=13.

  • Domain of a composition

    An input is in the domain of f∘gf \circ gf∘g exactly when it is allowed into ggg AND the output g(x)g(x)g(x) is allowed into fff.

    Use when Both tests, always. The second can bar an input the inner function accepts, so the domain is neither function's by itself.

  • Defining property of an inverse

    f−1(f(x))=xf(f−1(x))=x\begin{gathered} f^{-1}(f(x)) = x \\ f(f^{-1}(x)) = x \end{gathered}f−1(f(x))=xf(f−1(x))=x​
    Text description

    Two ovals: an arrow labelled f carries x across to f of x, and a return arrow labelled f inverse carries it back to x.

    Use when The first holds on the domain of fff, the second on the domain of f−1f^{-1}f−1. The raised −1-1−1 names the inverse under composition, never a reciprocal.

  • Domain and range trade places

    The domain of f−1f^{-1}f−1 is the range of fff, and its range is the domain of fff.

    Use when Whenever f−1f^{-1}f−1 exists. It follows from swapping every pair, so the forbidden inputs swap as well.

    e.g. f(x)=1x−3f(x) = \dfrac{1}{x - 3}f(x)=x−31​ bans 333; f−1(x)=1x+3f^{-1}(x) = \dfrac{1}{x} + 3f−1(x)=x1​+3 bans 000.

  • One-to-one, and the horizontal line test

    A function has an inverse function exactly when it is one-to-one, which on a graph means no horizontal line crosses it more than once.

    Use when A rule that fails can often be repaired by shrinking the domain to a one-to-one piece, and that restriction travels with the inverse.

    e.g. f(x)=x2f(x) = x^2f(x)=x2 fails (333 and −3-3−3 both give 999); on x≥0x \ge 0x≥0 its inverse is x\sqrt{x}x​.

  • Evaluating a defined operation

    Substitute the first input for every aaa and the second for every bbb in the defining rule, then simplify.

    Use when The symbol carries no meaning of its own; only the rule does.

    e.g. With a⋆b=2a+b−1a \star b = 2a + b - 1a⋆b=2a+b−1: 3⋆5=2(3)+5−1=103 \star 5 = 2(3) + 5 - 1 = 103⋆5=2(3)+5−1=10.

  • Identity element of an operation

    a⋆e=ae⋆a=a\begin{gathered} a \star e = a \\ e \star a = a \end{gathered}a⋆e=ae⋆a=a​

    Use when One fixed number eee must satisfy both, for EVERY aaa. Both sides, since the operation need not be commutative; some operations have no identity.

    e.g. a⊕b=a+b+aba \oplus b = a + b + aba⊕b=a+b+ab has identity 000; a⋆b=2a+b−1a \star b = 2a + b - 1a⋆b=2a+b−1 has none.

Problem types, step by step

Evaluate a function

  1. Replace every xxx in the rule with the given input, wrapped in parentheses so signs survive.
  2. Simplify, squaring and multiplying before adding, and record the pair as f(input)=outputf(\text{input}) = \text{output}f(input)=output.

e.g. f(x)=x2−2f(x) = x^2 - 2f(x)=x2−2: f(−3)=(−3)2−2=7f(-3) = (-3)^2 - 2 = 7f(−3)=(−3)2−2=7.

Decide whether a relationship is a function

  1. From pairs or a table, look for one input listed twice with different outputs.
  2. From a graph, apply the vertical line test.
  3. From an equation, pick an input, solve for the output, and see whether two values come back.

e.g. {(4,1),(4,2),(5,3)}\{(4, 1), (4, 2), (5, 3)\}{(4,1),(4,2),(5,3)} fails: the input 444 has both 111 and 222.

Find a domain and a range

  1. Start from any domain the rule or the situation states outright, such as a restriction written with the function or a real-world quantity that cannot go negative.
  2. Then set every denominator equal to zero and exclude the inputs you find, and require anything under a square root to be ≥0\ge 0≥0; otherwise the domain is all real numbers.
  3. For the range, ask what the rule can actually reach: a square is never negative.

e.g. f(x)=1x−3f(x) = \dfrac{1}{x - 3}f(x)=x−31​ has domain all real numbers except 333; g(x)=x2+1g(x) = x^2 + 1g(x)=x2+1 has range all real numbers ≥1\ge 1≥1.

Combine two functions by arithmetic

  1. Substitute both rules and simplify, bracketing the second rule before a subtraction.
  2. For a quotient, solve g(x)=0g(x) = 0g(x)=0 and exclude every solution.

e.g. f(x)=3xf(x) = 3xf(x)=3x, g(x)=x+2g(x) = x + 2g(x)=x+2: (f−g)(x)=3x−(x+2)=2x−2(f - g)(x) = 3x - (x + 2) = 2x - 2(f−g)(x)=3x−(x+2)=2x−2.

Compose two functions

  1. Read the nesting: the inner function is the one whose parentheses hold the input.
  2. At a number, evaluate the inner function first, then run the outer on that output.
  3. For a formula, drop the ENTIRE inner rule into the outer wherever it expects its input.
  4. Expand and simplify, keeping the middle term of any squared binomial.

e.g. f(x)=x2f(x) = x^2f(x)=x2, g(x)=x−1g(x) = x - 1g(x)=x−1: f(g(4))=f(3)=9f(g(4)) = f(3) = 9f(g(4))=f(3)=9.

Find the domain of a composition

  1. Exclude every input the inner function rejects.
  2. Set the inner rule equal to each value the outer function rejects, and exclude those solutions too.
  3. Report what survived both, not what the simplified formula seems to allow.

e.g. f(x)=1xf(x) = \dfrac{1}{x}f(x)=x1​, g(x)=x−7g(x) = x - 7g(x)=x−7: g(7)=0g(7) = 0g(7)=0, so exclude 777.

Model a two-step process as a composition

  1. Name each step as its own function and decide which acts on the raw input first.
  2. Write the model with the second step on the outside, so the first step sits inside its parentheses.
  3. Substitute, simplify, and evaluate at the value asked for.

e.g. A discount d(p)=0.8pd(p) = 0.8pd(p)=0.8p then a 555 fee s(x)=x+5s(x) = x + 5s(x)=x+5: s(d(40))=0.8(40)+5=37s(d(40)) = 0.8(40) + 5 = 37s(d(40))=0.8(40)+5=37.

Find the inverse of a function

  1. Write y=f(x)y = f(x)y=f(x).
  2. Swap xxx and yyy; a domain restriction described the input, so it moves to yyy.
  3. Solve for yyy, using that restriction where a square root offers two values.
  4. Rename it f−1(x)f^{-1}(x)f−1(x) and confirm both compositions collapse to xxx.

e.g. f(x)=5x−2f(x) = 5x - 2f(x)=5x−2: from x=5y−2x = 5y - 2x=5y−2, f−1(x)=x+25f^{-1}(x) = \dfrac{x + 2}{5}f−1(x)=5x+2​.

Verify that two functions are inverses

  1. Build f(g(x))f(g(x))f(g(x)) by substituting the whole rule for ggg into fff, and simplify.
  2. Build g(f(x))g(f(x))g(f(x)) the same way.
  3. Both must reduce to xxx; if either does not, the pair are not inverses.

Test a defined operation for commutativity or associativity

  1. For commutativity, compute a⋆ba \star ba⋆b and b⋆ab \star ab⋆a on one concrete pair; different values settle it, one counterexample being enough.
  2. Equal values settle nothing, so argue from the rule: one that treats its two slots identically is commutative always.
  3. For associativity, compare (a⋆b)⋆c(a \star b) \star c(a⋆b)⋆c with a⋆(b⋆c)a \star (b \star c)a⋆(b⋆c), each worked from the inside out; one unequal triple disproves it, while equal values again settle nothing.

e.g. a⋄b=a2−ba \diamond b = a^2 - ba⋄b=a2−b: 3⋄1=83 \diamond 1 = 83⋄1=8 but 1⋄3=−21 \diamond 3 = -21⋄3=−2.

Find an identity element, or show there is none

  1. Write a⋆e=aa \star e = aa⋆e=a with the defining rule substituted in, and solve for eee.
  2. If the value of eee depends on aaa, no single number works and the operation has no identity.
  3. If eee is one fixed number, confirm e⋆a=ae \star a = ae⋆a=a as well before claiming it.

Solve an equation containing a defined operation

  1. Substitute the definition, placing the unknown in whichever slot it occupies.
  2. Solve the ordinary equation that remains, keeping both roots when a square gave two.
  3. Check by running the original operation on your answer.

e.g. x⋄3=22x \diamond 3 = 22x⋄3=22 with a⋄b=a2−ba \diamond b = a^2 - ba⋄b=a2−b: x2=25x^2 = 25x2=25, so x=5x = 5x=5 or x=−5x = -5x=−5.

Exam traps

  • Trap Reading f−1f^{-1}f−1 as a reciprocal: for f(x)=x+3f(x) = x + 3f(x)=x+3, calling f−1(5)f^{-1}(5)f−1(5) the value 1f(5)=18\dfrac{1}{f(5)} = \dfrac{1}{8}f(5)1​=81​.

    Fix The raised −1-1−1 names the inverse under composition, never 1f\dfrac{1}{f}f1​. Here f−1(x)=x−3f^{-1}(x) = x - 3f−1(x)=x−3, so f−1(5)=2f^{-1}(5) = 2f−1(5)=2, the input that fff sends to 555.

  • Trap Reading f(3)f(3)f(3) as "fff times 333": for f(x)=2x+1f(x) = 2x + 1f(x)=2x+1, writing f(3)=3(2x+1)=6x+3f(3) = 3(2x + 1) = 6x + 3f(3)=3(2x+1)=6x+3.

    Fix The parentheses are an instruction to apply the rule, not a multiplication sign. Substitute instead: f(3)=2(3)+1=7f(3) = 2(3) + 1 = 7f(3)=2(3)+1=7.

  • Trap Substituting only the variable: for f(x)=x2f(x) = x^2f(x)=x2 and g(x)=x+4g(x) = x + 4g(x)=x+4, writing f(g(x))=x2+4f(g(x)) = x^2 + 4f(g(x))=x2+4.

    Fix The entire inner rule goes in: f(g(x))=(x+4)2=x2+8x+16f(g(x)) = (x + 4)^2 = x^2 + 8x + 16f(g(x))=(x+4)2=x2+8x+16. The answer x2+4x^2 + 4x2+4 is really g(f(x))g(f(x))g(f(x)), the other order.

  • Trap Answering "which input gives an output of 777?" by computing f(7)f(7)f(7).

    Fix f(7)f(7)f(7) evaluates AT the input 777; finding the input that yields 777 means solving f(x)=7f(x) = 7f(x)=7. For f(x)=2x+1f(x) = 2x + 1f(x)=2x+1 that is x=3x = 3x=3, not f(7)=15f(7) = 15f(7)=15.

  • Trap Calling {(1,5),(2,5),(3,5)}\{(1, 5), (2, 5), (3, 5)\}{(1,5),(2,5),(3,5)} not a function because the output 555 repeats, or rejecting f(x)=x2f(x) = x^2f(x)=x2 because a horizontal line meets its graph twice.

    Fix Repeated outputs are legal; only one input with two outputs is banned. Vertical crossings decide whether a graph is a function, horizontal crossings only whether it is one-to-one.

  • Trap Reading the domain of f∘gf \circ gf∘g off the simplified formula: with f(x)=x2f(x) = x^2f(x)=x2 and g(x)=xg(x) = \sqrt{x}g(x)=x​, (x)2=x\left(\sqrt{x}\right)^2 = x(x​)2=x looks defined everywhere.

    Fix The inner function must accept the input first. Since ggg rejects every negative, the domain is x≥0x \ge 0x≥0, though the simplified rule shows no trace of the root.

  • Trap Declaring two functions inverses after checking one direction only.

    Fix One direction can hold while the other fails. For f(x)=x2f(x) = x^2f(x)=x2 on all real numbers and g(x)=xg(x) = \sqrt{x}g(x)=x​: f(g(x))=xf(g(x)) = xf(g(x))=x, but g(f(−3))=9=3g(f(-3)) = \sqrt{9} = 3g(f(−3))=9​=3, not −3-3−3.

  • Trap Letting the invented symbol override the order of operations: reading 3⋆53 \star 53⋆5 with a⋆b=2a+b−1a \star b = 2a + b - 1a⋆b=2a+b−1 as 2(3+5)−1=152(3 + 5) - 1 = 152(3+5)−1=15.

    Fix Substitution changes nothing about how the expression is read. Only aaa is doubled: 2(3)+5−1=102(3) + 5 - 1 = 102(3)+5−1=10.

  • Trap Substituting only part of an expression input: with a⋄b=a2−ba \diamond b = a^2 - ba⋄b=a2−b, writing (k+1)⋄4=k2+1−4=k2−3(k + 1) \diamond 4 = k^2 + 1 - 4 = k^2 - 3(k+1)⋄4=k2+1−4=k2−3.

    Fix The whole expression drops into the slot as one block: (k+1)2−4=k2+2k−3(k + 1)^2 - 4 = k^2 + 2k - 3(k+1)2−4=k2+2k−3. The middle term 2k2k2k is exactly what dropping the parentheses loses.
