    Part C

    Worked solution

    Part A

    3†4=3+2(4)=3+8=11.3 \dagger 4 = 3 + 2(4) = 3 + 8 = 11.3†4=3+2(4)=3+8=11.

    4†3=4+2(3)=4+6=10.4 \dagger 3 = 4 + 2(3) = 4 + 6 = 10.4†3=4+2(3)=4+6=10.

    Part B

    Write the condition using the definition.

    a†e=a+2e=a.a \dagger e = a + 2e = a.a†e=a+2e=a.

    Subtract aaa from both sides. The aaa's cancel completely, which is exactly what has to happen for a single value of eee to work no matter which number aaa is.

    2e=0⟹e=0.2e = 0 \quad\Longrightarrow\quad e = 0.2e=0⟹e=0.

    Since aaa dropped out on its own, e=0e = 0e=0 is forced, and it is the only value that could possibly work as a right input.

    Part C

    Substitute the value of eee found in part B into the OTHER order.

    e†a=e+2a.e \dagger a = e + 2a.e†a=e+2a.

    With e=0e = 0e=0 this becomes

    0†a=0+2a=2a.0 \dagger a = 0 + 2a = 2a.0†a=0+2a=2a.

    For this to equal aaa no matter which number aaa is, we would need 2a=a2a = a2a=a for every choice of aaa, which simplifies to a=0a = 0a=0. That is true only at the single number a=0a = 0a=0, not for every aaa: for example 0†5=100 \dagger 5 = 100†5=10, not 555. So e=0e = 0e=0 fails this second condition in general, even though it satisfied the first one.

    Part D

    An identity element has to satisfy BOTH a†e=aa \dagger e = aa†e=a and e†a=ae \dagger a = ae†a=a, for every choice of aaa, using the SAME value of eee in both. Part B shows that the first condition, by itself, already pins eee down uniquely:

    a†e=a ⟹ e=0,a \dagger e = a \ \Longrightarrow\ e = 0,a†e=a ⟹ e=0,

    so there is no freedom left to choose a different value there. Part C then tests that forced value against the second condition and finds that it only works at the single number a=0a = 0a=0, not for every aaa.

    Since the first condition allows no candidate for eee other than 000, and e=0e = 0e=0 fails the second condition for every aaa except one, there is no value of eee left to try. The operation †\dagger† has no identity element. The star operation in the lesson reached the same verdict by a different route: there the one-sided condition had no fixed solution at all, since it forced a value that still depended on aaa, while here it has exactly one candidate and that candidate fails the other side.

    In one line

    Solving a†e=aa \dagger e = aa†e=a forces e=0e = 0e=0, but that same value fails e†a=ae \dagger a = ae†a=a for every aaa except a=0a = 0a=0, so no single value satisfies both identity conditions for every choice of aaa: the operation †\dagger† has no identity element.
