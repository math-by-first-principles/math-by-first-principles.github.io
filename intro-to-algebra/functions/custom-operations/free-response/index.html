  1. Problem 1 Two signed inputs

    Define a⊘b=(a−b)/(a+b)a\oslash b=(a-b)/(a+b)a⊘b=(a−b)/(a+b) when a+b≠0a+b\ne0a+b=0. Find (−3)⊘1(-3)\oslash1(−3)⊘1.

    1. Hint 1

      The two input slots keep their order in both parts of the fraction.

    2. Hint 2

      Compute the numerator and denominator separately before dividing.

    Answer

    222.

    Full solution

    The denominator is −3+1=−2-3+1=-2−3+1=−2, so the operation is defined.

    Substitution gives

    (−3)⊘1=−3−1−3+1.(-3)\oslash1=\frac{-3-1}{-3+1}.(−3)⊘1=−3+1−3−1​.

    The numerator is −4-4−4, and dividing by −2-2−2 gives 222.

    Multiplying 222 by the denominator −2-2−2 returns the numerator −4-4−4.

    Answer

    222.

    Key idea

    A defined operation may have restrictions on the pair of inputs as well as a rule for its output.

  2. Problem 2 Two expression slots

    For all real inputs, define a⊞b=(a+b)2−aba\boxplus b=(a+b)^2-aba⊞b=(a+b)2−ab. Write (t+1)⊞(t−1)(t+1)\boxplus(t-1)(t+1)⊞(t−1) as an expanded polynomial.

    1. Hint 1

    2. Hint 2

    Full solution

    Therefore the operation gives

    (2t)2−(t2−1).(2t)^2-(t^2-1).(2t)2−(t2−1).

    Expanding and collecting gives

    3t2+1.3t^2+1.3t2+1.

    At t=0t=0t=0, the inputs are 111 and −1-1−1, producing 111, as the polynomial also does.

    Answer

    3t2+13t^2+13t2+1.

    Key idea

    Both slots can contain whole expressions, and each must stay intact during substitution.

  3. Problem 3 Related input expressions

    For all real inputs, define a⊝b=a2−aba\circleddash b=a^2-aba⊝b=a2−ab. Find every real xxx satisfying (x+1)⊝(x−1)=8(x+1)\circleddash(x-1)=8(x+1)⊝(x−1)=8.

    1. Hint 1

      Replace the custom symbol with its rule before solving.

    2. Hint 2

      Both terms share the full first input as a factor, which can simplify the equation.

    Answer

    x=3x=3x=3.

    Full solution

    Substitution gives

    (x+1)2−(x+1)(x−1)=8.(x+1)^2-(x+1)(x-1)=8.(x+1)2−(x+1)(x−1)=8.

    Factor the shared expression without dividing by it:

    (x+1)((x+1)−(x−1))=8.(x+1)((x+1)-(x-1))=8.(x+1)((x+1)−(x−1))=8.

    Thus 2(x+1)=82(x+1)=82(x+1)=8, which gives x=3x=3x=3.

    Check with inputs 444 and 222.

    42−4(2)=8.4^2-4(2)=8.42−4(2)=8.

    The simplification was valid for every real xxx, so no other solutions were lost.

    Answer

    x=3x=3x=3.

    Key idea

    Replacing a custom symbol can reveal cancellation that turns an apparent quadratic into a linear equation.

  4. Problem 4 An unknown inside the inner pair

    Define a⊠b=a2+b2a\boxtimes b=a^2+b^2a⊠b=a2+b2 for real inputs. Find every real xxx with (x⊠1)⊠2=29(x\boxtimes1)\boxtimes2=29(x⊠1)⊠2=29.

    1. Hint 1

      The inner pair must become a single expression before the outer rule can be applied.

    2. Hint 2

      After substituting, a square of an expression equals a number, so ask which values that expression is allowed to take before solving for xxx.

    Answer

    x=2x=2x=2 or x=−2x=-2x=−2.

    Full solution

    The inner pair gives x⊠1=x2+1x\boxtimes1=x^2+1x⊠1=x2+1, and that expression fills the first outer slot, so the equation becomes

    (x2+1)2+22=29.(x^2+1)^2+2^2=29.(x2+1)2+22=29.

    Subtracting 444 from both sides leaves

    (x2+1)2=25.(x^2+1)^2=25.(x2+1)2=25.

    A square equal to 252525 leaves two branches, x2+1=5x^2+1=5x2+1=5 and x2+1=−5x^2+1=-5x2+1=−5.

    The second is impossible, since x2+1x^2+1x2+1 is at least 111 for every real xxx.

    The first gives x2=4x^2=4x2=4, so x=2x=2x=2 or x=−2x=-2x=−2.

    Both check: 2⊠1=52\boxtimes1=52⊠1=5 and (−2)⊠1=5(-2)\boxtimes1=5(−2)⊠1=5, and

    5⊠2=29.5\boxtimes2=29.5⊠2=29.

    Answer

    x=2x=2x=2 or x=−2x=-2x=−2.

    Key idea

    A square equal to a positive number opens two branches, so test each one and keep every real solution it allows, negative values included.

  5. Problem 5 A rule from records

    An operation on real numbers has rule a⊡b=ma+nba\boxdot b=ma+nba⊡b=ma+nb. Its records include 1⊡2=81\boxdot2=81⊡2=8 and 2⊡1=72\boxdot1=72⊡1=7. Find mmm and nnn, then find (2⊡3)−(3⊡2)(2\boxdot3)-(3\boxdot2)(2⊡3)−(3⊡2).

    1. Hint 1

      The two records form equations for the two fixed coefficients.

    2. Hint 2

      Solve those equations, then use the recovered rule in both orders.

    Answer

    m=2m=2m=2, n=3n=3n=3; (2⊡3)−(3⊡2)=1(2\boxdot3)-(3\boxdot2)=1(2⊡3)−(3⊡2)=1.

    Full solution

    The records give m+2n=8m+2n=8m+2n=8 and 2m+n=72m+n=72m+n=7.

    Double the first equation and subtract the second to get

    3n=9.3n=9.3n=9.

    Therefore n=3n=3n=3 and m=2m=2m=2.

    The completed rule gives 2⊡3=132\boxdot3=132⊡3=13 and 3⊡2=123\boxdot2=123⊡2=12, so their difference is 111.

    The records check as 2+6=82+6=82+6=8 and 4+3=74+3=74+3=7.

    Answer

    m=2m=2m=2, n=3n=3n=3; (2⊡3)−(3⊡2)=1(2\boxdot3)-(3\boxdot2)=1(2⊡3)−(3⊡2)=1.

    Key idea

    Multiple records can determine how a custom rule weights its two input slots.

  6. Problem 6 Checking a classmate's expansion

    For all real inputs, define a⊛b=a2−3ba\circledast b=a^2-3ba⊛b=a2−3b. Asked for (m−2)⊛5(m-2)\circledast5(m−2)⊛5, Rowan writes m2−22−3(5)m^2-2^2-3(5)m2−22−3(5) and simplifies it to m2−19m^2-19m2−19. Name the first step that is wrong, and give the correct expanded expression.

    1. Hint 1

      The first input here is a whole expression, and the rule squares whatever sits in that slot.

    2. Hint 2

      Substitute m−2m-2m−2 into the squared slot as one block, expand that square, then combine it with the second term.

    Answer

    The first wrong step is replacing (m−2)2(m-2)^2(m−2)2 with m2−22m^2-2^2m2−22. The correct expression is m2−4m−11m^2-4m-11m2−4m−11.

    Full solution

    The rule squares the entire first input, so substituting the two inputs gives

    (m−2)2−3(5).(m-2)^2-3(5).(m−2)2−3(5).

    Rowan's second term is right, since 3(5)3(5)3(5) is 151515.

    His first step is the wrong one: (m−2)2(m-2)^2(m−2)2 is not m2−22m^2-2^2m2−22, because squaring a difference produces the middle term −4m-4m−4m.

    Expanding correctly gives m2−4m+4m^2-4m+4m2−4m+4, so the operation gives

    m2−4m−11.m^2-4m-11.m2−4m−11.

    At m=0m=0m=0 the rule gives −11-11−11, while Rowan's expression gives −19-19−19, so the two disagree.

    Answer

    The first wrong step is replacing (m−2)2(m-2)^2(m−2)2 with m2−22m^2-2^2m2−22. The correct expression is m2−4m−11m^2-4m-11m2−4m−11.

    Key idea

    An expression input enters its slot as one block, so a squared slot is expanded rather than squared piece by piece.

  7. Problem 7 A prescribed identity

    3⊚a=3a33\circledcirc a=\frac{3a}{3}3⊚a=33a​

  8. Problem 8 Order and grouping

    Define a⊼b=∣a−b∣a\barwedge b=|a-b|a⊼b=∣a−b∣ for all real inputs. Kai says this operation is both commutative and associative. Decide each part of his claim, and justify each decision either for every real input or with a specific counterexample.

    1. Hint 1

      Commutativity asks whether the rule is unchanged when the two inputs trade places; associativity asks whether the two groupings of three inputs agree. Decide each on its own evidence.

    2. Hint 2

      Compare ∣a−b∣|a-b|∣a−b∣ with ∣b−a∣|b-a|∣b−a∣ in general, then compute both groupings of the triple 111, 222, and 444.

    Answer

    Commutative: yes. Associative: no; for example (1⊼2)⊼4=3(1\barwedge2)\barwedge4=3(1⊼2)⊼4=3 but 1⊼(2⊼4)=11\barwedge(2\barwedge4)=11⊼(2⊼4)=1.

    Full solution

    Swapping inputs gives

    b−a=−(a−b).b-a=-(a-b).b−a=−(a−b).

    Opposite numbers have the same absolute value, so

    ∣b−a∣=∣a−b∣.|b-a|=|a-b|.∣b−a∣=∣a−b∣.

    This proves commutativity for every pair.

    One triple settles the other half.

    For the left grouping, 1⊼2=11\barwedge2=11⊼2=1, followed by

    1⊼4=3.1\barwedge4=3.1⊼4=3.

    For the right grouping, 2⊼4=22\barwedge4=22⊼4=2, followed by

    1⊼2=1.1\barwedge2=1.1⊼2=1.

    Since 3≠13\ne13=1, associativity fails.

    Answer

    Commutative: yes. Associative: no; for example (1⊼2)⊼4=3(1\barwedge2)\barwedge4=3(1⊼2)⊼4=3 but 1⊼(2⊼4)=11\barwedge(2\barwedge4)=11⊼(2⊼4)=1.

    Key idea

    An operation may ignore input order while still depending on grouping.

  9. Problem 9 A claim about the first input

    Define a†b=a+b−aba\dagger b=a+b-aba†b=a+b−ab for all real inputs. Lila claims at least two values of the first input make the output the same for every possible second input. Decide whether Lila is correct, and name every first input with that property together with the constant output it produces.

    1. Hint 1

      Keep the first input fixed and collect the terms involving the second input.

    2. Hint 2

      Compare the outputs at second inputs zero and one to find a necessary condition, then check it generally.

    Answer

    No; exactly one first input has that property: a=1a=1a=1, with constant output 111.

    Full solution

    The rule can be written

    a†b=a+(1−a)b.a\dagger b=a+(1-a)b.a†b=a+(1−a)b.

    In particular, the outputs at b=0b=0b=0 and b=1b=1b=1 are aaa and 111.

    If all outputs agree, these two must agree, so a=1a=1a=1.

    For this value,

    1†b=1+b−b,1\dagger b=1+b-b,1†b=1+b−b,

    which equals 111 for every real bbb.

    No other first input can work, so exactly one value has the property and Lila is wrong to claim two or more.

    Answer

    No; exactly one first input has that property: a=1a=1a=1, with constant output 111.

    Comparing selected inputs can identify a necessary condition, which must then be checked for all inputs.

  10. Problem 10 Two properties of a root rule

    Define a⊻b=a2+b2a\veebar b=\sqrt{a^2+b^2}a⊻b=a2+b2​ for inputs that are zero or positive. Decide whether this operation has an identity element and whether it is associative, and justify both conclusions for every allowed input.

    1. Hint 1

      The nonnegative input restriction matters when a square and a square root cancel.

    2. Hint 2

      Test the identity condition at the input 000 to narrow the candidates to one, check that candidate in both orders, then compare the expressions the two groupings produce.

    Answer

    Identity: 000. The operation is associative on the stated input set.

    Full solution

    If eee is an identity, using input 000 requires e2=0\sqrt{e^2}=0e2​=0, hence e=0e=0e=0.

    For every allowed aaa, the two orders with zero both give

    a2=a.\sqrt{a^2}=a.a2​=a.

    Thus zero is an identity.

    For allowed aaa, bbb, and ccc, each inner output is nonnegative, so it is itself an allowed input.

    The left grouping gives

    (a⊻b)⊻c=(a2+b2)2+c2,(a\veebar b)\veebar c=\sqrt{(\sqrt{a^2+b^2})^2+c^2},(a⊻b)⊻c=(a2+b2​)2+c2​,

    and the right grouping gives

    a⊻(b⊻c)=a2+(b2+c2)2.a\veebar(b\veebar c)=\sqrt{a^2+(\sqrt{b^2+c^2})^2}.a⊻(b⊻c)=a2+(b2+c2​)2​.

    Each inner radicand is nonnegative, so each square undoes its own root, and both expressions reduce to

    a2+b2+c2.\sqrt{a^2+b^2+c^2}.a2+b2+c2​.

    The two groupings therefore agree for every allowed triple, so the operation is associative.

    Answer

    Identity: 000. The operation is associative on the stated input set.

    Key idea

    A domain restriction can make simplifications valid and support a general identity or associativity proof.
