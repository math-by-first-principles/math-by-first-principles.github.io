Combining and Composing Functions Advanced. This lesson goes beyond core Algebra I. You can skip it.

Intuition

In the previous lesson you learned to name a rule fff, evaluate it at an input, and describe its domain and range. Now that each rule has its own name, a new question opens up: how do you build a fresh function out of the ones you already have? There are two natural ways, and this lesson covers both. The first is plain arithmetic, adding, subtracting, multiplying, or dividing two functions to make a new one. The second is the real workhorse of algebra, running one function and feeding its output straight into a second function. Chaining rules like that is called composition, and it is how a single complicated formula is usually built out of a few simple steps.

Learning goals

  • Add, subtract, multiply and divide two functions, excluding any input where the divisor is zero
  • Compose with (f∘g)(x)=f(g(x))(f \circ g)(x) = f(g(x))(f∘g)(x)=f(g(x)), inner first
  • Substitute the whole inner rule to get a composed formula
  • Show that f∘gf \circ gf∘g usually differs from g∘fg \circ fg∘f
  • Require an input allowed into both functions in turn

Building new functions by arithmetic

Suppose two functions share the same input. Say f(x)=3xf(x) = 3xf(x)=3x gives the distance in metres that one runner has covered after xxx seconds, and g(x)=x+2g(x) = x + 2g(x)=x+2 gives a second runner’s distance, starting from a two-metre head start. At any moment xxx you can ask about the two runners together: their combined distance is f(x)+g(x)f(x) + g(x)f(x)+g(x), and the difference between their positions is f(x)−g(x)f(x) - g(x)f(x)−g(x). Nothing exotic is happening. You evaluate each function at the same input, then combine the two outputs with ordinary arithmetic. That one idea defines four brand-new functions:

(f+g)(x)=f(x)+g(x),(f−g)(x)=f(x)−g(x),(f + g)(x) = f(x) + g(x), \qquad (f - g)(x) = f(x) - g(x),(f+g)(x)=f(x)+g(x),(f−g)(x)=f(x)−g(x), (fg)(x)=f(x)⋅g(x),(fg)(x)=f(x)g(x).(fg)(x) = f(x) \cdot g(x), \qquad \left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)}.(fg)(x)=f(x)⋅g(x),(gf​)(x)=g(x)f(x)​.

Read the left side of each line as the name of a single new function. The symbol f+gf + gf+g is one function whose rule is “evaluate fff, evaluate ggg, and add the results.” To find its output at any input, you do exactly that.

The first three combinations accept every input that both fff and ggg accept, so they need no special care. The quotient is the one that does. You already know that division by zero is undefined, so the fraction f(x)g(x)\dfrac{f(x)}{g(x)}g(x)f(x)​ has no value at any input where the denominator g(x)g(x)g(x) equals zero. Those inputs have to be thrown out, even when fff and ggg are both perfectly happy there. So the quotient fg\dfrac{f}{g}gf​ is defined wherever fff and ggg are both defined and, on top of that, g(x)≠0g(x) \neq 0g(x)=0: it carries the same requirement as the other three combinations, plus one extra ban. This is not a new rule to memorize; it is the old ban on dividing by zero, now applied to the output of ggg.

Worked example 1 Adding, subtracting, multiplying, and dividing two functions

Let f(x)=3xf(x) = 3xf(x)=3x and g(x)=x+2g(x) = x + 2g(x)=x+2, now treated simply as algebra rules that accept any real number xxx, not only the runner story’s elapsed time. Build all four combinations, and find where the quotient is defined.

For the sum, subtraction, and product, substitute the two rules and simplify:

(f+g)(x)=3x+(x+2)=4x+2,(f + g)(x) = 3x + (x + 2) = 4x + 2,(f+g)(x)=3x+(x+2)=4x+2,(f−g)(x)=3x−(x+2)=2x−2,(f - g)(x) = 3x - (x + 2) = 2x - 2,(f−g)(x)=3x−(x+2)=2x−2,(fg)(x)=3x⋅(x+2)=3x2+6x.(fg)(x) = 3x \cdot (x + 2) = 3x^2 + 6x.(fg)(x)=3x⋅(x+2)=3x2+6x.

For the quotient, write the fraction and then find the input that would make the denominator zero:

(fg)(x)=3xx+2,x+2=0  ⟹  x=−2.\left(\frac{f}{g}\right)(x) = \frac{3x}{x + 2}, \qquad x + 2 = 0 \;\Longrightarrow\; x = -2.(gf​)(x)=x+23x​,x+2=0⟹x=−2.

So fg\dfrac{f}{g}gf​ is defined for every input except x=−2x = -2x=−2. You can also evaluate any combination at a number. At x=4x = 4x=4, for instance, f(4)=12f(4) = 12f(4)=12 and g(4)=6g(4) = 6g(4)=6, so (f+g)(4)=18(f + g)(4) = 18(f+g)(4)=18 and (fg)(4)=72(fg)(4) = 72(fg)(4)=72.

Composing: feeding one function into another

Combining with arithmetic keeps the two functions side by side. Composition instead stands them in a line. Picture a small factory with two machines. The first machine takes your raw input and produces a part; the second machine takes that part and finishes it. The output of the first becomes the input of the second.

Make it concrete with g(x)=x+4g(x) = x + 4g(x)=x+4 and f(x)=x2f(x) = x^2f(x)=x2. Start with an input, say 333. Run ggg first: g(3)=3+4=7g(3) = 3 + 4 = 7g(3)=3+4=7. Now take that result, 777, and run it through fff: f(7)=72=49f(7) = 7^2 = 49f(7)=72=49. The end product of the two-step process is 494949. Written on one line, this is f(g(3))f(g(3))f(g(3)): the inner function ggg acts on 333, and fff acts on whatever ggg hands it.

This two-step operation is composition, and it has its own symbol. The composition of fff and ggg is written f∘gf \circ gf∘g (read ”fff composed with ggg,” or ”fff after ggg”), and it is defined by

(f∘g)(x)=f(g(x)).(f \circ g)(x) = f(g(x)).(f∘g)(x)=f(g(x)).

The little ring ∘\circ∘ is not multiplication and not the letter o; it is the composition sign. The right-hand side, f(g(x))f(g(x))f(g(x)), is the form you actually calculate with.

Notice how different this is from the product fgfgfg from the last section. The product runs fff and ggg side by side on the same input and multiplies the two outputs. Composition runs them in a chain: ggg‘s output becomes fff‘s input. For f(x)=x+1f(x) = x + 1f(x)=x+1 and g(x)=2xg(x) = 2xg(x)=2x at x=3x = 3x=3, the product is (fg)(3)=f(3)⋅g(3)=4⋅6=24(fg)(3) = f(3) \cdot g(3) = 4 \cdot 6 = 24(fg)(3)=f(3)⋅g(3)=4⋅6=24, but the composition is (f∘g)(3)=f(g(3))=f(6)=7(f \circ g)(3) = f(g(3)) = f(6) = 7(f∘g)(3)=f(g(3))=f(6)=7. Same two functions, same input, two very different answers.

Which function runs first? The nested notation answers the question on its own. In f(g(x))f(g(x))f(g(x)) the input xxx is wrapped inside ggg, and g(x)g(x)g(x) then sits inside the parentheses of fff. Just as with nested parentheses in arithmetic, you work from the inside out: whatever is deepest gets evaluated first. So ggg runs first on the raw input, and fff runs second on ggg‘s output. The inner function, the one written closest to the input, always goes first, even though in the name f∘gf \circ gf∘g it is written second.

Worked example 2 Composing at a number in both orders

Let f(x)=x2f(x) = x^2f(x)=x2 and g(x)=x+4g(x) = x + 4g(x)=x+4. You already found f(g(3))=49f(g(3)) = 49f(g(3))=49 above by running ggg first and then fff. Now reverse the order and compute g(f(3))g(f(3))g(f(3)): run fff on 333 first, then run ggg on the result.

f(3)=32=9,g(9)=9+4=13.f(3) = 3^2 = 9, \qquad g(9) = 9 + 4 = 13.f(3)=32=9,g(9)=9+4=13.

So g(f(3))=13g(f(3)) = 13g(f(3))=13. Same two functions, same starting number, but 494949 and 131313 are nowhere near each other. The order in which you apply the functions clearly matters, a point the next section makes exact.

Finding a formula for a composition

Evaluating at one input is fine, but usually you want a single formula for f∘gf \circ gf∘g that works at every allowed input at once, that is, every input that survives both steps of the composition. The recipe is the substitution you have used since your first algebra lesson. To build f(g(x))f(g(x))f(g(x)), take the entire rule for g(x)g(x)g(x) and drop that rule into fff wherever fff expects its input.

Worked example 3 Finding a formula for f∘gf \circ gf∘g and g∘fg \circ fg∘f

Let f(x)=x2f(x) = x^2f(x)=x2 and g(x)=x+4g(x) = x + 4g(x)=x+4. Find formulas for (f∘g)(x)(f \circ g)(x)(f∘g)(x) and (g∘f)(x)(g \circ f)(x)(g∘f)(x).

For f∘gf \circ gf∘g, substitute the whole rule g(x)=x+4g(x) = x + 4g(x)=x+4 into fff in place of its input, then expand the square. Recall (a+b)2=a2+2ab+b2(a + b)^2 = a^2 + 2ab + b^2(a+b)2=a2+2ab+b2, so with a=xa = xa=x and b=4b = 4b=4:

(f∘g)(x)=f(g(x))=f(x+4)=(x+4)2=x2+2(4x)+42=x2+8x+16.\begin{aligned} (f \circ g)(x) &= f(g(x)) = f(x + 4) = (x + 4)^2 \\ &= x^2 + 2(4x) + 4^2 = x^2 + 8x + 16. \end{aligned}(f∘g)(x)​=f(g(x))=f(x+4)=(x+4)2=x2+2(4x)+42=x2+8x+16.​

For g∘fg \circ fg∘f, substitute the whole rule f(x)=x2f(x) = x^2f(x)=x2 into ggg in place of its input:

(g∘f)(x)=g(f(x))=g(x2)=x2+4.(g \circ f)(x) = g(f(x)) = g(x^2) = x^2 + 4.(g∘f)(x)=g(f(x))=g(x2)=x2+4.

These two formulas are not the same function, and that matches the previous worked example: plugging x=3x = 3x=3 into x2+8x+16x^2 + 8x + 16x2+8x+16 and into x2+4x^2 + 4x2+4 reproduces the very numbers, 494949 and 131313, found there by running the machines step by step.

Order matters: a composition is not commutative

Look back at the last two worked examples. In both, swapping the order changed the answer: f(g(3))=49f(g(3)) = 49f(g(3))=49 but g(f(3))=13g(f(3)) = 13g(f(3))=13, and the formula f(g(x))=x2+8x+16f(g(x)) = x^2 + 8x + 16f(g(x))=x2+8x+16 against g(f(x))=x2+4g(f(x)) = x^2 + 4g(f(x))=x2+4. This is not a fluke of one example. Composition is not commutative: in general f∘gf \circ gf∘g and g∘fg \circ fg∘f are different functions, and reversing the order usually changes the result. This is the single most important idea in the lesson, so it is worth understanding why it happens rather than just noting that it does.

The reason is exactly the assembly-line picture. In f∘gf \circ gf∘g the last machine to touch the number is fff, so the final answer is always something fff produced. In g∘fg \circ fg∘f the last machine is ggg, so the final answer is always something ggg produced. For these two functions fff and ggg do different jobs, one squares and one shifts, so the two lines hand you different products. Squaring and then adding four is not the same as adding four and then squaring: g(f(x))=x2+4g(f(x)) = x^2 + 4g(f(x))=x2+4 puts the four in at the very end. By contrast, f(g(x))=(x+4)2f(g(x)) = (x + 4)^2f(g(x))=(x+4)2 adds the four first and then squares the whole thing, which spreads the four through the extra middle term 8x8x8x. The four enters at a different stage, and the machine that comes after it treats it differently.

The domain of a composition

Because a composition runs in two steps, an input has to survive both to be allowed through. Here is a case where that catches an input by surprise.

Worked example 4 The domain of a composition

Let f(x)=1xf(x) = \dfrac{1}{x}f(x)=x1​ and g(x)=x−4g(x) = x - 4g(x)=x−4. Find (f∘g)(x)(f \circ g)(x)(f∘g)(x) and its domain.

Substitute ggg into fff to get the formula:

(f∘g)(x)=f(g(x))=f(x−4)=1x−4.(f \circ g)(x) = f(g(x)) = f(x - 4) = \frac{1}{x - 4}.(f∘g)(x)=f(g(x))=f(x−4)=x−41​.

Now watch what happens at x=4x = 4x=4. The inner function is perfectly happy there: g(4)=0g(4) = 0g(4)=0, and ggg never complains about the input 444. But hand that output, 000, to fff, and f(0)=10f(0) = \dfrac{1}{0}f(0)=01​ is undefined. So x=4x = 4x=4 looked completely safe going in, yet it is excluded from the domain of f∘gf \circ gf∘g. A safe input like x=6x = 6x=6 sails through instead: g(6)=2g(6) = 2g(6)=2 and then f(2)=12f(2) = \dfrac{1}{2}f(2)=21​. The domain of f∘gf \circ gf∘g is all numbers except 444.

That is not a coincidence of these two particular functions; the same two-step test decided the outcome for 444 above, and it decides every composition’s domain. Here is that test stated exactly.

Which inputs a composition accepts#

To evaluate (f∘g)(x)=f(g(x))(f \circ g)(x) = f(g(x))(f∘g)(x)=f(g(x)), an input has to survive two questions asked in order.

Can ggg use it? The first step computes g(x)g(x)g(x). If xxx is not in the domain of ggg, then g(x)g(x)g(x) does not exist, so there is nothing to hand to fff. The composite f(g(x))f(g(x))f(g(x)) is undefined before fff even gets a turn.

Can fff use what ggg produces? Even when g(x)g(x)g(x) exists, fff can only act on it if g(x)g(x)g(x) is itself an allowed input of fff, that is, if g(x)g(x)g(x) lies in the domain of fff. If g(x)g(x)g(x) is a value fff rejects, such as a number that would make fff divide by zero, then f(g(x))f(g(x))f(g(x)) is undefined again.

Both questions have to come back yes. An input that fails either one is excluded from the domain of f∘gf \circ gf∘g; an input that passes both is included. That two-part rule is nothing new to memorize, it is just the two-step process read out loud.

Composition models a two-step process

Composition is not just a symbol game. Any time one quantity depends on a second, which in turn depends on a third, you have a composition waiting to be written down. Discounts followed by fees, readings passed through a converter, a shape whose size grows with time: each is one function feeding the next.

Worked example 5 A discount followed by shipping

An online store takes 202020 percent off every item, then adds a flat shipping fee of 555 dollars to the discounted price. Model the final price as a composition, and find it for an item that normally costs 404040 dollars.

Name the two steps. Taking 202020 percent off leaves 808080 percent of the price, so the discount function is d(p)=0.8pd(p) = 0.8pd(p)=0.8p. Adding shipping to a price is s(x)=x+5s(x) = x + 5s(x)=x+5. The store discounts first and then adds shipping to the discounted price, so shipping is the outer function and the final price is s(d(p))s(d(p))s(d(p)):

s(d(p))=s(0.8p)=0.8p+5.s(d(p)) = s(0.8p) = 0.8p + 5.s(d(p))=s(0.8p)=0.8p+5.

For an item with p=40p = 40p=40:

s(d(40))=0.8(40)+5=32+5=37.s(d(40)) = 0.8(40) + 5 = 32 + 5 = 37.s(d(40))=0.8(40)+5=32+5=37.

The final price is 373737 dollars. Order matters here too, exactly as before. Had the store instead added shipping first and then discounted, the result would be d(s(p))=0.8(p+5)=0.8p+4d(s(p)) = 0.8(p + 5) = 0.8p + 4d(s(p))=0.8(p+5)=0.8p+4, which at p=40p = 40p=40 gives 363636 dollars. The two policies are genuinely different, and the composition records which one the store actually uses.

Common mistakes

Common mistakes

  • Composing in the wrong order. In f(g(x))f(g(x))f(g(x)) the inner function ggg runs first, even though fff is written first in f∘gf \circ gf∘g. Work from the inside out, just like nested parentheses.
  • Assuming f∘gf \circ gf∘g equals g∘fg \circ fg∘f. Composition is not commutative. In general f(g(x))≠g(f(x))f(g(x)) \neq g(f(x))f(g(x))=g(f(x)), so you must respect the order the problem gives you.
  • Substituting only part of the inner rule. To build f(g(x))f(g(x))f(g(x)) you drop the entire rule for g(x)g(x)g(x) into fff, not just the variable. For f(x)=x2f(x) = x^2f(x)=x2 and g(x)=x+4g(x) = x + 4g(x)=x+4, that is (x+4)2(x + 4)^2(x+4)2, not x2+4x^2 + 4x2+4.
  • Forgetting to expand a squared binomial. (x+4)2(x + 4)^2(x+4)2 is x2+8x+16x^2 + 8x + 16x2+8x+16, not x2+16x^2 + 16x2+16. The middle term 8x8x8x is part of the square and drops out only if you forget it.
  • Ignoring the quotient’s forbidden inputs. fg\dfrac{f}{g}gf​ is undefined wherever g(x)=0g(x) = 0g(x)=0. Find those inputs and exclude them, even when fff itself is fine there.
  • Checking only the inner function’s domain. An input can be legal for ggg and still be barred from f∘gf \circ gf∘g because g(x)g(x)g(x) is a value fff rejects. Always test both steps.

Key takeaways

  • Two functions with the same input combine by arithmetic: (f+g)(x)=f(x)+g(x)(f + g)(x) = f(x) + g(x)(f+g)(x)=f(x)+g(x), (f−g)(x)=f(x)−g(x)(f - g)(x) = f(x) - g(x)(f−g)(x)=f(x)−g(x), (fg)(x)=f(x)⋅g(x)(fg)(x) = f(x) \cdot g(x)(fg)(x)=f(x)⋅g(x), and (fg)(x)=f(x)g(x)\left(\dfrac{f}{g}\right)(x) = \dfrac{f(x)}{g(x)}(gf​)(x)=g(x)f(x)​.
  • The quotient fg\dfrac{f}{g}gf​ needs xxx accepted by both fff and ggg, the same as the other three combinations, plus one more requirement: g(x)≠0g(x) \neq 0g(x)=0, because dividing by zero is undefined.
  • Composition feeds one output into another: (f∘g)(x)=f(g(x))(f \circ g)(x) = f(g(x))(f∘g)(x)=f(g(x)). The inner function ggg runs first, then the outer function fff runs on its output.
  • To find a formula for f∘gf \circ gf∘g, substitute the whole rule for g(x)g(x)g(x) into fff and simplify.
  • Composition is not commutative: do not swap the order unless you check. In general f∘gf \circ gf∘g and g∘fg \circ fg∘f are different functions, because the outer function is the last one to act, so it has the final say over the output.
  • An input is in the domain of f∘gf \circ gf∘g only when it is allowed into ggg and g(x)g(x)g(x) is allowed into fff.

A bit of history (optional)

Long before Charles Babbage drew up his famous calculating engines, he spent years on a stranger question. What can you do to a function itself?

Ordinary algebra hunts for an unknown number. Babbage wanted an algebra whose unknown was a whole rule. He called the subject the calculus of functions. His first paper on it appeared in 1815, when he was still in his early twenties.

Many of the questions that subject asks only make sense once you are willing to feed a function’s output into a function. That is the move this whole lesson rests on. Composition lets one rule accept another rule’s output as its own input, as long as that output actually lies in its domain, and the parentheses keep the bookkeeping straight.

The engines came later, and they are what his name is remembered for. A machine like that computes by running one step into the next, which is composition in another guise, and a chain has a direction. Feed xxx to ggg first and hand the result to fff, then compare that to running fff first and handing its result to ggg: as in this lesson, the two chains usually land on different answers.
