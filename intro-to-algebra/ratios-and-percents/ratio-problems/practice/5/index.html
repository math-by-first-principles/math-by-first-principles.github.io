    The ratio of Anna's age to Ben's age is 4:34 : 34:3. In 666 years the ratio will be 6:56 : 56:5. How old is Anna now?

    Answer choices for question 1

    Solution

    Correct answer: B

    Write the ages as 4k4k4k and 3k3k3k. In 666 years, (4k+6):(3k+6)(4k + 6) : (3k + 6)(4k+6):(3k+6) equals 6:56 : 56:5, so cross-multiply.

    5(4k+6)=6(3k+6)  ⟹  20k+30=18k+36  ⟹  k=35(4k + 6) = 6(3k + 6) \implies 20k + 30 = 18k + 36 \implies k = 35(4k+6)=6(3k+6)⟹20k+30=18k+36⟹k=3

    Anna is 4k=124k = 124k=12.

    The ratio of sheep to cows is 9:49 : 49:4, and there are 656565 more sheep than cows. How many animals are there in total?

    Answer choices for question 2

    Solution

    Correct answer: A

    Sheep minus cows is 9k−4k=5k9k - 4k = 5k9k−4k=5k, so 5k=655k = 655k=65 and k=13k = 13k=13. The total is all 9+4=139 + 4 = 139+4=13 parts.

    5k=65  ⟹  k=13,13k=1695k = 65 \implies k = 13, \quad 13k = 1695k=65⟹k=13,13k=169

    There are 169169169 animals.

    A recipe has sugar, flour, and cocoa in the ratio 2:5:12 : 5 : 12:5:1. A baker uses 151515 cups of flour. How many cups of the whole mixture result?

    Answer choices for question 3

    Solution

    Correct answer: D

    Flour is the 555 term, so 5k=155k = 155k=15 and k=3k = 3k=3. The whole mixture is all 2+5+1=82 + 5 + 1 = 82+5+1=8 parts.

    5k=15  ⟹  k=3,8k=245k = 15 \implies k = 3, \quad 8k = 245k=15⟹k=3,8k=24

    The recipe makes 242424 cups.

    Combine x:y=5:2x : y = 5 : 2x:y=5:2 and y:z=6:7y : z = 6 : 7y:z=6:7. If z=42z = 42z=42, find xxx.

    Answer choices for question 4

    Solution

    Correct answer: B

    Scale yyy to the least common multiple of 222 and 666, which is 666: 5:2=15:65 : 2 = 15 : 65:2=15:6, so x:y:z=15:6:7x : y : z = 15 : 6 : 7x:y:z=15:6:7. Then z=7k=42z = 7k = 42z=7k=42, so k=6k = 6k=6.

    7k=42  ⟹  k=6,15k=907k = 42 \implies k = 6, \quad 15k = 907k=42⟹k=6,15k=90

    So x=90x = 90x=90.

  5. 5

    A mix has almonds to cashews in the ratio 5:35 : 35:3. Removing 888 almonds makes the two counts equal. How many cashews are in the mix?

    Answer choices for question 5

    Solution

    Correct answer: C

    Write almonds as 5k5k5k and cashews as 3k3k3k. Removing 888 almonds makes them equal, so 5k−8=3k5k - 8 = 3k5k−8=3k.

    5k−8=3k  ⟹  2k=8  ⟹  k=45k - 8 = 3k \implies 2k = 8 \implies k = 45k−8=3k⟹2k=8⟹k=4

    Cashews is 3k=123k = 123k=12.

  6. 6

    A rectangle's length to width is 7:47 : 47:4, and its perimeter is 888888 cm. What is its length, in cm?

    Answer choices for question 6

    Solution

    Correct answer: B

    Write length as 7k7k7k and width as 4k4k4k. The perimeter is 2(7k+4k)=22k=882(7k + 4k) = 22k = 882(7k+4k)=22k=88, so k=4k = 4k=4.

    22k=88  ⟹  k=4,7k=2822k = 88 \implies k = 4, \quad 7k = 2822k=88⟹k=4,7k=28

  7. 7

    Two numbers are in the ratio 5:25 : 25:2. Adding 999 to the smaller makes it equal to the larger. What is the larger number?

    Answer choices for question 7

    Solution

    Correct answer: D

    Write the numbers as 5k5k5k and 2k2k2k. Adding 999 to the smaller matches the larger, so 2k+9=5k2k + 9 = 5k2k+9=5k.

    2k+9=5k  ⟹  3k=9  ⟹  k=32k + 9 = 5k \implies 3k = 9 \implies k = 32k+9=5k⟹3k=9⟹k=3

    The larger number is 5k=155k = 155k=15.

  8. 8

    Two numbers are in the ratio 5:35 : 35:3. Adding 101010 to each makes the ratio 7:57 : 57:5. What is the larger original number?

    Answer choices for question 8

    Solution

    Correct answer: C

    Write the numbers as 5k5k5k and 3k3k3k. After adding 101010 to each, (5k+10):(3k+10)(5k + 10) : (3k + 10)(5k+10):(3k+10) equals 7:57 : 57:5, so cross-multiply.

    5(5k+10)=7(3k+10)  ⟹  25k+50=21k+70  ⟹  k=55(5k + 10) = 7(3k + 10) \implies 25k + 50 = 21k + 70 \implies k = 55(5k+10)=7(3k+10)⟹25k+50=21k+70⟹k=5

    The larger original number is 5k=255k = 255k=25.

    Water is 7k=567k = 567k=56 liters.
