    Solution

    A jar has red to blue marbles in the ratio 4:74 : 74:7. Adding 666 blue marbles makes the ratio 4:94 : 94:9. How many red marbles are there?

    Answer choices for question 2

    Solution

    Correct answer: A

    Write red as 4k4k4k and blue as 7k7k7k. The red count is unchanged, so 4k:(7k+6)4k : (7k + 6)4k:(7k+6) equals 4:94 : 94:9, and cross-multiplying gives the equation in kkk.

    9(4k)=4(7k+6)  ⟹  36k=28k+24  ⟹  k=39(4k) = 4(7k + 6) \implies 36k = 28k + 24 \implies k = 39(4k)=4(7k+6)⟹36k=28k+24⟹k=3

    Red is 4k=124k = 124k=12.

  3. 3

    A sum of 950095009500 dollars is split among PPP, QQQ, RRR with P:Q=3:4P : Q = 3 : 4P:Q=3:4 and Q:R=8:5Q : R = 8 : 5Q:R=8:5. How many dollars does RRR get?

    Answer choices for question 3

    Solution

    Correct answer: D

    Scale QQQ to the least common multiple of 444 and 888, which is 888: 3:4=6:83 : 4 = 6 : 83:4=6:8, so P:Q:R=6:8:5P : Q : R = 6 : 8 : 5P:Q:R=6:8:5. The parts total 191919, so 19k=950019k = 950019k=9500 and k=500k = 500k=500.

    19k=9500  ⟹  k=500,5k=250019k = 9500 \implies k = 500, \quad 5k = 250019k=9500⟹k=500,5k=2500

    So RRR gets 250025002500 dollars.

  4. 4

    Two numbers are in the ratio 9:59 : 59:5. Subtracting 888 from each makes the ratio 7:37 : 37:3. What is the smaller original number?

    Answer choices for question 4

    Solution

    Correct answer: A

    Write the numbers as 9k9k9k and 5k5k5k. After subtracting 888 from each, (9k−8):(5k−8)(9k - 8) : (5k - 8)(9k−8):(5k−8) equals 7:37 : 37:3, so cross-multiply.

    3(9k−8)=7(5k−8)  ⟹  27k−24=35k−56  ⟹  k=43(9k - 8) = 7(5k - 8) \implies 27k - 24 = 35k - 56 \implies k = 43(9k−8)=7(5k−8)⟹27k−24=35k−56⟹k=4

    The smaller original number is 5k=205k = 205k=20.

  5. 5

    The angles of a triangle are in the ratio 4:5:64 : 5 : 64:5:6. What is the smallest angle, in degrees? (The angles add to 180180180.)

    Answer choices for question 5

    Solution

    Correct answer: C

    The parts total 4+5+6=154 + 5 + 6 = 154+5+6=15, so 15k=18015k = 18015k=180 and k=12k = 12k=12. The smallest angle is the 444 term.

    15k=180  ⟹  k=12,4k=4815k = 180 \implies k = 12, \quad 4k = 4815k=180⟹k=12,4k=48

    The smallest angle is 484848 degrees.
