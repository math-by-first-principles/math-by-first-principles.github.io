Special Functions: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Radical function
A function with the variable under a root, as in x\sqrt{x}x​ or x+43\sqrt[3]{x + 4}3x+4​. Its index names the root (222 when unwritten); the radicand sits under it.
Principal square root
x\sqrt{x}x​ names the root that is not negative, so 16=4\sqrt{16} = 416​=4 alone, never ±4\pm 4±4.
Extraneous solution
A candidate satisfying the equation you produced but not the original. Squaring, or clearing a variable denominator, can manufacture one.
Absolute value ∣x∣\lvert x \rvert∣x∣
The distance from xxx to 000 on the number line, so ∣−5∣=∣5∣=5\lvert -5 \rvert = \lvert 5 \rvert = 5∣−5∣=∣5∣=5.
Vertex
The corner of a V graph: lowest point when it opens up, highest when it opens down.
Floor ⌊x⌋\lfloor x \rfloor⌊x⌋ and ceiling ⌈x⌉\lceil x \rceil⌈x⌉
The greatest integer at or below xxx, and the least at or above it: the nearest integer LEFT, and RIGHT. Both are staircases, domain all reals, range the integers.
Step function
A piecewise function with constant pieces, graphing as flat segments. The floor, the ceiling, and tiered shipping are the examples.
Rational function
A ratio of two polynomials, f(x)=p(x)q(x)f(x) = \dfrac{p(x)}{q(x)}f(x)=q(x)p(x)​, with qqq not the zero polynomial.
Asymptote
A straight line the graph approaches ever more closely outward. A guide-line, not part of the graph.
Piecewise function
A function given by two or more formulas, its pieces, each with a condition naming the inputs it governs.
Boundary
An input where one piece's condition ends and the next begins. The inequality signs decide which piece owns it.

Formulas and theorems

  • Domain of a radical

    Even index: solve radicand≥0\text{radicand} \ge 0radicand≥0. Odd index: every real is allowed. A root is a fractional power: xn=x1/n\sqrt[n]{x} = x^{1/n}nx​=x1/n.

    Use when Even n=2,4,6,…n = 2, 4, 6, \dotsn=2,4,6,…: a real even power is never negative. Odd n=3,5,…n = 3, 5, \dotsn=3,5,…: −83=−2\sqrt[3]{-8} = -23−8​=−2 is genuine.

  • The three parent graphs

    y=xy = \sqrt{x}y=x​: from the starting point (0,0)(0, 0)(0,0), climbing ever more slowly. y=∣x∣y = \lvert x \rverty=∣x∣: a V, vertex (0,0)(0, 0)(0,0), branch slopes −1-1−1 and +1+1+1. y=1xy = \dfrac{1}{x}y=x1​: a hyperbola, two branches never joined, asymptotes x=0x = 0x=0 and y=0y = 0y=0.

    Text description

    Three panels: a square-root curve, an absolute-value V, and the reciprocal's two branches.

    Use when Ranges: y≥0y \ge 0y≥0 for the first two. The square-root curve is the upper half of the sideways parabola y2=xy^2 = xy2=x.

  • Shifted parent forms

    y=ax−h+ky=a∣x−h∣+ky=ax−h+k\begin{gathered} y = a\sqrt{x - h} + k \\ y = a\lvert x - h \rvert + k \\ y = \frac{a}{x - h} + k \end{gathered}y=ax−h​+ky=a∣x−h∣+ky=x−ha​+k​

    Use when a≠0a \neq 0a=0. The anchor moves to (h,k)(h, k)(h,k): starting point, vertex, or where x=hx = hx=h meets y=ky = ky=k. Domains: x≥hx \ge hx≥h, all reals, all reals but hhh. Radical and V ranges: y≥ky \ge ky≥k if a>0a > 0a>0, else y≤ky \le ky≤k. Reciprocal range: all reals but kkk. Larger ∣a∣\lvert a \rvert∣a∣ narrows a V; a<0a < 0a<0 flips across y=ky = ky=k.

    e.g. y=−2xy = -2\sqrt{x}y=−2x​ keeps domain x≥0x \ge 0x≥0 but flips the range to y≤0y \le 0y≤0.

  • Piecewise rule for absolute value

    ∣x∣={xif x≥0,−xif x<0.\lvert x \rvert = \begin{cases} x & \text{if } x \ge 0, \\ -x & \text{if } x < 0. \end{cases}∣x∣={x−x​if x≥0,if x<0.​

    Use when Every real xxx; ∣x∣≥0\lvert x \rvert \ge 0∣x∣≥0 always, equality only at x=0x = 0x=0. Split a shifted bar on the sign of its inside: ∣x−3∣\lvert x - 3 \rvert∣x−3∣ is x−3x - 3x−3 for x≥3x \ge 3x≥3, else 3−x3 - x3−x.

  • Absolute value equations and inequalities

    ∣X∣=c\lvert X \rvert = c∣X∣=c: two cases X=cX = cX=c or X=−cX = -cX=−c when c>0c > 0c>0; one case X=0X = 0X=0 when c=0c = 0c=0; no solution when c<0c < 0c<0. ∣X∣<c\lvert X \rvert < c∣X∣<c: one band, −c<X<c-c < X < c−c<X<c. ∣X∣>c\lvert X \rvert > c∣X∣>c: two rays, X<−cX < -cX<−c or X>cX > cX>c.

    Use when Isolate the bars first; XXX may be any expression. The inequality forms need c>0c > 0c>0; ≤\le≤ and ≥\ge≥ read the same, endpoints included.

  • Floor and ceiling, pinned by inequalities

    ⌊x⌋≤x<⌊x⌋+1⌈x⌉−1<x≤⌈x⌉\begin{gathered} \lfloor x \rfloor \le x < \lfloor x \rfloor + 1 \\ \lceil x \rceil - 1 < x \le \lceil x \rceil \end{gathered}⌊x⌋≤x<⌊x⌋+1⌈x⌉−1<x≤⌈x⌉​
    Text description

    A staircase of unit steps, each closed at its left end and open at its right.

    Use when Every real xxx; the integer satisfying either is unique. The brackets agree on the integers, where ⌊x⌋=⌈x⌉=x\lfloor x \rfloor = \lceil x \rceil = x⌊x⌋=⌈x⌉=x, and differ by exactly 111 elsewhere.

    e.g. ⌈x⌉=−1\lceil x \rceil = -1⌈x⌉=−1 holds for exactly the inputs −2<x≤−1-2 < x \le -1−2<x≤−1.

  • Fractional part

    {x}=x−⌊x⌋,0≤{x}<1\{x\} = x - \lfloor x \rfloor, \qquad 0 \le \{x\} < 1{x}=x−⌊x⌋,0≤{x}<1

    Use when Every real xxx, negatives included, and 000 exactly on the integers. For a negative non-integer it is NOT the digits after the decimal point.

    e.g. {−1.25}=−1.25−(−2)=0.75\{-1.25\} = -1.25 - (-2) = 0.75{−1.25}=−1.25−(−2)=0.75.

  • Vertical asymptote or hole

    Cancel as far as it will go, then read the REDUCED denominator: if x−ax - ax−a still divides it, x=ax = ax=a is a vertical asymptote; if not, a hole at the reduced form's height.

    Use when Either way x=ax = ax=a must be a zero of the ORIGINAL denominator; only complete factoring separates the cases.

    e.g. (x−3)(x+2)(x−3)(x+3)\dfrac{(x - 3)(x + 2)}{(x - 3)(x + 3)}(x−3)(x+3)(x−3)(x+2)​: hole at (3,56)\left(3, \tfrac{5}{6}\right)(3,65​), asymptote x=−3x = -3x=−3.

  • Horizontal asymptote by degrees

    n<mn < mn<m: y=0y = 0y=0. n=mn = mn=m: y=aby = \dfrac{a}{b}y=ba​, the ratio of leading coefficients. n>mn > mn>m: none.

    Use when nnn, mmm are the degrees and aaa, bbb the leading coefficients of top and bottom. When n=m+1n = m + 1n=m+1 a slant line takes the asymptote's place, found by dividing.

    e.g. 3x+2x2−1\dfrac{3x + 2}{x^2 - 1}x2−13x+2​ settles toward y=0y = 0y=0, while x3+1x2−5\dfrac{x^3 + 1}{x^2 - 5}x2−5x3+1​ has none.

  • Piecewise: partition, dots, and the jump test

    Conditions must give each input exactly one piece. Close the dot on the piece that includes a boundary, open it on the one that excludes it. When both pieces have a definite height there, as with lines, constants, and polynomials, evaluate BOTH formulas: equal heights connect, different heights jump. A piece that is undefined or unbounded at the boundary, such as a rational function's hole or vertical asymptote, needs the tools from that lesson instead.

    Use when Pair x≤bx \le bx≤b with x>bx > bx>b, or x<bx < bx<b with x≥bx \ge bx≥b; pairing ≤\le≤ with ≥\ge≥ claims bbb twice, <<< with >>> not at all. A connected boundary can still be a corner, as at the vertex of ∣x∣\lvert x \rvert∣x∣.

Problem types, step by step

Find the domain of a radical or a rational function

  1. Radical, even index: set the radicand ≥0\ge 0≥0 and solve, flipping the inequality if you divide by a negative. Odd index: all reals.
  2. Rational: set only the denominator to zero, factor, and solve; one with no real zeros, like x2+4x^2 + 4x2+4, excludes nothing.
  3. Exclude those values, even if a factor later cancels.

e.g. 5−x\sqrt{5 - x}5−x​ needs 5−x≥05 - x \ge 05−x≥0, so the domain is x≤5x \le 5x≤5.

Graph a shifted parent from its equation

  1. Match to one of the three shifted parent forms, reading hhh from x−hx - hx−h.
  2. Plot the anchor (h,k)(h, k)(h,k): starting point, vertex, or asymptote crossing.
  3. Use ∣a∣\lvert a \rvert∣a∣ for the stretch and the sign of aaa for a flip across y=ky = ky=k.
  4. Add one more point: an input making the radicand a perfect square, or one unit from a vertex.

e.g. y=−2∣x−1∣+5y = -2\lvert x - 1 \rvert + 5y=−2∣x−1∣+5: vertex (1,5)(1, 5)(1,5), opens down, and x=2x = 2x=2 gives 333.

Solve a radical equation

  1. Isolate the radical first.
  2. Raise both sides to the power matching the index.
  3. Expand any binomial in full: (x−2)2=x2−4x+4(x - 2)^2 = x^2 - 4x + 4(x−2)2=x2−4x+4, not x2+4x^2 + 4x2+4.
  4. Solve what remains, then test EVERY candidate in the original, keeping those that hold.

e.g. x=x−2\sqrt{x} = x - 2x​=x−2 yields 111 and 444; only 444 checks, so 111 is extraneous.

Solve an absolute value equation or inequality

  1. Isolate the bars.
  2. Equation: negative right side, no solution; zero, solve inside =0= 0=0; positive, solve both cases inside =±c= \pm c=±c.
  3. Inequality with <<<: solve the band −c<X<c-c < X < c−c<X<c as one chain.
  4. Inequality with >>>: solve X<−cX < -cX<−c and X>cX > cX>c separately, joined by "or".

e.g. ∣x−1∣≤3\lvert x - 1 \rvert \le 3∣x−1∣≤3 becomes the band −3≤x−1≤3-3 \le x - 1 \le 3−3≤x−1≤3, so −2≤x≤4-2 \le x \le 4−2≤x≤4.

Evaluate a floor or ceiling, or solve one for xxx

  1. Locate the input between consecutive integers: floor on the left, ceiling on the right. An integer returns unchanged from both.
  2. For a fractional part, subtract the floor; the result lands in [0,1)[0, 1)[0,1).
  3. To solve, expand the bracket into its step: closed left for a floor, closed right for a ceiling.

e.g. ⌊−7.2⌋=−8\lfloor -7.2 \rfloor = -8⌊−7.2⌋=−8 and ⌈−7.2⌉=−7\lceil -7.2 \rceil = -7⌈−7.2⌉=−7, so {−7.2}=0.8\{-7.2\} = 0.8{−7.2}=0.8.

Choose a floor or a ceiling in a counting problem

  1. Divide the total NNN by one group's capacity kkk.
  2. Leftover needs a container: round up, ⌈N/k⌉\lceil N/k \rceil⌈N/k⌉. Leftover discarded: round down, ⌊N/k⌋\lfloor N/k \rfloor⌊N/k⌋.
  3. Report the leftover as N−k⌊N/k⌋N - k\lfloor N/k \rfloorN−k⌊N/k⌋.

e.g. 150150150 students in 404040-seat buses: 444 buses needed, 333 full, 303030 in the fourth.

Analyze and graph a rational function

  1. Factor the numerator and denominator completely.
  2. Cancel every shared factor, then read the REDUCED denominator: a fully cancelled x−ax - ax−a (no copy left) is a hole at x=ax = ax=a, at the reduced value there; a copy still dividing the reduced denominator makes x=ax = ax=a a vertical asymptote instead.
  3. Every surviving denominator zero is a vertical asymptote; the degrees give the horizontal one.
  4. Intercepts: x from the numerator's surviving zeros, y from the value at x=0x = 0x=0; then sketch a branch on each side of a vertical asymptote.

e.g. x−4x2−16\dfrac{x - 4}{x^2 - 16}x2−16x−4​ reduces to 1x+4\dfrac{1}{x + 4}x+41​: hole (4,18)\left(4, \tfrac{1}{8}\right)(4,81​), asymptotes x=−4x = -4x=−4 and y=0y = 0y=0.

Solve a rational equation

  1. Multiply every term by a common denominator.
  2. Solve the polynomial equation left behind.
  3. Discard any candidate making an original denominator zero; if all go, answer "no solution".

e.g. xx−2=2x−2+3\dfrac{x}{x - 2} = \dfrac{2}{x - 2} + 3x−2x​=x−22​+3 yields only the excluded x=2x = 2x=2, so there is no solution.

Evaluate and graph a piecewise function

  1. To evaluate, use the piece whose condition the input satisfies; at a boundary that is the one with the "or equal to".
  2. To graph, draw each piece over its own interval and nowhere else.
  3. Domain: union the intervals. Range: restrict each formula to its interval, then union the outputs.

e.g. x+1x + 1x+1 on x≤1x \le 1x≤1 with 444 on x>1x > 1x>1: f(1)=2f(1) = 2f(1)=2, and the range is y≤2y \le 2y≤2 or y=4y = 4y=4.

Build a piecewise model from a description

  1. Give each band its own formula and condition, carrying forward what earlier bands charge.
  2. Hand every threshold to exactly one band: "up to and including" is ≤\le≤.

e.g. 333 dollars for the first mile, then 222 per extra mile: F(d)=3+2(d−1)F(d) = 3 + 2(d - 1)F(d)=3+2(d−1) for d>1d > 1d>1, so F(4)=9F(4) = 9F(4)=9.

Exam traps

  • Trap Rounding a negative toward zero, so ⌊−2.3⌋=−2\lfloor -2.3 \rfloor = -2⌊−2.3⌋=−2.

    Fix The floor goes DOWN, toward negative infinity: ⌊−2.3⌋=−3\lfloor -2.3 \rfloor = -3⌊−2.3⌋=−3, while ⌈−2.3⌉=−2\lceil -2.3 \rceil = -2⌈−2.3⌉=−2. Dropping the digits is truncation, a different move.

  • Trap Reading the shift straight off the sign inside, so y=x+3−5y = \sqrt{x + 3} - 5y=x+3​−5 looks like a shift right 333.

    Fix Match x−hx - hx−h: x+3x + 3x+3 is x−(−3)x - (-3)x−(−3), so h=−3h = -3h=−3, the graph goes LEFT 333 and down 555, starting point (−3,−5)(-3, -5)(−3,−5). The same reversal hits ∣x+3∣\lvert x + 3 \rvert∣x+3∣ and 1x+3\dfrac{1}{x + 3}x+31​.

  • Trap Splitting an absolute value equation before the bars are alone: 2∣x+1∣−3=52\lvert x + 1 \rvert - 3 = 52∣x+1∣−3=5 giving x+1=±5x + 1 = \pm 5x+1=±5.

    Fix That solves a different equation. Reduce to ∣x+1∣=4\lvert x + 1 \rvert = 4∣x+1∣=4 first, giving x=3x = 3x=3 or x=−5x = -5x=−5, not 444 or −6-6−6.

  • Trap Squeezing a "greater than" answer into one chain, as −7≥x≥1-7 \ge x \ge 1−7≥x≥1.

    Fix Two rays are two pieces: write x≤−7x \le -7x≤−7 or x≥1x \ge 1x≥1. A chain claims xxx is below −7-7−7 and above 111 at once.

  • Trap Treating a cancelled factor's input as an ordinary point of the graph.

    Fix Cancelling never restores an input. After x−3x - 3x−3 cancels, x=3x = 3x=3 stays barred: the reduced curve, punched out there.

  • Trap Reading a horizontal asymptote off the constant terms, or assuming a curve can never cross one.

    Fix Leading terms decide: 4x2−x2x2+7\dfrac{4x^2 - x}{2x^2 + 7}2x2+74x2−x​ gives y=2y = 2y=2, not 07\tfrac{0}{7}70​, and a higher degree on top leaves none. Crossing is allowed: only a vertical asymptote is off limits, where the function has no value.

  • Trap Deciding which candidate is extraneous by size, or assuming exactly one always fails.

    Fix Only substitution decides: in 7x−5=x+1\sqrt{7x - 5} = x + 17x−5​=x+1 both x=2x = 2x=2 and x=3x = 3x=3 survive, while a rational equation can lose every candidate.

  • Trap Joining the two ends of a jump with a vertical segment.

    Fix A jump is a gap: an open dot and a closed dot at different heights, nothing between, because the function skips those values.
