    The answer

    Part A

    x=4x=4x=4 is a genuine vertical asymptote, but x=−4x=-4x=−4 is not: the factor that vanishes there also cancels with the numerator, so it is a hole instead. The missed check was testing the numerator at each excluded value, not just the denominator.

    Part A

    x=a is a vertical asymptote  ⟺  (x−a) does not cancel with the numerator.x=a \text{ is a vertical asymptote} \iff (x-a) \text{ does not cancel with the numerator}.x=a is a vertical asymptote⟺(x−a) does not cancel with the numerator.
