  1. Problem 1 The allowed inputs

    Find the domain of f(x)=7−2x+1f(x)=\sqrt{7-2x}+1f(x)=7−2x​+1.

    1. Hint 1

      Here only what sits under the even root can restrict the inputs, so look at the radicand alone.

    2. Hint 2

      Set the radicand to be nonnegative and solve for xxx, checking the inequality direction once xxx is isolated.

    Answer

    x≤72x\le\tfrac72x≤27​, that is x≤3.5x\le3.5x≤3.5.

    Full solution

    The 111 is added outside the root, so it places no restriction on the input.

    The root has even index, so its radicand must be nonnegative, which requires

    7−2x≥07-2x\ge07−2x≥0

    Adding 2x2x2x to both sides gives 7≥2x7\ge2x7≥2x, and dividing by the positive 222 gives

    x≤72x\le\tfrac72x≤27​

    So the accepted inputs are every x≤3.5x\le3.5x≤3.5.

    At x=3.5x=3.5x=3.5 the radicand is 000, so f(3.5)=1f(3.5)=1f(3.5)=1.

    At x=4x=4x=4 the radicand is −1-1−1, which no real number squares to, so that input is excluded.

    Answer

    x≤72x\le\tfrac72x≤27​, that is x≤3.5x\le3.5x≤3.5.

    Key idea

    A constant added outside an even root leaves the domain to the sign condition on the radicand.

  2. Problem 2 The machine setting

    A machine can take either the fourth root or the fifth root of its input. It must return a real number for every real input. Which root index should be installed?

    1. Hint 1

      The setting must work for negative inputs as well as zero and positive inputs.

    2. Hint 2

      Compare which real values an even power and an odd power can produce.

    Answer

    555.

    Full solution

    A fourth power is never negative, so a fourth-root setting cannot return a real number for a negative input.

    For example, no real number has fourth power −1-1−1.

    A fifth power can produce every real value, with negative, zero, and positive outputs.

    Its inverse, the fifth root, therefore accepts every real input, so install index 555.

    Answer

    555.

    Key idea

    An odd-index root accepts every real input because the corresponding odd power can produce every real output.

  3. Problem 3 The enclosed square

    Find the real domain of f(x)=(x−2)2f(x)=\sqrt{(x-2)^2}f(x)=(x−2)2​.

    1. Hint 1

      The even root needs its entire radicand to be zero or positive.

    2. Hint 2

      Test a few inputs on either side of x=2x=2x=2, including x=2x=2x=2 itself, and decide what the radicand can never be.

    Answer

    All real numbers.

    Full solution

    For every real input,

    (x−2)2≥0(x-2)^2\ge0(x−2)2≥0

    Thus every input meets the square root restriction.

    In particular, x=2x=2x=2 gives radicand zero and is included; inputs on both sides give positive radicands.

    Answer

    All real numbers.

    Key idea

    A squared real expression already satisfies the sign restriction of a square-root radicand.

  6. Problem 6 The nested machine

    A machine first computes u=x−3u=\sqrt{x-3}u=x−3​ and then reports 9−u\sqrt{9-u}9−u​. Find all real inputs the machine accepts, and the machine's output at each extreme input it accepts.

    1. Hint 1

      Each square root must receive a nonnegative radicand.

    2. Hint 2

      After requiring x≥3x\ge3x≥3, require the first output to be at most 999.

    Answer

    3≤x≤843\le x\le843≤x≤84; output 333 at x=3x=3x=3 and 000 at x=84x=84x=84.

    Full solution

    The first root requires x≥3x\ge3x≥3.

    The second requires

    x−3≤9.\sqrt{x-3}\le9.x−3​≤9.

    Both quantities are nonnegative, so squaring gives

    x−3≤81x-3\le81x−3≤81

    Therefore the accepted inputs are

    3≤x≤84.3\le x\le84.3≤x≤84.

    At x=3x=3x=3, the intermediate output is 000 and the final output is 9=3\sqrt9=39​=3.

    At x=84x=84x=84, the intermediate output is 999 and the final output is 0=0\sqrt0=00​=0.

    Both endpoints are allowed.

    Answer

    3≤x≤843\le x\le843≤x≤84; output 333 at x=3x=3x=3 and 000 at x=84x=84x=84.

    Key idea

    Composed radical operations must satisfy the domain restriction at every stage.

  7. Problem 7 The square panel

    A square panel has area 12−x12-x12−x square cm and side length x−6x-6x−6 cm, where xxx is real and the side is positive. Find xxx and the panel dimensions, checking every algebraic candidate.

    1. Hint 1

      The nonnegative square root of the area must equal the positive side.

    2. Hint 2

      Squaring gives a quadratic, but a candidate with a negative stated side must be rejected.

    Answer

    x=8x=8x=8; side 222 cm; area 444 square cm; the candidate x=3x=3x=3 is rejected.

    Full solution

    The conditions include x>6x>6x>6 and 12−x≥012-x\ge012−x≥0.

    The side equation is

    12−x=x−6\sqrt{12-x}=x-612−x​=x−6

    Squaring and collecting gives

    x2−11x+24=0x^2-11x+24=0x2−11x+24=0

    Factoring gives (x−3)(x−8)=0(x-3)(x-8)=0(x−3)(x−8)=0, so the candidates are 333 and 888.

    At 333, the principal root is 333 but the stated side is −3-3−3, so that candidate fails.

    At 888, the area is 444 square cm and the side is 222 cm.

    The principal root is 222, so this candidate checks and gives the requested dimensions.

    Answer

    x=8x=8x=8; side 222 cm; area 444 square cm; the candidate x=3x=3x=3 is rejected.

    Key idea

    A candidate from squaring survives only if it satisfies the original equation and every stated condition, here that the side x−6x-6x−6 is positive.

  9. Problem 9 The two root records

    For x≥9x\ge9x≥9, consider x−4=x−9\sqrt{x-4}=\sqrt{x-9}x−4​=x−9​. Ivo says squaring this equation cannot introduce an extraneous candidate because both sides are nonnegative. Is he correct, and does the equation have any solutions?

    1. Hint 1

      On the stated domain both roots exist and are nonnegative.

    2. Hint 2

      Both radicands are already isolated under single roots, so compare what the squared equation says about x−4x-4x−4 and x−9x-9x−9.

    Answer

    Ivo is correct; there are no solutions.

    Full solution

    On x≥9x\ge9x≥9, both sides are nonnegative.

    Squaring is reversible for such values, so it introduces no extraneous candidate here.

    The squared equation is

    x−4=x−9x-4=x-9x−4=x−9

    Subtracting xxx would require −4=−9-4=-9−4=−9, which is false.

    Thus no candidate exists, and the original equation has no solutions.

    Answer

    Ivo is correct; there are no solutions.

    Key idea

    Squaring an equality is reversible when both sides are known to be nonnegative.
