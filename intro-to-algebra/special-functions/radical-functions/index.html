Radical Functions Advanced. This lesson goes beyond core Algebra I. You can skip it.

Intuition

Squaring a number is easy: feed in 555 and out comes 252525. A radical function runs that machine backward. It starts from the area of a square and hands you back the side, starting from 252525 and returning 555. You first met the square root as an operation, back when you learned exponents and roots. Here the square root becomes a function in its own right, with an input, an output, a domain, and a graph. Because a radical undoes a power, everything about it flows from a single question: which number, raised to this power, gives what I started with? Answering that carefully is what explains why square roots refuse negative inputs, and why the graph has a fixed starting point and bends the way it does. Answering that question also explains why solving a radical equation can hand you an answer that turns out to be false.

Learning goals

  • Solve radicand ≥0\ge 0≥0 for an even-index domain
  • Accept every real input for an odd-index root
  • Draw y=xy = \sqrt{x}y=x​ from its starting point, rising ever slower
  • Place the starting point at (h,k)(h, k)(h,k) in y=ax−h+ky = a\sqrt{x - h} + ky=ax−h​+k
  • Check every candidate, since squaring can add extraneous ones

What a radical function is

Squaring sends 333 to 999 and 777 to 494949. The square root asks the reverse question: which nonnegative number, squared, gives the input? Packaging that question as a function gives the square-root function

f(x)=x.f(x) = \sqrt{x}.f(x)=x​.

By agreement x\sqrt{x}x​ means the principal root, the one that is not negative. Both 444 and −4-4−4 square to 161616, but 16\sqrt{16}16​ is defined to be 444 alone. That definition makes fff return exactly one output per input, so fff is a genuine function.

The same idea works for any power. The cube root x3\sqrt[3]{x}3x​ undoes cubing, and in general the nnnth root xn\sqrt[n]{x}nx​ undoes raising to the nnnth power. The little number nnn is the index of the radical; a square root is the case n=2n = 2n=2, and its index is left unwritten. Each of these is the same thing you already know from rational exponents, since taking an nnnth root is raising to the power 1n\tfrac{1}{n}n1​:

x=x1/2,x3=x1/3,xn=x1/n.\sqrt{x} = x^{1/2}, \qquad \sqrt[3]{x} = x^{1/3}, \qquad \sqrt[n]{x} = x^{1/n}.x​=x1/2,3x​=x1/3,nx​=x1/n.

A radical function is any function whose rule contains the variable under a root like this. The rest of the lesson works out the two features that make radicals behave unlike the polynomials of earlier chapters: a restricted domain, and a graph that bends.

Domain: which inputs a root will accept

A polynomial such as x2−3xx^2 - 3xx2−3x accepts every real number. A radical is fussier. Try to compute −9\sqrt{-9}−9​ and you are asking for a number whose square is −9-9−9, and no real number squares to a negative. So −9\sqrt{-9}−9​ has no real value, and −9-9−9 cannot be in the domain of f(x)=xf(x) = \sqrt{x}f(x)=x​. The same objection rules out every negative input.

Why an even-index root rejects negative inputs#

Start from the definition. The value a\sqrt{a}a​ is the nonnegative number whose square is aaa, so if a=b\sqrt{a} = ba​=b then bbb must satisfy b2=ab^2 = ab2=a. The question is whether any real number bbb can have a negative square. A positive times a positive is positive, a negative times a negative is again positive, and 02=00^2 = 002=0, so for every real number bbb,

b2≥0.b^2 \ge 0.b2≥0.

A square is never negative. If aaa is negative, there is no real bbb with b2=ab^2 = ab2=a, so a\sqrt{a}a​ has no real value. That is exactly why the domain of f(x)=xf(x) = \sqrt{x}f(x)=x​ is every xxx with x≥0x \ge 0x≥0. The same reasoning applies to any even index: the input under a fourth root, a sixth root, and so on must be zero or greater.

Odd-index roots escape the restriction, and the sign test shows why. A cube can be negative, since (−2)3=−8(-2)^3 = -8(−2)3=−8, which makes −83=−2\sqrt[3]{-8} = -23−8​=−2 a perfectly good real number. As bbb runs through every real number, b3b^3b3 runs through every real output exactly once, so x3\sqrt[3]{x}3x​ is defined for all real xxx. The domain shrinks only when the index is even, because only an even power is forced to stay nonnegative.

∎

To find the domain of a more involved radical, you do not need a new rule. For an even root, whatever sits under the radical must be greater than or equal to zero. So for an even root, set the radicand (the expression under the root) to be nonnegative and solve the resulting inequality. That test finds the whole domain here because nothing else in the rules of this lesson, such as a denominator, restricts the input further; a function that combined a root with another restriction would need both checked.

Handle each root by looking only at what it demands of the radicand.

For f(x)=2x−6f(x) = \sqrt{2x - 6}f(x)=2x−6​, the index is even, so the radicand cannot be negative. Require it to be nonnegative and solve:

2x−6≥0⟹x≥3.2x - 6 \ge 0 \quad \Longrightarrow \quad x \ge 3.2x−6≥0⟹x≥3.

The graph of the square root

To plot y=xy = \sqrt{x}y=x​, choose inputs whose roots come out whole, the perfect squares, so the points are easy to place:

xxx000111444999161616
y=xy = \sqrt{x}y=x​000111222333444

The curve begins at the starting point (0,0)(0, 0)(0,0), since 0=0\sqrt{0} = 00​=0, and it climbs to the right forever. But the climb keeps slowing: getting from output 111 to output 222 costs three units of input (from 111 to 444). Getting from output 222 to output 333 then costs five units of input (from 444 to 999). Each additional unit of height demands a wider stretch of input, so the graph rises steeply near the start and then flattens.

That shape is not arbitrary. Saying y=xy = \sqrt{x}y=x​ says two things at once: y≥0y \ge 0y≥0 (the root is never negative) and y2=xy^2 = xy2=x (squaring the output returns the input). Read on its own, the equation y2=xy^2 = xy2=x describes a parabola lying on its side, opening to the right, because for each height yyy the input is x=y2x = y^2x=y2. Keeping only the part with y≥0y \ge 0y≥0 leaves the upper half of that sideways parabola, and that half is exactly the square-root graph.

There is a second way to see the same curve. Since the square root undoes squaring on nonnegative inputs, y=xy = \sqrt{x}y=x​ is the inverse of y=x2y = x^2y=x2 restricted to x≥0x \ge 0x≥0. So the graph of y=xy = \sqrt{x}y=x​ is the reflection of that parabola across the line y=xy = xy=x, the mirror you met when studying inverse functions. Reflecting swaps each point (a,b)(a, b)(a,b) into (b,a)(b, a)(b,a), which turns the steep, upward half-parabola into the flat, rightward square-root curve.

The graph also settles the range. The outputs of x\sqrt{x}x​ are the heights the curve reaches, and starting at 000 it climbs through every positive value without bound, so the range is every y≥0y \ge 0y≥0. Every nonnegative number is hit exactly once, since a target height yyy is the root of x=y2x = y^2x=y2.

Reading transformations off the equation

You do not have to build a fresh table for every square-root function. Every function of the form below is a shifted and scaled copy of y=xy = \sqrt{x}y=x​, using the same shifts, stretches, and reflections from the graphing lessons, now applied to the root. The general form is

y=ax−h+k.y = a\sqrt{x - h} + k.y=ax−h​+k.

Read the three pieces separately, exactly as you did for parabolas:

  • The x−hx - hx−h inside the root shifts the graph right by hhh. It also sets the domain, because the radicand x−hx - hx−h must be nonnegative, giving x≥hx \ge hx≥h.
  • The +k+k+k outside shifts the graph up by kkk.
  • The aaa outside stretches the graph vertically by ∣a∣\lvert a \rvert∣a∣, and when aaa is negative it also reflects the graph across the x-axis, flipping the curve downward.

Putting these together, the starting point that used to sit at (0,0)(0, 0)(0,0) now sits at (h,k)(h, k)(h,k). The domain is x≥hx \ge hx≥h, and for a≠0a \ne 0a=0 the range is y≥ky \ge ky≥k when a>0a > 0a>0 or y≤ky \le ky≤k when a<0a < 0a<0. The range splits into two cases because the curve leaves the starting point heading up or down according to the sign of aaa.

Match the rule to the form y=ax−h+ky = a\sqrt{x - h} + ky=ax−h​+k. Here a=1a = 1a=1, h=2h = 2h=2, and k=1k = 1k=1, so nothing is stretched or flipped, and the whole curve is only shifted.

The inside x−2x - 2x−2 moves the graph right by 222, and the +1+1+1 moves it up by 111, so the starting point travels from (0,0)(0, 0)(0,0) to

(h,k)=(2,1).(h, k) = (2, 1).(h,k)=(2,1).

From there the curve has the ordinary square-root shape. To place a second point, pick an input that makes the radicand a perfect square, say x=6x = 6x=6: then 6−2+1=4+1=3\sqrt{6 - 2} + 1 = \sqrt{4} + 1 = 36−2​+1=4​+1=3, giving the point (6,3)(6, 3)(6,3).

The domain comes from the radicand: x−2≥0x - 2 \ge 0x−2≥0, so x≥2x \ge 2x≥2, which matches the starting point sitting at x=2x = 2x=2. Since a=1>0a = 1 > 0a=1>0 the curve rises from that starting point, so the outputs start at 111 and grow, and the range is y≥1y \ge 1y≥1.

Worked example 3 Describe the graph of y=−2xy = -2\sqrt{x}y=−2x​

Read y=−2xy = -2\sqrt{x}y=−2x​ as y=axy = a\sqrt{x}y=ax​ with a=−2a = -2a=−2, a single coefficient doing two jobs at once.

Its size, ∣a∣=2\lvert a \rvert = 2∣a∣=2, is a vertical stretch: every output of x\sqrt{x}x​ is doubled. Its sign, negative, reflects the graph across the x-axis, turning the curve downward. Tracking the anchor points of y=xy = \sqrt{x}y=x​ through the rule makes both effects concrete:

(1,1)⟶(1,−2),(4,2)⟶(4,−4).(1, 1) \longrightarrow (1, -2), \qquad (4, 2) \longrightarrow (4, -4).(1,1)⟶(1,−2),(4,2)⟶(4,−4).

The starting point (0,0)(0, 0)(0,0) stays fixed, since −2×0=0-2 \times 0 = 0−2×0=0. The domain is unchanged at x≥0x \ge 0x≥0, because the radicand xxx is untouched. But the outputs are now zero or negative, so the range flips to y≤0y \le 0y≤0. The curve now drops away from the origin into the fourth quadrant instead of climbing into the first.

It came from inside the root.

Solving radical equations

A radical equation has the variable under a root, as in 2x−1=5\sqrt{2x - 1} = 52x−1​=5. The plan is to free the variable from the root, and the tool is the inverse relationship you have leaned on all lesson: squaring undoes a square root. Isolate the radical on one side, then raise both sides to the power that matches the index. For a square root you square; for a cube root you cube.

2x−1=5⟹2x−1=25⟹x=13.\sqrt{2x - 1} = 5 \quad \Longrightarrow \quad 2x - 1 = 25 \quad \Longrightarrow \quad x = 13.2x−1​=5⟹2x−1=25⟹x=13.

Squaring turned the awkward equation into a linear one. There is a catch, though, and it is not optional bookkeeping. Squaring both sides can manufacture solutions that solve the new equation but not the original. (Cubing does not have this problem, since no two different real numbers ever share a cube, but squaring does: 333 and −3-3−3 both square to 999.) These manufactured answers are called extraneous solutions, and the next argument explains exactly where they come from.

Why squaring both sides can create extraneous solutions#

Squaring both sides of an equation is a one-way street. If two quantities are equal, then their squares are equal too: from A=BA = BA=B it always follows that A2=B2A^2 = B^2A2=B2. So every genuine solution of the original equation survives the squaring, and none is lost.

The reverse direction is where trouble enters. Knowing A2=B2A^2 = B^2A2=B2 does not force A=BA = BA=B, because a square erases a sign. The statement A2=B2A^2 = B^2A2=B2 means

A=BorA=−B,A = B \quad \text{or} \quad A = -B,A=BorA=−B,

since AAA and −A-A−A share the same square. Squaring folds those two possibilities into one, so the squared equation quietly carries the solutions of A=BA = BA=B together with the solutions of A=−BA = -BA=−B. Any candidate that belongs only to the second family satisfies the squared equation while failing the one you started with.

Those intruders are the extraneous solutions. They are not errors in the algebra; they are the price of an irreversible step, because squaring cannot tell AAA from −A-A−A. The only way to know which candidates are real solutions is to substitute each one back into the original equation and keep those that make it true.

∎

Worked example 4 Solve 1+2x+3=61 + \sqrt{2x + 3} = 61+2x+3​=6

Isolate the radical before doing anything else. Subtract 111 from both sides so the root stands alone:

2x+3=5.\sqrt{2x + 3} = 5.2x+3​=5.

Now the two sides are single quantities, so square both to remove the root:

2x+3=25⟹2x=22⟹x=11.2x + 3 = 25 \quad \Longrightarrow \quad 2x = 22 \quad \Longrightarrow \quad x = 11.2x+3=25⟹2x=22⟹x=11.

Check the candidate in the original equation, not the squared one:

1+2(11)+3=1+25=1+5=6.✓1 + \sqrt{2(11) + 3} = 1 + \sqrt{25} = 1 + 5 = 6. \checkmark1+2(11)+3​=1+25​=1+5=6.✓

The check holds, so x=11x = 11x=11 is the solution. Isolating first mattered: squaring the equation while the 111 was still attached would have left a radical behind.

Worked example 5 Solve x=x−2\sqrt{x} = x - 2x​=x−2 and watch an extraneous solution appear

The radical is already isolated, so square both sides. The right side is a binomial, so expand it carefully:

x=(x−2)2=x2−4x+4.x = (x - 2)^2 = x^2 - 4x + 4.x=(x−2)2=x2−4x+4.

Move everything to one side to get a quadratic, then factor:

x2−5x+4=0⟹(x−1)(x−4)=0,x^2 - 5x + 4 = 0 \quad \Longrightarrow \quad (x - 1)(x - 4) = 0,x2−5x+4=0⟹(x−1)(x−4)=0,

so the candidates are x=1x = 1x=1 and x=4x = 4x=4. Squaring may have added a stranger, so test both in the original equation x=x−2\sqrt{x} = x - 2x​=x−2.

For x=4x = 4x=4: the left side is 4=2\sqrt{4} = 24​=2 and the right side is 4−2=24 - 2 = 24−2=2. The two agree, so x=4x = 4x=4 is genuine.

For x=1x = 1x=1: the left side is 1=1\sqrt{1} = 11​=1 and the right side is 1−2=−11 - 2 = -11−2=−1. Since 1≠−11 \ne -11=−1, the candidate x=1x = 1x=1 fails, so it is extraneous. It is exactly the intruder the proof predicted: it solves the other branch x=−(x−2)\sqrt{x} = -(x - 2)x​=−(x−2), because 1=−(1−2)=11 = -(1 - 2) = 11=−(1−2)=1 is true. The only solution is x=4x = 4x=4.

Worked example 6 Solve 7x−5=x+1\sqrt{7x - 5} = x + 17x−5​=x+1

Square both sides, expanding the right side as a binomial:

7x−5=(x+1)2=x2+2x+1.7x - 5 = (x + 1)^2 = x^2 + 2x + 1.7x−5=(x+1)2=x2+2x+1.

Collect into a quadratic and factor:

x2−5x+6=0⟹(x−2)(x−3)=0,x^2 - 5x + 6 = 0 \quad \Longrightarrow \quad (x - 2)(x - 3) = 0,x2−5x+6=0⟹(x−2)(x−3)=0,

giving candidates x=2x = 2x=2 and x=3x = 3x=3. Test each in the original equation, since squaring might have introduced a false root.

For x=2x = 2x=2: 7(2)−5=9=3\sqrt{7(2) - 5} = \sqrt{9} = 37(2)−5​=9​=3, and x+1=3x + 1 = 3x+1=3. They match.

For x=3x = 3x=3: 7(3)−5=16=4\sqrt{7(3) - 5} = \sqrt{16} = 47(3)−5​=16​=4, and x+1=4x + 1 = 4x+1=4. They match too.

This time both candidates check out, so the equation has two solutions, x=2x = 2x=2 and x=3x = 3x=3. The lesson is not that the smaller root is always extraneous; it is that you cannot know until you test, so check every candidate in the original equation.

Common mistakes

Common mistakes

  • Thinking a square root can be negative. The symbol x\sqrt{x}x​ means the principal, nonnegative root, so 16=4\sqrt{16} = 416​=4, not ±4\pm 4±4. The two square roots of 161616 are 444 and −4-4−4, but the function returns only the nonnegative one.
  • Forgetting to restrict the domain. For an even root the radicand must be ≥0\ge 0≥0. Before doing anything with 2x−6\sqrt{2x - 6}2x−6​, note that x≥3x \ge 3x≥3; inputs below that are simply not allowed.
  • Flipping the inequality the wrong way, or not at all. Solving 5−x≥05 - x \ge 05−x≥0 gives x≤5x \le 5x≤5, not x≥5x \ge 5x≥5. When the variable has a negative coefficient, isolating it reverses the inequality.
  • Squaring term by term. (x−2)2(x - 2)^2(x−2)2 is x2−4x+4x^2 - 4x + 4x2−4x+4, not x2+4x^2 + 4x2+4. A binomial must be expanded in full; you cannot square each piece separately.
  • Skipping the check. Squaring both sides can create extraneous solutions, so every candidate must be tested in the original equation. Never report a root you have not verified.
  • Assuming the smaller candidate is the extraneous one. Sometimes both candidates are valid, and sometimes the larger one fails. Only substitution decides which roots are real.

Key takeaways

  • A radical function puts the variable under a root, as in f(x)=xf(x) = \sqrt{x}f(x)=x​ or xn=x1/n\sqrt[n]{x} = x^{1/n}nx​=x1/n; the square root returns the principal (nonnegative) value.
  • Domain: an even-index radicand must be ≥0\ge 0≥0 (because a real square is never negative), so solve radicand ≥0\ge 0≥0; an odd-index root accepts every real number.
  • The graph of y=xy = \sqrt{x}y=x​ starts at the point (0,0)(0, 0)(0,0) and rises ever more slowly. The same curve is the upper half of the sideways parabola y2=xy^2 = xy2=x, equivalently the reflection of y=x2y = x^2y=x2 (for x≥0x \ge 0x≥0) across y=xy = xy=x. Its range is y≥0y \ge 0y≥0.
  • Transformations: in y=ax−h+ky = a\sqrt{x - h} + ky=ax−h​+k with a≠0a \ne 0a=0, the starting point sits at (h,k)(h, k)(h,k) and the domain is x≥hx \ge hx≥h. The factor aaa stretches by ∣a∣\lvert a \rvert∣a∣ (and reflects across the x-axis when a<0a < 0a<0), and the range is y≥ky \ge ky≥k if a>0a > 0a>0 or y≤ky \le ky≤k if a<0a < 0a<0.
  • Solving: isolate the radical, then raise both sides to the matching power. Squaring is irreversible, so it can add extraneous solutions; check every candidate in the original equation and keep only those that make it true.

A bit of history (optional)

People were computing roots long before anyone had a sign for one. A Babylonian clay tablet carries an approximation of the square root of 222. It was written nearly four thousand years ago, and it is correct to five decimal places. Greek geometers pictured a root as the side of a square with a given area. That is exactly the picture this lesson opened with. What none of them had was a quick way to write it down.

The radical sign you use appeared in print in 1525, in a German algebra book by Christoff Rudolff. The usual story is that its tick shape is a hurried lowercase rrr, not a checkmark. It stands for the Latin word radix, meaning root. That one word is still working in English today. Radical comes from it, and so, less grandly, does radish.

Rudolff’s mark had no bar across the top, and the omission left a real ambiguity. Written his way, does a+b\sqrt{a} + ba​+b mean the root of aaa, with bbb added on afterwards? Or does it mean the root of the whole sum? Writers settled it with brackets, with dots, or with hope. The horizontal bar arrived about a century later. It fused with the tick into the single symbol you know. Its name is the vinculum, from the Latin for a link, because it binds the radicand together.

That bar is doing quiet work in every rule you learned here. It marks where the radicand stops, and the radicand is what decides the domain.
