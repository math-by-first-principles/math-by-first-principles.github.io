Quadratic Equations: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Quadratic equation, standard form ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0
Every term moved to one side, written in decreasing power. Here aaa is the leading coefficient and ccc the constant term. The one unbreakable requirement is a≠0a \neq 0a=0; bbb or ccc may be 000.
Root (solution)
A value making the standard-form expression equal exactly 000. A quadratic has two, one, or no real root, so finding one does not finish the problem.
Repeated root
The single root left when the two roots merge into one value, as in x2=0x^2 = 0x2=0.
Factored form
The same equation as a product of factors set to 000, like (x−2)(x+3)=0(x - 2)(x + 3) = 0(x−2)(x+3)=0. It puts the roots on display; standard form hides them.
Monic and non-monic trinomials
Monic means the leading coefficient is exactly 111, so the squared term is a plain x2x^2x2. Non-monic means it is not 111, and that coefficient then splits across both factors.
Irreducible over the integers
A trinomial with no factorization into factors with integer coefficients, such as x2+x+1x^2 + x + 1x2+x+1. Integer factoring is the wrong tool for it, not a dead end for the equation: x2+x−1=0x^2 + x - 1 = 0x2+x−1=0 is also irreducible yet has two real roots, while x2+x+1=0x^2 + x + 1 = 0x2+x+1=0 has no real roots.
Parabola
The U-shaped curve y=ax2+bx+cy = ax^2 + bx + cy=ax2+bx+c. Where it meets the xxx-axis is exactly where the real roots are: it can cross twice, touch once at a repeated root, or miss the axis entirely.

Formulas and theorems

  • Zero-product property

    If a product equals 000, at least one factor is 000: AB=0AB = 0AB=0 forces A=0A = 0A=0 or B=0B = 0B=0.

    Use when The product must equal exactly 000; no other number works. It extends to any number of factors, and a nonzero constant factor out front (the 333 in 3(x−4)(x+2)=03(x - 4)(x + 2) = 03(x−4)(x+2)=0) contributes no root.

  • Square-root method

    x2=k  gives  x=±k(x−h)2=k  gives  x=h±k\begin{gathered} x^2 = k \ \text{ gives } \ x = \pm\sqrt{k} \\ (x - h)^2 = k \ \text{ gives } \ x = h \pm \sqrt{k} \end{gathered}x2=k  gives  x=±k​(x−h)2=k  gives  x=h±k​​
    Text description

    One parabola cut by a horizontal line above its lowest point (two crossings), through that point (one), and below it (none).

    Use when Needs one squared quantity alone on one side and a constant on the other: either a bare x2x^2x2, so b=0b = 0b=0, or a whole squared bracket already isolated. k>0k > 0k>0: two real roots. k=0k = 0k=0: one repeated root. k<0k < 0k<0: no real root, because no real number squares to a negative. Treat whatever sits inside the square as one quantity, and undo the shift only after taking the root.

    e.g. (x+2)2=9(x + 2)^2 = 9(x+2)2=9: x+2=±3x + 2 = \pm 3x+2=±3, so x=1x = 1x=1 or x=−5x = -5x=−5.

  • Monic factoring: sum bbb, product ccc

    (x+p)(x+q)=x2+(p+q)x+pq\begin{gathered} (x + p)(x + q) \\ = x^2 + (p + q)x + pq \end{gathered}(x+p)(x+q)=x2+(p+q)x+pq​

    Use when Read right to left to factor x2+bx+cx^2 + bx + cx2+bx+c: find integers ppp, qqq with p+q=bp + q = bp+q=b and pq=cpq = cpq=c. Needs a leading coefficient of exactly 111, so pull out any common numerical factor first. For some trinomials no such pair exists.

    e.g. (x+2)(x+6)=x2+8x+12(x + 2)(x + 6) = x^2 + 8x + 12(x+2)(x+6)=x2+8x+12, read backward to factor.

  • Reading the signs of ppp and qqq

    If c>0c > 0c>0 the two numbers share a sign, and it is the sign of bbb. If c<0c < 0c<0 they have opposite signs, and the one of larger size carries the sign of bbb.

    Use when A monic trinomial factored over the integers; it halves the search before any adding. When b=0b = 0b=0 and c<0c < 0c<0 the pair are opposites of equal size (x2−9=(x+3)(x−3)x^2 - 9 = (x + 3)(x - 3)x2−9=(x+3)(x−3)); when b=0b = 0b=0 and c>0c > 0c>0 no real pair exists.

  • Non-monic factoring: (px+r)(qx+s)(px + r)(qx + s)(px+r)(qx+s)

    (px+r)(qx+s)=pq x2+(ps+qr) x+rs\begin{gathered} (px + r)(qx + s) \\ = pq\,x^2 + (ps + qr)\,x + rs \end{gathered}(px+r)(qx+s)=pqx2+(ps+qr)x+rs​
    Text description

    A rectangle split into four cells, the two shaded cross cells adding to the middle term.

    Use when Matching ax2+bx+cax^2 + bx + cax2+bx+c term by term forces pq=apq = apq=a, rs=crs = crs=c, ps+qr=bps + qr = bps+qr=b. The middle coefficient is a sum of two CROSS products, not a plain sum, so which constant sits beside which xxx term matters.

    e.g. (3x+4)(x+2)=3x2+10x+8(3x + 4)(x + 2) = 3x^2 + 10x + 8(3x+4)(x+2)=3x2+10x+8.

  • The a⋅ca \cdot ca⋅c split

    (ps)+(qr)=b(ps)(qr)=a⋅c\begin{gathered} (ps) + (qr) = b \\ (ps)(qr) = a \cdot c \end{gathered}(ps)+(qr)=b(ps)(qr)=a⋅c​

    Use when a≠0a \neq 0a=0. The two cross products are themselves a sum-and-product pair, so the monic search finds them. It aims the trial rather than replacing it: still expand to confirm.

    e.g. 6x2+7x−36x^2 + 7x - 36x2+7x−3: ac=−18ac = -18ac=−18, and 9+(−2)=79 + (-2) = 79+(−2)=7, pointing at (3x−1)(2x+3)(3x - 1)(2x + 3)(3x−1)(2x+3).

  • Root read off a linear factor

    px+r=0givesx=−rppx + r = 0 \quad \text{gives} \quad x = -\frac{r}{p}px+r=0givesx=−pr​

    Use when p≠0p \neq 0p=0. The root comes out a fraction whenever ppp does not divide rrr: routine for non-monic quadratics, and not an error.

    e.g. 2x−3=02x - 3 = 02x−3=0 gives x=32x = \tfrac{3}{2}x=23​.

  • Quadratic with no constant term (c=0c = 0c=0)

    ax2+bx=x(ax+b)ax^2 + bx = x(ax + b)ax2+bx=x(ax+b)

    Use when Applies exactly when c=0c = 0c=0. The roots are x=0x = 0x=0 and x=−bax = -\tfrac{b}{a}x=−ab​, so x=0x = 0x=0 is always one of them; when b=0b = 0b=0 as well the two coincide and 000 is a repeated root.

    e.g. 3x2+12x=3x(x+4)3x^2 + 12x = 3x(x + 4)3x2+12x=3x(x+4), with roots 000 and −4-4−4.

  • Sum and product of the roots (Vieta's formulas)

    r+s=−ba,rs=car + s = -\frac{b}{a}, \qquad rs = \frac{c}{a}r+s=−ab​,rs=ac​

    Use when a≠0a \neq 0a=0, read from standard form; both totals divide by aaa. When a=1a = 1a=1 they collapse to r+s=−br + s = -br+s=−b and rs=crs = crs=c, and the monic factoring numbers ppp, qqq are the negatives of the roots: same product, opposite sum. They hold for every quadratic with a≠0a \neq 0a=0, whether or not its roots are real.

    e.g. 5x2−3x−25x^2 - 3x - 25x2−3x−2: sum 35\tfrac{3}{5}53​, product −25-\tfrac{2}{5}−52​.

  • Monic quadratic from its roots

    x2−(r+s)x+rs=0x^2 - (r + s)x + rs = 0x2−(r+s)x+rs=0

    Use when Builds the monic quadratic with roots rrr and sss; the constant keeps the product's own sign. Scaling the equation by any nonzero number changes the coefficients but never the roots, which is how fractions clear.

    e.g. Roots −3-3−3 and 555: sum 222, product −15-15−15, so x2−2x−15=0x^2 - 2x - 15 = 0x2−2x−15=0.

Problem types, step by step

Decide whether an equation is quadratic and read aaa, bbb, ccc

  1. Move every term to one side so the other side reads 000, then collect like terms.
  2. Write the terms in decreasing power: squared term, xxx term, constant.
  3. Read aaa, bbb, ccc with their signs. If a=0a = 0a=0 the equation is linear, not quadratic; a missing bbb or ccc is fine.

e.g. 5x=2x2−35x = 2x^2 - 35x=2x2−3 becomes 2x2−5x−3=02x^2 - 5x - 3 = 02x2−5x−3=0, so a=2a = 2a=2, b=−5b = -5b=−5, c=−3c = -3c=−3.

Test whether a number is a root

  1. Substitute the candidate for every xxx in the standard-form expression, squaring before adding.
  2. It is a root exactly when the result is 000. Keep looking: a second root may remain.

e.g. x=2x = 2x=2 in x2−x−2x^2 - x - 2x2−x−2: 4−2−2=04 - 2 - 2 = 04−2−2=0, so 222 is a root.

Solve an equation that is already factored

  1. Confirm the other side is 000; if it is not, expand and rearrange first.
  2. Set each variable factor to 000 and solve. A nonzero constant factor gives no root.

e.g. (2x−1)(x+4)=0(2x - 1)(x + 4) = 0(2x−1)(x+4)=0 gives x=12x = \tfrac{1}{2}x=21​ or x=−4x = -4x=−4.

Solve by taking square roots

  1. Isolate the squared quantity, whether it is x2x^2x2 alone or a whole bracket.
  2. Check the sign of the right side: negative means no real solution, and 000 means one repeated root.
  3. Take the square root of both sides and write ±\pm± on the number.
  4. Solve the two resulting linear equations.

e.g. (x−3)2=16(x - 3)^2 = 16(x−3)2=16: x−3=±4x - 3 = \pm 4x−3=±4, so x=7x = 7x=7 or x=−1x = -1x=−1.

Factor a monic trinomial x2+bx+cx^2 + bx + cx2+bx+c

  1. Pull out any common numerical factor, and when c=0c = 0c=0 pull out the shared xxx as well.
  2. Read the signs of ccc and bbb to decide whether the pair share a sign.
  3. List the integer pairs multiplying to ccc and pick the one adding to bbb.
  4. Write (x+p)(x+q)(x + p)(x + q)(x+p)(x+q) and expand back to confirm. If no pair works, report it irreducible over the integers.

e.g. x2−9x+20x^2 - 9x + 20x2−9x+20: both numbers negative, −4-4−4 and −5-5−5, so (x−4)(x−5)(x - 4)(x - 5)(x−4)(x−5).

Factor a non-monic trinomial by reverse FOIL

  1. Pull out any common numerical factor first, which shrinks aaa.
  2. Find the integer pair with product a⋅ca \cdot ca⋅c and sum bbb; those are the two cross products.
  3. Build a candidate (px+r)(qx+s)(px + r)(qx + s)(px+r)(qx+s) from a factor pair of aaa and one of ccc that produces those cross products.
  4. Expand the candidate. If the middle term is not bxbxbx, swap the constants and expand again; the arrangements differ.

e.g. 3x2−8x+43x^2 - 8x + 43x2−8x+4: ac=12ac = 12ac=12, pair −6-6−6 and −2-2−2, giving (3x−2)(x−2)(3x - 2)(x - 2)(3x−2)(x−2).

Solve a quadratic by factoring

  1. Rearrange to ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 so a bare 000 stands alone on one side.
  2. Factor the left side completely, common factor first.
  3. Set each variable factor to 000 and solve.
  4. Check by substituting both roots back, or by expanding the factors.

e.g. 3x2−6x−24=03x^2 - 6x - 24 = 03x2−6x−24=0: 3(x−4)(x+2)=03(x - 4)(x + 2) = 03(x−4)(x+2)=0, so x=4x = 4x=4 or x=−2x = -2x=−2.

Build a quadratic with given roots

  1. Add the two roots for the sum SSS, and multiply them for the product PPP.
  2. Write x2−Sx+P=0x^2 - Sx + P = 0x2−Sx+P=0.
  3. If integer coefficients are wanted, multiply every term by the common denominator.
  4. Confirm by factoring the result back.

e.g. Roots 12\tfrac{1}{2}21​ and 333: x2−72x+32=0x^2 - \tfrac{7}{2}x + \tfrac{3}{2} = 0x2−27​x+23​=0, times 222 gives 2x2−7x+3=02x^2 - 7x + 3 = 02x2−7x+3=0.

Use the sum and product of the roots

  1. Rearrange to standard form and read aaa, bbb, ccc with their signs.
  2. Compute the sum −ba-\tfrac{b}{a}−ab​ and the product ca\tfrac{c}{a}ac​; fractional totals are normal when a≠1a \neq 1a=1.
  3. For a missing root, subtract the known root from the sum, then confirm by dividing the product by that root (when it is not 000).
  4. For a proposed pair, test BOTH totals; matching only one is not enough.

e.g. 3x2−10x+8=03x^2 - 10x + 8 = 03x2−10x+8=0 with root 222: the sum is 103\tfrac{10}{3}310​, so the other root is 43\tfrac{4}{3}34​.

Exam traps

  • Trap Splitting a product that does not equal 000: from (x−2)(x+3)=14(x - 2)(x + 3) = 14(x−2)(x+3)=14, writing x−2=14x - 2 = 14x−2=14 or x+3=14x + 3 = 14x+3=14, so x=16x = 16x=16 or x=11x = 11x=11.

    Fix The property needs a bare 000 on one side. Expand and rearrange to x2+x−20=0x^2 + x - 20 = 0x2+x−20=0, factor to (x+5)(x−4)=0(x + 5)(x - 4) = 0(x+5)(x−4)=0, and the roots are x=−5x = -5x=−5 or x=4x = 4x=4.

  • Trap Dividing both sides by xxx: from x2=5xx^2 = 5xx2=5x, cancelling leaves only x=5x = 5x=5.

    Fix Dividing by an expression that can be zero deletes the root x=0x = 0x=0. Move everything to one side and factor: x(x−5)=0x(x - 5) = 0x(x−5)=0 keeps both.

  • Trap Reading a root straight off its factor, so (x+4)(x + 4)(x+4) looks like the root 444.

    Fix A factor and the root it produces have opposite signs: x+4=0x + 4 = 0x+4=0 gives x=−4x = -4x=−4.

  • Trap Answering (x+1)2=25(x + 1)^2 = 25(x+1)2=25 with x=±5x = \pm 5x=±5.

    Fix The ±5\pm 5±5 is the value of x+1x + 1x+1, not of xxx. Finish both branches: x=4x = 4x=4 or x=−6x = -6x=−6.

  • Trap Treating (2x+3)(x+1)(2x + 3)(x + 1)(2x+3)(x+1) and (2x+1)(x+3)(2x + 1)(x + 3)(2x+1)(x+3) as the same factorization.

    Fix Swapping the constants is free only when the two xxx-coefficients match, as they always do in a monic trinomial. Here they are 222 and 111, so the leading 222 multiplies the constant in the other binomial, the one it meets in the cross product: the first expands to 2x2+5x+32x^2 + 5x + 32x2+5x+3, the second to 2x2+7x+32x^2 + 7x + 32x2+7x+3.

  • Trap Stopping at 2x2+6x+4=(2x+2)(x+2)2x^2 + 6x + 4 = (2x + 2)(x + 2)2x2+6x+4=(2x+2)(x+2).

    Fix True but incomplete: 2x+22x + 22x+2 still hides a factor of 222. Pull common factors all the way out front, giving 2(x+1)(x+2)2(x + 1)(x + 2)2(x+1)(x+2).

  • Trap Using −b-b−b and ccc on a non-monic quadratic: reading 2x2−9x+42x^2 - 9x + 42x2−9x+4 as sum 999, product 444.

    Fix Both totals divide by aaa: the sum is −ba=92-\tfrac{b}{a} = \tfrac{9}{2}−ab​=29​ and the product is ca=2\tfrac{c}{a} = 2ac​=2. Dividing only one of the two is the usual half-done version.

  • Trap Saying the roots of x2−7x+10x^2 - 7x + 10x2−7x+10 sum to −7-7−7.

    Fix The sum is −b-b−b, and bbb is already −7-7−7, so the roots sum to +7+7+7. That minus is never optional, and it never touches the product.

  • Trap Building from roots as x2+Sx+Px^2 + Sx + Px2+Sx+P.

    Fix The coefficient of xxx is the negative of the sum, so the template is x2−Sx+Px^2 - Sx + Px2−Sx+P. The constant keeps the product's own sign.
