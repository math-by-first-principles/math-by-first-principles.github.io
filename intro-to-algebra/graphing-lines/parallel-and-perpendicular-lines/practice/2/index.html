    What is the slope of any line parallel to y=−23x+7y = -\tfrac{2}{3}x + 7y=−32​x+7?

    Answer choices for question 1

    Solution

    Correct answer: B

    Parallel lines have equal slopes, so read the slope straight off the equation.

    m∥=−23m_{\parallel} = -\frac{2}{3}m∥​=−32​

    The flipped value 32\tfrac{3}{2}23​ belongs to a perpendicular line (after a sign change), not a parallel one.

    What is the slope of any line perpendicular to y=4x−9y = 4x - 9y=4x−9?

    Answer choices for question 2

    Solution

    Correct answer: D

    The given slope is 444. Take the negative reciprocal: flip and change the sign.

    m⊥=−14m_{\perp} = -\frac{1}{4}m⊥​=−41​

    As a check, 4⋅(−14)=−14 \cdot \left(-\tfrac{1}{4}\right) = -14⋅(−41​)=−1.

  3. 3

    A line is perpendicular to x+3y=6x + 3y = 6x+3y=6. What is its slope?

    Answer choices for question 3

    Solution

    Correct answer: C

    First find the slope of the given line by solving for yyy.

    x+3y=6  ⇒  y=−13x+2x + 3y = 6 \;\Rightarrow\; y = -\tfrac{1}{3}x + 2x+3y=6⇒y=−31​x+2

    Its slope is −13-\tfrac{1}{3}−31​, so the perpendicular slope is the negative reciprocal: flip to −3-3−3 and change the sign, giving 333.

  5. 5

    Are y=5x−1y = 5x - 1y=5x−1 and x+5y=10x + 5y = 10x+5y=10 parallel, perpendicular, or neither?

    Answer choices for question 5

    Solution

    Correct answer: A

    Convert the second line to slope-intercept form.

    x+5y=10  ⇒  y=−15x+2x + 5y = 10 \;\Rightarrow\; y = -\tfrac{1}{5}x + 2x+5y=10⇒y=−51​x+2

    The slopes are 555 and −15-\tfrac{1}{5}−51​, and 5⋅(−15)=−15 \cdot \left(-\tfrac{1}{5}\right) = -15⋅(−51​)=−1, so the lines are perpendicular.

  6. 6

    Which line is parallel to y=2x+1y = 2x + 1y=2x+1 and passes through (0,−3)(0, -3)(0,−3), in slope-intercept form?

    Answer choices for question 6

    Solution

    Correct answer: D

    A parallel line has the same slope, 222. The point (0,−3)(0, -3)(0,−3) is the yyy-intercept, so b=−3b = -3b=−3.

    y=2x−3y = 2x - 3y=2x−3

    The line y=2x+1y = 2x + 1y=2x+1 is parallel but passes through (0,1)(0, 1)(0,1), not (0,−3)(0, -3)(0,−3), so it is not the answer.

    A line parallel to y=−x+8y = -x + 8y=−x+8 passes through the origin. What is its equation?

    Answer choices for question 7

    Solution

    Correct answer: A

    A parallel line has slope −1-1−1, and passing through the origin makes b=0b = 0b=0.

    y=−x+0=−xy = -x + 0 = -xy=−x+0=−x

    The line y=−x+8y = -x + 8y=−x+8 is parallel but crosses the yyy-axis at (0,8)(0, 8)(0,8), not the origin.

  9. 9

    The line y=7y = 7y=7 is horizontal. Any line perpendicular to it is which of the following?

    Answer choices for question 9

    Solution

    Correct answer: C

    A horizontal line has slope 000, and 000 has no negative reciprocal, so the product rule does not apply here.

    horizontal⊥vertical\text{horizontal} \perp \text{vertical}horizontal⊥vertical

    The partner that meets a horizontal line at a right angle is a vertical line, of the form x=cx = cx=c.

    The lines y=12x+4y = \tfrac{1}{2}x + 4y=21​x+4 and x−2y=−8x - 2y = -8x−2y=−8 are which of the following?

    Answer choices for question 11

    Solution

    Correct answer: C

    Solve the second equation for yyy.

    x−2y=−8  ⇒  y=12x+4x - 2y = -8 \;\Rightarrow\; y = \tfrac{1}{2}x + 4x−2y=−8⇒y=21​x+4

    Answer choices for question 12

    Solution

    Correct answer: D
