    A line passes through (−5,3)(-5,3)(−5,3). Moving 4 units right along it raises the height by 6 units. Write its equation in point-slope form using the given point.

    1. Hint 1

      The movement supplies the slope needed with the point.

    2. Hint 2

    y−3=32(x+5)y-3=\frac32(x+5)y−3=23​(x+5).

    Full solution

    The move is a run of 4 and a rise of 6, so the slope is

    m=64m=\frac64m=46​ m=32m=\frac32m=23​

    Using the point (−5,3)(-5,3)(−5,3) gives

    y−3=32(x+5)y-3=\frac32(x+5)y−3=23​(x+5)

    At the given point both sides are zero.

    The stated move reaches (−1,9)(-1,9)(−1,9), where both sides are 666, checking the direction and size of the step.

    Answer

    y−3=32(x+5)y-3=\frac32(x+5)y−3=23​(x+5).

    Key idea

    A movement along a line supplies the slope for its point-slope equation.

  4. Problem 4 Workshop charge

  7. Problem 7 Raised tracing

    1. Hint 1

      Think about what a vertical move does to the rise and the run between any two points.

    2. Hint 2

      Keep the slope, and move the anchor point (−1,2)(-1,2)(−1,2) up 3 units.

    Answer

  9. Problem 9 Zero coefficients

    A student allows both AAA and BBB to be zero in Ax+By=CAx+By=CAx+By=C. For each of 0x+0y=60x+0y=60x+0y=6 and 0x+0y=00x+0y=00x+0y=0, describe the set of points that satisfy it, and decide whether it is a line.

    1. Hint 1

      Consider what remains after the zero coefficients remove both coordinate terms.

    2. Hint 2

      Substitute any point you like into each equation, and notice whether the choice of point changes the result.

    Answer

    0x+0y=60x+0y=60x+0y=6 has no points; 0x+0y=00x+0y=00x+0y=0 has every point in the plane; neither is a line.

    Full solution

    The first equation reduces to

    0=60=60=6

    This is false for every choice of coordinates, so it has no points.

    The second reduces to

    0=00=00=0

    This is true for every point in the plane, including points outside any chosen line.

    A standard-form equation for a line therefore needs at least one nonzero variable coefficient.

    Answer

    0x+0y=60x+0y=60x+0y=6 has no points; 0x+0y=00x+0y=00x+0y=0 has every point in the plane; neither is a line.

    Key idea

    At least one variable coefficient must be nonzero for a standard-form equation to describe one line.
