Solving Linear Equations

Intuition

An equation is a claim that two expressions are equal, and a balance scale is the right picture for it. The equals sign is the pivot, and the two sides are equal weights holding the beam level. Solving the equation asks one question, namely for what value of the variable does the balance actually hold. You have already handled simple cases like x+3=7x + 3 = 7x+3=7 in earlier work. Here the equations grow more tangled, with parentheses, with several terms, and with the variable appearing on both sides at once. A single principle still handles all of them: whatever you do to one side you must also do to the other, so the scale never tips. Keep it balanced and strip away everything wrapped around the variable, one step at a time, until the variable stands alone.

Learning goals

  • Confirm a solution by substituting it into the original equation
  • Apply the properties of equality to write an equivalent equation
  • Undo the operations around the variable in reverse order with inverse moves
  • Distribute and combine like terms before isolating the variable
  • Collect the variable on one side when it appears on both

What a linear equation is

An equation is a statement that two expressions are equal, written with an equals sign between them, such as 3x−5=73x - 5 = 73x−5=7. A solution of an equation is a value of the variable that makes that statement true. You already have the tool for testing a candidate, namely substitution: replace the variable with the value and check whether the two sides come out equal.

Is x=4x = 4x=4 a solution of 3x−5=73x - 5 = 73x−5=7? Substitute and compute the left side:

3(4)−5=12−5=7.3(4) - 5 = 12 - 5 = 7.3(4)−5=12−5=7.

The left side equals 777, the same as the right, so x=4x = 4x=4 is a solution. The value x=2x = 2x=2 is not, because 3(2)−5=13(2) - 5 = 13(2)−5=1, which is not 777. Solving an equation means finding every value that passes this test.

This lesson is about linear equations in one variable: equations in which the variable appears only to the first power. It is never squared, never under a root, never in a denominator, so x2=9x^2 = 9x2=9, x=3\sqrt{x} = 3x​=3, and 6x=2\frac{6}{x} = 2x6​=2 all fall outside our scope for now. The linear equations you will solve in this lesson can be rearranged into the standard form

ax+b=c,ax + b = c,ax+b=c,

where aaa, bbb, and ccc are numbers and a≠0a \neq 0a=0, which gives exactly one solution. A few one-variable equations instead collapse to the special case a=0a = 0a=0, with either no solution or infinitely many; the next lesson handles those. Here the point is that the variable stands alone to the first power, which makes these the simplest equations to solve.

Keeping the balance: the properties of equality

That balance picture is the key to solving, because it tells you exactly which moves are legal. Change one pan alone and the scale tips, so the equation breaks. Change both pans by the same amount, and the beam stays level, so the equality survives.

Four such moves, the properties of equality, are the only tools you need. If a=ba = ba=b, then for any number ccc:

  • a+c=b+ca + c = b + ca+c=b+c (add the same amount to both sides),
  • a−c=b−ca - c = b - ca−c=b−c (subtract the same amount from both sides),
  • a⋅c=b⋅ca \cdot c = b \cdot ca⋅c=b⋅c (multiply both sides by the same nonzero number),
  • ac=bc\dfrac{a}{c} = \dfrac{b}{c}ca​=cb​ (divide both sides by the same nonzero number).

Each move produces a new equation, and the new equation has exactly the same solutions as the old one. Two equations with the same solution set are called equivalent. Solving works by walking through a chain of equivalent equations, each simpler than the last, until the variable stands alone. Here is why the moves preserve the solutions.

Why the same move on both sides keeps the same solutions#

Take x+3=8x + 3 = 8x+3=8, whose solution is x=5x = 5x=5: substituting gives 5+3=85 + 3 = 85+3=8, which checks. Subtract 333 from both sides, as in the balance above, and you get x=5x = 5x=5: the new equation still has 555 as its solution, and now the equation states that solution directly. That is no accident.

Call the left and right sides of any equation LLL and RRR, so the equation reads L=RL = RL=R. A value of the variable is a solution when it makes LLL and RRR come out equal.

Suppose x=sx = sx=s is a solution, so at x=sx = sx=s both sides equal the same number, call it kkk. Add the same amount ccc to each side: the left becomes k+ck + ck+c and the right becomes k+ck + ck+c, still the very same number, so sss still solves L+c=R+cL + c = R + cL+c=R+c. Adding ccc to both sides therefore never loses a solution.

It never gains one either, because the move undoes itself. Subtracting ccc from both sides of L+c=R+cL + c = R + cL+c=R+c returns you to L=RL = RL=R, by the same reasoning, so any solution of the new equation is a solution of the old one too. The two equations have exactly the same solutions, which is what it means for them to be equivalent.

The same argument works for multiplying or dividing both sides by a number ccc, as long as ccc is not zero. That condition matters: multiplying both sides by 000 turns any equation into 0=00 = 00=0, true for every value, so the step throws away all information about the variable and cannot be undone. That is the one move the balance forbids: add, subtract, multiply, or divide both sides by the same number, but never multiply or divide by zero.

∎

Isolating the variable

To solve is to transform the equation, one legal move at a time, into the form x=(a number)x = (\text{a number})x=(a number). The strategy is to undo the operations wrapped around the variable, in reverse order. Building an expression like 2x+32x + 32x+3 from xxx means first multiplying by 222 and then adding 333. To take that expression apart, you reverse both the operations and their order, subtracting 333 first and dividing by 222 last. Each undoing uses an inverse operation: addition and subtraction undo each other, and multiplication and division undo each other.

Applied to the standard form, this reverse-order idea always lands on a single value.

Why ax+b=cax + b = cax+b=c has the single solution x=c−bax = \dfrac{c - b}{a}x=ac−b​#

Take any linear equation in one variable, gathered into the standard form ax+b=cax + b = cax+b=c, where aaa, bbb, and ccc are numbers and a≠0a \neq 0a=0. Two moves isolate xxx, each one an application of the properties of equality.

First subtract bbb from both sides to strip away the constant:

ax+b−b=c−b,soax=c−b.ax + b - b = c - b, \qquad\text{so}\qquad ax = c - b.ax+b−b=c−b,soax=c−b.

Then divide both sides by aaa, which is legal precisely because a≠0a \neq 0a=0:

axa=c−ba,sox=c−ba.\frac{ax}{a} = \frac{c - b}{a}, \qquad\text{so}\qquad x = \frac{c - b}{a}.aax​=ac−b​,sox=ac−b​.

Because every step produced an equivalent equation, this value is the one and only solution. The formula itself is not worth memorizing; the two moves that built it are. Undo the added constant, then undo the multiplication by the coefficient, and any one-variable linear equation collapses to a single value of xxx.

∎

Worked example 1 Solve 2x+3=112x + 3 = 112x+3=11

Two operations wrap the variable: it is multiplied by 222, then 333 is added. Undo them in reverse order. First subtract 333 from both sides to peel off the constant:

2x+3−3=11−3,2x=8.2x + 3 - 3 = 11 - 3, \qquad 2x = 8.2x+3−3=11−3,2x=8.

Then divide both sides by 222, the coefficient of xxx:

2x2=82,x=4.\frac{2x}{2} = \frac{8}{2}, \qquad x = 4.22x​=28​,x=4.

Check the answer in the original equation, not in a later line where a slip might already hide:

2(4)+3=8+3=11.2(4) + 3 = 8 + 3 = 11.2(4)+3=8+3=11.

The left side equals 111111, matching the right, so x=4x = 4x=4 is correct.

Check your understanding

Solve 3x+7=223x + 7 = 223x+7=22.

Answer choices

Undo the operations in reverse: subtract 777 from both sides, then divide by 333.

3x=15,x=53x = 15, \qquad x = 53x=15,x=5

Checking in the original, 3(5)+7=15+7=223(5) + 7 = 15 + 7 = 223(5)+7=15+7=22, so x=5x = 5x=5.

Clearing parentheses and combining like terms

Most equations do not arrive in tidy standard form. They come with parentheses and with several like terms scattered on a side. So before you isolate the variable, you first simplify each side on its own, using the skills from the last two lessons. Distribute to clear any parentheses, then combine like terms, and only then start undoing operations. Keep the two jobs separate: finish simplifying a side before you move any term across the equals sign.

Worked example 2 Solve 2(x+3)+3x=262(x + 3) + 3x = 262(x+3)+3x=26

The left side has parentheses and two xxx terms, so tidy it before isolating anything. Distribute the 222 across the parentheses:

2(x+3)+3x=2x+6+3x.2(x + 3) + 3x = 2x + 6 + 3x.2(x+3)+3x=2x+6+3x.

Combine the like terms 2x2x2x and 3x3x3x:

2x+3x+6=5x+6.2x + 3x + 6 = 5x + 6.2x+3x+6=5x+6.

The equation is now the two-step 5x+6=265x + 6 = 265x+6=26. Subtract 666, then divide by 555:

5x=20,x=4.5x = 20, \qquad x = 4.5x=20,x=4.

Substituting back into the original, 2(4+3)+3(4)=14+12=262(4 + 3) + 3(4) = 14 + 12 = 262(4+3)+3(4)=14+12=26, which matches.

Variables on both sides

So far the variable has lived on one side. When it appears on both, as in 5x+2=3x+105x + 2 = 3x + 105x+2=3x+10, you cannot isolate it until it occupies a single side, and the subtraction property is what gets it there. Compare the coefficients of the two variable terms, 555 and 333, and subtract the term with the smaller coefficient, 3x3x3x, from both sides. On the right, 3x−3x=03x - 3x = 03x−3x=0, so the variable leaves that side entirely; on the left, 5x−3x=2x5x - 3x = 2x5x−3x=2x:

5x+2−3x=3x+10−3x,2x+2=10.5x + 2 - 3x = 3x + 10 - 3x, \qquad 2x + 2 = 10.5x+2−3x=3x+10−3x,2x+2=10.

What remains is an ordinary two-step equation. Subtracting the term with the smaller coefficient, 3x3x3x rather than 5x5x5x, is a deliberate choice. That choice leaves the variable with a positive coefficient, which heads off the sign slips that a negative coefficient invites. From there you solve as before, and the balance never tipped, because every term you removed left from both pans at once.

Worked example 3 Solve 7x−4=2x+117x - 4 = 2x + 117x−4=2x+11

The variable sits on both sides, so first collect it on one. The term with the smaller coefficient is 2x2x2x, so subtract 2x2x2x from both sides; it vanishes on the right and drops the left to 5x5x5x:

7x−4−2x=2x+11−2x,5x−4=11.7x - 4 - 2x = 2x + 11 - 2x, \qquad 5x - 4 = 11.7x−4−2x=2x+11−2x,5x−4=11.

Now it is an ordinary two-step equation. Add 444, then divide by 555:

5x=15,x=3.5x = 15, \qquad x = 3.5x=15,x=3.

Check in the original, evaluating each side on its own. The left is 7(3)−4=177(3) - 4 = 177(3)−4=17 and the right is 2(3)+11=172(3) + 11 = 172(3)+11=17. The two sides agree, so x=3x = 3x=3.

Check your understanding

Solve 6x−5=4x+96x - 5 = 4x + 96x−5=4x+9.

Answer choices

Subtract the term with the smaller coefficient, 4x4x4x, from both sides, then finish the two-step equation.

2x−5=9,2x=14,x=72x - 5 = 9, \qquad 2x = 14, \qquad x = 72x−5=9,2x=14,x=7

Both sides of the original equal 373737 at x=7x = 7x=7, since 6(7)−5=376(7) - 5 = 376(7)−5=37 and 4(7)+9=374(7) + 9 = 374(7)+9=37.

Putting the steps together

Every equation in this lesson, however tangled it looks, yields to the same ordered routine. Nothing in it is new; it just fixes the order in which to spend the tools you already have.

  1. Clear parentheses by distributing across each one.
  2. Combine like terms on each side separately.
  3. Collect the variable on one side and the constants on the other, using the addition and subtraction properties.
  4. Divide by the coefficient of the variable to leave it alone.
  5. Check by substituting the answer into the original equation.

The last step is not optional. A single arithmetic slip anywhere above produces a wrong value, and substituting back into the original equation is how you catch it. That check works because the original is the one line you know for certain was written correctly.

Worked example 4 Solve 4(x−1)=2(x+3)4(x - 1) = 2(x + 3)4(x−1)=2(x+3)

Both sides carry parentheses, so clear them first:

4x−4=2x+6.4x - 4 = 2x + 6.4x−4=2x+6.

Collect the variable on the left by subtracting the term with the smaller coefficient, 2x2x2x, from both sides:

2x−4=6.2x - 4 = 6.2x−4=6.

Add 444, then divide by 222:

2x=10,x=5.2x = 10, \qquad x = 5.2x=10,x=5.

Check: the left is 4(5−1)=164(5 - 1) = 164(5−1)=16 and the right is 2(5+3)=162(5 + 3) = 162(5+3)=16, so the solution is x=5x = 5x=5.

Worked example 5 Solve 23x+1=7\dfrac{2}{3}x + 1 = 732​x+1=7

A fractional coefficient is handled the same way; the inverse of multiplying by 23\frac{2}{3}32​ is multiplying by its reciprocal 32\frac{3}{2}23​. First subtract 111 from both sides:

23x=6.\frac{2}{3}x = 6.32​x=6.

Now multiply both sides by 32\frac{3}{2}23​ to undo the 23\frac{2}{3}32​:

32⋅23x=32⋅6,x=9.\frac{3}{2} \cdot \frac{2}{3}x = \frac{3}{2} \cdot 6, \qquad x = 9.23​⋅32​x=23​⋅6,x=9.

Check in the original: 23(9)+1=6+1=7\frac{2}{3}(9) + 1 = 6 + 1 = 732​(9)+1=6+1=7. Multiplying by the reciprocal turns a fractional coefficient into 111, which is why it isolates xxx in a single step.

Check your understanding

Solve 2(x+4)=3(x−1)2(x + 4) = 3(x - 1)2(x+4)=3(x−1).

Answer choices

Distribute on each side, then gather the variable on the side where its coefficient is larger.

2x+8=3x−3,8=x−3,x=112x + 8 = 3x - 3, \qquad 8 = x - 3, \qquad x = 112x+8=3x−3,8=x−3,x=11

Checking, 2(11+4)=302(11 + 4) = 302(11+4)=30 and 3(11−1)=303(11 - 1) = 303(11−1)=30, so x=11x = 11x=11.

Common mistakes

Common mistakes

  • Changing only one side. The single most common error is subtracting a number from the left and forgetting the right. Every move must land on both sides at once, or the new equation is no longer equivalent to the old one.
  • Sign slips when moving a term. Moving 3x3x3x to the other side means subtracting 3x3x3x from both sides, so it arrives with the opposite sign. Track the sign rather than just “jumping” the term across, and gather the variable on the side where its coefficient is larger, so that coefficient stays positive. This still works when both coefficients are negative: in 9−4x=1−2x9 - 4x = 1 - 2x9−4x=1−2x, compare −4-4−4 and −2-2−2. Since −2-2−2 is larger, keep the variable on that side by eliminating the smaller coefficient’s term, −4x-4x−4x: add 4x4x4x to both sides, leaving 9=1+2x9 = 1 + 2x9=1+2x with a positive coefficient.
  • Distributing to only part of the parentheses. 3(x+4)=3x+123(x + 4) = 3x + 123(x+4)=3x+12, not 3x+43x + 43x+4. The factor must reach every term inside before you go on, and a leading minus flips every inner term, so −(x−4)=−x+4-(x - 4) = -x + 4−(x−4)=−x+4.
  • Dividing only part of an equation. Dividing both sides by the same nonzero number is legal, but the number must divide every term on both sides, not just the one with the variable. Dividing 2x+6=202x + 6 = 202x+6=20 straight through by 222 correctly gives x+3=10x + 3 = 10x+3=10; dividing only the 2x2x2x gives the wrong equation x+6=20x + 6 = 20x+6=20. If that split is easy to miss, subtract 666 first to reach 2x=142x = 142x=14, then divide by 222.
  • Skipping the check, or checking a rewritten line. Always substitute your answer into the original equation. A later line may already carry the very mistake you are trying to catch.

Key takeaways

  • An equation states that two expressions are equal; a solution is a value that makes it true, confirmed by substitution.
  • A linear equation in one variable has the variable only to the first power and rearranges to the standard form ax+b=cax + b = cax+b=c with a≠0a \neq 0a=0.
  • The properties of equality let you add, subtract, multiply, or divide both sides by the same number (nonzero for multiply and divide). Each move produces an equivalent equation with the same solutions.
  • To solve, undo the operations around the variable in reverse order with inverse operations. Distribute and combine like terms first, then collect the variable on one side and the constants on the other, then divide by the coefficient.
  • With the variable on both sides, subtract the term with the smaller coefficient from both sides to bring the variable to one side.
  • Always check by substituting your answer into the original equation.

A bit of history (optional)

Copying out algebra used to be slow work. The word “equals” had to be written out in full, every single time it was needed. One worked problem might carry the phrase “is equalle to” a dozen times over, spelled in letters and never once in a sign.

Robert Recorde decided that was enough. He was a Welshman who wrote the first algebra book in English, and in 1557 he gave it the splendid title The Whetstone of Witte. Inside it he offered a mark that would spare him the repetition: two straight lines of equal length, one set above the other. He drew them far longer than we do, a stretched pair of rails running across the page.

The new sign did not sweep the field. For most of the next century authors and printers carried on with words, or with rival marks of their own invention. Recorde’s pair of lines won out slowly, and only because enough people found them convenient.

What they won was worth the wait. An equals sign is not an instruction to work something out. It is a claim that two descriptions name one and the same number. That claim is what licenses every move in this lesson. If both sides really are a single number, the same operation applied to both must leave them a single number still. That is why the balance never tips.
