  1. Problem 1 Two operations around one variable

    Solve 4x−7=−174x - 7 = -174x−7=−17, and check your value in the original equation.

    1. Hint 1

      Read 4x−74x - 74x−7 as a recipe carried out on xxx: one operation was applied first and one last. Solving runs the recipe backwards.

    2. Hint 2

      The last operation applied was subtracting 777, so undo it first by adding 777 to both sides. That leaves 4x4x4x alone on the left.

    3. Hint 3

      One more move, applied to both sides, undoes the multiplication by 444. The value need not be a whole number; check it in 4x−74x - 74x−7 itself.

    Answer

    x=−52x = -\tfrac{5}{2}x=−25​ (or −2.5-2.5−2.5); check: 4(−52)−7=−174(-\tfrac52) - 7 = -174(−25​)−7=−17.

    Full solution

    Building 4x−74x - 74x−7 from xxx multiplies by 444 and then subtracts 777.

    Undoing them in reverse order, the subtraction first, is the convenient order, because it leaves 4x4x4x on its own.

    It is not the only legal order.

    Add 777 to both sides:

    4x=−10.4x = -10.4x=−10.

    Divide both sides by 444, which is allowed because 444 is not zero:

    x=−104.x = -\frac{10}{4}.x=−410​.

    Simplify the fraction by dividing its top and bottom by 222:

    x=−52.x = -\frac{5}{2}.x=−25​.

    As a decimal, this is −2.5-2.5−2.5.

    Check in the original equation: 4(−52)=−104\left(-\tfrac{5}{2}\right) = -104(−25​)=−10, and −10−7=−17-10 - 7 = -17−10−7=−17, which matches the right side.

    Dividing by 444 first is legal too, but the division must reach every term, the 777 included.

    It gives x−74=−174x - \tfrac{7}{4} = -\tfrac{17}{4}x−47​=−417​, and adding 74\tfrac{7}{4}47​ to both sides then gives the same x=−52x = -\tfrac{5}{2}x=−25​, with more fractions along the way.

    Answer

    x=−52x = -\tfrac{5}{2}x=−25​ (or −2.5-2.5−2.5); check: 4(−52)−7=−174(-\tfrac52) - 7 = -174(−25​)−7=−17.

    Undo the operations around the variable in the reverse of the order they were applied, and let a property of equality license each move.

  2. Problem 2 A coefficient that is a fraction

    Solve 35x−4=8\dfrac{3}{5}x - 4 = 853​x−4=8, and check your value in the original equation.

    1. Hint 1

      A fractional coefficient is handled like a whole-number one: remove the constant first, then undo the multiplication with its inverse.

    2. Hint 2

      After adding 444 to both sides, a fraction of xxx equals a number. Which number, multiplied by 35\tfrac{3}{5}53​, gives exactly 111?

    Answer

    x=20x = 20x=20; check: 35(20)−4=8\tfrac35(20) - 4 = 853​(20)−4=8.

    Full solution

    Undo the operations in reverse order.

    The constant was attached last, so remove it first by adding 444 to both sides:

    35x=12.\frac{3}{5}x = 12.53​x=12.

    Now xxx is multiplied by 35\tfrac{3}{5}53​.

    That coefficient is not zero, so it has a reciprocal, 53\tfrac{5}{3}35​; zero has no reciprocal, which is why this move needs a nonzero coefficient.

    Multiply both sides by 53\tfrac{5}{3}35​.

    On the left, 53⋅35=1\tfrac{5}{3} \cdot \tfrac{3}{5} = 135​⋅53​=1, which leaves 1⋅x1 \cdot x1⋅x, that is, xxx.

    On the right,

    53⋅12=20.\tfrac{5}{3} \cdot 12 = 20.35​⋅12=20.

    So x=20x = 20x=20.

    Check in the original equation: 35(20)=12\tfrac{3}{5}(20) = 1253​(20)=12, and 12−4=812 - 4 = 812−4=8, which matches the right side.

    Multiplying both sides by 53\tfrac{5}{3}35​ is the multiplication property of equality, allowed because 53\tfrac{5}{3}35​ is not zero.

    Dividing both sides by 35\tfrac{3}{5}53​, the division property of equality, is the same move under another name, because dividing by a nonzero number means multiplying by its reciprocal.

    Answer

  5. Problem 5 Keeping a balance level

    A balance scale is level. Its left pan holds four identical bags of flour and a 222 kg weight, and its right pan holds a single bag of the same kind and an 111111 kg weight. Writing bbb for the weight of one bag in kilograms, the level scale says

    4b+2=b+11.4b + 2 = b + 11.4b+2=b+11.

    Solve for bbb, describing each move as something done to the two pans, and check your value by finding what each pan weighs. Then explain why a move made with the bags can keep the scale level even though nobody yet knows what a bag weighs.

    1. Hint 1

      Removing equal weights from the two pans keeps the scale level.

    2. Hint 2

      Lift a bag off each pan so that bags remain on the left only. Then take the loose weight off both pans, and share out what is left.

    3. Hint 3

      A letter stands for one definite number, even while you do not know it. Ask whether both pans lose the same weight when a bag comes off each.

    Answer

    b=3b = 3b=3: each bag weighs 333 kg; check: each pan weighs 141414 kg. Moves: a bag off each pan, 222 kg off each pan, then a third of each pan kept.

    Full solution

    Collect the bags on the left, where there are more of them.

    Subtracting bbb from both sides is lifting one bag off each pan:

    4b+2−b=b+11−b.4b + 2 - b = b + 11 - b.4b+2−b=b+11−b.

    Combining like terms on each side leaves

    3b+2=11.3b + 2 = 11.3b+2=11.

    Subtracting 222 from both sides is taking 222 kg off each pan:

    3b=9.3b = 9.3b=9.

    Dividing both sides by 333 is keeping a third of what is on each pan, one of the three bags on the left and 333 kg of the 999 kg on the right.

    That leaves b=3b = 3b=3.

    Check against the scale as described: the left pan holds 4(3)+2=144(3) + 2 = 144(3)+2=14 kg and the right pan holds 3+11=143 + 11 = 143+11=14 kg.

    The pans balance, so each bag weighs 333 kg.

    The weight of a bag is unknown to us, but it is not undecided: every bag weighs the same definite number of kilograms, and bbb names that number.

    The pans hold equal weights before the move.

    Lifting one bag off each takes the same weight, bbb kg, from both, and equal amounts with the same amount removed stay equal.

    That is the subtraction property of equality, used with the number bbb.

    Answer

    b=3b = 3b=3: each bag weighs 333 kg; check: each pan weighs 141414 kg. Moves: a bag off each pan, 222 kg off each pan, then a third of each pan kept.

    Key idea

    Removing equal weights from both pans, like subtracting the same number from both sides, keeps the balance level even when the weight of a bag is unknown.

    Substituting x=5x = 5x=5 into the lines agrees with the verdicts: lines A and C balance, at 333 and 161616, while line B gives 262626 against 666 and line D gives 333 against 111111.

    A: same (both sides divided by 222). B: not (the 666 must also multiply the 444, giving 6x−246x - 246x−24). C: same (2x2x2x added to both sides). D: not (the 161616 was left unhalved). The solution is x=5x = 5x=5, where both sides equal 666.

    Key idea

    A step keeps the solutions when it applies one legal move to both whole sides or rewrites a side as an equal expression; a move that reaches only part of a side can change them.

  10. Problem 10 Putting an equation together

    Start from the statement x=−2x = -2x=−2. Apply exactly two properties of equality to build an equation of the form ax+b=cax + b = cax+b=c: first multiply or divide both sides by a nonzero number, then add or subtract a number. Write the equation after each move, and name the property you used.

    Explain why the equation you built has no solution other than −2-2−2. Then explain why multiplying both sides by 000 is not allowed as one of the moves.

    1. Hint 1

      Building runs the solving moves forwards. Every legal move (adding or subtracting a number, multiplying or dividing by a nonzero number) can be run backwards by the opposite move.

    2. Hint 2

      Multiply both sides of x=−2x = -2x=−2 by a nonzero number of your choice, then add a number of your choice to both sides.

    3. Hint 3

      Work out what multiplying both sides of any equation by 000 produces, and which numbers make the result true.

    Answer

    One build: multiply by 333 (multiplication property), 3x=−63x = -63x=−6; add 555 (addition property), 3x+5=−13x + 5 = -13x+5=−1. Any nonzero multiplier and any added number work. Only −2-2−2 solves it. Multiplying by 000 gives 0=00 = 00=0, true for every number.

    Full solution

    Start from the statement whose solution is to be kept, and apply each move to both sides.

    Multiply both sides by 333, the multiplication property of equality used with the nonzero number 333:

    3x=−6.3x = -6.3x=−6.

    Add 555 to both sides, the addition property of equality used with 555:

    3x+5=−1.3x + 5 = -1.3x+5=−1.

    The result has the form ax+b=cax + b = cax+b=c, with a=3a = 3a=3, b=5b = 5b=5 and c=−1c = -1c=−1.

    Substituting −2-2−2 confirms the build:

    3(−2)+5=−1.3(-2) + 5 = -1.3(−2)+5=−1.

    Any nonzero multiplier and any added number would do as well, so there are many correct builds.

    Each move can be run backwards.

    Subtracting 555 from both sides undoes the addition, and dividing both sides by 333 undoes the multiplication, which is allowed because 333 is not zero.

    Read forwards, the moves show that −2-2−2 satisfies the built equation.

    Read backwards, they show that any number satisfying the built equation also satisfies x=−2x = -2x=−2.

    That statement is true for one number only, so the built equation is too.

    Multiplying both sides of any equation by 000 produces 0=00 = 00=0, which every number satisfies.

    Applied to the built equation, it would gain every other number as a solution.

    The step cannot be undone either, because every equation leads to the same line 0=00 = 00=0, so nothing tells you which equation it came from.

    That is why the multiplication and division properties require a nonzero number.

    Answer

    One build: multiply by 333 (multiplication property), 3x=−63x = -63x=−6; add 555 (addition property), 3x+5=−13x + 5 = -13x+5=−1. Any nonzero multiplier and any added number work. Only −2-2−2 solves it. Multiplying by 000 gives 0=00 = 00=0, true for every number.

    Key idea

    A legal move keeps the solutions because it can be undone; multiplying by zero cannot be undone, so it is not a legal move.
