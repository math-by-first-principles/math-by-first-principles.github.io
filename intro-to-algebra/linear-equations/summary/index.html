Linear Equations: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Equation and solution
An equation claims two expressions are equal. A solution is a value making that claim true, confirmed by substituting it into the original equation.
Linear equation in one variable, standard form ax+b=cax + b = cax+b=c
The variable appears only to the first power: no square, no root, no variable denominator. With a≠0a \neq 0a=0 there is exactly one solution.
Equivalent equations
Equations with exactly the same solutions. Reversible solving steps keep equations equivalent on the original allowed inputs; retain every original denominator restriction.
Inverse operations, undone in reverse order
Operations that undo each other: addition and subtraction, or multiplication and division by a nonzero number. Undo the last operation around the variable first.
Least common denominator (LCD)
For positive whole-number denominators, the smallest positive whole number divisible by all of them. For algebraic fractions, the smallest expression every denominator divides into; keep the original excluded values.
Proportion ab=cd\dfrac{a}{b} = \dfrac{c}{d}ba​=dc​
An equation stating that two ratios are equal, with b≠0b \neq 0b=0 and d≠0d \neq 0d=0.
Excluded value
A value making a denominator zero, so the equation is undefined there.
Contradiction
An equation true for no allowed value of the variable. When the variable cancels after reversible steps, a false statement such as 2=52 = 52=5 shows this.
Identity
An equation true for every allowed value. With no excluded values, reaching a true statement such as 4=44 = 44=4 by reversible steps means all real numbers are solutions.
Literal equation
An equation with more than one letter, such as A=lwA = lwA=lw or d=rtd = rtd=rt. Most formulas are literal equations.
Solving for a variable
Rewriting a literal equation so one chosen letter stands alone, every other letter treated as a fixed but unknown number.
Consecutive integers
Integers stepping by 111: nnn, n+1n + 1n+1, n+2n + 2n+2. Consecutive even or odd integers step by 222: nnn, n+2n + 2n+2, n+4n + 4n+4, with an even or odd starting integer as required.

Formulas and theorems

  • Properties of equality

    If a=b, then:a+c=b+ca−c=b−cac=bcac=bc\begin{gathered} \text{If } a = b, \text{ then:} \\ a + c = b + c \\ a - c = b - c \\ ac = bc \\ \frac{a}{c} = \frac{b}{c} \end{gathered}If a=b, then:a+c=b+ca−c=b−cac=bcca​=cb​​
    Text description

    A level balance beam whose left pan holds a plus c and whose right pan holds b plus c.

    Use when Adding or subtracting the same quantity, defined at every originally allowed input, preserves the solutions. A multiplier must be defined and nonzero at every originally allowed input to make multiplication reversible. Division is defined only with a nonzero divisor, so the same condition applies. For example, multiplying by x−3x - 3x−3 cannot be undone at x=3x = 3x=3. Retain original denominator restrictions.

  • Solution of the standard form

    ax+b=c⟹x=c−baax + b = c \quad\Longrightarrow\quad x = \frac{c - b}{a}ax+b=c⟹x=ac−b​

    Use when Fixed numbers aaa, bbb, ccc, with a≠0a \neq 0a=0. Subtract bbb, then divide by aaa.

    e.g. 5x+6=265x + 6 = 265x+6=26 gives x=26−65=4x = \frac{26 - 6}{5} = 4x=526−6​=4.

  • How many solutions

    Gather variable terms on one side and constants on the other, leaving ax=bax = bax=b. If a≠0a \neq 0a=0: one solution, x=bax = \frac{b}{a}x=ab​. If a=0a = 0a=0 and b≠0b \neq 0b=0: none. If a=0a = 0a=0 and b=0b = 0b=0: infinitely many, every real number.

    Use when These are the solutions of the cleared equation. They transfer without exclusions when every clearing multiplier was a nonzero number. For variable denominators, reject excluded candidates; an identity means all original allowed values.

    e.g. 4x+2=4x+54x + 2 = 4x + 54x+2=4x+5 collapses to 2=52 = 52=5, false, so no solution.

  • Clearing fractions with the LCD

    Multiply every term on both sides by the LCD, including terms without fractions. Keep a sum numerator in parentheses.

    Use when A nonzero numerical LCD gives a reversible step. For a variable denominator, list the original excluded values first and keep them after clearing.

  • Clearing decimals with a power of ten

    Multiply every term on both sides by a power of ten that makes all coefficients and constants integers.

    Use when Terminating decimals. Use 10k10^k10k, where kkk is the greatest number of decimal places present. The multiplier is nonzero.

    e.g. 0.5x−0.2=0.1x+10.5x - 0.2 = 0.1x + 10.5x−0.2=0.1x+1 times 101010 gives 5x−2=x+105x - 2 = x + 105x−2=x+10, so x=3x = 3x=3.

  • Cross-multiplication

    ab=cd⟺ad=bc\frac{a}{b} = \frac{c}{d} \quad\Longleftrightarrow\quad ad = bcba​=dc​⟺ad=bc

    Use when b≠0b \neq 0b=0 and d≠0d \neq 0d=0; the move is multiplying both sides by bdbdbd.

    e.g. x6=x+49\frac{x}{6} = \frac{x+4}{9}6x​=9x+4​ gives 9x=6(x+4)9x = 6(x + 4)9x=6(x+4), so x=8x = 8x=8.

  • Excluded values

    Set each denominator holding the variable equal to zero; those values are excluded. Solve, then reject any answer equal to an excluded value.

    Text description

    A number line from zero to five with the point at three punched out and marked excluded.

    Use when Use the original denominators. Multiplication by a variable denominator reverses only where that denominator is nonzero.

    e.g. xx−3=3x−3\frac{x}{x-3} = \frac{3}{x-3}x−3x​=x−33​ clears to x=3x = 3x=3, the excluded value, so there is no solution.

  • Ages at another time

    In kkk years every age is kkk larger; kkk years ago every age was kkk smaller.

    Use when Use the given relationship to express present ages, then add or subtract the same number of years from every age. Check that the resulting ages fit the situation.

    e.g. Maria is 4b4b4b and her brother bbb; in 666 years 4b+6=2(b+6)4b + 6 = 2(b + 6)4b+6=2(b+6), so b=3b = 3b=3.

  • Distance, rate, time

    d=rtd = rtd=rt

    Use when A constant rate, units matched. Rearranged, r=dtr = \frac{d}{t}r=td​ needs t≠0t \neq 0t=0 and t=drt = \frac{d}{r}t=rd​ needs r≠0r \neq 0r=0. Along a straight route from one starting point, opposite-direction separation is the sum of the distances; same-direction separation is the larger distance minus the smaller. Catching up means equal distances from that point. Use each traveler's own elapsed time, including a time head start only when given.

    e.g. Two riders leave the same point together at 121212 and 161616 mph in opposite directions. They are 707070 miles apart when 12t+16t=7012t + 16t = 7012t+16t=70, where ttt is hours since departure, so t=2.5t = 2.5t=2.5 hours.

  • Total value of a collection

    value of one kind=(number of items)× (value of each)\begin{gathered} \text{value of one kind} = \\ (\text{number of items}) \\ \times\ (\text{value of each}) \end{gathered}value of one kind=(number of items)× (value of each)​

    Use when Items have the same unit value within each kind. Add the values of the different kinds to find the total; use one unit throughout, such as cents. Coin counts must be nonnegative whole numbers.

    e.g. 303030 coins, nickels and dimes, worth 245245245 cents: 5n+10(30−n)=2455n + 10(30 - n) = 2455n+10(30−n)=245, so n=11n = 11n=11 nickels.

  • Percent translation

    p%p\%p% of a quantity is p100\frac{p}{100}100p​ times it; "of" multiplies and "is" often marks equality. A p%p\%p% discount leaves (100−p)%(100 - p)\%(100−p)% of the price. A p%p\%p% increase gives (100+p)%(100 + p)\%(100+p)% of the original amount.

    Text description

    A price bar split into a p percent discount and the 100 minus p percent you actually pay.

    Use when Convert the percent to a fraction or decimal. A discount assumes 0≤p≤1000 \le p \le 1000≤p≤100; an increase uses p≥0p \ge 0p≥0. Use the original amount as the base.

    e.g. 343434 is 85%85\%85% of ttt means 0.85t=340.85t = 340.85t=34, so t=40t = 40t=40.

Problem types, step by step

Solve a multi-step linear equation

  1. Distribute and combine like terms on each side; work through nested groups from inside out.
  2. If the variable appears on both sides, subtract one variable term from both. When the coefficients differ, choosing the smaller one leaves a positive coefficient.
  3. Add or subtract to collect constants on the other side.
  4. Divide by the nonzero coefficient. If the variable cancels, decide whether the remaining statement is true or false.
  5. Check by substituting into the original equation.

e.g. 4(x−1)=2(x+3)4(x - 1) = 2(x + 3)4(x−1)=2(x+3): 4x−4=2x+64x - 4 = 2x + 64x−4=2x+6, so 2x=102x = 102x=10 and x=5x = 5x=5.

Solve an equation with fractions or decimals

  1. Record any values that make an original denominator zero. Choose the LCD for fractions, or a power of ten that clears all terminating decimals.
  2. Multiply every term on both sides by it, keeping sum numerators in parentheses.
  3. Distribute each multiplier, including any minus sign, to every term in its group.
  4. Keep all original restrictions when solving the resulting equation and checking in the original. For an identity, every original allowed value works.

e.g. x+12−x−35=2\frac{x+1}{2} - \frac{x-3}{5} = 22x+1​−5x−3​=2 times 101010: 5(x+1)−2(x−3)=205(x+1) - 2(x-3) = 205(x+1)−2(x−3)=20, so 3x+11=203x + 11 = 203x+11=20 and x=3x = 3x=3.

Solve a proportion, or an equation with the variable in a denominator

  1. Set each denominator holding the variable to zero and record the excluded values.
  2. If both sides share one denominator, multiply both sides by it. For one ratio equal to another with different denominators, cross-multiply. Otherwise multiply every term by the LCD.
  3. Use this method when the cleared equation collects to ax=bax = bax=b with fixed numbers aaa and bbb. Solve it, or decide whether it reduces to a true or false statement.
  4. Keep all original denominator restrictions. Reject excluded candidates; if clearing gives an identity, all original allowed values work. Check in the original.

e.g. x+1x−2=3\frac{x+1}{x-2} = 3x−2x+1​=3 with x≠2x \neq 2x=2: x+1=3x−6x + 1 = 3x - 6x+1=3x−6, so x=72x = \frac{7}{2}x=27​, which is allowed.

Decide whether an equation has one solution, no solution, or infinitely many

  1. Record any denominator exclusions, then clear fractions or decimals and simplify.
  2. Collect variable terms on one side and constants on the other.
  3. A nonzero variable coefficient gives one candidate. Reject it if excluded.
  4. If the variable cancels, a false statement means no solution; a true one means every original allowed value.

e.g. 5x−(x−4)=4(x+1)5x - (x - 4) = 4(x + 1)5x−(x−4)=4(x+1) leaves 4=44 = 44=4, which is true, so every real number is a solution.

Solve a formula for a chosen variable that appears once

  1. Treat every other letter as a fixed but unknown number.
  2. Undo the operations around the target in reverse order. For a multiplied group, undo the outer multiplication before the addition or subtraction inside. Undo a nonzero fractional multiplier by multiplying by its reciprocal. If the target is in a denominator, record that the denominator must be nonzero and clear it before continuing to isolate the target.
  3. Keep a multi-term side whole over the divisor instead of dividing one term of it.
  4. State nonzero divisor conditions, retain original restrictions, and check with simple numbers. A successful check alone is not a general proof.

e.g. C=59(F−32)C = \frac{5}{9}(F - 32)C=95​(F−32): multiply by 95\frac{9}{5}59​ for 95C=F−32\frac{9}{5}C = F - 3259​C=F−32, so F=95C+32F = \frac{9}{5}C + 32F=59​C+32.

Solve a formula for a variable that appears in two or more terms

  1. If the target is in a denominator, record that the denominator must be nonzero and clear it first. Then move every term containing the target to one side.
  2. Factor the target out; a lone copy leaves a 111 behind.
  3. If the remaining factor is nonzero, divide both sides by it.
  4. State the nonzero condition and keep original restrictions. If the factor is zero, inspect the original equation separately.

e.g. ax=bx+cax = bx + cax=bx+c: x(a−b)=cx(a - b) = cx(a−b)=c, so x=ca−bx = \frac{c}{a - b}x=a−bc​ provided a≠ba \neq ba=b.

Translate a word problem into one equation and solve it

  1. Find the question and decide which quantity is wanted.
  2. Name one unknown and write what it stands for, units included.
  3. Where the given relationships permit one unknown, express every other quantity in terms of that letter.
  4. Translate the sentence saying two quantities are equal, and solve.
  5. Check against the words, including positive lengths and whole-number counts where required. Report the quantity asked for with units.

e.g. Perimeter 363636 cm, length 2w+32w + 32w+3: 2((2w+3)+w)=362\big((2w + 3) + w\big) = 362((2w+3)+w)=36 gives w=5w = 5w=5, so 555 cm by 131313 cm.

Set up a two-part total-value problem

  1. Let the variable measure one part; the other is the total minus it, such as 20−q20 - q20−q coins.
  2. Multiply each part by its unit value: coin counts by cents per coin, or pounds by dollars per pound. Keep the units consistent.
  3. Set the sum of those products equal to the total value: the given total, or for a mixture, its total weight times its price per pound.
  4. Solve, report both parts, and check the total. Amounts must be nonnegative; coin counts must also be whole numbers.

e.g. For a total of 202020 coins (quarters and dimes) worth 365365365 cents, let qqq count quarters: 25q+10(20−q)=36525q + 10(20-q) = 36525q+10(20−q)=365 gives q=11q = 11q=11, so there are 111111 quarters and 999 dimes.

Exam traps

  • Trap Multiplying only the fractions by the LCD and leaving a whole-number term alone.

    Fix The multiplier hits every term on both sides: x2+x3=5\frac{x}{2} + \frac{x}{3} = 52x​+3x​=5 times 666 is 3x+2x=303x + 2x = 303x+2x=30, not 3x+2x=53x + 2x = 53x+2x=5.

  • Trap Letting a minus sign reach only the first term of a grouped numerator or parenthesis.

    Fix A fraction bar groups its numerator, so −x−35-\frac{x-3}{5}−5x−3​ times 101010 is −2(x−3)=−2x+6-2(x - 3) = -2x + 6−2(x−3)=−2x+6, not −2x−6-2x - 6−2x−6; likewise −(x−4)=−x+4-(x - 4) = -x + 4−(x−4)=−x+4.

  • Trap Cross-multiplying when a side is a sum of fractions or carries an extra term.

    Fix Cross-multiplication belongs to ab=cd\frac{a}{b} = \frac{c}{d}ba​=dc​ alone. Anything else: clear with the LCD first, then solve.

  • Trap Reading a canceled variable as x=0x = 0x=0.

    Fix A false statement such as 2=52 = 52=5 means no solution. A true statement such as 4=44 = 44=4 means every allowed value works. Original denominator exclusions still apply.

  • Trap Trusting the one, none, or infinitely many verdict after clearing a denominator that held the variable.

    Fix A nonzero numerical multiplier reverses for every input. Clearing a variable denominator reverses only at allowed inputs: xx−3=3x−3\frac{x}{x-3} = \frac{3}{x-3}x−3x​=x−33​ gives the excluded candidate x=3x = 3x=3, so the equation has no solution.

  • Trap Dividing only the first term of a multi-term side by the coefficient.

    Fix 2w=P−2l2w = P - 2l2w=P−2l gives w=P−2l2w = \frac{P - 2l}{2}w=2P−2l​, which is P2−l\frac{P}{2} - l2P​−l, never P2−2l\frac{P}{2} - 2l2P​−2l. Every term crosses the division.

  • Trap Factoring the target out and losing the invisible 111.

    Fix Since P=P⋅1P = P \cdot 1P=P⋅1, A=P+PrtA = P + PrtA=P+Prt becomes A=P(1+rt)A = P(1 + rt)A=P(1+rt). Thus P=A1+rtP = \frac{A}{1 + rt}P=1+rtA​ when 1+rt≠01 + rt \neq 01+rt=0. The expression Art\frac{A}{rt}rtA​ drops the needed 111 from the denominator. Expand to check the factoring.

  • Trap Translating "less than" and "more than" in the order the words arrive.

    Fix "555 less than xxx" is x−5x - 5x−5, not 5−x5 - x5−x; the amount taken away comes second. "333 less than twice a number" is 2n−32n - 32n−3. Addition can be reordered, but subtraction cannot.

  • Trap Applying a move to one side only, such as subtracting 666 from the left of 2x+6=202x + 6 = 202x+6=20 and leaving the right untouched.

    Fix That leaves 2x=202x = 202x=20 and the wrong answer x=10x = 10x=10; subtracting 666 from both sides leaves 2x=142x = 142x=14, so x=7x = 7x=7. Adding, subtracting, multiplying, or dividing applies to both whole sides, with the nonzero conditions for multiplication and division. Rewriting either side as an equal expression is also legal.
