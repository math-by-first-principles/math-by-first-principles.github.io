    A number increased by 555 equals 121212. What is the number?

    Answer choices for question 1

    Solution

    Correct answer: B

    Let nnn be the number. Adding 555 to it gives 121212, so set up and solve the equation.

    n+5=12,n=7n + 5 = 12, \qquad n = 7n+5=12,n=7

    Check: 7+5=127 + 5 = 127+5=12, so the number is 777.

    Twice a number is 181818. What is the number?

    Answer choices for question 2

    Solution

    Correct answer: C

    Let nnn be the number. Twice the number is 2n2n2n, and it equals 181818.

    2n=18,n=92n = 18, \qquad n = 92n=18,n=9

    Check: 2×9=182 \times 9 = 182×9=18, so the number is 999.

    Two consecutive integers sum to 232323. What is the smaller integer?

    Answer choices for question 3

    Solution

    Correct answer: C

    Let nnn be the smaller integer, so the next one is n+1n + 1n+1. Their sum is 232323.

    n+(n+1)=23,2n+1=23,n=11n + (n + 1) = 23, \qquad 2n + 1 = 23, \qquad n = 11n+(n+1)=23,2n+1=23,n=11

    The integers are 111111 and 121212, and 11+12=2311 + 12 = 2311+12=23, so the smaller is 111111.

    A pencil costs 222 dollars. Which expression gives the cost, in dollars, of ppp pencils?

    Answer choices for question 5

    Solution

    Correct answer: D

    The total cost is the number of pencils times the price of each, and each pencil costs 222 dollars.

    2×p=2p2 \times p = 2p2×p=2p

    So ppp pencils cost 2p2p2p dollars.

  6. 6

    Which equation models: the sum of two consecutive integers, the smaller being nnn, is 474747?

    Answer choices for question 6

    Solution

    Correct answer: D

    Consecutive integers step by 111, so if the smaller is nnn, the next is n+1n + 1n+1. Their sum is 474747.

    n+(n+1)=47n + (n + 1) = 47n+(n+1)=47

    The gap between consecutive integers is 111, which is why the second integer is n+1n + 1n+1.

    A rectangle is twice as long as it is wide, with perimeter 242424 cm. How wide is it?

    Answer choices for question 7

    Solution

    Correct answer: C

    Let www be the width in centimeters, so the length is 2w2w2w. The perimeter is twice the sum of length and width.

    2(2w+w)=24,6w=24,w=42(2w + w) = 24, \qquad 6w = 24, \qquad w = 42(2w+w)=24,6w=24,w=4

    Check: with width 444 and length 888, the perimeter is 2(8+4)=242(8 + 4) = 242(8+4)=24 cm, so the width is 444 cm.

    In xxx years, Ana (now 121212) will be 202020. Which equation models this?

    Answer choices for question 9

    Solution

    Correct answer: A

    Let xxx be the number of years from now. In xxx years Ana is xxx years older, so her age is 12+x12 + x12+x, and that equals 202020.

    12+x=2012 + x = 2012+x=20

    Solving gives x=8x = 8x=8, so the equation is 12+x=2012 + x = 2012+x=20.
