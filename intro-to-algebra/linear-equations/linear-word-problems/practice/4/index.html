    Two angles are complementary, so they sum to 909090 degrees. One is 181818 degrees more than the other. What is the larger angle?

    Answer choices for question 5

    Solution

    Correct answer: D

    Let nnn be the smaller angle in degrees, so the larger is n+18n + 18n+18. Complementary angles sum to 909090.

    n+(n+18)=90,2n+18=90,n=36n + (n + 18) = 90, \qquad 2n + 18 = 90, \qquad n = 36n+(n+18)=90,2n+18=90,n=36

    The smaller is 363636 and the larger is 36+18=5436 + 18 = 5436+18=54 degrees; check 36+54=9036 + 54 = 9036+54=90.

    Solution

  9. 9

    A rectangle's length is 777 cm more than its width www. Which equation says its perimeter is 505050 cm?

    Answer choices for question 9

    Solution

    Correct answer: A

    The width is www and the length is w+7w + 7w+7. The perimeter adds two widths and two lengths.

    2w+2(w+7)=502w + 2(w + 7) = 502w+2(w+7)=50

    The second choice is only one width plus one length (half the perimeter), so the correct model is 2w+2(w+7)=502w + 2(w + 7) = 502w+2(w+7)=50.

    Check: 2(8+3)=222(8 + 3) = 222(8+3)=22, so the number is 888.
