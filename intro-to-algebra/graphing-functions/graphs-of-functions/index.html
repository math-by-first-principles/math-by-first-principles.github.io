Graphs of Functions

Intuition

In recent chapters you graphed equations like y=2x−1y = 2x - 1y=2x−1 and y=x2−2x−3y = x^2 - 2x - 3y=x2−2x−3 by finding solution points and plotting them. Now that a rule has a name, fff, the same picture becomes something more powerful. The graph of a function collects every input together with the output it produces, so a single picture holds the whole function at once. Better still, you can run the picture both ways: point to a place on the horizontal axis and the height of the curve there tells you the output. Point to a height instead, and read off which inputs reach it. This lesson shows how to build such a graph and, more useful still, how to read a function’s value, its intercepts, and its domain and range. It shows where the function climbs or falls too, and all of that comes straight off the picture, often with no algebra at all.

Learning goals

  • Read the graph as every pair (x,f(x))(x, f(x))(x,f(x))
  • Build a graph from a table of inputs and outputs
  • Find f(a)f(a)f(a) by moving up or down to the curve and across
  • Locate any intercepts, where the graph meets an axis
  • Take the domain as horizontal spread and the range as vertical
  • Say where a function increases, decreases, and turns

The graph of a function is a picture of every input and output

Take f(x)=x2−2x−3f(x) = x^2 - 2x - 3f(x)=x2−2x−3 from the callout above. The input 222 gives f(2)=4−4−3=−3f(2) = 4 - 4 - 3 = -3f(2)=4−4−3=−3, so the graph includes the point (2,−3)(2, -3)(2,−3). Every other allowed input produces another point the same way, and together all of those points make up the graph.

The graph of a function fff is the set of all points (x,f(x))(x, f(x))(x,f(x)) as xxx runs over the domain of fff. Read that pairing carefully: the first coordinate of each point is an input, and the second coordinate is the output the function assigns to it. Setting y=f(x)y = f(x)y=f(x) says the same thing in the language of the last chapters, because then each allowed input xxx gives exactly one point (x,y)(x, y)(x,y) with y=f(x)y = f(x)y=f(x). So graphing a function is nothing new. It is graphing the equation y=f(x)y = f(x)y=f(x), and every technique you built for lines and parabolas carries straight over. What is new is everything the finished picture now lets you read.

The single most useful fact is this. The second coordinate of every point on the graph is an output. So the height of the graph above an input aaa, measured against the vertical axis, is exactly f(a)f(a)f(a). The function pairs aaa with one output, so there is exactly one point of the graph directly above (or below) each input in the domain. That single point is why “the height at x=ax = ax=a” names one definite number. That is the vertical line test from the What Is a Function? lesson, seen from the reading side. Each vertical line meets the graph at most once, and where it does, the height it reaches is the output.

A point (a,b)(a, b)(a,b) lies on the graph exactly when b=f(a)b = f(a)b=f(a), because the graph’s point at input aaa is (a,f(a))(a, f(a))(a,f(a)). Set bbb to the height of the graph above aaa, and that says the height is f(a)f(a)f(a). Fix a height bbb instead, and it says the inputs whose output is bbb are exactly the xxx where the horizontal line y=by = by=b crosses the graph. That one fact is behind every reading below.

This holds for every input in the domain, not just the one pictured next. Read the full argument in the Go deeper section at the end of this lesson.

Building a graph from a table

To draw a function’s graph, use the routine you already trust for lines and parabolas. Choose several inputs, evaluate fff at each to get the matching output, then plot the points (x,f(x))(x, f(x))(x,f(x)). A table only pins down the points you compute; it is the rule itself, not the sample, that decides what happens between them. Join the points with a ruler when you already know the rule is linear, or with a smooth parabola when you already know it is quadratic, as in the next example. A small spread of inputs, including a negative, zero, and a few positives, is enough to see that known shape clearly.

Worked example 1 Graph f(x)=x2−2x−3f(x) = x^2 - 2x - 3f(x)=x2−2x−3 from a table

The rule squares the input, subtracts twice the input, then subtracts 333. Because the highest power of xxx is a square, you already know the graph will be a parabola. Pick a spread of inputs and evaluate, keeping the parentheses so the signs are safe.

Reading a value off the graph

Two questions come up again and again, and the graph answers both by tracing a straight path to an axis.

Finding f(a)f(a)f(a) from the picture. Locate the input aaa on the horizontal axis, move straight up or down until you meet the curve, then read the height there against the vertical axis. That height is f(a)f(a)f(a), because the point you land on is (a,f(a))(a, f(a))(a,f(a)).

Solving f(x)=bf(x) = bf(x)=b from the picture. This asks the reverse question: which inputs produce the output bbb. Locate the value bbb on the vertical axis, move straight across to the curve, and read the input below each meeting point. Every such input xxx satisfies f(x)=bf(x) = bf(x)=b. A horizontal line can cross a curve more than once, so an equation f(x)=bf(x) = bf(x)=b can have several solutions, one solution, or none. The picture shows exactly which case you are in.

Worked example 2 Reading f(2)f(2)f(2) and solving f(x)=−3f(x) = -3f(x)=−3 from the graph

Use the graph of f(x)=x2−2x−3f(x) = x^2 - 2x - 3f(x)=x2−2x−3 above, without any algebra.

To find f(2)f(2)f(2), start at x=2x = 2x=2 on the horizontal axis and move straight down to the curve. You land on the point (2,−3)(2, -3)(2,−3), whose height is −3-3−3, so

f(2)=−3.f(2) = -3.f(2)=−3.

To solve f(x)=−3f(x) = -3f(x)=−3, do the reverse. Find −3-3−3 on the vertical axis and slide across the horizontal line y=−3y = -3y=−3. It meets the parabola at two points, the ones sitting above x=0x = 0x=0 and above x=2x = 2x=2. Reading the input beneath each gives the two solutions

The same value −3-3−3 is an output of the function at two different inputs, which is why the horizontal line crosses twice. A quick check confirms both: f(0)=−3f(0) = -3f(0)=−3 and f(2)=4−4−3=−3f(2) = 4 - 4 - 3 = -3f(2)=4−4−3=−3.

Intercepts and where the graph meets the axes

Two special readings come up so often that they have their own names.

The y-intercept is the point where the graph meets the vertical axis. Every point on that axis has x=0x = 0x=0, so when 000 is an allowed input, the y-intercept is the single point (0,f(0))(0, f(0))(0,f(0)), found by evaluating f(0)f(0)f(0). A function has at most one y-intercept: either 000 is not an input at all, or it is one input with one output.

The x-intercepts are the points where the graph meets the horizontal axis. Every point on that axis has y=0y = 0y=0, so an x-intercept is a point (a,0)(a, 0)(a,0) with f(a)=0f(a) = 0f(a)=0. Finding the x-intercepts therefore means solving the equation f(x)=0f(x) = 0f(x)=0, which is the b=0b = 0b=0 case of the reading above. These inputs are also called the zeros or roots of the function, and there may be several, one, or none.

Worked example 3 Find the intercepts of f(x)=x2−2x−3f(x) = x^2 - 2x - 3f(x)=x2−2x−3

The graph plotted earlier already marks these crossings: (0,−3)(0, -3)(0,−3) on the vertical axis, and (−1,0)(-1, 0)(−1,0) and (3,0)(3, 0)(3,0) on the horizontal axis. Here is how to find each one directly from the rule, which confirms what the picture already shows.

For the y-intercept, evaluate the rule at x=0x = 0x=0:

f(0)=0−0−3=−3,f(0) = 0 - 0 - 3 = -3,f(0)=0−0−3=−3,

so the y-intercept is the point (0,−3)(0, -3)(0,−3).

For the x-intercepts, set the output to 000 and solve f(x)=0f(x) = 0f(x)=0. The rule factors, which is the fastest route to its zeros:

x2−2x−3=0⟹(x−3)(x+1)=0.x^2 - 2x - 3 = 0 \quad \Longrightarrow \quad (x - 3)(x + 1) = 0.x2−2x−3=0⟹(x−3)(x+1)=0.

A product is zero exactly when one of its factors is zero, so x=3x = 3x=3 or x=−1x = -1x=−1. The x-intercepts are (3,0)(3, 0)(3,0) and (−1,0)(-1, 0)(−1,0). All three points match the graph: it crosses the vertical axis once, at −3-3−3, and the horizontal axis twice, at −1-1−1 and 333.

Domain and range from a graph

The domain is the set of allowed inputs and the range is the set of outputs the function actually produces, and a graph puts both on display. Sweep your eye left to right across the graph: the xxx-values it covers are the domain. Sweep bottom to top: the yyy-values it covers are the range. A graph that runs on forever to the left and right, like a full parabola, has domain “all real numbers.” By contrast, a graph drawn only between two endpoints has a domain that stops at those endpoints.

Worked example 4 Read the domain and range from the graph

The curve above is drawn only between its two endpoints, (−1,0)(-1, 0)(−1,0) on the left and (3,0)(3, 0)(3,0) on the right, so those endpoints fence in the inputs.

Sweeping left to right, the graph occupies every horizontal position from x=−1x = -1x=−1 to x=3x = 3x=3, and nothing outside. That horizontal spread is the domain:

domain ⁣:−1≤x≤3.\text{domain} \colon \quad -1 \le x \le 3.domain:−1≤x≤3.

Sweeping bottom to top, the lowest the curve reaches is the valley at height −4-4−4, and the highest is 000, shared by the two endpoints. That vertical spread is the range:

range ⁣:−4≤y≤0.\text{range} \colon \quad -4 \le y \le 0.range:−4≤y≤0.

Notice the domain is read along the horizontal axis and the range along the vertical axis. If instead the parabola were drawn with arrows running off both sides, the inputs would never stop and the domain would be all real numbers. With those arrows, the range would be y≥−4y \ge -4y≥−4, every height from the low point upward.

Increasing and decreasing

The last thing a picture shows at a glance is the function’s direction. Read the graph the way you read a sentence, left to right, in the direction of increasing xxx. Where the curve rises as you move right, the outputs are getting larger, and the function is increasing there. Where the curve falls as you move right, the outputs are getting smaller, and the function is decreasing.

Made precise, a function is increasing on an interval if larger inputs give larger outputs across it (if a<ba < ba<b then f(a)<f(b)f(a) < f(b)f(a)<f(b)). A function is decreasing on an interval if larger inputs give smaller outputs across it (if a<ba < ba<b then f(a)>f(b)f(a) > f(b)f(a)>f(b)). A point where the graph stops falling and starts rising, or the reverse, is a turning point. At the bottom of a valley the output is smaller than at any nearby input, a minimum. At the top of a hill the output is larger than at any nearby input, a maximum.

Worked example 5 Where is f(x)=x2−2x−3f(x) = x^2 - 2x - 3f(x)=x2−2x−3 increasing?

Trace the graph from left to right. Starting far to the left, the curve comes down steadily, so the outputs are shrinking and fff is decreasing. It keeps falling until it reaches the lowest point at (1,−4)(1, -4)(1,−4), then it turns and climbs. To the right of that turning point the outputs grow, so fff is increasing.

Reading the two stretches off the horizontal axis, the turning happens at x=1x = 1x=1, so

Common mistakes

Common mistakes

  • Confusing input and output when reading. To find f(a)f(a)f(a), start on the horizontal axis at the input aaa and go to the curve. To solve f(x)=bf(x) = bf(x)=b, start on the vertical axis at the output bbb and go across to the curve. Reversing them answers the wrong question.
  • Expecting f(x)=bf(x) = bf(x)=b to have exactly one solution. A horizontal line can meet a curve several times, so one output can come from several inputs. Read off every meeting point, not just the first.
  • Mixing up the two intercepts. The y-intercept comes from setting x=0x = 0x=0 and computing f(0)f(0)f(0), when 000 is an allowed input; the x-intercepts come from setting y=0y = 0y=0 and solving f(x)=0f(x) = 0f(x)=0. Zero the coordinate of the axis you are meeting, which is the opposite letter.
  • Swapping domain and range. The domain is the horizontal spread of the graph (the inputs), read along the x-axis; the range is the vertical spread (the outputs), read along the y-axis.
  • Judging direction from right to left. Increasing and decreasing are always read moving left to right, in the direction of increasing xxx. A valley looks like it “goes up” on its left side only if you read backward.

Key takeaways

  • The graph of a function fff is the set of all points (x,f(x))(x, f(x))(x,f(x)); a point (a,b)(a, b)(a,b) lies on it exactly when f(a)=bf(a) = bf(a)=b.
  • Build a graph by making a table of inputs and outputs, plotting the points, and connecting them only when you already know the type of rule: a line for a linear rule, a smooth parabola for a quadratic one.
  • To read f(a)f(a)f(a), go from aaa on the horizontal axis to the curve and read the height. To solve f(x)=bf(x) = bf(x)=b, go from bbb on the vertical axis across to the curve and read the inputs; there may be several.
  • When 000 is an allowed input, the y-intercept is (0,f(0))(0, f(0))(0,f(0)); the x-intercepts (the zeros of fff) are the solutions of f(x)=0f(x) = 0f(x)=0.
  • The domain is the horizontal spread of the graph (its inputs) and the range is the vertical spread (its outputs).
  • A function is increasing where its graph rises left to right and decreasing where it falls; a turning point is a maximum or a minimum.

A bit of history (optional)

A steam engine of the 1790s was a loud iron box, and nobody could see inside it. Engineers badly wanted to know what happened during a single stroke of the piston. Every measurement they had was a single number, taken afterward. One number cannot describe a whole stroke.

James Watt, a Scottish engineer, wanted a way around this, and around 1796 his assistant John Southern built it. The engine drew its own picture. A pencil was attached to a small piston that rose and fell with the pressure of the steam. The paper under the pencil slid back and forth with the engine’s main piston. One full cycle of the piston, out and back, traced one closed loop.

That loop was called an indicator diagram. Boulton and Watt’s company guarded it as a trade secret for roughly twenty-five years. A trained eye could study the shape and say where the steam had entered too late. It showed which valve was leaking, and how much work the stroke had delivered. The engine itself was still a sealed box. Its whole performance now lay on a sheet of paper, moment by moment, in a form that could be read instead of calculated.

A function’s graph does a simpler job than that loop. The trace returns to where it began, so one piston position can carry two different pressures. A vertical line there crosses the loop twice. A function’s graph never does that: one input gives exactly one point. Still, you read yours the same way. You found the height f(a)f(a)f(a) above an input, the places it crossed each axis, and where it climbed and fell. One input, one output, read at a glance.
