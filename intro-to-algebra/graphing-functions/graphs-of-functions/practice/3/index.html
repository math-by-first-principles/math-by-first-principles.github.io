    The graph of fff is shown. How many solutions does the equation f(x)=−3f(x) = -3f(x)=−3 have?

    Answer choices for question 1

    Solution

    Correct answer: D

    The solutions of f(x)=−3f(x) = -3f(x)=−3 are where the horizontal line y=−3y = -3y=−3 meets the curve.

    y=−3 meets the parabola at x=0 and x=2y = -3 \text{ meets the parabola at } x = 0 \text{ and } x = 2y=−3 meets the parabola at x=0 and x=2

    Two crossings mean two solutions.

  3. 3

    The graph of fff increases for x<−1x < -1x<−1, decreases for −1<x<2-1 < x < 2−1<x<2, and increases for x>2x > 2x>2. How many turning points does it have?

    Answer choices for question 3

    Solution

    Correct answer: D

    A turning point is where the direction changes. The direction changes at x=−1x = -1x=−1 (rise to fall) and at x=2x = 2x=2 (fall to rise).

    changes at x=−1 and x=2  ⇒  2 turning points\text{changes at } x = -1 \text{ and } x = 2 \;\Rightarrow\; 2 \text{ turning points}changes at x=−1 and x=2⇒2 turning points

    The first is a maximum and the second a minimum.

    The graph of fff passes through (1,2)(1, 2)(1,2) and (4,11)(4, 11)(4,11). What is the slope of the straight line through these two points?

    Answer choices for question 5

    Solution

    Correct answer: C

    The slope is the change in output divided by the change in input between the two points.

    11−24−1=93=3\frac{11 - 2}{4 - 1} = \frac{9}{3} = 34−111−2​=39​=3

    That slope measures how steeply the graph climbs between the two points.

  7. 7

    For f(x)=x2f(x) = x^2f(x)=x2, which statement about its graph is true?

    Answer choices for question 7

    Solution

    Correct answer: B

    The parabola y=x2y = x^2y=x2 falls to the origin then rises.

    decreasing for x<0,increasing for x>0\text{decreasing for } x < 0, \quad \text{increasing for } x > 0decreasing for x<0,increasing for x>0

    Its single turning point (a minimum) is at the origin, which is also its only x-intercept.

  11. 11

    A parabola opens upward with vertex (−2,−5)(-2, -5)(−2,−5). What is its range?

    Answer choices for question 11

    Solution

    Correct answer: C

    An upward parabola has its lowest output at the vertex and rises without bound.

    minimum output −5  ⇒  y≥−5\text{minimum output } -5 \;\Rightarrow\; y \ge -5minimum output −5⇒y≥−5

    The −2-2−2 is the input at the vertex, not an output.

  12. 12

    Which pair of points can NOT both lie on the graph of the same function?

    Answer choices for question 12

    Solution

    Correct answer: A

    A function assigns each input one output, so no two points may share a first coordinate with different second coordinates.

    (2,0) and (2,3) share input 2 with outputs 0≠3(2, 0) \text{ and } (2, 3) \text{ share input } 2 \text{ with outputs } 0 \ne 3(2,0) and (2,3) share input 2 with outputs 0=3

    That violates the definition. Sharing an output, as in the other pairs, is perfectly fine.
