Shifting Graphs

Intuition

When you wrote a parabola in vertex form, y=(x−h)2+ky = (x - h)^2 + ky=(x−h)2+k, you were really giving directions: start with the plain bowl y=x2y = x^2y=x2 and slide it so its lowest point lands at (h,k)(h, k)(h,k). This lesson makes that idea general. Take any graph you already know, and you can build a whole family of new graphs from it just by sliding it around, with no new table of values to work out. Adding a number changes the height of the graph. Changing the input changes its left-to-right position, and that is where the sign plays a trick: a graph slides sideways in the opposite direction from the sign you see inside the function. Why does that happen? This lesson shows you, so the rule stops being something to memorize and becomes something you can see for yourself.

Learning goals

  • Move a graph up by kkk with y=f(x)+ky = f(x) + ky=f(x)+k
  • Shift right by hhh with y=f(x−h)y = f(x - h)y=f(x−h)
  • Explain why subtracting inside moves the graph rightward
  • Combine both into y=f(x−h)+ky = f(x - h) + ky=f(x−h)+k
  • Track how a shift moves intercepts, domain and range

Sliding a graph without building a new table

A shift, also called a translation, moves every point of a graph the same distance in the same direction, without turning it, stretching it, or flipping it. The shape stays identical; only its location changes. Because a graph is the set of points (x,f(x))(x, f(x))(x,f(x)), a shift acts on those points. We can predict exactly where each point goes by looking at how the rule changes.

There are two kinds of shift: a vertical shift moves the graph up or down, and a horizontal shift moves it left or right. We handle each on its own first, then combine them. Throughout, keep one fact from the last lesson in front of you: a point (a,b)(a, b)(a,b) lies on the graph of y=f(x)y = f(x)y=f(x) exactly when b=f(a)b = f(a)b=f(a). So the second coordinate is an output and the first is an input. Every rule below comes straight from tracking what happens to that pairing.

Vertical shifts: change the output

Adding a number to the outside of a function moves its graph straight up or down. It never changes the graph’s shape. Here is what that looks like on a graph you already know.

Worked example 1 Graph y=x2+3y = x^2 + 3y=x2+3 by sliding y=x2y = x^2y=x2 upward

The rule y=x2+3y = x^2 + 3y=x2+3 takes the familiar bowl y=x2y = x^2y=x2 and adds 333 to every output, so the whole graph rises by 333. There is no need to build a new table; shift the points you already know.

The vertex of y=x2y = x^2y=x2 sits at (0,0)(0, 0)(0,0). Adding 333 lifts it to

(0, 0+3)=(0,3).(0,\, 0 + 3) = (0, 3).(0,0+3)=(0,3).

Take two more anchor points and raise each by 333. On y=x2y = x^2y=x2 the points (1,1)(1, 1)(1,1) and (2,4)(2, 4)(2,4) appear; after the shift they become

(1, 1+3)=(1,4),(2, 4+3)=(2,7).(1,\, 1 + 3) = (1, 4), \qquad (2,\, 4 + 3) = (2, 7).(1,1+3)=(1,4),(2,4+3)=(2,7).

Plot the lifted vertex (0,3)(0, 3)(0,3) and the lifted points, then draw the identical bowl through them. Because the lowest output is now 333, the graph never dips below the line y=3y = 3y=3, and its y-intercept is (0,3)(0, 3)(0,3). The parabola has not changed shape at all; it simply sits three units higher.

Look at what happened. Every output on y=x2y = x^2y=x2 picked up the same extra 333: the vertex (0,0)(0, 0)(0,0) became (0,3)(0, 3)(0,3), and (1,1)(1, 1)(1,1) became (1,4)(1, 4)(1,4). Adding the same number to every height is exactly what slides a shape straight up without bending it, and the same thing happens for any starting graph, not only a parabola. Written in general, adding a constant kkk outside a function does this to every point of y=f(x)y = f(x)y=f(x):

y=f(x)+k.y = f(x) + k.y=f(x)+k.

Every input still passes through fff, but whatever comes out is then increased by kkk. Since the output is the height of the graph, raising every output by kkk raises the whole graph by kkk, up when k>0k > 0k>0 and down when k<0k < 0k<0.

Why y=f(x)+ky = f(x) + ky=f(x)+k slides the graph up by kkk#

Let g(x)=f(x)+kg(x) = f(x) + kg(x)=f(x)+k. Pick any input aaa. The original graph has the point (a,f(a))(a, f(a))(a,f(a)), sitting at height f(a)f(a)f(a) directly above the input aaa. The new graph has the point (a,g(a))(a, g(a))(a,g(a)), and

g(a)=f(a)+k,g(a) = f(a) + k,g(a)=f(a)+k,

so that point is (a,f(a)+k)(a, f(a) + k)(a,f(a)+k). The two points share the same first coordinate aaa, so they lie on the same vertical line. The new point’s second coordinate minus the old one’s equals exactly kkk, whatever the sign of kkk turns out to be. That is a rise of kkk when k>0k > 0k>0, and a drop of ∣k∣\lvert k \rvert∣k∣ when k<0k < 0k<0. Nothing about the input changed, so the point did not move left or right at all.

Since aaa was an arbitrary input, this happens to every point at once: each one rises by kkk when k>0k > 0k>0, or drops by ∣k∣\lvert k \rvert∣k∣ when k<0k < 0k<0. A rigid slide of every point by the same amount in the same direction is exactly a translation. So the graph of y=f(x)+ky = f(x) + ky=f(x)+k is the graph of y=f(x)y = f(x)y=f(x) moved vertically by kkk, and its shape is untouched.

∎

The same reasoning reads points off a graph directly. If (a,b)(a, b)(a,b) is on y=f(x)y = f(x)y=f(x), then (a,b+k)(a, b + k)(a,b+k) is on y=f(x)+ky = f(x) + ky=f(x)+k: keep the input, add kkk to the height.

Horizontal shifts: the direction that looks backward

Now change the input instead of the output. Replace xxx with x−hx - hx−h to get

y=f(x−h).y = f(x - h).y=f(x−h).

Here is the trap. Almost everyone expects x−hx - hx−h, with its minus sign, to move the graph left, in the negative direction. It does the opposite: for h>0h > 0h>0 the graph moves right by hhh. Rather than memorize that, derive it, because the derivation shows exactly why the sign feels reversed.

Worked example 2 Relate y=(x−3)2y = (x - 3)^2y=(x−3)2 to y=x2y = x^2y=x2

The rule y=(x−3)2y = (x - 3)^2y=(x−3)2 has the form f(x−h)f(x - h)f(x−h) with f(x)=x2f(x) = x^2f(x)=x2 and h=3h = 3h=3. Check the direction with the vertex. The bowl y=x2y = x^2y=x2 bottoms out where its input is 000. For y=(x−3)2y = (x - 3)^2y=(x−3)2, the lowest output happens where the inside is 000:

x−3=0⟹x=3,x - 3 = 0 \quad \Longrightarrow \quad x = 3,x−3=0⟹x=3,

so the new vertex is (3,0)(3, 0)(3,0), three units right of the origin, even though the rule contains a minus sign. Track one more point the same way. The point (1,1)(1, 1)(1,1) is on y=x2y = x^2y=x2; to make the inside of (x−3)2(x - 3)^2(x−3)2 equal 111, solve x−3=1x - 3 = 1x−3=1, giving x=4x = 4x=4. So the matching point on the new graph is (4,1)(4, 1)(4,1), again shifted right by 333:

(1,1) ⟶ (4,1).(1, 1) \ \longrightarrow \ (4, 1).(1,1) ⟶ (4,1).

Every point moves the same way, so the parabola lands three units to the right, exactly as the picture shows.

Look at why that happened. To make (x−3)2(x - 3)^2(x−3)2 reproduce the height that 121^212 gave on the original graph, the inside x−3x - 3x−3 had to equal 111, and that forced xxx to be three more than before: x=4x = 4x=4, not x=−2x = -2x=−2. Subtracting inside asks xxx to grow to keep the inside value the same, and that is true for every point, not just this one.

Why y=f(x−h)y = f(x - h)y=f(x−h) slides the graph right by hhh#

Let g(x)=f(x−h)g(x) = f(x - h)g(x)=f(x−h). Fix any input aaa, so the original graph has the point (a,f(a))(a, f(a))(a,f(a)) at height f(a)f(a)f(a). Ask the key question: at which input xxx does the new function ggg produce that same height f(a)f(a)f(a)?

The function fff returns the value f(a)f(a)f(a) when its input equals aaa. But the input handed to fff inside ggg is not xxx; it is x−hx - hx−h. So g(x)g(x)g(x) produces that same height f(a)f(a)f(a) when the inside matches aaa:

x−h=a⟹x=a+h.x - h = a \quad \Longrightarrow \quad x = a + h.x−h=a⟹x=a+h.

Therefore g(a+h)=f((a+h)−h)=f(a)g(a + h) = f\big((a + h) - h\big) = f(a)g(a+h)=f((a+h)−h)=f(a), which means the new graph has the point (a+h,f(a))(a + h, f(a))(a+h,f(a)). Compare it with the old point (a,f(a))(a, f(a))(a,f(a)): both sit at the same height f(a)f(a)f(a). The new point, though, is at input a+ha + ha+h, exactly hhh units to the right of aaa when h>0h > 0h>0.

Since aaa was arbitrary, every point moves right by hhh, so y=f(x−h)y = f(x - h)y=f(x−h) is y=f(x)y = f(x)y=f(x) shifted right by hhh. The reason the minus sign feels backward is now visible: subtracting hhh inside means the function needs a larger input xxx to feed fff the same inside value. So each feature of the graph shows up hhh units later, that is, farther to the right. Reading it the other way, y=f(x+h)y = f(x + h)y=f(x+h) is y=f(x−(−h))y = f(x - (-h))y=f(x−(−h)), a shift right by −h-h−h, which is a shift left by hhh.

∎

A horizontal shift always works this way: to make the inside expression reach a value it used to reach, you move xxx in the direction that undoes the sign in front of hhh.

Why does y=f(x−3)y = f(x - 3)y=f(x−3) move the graph of y=f(x)y = f(x)y=f(x) to the right, instead of to the left where the minus sign might suggest?

Answer choices

A horizontal shift changes inputs, not outputs, so the second and third options describe the wrong kind of change; there is no reflection involved either, only a slide. The real reason is the one the proof works out: to make x−3x - 3x−3 equal an input value aaa that fff already used, xxx must equal a+3a + 3a+3, three more than before. Needing a larger input to reproduce the same feature is exactly what pushes the graph rightward.

The proof above never used the fact that fff was a squaring function, so the same rule moves any graph. See it drawn on a curve with a single rounded hump, in the Go deeper section at the end of this lesson.

Changing the input is a horizontal shift. Combining a horizontal and a vertical shift

The two moves do not interfere, so you can apply both at once. Starting from y=f(x)y = f(x)y=f(x), the rule

y=f(x−h)+ky = f(x - h) + ky=f(x−h)+k

shifts the graph right by hhh (from the x−hx - hx−h inside) and up by kkk (from the +k+ k+k outside). Track a single point to see both at work: a point (a,f(a))(a, f(a))(a,f(a)) on the original graph reappears at

(a+h, f(a)+k),\big(a + h,\ f(a) + k\big),(a+h, f(a)+k),

its input increased by hhh and its height increased by kkk. Negative values of hhh or kkk just reverse the corresponding direction.

This is where vertex form finally makes complete sense. Applying the combined shift to y=x2y = x^2y=x2 gives y=(x−h)2+ky = (x - h)^2 + ky=(x−h)2+k, and since the vertex of y=x2y = x^2y=x2 is at the origin, it lands at (h,k)(h, k)(h,k). The numbers hhh and kkk in vertex form are not mysterious; they are simply how far the basic bowl was slid right and up.

Nothing in the argument used the fact that fff was a squaring function, so try the combined shift on a different shape: y=∣x−h∣+ky = \lvert x - h \rvert + ky=∣x−h∣+k, a V-shaped graph with a corner instead of a smooth vertex. Start at h=0h = 0h=0 and k=0k = 0k=0, then increase hhh to 333. Watch the corner move three units to the right, even though the rule now reads x−3x - 3x−3. Next, hold hhh where it is and change kkk. The corner moves straight up or down and stays at the same left-to-right position, because kkk never touches the inside of the function. Leave the coefficient aaa at 111 for now; the next lesson is what that control is for.

Worked example 3 Shift y=x2y = x^2y=x2 into vertex form y=(x−2)2+1y = (x - 2)^2 + 1y=(x−2)2+1

Read the rule y=(x−2)2+1y = (x - 2)^2 + 1y=(x−2)2+1 as a set of directions applied to y=x2y = x^2y=x2. The inside x−2x - 2x−2 says shift right 222, and the +1+ 1+1 outside says shift up 111.

Move the vertex first. It starts at (0,0)(0, 0)(0,0), then goes right 222 and up 111:

(0,0) ⟶ (0+2, 0+1)=(2,1).(0, 0) \ \longrightarrow \ (0 + 2,\ 0 + 1) = (2, 1).(0,0) ⟶ (0+2, 0+1)=(2,1).

To confirm with the rule, the lowest output happens where the squared part is 000, at x−2=0x - 2 = 0x−2=0, so x=2x = 2x=2; there the output is (0)+1=1(0) + 1 = 1(0)+1=1, matching the vertex (2,1)(2, 1)(2,1). Carry one more point along for the shape: the point (1,1)(1, 1)(1,1) on y=x2y = x^2y=x2 moves right 222 and up 111 to (3,2)(3, 2)(3,2). Plot the vertex (2,1)(2, 1)(2,1) and a few shifted points, then draw the same bowl. The graph is y=x2y = x^2y=x2 resting with its bottom at (2,1)(2, 1)(2,1), which is precisely what vertex form announces.

The point (2,5)(2, 5)(2,5) lies on the graph of y=f(x)y = f(x)y=f(x). Which point must lie on the graph of y=f(x−3)+2y = f(x - 3) + 2y=f(x−3)+2?

Answer choices

A combined shift moves the input by h=3h = 3h=3 and the output by k=2k = 2k=2 at the same time.

(2+3,  5+2)=(5,7)(2 + 3,\; 5 + 2) = (5, 7)(2+3,5+2)=(5,7)

Subtracting 333 from the input instead of adding it gives (−1,7)(-1, 7)(−1,7); getting the sign of kkk backward gives (5,3)(5, 3)(5,3); missing both signs gives (−1,3)(-1, 3)(−1,3). Both coordinates move here because both shifts are present.

A combined shift also relocates the intercepts. A horizontal shift slides the x-intercepts sideways by hhh, while a vertical shift raises or lowers the graph. A vertical shift can also change how many x-intercepts there are, since it may push the curve across or away from the horizontal axis. Vertex form makes them easy to find by solving directly.

Worked example 4 Find the vertex and x-intercepts of y=(x−3)2−4y = (x - 3)^2 - 4y=(x−3)2−4

The rule y=(x−3)2−4y = (x - 3)^2 - 4y=(x−3)2−4 shifts y=x2y = x^2y=x2 right 333 and down 444, so the vertex moves from (0,0)(0, 0)(0,0) to

(0+3, 0−4)=(3,−4).(0 + 3,\ 0 - 4) = (3, -4).(0+3, 0−4)=(3,−4).

Because the vertex sits below the horizontal axis and the bowl opens upward, the graph must cross that axis twice, so expect two x-intercepts. Find them by setting the output to 000:

(x−3)2−4=0⟹(x−3)2=4.(x - 3)^2 - 4 = 0 \quad \Longrightarrow \quad (x - 3)^2 = 4.(x−3)2−4=0⟹(x−3)2=4.

A number whose square is 444 is 222 or −2-2−2, so x−3=2x - 3 = 2x−3=2 or x−3=−2x - 3 = -2x−3=−2, giving

x=5orx=1.x = 5 \quad \text{or} \quad x = 1.x=5orx=1.

The x-intercepts are (1,0)(1, 0)(1,0) and (5,0)(5, 0)(5,0), sitting symmetrically on either side of the vertex’s input x=3x = 3x=3. The down-444 shift is what dropped the vertex below the axis and created two crossings; without it, y=(x−3)2y = (x - 3)^2y=(x−3)2 would only touch the axis at its vertex.

Worked example 5 Shift a general function and track its domain and range

Suppose fff has domain 0≤x≤60 \le x \le 60≤x≤6 and range −1≤y≤5-1 \le y \le 5−1≤y≤5, and the point (4,−1)(4, -1)(4,−1) lies on its graph. Describe the graph of y=f(x−2)+3y = f(x - 2) + 3y=f(x−2)+3.

The rule shifts the graph right 222 and up 333, so apply that to the point first:

(4,−1) ⟶ (4+2, −1+3)=(6,2).(4, -1) \ \longrightarrow \ (4 + 2,\ -1 + 3) = (6, 2).(4,−1) ⟶ (4+2, −1+3)=(6,2).

The domain is the horizontal spread of the graph, so a shift right by 222 slides both ends of the domain right by 222, adding 222 to each:

0≤x≤6⟶2≤x≤8.0 \le x \le 6 \quad \longrightarrow \quad 2 \le x \le 8.0≤x≤6⟶2≤x≤8.

The range is the vertical spread, so a shift up by 333 raises both ends of the range by 333:

−1≤y≤5⟶2≤y≤8.-1 \le y \le 5 \quad \longrightarrow \quad 2 \le y \le 8.−1≤y≤5⟶2≤y≤8.

The horizontal shift touches only the inputs (the domain) and the vertical shift touches only the outputs (the range). The two moves can therefore be handled separately even when they happen together.

Common mistakes

Common mistakes

  • Shifting horizontally the wrong way. y=f(x−h)y = f(x - h)y=f(x−h) moves right by hhh, and y=f(x+h)y = f(x + h)y=f(x+h) moves left. The direction is opposite the sign inside. Check it with one point: the inside x−hx - hx−h reaches an old value only when xxx grows by hhh, which is a move to the right.
  • Swapping which change moves which way. A number added outside the function, f(x)+kf(x) + kf(x)+k, is a vertical shift (it changes the height). A number combined with xxx inside the function, f(x−h)f(x - h)f(x−h), is a horizontal shift (it changes the position). Watch where the number sits.
  • Moving a point in both coordinates for a single shift. A vertical shift changes only the output, so (a,b)→(a,b+k)(a, b) \to (a, b + k)(a,b)→(a,b+k); the input is untouched. A horizontal shift changes only the input, so (a,b)→(a+h,b)(a, b) \to (a + h, b)(a,b)→(a+h,b). Do not shift both coordinates unless both shifts are present.
  • Misreading vertex form. In y=(x−h)2+ky = (x - h)^2 + ky=(x−h)2+k the vertex is (h,k)(h, k)(h,k), so y=(x+3)2−5y = (x + 3)^2 - 5y=(x+3)2−5 has vertex (−3,−5)(-3, -5)(−3,−5), taking the sign from x−(−3)x - (-3)x−(−3). Read hhh as the value that makes the inside zero.
  • Expecting the shape to change. A translation slides the graph; it never stretches, squeezes, or flips it. If your new graph looks wider, narrower, or upside down, you have done something other than a shift.

Key takeaways

  • A shift (translation) moves every point of a graph the same distance in the same direction; the shape is unchanged.
  • Vertical: y=f(x)+ky = f(x) + ky=f(x)+k moves the graph up by kkk (down when k<0k < 0k<0), because adding kkk to every output raises every point. Points map by (a,b)→(a,b+k)(a, b) \to (a, b + k)(a,b)→(a,b+k).
  • Horizontal: y=f(x−h)y = f(x - h)y=f(x−h) moves the graph right by hhh (left when h<0h < 0h<0), because x−hx - hx−h reaches an old input value only when xxx grows by hhh. Points map by (a,b)→(a+h,b)(a, b) \to (a + h, b)(a,b)→(a+h,b).
  • The horizontal direction looks backward on purpose: subtracting inside makes the graph appear farther to the right, and adding inside makes it appear to the left.
  • Combined: y=f(x−h)+ky = f(x - h) + ky=f(x−h)+k shifts right hhh and up kkk, sending (a,b)→(a+h,b+k)(a, b) \to (a + h, b + k)(a,b)→(a+h,b+k). For a parabola this is vertex form y=(x−h)2+ky = (x - h)^2 + ky=(x−h)2+k, with vertex (h,k)(h, k)(h,k).
  • A horizontal shift moves the domain and the x-intercepts sideways by hhh. A vertical shift moves the range up or down by kkk and can change the number of x-intercepts.

Why the horizontal shift works on any shape, not just a parabola

The proof in the main lesson never assumed fff was a squaring function; it works for any function fff and any input aaa. This curve makes that concrete: it has a single rounded peak instead of a parabola’s smooth bowl, and the peak still moves from input aaa to input a+3a + 3a+3 under y=f(x−3)y = f(x - 3)y=f(x−3), for exactly the same reason a parabola’s vertex does.

A bit of history (optional)

Every place on the Earth carries a number for how far east or west it lies. East or west of what, though? For centuries each seafaring nation answered that with a line of its own, drawn through a home observatory. The same harbor then carried one number on a French chart and a different number on a British one.

An international conference settled the question in 1884. It chose the line through Greenwich, an observatory on a hill above the river in London, and charts have mostly followed it since. Nothing on the ground moved that day: cliffs, ports and islands all stayed exactly where they were. What moved was the zero. On every chart that changed over, each longitude shifted by the same amount, and all of them shifted the same way.

A function shift is a cousin of that idea, though it works the opposite way around. Renumbering the charts left every place exactly where it was; only the number attached to each place changed. A graph shift does the reverse: the axes never move, and it is the curve itself that slides to a new spot on them. What both stories share is the deeper point that a single number, added in the right place, can move where something sits. That is worth remembering the next time x−hx - hx−h tempts you to guess left instead of right.

Vertex form is that idea at its plainest. Writing y=(x−h)2+ky = (x - h)^2 + ky=(x−h)2+k does not describe some new bowl. It takes the familiar bowl y=x2y = x^2y=x2 and slides it, exactly as a shift always does, so its lowest point lands at (h,k)(h, k)(h,k).
