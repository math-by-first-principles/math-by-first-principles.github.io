    Part A

    A flat surcharge is added to whatever the company already charges, so it changes the OUTPUT of CCC, not the input. Adding a fixed amount to every output is exactly a vertical shift.

    new cost(x)=C(x)+7.\text{new cost}(x) = C(x) + 7.new cost(x)=C(x)+7.

    2≤x≤18(unchanged).2 \le x \le 18 \quad \text{(unchanged)}.2≤x≤18(unchanged).

    Part C

    A vertical shift, by definition, changes only the output of a function; the input is whatever it always was. Here the input is the package's weight, and the surcharge sits entirely on the output side, added to CCC.

    2≤x≤18(same domain, before and after).2 \le x \le 18 \quad \text{(same domain, before and after)}.2≤x≤18(same domain, before and after).

    Part A

    Test the claim with the definition rather than with how the sign looks. A horizontal shift asks: at what input does the INSIDE expression reach a value fff already produces?     3. Does the order of two shifts matter? . Reasoning, 9 points. Question 3 of 5.

    Reasoning 9 pts

    Start from a function fff. A horizontal shift right by hhh replaces xxx with x−hx - hx−h in the rule; a vertical shift up by kkk adds kkk to the output.     Answer and solution

    The answer

    Part A

    f(x−h)+kf(x-h) + kf(x−h)+k.

    Part B

    f(x−h)+kf(x-h) + kf(x−h)+k, the same expression as part A.

    Part C

    They always agree: both orders give f(x−h)+kf(x-h)+kf(x−h)+k, because the horizontal shift only touches what is fed into fff and the vertical shift only touches what comes out, so the two operations act on different parts of the expression and cannot interfere.

    Not what you got? Look for the slip on your own paper before you open the solution. Finding it yourself is worth more than reading it.

    Worked solution

    Part A

    Apply the two definitions in the stated order. Shifting fff right by hhh means building the rule q(x)=f(x−h)q(x) = f(x-h)q(x)=f(x−h). Shifting the RESULT qqq up by kkk means adding kkk to its output:

    q(x)+k=f(x−h)+k.q(x) + k = f(x-h) + k.q(x)+k=f(x−h)+k.

    So doing the horizontal shift first and the vertical shift second gives f(x−h)+kf(x-h)+kf(x−h)+k.

    Part B

    Reverse the order. Shifting fff up by kkk first means building the rule p(x)=f(x)+kp(x) = f(x) + kp(x)=f(x)+k. Shifting the RESULT ppp right by hhh second means replacing xxx with x−hx - hx−h inside ppp's rule, not inside fff directly:

    p(x−h)=f(x−h)+k.p(x - h) = f(x-h) + k.p(x−h)=f(x−h)+k.

    So doing the vertical shift first and the horizontal shift second also gives f(x−h)+kf(x-h)+kf(x−h)+k.

    Part C

    Parts A and B computed the two orders and landed on the identical expression

    f(x−h)+k,f(x-h) + k,f(x−h)+k,

    with no restriction anywhere on which function fff was used or which real numbers hhh and kkk were chosen, so the agreement holds in general, not just for one case that happened to work out.

    The reason is structural. The horizontal shift only ever changes what gets FED INTO fff, and the vertical shift only ever changes what happens to the number that comes back OUT of fff. Those are two different places in the expression, so performing one first can never disturb what the other does; the two operations simply do not touch the same thing.

    In one line

    Both orders give the same rule, f(x−h)+kf(x-h)+kf(x−h)+k: doing the horizontal shift first and the vertical shift second, or the reverse, land on an identical expression, because one shift only ever touches the value handed to fff and the other only ever touches the number added after fff runs, so neither step can interfere with the other, for every function fff and every choice of hhh and kkk.
