Stretching and Reflecting Graphs

Intuition

The last lesson slid graphs around without changing their shape. This one changes a graph’s scale or its orientation instead. Take a graph you already know and you can make it taller or shorter, flip it over an axis, or squeeze it narrower. All of that comes from editing the rule rather than from replotting a table. Multiplying the output by a number stretches the graph up and down; putting a minus sign on the output turns it upside down. The genuinely surprising move is horizontal scaling: when you multiply the input by a number bigger than 111, the graph gets narrower, not wider. This lesson derives why that direction looks backward, the same way the shift lesson explained why x−hx - hx−h moves a graph to the right. By the end you will read a rule like y=−2f(x)y = -2f(x)y=−2f(x) or y=f(3x)y = f(3x)y=f(3x) and know exactly what it does to the picture.

Learning goals

  • Scale heights with y=af(x)y = a f(x)y=af(x), stretching when a>1a > 1a>1
  • Flip across the xxx-axis with y=−f(x)y = -f(x)y=−f(x)
  • Compress toward the yyy-axis with y=f(bx)y = f(bx)y=f(bx) when b>1b > 1b>1
  • Mirror across the yyy-axis with y=f(−x)y = f(-x)y=f(−x)
  • Recognize y=a(x−h)2+ky = a(x - h)^2 + ky=a(x−h)2+k as vertex form for a parabola

Vertical stretches and compressions: scale the output

Take the familiar graph y=x2y = x^2y=x2. The point (1,1)(1, 1)(1,1) sits at height 111. Multiply every output by 222, giving y=2x2y = 2x^2y=2x2, and at that same input 111 the height becomes 2×1=22 \times 1 = 22×1=2, twice as far from the x-axis.

That is the whole idea, stated for any function fff and any positive constant aaa:

y=a f(x).y = a\,f(x).y=af(x).

Each input still passes through fff, but whatever comes out is then multiplied by aaa. Because the output is the height of the graph, scaling every output by aaa moves every point that same factor farther from the x-axis when a>1a > 1a>1, or closer to it when 0<a<10 < a < 10<a<1, whether the point sits above the axis or below it. For a graph that stays above the axis, like the parabola above, that means taller and steeper when a>1a > 1a>1 (a vertical stretch) and shorter and flatter when 0<a<10 < a < 10<a<1 (a vertical compression). The general reason behind that is worth seeing in full.

Why y=a f(x)y = a\,f(x)y=af(x) scales every height by aaa#

Let g(x)=a f(x)g(x) = a\,f(x)g(x)=af(x) with a>0a > 0a>0, and pick any input xxx in the domain. The original graph has the point (x,f(x))(x, f(x))(x,f(x)), sitting at height f(x)f(x)f(x) directly above the input. The new graph has the point (x,g(x))(x, g(x))(x,g(x)), and since g(x)=a f(x)g(x) = a\,f(x)g(x)=af(x), that point is (x, a f(x))(x,\, a\,f(x))(x,af(x)). The two share the same first coordinate, so the new point lies on the same vertical line as the old one, at aaa times its height.

Since xxx was arbitrary, every height on the graph is scaled by the same factor aaa: the graph stretches vertically when a>1a > 1a>1 and compresses vertically when 0<a<10 < a < 10<a<1. A point that already sits on the horizontal axis has height 000, and a×0=0a \times 0 = 0a×0=0, so every x-intercept stays exactly where it was.

∎

Reading points off the graph is immediate. If (x0,y0)(x_0, y_0)(x0​,y0​) lies on y=f(x)y = f(x)y=f(x), then (x0, ay0)(x_0,\, a y_0)(x0​,ay0​) lies on y=a f(x)y = a\,f(x)y=af(x): keep the input, multiply the height by aaa.

Worked example 1 Stretch and compress y=x2y = x^2y=x2

Both new rules keep f(x)=x2f(x) = x^2f(x)=x2 and only rescale its outputs, so shift the points you already know instead of building a fresh table.

For y=2x2y = 2x^2y=2x2, multiply every height by 222. The vertex (0,0)(0, 0)(0,0) stays at (0,0)(0, 0)(0,0) because 2×0=02 \times 0 = 02×0=0, while the anchor points (1,1)(1, 1)(1,1) and (2,4)(2, 4)(2,4) climb to

(1, 2×1)=(1,2),(2, 2×4)=(2,8).(1,\, 2 \times 1) = (1, 2), \qquad (2,\, 2 \times 4) = (2, 8).(1,2×1)=(1,2),(2,2×4)=(2,8).

The bowl passes through those higher points, so it looks narrower and steeper, though it still opens upward from the same vertex.

For y=12x2y = \tfrac{1}{2}x^2y=21​x2, multiply every height by 12\tfrac{1}{2}21​ instead. The same anchor points sink to

(1, 12),(2,2),\left(1,\, \tfrac{1}{2}\right), \qquad (2, 2),(1,21​),(2,2),

so this bowl is wider and flatter. In both cases the vertex and the single x-intercept at the origin never budge. Scaling a height of 000 leaves it at 000, so only the nonzero heights move.

Reflecting across the x-axis: negate the output

The case a=−1a = -1a=−1 deserves its own name. The rule

y=−f(x)y = -f(x)y=−f(x)

negates every output, sending a point at height y0y_0y0​ to height −y0-y_0−y0​. A point above the horizontal axis drops to the mirror-image spot the same distance below it, and a point below rises to the matching spot above. That is exactly a reflection across the x-axis: the graph flips over that axis like a card turning face down. Points sitting on the axis have height 000, and −0=0-0 = 0−0=0, so they stay fixed and act as the hinge of the flip.

A negative scale factor with size other than 111 just does both jobs at once. Writing a=−∣a∣a = -\lvert a \rverta=−∣a∣, the rule y=a f(x)y = a\,f(x)y=af(x) scales every height by ∣a∣\lvert a \rvert∣a∣ and then negates it, so it stretches or compresses vertically and reflects across the x-axis together.

Worked example 2 Reflect y=x2y = x^2y=x2 across the x-axis

The rule y=−x2y = -x^2y=−x2 is y=−f(x)y = -f(x)y=−f(x) with f(x)=x2f(x) = x^2f(x)=x2, so it takes the familiar upward bowl and negates every output. Track a few points by flipping the sign of each height:

(1,1)⟶(1,−1),(2,4)⟶(2,−4).(1, 1) \longrightarrow (1, -1), \qquad (2, 4) \longrightarrow (2, -4).(1,1)⟶(1,−1),(2,4)⟶(2,−4).

The vertex (0,0)(0, 0)(0,0) stays put, since −0=0-0 = 0−0=0. Plotting the flipped points gives the same parabola turned upside down, so it now opens downward. The origin that used to be its lowest point is now its highest. Nothing about the width changed, because reflecting only reverses the sign of each height without rescaling it. What was a minimum has become a maximum, purely from the minus sign.

Horizontal stretches and compressions: the direction that looks backward again

Now change the input instead of the output. Replace xxx with bxbxbx for a positive constant bbb:

y=f(bx).y = f(bx).y=f(bx).

Here is the trap, and it mirrors the one from the shift lesson. You might expect multiplying the input by a large bbb to stretch the graph wider. It does the opposite: for b>1b > 1b>1 the graph is squeezed narrower, pulled in toward the vertical axis. Rather than memorize that, derive it, because the derivation shows precisely why the direction feels reversed.

For example, if (8,5)(8, 5)(8,5) lies on y=f(x)y = f(x)y=f(x), that same height reappears on y=f(2x)y = f(2x)y=f(2x) at input 444, because 2×4=82 \times 4 = 82×4=8: half of the original input, not double it. Seeing why that works in general is the point of the derivation below.

Why y=f(bx)y = f(bx)y=f(bx) scales every width by 1b\tfrac{1}{b}b1​#

Let g(x)=f(bx)g(x) = f(bx)g(x)=f(bx) with b>0b > 0b>0. Fix any input aaa, so the original graph has the point (a,f(a))(a, f(a))(a,f(a)) at height f(a)f(a)f(a). Ask the key question: at which input xxx does the new function ggg produce that same height f(a)f(a)f(a)?

The function fff returns the value f(a)f(a)f(a) when its input equals aaa. But the input handed to fff inside ggg is not xxx; it is bxbxbx. So g(x)g(x)g(x) produces that same height when the inside matches aaa:

bx=a⟹x=ab.bx = a \quad \Longrightarrow \quad x = \frac{a}{b}.bx=a⟹x=ba​.

Therefore g ⁣(ab)=f ⁣(b⋅ab)=f(a)g\!\left(\tfrac{a}{b}\right) = f\!\left(b \cdot \tfrac{a}{b}\right) = f(a)g(ba​)=f(b⋅ba​)=f(a), which means the new graph has the point (ab, f(a))\left(\tfrac{a}{b},\, f(a)\right)(ba​,f(a)). Compare it with the old point (a,f(a))(a, f(a))(a,f(a)): both sit at the same height. The new point, though, is at input ab\tfrac{a}{b}ba​, the old input scaled by the factor 1b\tfrac{1}{b}b1​.

When b>1b > 1b>1 the factor 1b\tfrac{1}{b}b1​ is less than 111, so ab\tfrac{a}{b}ba​ is closer to 000 than aaa was. Every point is therefore pulled toward the vertical axis, a horizontal compression. When 0<b<10 < b < 10<b<1 the factor 1b\tfrac{1}{b}b1​ is greater than 111, so ab\tfrac{a}{b}ba​ is farther from 000: every point is pushed away, a horizontal stretch. A point on the vertical axis has a=0a = 0a=0, and 0b=0\tfrac{0}{b} = 0b0​=0, so it never moves.

∎

Worked example 3 Locate points and intercepts on y=f(2x)y = f(2x)y=f(2x) and y=f(x2)y = f\left(\tfrac{x}{2}\right)y=f(2x​)

Suppose (8,5)(8, 5)(8,5) lies on y=f(x)y = f(x)y=f(x), and suppose fff has x-intercepts at x=2x = 2x=2 and x=6x = 6x=6. Handle the two scalings by asking, in each case, what input makes the inside equal an old input.

For y=f(2x)y = f(2x)y=f(2x), a point reappears where 2x2x2x equals the old input. To get the height 555 back, set the inside equal to 888:

2x=8⟹x=4,2x = 8 \quad \Longrightarrow \quad x = 4,2x=8⟹x=4,

so (8,5)(8, 5)(8,5) moves to (4,5)(4, 5)(4,5), half the input. The x-intercepts move the same way: 2x=22x = 22x=2 gives x=1x = 1x=1 and 2x=62x = 62x=6 gives x=3x = 3x=3, so the zeros at 222 and 666 are pulled in to 111 and 333. With b=2>1b = 2 > 1b=2>1 the whole graph is compressed toward the vertical axis by a factor of 12\tfrac{1}{2}21​.

For y=f ⁣(x2)y = f\!\left(\tfrac{x}{2}\right)y=f(2x​), the inside is x2\tfrac{x}{2}2x​, so b=12b = \tfrac{1}{2}b=21​. Now x2=8\tfrac{x}{2} = 82x​=8 gives x=16x = 16x=16, so (8,5)(8, 5)(8,5) moves out to (16,5)(16, 5)(16,5). The zeros stretch out too, to x=4x = 4x=4 and x=12x = 12x=12. Because 0<b<10 < b < 10<b<1, the graph is stretched away from the vertical axis by a factor of 1b=2\tfrac{1}{b} = 2b1​=2.

4x=a  ⇒  x=a44x = a \;\Rightarrow\; x = \tfrac{a}{4}4x=a⇒x=4a​

Reflecting across the y-axis: negate the input

The case b=−1b = -1b=−1 is the horizontal partner of the x-axis reflection. The rule

y=f(−x)y = f(-x)y=f(−x)

feeds fff the opposite input. Following the derivation above, a point (a,f(a))(a, f(a))(a,f(a)) reappears where the inside −x-x−x equals aaa, that is, at x=−ax = -ax=−a, so it moves to (−a,f(a))(-a, f(a))(−a,f(a)). Every point keeps its height but lands at the opposite horizontal position, which is a reflection across the y-axis: the graph flips left to right. A point already on the vertical axis has a=0a = 0a=0, and −0=0-0 = 0−0=0, so it stays fixed and serves as the hinge.

Worked example 4 Reflect a graph across the y-axis

Suppose fff passes through (3,5)(3, 5)(3,5) and (−1,2)(-1, 2)(−1,2), and its only x-intercept is at x=4x = 4x=4. Describe the graph of y=f(−x)y = f(-x)y=f(−x).

Reflection across the y-axis keeps every height and flips the sign of every input, so map each feature by negating its first coordinate:

(3,5)⟶(−3,5),(−1,2)⟶(1,2).(3, 5) \longrightarrow (-3, 5), \qquad (-1, 2) \longrightarrow (1, 2).(3,5)⟶(−3,5),(−1,2)⟶(1,2).

The x-intercept at x=4x = 4x=4 moves to x=−4x = -4x=−4, since setting the inside −x=4-x = 4−x=4 gives x=−4x = -4x=−4. Any point that happened to sit on the y-axis, where the input is 000, would not move at all. So y=f(−x)y = f(-x)y=f(−x) is the mirror image of y=f(x)y = f(x)y=f(x) across the vertical axis, with the whole picture swapped left for right while every height is preserved.

Answer choices

Negating the input reflects the graph across the y-axis, which flips the sign of the input while the height stays the same.

The height 222 is unchanged, which rules out the options that negate it; only the horizontal position flips sides.

Combining a scaling with a shift

Scalings and shifts stack, so a rule can do several things at once. Reading it correctly means separating what happens to the output from what happens to the input. For a vertical scaling followed by a shift,

y=a f(x−h)+k,y = a\,f(x - h) + k,y=af(x−h)+k,

the inside x−hx - hx−h moves the graph right by hhh, while the outside multiplies each height by aaa and then adds kkk. Tracking a single point makes the order clear: a point (p,q)(p, q)(p,q) on y=f(x)y = f(x)y=f(x) reappears at

(p+h, aq+k).\big(p + h,\ a q + k\big).(p+h, aq+k).

The input picks up the shift hhh, and the output is first scaled by aaa (which also flips it when aaa is negative) and then raised by kkk. The horizontal part touches only the first coordinate and the vertical part only the second, exactly as with pure shifts.

For a parabola this is the vertex form you already know, now read as a transformation. The rule y=a(x−h)2+ky = a(x - h)^2 + ky=a(x−h)2+k takes y=x2y = x^2y=x2, scales it vertically by aaa (reflecting it downward when a<0a < 0a<0), then moves the vertex to (h,k)(h, k)(h,k). The number aaa controls how narrow the bowl is and which way it opens; hhh and kkk say where its vertex sits.

Worked example 5 Graph y=−2x2y = -2x^2y=−2x2

Read the rule y=−2x2y = -2x^2y=−2x2 as y=a x2y = a\,x^2y=ax2 with a=−2a = -2a=−2, a single number that does two jobs. Its size, ∣a∣=2\lvert a \rvert = 2∣a∣=2, stretches the bowl vertically to twice its height, and its sign, negative, reflects it across the x-axis so it opens downward.

Apply both to the anchor points of y=x2y = x^2y=x2. Multiply each height by −2-2−2:

(1,1)⟶(1,−2),(2,4)⟶(2,−8).(1, 1) \longrightarrow (1, -2), \qquad (2, 4) \longrightarrow (2, -8).(1,1)⟶(1,−2),(2,4)⟶(2,−8).

The vertex (0,0)(0, 0)(0,0) holds still, since −2×0=0-2 \times 0 = 0−2×0=0. Plotting the results gives a downward parabola, narrower than y=x2y = x^2y=x2, whose highest point is the origin. What was the minimum of the plain bowl has become a maximum, and the graph is twice as steep, all encoded in the single coefficient −2-2−2.

Worked example 6 Include an actual shift: y=−2(x−3)2+1y = -2(x - 3)^2 + 1y=−2(x−3)2+1

That last example had no shift at all, since h=0h = 0h=0 and k=0k = 0k=0. Here is a rule where every part is doing something: a=−2a = -2a=−2, h=3h = 3h=3, k=1k = 1k=1. Track it with the point rule from before, (p,q)→(p+h, aq+k)(p, q) \to (p + h,\ a q + k)(p,q)→(p+h, aq+k).

(0,0)⟶(0+3, −2×0+1)=(3,1),(1,1)⟶(1+3, −2×1+1)=(4,−1).\begin{aligned} (0, 0) &\longrightarrow (0 + 3,\ -2 \times 0 + 1) \\ &= (3, 1), \\[4pt] (1, 1) &\longrightarrow (1 + 3,\ -2 \times 1 + 1) \\ &= (4, -1). \end{aligned}(0,0)(1,1)​⟶(0+3, −2×0+1)=(3,1),⟶(1+3, −2×1+1)=(4,−1).​

The vertex of y=x2y = x^2y=x2 at (0,0)(0, 0)(0,0) becomes the vertex of this parabola at (3,1)(3, 1)(3,1): shifted right 333 and up 111. Because a=−2a = -2a=−2 is negative, the graph opens downward and is twice as steep as y=x2y = x^2y=x2. Reading the rule this way gives the vertex, the opening direction, and the width without plotting a single extra point.

Scaling also reshapes the domain and range: a vertical scaling touches only the range, and a horizontal scaling touches only the domain.

Working out exactly how the endpoints move, including what happens when a reflection flips them, takes a couple of worked examples. You can read them in the Go deeper section at the end of this lesson.

Common mistakes

Common mistakes

  • Scaling horizontally the wrong way. y=f(bx)y = f(bx)y=f(bx) with b>1b > 1b>1 compresses the graph toward the vertical axis; it does not stretch it. The width scales by 1b\tfrac{1}{b}b1​, so a larger bbb means a narrower graph. Check it with one point: the inside bxbxbx reaches an old input at x=abx = \tfrac{a}{b}x=ba​, which is closer to 000.
  • Mixing up which change affects which direction. A factor multiplied outside the function, a f(x)a\,f(x)af(x), is a vertical scaling: it changes only the output, so (x0,y0)→(x0, ay0)(x_0, y_0) \to (x_0,\, a y_0)(x0​,y0​)→(x0​,ay0​). A factor multiplied with xxx inside the function, f(bx)f(bx)f(bx), is a horizontal scaling: it changes only the input, so (x0,y0)→(x0b, y0)(x_0, y_0) \to \left(\tfrac{x_0}{b},\, y_0\right)(x0​,y0​)→(bx0​​,y0​). Watch where the factor sits, and never rescale both coordinates for a single factor.
  • Adding instead of multiplying. A stretch multiplies a coordinate; a shift adds to it. For y=3f(x)y = 3f(x)y=3f(x) a point (2,5)(2, 5)(2,5) goes to (2,15)(2, 15)(2,15), not (2,8)(2, 8)(2,8). Multiply the height, do not add.
  • Thinking a reflection changes the shape. Reflecting across either axis flips the graph but never stretches or compresses it. Only a scale factor whose size differs from 111 changes how tall or wide the graph is.
  • Losing the fixed points. A vertical scaling pins every x-intercept in place (a height of 000 scales to 000); a horizontal scaling pins the y-intercept (an input of 000 scales to 000). If those anchor points drifted, recheck the work.

Key takeaways

  • Vertical scaling: y=a f(x)y = a\,f(x)y=af(x) multiplies every height by aaa, stretching the graph when a>1a > 1a>1 and compressing it when 0<a<10 < a < 10<a<1. Points map by (x0,y0)→(x0, ay0)(x_0, y_0) \to (x_0,\, a y_0)(x0​,y0​)→(x0​,ay0​), and every x-intercept stays fixed.
  • Reflection across the x-axis: y=−f(x)y = -f(x)y=−f(x) negates every output, flipping the graph over the x-axis (the case a=−1a = -1a=−1). A negative aaa scales and flips at once.
  • Horizontal scaling: y=f(bx)y = f(bx)y=f(bx) divides every input by bbb, so b>1b > 1b>1 compresses the graph toward the y-axis and 0<b<10 < b < 10<b<1 stretches it away. Points map by (x0,y0)→(x0b, y0)(x_0, y_0) \to \left(\tfrac{x_0}{b},\, y_0\right)(x0​,y0​)→(bx0​​,y0​), and the direction looks backward for the same reason shifts do.
  • Reflection across the y-axis: y=f(−x)y = f(-x)y=f(−x) negates every input, flipping the graph over the y-axis (the case b=−1b = -1b=−1), sending (x0,y0)→(−x0, y0)(x_0, y_0) \to (-x_0,\, y_0)(x0​,y0​)→(−x0​,y0​).
  • Combined: y=a f(x−h)+ky = a\,f(x - h) + ky=af(x−h)+k sends (p,q)→(p+h, aq+k)(p, q) \to (p + h,\ a q + k)(p,q)→(p+h, aq+k); for a parabola this is vertex form y=a(x−h)2+ky = a(x - h)^2 + ky=a(x−h)2+k, where aaa sets the width and opening and (h,k)(h, k)(h,k) is the vertex.
  • For a domain or range written as a single interval, a vertical scaling reshapes the range and a horizontal scaling reshapes the domain; a reflection swaps and reorders the endpoints of the interval it acts on.

Tracking domain and range through a scaling

Suppose fff has domain 0≤x≤80 \le x \le 80≤x≤8 and range −2≤y≤6-2 \le y \le 6−2≤y≤6. Track the domain and range of two transformed graphs.

For y=−2f(x)y = -2f(x)y=−2f(x), only the outputs change, so the domain stays 0≤x≤80 \le x \le 80≤x≤8. Each output is multiplied by −2-2−2, which scales the range endpoints and swaps them because the factor is negative:

−2×(−2)=4,−2×6=−12,-2 \times (-2) = 4, \qquad -2 \times 6 = -12,−2×(−2)=4,−2×6=−12,

so the new range runs from the lower value up, −12≤y≤4-12 \le y \le 4−12≤y≤4. The reflection is what turned the top of the old range into the bottom of the new one.

For y=f(2x)y = f(2x)y=f(2x), only the inputs change, so the range stays −2≤y≤6-2 \le y \le 6−2≤y≤6. Each input is divided by 222 (the inside 2x2x2x reaches the old inputs at half the xxx), so the domain endpoints halve:

0≤x≤8⟶0≤x≤4.0 \le x \le 8 \quad \longrightarrow \quad 0 \le x \le 4.0≤x≤8⟶0≤x≤4.

The graph is squeezed into half the horizontal room while covering the same heights.

A bit of history (optional)

A painter who needs a hundred different faces cannot invent every one from nothing. Albrecht Durer, a German painter who studied geometry, wondered whether a face could be altered by rule instead of by guesswork.

His answer appeared in 1528, in a book about human proportion. Durer drew a head over a square grid. Then he copied it across, square by square, onto a grid whose spacing he had deliberately changed. Pull the columns apart and the face broadens. Squeeze the rows together and it turns squat. Every one of those heads is the same head, redrawn against different spacings.

Those grids carry the exact distinction this lesson draws. Stretch both directions by the same factor and the shape survives untouched, since only its size has changed. Stretch one direction alone and the shape itself is remade. That is why y=2f(x)y = 2f(x)y=2f(x) and y=f(2x)y = f(2x)y=f(2x) do such different things to a single curve. It is also why a squeeze in one direction alone turns a careful portrait into a caricature.

Durer had a grid and a patient hand, and no equations whatever. You have the rule instead. Multiply the output by aaa and every height is scaled by aaa. Multiply the input by bbb and every width is divided by bbb. Put a minus sign on either one and the same operation arrives with a mirror attached.
