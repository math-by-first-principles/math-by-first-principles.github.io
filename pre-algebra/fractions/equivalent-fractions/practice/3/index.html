    Write 3648\frac{36}{48}4836​ in lowest terms.

    Answer choices for question 1

    Solution

    Correct answer: B

    Divide by the greatest common factor of 363636 and 484848. Both factor as 36=12×336 = 12 \times 336=12×3 and 48=12×448 = 12 \times 448=12×4, so the GCF is 121212.

    3648=36÷1248÷12=34\frac{36}{48} = \frac{36 \div 12}{48 \div 12} = \frac{3}{4}4836​=48÷1236÷12​=43​

    Since 333 and 444 share no factor above 111, 34\frac{3}{4}43​ is in lowest terms.

    Using equivalent fractions over a common denominator, which is larger, 34\frac{3}{4}43​ or 57\frac{5}{7}75​?

    Answer choices for question 3

    Solution

    Correct answer: B

    Rewrite both over the common denominator 282828.

    34=2128,57=2028\frac{3}{4} = \frac{21}{28}, \qquad \frac{5}{7} = \frac{20}{28}43​=2821​,75​=2820​

    With the same denominator, the larger numerator wins: 21>2021 > 2021>20, so 34>57\frac{3}{4} > \frac{5}{7}43​>75​.
