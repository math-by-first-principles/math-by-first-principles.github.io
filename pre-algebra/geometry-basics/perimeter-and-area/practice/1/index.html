  3. 3

    Which unit is used to measure area?

    Answer choices for question 3

    Solution

    Correct answer: B

    Area counts how many unit squares cover a shape, so it uses square units.

    Square metres (m2\text{m}^2m2) is an area unit; plain metres, kilometres, and centimetres are length units used for perimeter.
