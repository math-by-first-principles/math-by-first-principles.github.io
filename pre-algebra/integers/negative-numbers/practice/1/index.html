  1. 1

    Which of these is a negative number?

    Answer choices for question 1

    Solution

    Correct answer: A

    A negative number is less than zero and is written with a minus sign in front of it.

    −6<0-6 < 0−6<0

    The values 444 and 111111 are positive, and 000 is neither, so the only negative number is −6-6−6.

    How do you read the number −3-3−3 aloud?

    Answer choices for question 2

    Solution

    Correct answer: B

    In the numeral −3-3−3, the sign in front shows that the number is negative, so it is read with the word "negative."

    −3="negative three"-3 = \text{"negative three"}−3="negative three"

  3. 3

    On the number line, where do the negative numbers lie?

    Answer choices for question 3

    Solution

    Correct answer: D

    Zero splits the line. The positive numbers run to the right of zero.

    negatives  ←  0  →  positives\text{negatives} \;\leftarrow\; 0 \;\rightarrow\; \text{positives}negatives←0→positives

    So the negative numbers run to the left of zero.

  4. 4

    What is the opposite of 777?

    Answer choices for question 4

    Solution

    Correct answer: A

    The opposite of a number sits the same distance from zero, on the other side. The number 777 is seven units right of zero, so its opposite is seven units left.

    opposite of 7=−7\text{opposite of } 7 = -7opposite of 7=−7

  5. 5

    Which number is its own opposite?

    Answer choices for question 5

    Solution

    Correct answer: C

    Reflecting a number across zero gives its opposite. Only the number sitting exactly at zero stays in place when reflected.

    opposite of 0=0\text{opposite of } 0 = 0opposite of 0=0

    So zero is the only number that is its own opposite.

  6. 6

    Which symbol makes a true statement: −2  □  3-2 \;\square\; 3−2□3?

    Answer choices for question 6

    Solution

    Correct answer: D

    Every negative number lies to the left of every positive number, so a negative is always less than a positive.

    −2<3-2 < 3−2<3

  7. 7

    Which of these numbers is an integer?

    Answer choices for question 7

    Solution

    Correct answer: B

    Integers are the whole numbers and their negatives, the numbers that land right on the ticks of the line.

    −5 is an integer-5 \text{ is an integer}−5 is an integer

    The values 12\tfrac{1}{2}21​, 2.72.72.7, and 3.13.13.1 fall between the integer ticks, so they are not integers.

  8. 8

    A point sits 333 ticks to the right of zero. What number is it?

    Answer choices for question 8

    Solution

    Correct answer: C

    Points to the right of zero are positive, and the count gives the size.

    3 ticks right of 0=33 \text{ ticks right of } 0 = 33 ticks right of 0=3

  9. 9

    Is zero positive, negative, or neither?

    Answer choices for question 9

    Solution

    Correct answer: C

    Zero is the dividing point between the two sides of the line, the reference from which above and below are measured.

    0 is neither positive nor negative0 \text{ is neither positive nor negative}0 is neither positive nor negative

    What is the opposite of 000?

    Answer choices for question 10

    Solution

    Correct answer: B

    Zero sits exactly at the fold of the line, so reflecting it across zero leaves it in place.

    opposite of 0=0\text{opposite of } 0 = 0opposite of 0=0

  11. 11

    Which point is farther to the left on the number line, −2-2−2 or −9-9−9?

    Answer choices for question 11

    Solution

    Correct answer: D

    The more negative a number, the farther left it sits. The point −9-9−9 is nine steps left of zero, while −2-2−2 is two steps left.

    −9<−2-9 < -2−9<−2

    So −9-9−9 is farther to the left.

  12. 12

    Which symbol makes a true statement: −5  □  −5-5 \;\square\; -5−5□−5?

    Answer choices for question 12

    Solution

    Correct answer: A

    The two numbers are identical, so they sit at the same point on the line.

    −5=−5-5 = -5−5=−5
