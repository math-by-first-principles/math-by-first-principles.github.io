Absolute Value

Intuition

Multiplying and dividing kept pulling a number in two: multiply the sizes, then settle the sign separately. That size has had no name and no symbol of its own until now. Back when you first met the number line, you saw that 555 and −5-5−5 sit the same distance from zero, just on opposite sides. That distance is the size, and this lesson gives it a name and a way to write it. Sometimes it is all you care about, and the side does not matter. A diver 303030 meters below the surface and a kite 303030 meters above it are both 303030 meters from sea level. The absolute value of a number is that idea made precise: how far the number is from zero, ignoring which way. Because a distance is never negative, the absolute value of any number is never negative either.

Learning goals

  • Find any integer's absolute value by reading its distance from zero, so the answer is never negative
  • Explain why a number and its opposite share one absolute value
  • Say why the rule needs two cases, and why the negative case still gives a positive answer
  • Simplify inside the bars before measuring, and handle a minus sign written outside them
  • Measure how far apart two numbers are as the absolute value of their difference

Distance, without the direction

Every integer’s position on the number line carries two pieces of information. One is how far the number is from zero. The other is which side of zero it is on. The sign is what tells you that: a positive number sits to the right, a negative number to the left.

Often a problem cares only about the first piece. How far did the temperature move, up or down? To answer that, we need a way to keep the distance and let the side go.

The absolute value of a number is its distance from zero on the number line.

Distance is a count of equal steps, and you cannot take a negative number of steps along a line. So an absolute value is never negative.

The notation

To write “the distance of a number from zero,” we wrap the number in a pair of vertical bars. The absolute value of −5-5−5 is written ∣−5∣\lvert -5 \rvert∣−5∣, and we read it aloud as “the absolute value of negative five.” Since −5-5−5 is five units from zero,

∣−5∣=5.\lvert -5 \rvert = 5.∣−5∣=5.

The bars are a command: measure how far what is inside sits from zero, and report that distance. A few quick readings, straight off the line:

∣7∣=7,∣−7∣=7,∣0∣=0.\lvert 7 \rvert = 7, \qquad \lvert -7 \rvert = 7, \qquad \lvert 0 \rvert = 0.∣7∣=7,∣−7∣=7,∣0∣=0.

The number 777 is seven units from zero, and so is −7-7−7, so both have absolute value 777. Zero is no distance from itself, so ∣0∣=0\lvert 0 \rvert = 0∣0∣=0. Notice the output of the bars is just a number: once you have measured the distance, the bars have done their job and disappear.

Why the rule splits into two cases

If absolute value simply throws away a minus sign, why bother with a careful definition? Because “throw away the minus sign” describes what you see on the page. It is not a reason, and it stops working the moment a letter stands where the number was.

Read the two sides of zero off the line instead, one at a time.

A number that is already positive, or zero, sits at its own distance with nothing to undo. The point 777 is seven units to the right of zero, so ∣7∣=7\lvert 7 \rvert = 7∣7∣=7, the number itself.

A negative number is the interesting case. The point −5-5−5 lies five units to the left of zero, so its distance is 555. That 555 is the opposite of −5-5−5, and taking the opposite of a negative number gives a positive result: −(−5)=5-(-5) = 5−(−5)=5. So ∣−5∣=5\lvert -5 \rvert = 5∣−5∣=5, the opposite of the number.

Neither reading used the size of the number. What mattered was only which side of zero it sat on, so the same two readings work for any integer xxx. Writing them down needs one new symbol. The sign ≥\ge≥ is read “is greater than or equal to”, so x≥0x \ge 0x≥0 says that xxx is zero or above. It is the familiar >>> with the equal case allowed in as well.

∣x∣=xwhen x≥0,∣x∣=−xwhen x<0.\lvert x \rvert = x \qquad \text{when } x \ge 0, \qquad\qquad \lvert x \rvert = -x \qquad \text{when } x < 0.∣x∣=xwhen x≥0,∣x∣=−xwhen x<0.

The second case looks like it should be negative, and it is not. Here −x-x−x means the opposite of xxx, and xxx is negative in that case, so its opposite is positive.

The full argument shows why these two cases cover every integer, and why no third case is needed. One side of zero already counts its own units and the other does not, and every integer lies on one side or at zero. It also shows why the answer can never come out negative. You can read it in the Go deeper section at the end of this lesson.

Check your understanding

What is ∣−12∣\lvert -12 \rvert∣−12∣?

Answer choices

Absolute value is the distance from zero, and −12-12−12 sits 121212 units to the left of zero.

∣−12∣=12\lvert -12 \rvert = 12∣−12∣=12

The distance is 121212, a positive number, even though the number inside the bars is negative.

A number and its opposite share one absolute value

Opposites, as the first lesson of this chapter showed, are the same distance from zero on opposite sides. Absolute value reports exactly that distance, so it cannot tell 888 apart from −8-8−8: both give 888. That holds for every number and its opposite:

∣x∣=∣−x∣.\lvert x \rvert = \lvert -x \rvert.∣x∣=∣−x∣.

A small but useful consequence is that the only number with an absolute value of 000 is 000 itself. Any other number sits some positive distance from zero, so its absolute value is positive.

The bars are grouping symbols

The absolute-value bars are grouping symbols. Like parentheses, they tell you what to finish first. They also do one job parentheses do not: once the inside is a single number, the bars measure how far that number is from zero. So a pair of bars is two instructions in one, and the grouping happens first.

Compare two expressions that look almost identical:

∣(−3)+5∣versus∣−3∣+∣5∣.\lvert (-3) + 5 \rvert \qquad \text{versus} \qquad \lvert -3 \rvert + \lvert 5 \rvert.∣(−3)+5∣versus∣−3∣+∣5∣.

In the first, the bars group the sum, so add inside first and then take the absolute value:

∣(−3)+5∣=∣2∣=2.\lvert (-3) + 5 \rvert = \lvert 2 \rvert = 2.∣(−3)+5∣=∣2∣=2.

In the second, each number has its own bars, so take each absolute value first and then add:

∣−3∣+∣5∣=3+5=8.\lvert -3 \rvert + \lvert 5 \rvert = 3 + 5 = 8.∣−3∣+∣5∣=3+5=8.

The two are not equal. In the first expression the bars enclose (−3)+5(-3) + 5(−3)+5 and reduce it to the single number 222. The second never forms that sum at all, so it measures −3-3−3 and 555 separately and adds the two distances. So finish the arithmetic inside a pair of bars first. That leaves one number, and its distance from zero is the answer.

Check your understanding

Evaluate ∣(−8)+3∣\lvert (-8) + 3 \rvert∣(−8)+3∣.

Answer choices

The bars group the sum, so add inside first. Adding a positive to a negative means moving right: starting at −8-8−8 and adding 333 lands at −5-5−5.

∣(−8)+3∣=∣−5∣=5\lvert (-8) + 3 \rvert = \lvert -5 \rvert = 5∣(−8)+3∣=∣−5∣=5

The sum inside is −5-5−5, and its distance from zero is 555.

A minus sign written outside the bars

The bars measure only what stands between them. A minus sign written in front of a pair of bars is outside them, so it takes no part in the measuring. It waits until the measuring is done, and then takes the opposite of the result:

∣−4∣=4,−∣−4∣=−(4)=−4.\lvert -4 \rvert = 4, \qquad -\lvert -4 \rvert = -(4) = -4.∣−4∣=4,−∣−4∣=−(4)=−4.

The second answer is negative, and nothing has gone wrong, because it is not an absolute value. It is the opposite of one. “An absolute value is never negative” is a promise about what comes out from between the bars, and this minus sign was never between them.

Check your understanding

Evaluate −∣−9∣-\lvert -9 \rvert−∣−9∣.

Answer choices

Measure first, then apply the minus sign that stands outside the bars.

−∣−9∣=−(9)=−9-\lvert -9 \rvert = -(9) = -9−∣−9∣=−(9)=−9

The bars return the distance 999, and the minus in front takes the opposite of it. The answer is the opposite of an absolute value, so it is allowed to be negative.

Worked examples

Worked example 1 Evaluate ∣6−10∣\lvert 6 - 10 \rvert∣6−10∣

The bars are grouping symbols, so do the subtraction inside before taking the absolute value. Subtract first:

6−10=−4.6 - 10 = -4.6−10=−4.

Now take the absolute value of that single number. The point −4-4−4 is four units from zero:

∣6−10∣=∣−4∣=4.\lvert 6 - 10 \rvert = \lvert -4 \rvert = 4.∣6−10∣=∣−4∣=4.

A common slip is to compute ∣6∣−∣10∣=6−10=−4\lvert 6 \rvert - \lvert 10 \rvert = 6 - 10 = -4∣6∣−∣10∣=6−10=−4, but that ignores the grouping and even produces a negative result, which an absolute value can never be. Inside first, then the bars.

Worked example 2 Compare ∣−7∣\lvert -7 \rvert∣−7∣ and ∣5∣\lvert 5 \rvert∣5∣

Replace each absolute value with the distance it stands for, then compare those numbers the usual way.

The first is the distance of −7-7−7 from zero:

∣−7∣=7.\lvert -7 \rvert = 7.∣−7∣=7.

The second is the distance of 555 from zero:

∣5∣=5.\lvert 5 \rvert = 5.∣5∣=5.

Now compare the results: 7>57 > 57>5, so

∣−7∣>∣5∣.\lvert -7 \rvert > \lvert 5 \rvert.∣−7∣>∣5∣.

Even though −7<5-7 < 5−7<5 as signed numbers, −7-7−7 is farther from zero than 555 is, so it has the larger absolute value. Distance and order are different questions: one asks how far, the other asks which side.

Check your understanding

Which number has the greatest absolute value: −9-9−9, 666, −2-2−2, or 777?

Answer choices

Take the absolute value of each, since the question is about distance from zero, not about which is largest as a signed number.

∣−9∣=9,∣6∣=6,∣−2∣=2,∣7∣=7\lvert -9 \rvert = 9, \quad \lvert 6 \rvert = 6, \quad \lvert -2 \rvert = 2, \quad \lvert 7 \rvert = 7∣−9∣=9,∣6∣=6,∣−2∣=2,∣7∣=7

The largest distance is 999, from −9-9−9. The most negative number can still be the farthest from zero.

Distance between two numbers

Absolute value also answers a question you might not expect: how far apart are two numbers on the line?

Walk from 333 to 888 on the line and it takes five one-unit steps. The two subtractions give opposite results, −5-5−5 and 555. Taking the absolute value turns both of them into that same five:

∣3−8∣=∣−5∣=5,∣8−3∣=∣5∣=5.\lvert 3 - 8 \rvert = \lvert -5 \rvert = 5, \qquad \lvert 8 - 3 \rvert = \lvert 5 \rvert = 5.∣3−8∣=∣−5∣=5,∣8−3∣=∣5∣=5.

The subtraction 3−83 - 83−8 measures the signed gap, and its sign only records which number was taken from which. The bars throw that sign away and keep the size of the gap, which is what “how far apart” should mean. Since 3−83 - 83−8 and 8−38 - 38−3 are opposites, and opposites share one absolute value, the order of subtraction cannot change the answer.

So the gap between any two integers aaa and bbb is the absolute value of their difference,

distance between a and b=∣a−b∣.\text{distance between } a \text{ and } b = \lvert a - b \rvert.distance between a and b=∣a−b∣.

This works across zero too. The distance between −2-2−2 and 444 is

∣−2−4∣=∣−6∣=6,\lvert -2 - 4 \rvert = \lvert -6 \rvert = 6,∣−2−4∣=∣−6∣=6,

and the walk splits neatly at zero: two steps from −2-2−2 up to zero, then four more out to 444.

Worked example 3 Find the distance between −6-6−6 and 222

Use the distance rule: subtract the two numbers and take the absolute value of the result. Subtract first, remembering that subtracting a positive moves left:

−6−2=−8.-6 - 2 = -8.−6−2=−8.

Now take the absolute value to discard the sign and keep the size of the gap:

∣−6−2∣=∣−8∣=8.\lvert -6 - 2 \rvert = \lvert -8 \rvert = 8.∣−6−2∣=∣−8∣=8.

The two numbers are 888 units apart. You can confirm the answer by walking the line. Six one-unit steps take you from −6-6−6 up to zero, and two more reach 222, which is eight steps in all.

Common mistakes

Common mistakes

  • Thinking ∣x∣=−x\lvert x \rvert = -x∣x∣=−x is negative. When xxx is negative, −x-x−x is its opposite, and the opposite of a negative number is positive. So ∣−5∣=−(−5)=5\lvert -5 \rvert = -(-5) = 5∣−5∣=−(−5)=5, not −5-5−5.
  • Splitting the bars across an operation. The bars group what is inside, so ∣a+b∣\lvert a + b \rvert∣a+b∣ is not ∣a∣+∣b∣\lvert a \rvert + \lvert b \rvert∣a∣+∣b∣ in general. Compare ∣(−3)+5∣=2\lvert (-3) + 5 \rvert = 2∣(−3)+5∣=2 with ∣−3∣+∣5∣=8\lvert -3 \rvert + \lvert 5 \rvert = 8∣−3∣+∣5∣=8. Finish the inside first.
  • Dropping a minus sign that sits outside the bars. The bars measure only what stands between them. In −∣−4∣-\lvert -4 \rvert−∣−4∣ they return 444, and the minus in front then makes it −4-4−4. That answer is allowed to be negative, because it is the opposite of an absolute value rather than one.
  • Confusing “largest” with “largest absolute value.” As signed numbers −9<6-9 < 6−9<6, yet ∣−9∣=9\lvert -9 \rvert = 9∣−9∣=9 beats ∣6∣=6\lvert 6 \rvert = 6∣6∣=6, because a very negative number is a long way from zero.
  • Forgetting that distance has no direction. In ∣a−b∣\lvert a - b \rvert∣a−b∣, subtracting in either order gives the same answer, since a−ba - ba−b and b−ab - ab−a are opposites and share one absolute value.

Key takeaways

  • The absolute value ∣x∣\lvert x \rvert∣x∣ is the distance from xxx to zero on the number line, so it is always zero or positive.
  • It splits into two cases: ∣x∣=x\lvert x \rvert = x∣x∣=x when x≥0x \ge 0x≥0, and ∣x∣=−x\lvert x \rvert = -x∣x∣=−x (the opposite, which is positive) when x<0x < 0x<0.
  • A number and its opposite share one absolute value: ∣x∣=∣−x∣\lvert x \rvert = \lvert -x \rvert∣x∣=∣−x∣, for example ∣8∣=∣−8∣=8\lvert 8 \rvert = \lvert -8 \rvert = 8∣8∣=∣−8∣=8. The only number with absolute value 000 is 000.
  • The bars group like parentheses and then measure: simplify what is inside down to one number first, then take its distance, so ∣(−3)+5∣=∣2∣=2\lvert (-3) + 5 \rvert = \lvert 2 \rvert = 2∣(−3)+5∣=∣2∣=2. A minus sign written outside the bars is not measured, so −∣−4∣=−4-\lvert -4 \rvert = -4−∣−4∣=−4.
  • The distance between two numbers aaa and bbb is ∣a−b∣\lvert a - b \rvert∣a−b∣, and the order of subtraction does not change it.

Why the two cases cover every integer, and never return a negative answer

The lesson reads the two cases off the line on 777 and −5-5−5. This runs the same reading with a letter in place of the number, so it settles every integer at once.

Why ∣x∣=x\lvert x \rvert = x∣x∣=x when x≥0x \ge 0x≥0 and ∣x∣=−x\lvert x \rvert = -x∣x∣=−x when x<0x < 0x<0#

Let xxx stand for any integer, and recall that ∣x∣\lvert x \rvert∣x∣ is the distance from xxx to zero on the number line. Every integer sits either at or to the right of zero, or to the left of it. There is no third place for it to be, so two cases are enough to cover them all.

First suppose xxx is positive or zero, so xxx sits at or to the right of zero. The distance from zero to a point xxx units to the right is just xxx units, so there is nothing to flip:

∣x∣=xwhen x≥0.\lvert x \rvert = x \qquad \text{when } x \ge 0.∣x∣=xwhen x≥0.

Now suppose xxx is negative, so xxx sits to the left of zero. The number xxx is itself negative, so it cannot equal the distance, which must be positive. The distance is instead the opposite of xxx, and the opposite of a negative number is positive:

∣x∣=−xwhen x<0.\lvert x \rvert = -x \qquad \text{when } x < 0.∣x∣=−xwhen x<0.

Neither case used the size of the number, only which side of zero it sat on, so the two cases hold for every integer xxx. In the first case the answer is xxx itself, which is zero or positive there. In the second it is the opposite of a negative number, which is positive. So no integer produces a negative answer, which is exactly what a distance must never be.

∎

A bit of history (optional)

The idea in this lesson is much older than the symbol for it. For centuries writers had to spell it out in words: the value of the number, taken without regard to its sign. That is tolerable to write once. It is a burden when it belongs on every line of an argument. And that is where it kept turning up.

The name is the better clue anyway. Absolute comes from a Latin word meaning loosened, or set free. An absolute value is a number set free from its sign. What survives is the size, once you stop asking which side of zero the number sits on. Nothing else about it is kept.

The two bars are young by comparison. A German mathematician, Karl Weierstrass, first fenced a number between them in 1841. The shape is well chosen, because it looks like the instruction it carries. A wall goes up on each side, and the measuring waits until the arithmetic inside is finished.
