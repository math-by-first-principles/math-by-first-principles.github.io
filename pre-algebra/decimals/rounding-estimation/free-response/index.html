  1. Problem 1 The scale labels

    A scale can label a reading with either 27.827.827.8 or 27.927.927.9. Which label is nearer to 27.8627.8627.86?

    1. Hint 1

      Compare the distances from the reading to the two allowed labels.

    2. Hint 2

      Subtract the smaller number from the larger number for each distance.

    Answer

    27.927.927.9.

    Full solution

    The distance from the lower label is

    27.86−27.8=0.0627.86-27.8=0.0627.86−27.8=0.06

    The distance from the upper label is

    27.9−27.86=0.0427.9-27.86=0.0427.9−27.86=0.04

    Since 0.04<0.060.04<0.060.04<0.06, the label 27.927.927.9 is nearer.

    To the nearest tenth, 27.86≈27.927.86\approx27.927.86≈27.9.

    Answer

    27.927.927.9.

    Key idea

    Rounding selects the allowed value with the smaller distance from the original number.

  2. Problem 2 The logger entry

    A logger rounds each reading to the nearest thousandth and then records how many thousandths the rounded value contains. What does it record for a reading of 0.0036720.0036720.003672?

    1. Hint 1

      First decide which thousandth is nearer to the reading.

    2. Hint 2

      After rounding, express that value as a count of parts each worth one thousandth.

    Answer

    444.

    Full solution

    The reading is between 0.0030.0030.003 and 0.0040.0040.004, above their midpoint 0.00350.00350.0035.

    It therefore rounds to

    0.003672≈0.0040.003672\approx0.0040.003672≈0.004

    That rounded value is four thousandths.

    0.004=410000.004=\frac{4}{1000}0.004=10004​

    The logger records the count 444, rather than the decimal value of the reading.

    Answer

    444.

    Key idea

    After rounding to a place, the rounded value is a whole number of units of that place, so 0.0040.0040.004 is four thousandths.

  3. Problem 3 The combined charge

    A service makes two charges of 0.4860.4860.486 dollars each. The combined charge is then rounded to the nearest cent. What combined amount is billed?

    1. Hint 1

      Only the combined charge is rounded, so first work with the exact charges.

    2. Hint 2

      Add the charges, then round the sum to two decimal places, since a cent is one hundredth of a dollar.

    Answer

    0.970.970.97 dollars.

    Full solution

    First add the exact charges.

    0.486+0.486=0.9720.486+0.486=0.9720.486+0.486=0.972

    A cent is one hundredth of a dollar.

    The thousandths digit is 222, so the hundredths digit stays as it is.

    0.972≈0.970.972\approx0.970.972≈0.97

    The billed amount is 0.970.970.97 dollars.

    Rounding each charge first would give 0.49+0.49=0.980.49+0.49=0.980.49+0.49=0.98 dollars, one cent more, so rounding before adding changes the bill.

    Answer

    0.970.970.97 dollars.

    Key idea

    When a total must be rounded, compute the exact total before rounding it once.

  4. Problem 4 The unfinished record

    A reading is written 17.9□17.9\square17.9□, where the box holds one digit. Which digits in the box make the reading round to 18.018.018.0 to the nearest tenth? Use round half up for an exact tie.

    1. Hint 1

      The missing digit is immediately after the rounding place.

    2. Hint 2

      Find the midpoint between the two possible rounded readings, including how an exact tie is treated.

    Answer

    555, 666, 777, 888 and 999.

    Full solution

    The two neighboring tenths are 17.917.917.9 and 18.018.018.0, with midpoint 17.9517.9517.95.

    The missing digit is in the hundredths column.

    At the midpoint, round half up gives

    17.95≈18.017.95\approx18.017.95≈18.0

    Each larger digit also rounds upward.

    Digits below 555 stay below the midpoint, for example

    17.94≈17.917.94\approx17.917.94≈17.9

    Thus the allowed digits are 555, 666, 777, 888 and 999.

    Rounding up turns the nine tenths into a whole, so the recorded result is 18.018.018.0.

    Answer

    555, 666, 777, 888 and 999.

    Key idea

    Find the midpoint and include its tie convention when recovering digits from a rounded result.

  5. Problem 5 The trip log

    A trip meter reads 12.38412.38412.384 km before a journey and 17.0817.0817.08 km afterward. What distance should be entered in a log that reports journeys to the nearest hundredth of a km?

    1. Hint 1

      The journey distance is the change in the meter reading.

    2. Hint 2

      Pad the final reading to three decimal places before subtracting, then watch for a 999 that carries when the hundredths digit rounds up.

    Answer

    4.704.704.70 km.

    Full solution

    Pad the final reading to thousandths and subtract the starting reading.

    17.080−12.384=4.69617.080-12.384=4.69617.080−12.384=4.696

    The thousandths digit is 666, so the hundredths digit rounds upward.

    Raising nine hundredths carries into the tenths.

    4.696≈4.704.696\approx4.704.696≈4.70

    The log should record 4.704.704.70 km.

    Before rounding, adding 4.6964.6964.696 km to the starting reading returns the final reading.

    Answer

    4.704.704.70 km.

    Key idea

    When the digit in the rounding place is a 999 that rounds up, it carries into the place on its left, so 4.6964.6964.696 rounds to 4.704.704.70.

  6. Problem 6 The two measurements

    Two measurements are 6.486.486.48 meters and 2.512.512.51 meters. Estimate their difference by rounding each to the nearest whole number. Without finding the exact difference, say whether the estimate is above or below it and why; then find the exact difference to check.

    1. Hint 1

      The estimate uses rounded measurements, while the exact difference uses the original values.

    2. Hint 2

      Note which way each measurement moved when it was rounded, and how each move changes a difference.

    3. Hint 3

      Subtract the original measurements last, to check the prediction you made from those moves.

    Answer

    Estimate: 333 meters, below the exact difference of 3.973.973.97 meters.

    Full solution

    To the nearest whole number, 6.48≈66.48\approx66.48≈6 and 2.51≈32.51\approx32.51≈3.

    The estimate is

    6−3=36-3=36−3=3

    Rounding lowered the first measurement, and a smaller starting number gives a smaller difference.

    Rounding raised the second measurement, and subtracting a larger number also gives a smaller difference.

    Both changes shrink the difference, so the estimate is below the exact difference.

    The exact difference is

    6.48−2.51=3.976.48-2.51=3.976.48−2.51=3.97

    The estimate is below it, as predicted, by 0.970.970.97 meters.

    3.97−3=0.973.97-3=0.973.97−3=0.97

    Answer

    Estimate: 333 meters, below the exact difference of 3.973.973.97 meters.

    Key idea

    When a difference is estimated, rounding the first number down and the second number up both push the estimate below the exact difference.

  7. Problem 7 The carrier limit

    Two containers weigh 18.418.418.4 kg and 13.713.713.7 kg. A carrier can hold at most 323232 kg. Estimate their combined weight by rounding each weight to the nearest whole number. Does the estimate settle whether the carrier can hold both? Decide whether it can.

    1. Hint 1

      Compare the estimate with the limit, then ask how far the two roundings could have moved the estimate away from the true total.

    2. Hint 2

      Add the rounded weights and the original weights separately.

    Answer

    Estimate: 323232 kg, which does not settle it; exact total: 32.132.132.1 kg; the carrier cannot hold both.

    Full solution

    The rounded weights are 181818 kg and 141414 kg, giving

    18+14=3218+14=3218+14=32

    The estimate lands exactly on the 323232 kg limit.

    Each weight moved by less than half a kilogram when it was rounded, so the true total could lie on either side of the limit, and the estimate does not settle the question.

    The exact total is

    18.4+13.7=32.118.4+13.7=32.118.4+13.7=32.1

    The exact total is 0.10.10.1 kg over the 323232 kg limit, so the carrier cannot hold both.

    Rounding moved 18.418.418.4 down by 0.40.40.4 but 13.713.713.7 up by 0.30.30.3, so the estimate came out 0.10.10.1 kg too low and seemed to fit.

    Answer

    Estimate: 323232 kg, which does not settle it; exact total: 32.132.132.1 kg; the carrier cannot hold both.

    Key idea

    Use exact amounts when an estimate is too close to a stated limit to settle a decision.

  8. Problem 8 The covered digits

    A terminating decimal starts with 6.476.476.47, and its remaining digits are covered. Using round half up, which of these can be settled now: the number to the nearest whole number, to the nearest tenth, and to the nearest hundredth? Give each value that can be settled and explain.

    1. Hint 1

      The visible digits fix a range the number must lie in; compare that range with the midpoint between the two neighbors at each place asked.

    2. Hint 2

      The covered digits add less than one hundredth to the visible starting value.

    3. Hint 3

      A rounding is settled when the whole range sits on one side of its midpoint, and still open when the range reaches both sides.

    Answer

    Nearest whole number: 666; nearest tenth: 6.56.56.5; nearest hundredth: cannot be settled (6.476.476.47 or 6.486.486.48).

    Full solution

    Whatever the covered digits are, they add less than one hundredth to 6.476.476.47, so the number is at least 6.476.476.47 and below 6.486.486.48.

    For the nearest whole number, the neighbors are 666 and 777, with midpoint 6.56.56.5.

    The whole range lies below 6.56.56.5, so the number rounds to 666.

    For the nearest tenth, the neighbors are 6.46.46.4 and 6.56.56.5, with midpoint 6.456.456.45.

    The whole range lies past 6.456.456.45, so the number rounds to 6.56.56.5.

    For the nearest hundredth, the neighbors are 6.476.476.47 and 6.486.486.48, with midpoint 6.4756.4756.475.

    The range reaches both sides of it: 6.4716.4716.471 would round to 6.476.476.47, and 6.4796.4796.479 would round to 6.486.486.48.

    That rounding depends on the covered thousandths digit, so it cannot be settled yet.

    Answer

    Nearest whole number: 666; nearest tenth: 6.56.56.5; nearest hundredth: cannot be settled (6.476.476.47 or 6.486.486.48).

    Key idea

    For a nonnegative terminating decimal under round half up, a rounding can be settled once the digit just right of the rounding place is visible.

  9. Problem 9 The matching results

    Under round half up, both 4.2504.2504.250 and 4.2514.2514.251 round to 4.34.34.3 to the nearest tenth. A student says that switching to round half down would change both results. Is the student correct? Explain.

    1. Hint 1

      The same rounded result does not require the same relationship to the midpoint.

    2. Hint 2

      Compare each original value with the midpoint between the neighboring tenths.

    Answer

    No; under round half down 4.2504.2504.250 becomes 4.24.24.2, while 4.2514.2514.251 still rounds to 4.34.34.3.

    Full solution

    The midpoint between 4.24.24.2 and 4.34.34.3 is 4.254.254.25.

    The first value is exactly there.

    Its distance to the lower tenth is

    4.250−4.2=0.0504.250-4.2=0.0504.250−4.2=0.050

    Its distance to the upper tenth is the same.

    4.3−4.250=0.0504.3-4.250=0.0504.3−4.250=0.050

    So 4.2504.2504.250 is a tie, and the tie rule decides it: round half up gives 4.34.34.3, while round half down gives 4.24.24.2.

    The second value is past the midpoint.

    Its distance to the lower tenth is

    4.251−4.2=0.0514.251-4.2=0.0514.251−4.2=0.051

    Its distance to the upper tenth is

    4.3−4.251=0.0494.3-4.251=0.0494.3−4.251=0.049

    Since 4.34.34.3 is strictly nearer, 4.2514.2514.251 rounds to 4.34.34.3 under either tie rule.

    Switching rules changes only the result for 4.2504.2504.250, so the student is not correct.

    Answer

    No; under round half down 4.2504.2504.250 becomes 4.24.24.2, while 4.2514.2514.251 still rounds to 4.34.34.3.

    Key idea

    Switching the tie convention changes a rounded result only when the value sits exactly on the midpoint.

  10. Problem 10 The filling log

    A machine fills 181818 bins with 4.354.354.35 liters each. Its log printed the total's digits as 783783783 but lost the decimal point. Use an estimate, with the amount in each bin rounded to the nearest whole number, to place the point, and explain, from the most each bin's amount could have moved when it was rounded, why no other placement of the point is possible.

    1. Hint 1

      The total amount is the number of bins multiplied by the amount that goes into each bin.

    2. Hint 2

      Compare the rounded product with the values the digits can make as the point moves, and keep the one of the right size.

    3. Hint 3

      Each bin's amount moved by less than half a liter when it was rounded. How far could eighteen such moves shift the total?

    Answer

    Estimate: 727272 liters; total: 78.378.378.3 liters.

    Full solution

    The amount in each bin rounds to 444 liters, and 181818 is already a whole number.

    The estimate is

    18×4=7218\times4=7218×4=72

    Placing the point in the digits 783783783 gives values such as 7.837.837.83, 78.378.378.3 and 783783783.

    Only 78.378.378.3 is near 727272, so the total has two digits before its point.

    Each bin's amount moved by less than half a liter when it was rounded, so the eighteen moves together shift the total by less than

    18×0.5=918\times0.5=918×0.5=9

    So the true total lies within 999 liters of 727272, between 636363 and 818181.

    78.378.378.3 lies in that range, while every other placement is at most 7.837.837.83 or at least 783783783, far outside it, so no other placement of the point is possible.

    As a check, multiply the digits as whole numbers.

    18×435=783018\times435=783018×435=7830

    The factor 4.354.354.35 has two decimal places, so the product is 78.3078.3078.30, which is 78.378.378.3 liters and matches the printed digits 783783783.

    Answer

    Estimate: 727272 liters; total: 78.378.378.3 liters.

    Key idea

    Knowing how far rounding could move each input bounds how far an estimate can miss, and that bound can rule out a misplaced decimal point.
