    What is −23−14-\tfrac{2}{3} - \tfrac{1}{4}−32​−41​?

    Answer choices for question 2

    Solution

    Correct answer: D

    Subtracting is adding the opposite: −23+(−14)-\tfrac{2}{3} + \left(-\tfrac{1}{4}\right)−32​+(−41​). Both are negative, so add the sizes over twelfths and keep the minus sign.

    812+312=1112\frac{8}{12} + \frac{3}{12} = \frac{11}{12}128​+123​=1211​

    So the answer is −1112-\tfrac{11}{12}−1211​. The choice −512-\tfrac{5}{12}−125​ subtracts the sizes, which is the rule for different signs.

    What is 0÷(−37)0 \div \left(-\tfrac{3}{7}\right)0÷(−73​)?

    Answer choices for question 11

    Solution

    Correct answer: B

    Division asks for the missing factor: what number times −37-\tfrac{3}{7}−73​ gives 000? Exactly one number does, and it is 000.

    0×(−37)=00 \times \left(-\frac{3}{7}\right) = 00×(−73​)=0

    So the quotient is 000. Only dividing by zero is undefined; dividing zero by a nonzero number is fine.
