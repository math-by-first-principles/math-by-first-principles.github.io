  1. 1

    In 0.5550.5550.555, the value of the leftmost 555 is how many times the value of the rightmost 555?

    Answer choices for question 1

    Solution

    Correct answer: B

    The leftmost 555 is in the tenths place (value 510\tfrac{5}{10}105​) and the rightmost 555 is in the thousandths place (value 51000\tfrac{5}{1000}10005​). Divide the two values.

    5/105/1000=100010=100\frac{5/10}{5/1000} = \frac{1000}{10} = 1005/10005/10​=101000​=100

    So the leftmost 555 is worth 100100100 times the rightmost 555.

    Which decimal is the greatest: 0.40.40.4, 0.390.390.39, 0.4010.4010.401, 0.410.410.41?

    Answer choices for question 2

    Solution

    Correct answer: D

    Pad to three places and compare from the left. The tenths digit is 444 for all but 0.3900.3900.390, which has 333. Among the 444-tenths group, compare hundredths: 0.4000.4000.400 and 0.4010.4010.401 have 000, while 0.4100.4100.410 has 111.

    0.41>0.401>0.4>0.390.41 > 0.401 > 0.4 > 0.390.41>0.401>0.4>0.39

    So 0.410.410.41 is greatest; more digits does not mean larger.

    How many hundredths are in 0.40.40.4?

    Answer choices for question 4

    Solution

    Correct answer: C

    Rewrite 0.40.40.4 with the same denominator as one hundredth. Since 410=40100\tfrac{4}{10} = \tfrac{40}{100}104​=10040​, it is forty hundredths.

    So 0.40.40.4 contains 404040 hundredths.

    Using the digits 000, 444, and 777 each once after a decimal point (as 0._ _ _0.\_\,\_\,\_0.___), what is the smallest decimal you can form?

    Answer choices for question 5

    Solution

    Correct answer: A

    To make a decimal small, put the smallest digit in the highest place after the point (the tenths), then continue in increasing order.

    0.0⏟tenths4⏟hundredths7⏟thousandths=0.0470.\underbrace{0}_{\text{tenths}}\underbrace{4}_{\text{hundredths}}\underbrace{7}_{\text{thousandths}} = 0.0470.tenths0​​hundredths4​​thousandths7​​=0.047

    A 000 in the tenths place makes the value less than any choice with 444 or 777 there.

    The value of the digit 666 is exactly 6100\tfrac{6}{100}1006​ in which decimal?

    Answer choices for question 7

    Solution

    Correct answer: D

    A value of 6100\tfrac{6}{100}1006​ puts the 666 in the hundredths place, the second place after the point.

    6×1100=61006 \times \frac{1}{100} = \frac{6}{100}6×1001​=1006​

    Only 0.360.360.36 has the 666 as its second digit after the point. In 0.60.60.6 and 0.630.630.63 the 666 is in the tenths place (worth 610\tfrac{6}{10}106​), and in 0.0060.0060.006 it is in the thousandths place (worth 61000\tfrac{6}{1000}10006​).

    Answer choices for question 8

    Solution

    Correct answer: C

    As tenths, 0.5=5100.5 = \tfrac{5}{10}0.5=105​, so it is five tenths. Rewriting over a hundred, 510=50100\tfrac{5}{10} = \tfrac{50}{100}105​=10050​, so it is fifty hundredths.

    Which statement about the decimal 0.4080.4080.408 is true?

    Answer choices for question 9

    Solution

    Correct answer: B

    The last digit, 888, sits in the thousandths place, and the digits "408" read as a whole number named by that last place.

    0.408=40810000.408 = \frac{408}{1000}0.408=1000408​

    So it reads "four hundred eight thousandths." The 444 is worth 410\tfrac{4}{10}104​, the 888 is thousandths, and 0.408≠0.480.408 \ne 0.480.408=0.48, so the other statements are false.

  10. 10

    Reading 0.070.070.07 and 0.70.70.7, the value of 0.70.70.7 is how many times the value of 0.070.070.07?

    Answer choices for question 10

    Solution

    Correct answer: D

    Write both as fractions: 0.7=7100.7 = \tfrac{7}{10}0.7=107​ and 0.07=71000.07 = \tfrac{7}{100}0.07=1007​. Divide one by the other.

    7/107/100=10010=10\frac{7/10}{7/100} = \frac{100}{10} = 107/1007/10​=10100​=10

    So 0.70.70.7 is ten times 0.070.070.07, just as each place is ten times the place to its right.
