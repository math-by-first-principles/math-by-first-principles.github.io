    Answer choices for question 8

    Solution

    Correct answer: C

    A zero on the far right does not change a decimal's value, so padding 0.450.450.45 with a trailing zero gives 0.4500.4500.450.

    0.45=0.4500.45 = 0.4500.45=0.450

    So the two decimals are equal.

  12. 12

    In 0.660.660.66, the value of the first 666 is how many times the value of the second 666?

    Answer choices for question 12

    Solution

    Correct answer: A

    The first 666 is in the tenths place (value 610\tfrac{6}{10}106​) and the second 666 is in the hundredths place (value 6100\tfrac{6}{100}1006​). Each place is ten times the place to its right.

    6/106/100=610×1006=10\frac{6/10}{6/100} = \frac{6}{10} \times \frac{100}{6} = 106/1006/10​=106​×6100​=10

    So the first 666 is worth 101010 times the second.
