  4. Problem 4 After the game

    A stadium has 232^323 stands. Each stand has 252^525 rows, and each row has 252^525 seats. After a game, 242^424 cleaning crews share the seats equally. How many seats does each crew clean? Give the answer as a single power of 222.

    The seat count is the number of stands times the rows in each stand times the seats in each row.

    213÷24=292^{13}\div2^4=2^9213÷24=29

    So each crew cleans 292^929 seats, which is 512512512 seats.

    8192÷16=512.8192\div16=512.8192÷16=512.

    Answer

    292^929 seats, which is 512512512 seats.

    Key idea

    Equal groups inside equal groups multiply, so their exponents add, and an equal share divides, so its exponent is subtracted, with the base unchanged.
