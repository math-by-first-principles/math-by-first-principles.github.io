Problem 1 of 10

  1. Problem 1 Color labels

    A roll contains rrr red labels and bbb blue labels. Write an expression in rrr and bbb for the total number of labels.

    1. Hint 1

      The total includes both colors.

    2. Hint 2

      Picture a roll with 444 red and 666 blue labels. What would you do with 444 and 666 to get the total? Do the same with the letters.

    Answer

    r+br+br+b, or b+rb+rb+r, labels.

    Full solution

    The letter rrr stands for the number of red labels, and bbb stands for the number of blue labels.

    Adding the two counts gives the total:

    r+br+br+b

    The expression b+rb+rb+r gives the same total because changing the order of addition does not change its value.

    Neither count needs to be known before the expression is written.

    Answer

    r+br+br+b, or b+rb+rb+r, labels.

    Key idea

    A letter lets one expression describe a quantity even when its component counts are unknown.

  2. Problem 2 An expression to build

    Write an expression with two terms in which the coefficient of kkk is −15-\frac{1}{5}−51​ and the constant is 121212, with kkk written in the numerator of a fraction.

    1. Hint 1

      The coefficient is the number multiplying the variable, including its sign.

    2. Hint 2

      Dividing by 555 is multiplying by 15\frac{1}{5}51​.

    Answer

    −k5+12-\frac{k}{5}+12−5k​+12, or 12−k512-\frac{k}{5}12−5k​ (also −k5+12\frac{-k}{5}+125−k​+12).

    Full solution

    A coefficient of −15-\frac{1}{5}−51​ means negative one fifth of kkk:

    −15k=−k5-\frac{1}{5}k=-\frac{k}{5}−51​k=−5k​

    Adding the constant term 121212 gives the two-term expression −k5+12-\frac{k}{5}+12−5k​+12.

    Writing the same two terms in the other order gives 12−k512-\frac{k}{5}12−5k​.

    Answer

    −k5+12-\frac{k}{5}+12−5k​+12, or 12−k512-\frac{k}{5}12−5k​ (also −k5+12\frac{-k}{5}+125−k​+12).

    Key idea

    A variable in a fraction can have a fractional coefficient.

  3. Problem 3 A numerator to finish

    Find the value of 2−3v5\frac{2-3v}{5}52−3v​ when v=−6v=-6v=−6.

    1. Hint 1

      The fraction bar groups the entire numerator.

    2. Hint 2

      Replace vvv with (−6)(-6)(−6), multiply before subtracting in the numerator, then divide.

    Answer

    444

    Full solution

    Substitute the given value in parentheses.

    In the numerator, multiply before subtracting, and subtracting a negative means adding its opposite:

    2−3(−6)=2−(−18)2−(−18)=20\begin{aligned}2-3(-6)&=2-(-18)\\2-(-18)&=20\end{aligned}2−3(−6)2−(−18)​=2−(−18)=20​

    The whole numerator is now finished, so divide it by the denominator:

    205=4\frac{20}{5}=4520​=4

    Answer

    444

    Key idea

    Inside a numerator the order of operations still applies, and the whole numerator is finished before it is divided by the denominator.

  4. Problem 4 Two letters and a phrase

    Write "three less than half the sum of aaa and bbb" as an expression. Then find its value when a=−10a=-10a=−10 and b=4b=4b=4.

    1. Hint 1

      First identify the amount from which three is taken away.

    2. Hint 2

      Half the sum means add the two inputs before dividing by two.

    3. Hint 3

      Put each given value in parentheses and finish the grouped sum first.

    Answer

    a+b2−3\frac{a+b}{2}-32a+b​−3, or 12(a+b)−3\frac{1}{2}(a+b)-321​(a+b)−3 (either order of aaa and bbb); value −6-6−6.

    Full solution

    The sum must stay together when it is halved.

    Three less than that amount means starting from the half and subtracting 333 afterward, giving a+b2−3\frac{a+b}{2}-32a+b​−3 rather than 3−a+b23-\frac{a+b}{2}3−2a+b​.

    Halving is multiplying by 12\frac{1}{2}21​, so 12(a+b)−3\frac{1}{2}(a+b)-321​(a+b)−3 records the same amount.

    Reversing the order of the two addends in either form gives the same amount too.

    For the given inputs, the sum is −6-6−6 and half of it is −3-3−3:

    (−10)+(4)2−3=−6\frac{(-10)+(4)}{2}-3=-62(−10)+(4)​−3=−6

    Three less than −3-3−3 is −6-6−6, so the number matches the phrase.

    Answer

    a+b2−3\frac{a+b}{2}-32a+b​−3, or 12(a+b)−3\frac{1}{2}(a+b)-321​(a+b)−3 (either order of aaa and bbb); value −6-6−6.

    Key idea

    Read a grouped phrase as a whole before carrying out an operation on it.

  5. Problem 5 Pages in a pad

    Tom's pad starts with ppp pages, and he uses 888 of them. Write the number of pages Tom has left, using only ppp and 888. Ana's pad started with qqq pages; she has used 666 and has exactly 131313 left. Write one line, using qqq, 666 and 131313, about the pages Ana has left. For each of your two lines, say whether it is an expression or an equation and whether you would evaluate it or solve it; do not solve.

    1. Hint 1

      An amount can be described without claiming it equals a particular number.

    2. Hint 2

      Ana's pad has a known final amount; how do you write that one amount is equal to another?

    Answer

    p−8p-8p−8: expression, evaluate; q−6=13q-6=13q−6=13 (or 13=q−613=q-613=q−6): equation, solve.

    Full solution

    For Tom's pad, subtract the pages used from the starting number:

    p−8p-8p−8

    That line has no equals sign, so it is an expression, and it can be evaluated after a value of ppp is chosen.

    For Ana's pad, the pages left are q−6q-6q−6, and that amount is known to be 131313, so the line is

    q−6=13q-6=13q−6=13

    That line has an equals sign, so it is an equation.

    Solving it would find the starting number that makes the equality true, while the first line names the pages left for any starting number ppp.

    Answer

    p−8p-8p−8: expression, evaluate; q−6=13q-6=13q−6=13 (or 13=q−613=q-613=q−6): equation, solve.

    Key idea

    An expression names an amount, while an equation states that two amounts are equal.

  6. Problem 6 An expression to read

    For −a2+2b−c+9-a^2+2b-c+9−a2+2b−c+9, name each term with its sign, give the coefficient of each variable term, and name the constant.

    1. Hint 1

      A term carries the sign written in front of it.

    2. Hint 2

      A missing visible multiplier can still mean one copy, or negative one copy, of a variable part.

    Answer

    Terms: −a2-a^2−a2, 2b2b2b, −c-c−c, 999; coefficients: −1-1−1, 222, −1-1−1 respectively; constant: 999.

    Full solution

    The additions and subtractions separate four terms.

    Keeping each sign with its term gives −a2-a^2−a2, 2b2b2b, −c-c−c, and 999.

    The two invisible multipliers become visible when the terms are written as

    −a2=(−1)a2-a^2=(-1)a^2−a2=(−1)a2

    and

    −c=(−1)c-c=(-1)c−c=(−1)c

    Thus the coefficients are −1-1−1, 222, and −1-1−1.

    The term 999 contains no variable, so it is the constant.

    Answer

    Terms: −a2-a^2−a2, 2b2b2b, −c-c−c, 999; coefficients: −1-1−1, 222, −1-1−1 respectively; constant: 999.

    Key idea

    Terms keep their signs, including when their coefficients are not written explicitly.

  7. Problem 7 A storage panel

    A panel has 484848 empty slots. A morning group fills qqq slots and an afternoon group fills ttt different slots. Write the number of empty slots left as an expression in qqq and ttt. Find that number when q=14q=14q=14 and t=18t=18t=18.

    1. Hint 1

      Both groups reduce the number of empty slots.

    2. Hint 2

      Take away each group from the starting total without taking any slot away twice.

    Answer

    48−q−t48-q-t48−q−t, 48−t−q48-t-q48−t−q, or 48−(q+t)48-(q+t)48−(q+t); 161616 slots left.

    Full solution

    The occupied groups do not overlap, so each must be removed from the 484848 starting slots.

    Either 48−q−t48-q-t48−q−t or 48−t−q48-t-q48−t−q records that.

    Taking away the two groups' total at once, 48−(q+t)48-(q+t)48−(q+t), records the same count.

    Substitute the counts and subtract from left to right:

    48−(14)−(18)=34−1834−18=16\begin{aligned}48-(14)-(18)&=34-18\\34-18&=16\end{aligned}48−(14)−(18)34−18​=34−18=16​

    The occupied slots total 14+18=3214+18=3214+18=32, and 32+16=4832+16=4832+16=48, checking the remaining count.

    Answer

    48−q−t48-q-t48−q−t, 48−t−q48-t-q48−t−q, or 48−(q+t)48-(q+t)48−(q+t); 161616 slots left.

    Key idea

    Defined variables can record separate contributions to one total.

  8. Problem 8 Noah's written work

    Noah is finding n−n4n-\frac{n}{4}n−4n​ when n=−8n=-8n=−8. He writes −8−84-8-\frac{8}{4}−8−48​. Is his substitution correct? Explain and give the correct value.

    1. Hint 1

      Every occurrence of the same letter has the same value within one evaluation.

    2. Hint 2

      Compare each occurrence of nnn with the number in its place, sign included.

    Answer

    No; the correct value is −6-6−6.

    Full solution

    Noah wrote −8-8−8 for the first nnn but 888 for the second, dropping its sign.

    Both occurrences must receive the stated value −8-8−8, and parentheses keep its sign.

    The correct computation divides before subtracting, and subtracting −2-2−2 means adding 222:

    (−8)−(−8)4=−8−(−2)−8−(−2)=−6\begin{aligned}(-8)-\frac{(-8)}{4}&=-8-(-2)\\-8-(-2)&=-6\end{aligned}(−8)−4(−8)​−8−(−2)​=−8−(−2)=−6​

    Noah's line gives −8−2=−10-8-2=-10−8−2=−10 instead, so his substitution is not correct.

    Answer

    No; the correct value is −6-6−6.

    Key idea

    Use the given value, sign included, at every occurrence of the same variable.

  9. Problem 9 Jules's swap

    For the expression ab−4ab-4ab−4, Jules claims that exchanging the values assigned to aaa and bbb leaves the result unchanged. Is this true for every pair of numbers? Explain.

    1. Hint 1

      Only the order of the two factors changes when the inputs are exchanged.

    2. Hint 2

      Compare the products ababab and bababa before considering the subtraction.

    Answer

    Yes, for every pair of numbers.

    Full solution

    Exchanging the inputs changes the product from ababab to bababa.

    The commutative property of multiplication gives

    ab=baab=baab=ba

    Subtracting the same 444 from equal products preserves equality:

    ab−4=ba−4ab-4=ba-4ab−4=ba−4

    Thus Jules is correct for every pair of numbers, including negative numbers and zero.

    Answer

    Yes, for every pair of numbers.

    Key idea

    Exchanging two factors leaves their product unchanged, so subtracting the same number from it gives the same result.

  10. Problem 10 Lena's claim

    Lena says that choosing different values of rrr must give different values of r2−7r^2-7r2−7. Test r=−4r=-4r=−4 and r=4r=4r=4, then explain whether her claim is true.

    1. Hint 1

      Think about what squaring does to the sign of a negative input.

    2. Hint 2

      Use parentheses around the negative input, and compare the two final values.

    Answer

    Both values are 999; Lena's claim is false.

    Full solution

    For the negative input, the square comes before the subtraction, and the square of a negative number is positive:

    (−4)2−7=16−716−7=9\begin{aligned}(-4)^2-7&=16-7\\16-7&=9\end{aligned}(−4)2−716−7​=16−7=9​

    For the positive input,

    (4)2−7=16−716−7=9\begin{aligned}(4)^2-7&=16-7\\16-7&=9\end{aligned}(4)2−716−7​=16−7=9​

    The inputs differ but the outputs agree, so the claim is false.

    The inputs −4-4−4 and 444 are opposites, so they have the same square, and subtracting 777 from equal squares gives equal values.

    Answer

    Both values are 999; Lena's claim is false.

    Key idea

    An expression containing a variable can still have the same value for different inputs.
