    Which of these lines is an equation rather than an expression?

    Answer choices for question 1

    Solution

    Correct answer: B

    You chose A: Counts two operations written together as enough to make a sentence, though nothing here is claimed to equal anything.

    You chose C: Reads the fraction bar as doing the equals sign's job of joining two sides, though a bar is a division inside a single expression.

    You chose D: Treats the parentheses as a boundary between two sides of a statement, though they only group a sum that is about to be multiplied.

    An equation is two expressions joined by an equals sign, which makes it a sentence that can be true or false. An expression has no equals sign; it only names a value.

    5c+2=275c + 2 = 275c+2=27

    Only this line carries an equals sign, so only this line makes a claim. The other three name amounts and assert nothing, which is why you evaluate them and solve this one.

  8. Problem 8 A harbor warning light

    Answer
