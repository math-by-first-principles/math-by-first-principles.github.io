Evaluating and Simplifying Expressions

Intuition

There are two very different things you can do with an expression, and this lesson is about both. You can evaluate it: hand the variables actual numbers and work out the single value that comes out, turning 4x+74x + 74x+7 at x=5x = 5x=5 into 272727. Or you can simplify it: rewrite it as a shorter expression that always means the same thing, for every possible input, without ever choosing a number for xxx. That move turns 3x+5x3x + 5x3x+5x into 8x8x8x. Evaluating always ends in a single number. Simplifying usually still carries a variable, but not always: it is possible to simplify all the way down to a plain number, as x−xx - xx−x does to 000. Evaluating leans on the order of operations; simplifying leans on the distributive property and combining like terms. Both are tools you already own.

Learning goals

  • Evaluate with the full order of operations, protecting each substituted sign with parentheses
  • Combine like terms by adding coefficients, and explain why using the distributive property run backward
  • Distribute first when parentheses are present, then collect, treating a leading minus as −1-1−1
  • Distinguish simplifying from evaluating, and say what each produces

Evaluating with the full order of operations

You met substitution in the last lesson: replace each variable with its value, written in parentheses, then compute. With a single small term that is the whole story. The moment an expression has several terms, an exponent, or a grouped piece, the second half of the job starts doing real work. That second half is the order of operations.

Recall the order from the order-of-operations chapter, often remembered as PEMDAS: first whatever is inside Parentheses, then Exponents. Next come Multiplication and Division from left to right, and last Addition and Subtraction from left to right. Substitution does not change any of that. It only swaps a letter for a number; the operations already written around that letter still run in their fixed order.

So evaluating a multi-term expression happens in two steps. Step one: substitute every variable, each value wrapped in its own parentheses. Step two: work through the resulting arithmetic strictly in order, one operation at a time. Wrapping each value in parentheses in step one protects its sign through step two.

Worked example 1 Evaluate 3x2−5x+83x^2 - 5x + 83x2−5x+8 when x=4x = 4x=4

Substitute 444 for every xxx, each one in its own parentheses, and copy the rest of the expression unchanged:

3x2−5x+8=3(4)2−5(4)+8.3x^2 - 5x + 8 = 3(4)^2 - 5(4) + 8.3x2−5x+8=3(4)2−5(4)+8.

Now work in order. Exponents come before multiplication, so square the 444 first:

3(4)2=3⋅16=48.3(4)^2 = 3 \cdot 16 = 48.3(4)2=3⋅16=48.

The middle term is a multiplication, 5(4)=205(4) = 205(4)=20. Substituting those two results back leaves only additions and subtractions:

48−20+8.48 - 20 + 8.48−20+8.

Going left to right, 48−20=2848 - 20 = 2848−20=28, then 28+8=3628 + 8 = 3628+8=36. So the expression is worth 363636 when x=4x = 4x=4. The exponent reached only the 444, never the coefficient 333, because x2x^2x2 squares the variable alone.

When the input is negative

A negative input is where the parentheses earn their keep. The whole point of writing a substituted value as (−2)(-2)(−2) instead of a bare −2-2−2 is to keep the minus sign glued to the number. That glue matters when an exponent or a coefficient acts on the number. Two cases trip people up constantly.

The first is squaring a negative. If x=−3x = -3x=−3, then x2x^2x2 means (−3)2(-3)^2(−3)2, and a negative times a negative is positive, so (−3)2=9(-3)^2 = 9(−3)2=9. Without the parentheses you might write −32-3^2−32, which by the order of operations means −(32)=−9-(3^2) = -9−(32)=−9, the wrong sign entirely. The parentheses are the difference between 999 and −9-9−9.

The second is a coefficient meeting a negative. In −5x-5x−5x with x=−3x = -3x=−3 you get −5(−3)=15-5(-3) = 15−5(−3)=15, because the two minus signs multiply to a plus. Keep both signs visible and let the integer rules from chapter 2 settle them.

Worked example 2 Evaluate 2x2−4x−12x^2 - 4x - 12x2−4x−1 when x=−3x = -3x=−3

Substitute −3-3−3 for each xxx, every value inside parentheses so the sign cannot drift:

2x2−4x−1=2(−3)2−4(−3)−1.2x^2 - 4x - 1 = 2(-3)^2 - 4(-3) - 1.2x2−4x−1=2(−3)2−4(−3)−1.

Exponents first. Squaring −3-3−3 gives a positive result, since a negative times a negative is positive:

(−3)2=9,so2(−3)2=2⋅9=18.(-3)^2 = 9, \qquad \text{so} \qquad 2(-3)^2 = 2 \cdot 9 = 18.(−3)2=9,so2(−3)2=2⋅9=18.

Next the multiplication in the middle term. Watch the sign already in front: the term is −4x-4x−4x, so

−4(−3)=+12.-4(-3) = +12.−4(−3)=+12.

Substituting both results back, the expression becomes a short arithmetic chain:

18+12−1=29.18 + 12 - 1 = 29.18+12−1=29.

So the value is 292929. Every sign survived because each −3-3−3 travelled inside its own parentheses.

Answer choices

(−4)2+3(−4)=16+(−12)=4(-4)^2 + 3(-4) = 16 + (-12) = 4(−4)2+3(−4)=16+(−12)=4

The square (−4)2(-4)^2(−4)2 is positive 161616, and 3(−4)=−123(-4) = -123(−4)=−12, so the sum is 444.

Two variables and grouped pieces

Nothing changes when there are two letters: substitute both, still each in parentheses, then compute in order. A grouped piece inside parentheses must be finished first, exactly as the “P” in PEMDAS demands, before it is combined with anything else in the expression.

Worked example 3 Evaluate 5(a+b)−a25(a + b) - a^25(a+b)−a2 when a=2a = 2a=2 and b=6b = 6b=6

Replace aaa with 222 and bbb with 666, keeping the grouping parentheses that were already there:

5(a+b)−a2=5((2)+(6))−(2)2.5(a + b) - a^2 = 5\big((2) + (6)\big) - (2)^2.5(a+b)−a2=5((2)+(6))−(2)2.

The order of operations says finish the inside of the parentheses first:

(2)+(6)=8,so the first term is5(8)=40.(2) + (6) = 8, \qquad \text{so the first term is} \qquad 5(8) = 40.(2)+(6)=8,so the first term is5(8)=40.

Then the exponent in the last term, (2)2=4(2)^2 = 4(2)2=4. The line is now

40−4=36.40 - 4 = 36.40−4=36.

So the expression equals 363636. The addition a+ba + ba+b ran before the multiplication by 555 only because parentheses surrounded it. Without them, the order of operations would multiply first and change the answer.

Simplifying: the idea of like terms

Now set substitution aside. To simplify an expression is to rewrite it in a shorter, equivalent form, one that produces the same value for every possible input. You do that rewriting without choosing any input at all. The main tool for doing this is combining like terms.

Two terms are like terms when they have exactly the same variable part: the same letters raised to the same powers. Only the coefficient out front is allowed to differ. The terms 3x3x3x and 5x5x5x are like terms, both being some number of xxx‘s. The terms 7y7y7y and 2y2y2y are like terms. But 4x4x4x and 4y4y4y are not like terms, because the variables differ, and xxx and x2x^2x2 are not like terms, because the powers differ. A plain number, a constant, is like only another constant.

Three xxx‘s plus five xxx‘s is eight xxx‘s, the same way three apples plus five apples is eight apples: you are just counting how many copies of the same thing you have. The reason that always works, no matter what the coefficients are, comes straight from the distributive property you proved in chapter 1.

Why 3x+5x=8x3x + 5x = 8x3x+5x=8x#

Recall the distributive property, a(b+c)=ab+aca(b + c) = ab + aca(b+c)=ab+ac. Read from right to left it says that a common factor can be pulled out of a sum: ab+ac=a(b+c)ab + ac = a(b + c)ab+ac=a(b+c). The two terms 3x3x3x and 5x5x5x share exactly such a common factor, namely xxx, since 3x=x⋅33x = x \cdot 33x=x⋅3 and 5x=x⋅55x = x \cdot 55x=x⋅5.

Pull that shared xxx out front. The distributive property, run backward, gives

3x+5x=x(3+5).3x + 5x = x(3 + 5).3x+5x=x(3+5).

Inside the parentheses is ordinary arithmetic: 3+5=83 + 5 = 83+5=8. Therefore

3x+5x=x(8)=8x.3x + 5x = x(8) = 8x.3x+5x=x(8)=8x.

So combining like terms is not a new rule to memorize. It is the distributive property pulling the whole matching variable part out front, then adding the coefficients left behind. That only works when the two variable parts are identical, letter for letter and power for power. 3x3x3x and 5y5y5y do not match, so there is no single variable part to pull out, and the distributive property gives nothing useful. The sum 3x+5y3x + 5y3x+5y is already as short as it gets.

Sharing part of a variable part is not enough either. 3x3x3x and 5x25x^25x2 both contain a factor of xxx, but xxx and x2x^2x2 are different variable parts, so they stay unlike terms and cannot combine, even though xxx divides evenly into both.

∎

This gives you a shortcut you will use every day. To combine like terms, add or subtract their coefficients and keep the common variable part unchanged. The variable part is a label that rides along: you never add the exponents or change the letter.

Check your understanding

Which pair are NOT like terms, even though both terms contain a factor of xxx?

Answer choices

3x3x3x and 5x25x^25x2 both contain a factor of xxx, but their variable parts are xxx and x2x^2x2, different powers. Combining like terms needs the variable parts to match exactly, not just share a factor.

The other pairs are all like terms: 3x3x3x and 5x5x5x share the variable part xxx, 7y7y7y and 2y2y2y share the variable part yyy, and −4-4−4 and 999 are both constants.

Check your understanding

Which equation is the reason 3x+5x3x + 5x3x+5x is allowed to combine into 8x8x8x?

Answer choices

Combining like terms is not a separate rule: it is the distributive property, a(b+c)=ab+aca(b+c)=ab+aca(b+c)=ab+ac, read from right to left. Because 3x=x⋅33x = x \cdot 33x=x⋅3 and 5x=x⋅55x = x \cdot 55x=x⋅5 share the factor xxx, that factor pulls out front: 3x+5x=x(3+5)=x(8)=8x3x + 5x = x(3+5) = x(8) = 8x3x+5x=x(3+5)=x(8)=8x. This only works because the variable parts of 3x3x3x and 5x5x5x are identical; it would not work for 3x3x3x and 5x25x^25x2, since xxx and x2x^2x2 are different variable parts.

Worked example 4 Simplify 7x+2+4x−97x + 2 + 4x - 97x+2+4x−9

Sort the expression into groups of like terms. The variable terms 7x7x7x and 4x4x4x are alike; the constants 222 and −9-9−9 are alike. Remember each term carries the sign in front of it, so the constants are +2+2+2 and −9-9−9:

7x+2+4x−9=(7x+4x)+(2−9).7x + 2 + 4x - 9 = (7x + 4x) + (2 - 9).7x+2+4x−9=(7x+4x)+(2−9).

Each term kept the sign it started with when it moved into its group.

Collect the xxx-terms by adding their coefficients:

7x+4x=11x.7x + 4x = 11x.7x+4x=11x.

Collect the constants the same way:

2−9=−7.2 - 9 = -7.2−9=−7.

Put the two simplified groups together:

7x+2+4x−9=11x−7.7x + 2 + 4x - 9 = 11x - 7.7x+2+4x−9=11x−7.

The expression went from four terms to two, and 11x−711x - 711x−7 has no more like terms to combine, so it is in simplest form. The xxx-terms and the constants stay separate because they are unlike.

9k−4k=5k,−3+10=79k - 4k = 5k, \qquad -3 + 10 = 79k−4k=5k,−3+10=7

Simplifying with the distributive property

Many expressions cannot be simplified until you first remove a set of parentheses, and the tool for that is the distributive property running forward, a(b+c)=ab+aca(b + c) = ab + aca(b+c)=ab+ac. Multiply the outside factor by every term inside, then look for like terms to collect. With variables in the mix, the only new feature is that the products keep their letters.

For instance, 3(x+4)3(x + 4)3(x+4) distributes to 3⋅x+3⋅4=3x+123 \cdot x + 3 \cdot 4 = 3x + 123⋅x+3⋅4=3x+12. The outside 333 reaches both the xxx and the 444, just as it reached both numbers in the chapter-1 version of the rule. Once the parentheses are gone, any like terms scattered across the expression can be gathered.

Worked example 5 Simplify 2(3x+5)+4x2(3x + 5) + 4x2(3x+5)+4x

Start by distributing the 222 across both terms inside the parentheses:

2(3x+5)=2⋅3x+2⋅5=6x+10.2(3x + 5) = 2 \cdot 3x + 2 \cdot 5 = 6x + 10.2(3x+5)=2⋅3x+2⋅5=6x+10.

Rewrite the whole expression with the parentheses gone:

2(3x+5)+4x=6x+10+4x.2(3x + 5) + 4x = 6x + 10 + 4x.2(3x+5)+4x=6x+10+4x.

Now combine the like terms. The variable terms 6x6x6x and 4x4x4x collect, while the constant 101010 has no partner:

6x+4x=10x,so the result is10x+10.6x + 4x = 10x, \qquad \text{so the result is} \qquad 10x + 10.6x+4x=10x,so the result is10x+10.

The simplified expression is 10x+1010x + 1010x+10. Distributing first was essential. Until the parentheses were cleared, there was no 6x6x6x to pair with the 4x4x4x.

A minus sign in front of a parenthesis is the classic trap, and it is really just distributing a −1-1−1. The expression −(x−6)-(x - 6)−(x−6) means −1-1−1 times (x−6)(x - 6)(x−6), so the sign of every term inside flips: −(x−6)=−x+6-(x - 6) = -x + 6−(x−6)=−x+6. Distributing a negative coefficient works the same way, with the integer sign rules from chapter 2 deciding each product.

Check your understanding

Simplify −(2x−5)-(2x - 5)−(2x−5).

Answer choices

A leading minus is a factor of −1-1−1, so it multiplies every term inside the parentheses, not just the first one.

−(2x−5)=(−1)(2x)+(−1)(−5)=−2x+5-(2x - 5) = (-1)(2x) + (-1)(-5) = -2x + 5−(2x−5)=(−1)(2x)+(−1)(−5)=−2x+5

Both signs flip: the 2x2x2x becomes −2x-2x−2x and the −5-5−5 becomes +5+5+5.

Worked example 6 Simplify 5(2x−1)−3(x−4)5(2x - 1) - 3(x - 4)5(2x−1)−3(x−4)

Distribute each factor across its parentheses, watching the signs in the second group especially. The first factor, 555, gives

5(2x−1)=10x−5.5(2x - 1) = 10x - 5.5(2x−1)=10x−5.

The second factor is −3-3−3, a negative, so it multiplies both inside terms and flips signs accordingly:

−3(x−4)=(−3)(x)+(−3)(−4)=−3x+12.-3(x - 4) = (-3)(x) + (-3)(-4) = -3x + 12.−3(x−4)=(−3)(x)+(−3)(−4)=−3x+12.

The negative times the negative 444 became +12+12+12. Now write the full expression without parentheses and gather like terms:

5(2x−1)−3(x−4)=10x−5−3x+12.5(2x - 1) - 3(x - 4) = 10x - 5 - 3x + 12.5(2x−1)−3(x−4)=10x−5−3x+12.

Combine the xxx-terms and the constants separately:

10x−3x=7x,−5+12=7,10x - 3x = 7x, \qquad -5 + 12 = 7,10x−3x=7x,−5+12=7,

so the simplified form is 7x+77x + 77x+7. The whole result rested on distributing the −3-3−3 correctly, including the sign change on the −4-4−4.

Evaluating versus simplifying

Evaluating and simplifying are distinguished by what you do, not just what you get. Evaluating substitutes a specific value for each variable and always ends in a single number. Simplifying rewrites the expression into an equivalent form that works for every input, without ever substituting a value; that equivalent form usually still carries a variable, but not always, since x−xx - xx−x simplifies to the plain number 000 even though no value was ever chosen.

They cooperate. Because a simplified expression equals the original for every input, you may simplify once and then evaluate as many times as you need. To evaluate 3(x+2)+5x3(x + 2) + 5x3(x+2)+5x at x=4x = 4x=4, simplifying it first to 8x+68x + 68x+6 turns the work into the single step 8(4)+6=388(4) + 6 = 388(4)+6=38, and that same simplified form makes evaluating at x=10x = 10x=10 just as fast: 8(10)+6=868(10) + 6 = 868(10)+6=86.

Answer choices

6x−2x=4x6x - 2x = 4x6x−2x=4x

Rewriting an expression in shorter equivalent form by combining like terms is simplifying. Evaluating would require a value for xxx and produce a number.

Common mistakes

Common mistakes

  • Combining unlike terms. 3x+4y3x + 4y3x+4y stays as 3x+4y3x + 4y3x+4y, and x+x2x + x^2x+x2 stays as it is: their variable parts differ, so there is nothing to collect.
  • Adding the exponents or the variables when combining. 2x+3x=5x2x + 3x = 5x2x+3x=5x, not 5x25x^25x2 and not 6x6x6x. Only the coefficients add.
  • Dropping a sign when substituting a negative. Write (−3)(-3)(−3), not a bare −3-3−3, so (−3)2=9(-3)^2 = 9(−3)2=9 instead of the careless −32=−9-3^2 = -9−32=−9.
  • Distributing to only the first term. 3(x+4)3(x + 4)3(x+4) is 3x+123x + 123x+12, never 3x+43x + 43x+4. The outside factor reaches every term inside.
  • Mishandling a minus in front of parentheses. −(x−6)-(x - 6)−(x−6) is −x+6-x + 6−x+6, not −x−6-x - 6−x−6: a leading minus flips every sign inside.
  • Confusing simplifying with evaluating. Combining like terms to get 8x8x8x is simplifying, no value needed. Substituting a number to reach a single value is evaluating.

Key takeaways

  • To evaluate, substitute each variable’s value in its own parentheses to protect its sign, then apply the full order of operations: (−3)2=9(-3)^2 = 9(−3)2=9, while −32=−9-3^2 = -9−32=−9.
  • Like terms have the same variable part (same letters, same powers). To combine them, add or subtract the coefficients and keep the variable part unchanged: 3x+5x=8x3x + 5x = 8x3x+5x=8x.
  • Combining like terms is legal because of the distributive property run backward: 3x+5x=x(3+5)=8x3x + 5x = x(3 + 5) = 8x3x+5x=x(3+5)=8x. It works only when the variable parts match exactly; sharing just part of a variable part, like the xxx in 3x3x3x and 5x25x^25x2, is not enough.
  • To simplify an expression with parentheses, distribute first (a(b+c)=ab+aca(b + c) = ab + aca(b+c)=ab+ac, with a leading minus acting as −1-1−1), then collect like terms.
  • Simplifying rewrites an expression in an equivalent, usually shorter form without substituting any value, so it stays valid for every input (it can even collapse to a plain number, as x−xx - xx−x does to 000); evaluating substitutes a specific value to reach a single number. Simplify once, then evaluate as many times as you need.

A bit of history (optional)

You just proved that 3x+5x3x + 5x3x+5x must equal 8x8x8x, using the distributive property. People used that kind of reasoning long before it had a name: pulling the xxx terms of a problem into one place and the plain numbers into another is exactly what you did here.

The name distributive arrived in 181418141814, given by the French mathematician and army officer Servois. Here is a useful modern memory aid for the name, not the historical reason behind it: the factor outside is handed, or “distributed,” to each term inside, the way you might hand out one thing to several people.

So the collecting you did here is not a trick to learn by heart. It is a law with a name, and you watched it proved.
