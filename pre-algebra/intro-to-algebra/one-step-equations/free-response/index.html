  1. Problem 1 A decimal sentence

    Find the value of xxx that makes x−(−2.35)=−0.8x-(-2.35)=-0.8x−(−2.35)=−0.8 true, and check it.

    1. Hint 1

      Subtracting a negative adds its opposite.

    2. Hint 2

      Undo that addition on both sides.

    Answer

    x=−3.15x=-3.15x=−3.15; both sides equal −0.8-0.8−0.8.

    Full solution

    The left side is x+2.35x+2.35x+2.35.

    Subtract 2.352.352.35 from both sides to isolate xxx:

    x=−0.8−2.35x=−3.15\begin{aligned}x&=-0.8-2.35\\x&=-3.15\end{aligned}xx​=−0.8−2.35=−3.15​

    In the original, the proposed value gives

    −3.15−(−2.35)=−0.8-3.15-(-2.35)=-0.8−3.15−(−2.35)=−0.8

    The sides agree, so the value solves the equation.

    Answer

    x=−3.15x=-3.15x=−3.15; both sides equal −0.8-0.8−0.8.

    Key idea

    Undo the operation attached to the variable after interpreting its signs.

  2. Problem 2 Finding rrr

    Find rrr if −0.6r=4.2-0.6r=4.2−0.6r=4.2, and check your value.

    1. Hint 1

      The variable is multiplied by a signed decimal coefficient.

    2. Hint 2

      Divide both sides by the whole coefficient, including its sign.

    Answer

    r=−7r=-7r=−7; both sides equal 4.24.24.2.

    Full solution

    r=4.2−0.6r=\frac{4.2}{-0.6}r=−0.64.2​

    A positive number divided by a negative number is negative, so

    r=−7r=-7r=−7

    Check in the original:

    −0.6(−7)=4.2-0.6(-7)=4.2−0.6(−7)=4.2

    Both sides equal 4.24.24.2, so the value solves the equation.

    Answer

    r=−7r=-7r=−7; both sides equal 4.24.24.2.

    Key idea

    Divide by the whole coefficient, sign included, and let the division rules settle the sign.

  3. Problem 3 A quotient of −8-8−8

    Find ttt if t÷(−34)=−8t\div(-\frac{3}{4})=-8t÷(−43​)=−8, and check your value.

    1. Hint 1

      The variable is divided by a nonzero fraction.

    2. Hint 2

      Multiply both sides by that whole divisor to undo the division.

    Answer

    t=6t=6t=6; both sides equal −8-8−8.

    Full solution

    Multiplying both sides by −34-\frac{3}{4}−43​ undoes the division by that same nonzero number:

    t=(−8)(−34)t=(-8)(-\frac{3}{4})t=(−8)(−43​)

    The product is positive, giving

    t=6t=6t=6

    Check by dividing the proposed value by the original divisor:

    6÷(−34)=−86\div(-\frac{3}{4})=-86÷(−43​)=−8

    Answer

    t=6t=6t=6; both sides equal −8-8−8.

    Key idea

    To undo division by a fraction, multiply by that fraction on both sides.

  4. Problem 4 An audio clip

    An audio clip is played at 1.251.251.25 times its normal speed. If its normal duration is ddd seconds, its playback duration is d÷1.25d\div1.25d÷1.25 seconds. Playback lasts 363636 seconds. Find the normal duration.

    1. Hint 1

      The given playback rule becomes an equation when its output is known.

    2. Hint 2

      Undo division by 1.251.251.25 on both sides.

    Answer

    454545 seconds.

    Full solution

    Set the playback expression equal to the measured duration:

    d÷1.25=36d\div1.25=36d÷1.25=36

    Multiply both sides by 1.251.251.25 to find the normal duration:

    d=36⋅1.25d=36\cdot1.25d=36⋅1.25

    Thus d=45d=45d=45 seconds.

    Checking the playback, 45÷1.25=3645\div1.25=3645÷1.25=36 seconds, matching the observation.

    Answer

    454545 seconds.

    Key idea

    A known output lets an operation in a duration rule be undone to recover the input.

  5. Problem 5 Flour in a container

    After 34\frac{3}{4}43​ cup of flour is used, a container holds 58\frac{5}{8}85​ cup. Find how much flour it held before.

    1. Hint 1

      The original amount minus the flour used equals the amount remaining.

    2. Hint 2

      Add the used amount to both sides to recover the original amount.

    Answer

    118\frac{11}{8}811​ cups, or 1381\frac{3}{8}183​ cups.

    Full solution

    Let fff be the original number of cups.

    The equation is

    f−34=58f-\frac{3}{4}=\frac{5}{8}f−43​=85​

    Add 34\frac{3}{4}43​, which is 68\frac{6}{8}86​, to both sides:

    f=58+68f=118\begin{aligned}f&=\frac{5}{8}+\frac{6}{8}\\f&=\frac{11}{8}\end{aligned}ff​=85​+86​=811​​

    which is 1381\frac{3}{8}183​ cups.

    For a check, 118−68=58\frac{11}{8}-\frac{6}{8}=\frac{5}{8}811​−86​=85​ cup remains after 34\frac{3}{4}43​ cup is used, as the statement says.

    Answer

    118\frac{11}{8}811​ cups, or 1381\frac{3}{8}183​ cups.

    Key idea

    Recover an original amount by adding back what was removed.

  6. Problem 6 A sensor reading

    A sensor displays the true temperature plus a fixed adjustment eee, with all temperatures in degrees Celsius. When the true temperature is −2.8-2.8−2.8, the display reads 1.61.61.6. Find eee and the display reading when the true temperature is 5.25.25.2.

    1. Hint 1

      The same adjustment is added to each true temperature.

    2. Hint 2

      Use the known true temperature and its display to form an equation for eee.

    Answer

    Adjustment: 4.44.44.4 degrees Celsius; display reading: 9.69.69.6 degrees Celsius.

    Full solution

    The known measurement gives

    −2.8+e=1.6-2.8+e=1.6−2.8+e=1.6

    Add 2.82.82.8 to both sides to isolate the adjustment:

    e=4.4e=4.4e=4.4

    For a true temperature of 5.25.25.2 degrees Celsius, the display is

    5.2+4.4=9.65.2+4.4=9.65.2+4.4=9.6

    The adjustment checks against the earlier reading because

    −2.8+4.4=1.6.-2.8+4.4=1.6.−2.8+4.4=1.6.

    Answer

    Adjustment: 4.44.44.4 degrees Celsius; display reading: 9.69.69.6 degrees Celsius.

    Key idea

    A fixed adjustment can be found from one known input and output and then applied to another input.

  7. Problem 7 A diver's descent

    A diver's height relative to the water surface changes by the same amount, rrr meters, in each of 888 minutes, and by −14-14−14 meters altogether. Write an equation for rrr, solve it, and check it.

    1. Hint 1

      Eight equal changes make up the total change.

    2. Hint 2

      Undo the multiplication by 888 on both sides.

    Answer

    8r=−148r=-148r=−14, or an equivalent equation; r=−1.75r=-1.75r=−1.75 (or −74-\frac{7}{4}−47​), a change of −1.75-1.75−1.75 meters each minute.

    Full solution

    Eight equal changes of rrr meters give a total change of 8r8r8r meters, so

    8r=−148r=-148r=−14

    The variable is multiplied by 888, so divide both sides by the nonzero number 888:

    r=−148r=−74r=−1.75\begin{aligned}r&=\frac{-14}{8}\\r&=-\frac{7}{4}\\r&=-1.75\end{aligned}rrr​=8−14​=−47​=−1.75​

    The height drops 1.751.751.75 meters each minute.

    Check in the equation:

    8(−1.75)=−148(-1.75)=-148(−1.75)=−14

    Eight changes of −1.75-1.75−1.75 meters make the stated total change.

    Answer

    8r=−148r=-148r=−14, or an equivalent equation; r=−1.75r=-1.75r=−1.75 (or −74-\frac{7}{4}−47​), a change of −1.75-1.75−1.75 meters each minute.

    Key idea

    Equal repeated changes give a product, which division undoes.

  8. Problem 8 Omar's second equation

    Omar solves x+(−7)=−2x+(-7)=-2x+(−7)=−2 by adding 777 to both sides and gets x=5x=5x=5. For −7x=−2-7x=-2−7x=−2 he again adds 777 to both sides and reports x=5x=5x=5 once more. Is his second answer right? Find and check the solution of −7x=−2-7x=-2−7x=−2.

    1. Hint 1

      Substitute the reported value into −7x=−2-7x=-2−7x=−2 before anything else.

    2. Hint 2

      In −7x=−2-7x=-2−7x=−2 the number −7-7−7 multiplies xxx rather than being added to it, so a different inverse operation is needed.

    Answer

    No; x=27x=\frac{2}{7}x=72​; both sides equal −2-2−2.

    Full solution

    Substituting the reported value gives

    −7(5)=−35-7(5)=-35−7(5)=−35

    This is not −2-2−2, so x=5x=5x=5 is not a solution of −7x=−2-7x=-2−7x=−2.

    Here −7-7−7 multiplies xxx, so the inverse is division.

    Divide both sides by the nonzero coefficient −7-7−7:

    x=−2−7x=\frac{-2}{-7}x=−7−2​

    A negative number divided by a negative number is positive, so

    x=27.x=\frac{2}{7}.x=72​.

    Its check is

    −7(27)=−2.-7(\frac{2}{7})=-2.−7(72​)=−2.

    Adding 777 to both sides of −7x=−2-7x=-2−7x=−2 is allowed, but it gives −7x+7=5-7x+7=5−7x+7=5, which does not isolate xxx, so x=5x=5x=5 cannot be read from it.

    Adding 777 worked in the first equation because there −7-7−7 was added to xxx, not multiplied by it.

    Answer

    No; x=27x=\frac{2}{7}x=72​; both sides equal −2-2−2.

    Key idea

    Choose an inverse operation from the relationship in an equation, not just its numbers.

  9. Problem 9 Sam's working page

    Sam changes 0.8x=−40.8x=-40.8x=−4 to 1.6x=−81.6x=-81.6x=−8, then reports x=−5x=-5x=−5. Is every step valid? Explain and check the reported value.

    1. Hint 1

      A valid change must preserve the equality for exactly the same values of xxx.

    2. Hint 2

      Compare the factor applied to each side in the first step, then identify the coefficient in the new equation.

    Answer

    Yes; x=−5x=-5x=−5; the original sides both equal −4-4−4.

    Full solution

    The first step doubles both sides.

    Multiplication by the same nonzero number preserves the solution, even though it does not yet isolate the variable.

    Dividing both sides of the new equation by the nonzero number 1.61.61.6 gives

    x=−81.6x=\frac{-8}{1.6}x=1.6−8​

    Therefore x=−5x=-5x=−5.

    Check in the original equation:

    0.8(−5)=−40.8(-5)=-40.8(−5)=−4

    The result matches its right side, so the reported value is correct.

    Answer

    Yes; x=−5x=-5x=−5; the original sides both equal −4-4−4.

    Key idea

    A valid balance move need not isolate the variable immediately.

  10. Problem 10 Priya's claim

    The equation is ax=bax=bax=b, where aaa is negative. Priya claims that its solution is positive when bbb is negative and is zero when b=0b=0b=0. Is she right in both cases? Explain without choosing specific values for aaa.

    1. Hint 1

      The coefficient is negative, so it is also nonzero.

    2. Hint 2

      Consider the sign of b÷ab\div ab÷a and then the case with a zero numerator.

    Answer

    Yes: positive for negative bbb, and x=0x=0x=0 for b=0b=0b=0.

    Full solution

    Since aaa is nonzero, divide both sides by aaa:

    x=bax=\frac{b}{a}x=ab​

    When bbb is negative, this is a negative number divided by a negative number, so the solution is positive.

    When b=0b=0b=0, zero divided by nonzero aaa is zero, so x=0x=0x=0.

    The zero case checks because a⋅0=0a\cdot0=0a⋅0=0.

    In the negative case, multiplying the quotient b÷ab\div ab÷a by its nonzero divisor aaa returns bbb.

    Answer

    Yes: positive for negative bbb, and x=0x=0x=0 for b=0b=0b=0.

    Key idea

    Writing the solution of ax=bax=bax=b as b÷ab\div ab÷a, with aaa nonzero, lets the division rules decide whether it is positive, negative or zero without choosing values.
