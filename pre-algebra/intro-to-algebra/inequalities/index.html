Inequalities

▾

Progress can't be saved in this browser, so this lesson's status can't be set.

Intuition

A ride requires you to be at least 484848 inches tall. A height of 484848 inches qualifies, and so does any greater height. This is different from asking for one exact height.

If hhh is the height in inches, write h≥48h \ge 48h≥48. The symbol means “greater than or equal to.” An inequality describes a comparison, and its solutions can fill a whole range of the number line. You can solve the inequalities here with the inverse operations you used for equations, with one extra rule when multiplying or dividing by a negative number.

Learning goals

  • Read the four symbols, and say which include the boundary
  • Describe all solutions as a range rather than giving just one value
  • Graph with an open or closed circle, shading the right way
  • Solve using inverse operations on both sides
  • Reverse the symbol when multiplying or dividing by a negative
  • Test one value inside the range and one outside

The four inequality symbols

An inequality compares two expressions that need not be equal. In place of the equals sign it uses one of four symbols:

SymbolRead asMeaning
<<<”less than”strictly smaller, not equal
>>>”greater than”strictly larger, not equal
≤\le≤”less than or equal to”, “at most”smaller, or exactly equal
≥\ge≥”greater than or equal to”, “at least”larger, or exactly equal

The statement 5<85 < 85<8 says five is less than eight. Written the other way, 8>58 > 58>5 says the same thing. The pointed end faces the smaller number; the open end faces the larger number.

The line under ≤\le≤ or ≥\ge≥ allows equality. For x≤6x \le 6x≤6, the value 666 is included along with every smaller number. The number separating included and excluded values is the boundary, here 666.

The symbols <<< and >>> are strict: equality is excluded. The symbols ≤\le≤ and ≥\ge≥ are non-strict: equality is included.

Solutions form a range

A solution is a value that makes the inequality true. Solving means finding all such values. For example,

x>3x > 3x>3

accepts 444, 101010, and 3.53.53.5, because each is greater than 333. It rejects 333 itself, since 3>33 > 33>3 is false, and it rejects 222. The solutions are all numbers greater than 333. There are infinitely many, so describe the range instead of trying to list them.

For x≥3x \ge 3x≥3, the boundary value 333 is included too. That is the only difference between these two ranges.

Graphing the solution on a number line

A graph shows all the solutions at once. Mark the boundary, then shade the numbers that work.

  • Use an open circle (hollow) for <<< or >>>: the boundary is excluded.
  • Use a closed circle (filled) for ≤\le≤ or ≥\ge≥: the boundary is included.
  • With the variable on the left, shade right for >>> or ≥\ge≥, toward larger numbers. Shade left for <<< or ≤\le≤, toward smaller numbers. The arrowhead shows that the range continues.

Read the comparison with the variable first. For example, 3<x3 < x3<x means x>3x > 3x>3, so its graph has an open circle on 333 and shading to the right.

Here is x>3x > 3x>3. The circle on 333 is open, because 333 is not a solution, and the shading runs right toward the larger numbers.

Now compare x≥3x \ge 3x≥3. Everything is the same except the circle on 333 is filled, because this time 333 is part of the solution.

A “less” relation shades the other way. Here is x≤1x \le 1x≤1: the circle on 111 is filled because the bar includes it, and the arrow runs left toward the smaller numbers.

Solving inequalities with inverse operations

As with equations, isolate the variable by applying the same inverse operation to both sides. Adding or subtracting the same number keeps the inequality symbol unchanged. Multiplying or dividing by the same positive number also keeps it unchanged.

For example, 2<52 < 52<5. Adding 333 gives 5<85 < 85<8: both points move three places right on the number line, so their order stays the same. Adding a negative number moves both points left, again without changing their order. Subtraction works for the same reason.

Multiplying 2<52 < 52<5 by 222 gives 4<104 < 104<10. A positive multiplier scales every distance from zero by the same factor and keeps each number on its own side of zero, so the order stays the same. Dividing by a positive number does this too. These moves can be reversed, so they preserve all the solutions.

Worked example 1 Solve x+4<9x + 4 < 9x+4<9 and graph it

The variable has 444 added to it, so subtract 444 from both sides, carrying the <<< symbol straight down:

x+4−4<9−4  ⇒  x<5.x + 4 - 4 < 9 - 4 \;\Rightarrow\; x < 5.x+4−4<9−4⇒x<5.

The solution is every number less than 555. To check the direction, test a number from inside the claimed range and one outside it. Try x=0x = 0x=0: is 0+4<90 + 4 < 90+4<9? That is 4<94 < 94<9, true, and 000 is indeed less than 555. Try x=6x = 6x=6, which is outside: 6+4<96 + 4 < 96+4<9 is 10<910 < 910<9, false, and 666 is not less than 555. The two tests agree with x<5x < 5x<5.

Graph it with an open circle on 555, since <<< excludes the boundary, and shade left:

Worked example 2 Solve 5x≥205x \ge 205x≥20

The variable is multiplied by the positive coefficient 555, so divide both sides by 555. Dividing by a positive number does not disturb the symbol, so the ≥\ge≥ comes straight down:

5x5≥205  ⇒  x≥4.\frac{5x}{5} \ge \frac{20}{5} \;\Rightarrow\; x \ge 4.55x​≥520​⇒x≥4.

The solution is 444 together with every number above it. Check with a value inside the range and one outside. Test x=4x = 4x=4, the boundary: 5(4)=205(4) = 205(4)=20, and 20≥2020 \ge 2020≥20 is true, so the boundary belongs, which matches the closed circle. Test x=0x = 0x=0, outside: 5(0)=05(0) = 05(0)=0, and 0≥200 \ge 200≥20 is false, as expected.

So x≥4x \ge 4x≥4. On a number line this is a closed circle on 444 with the shading running right.

Why a negative multiplier reverses the symbol

Start with 2<32 < 32<3. Multiplying both sides by −1-1−1 gives −2-2−2 and −3-3−3. But −2-2−2 is to the right of −3-3−3, so the true comparison is

−2>−3.-2 > -3.−2>−3.

Multiplying by −1-1−1 reflects each point across zero, reversing left and right. When you multiply or divide both sides by a negative number, reverse the inequality symbol. Thus <<< becomes >>>, and ≤\le≤ becomes ≥\ge≥, or the other way around.

Why multiplying by a negative reverses the inequality#

For 1<51 < 51<5, the gap is 5−1=45 - 1 = 45−1=4, a positive number. Multiplying this gap by positive 333 gives

3(5−1)=15−3=(−3)−(−15)=12>0.\begin{aligned} 3(5 - 1) &= 15 - 3 \\ &= (-3) - (-15) \\ &= 12 > 0. \end{aligned}3(5−1)​=15−3=(−3)−(−15)=12>0.​

A difference is positive exactly when the first number is larger than the number subtracted. So −3>−15-3 > -15−3>−15: multiplying the original numbers by −3-3−3 reversed their order.

For any a<ba < ba<b, the difference b−ab - ab−a is positive. Let kkk be a positive number. Multiplying by kkk keeps that difference positive:

k(b−a)=kb−ka>0.k(b - a) = kb - ka > 0.k(b−a)=kb−ka>0.

But kb−kakb - kakb−ka is also (−ka)−(−kb)(-ka) - (-kb)(−ka)−(−kb). So −ka-ka−ka is greater than −kb-kb−kb:

−ka>−kb.-ka > -kb.−ka>−kb.

This proves the reversal for any negative multiplier −k-k−k. If a=ba = ba=b, their products remain equal, so the same argument changes ≤\le≤ to ≥\ge≥. Dividing by a negative number is multiplying by its reciprocal, which is also negative, so it reverses the symbol too.

∎

Check the operation, not just whether a negative number appears. Adding or subtracting a negative number keeps the symbol unchanged. It reverses at a multiplication or division step when the number used on both sides is negative. Division by zero is undefined, and multiplying both sides by zero cannot be undone. Neither is a valid solving step.

Worked example 3 Solve −2x<8-2x < 8−2x<8 and graph it

The variable is multiplied by the negative coefficient −2-2−2, so divide both sides by −2-2−2. Because −2-2−2 is negative, reverse the symbol from <<< to >>> as you divide:

−2x−2>8−2  ⇒  x>−4.\frac{-2x}{-2} > \frac{8}{-2} \;\Rightarrow\; x > -4.−2−2x​>−28​⇒x>−4.

The reversal is the whole point: dividing by a negative reverses the relation. Check it against the original, where the inequality is still −2x<8-2x < 8−2x<8. Test x=0x = 0x=0, which should satisfy x>−4x > -4x>−4: −2(0)=0-2(0) = 0−2(0)=0, and 0<80 < 80<8 is true. Test x=−5x = -5x=−5, which should fail x>−4x > -4x>−4: −2(−5)=10-2(-5) = 10−2(−5)=10, and 10<810 < 810<8 is false, exactly as predicted. Both tests support x>−4x > -4x>−4, not x<−4x < -4x<−4.

Graph it with an open circle on −4-4−4 (the symbol is strict) and shade right:

Two-step inequalities

Use the order from two-step equations: undo the added or subtracted constant, then undo the multiplication or division. Check the sign of the multiplier or divisor at the second step. The examples below show a positive coefficient, a negative coefficient, and a constant written before the variable term.

Worked example 4 Solve 3x+5≤173x + 5 \le 173x+5≤17

The constant 555 is added on, so subtract 555 from both sides. Adding or subtracting never touches the symbol:

3x+5−5≤17−5  ⇒  3x≤12.3x + 5 - 5 \le 17 - 5 \;\Rightarrow\; 3x \le 12.3x+5−5≤17−5⇒3x≤12.

Now the variable is multiplied by the positive coefficient 333, so divide both sides by 333. Since 333 is positive, the symbol stays as ≤\le≤:

3x3≤123  ⇒  x≤4.\frac{3x}{3} \le \frac{12}{3} \;\Rightarrow\; x \le 4.33x​≤312​⇒x≤4.

Check a value inside the range against the original inequality. Test x=4x = 4x=4, the boundary: 3(4)+5=173(4) + 5 = 173(4)+5=17, and 17≤1717 \le 1717≤17 is true. Test x=5x = 5x=5, outside: 3(5)+5=203(5) + 5 = 203(5)+5=20, and 20≤1720 \le 1720≤17 is false. The solution is

x≤4,x \le 4,x≤4,

a closed circle on 444 shaded left.

Worked example 5 Solve −2x+1>9-2x + 1 > 9−2x+1>9

Subtract the constant 111 from both sides first. This is a subtraction, not a multiply or divide, so the symbol does not move:

−2x+1−1>9−1  ⇒  −2x>8.-2x + 1 - 1 > 9 - 1 \;\Rightarrow\; -2x > 8.−2x+1−1>9−1⇒−2x>8.

Now divide both sides by the coefficient −2-2−2. The divisor is negative, so reverse the symbol from >>> to <<<:

−2x−2<8−2  ⇒  x<−4.\frac{-2x}{-2} < \frac{8}{-2} \;\Rightarrow\; x < -4.−2−2x​<−28​⇒x<−4.

The reversal happens at the division step and only there. Check against the original: x=−5x = -5x=−5 should work, and −2(−5)+1=10+1=11>9-2(-5) + 1 = 10 + 1 = 11 > 9−2(−5)+1=10+1=11>9 is true; x=0x = 0x=0 should fail, and −2(0)+1=1>9-2(0) + 1 = 1 > 9−2(0)+1=1>9 is false. So

x<−4,x < -4,x<−4,

an open circle on −4-4−4 shaded left.

Worked example 6 Solve 8−3x≥28 - 3x \ge 28−3x≥2

Read the left side as 8+(−3x)8 + (-3x)8+(−3x). Subtract the constant 888 from both sides, leaving the variable term alone; subtraction does not affect the symbol:

8−3x−8≥2−8  ⇒  −3x≥−6.8 - 3x - 8 \ge 2 - 8 \;\Rightarrow\; -3x \ge -6.8−3x−8≥2−8⇒−3x≥−6.

Divide both sides by the coefficient −3-3−3. It is negative, so reverse ≥\ge≥ to ≤\le≤. A negative divided by a negative is positive, the rule from the integers chapter:

−3x−3≤−6−3  ⇒  x≤2.\frac{-3x}{-3} \le \frac{-6}{-3} \;\Rightarrow\; x \le 2.−3−3x​≤−3−6​⇒x≤2.

Check against the original: x=2x = 2x=2 gives 8−3(2)=8−6=2≥28 - 3(2) = 8 - 6 = 2 \ge 28−3(2)=8−6=2≥2, true, so the boundary is included, matching the closed circle; x=3x = 3x=3 gives 8−9=−1≥28 - 9 = -1 \ge 28−9=−1≥2, false. The solution is

x≤2.x \le 2.x≤2.

Checking a range with test values

Substitute one value from the claimed range into the original inequality; it should make the statement true. Then test a value outside the range; it should make the statement false. For ≤\le≤ or ≥\ge≥, check that the boundary works too.

These tests can catch a mistake, especially a missed reversal. They do not prove that every number in the claimed range is correct. The valid algebra steps establish the full range.

Worked example 7 Solve x2−3≥−1\dfrac{x}{2} - 3 \ge -12x​−3≥−1 and check it with two test values

Add the constant 333 to both sides; the symbol is unaffected by addition:

x2−3+3≥−1+3  ⇒  x2≥2.\frac{x}{2} - 3 + 3 \ge -1 + 3 \;\Rightarrow\; \frac{x}{2} \ge 2.2x​−3+3≥−1+3⇒2x​≥2.

The variable is divided by the positive number 222, so undo that by multiplying both sides by 222. The symbol is unchanged, because 222 is positive:

2⋅x2≥2⋅2  ⇒  x≥4.2 \cdot \frac{x}{2} \ge 2 \cdot 2 \;\Rightarrow\; x \ge 4.2⋅2x​≥2⋅2⇒x≥4.

Now check it. Pick x=6x = 6x=6 from inside the range x≥4x \ge 4x≥4 and substitute into the original:

62−3=3−3=0,0≥−1  ✓\frac{6}{2} - 3 = 3 - 3 = 0, \qquad 0 \ge -1 \;\checkmark26​−3=3−3=0,0≥−1✓

Then pick x=0x = 0x=0 from outside the range:

02−3=−3,−3≥−1  false\frac{0}{2} - 3 = -3, \qquad -3 \ge -1 \;\text{false}20​−3=−3,−3≥−1false

Common mistakes

Common mistakes

  • Missing the reversal. Dividing −2x<8-2x < 8−2x<8 by −2-2−2 gives x>−4x > -4x>−4, not x<−4x < -4x<−4.
  • Reversing at the wrong step. In −2x+1>9-2x + 1 > 9−2x+1>9, subtracting 111 keeps >>>. Dividing by −2-2−2 changes it to <<<.
  • Drawing the wrong graph. With xxx on the left, “greater than” shades right and “less than” shades left. Use an open circle for a strict symbol and a closed circle when equality is allowed.
  • Giving just one value. 444 is one solution of x>3x > 3x>3. The full answer is every number greater than 333.
  • Confusing “at most” with “at least.” “At most 202020” means x≤20x \le 20x≤20; “at least 484848” means x≥48x \ge 48x≥48. Both include the boundary.

Key takeaways

  • A solution makes the inequality true. Solving finds all such values, which form a range in these examples.
  • The symbols <<< and >>> exclude the boundary; ≤\le≤ and ≥\ge≥ include it.
  • Isolate the variable using the same inverse operation on both sides. Reverse the symbol when multiplying or dividing by a negative number.
  • Graph the range with the appropriate circle and shading, reading the comparison with the variable first.
  • Test values inside and outside the range in the original inequality. These checks support the algebra; they do not replace it.

A bit of history (optional)

Thomas Harriot, an English mathematician, never saw the algebra book that made his name part of the history of inequality signs. It appeared in 163116311631, ten years after his death. Others had assembled it from his papers.

That book contains the first known printed appearances of the familiar <<< and >>> signs. It is tempting to say Harriot invented them, but the story has a twist: the surviving handwritten papers use different marks. The familiar signs do not appear there in his handwriting.

Historians comparing the manuscripts with the printed book therefore distinguish the book bearing Harriot’s name from the work of its editors. We can point to the book where the signs first appeared in print more confidently than we can name the person who chose their final shapes.
