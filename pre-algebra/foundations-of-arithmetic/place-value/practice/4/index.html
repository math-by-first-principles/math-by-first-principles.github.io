    In 7,248,0917{,}248{,}0917,248,091, which digit is in the hundred-thousands place?

    Answer choices for question 1

    Solution

    Correct answer: A

    Label the places of 7,248,0917{,}248{,}0917,248,091 from the right: ones 111, tens 999, hundreds 000, thousands 888, ten-thousands 444, hundred-thousands 222, millions 777.

    2×100,000=200,0002 \times 100{,}000 = 200{,}0002×100,000=200,000

    So the digit in the hundred-thousands place is 222.

    In 5,4785{,}4785,478, the value of the 444 is how many times the value of the 888?

    Answer choices for question 2

    Solution

    Correct answer: B

    The 444 is in the hundreds place (value 400400400) and the 888 is in the ones place (value 888). Divide the two values.

    4008=50\frac{400}{8} = 508400​=50

    So the 444 is worth 505050 times the 888.

    Solution

    Correct answer: A

    Solution

    Solution

    Which statement about 50,60450{,}60450,604 is true?

    Answer choices for question 10

    Solution

    Correct answer: C

    Read the places of 50,60450{,}60450,604 from the right: ones 444, tens 000, hundreds 666, thousands 000, ten-thousands 555.

    5×10,000=50,0005 \times 10{,}000 = 50{,}0005×10,000=50,000
