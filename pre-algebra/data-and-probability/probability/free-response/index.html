  1. Problem 1 The marked chance

    The figure places event A on a probability scale. Write its probability as a percent.

    Text description of this figure

    A horizontal number line runs from 0 at the left end to 1 at the right end. Six evenly spaced tick marks divide it into five equal intervals, and only the two ends are labeled, 0 and 1; the four interior ticks carry no numbers. A filled dot sits on the fourth tick to the right of 0 and is labeled A above the line.

    1. Hint 1

      The distance from 000 to 111 represents the whole chance, or 100%100\%100%.

    2. Hint 2

      Use the equal intervals to find the fraction of the scale reached by A, then convert it to a percent.

    Answer

    80%80\%80%.

    Full solution

    The scale divides the whole into five equal intervals, and A is four intervals from 000.

    Its probability is 45\frac4554​.

    45=80100.\frac45=\frac{80}{100}.54​=10080​.

    That is 80%80\%80%, which lies between an even chance and certainty.

    Answer

    80%80\%80%.

    Key idea

    A probability scale locates a share of one whole, which can also be written as a percent.

  2. Problem 2 Marked tickets

    Exactly 404040 tickets are equally likely to be selected. Some are marked, and the probability of selecting a marked ticket is 0.350.350.35. How many tickets are marked?

    1. Hint 1

      The given probability is the marked share of all the tickets.

    2. Hint 2

      Multiply the total number of tickets by that share.

    Answer

    141414 tickets.

    Full solution

    Equal likelihood makes the probability the number marked divided by 404040.

    Therefore the marked count is

    0.35×40=14.0.35\times40=14.0.35×40=14.

    Check: 1440=0.35\frac{14}{40}=0.354014​=0.35, as required.

    Answer

    141414 tickets.

    Key idea

    With equally likely outcomes, multiplying a probability by the total count recovers the favorable count.

  3. Problem 3 A trial record

    An event occurred 181818 times in a completed experiment. Its experimental probability was 0.450.450.45. How many trials were recorded?

    1. Hint 1

      Experimental probability compares the occurrence count with the trial total.

    2. Hint 2

      If 0.450.450.45 of the trials account for 181818 occurrences, divide to recover the whole trial count.

    Answer

    404040 trials.

    Full solution

    The occurrence count is 0.450.450.45 times the number of trials.

    Dividing gives

    18÷0.45=40.18\div0.45=40.18÷0.45=40.

    Check: 1840=0.45\frac{18}{40}=0.454018​=0.45, so 404040 trials fit the record.

    Answer

    404040 trials.

    Key idea

    The occurrence count divided by the experimental probability recovers the number of trials when that probability is nonzero.

  4. Problem 4 Selecting a cell

    The grid shows a board whose cells are chosen by selecting a row and a column. Each row is equally likely, each column is equally likely, and the two selections are independent. What is the probability that the selected row label is greater than the selected column label? Give a fraction in simplest form.

    Text description of this figure

    A grid of three equal rows and four equal columns, making twelve cells, every one of them blank. Down the left side, under the heading Row label, the rows are labeled 2, 4 and 6 from top to bottom. Across the top, under the heading Column label, the columns are labeled 1, 3, 5 and 7 from left to right.

    1. Hint 1

      Each possible row and column pair identifies one cell.

    2. Hint 2

      In each row, count the column labels smaller than that row label.

    3. Hint 3

      Add the favorable cell counts and compare them with all cells.

    Answer

    12\frac1221​.

    Full solution

    The independent selections give equally likely cells.

    There are three rows and four columns, so

    3×4=12.3\times4=12.3×4=12.

    Row 222 has one smaller column label, 111.

    Row 444 has two, 111 and 333.

    Row 666 has three, 111, 333, and 555.

    Thus the favorable count is

    1+2+3=6.1+2+3=6.1+2+3=6.

    The probability is

    612=12.\frac{6}{12}=\frac12.126​=21​.

    No row label equals a column label, so the other six cells all have a smaller row label, and the two groups fill the board.

    Answer

    12\frac1221​.

    Key idea

    Favorable cells over all cells of an outcome grid give the probability when each stage is equally likely and the stages are independent.

  5. Problem 5 The image collection

    A collection contains 121212 images. Each is equally likely to be selected, and the probability of selecting a portrait is 13\frac1331​. Three new portraits are added, with no images removed. Every image in the enlarged collection is equally likely to be selected. What is the new probability of a portrait? Give a fraction in simplest form.

    1. Hint 1

      First find how many portraits were in the original collection.

    2. Hint 2

      The added portraits change both the favorable count and the total count.

    3. Hint 3

      Use the new counts in the probability fraction.

    Answer

    715\frac7{15}157​.

    Full solution

    The original portrait count is

    13×12=4.\frac13\times12=4.31​×12=4.

    Adding three portraits gives 4+3=74+3=74+3=7 portraits among 12+3=1512+3=1512+3=15 images.

    Thus the new probability is

    P(portrait)=715.P(\text{portrait})=\frac7{15}.P(portrait)=157​.

    The original eight images that were not portraits are still present, and 7+8=157+8=157+8=15 checks the new counts.

    Answer

    715\frac7{15}157​.

    Key idea

    Adding favorable outcomes changes both parts of a probability fraction.

  6. Problem 6 Two trial records

    A device has theoretical probability 14\frac1441​ of flashing green on each trial. All trials are independent. One record shows 777 green flashes in 252525 trials, and a separate record shows 111111 in 353535 trials. Find the experimental probability from the combined records as a decimal, and state whether it is above, below, or equal to the theoretical probability.

    1. Hint 1

      The two records together form one longer run of the same device.

    2. Hint 2

      Add the green flashes from both records, and add the trials from both records.

    3. Hint 3

      Write the theoretical fraction as a decimal for the comparison.

    Answer

    0.30.30.3; above the theoretical probability.

    Full solution

    The records contain 7+11=187+11=187+11=18 green flashes and 25+35=6025+35=6025+35=60 trials.

    1860=0.3.\frac{18}{60}=0.3.6018​=0.3.

    The theoretical value is

    14=0.25.\frac14=0.25.41​=0.25.

    Since 0.3>0.250.3>0.250.3>0.25, the combined experimental probability is above the theoretical probability.

    A trial record can differ from theory even when the device has the stated probability.

    Answer

    0.30.30.3; above the theoretical probability.

    Key idea

    When records come from the same experiment, pool their counts before comparing the relative frequency with the theoretical probability.

  7. Problem 7 A robot journey

    A robot independently chooses a turn, left or right, and a distance of 111, 222, 333, or 444 meters. Each turn is equally likely, and each distance is equally likely. It runs out of battery exactly for these choices: left with 444 meters, right with 333 meters, and right with 444 meters. For every other pair of choices it completes the journey. What is the probability it completes the journey? Give a fraction in simplest form.

    1. Hint 1

      Completing the journey and running out of battery cover all possibilities without overlap.

    2. Hint 2

      Count the equally likely turn and distance pairs, then find the probability that one of the listed failures occurs.

    3. Hint 3

      Subtract the failure probability from one.

    Answer

    58\frac5885​.

    Full solution

    There are two turn choices and four distance choices.

    Equal likelihood at each stage and independence make all pairs equally likely.

    2×4=8.2\times4=8.2×4=8.

    The three listed failures are different outcomes, so their probability is 38\frac3883​.

    The completion probability is

    1−38=58.1-\frac38=\frac58.1−83​=85​.

    Check directly: completion allows three left distances and two right distances, giving five of the eight outcomes.

    Answer

    58\frac5885​.

    Key idea

    Subtracting the probability of the outcomes that fail gives the probability of completion.

  8. Problem 8 The running record

    A fair chooser produces A, B, C, or D with equal probability on independent trials. A occurs twice in the first 888 trials, then occurs again on trial 999. Omar says the experimental probability of A is now closer to the theoretical probability. Is his claim correct? Justify your answer.

    1. Hint 1

      Find the theoretical probability and the two experimental probabilities.

    2. Hint 2

      Compare the old record with theory before deciding whether the new record is closer.

    Answer

    No; the value changes from 14\frac1441​ to 13\frac1331​, farther from the theoretical 14\frac1441​.

    Full solution

    One of four equally likely outputs is A, so the theoretical probability is 14\frac1441​.

    Before trial nine, the experimental probability was

    28=14.\frac28=\frac14.82​=41​.

    After another A, there are three occurrences in nine trials.

    39=13.\frac39=\frac13.93​=31​.

    The old value matched theory exactly, while the new value differs from it.

    Omar's claim is false: one more independent trial has moved the experimental probability farther from theory.

    Answer

    No; the value changes from 14\frac1441​ to 13\frac1331​, farther from the theoretical 14\frac1441​.

    Key idea

    One additional independent trial may move an experimental probability farther from its theoretical value.

  9. Problem 9 Two trial plans

    A device gives a red signal with theoretical probability 0.40.40.4 each time it runs. Separate runs of the device do not affect one another. Plan A runs the device 1,0001{,}0001,000 times and records each run's own result. Plan B runs it once and writes that result into all 1,0001{,}0001,000 record entries. Which plan provides a reason to expect its recorded red fraction to be close to 0.40.40.4? Explain, and state all possible red fractions for Plan B.

    1. Hint 1

      Many entries in a record need not represent many independent trials.

    2. Hint 2

      Count how many actual runs of the device each record contains.

    3. Hint 3

      In Plan B, decide how many red entries follow a red result and how many follow a result that is not red.

    Answer

    Plan A; Plan B can record red fractions of 000 or 111.

    Full solution

    Plan A supplies many independent trials.

    The law of large numbers gives a reason to expect its experimental red fraction to lie close to 0.40.40.4, although it does not guarantee a close result in this particular run.

    Plan B supplies just one actual trial.

    If that result is red, every copied entry is red.

    The recorded fraction is

    1,0001,000=1.\frac{1{,}000}{1{,}000}=1.1,0001,000​=1.

    If it is not red, no copied entry is red.

    The recorded fraction is

    01,000=0.\frac{0}{1{,}000}=0.1,0000​=0.

    These are the two possible fractions for Plan B.

    Copying the result adds no independent trials, so the larger record does not support the same expectation of closeness.

    Answer

    Plan A; Plan B can record red fractions of 000 or 111.

    Key idea

    A long record supports a close experimental estimate through independent trials, not through copies of one outcome.

  10. Problem 10 Choosing a file

    A program first chooses folder X or folder Y, with equal probability. Folder X contains one file, and folder Y contains three files. It then selects one file from the chosen folder, with each file in that folder equally likely. Pat says the file in X is more likely to be selected than any one file in Y. Is Pat correct? Give the probability of selecting the file in X and explain.

    1. Hint 1

      Equal chances for the folders do not automatically give equal chances to every file across both folders.

    2. Hint 2

      Ask which first choice guarantees that the file in X will be selected.

    3. Hint 3

      A file in Y needs folder Y to be chosen first, and then needs to be the one file picked from three.

    Answer

    Yes; the file in X has probability 12\frac1221​.

    Full solution

    The file in X is selected exactly when the first choice is folder X.

    There are two equally likely folder choices, so

    P(file in X)=12.P(\text{file in X})=\frac12.P(file in X)=21​.

    A particular file in Y can be selected only when the first choice is folder Y, which also has probability 12\frac1221​.

    Even then, it is selected only if it is the one file picked from the three in Y, and each of the other two files in Y can be picked instead.

    So its probability is less than 12\frac1221​.

    Therefore the file in X is more likely to be selected than any one file in Y, and Pat is correct.

    The four files do not have equal chances, so counting one file out of four would give the wrong value 14\frac1441​.

    Answer

    Yes; the file in X has probability 12\frac1221​.

    Key idea

    Counting favorable outcomes over all outcomes requires equal likelihood for the outcomes being counted.
