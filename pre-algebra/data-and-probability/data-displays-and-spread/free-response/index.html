  1. Problem 1 Library books on a dot plot

    Fourteen students record how many library books they borrowed this month: 333, 111, 444, 222, 000, 333, 333, 555, 222, 111, 333, 444, 222, 333.

    Draw a dot plot of the data. Use it to find the mode, and the number of students who borrowed at least 444 books.

    1. Hint 1

      A dot plot needs a number line that reaches from the smallest value to the largest, with one dot for each student.

    2. Hint 2

      Work through the list once, placing a dot above each value as you meet it, and stack repeated values in a column.

    3. Hint 3

      Check that your dots add up to 141414 before reading anything off the plot.

    Answer

    The dot plot has 1,2,3,5,2,11, 2, 3, 5, 2, 11,2,3,5,2,1 dots above 0,1,2,3,4,50, 1, 2, 3, 4, 50,1,2,3,4,5. The mode is 333 books, and 333 students borrowed at least 444 books.

    Full solution

    Draw a number line from 000 to 555, since the values run from 000 books to 555 books.

    Count each value as you place its dots.

    The value 000 gets 111 dot, 111 gets 222, 222 gets 333, 333 gets 555, 444 gets 222, and 555 gets 111.

    The dots must account for every student.

    1+2+3+5+2+1=141+2+3+5+2+1=141+2+3+5+2+1=14

    The tallest stack is the 555 dots above 333, so the mode is 333 books.

    At least 444 books means the stacks above 444 and 555.

    2+1=32+1=32+1=3

    So 333 students borrowed at least 444 books.

    Answer

    The dot plot has 1,2,3,5,2,11, 2, 3, 5, 2, 11,2,3,5,2,1 dots above 0,1,2,3,4,50, 1, 2, 3, 4, 50,1,2,3,4,5. The mode is 333 books, and 333 students borrowed at least 444 books.

    Key idea

    A dot plot keeps every value, so counts such as the mode can be read straight from the stacks.

  2. Problem 2 A season of points

    A basketball player's points in 111111 games were 181818, 999, 242424, 151515, 121212, 212121, 141414, 161616, 111111, 191919, 252525.

    Find the five-number summary and the interquartile range of the points.

    1. Hint 1

      The median and the quartiles are found by place, so the order of the list matters first.

    2. Hint 2

      With an odd count, the middle value belongs to neither half.

    3. Hint 3

      Each half here has five values, so each quartile is the middle value of its half.

    Answer

    The five-number summary is 9,12,16,21,259, 12, 16, 21, 259,12,16,21,25, and the IQR is 999 points.

    Full solution

    Sort the points from least to greatest: 999, 111111, 121212, 141414, 151515, 161616, 181818, 191919, 212121, 242424, 252525.

    There are 111111 values, so the median is the 666th value, which is 161616.

    Leave the 161616 out of both halves.

    The lower half is 9,11,12,14,159, 11, 12, 14, 159,11,12,14,15 and the upper half is 18,19,21,24,2518, 19, 21, 24, 2518,19,21,24,25.

    The middle of the lower half is 121212, so Q1=12Q_1=12Q1​=12.

    The middle of the upper half is 212121, so Q3=21Q_3=21Q3​=21.

    The smallest value is 999 and the largest is 252525, so the five-number summary is 9,12,16,21,259, 12, 16, 21, 259,12,16,21,25.

    The IQR is the distance between the quartiles.

    IQR=21−12\text{IQR}=21-12IQR=21−12 IQR=9\text{IQR}=9IQR=9

    Answer

    The five-number summary is 9,12,16,21,259, 12, 16, 21, 259,12,16,21,25, and the IQR is 999 points.

    Key idea

    For an odd count, leave the median out and take the middle of each half to find the quartiles.

  3. Problem 3 Eight bean plants

    The heights of eight bean plants, in centimeters, are 141414, 222222, 999, 171717, 252525, 121212, 191919, 303030.

    Find the five-number summary and the interquartile range of the heights.

    1. Hint 1

      Put the heights in order before you look for any middle.

    2. Hint 2

      With an even count, no value is left out when you split the list into halves.

    3. Hint 3

      Each half has four heights, so each quartile is the mean of two values.

    Answer

    The five-number summary is 9,13,18,23.5,309, 13, 18, 23.5, 309,13,18,23.5,30, in centimeters, and the IQR is 10.510.510.5 centimeters.

    Full solution

    Sort the heights.

    9,12,14,17,19,22,25,309,12,14,17,19,22,25,309,12,14,17,19,22,25,30

    With 888 values, the median is the mean of the 444th and 555th values.

    median=17+192\text{median}=\frac{17+19}{2}median=217+19​ median=18\text{median}=18median=18

    The lower half is 9,12,14,179, 12, 14, 179,12,14,17.

    Its middle values are 121212 and 141414, so Q1Q_1Q1​ is their mean.

    Q1=12+142Q_1=\frac{12+14}{2}Q1​=212+14​ Q1=13Q_1=13Q1​=13

    The upper half is 19,22,25,3019, 22, 25, 3019,22,25,30.

    Its middle values are 222222 and 252525.

    Q3=22+252Q_3=\frac{22+25}{2}Q3​=222+25​ Q3=23.5Q_3=23.5Q3​=23.5

    With the minimum 999 and the maximum 303030, the five-number summary is 9,13,18,23.5,309, 13, 18, 23.5, 309,13,18,23.5,30.

    Subtract the quartiles to find the IQR.

    IQR=23.5−13\text{IQR}=23.5-13IQR=23.5−13 IQR=10.5\text{IQR}=10.5IQR=10.5

    Answer

    The five-number summary is 9,13,18,23.5,309, 13, 18, 23.5, 309,13,18,23.5,30, in centimeters, and the IQR is 10.510.510.5 centimeters.

    Key idea

    When a half has an even count, its quartile is the mean of its two middle values, just like a median.

  4. Problem 4 Sixteen days of weather

    The daily high temperatures for 161616 days, in degrees Fahrenheit, were 585858, 636363, 717171, 666666, 595959, 747474, 686868, 626262, 777777, 656565, 707070, 616161, 696969, 737373, 646464, 676767.

    Make a frequency table using the intervals 555555 to 595959, 606060 to 646464, 656565 to 696969, 707070 to 747474, and 757575 to 797979. Describe the histogram you would draw from it, and say which interval holds the median temperature.

    1. Hint 1

      Each whole-number temperature belongs to exactly one interval, so tally each one once.

    2. Hint 2

      The frequencies should add to the number of days.

    3. Hint 3

      With 161616 values the median sits between the 888th and 999th values. Count up through the intervals from the lowest.

    Answer

    The frequencies are 222, 444, 555, 444, 111. The histogram has five touching bars of those heights, in order from 555555 to 595959 up to 757575 to 797979, and the median is in the interval 656565 to 696969.

    Full solution

    Tally each temperature in its interval.

    The interval 555555 to 595959 gets 585858 and 595959.

    The interval 606060 to 646464 gets 636363, 626262, 616161, 646464.

    The interval 656565 to 696969 gets 666666, 686868, 656565, 696969, 676767.

    The interval 707070 to 747474 gets 717171, 747474, 707070, 737373, and 757575 to 797979 gets only 777777.

    So the frequencies are 222, 444, 555, 444, 111, and they account for every day.

    2+4+5+4+1=162+4+5+4+1=162+4+5+4+1=16

    The histogram has one bar per interval with those heights.

    The bars touch and stay in number order, because the intervals sit side by side on the temperature scale.

    The median is the mean of the 888th and 999th temperatures in order.

    The first two intervals hold 2+4=62+4=62+4=6 values, and the first three hold 6+5=116+5=116+5=11.

    So the 888th and 999th values are both in 656565 to 696969, and so is the median.

    Answer

    The frequencies are 222, 444, 555, 444, 111. The histogram has five touching bars of those heights, in order from 555555 to 595959 up to 757575 to 797979, and the median is in the interval 656565 to 696969.

    Key idea

    Counting up through a histogram's bars finds the interval of each middle value; when an even count's two middle values land in different intervals, the histogram cannot tell which interval holds the median.

  5. Problem 5 Nine swimmers

    Nine swimmers' times for one length of the pool, in seconds, are 343434, 414141, 292929, 373737, 454545, 323232, 383838, 525252, 363636.

    Draw a box plot of the times. Then compare the lengths of its two whiskers and say what the comparison tells you about the fastest and the slowest swimmers.

    1. Hint 1

      A box plot is built from the five-number summary, so find those five numbers first.

    2. Hint 2

      With nine values, the middle one is left out of both halves, and each half then has four values.

    3. Hint 3

      Each whisker runs from a quartile out to the fastest or the slowest time, so compare how wide a stretch each one covers.

    Answer

    Five-number summary 29,33,37,43,5229, 33, 37, 43, 5229,33,37,43,52 seconds: a box from 333333 to 434343 with a line at 373737, and whiskers to 292929 and 525252. The right whisker spans 999 seconds and the left only 444: the slowest times are more spread out than the fastest.

    Full solution

    Sort the times.

    29,32,34,36,37,38,41,45,5229,32,34,36,37,38,41,45,5229,32,34,36,37,38,41,45,52

    The median is the 555th value, 373737, and it is left out of both halves.

    The lower half 29,32,34,3629, 32, 34, 3629,32,34,36 gives Q1Q_1Q1​ as the mean of 323232 and 343434, which is 333333.

    The upper half 38,41,45,5238, 41, 45, 5238,41,45,52 gives Q3Q_3Q3​ as the mean of 414141 and 454545, which is 434343.

    So the five-number summary is 29,33,37,43,5229, 33, 37, 43, 5229,33,37,43,52.

    Draw a number line from about 252525 to 555555.

    Draw a box from 333333 to 434343 with a line across it at 373737, then whiskers out to 292929 and to 525252.

    The left whisker covers 33−29=433-29=433−29=4 seconds and the right whisker covers 52−43=952-43=952−43=9 seconds.

    The two fastest times, 292929 and 323232, lie below Q1Q_1Q1​, and the two slowest, 454545 and 525252, lie above Q3Q_3Q3​.

    The right whisker spans 999 seconds against the left whisker's 444, so the slowest times are more spread out than the fastest.

    Answer

    Five-number summary 29,33,37,43,5229, 33, 37, 43, 5229,33,37,43,52 seconds: a box from 333333 to 434343 with a line at 373737, and whiskers to 292929 and 525252. The right whisker spans 999 seconds and the left only 444: the slowest times are more spread out than the fastest.

    Key idea

    A longer whisker means the values beyond that quartile are more spread out, not that there are more of them.

  6. Problem 6 Reading a commute box plot

    The box plot shows the commute times, in minutes, of 808080 workers. The times were measured to the second, so no two workers have the same time.

    How many of the workers commute for at least 151515 minutes? How many commute for between 202020 and 282828 minutes? What is the interquartile range? A worker says that more people commute between 282828 and 454545 minutes than between 151515 and 202020 minutes, because that part of the plot is longer. Is the worker right?

    Text description of this figure

    A box plot on a number line from 5 to 50 minutes, marked every 5. The left whisker runs from 8 to 15. The box runs from 15 to 28, with a line across it at 20. The right whisker runs from 28 to 45. The five values 8, 15, 20, 28 and 45 are labeled above the plot.

    1. Hint 1

      Read the five numbers from the plot: the two whisker ends, the two box edges, and the line inside the box.

    2. Hint 2

      With 808080 different times, each quartile and the median fall between two neighboring places in the sorted list. Work out which places.

    3. Hint 3

      The length of a section measures how spread out its times are, not how many workers it holds.

    Answer

    606060 workers commute for at least 151515 minutes, and 202020 commute for between 202020 and 282828 minutes. The IQR is 131313 minutes. The worker is wrong: each of those two stretches holds 202020 workers.

    Full solution

    The plot shows a minimum of 888, Q1=15Q_1=15Q1​=15, a median of 202020, Q3=28Q_3=28Q3​=28, and a maximum of 454545.

    With 808080 sorted times, the lower half is the 111st to 404040th.

    So Q1Q_1Q1​ is the mean of the 202020th and 212121st times, the median is the mean of the 404040th and 414141st, and Q3Q_3Q3​ is the mean of the 606060th and 616161st.

    No two times are equal, so the 202020th time is below 151515 and the 212121st is above it.

    The workers at 151515 minutes or more are the 212121st to 808080th.

    80−20=6080-20=6080−20=60

    In the same way, the times between 202020 and 282828 are the 414141st to 606060th, which is 202020 workers.

    The IQR is the width of the box.

    IQR=28−15\text{IQR}=28-15IQR=28−15 IQR=13\text{IQR}=13IQR=13

    The times from 151515 to 202020 are the 212121st to 404040th, and the times from 282828 to 454545 are the 616161st to 808080th, so each stretch holds 202020 workers.

    The right whisker is longer only because those commute times are more spread out, so the worker is wrong.

    Answer

    606060 workers commute for at least 151515 minutes, and 202020 commute for between 202020 and 282828 minutes. The IQR is 131313 minutes. The worker is wrong: each of those two stretches holds 202020 workers.

    Key idea

    When no values repeat, each section of a box plot holds about a quarter of the sorted list (exactly a quarter when the count divides by 444), whatever its length.

  7. Problem 7 The sunflower typo

    The heights of seven sunflowers, in centimeters, are 150150150, 162162162, 158158158, 171171171, 165165165, 168168168, 160160160. When the data was typed up, the 171171171 was entered as 171017101710 by mistake.

    Find the range and the interquartile range of the correct heights and of the typed heights. Which measure of spread does the mistake affect, and why?

    1. Hint 1

      Sort each list first. Is the mistyped value still in the same place in the sorted order?

    2. Hint 2

      With seven values, each half has three values, so each quartile is the middle value of its half.

    3. Hint 3

      Think about which values each measure actually uses.

    Answer

    Correct heights: range 212121 and IQR 101010 centimeters. Typed heights: range 156015601560 and IQR still 101010 centimeters. Only the range is affected, since it uses the maximum and the quartiles do not.

    Full solution

    Sort the correct heights.

    150,158,160,162,165,168,171150,158,160,162,165,168,171150,158,160,162,165,168,171

    The median is the 444th value, 162162162.

    The lower half 150,158,160150, 158, 160150,158,160 gives Q1=158Q_1=158Q1​=158, and the upper half 165,168,171165, 168, 171165,168,171 gives Q3=168Q_3=168Q3​=168.

    So the IQR is 168−158=10168-158=10168−158=10, and the range is

    171−150=21.171-150=21.171−150=21.

    In the typed list, 171017101710 is still the largest value, so every height keeps its place.

    The quartiles are still the 222nd and 666th values, 158158158 and 168168168, so the IQR is still 101010.

    The range now uses 171017101710 as the maximum.

    range=1710−150\text{range}=1710-150range=1710−150 range=1560\text{range}=1560range=1560

    So the mistake changes the range enormously and leaves the IQR alone.

    This works because the list has at least six values, so the quartiles come from the middle of each half and never use the largest value, and because 171017101710 stays at the end of the list.

    Answer

    Correct heights: range 212121 and IQR 101010 centimeters. Typed heights: range 156015601560 and IQR still 101010 centimeters. Only the range is affected, since it uses the maximum and the quartiles do not.

    Key idea

    In a list of six or more values, an end value pushed further out, staying at its end, stretches the range but leaves the quartiles and the IQR unchanged.

  8. Problem 8 Two study groups

    Two study groups record their homework times, in minutes, for one evening.

    Group P: 202020, 252525, 252525, 303030, 303030, 303030, 353535, 353535, 404040. Group Q: 555, 151515, 202020, 303030, 353535, 454545, 505050, 555555, 606060.

    Compare the two groups by center and by spread, using medians, interquartile ranges and ranges, and write one sentence describing how their evenings differ.

    1. Hint 1

      Both lists are already sorted and have nine values each, so each median is a single value.

    2. Hint 2

      Leave each median out, and each half then has four values.

    3. Hint 3

      Compare one measure at a time: first the centers, then the spreads.

    Answer

    Group P has median 303030, IQR 101010 and range 202020. Group Q has median 353535, IQR 353535 and range 555555. Group Q's typical time is a little longer, but its times are far more spread out, while Group P's times are all close to half an hour.

    Full solution

    Group P's median is its 555th value, 303030.

    Its lower half 20,25,25,3020, 25, 25, 3020,25,25,30 gives Q1=25Q_1=25Q1​=25, and its upper half 30,35,35,4030, 35, 35, 4030,35,35,40 gives Q3=35Q_3=35Q3​=35.

    So Group P's IQR is 35−25=1035-25=1035−25=10 and its range is 40−20=2040-20=2040−20=20.

    Group Q's median is its 555th value, 353535.

    Its lower half 5,15,20,305, 15, 20, 305,15,20,30 gives Q1Q_1Q1​ as the mean of 151515 and 202020, which is 17.517.517.5.

    Its upper half 454545, 505050, 555555, 606060 gives Q3Q_3Q3​ as the mean of 505050 and 555555, which is 52.552.552.5.

    IQR=52.5−17.5\text{IQR}=52.5-17.5IQR=52.5−17.5 IQR=35\text{IQR}=35IQR=35

    Group Q's range is 60−5=5560-5=5560−5=55.

    The centers are close, 303030 against 353535 minutes.

    The spreads are not: Group Q's IQR is more than three times Group P's.

    Group P's students all worked for about half an hour, while Group Q's times ran from a few minutes to an hour.

    Answer

    Group P has median 303030, IQR 101010 and range 202020. Group Q has median 353535, IQR 353535 and range 555555. Group Q's typical time is a little longer, but its times are far more spread out, while Group P's times are all close to half an hour.

    Key idea

    Two data sets with similar centers can still have very different spreads, so compare both.

  9. Problem 9 The longest whisker

    A box plot of the finishing times, in minutes, of 404040 runners in a school fun run has the five-number summary 4,12,15,17,204, 12, 15, 17, 204,12,15,17,20. The times were measured to the second, so no two runners have the same time.

    Jordan says, "The left whisker is by far the longest part of the plot, so most of the runners finished in 444 to 121212 minutes." Explain what is wrong with Jordan's reasoning, say how many runners finished in 444 to 121212 minutes, and say what the long whisker does tell you.

    1. Hint 1

      Think about what the five numbers of a box plot divide the data into.

    2. Hint 2

      With 404040 different times, Q1Q_1Q1​ falls between two neighboring places in the sorted list. Which places?

    3. Hint 3

      If a section holds a quarter of the runners but covers a wide stretch of times, how close together are those times?

    Answer

    Jordan reads a section's length as its number of values. Only 101010 of the 404040 runners, a quarter, finished in 444 to 121212 minutes, and the long whisker shows that the fastest quarter is spread out over 888 minutes.

    Full solution

    With 404040 sorted times, the lower half is the 111st to 202020th, so Q1Q_1Q1​ is the mean of the 101010th and 111111th times.

    No two times are equal, so the 101010th time is below 121212 and the 111111th is above it.

    The runners who finished in 444 to 121212 minutes are the 111st to 101010th, which is 101010 runners, a quarter of the field and not most of it.

    The left whisker is 12−4=812-4=812−4=8 minutes long, while the other three sections cover 15−12=315-12=315−12=3, 17−15=217-15=217−15=2 and 20−17=320-17=320−17=3 minutes.

    So the fastest quarter of the times is spread thinly over 888 minutes, and the other three quarters are packed between 121212 and 202020 minutes.

    Answer

    Jordan reads a section's length as its number of values. Only 101010 of the 404040 runners, a quarter, finished in 444 to 121212 minutes, and the long whisker shows that the fastest quarter is spread out over 888 minutes.

    Key idea

    The length of a box plot section shows how spread out its values are, never how many values it holds.

  10. Problem 10 Building a data set

    Write a list of seven whole numbers whose five-number summary is 1,3,6,8,121, 3, 6, 8, 121,3,6,8,12.

    Then describe every possible value of the 333rd and 555th numbers in the sorted list, and explain why those are the only possibilities.

    1. Hint 1

      In a sorted list of seven values, work out which place holds the median and which places hold the two quartiles.

    2. Hint 2

      With seven values, each half has three values, so each quartile is a single value in the list.

    3. Hint 3

      The places that are not fixed by the summary still have to fit between their neighbors in the sorted order.

    Answer

    One list that works is 111, 333, 444, 666, 777, 888, 121212. Any list of the form 1,3,a,6,b,8,121, 3, a, 6, b, 8, 121,3,a,6,b,8,12 works, where the 333rd number aaa is a whole number from 333 to 666 and the 555th number bbb is a whole number from 666 to 888.

    Full solution

    In a sorted list of seven values, the median is the 444th value.

    The lower half is the 111st to 333rd values, with middle value the 222nd, and the upper half is the 555th to 777th, with middle value the 666th.

    So the summary fixes five places: the 111st value is 111, the 222nd is 333, the 444th is 666, the 666th is 888, and the 777th is 121212.

    The list must stay sorted, so the 333rd value sits between the 222nd and the 444th.

    It can be any whole number from 333 to 666.

    In the same way, the 555th value sits between the 444th and the 666th, so it can be any whole number from 666 to 888.

    Choosing 444 and 777 gives 111, 333, 444, 666, 777, 888, 121212.

    Checking it, the median is 666, the lower half 1,3,41, 3, 41,3,4 has middle value 333, and the upper half 7,8,127, 8, 127,8,12 has middle value 888, as required.

    Answer

    One list that works is 111, 333, 444, 666, 777, 888, 121212. Any list of the form 1,3,a,6,b,8,121, 3, a, 6, b, 8, 121,3,a,6,b,8,12 works, where the 333rd number aaa is a whole number from 333 to 666 and the 555th number bbb is a whole number from 666 to 888.

    Key idea

    For a sorted list of seven values, a five-number summary fixes only five of the seven places, so many different lists share the same box plot.
