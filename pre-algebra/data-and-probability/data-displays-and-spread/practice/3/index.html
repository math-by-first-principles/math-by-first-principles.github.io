  1. 1

    The sorted data 2,4,6,8,10,12,k2, 4, 6, 8, 10, 12, k2,4,6,8,10,12,k has a last value kkk that is at least 121212. What is the interquartile range?

    Answer choices for question 1

    Solution

    Correct answer: D

    There are 777 values, so the median is the 444th, 888. The lower half is 2,4,62, 4, 62,4,6 and the upper half is 10,12,k10, 12, k10,12,k.

    Since kkk is at least 121212, it is the last value of the upper half, and the middle value of that half is 121212.

    IQR=12−4=8\text{IQR} = 12 - 4 = 8IQR=12−4=8

    The value of kkk affects the range, k−2k - 2k−2, but not the quartiles.

  2. 2

    For the data 111, 555, 555, 555, 555, 555, 555, 555, 121212, which statement is true?

    Answer choices for question 2

    Solution

    Correct answer: B

    With 999 values the median is the 555th, 555. The lower half 1,5,5,51, 5, 5, 51,5,5,5 gives Q1=5Q_1 = 5Q1​=5, and the upper half 5,5,5,125, 5, 5, 125,5,5,12 gives Q3=5Q_3 = 5Q3​=5.

    IQR=5−5=0,range=12−1=11\text{IQR} = 5 - 5 = 0, \qquad \text{range} = 12 - 1 = 11IQR=5−5=0,range=12−1=11

    An IQR of 000 means the middle of the data is piled on one value. It does not mean every value is equal: the 111 and the 121212 still differ.

  3. 3

    A data set has the five-number summary 10,30,36,38,4010, 30, 36, 38, 4010,30,36,38,40. Which description of its shape fits best?

    Answer choices for question 3

    Solution

    Correct answer: C

    Compare the four sections. The left whisker runs from 101010 to 303030, and the right whisker from 383838 to 404040.

    30−10=20,40−38=230 - 10 = 20, \qquad 40 - 38 = 230−10=20,40−38=2

    The median, 363636, also sits near the right end of the box. The values crowd together at the high end and stretch far to the left, so the data is skewed left.

  4. 4

    A data set has 232323 values. Using this lesson's method, which value in the sorted list is Q1Q_1Q1​?

    Answer choices for question 4

    Solution

    Correct answer: A

    With 232323 values the median is the 121212th, and it is left out of both halves. So the lower half is the 111st to 111111th values.

    The lower half has 111111 values, an odd count, so its middle is a single value.

    11+12=6\frac{11 + 1}{2} = 6211+1​=6

    So Q1Q_1Q1​ is the 666th value. Keeping the median in the lower half would give 121212 values and the mean of the 666th and 777th, which is the other method.

  5. 5

    The data 2,4,6,8,102, 4, 6, 8, 102,4,6,8,10 has Q1=3Q_1 = 3Q1​=3 and Q3=9Q_3 = 9Q3​=9. A sixth value, 202020, is added. What are the new quartiles?

    Answer choices for question 5

    Solution

    Correct answer: C

    Adding a value changes the count, so the halves change too. The new sorted list 2,4,6,8,10,202, 4, 6, 8, 10, 202,4,6,8,10,20 has an even count, so its halves are 2,4,62, 4, 62,4,6 and 8,10,208, 10, 208,10,20.

    Q1=4,Q3=10Q_1 = 4, \qquad Q_3 = 10Q1​=4,Q3​=10

    Moving an end value of a list of six or more values leaves its quartiles alone, as long as it stays at its end. Adding a whole new value is a different change, and here both quartiles moved.

  6. 6

    Two runners time their laps, in seconds. Ana's five-number summary is 60,62,63,64,7060, 62, 63, 64, 7060,62,63,64,70, and Ben's is 55,58,63,68,7155, 58, 63, 68, 7155,58,63,68,71. Which statement is best supported?

    Answer choices for question 6

    Solution

    Correct answer: D

    The medians are both 636363 seconds, so their typical laps match. Compare the spreads of the middle halves.

    64−62=2,68−58=1064 - 62 = 2, \qquad 68 - 58 = 1064−62=2,68−58=10

    Ana's IQR is 222 seconds and Ben's is 101010, so Ana's laps are much more consistent. One fast or slow lap does not decide who is faster.

  7. 7

    A histogram uses the intervals 000 to 999, 101010 to 191919, 202020 to 292929, and 303030 to 393939. Which of these can you find exactly from the histogram alone?

    Answer choices for question 7

    Solution

    Correct answer: B

    Each bar's height is a count, so adding the heights gives the number of values exactly.

    total=sum of the bar heights\text{total} = \text{sum of the bar heights}total=sum of the bar heights

    The histogram does not show the values inside each interval, so the median, the largest value and the mean can only be placed in an interval or estimated.

For a histogram with intervals 101010 to 191919, 202020 to 292929, 303030 to 393939, 404040 to 494949, and 505050 to 595959, what are the frequencies, in that order?

    Answer choices for question 8

    Solution

    Correct answer: A

  9. 9

    Set P is 111, 222, 555, 555, 555, 555, 555, 888, 999 and Set Q is 111, 222, 333, 444, 555, 666, 777, 888, 999. Both have range 888. What are their interquartile ranges?

    Answer choices for question 9

    Solution

    Correct answer: D

    Each set has 999 values, so the median is the 555th value and the halves are the four values on each side.

    For Set P, Q1=2+52=3.5Q_1 = \frac{2 + 5}{2} = 3.5Q1​=22+5​=3.5 and Q3=5+82=6.5Q_3 = \frac{5 + 8}{2} = 6.5Q3​=25+8​=6.5. For Set Q, Q1=2+32=2.5Q_1 = \frac{2 + 3}{2} = 2.5Q1​=22+3​=2.5 and Q3=7+82=7.5Q_3 = \frac{7 + 8}{2} = 7.5Q3​=27+8​=7.5.

    6.5−3.5=3,7.5−2.5=56.5 - 3.5 = 3, \qquad 7.5 - 2.5 = 56.5−3.5=3,7.5−2.5=5

    The same range can hide very different middles: Set P's middle values are packed at 555.

  11. 11

    Which statement is true of every box plot?

    Answer choices for question 11

    Solution

    Correct answer: B

    The box always runs from Q1Q_1Q1​ to Q3Q_3Q3​, so its width is always their difference.

    box width=Q3−Q1=IQR\text{box width} = Q_3 - Q_1 = \text{IQR}box width=Q3​−Q1​=IQR

    The median can sit anywhere inside the box, and the whiskers can differ. The box need not hold exactly half either: for 1,2,3,…,111, 2, 3, \ldots, 111,2,3,…,11, Q1=3Q_1 = 3Q1​=3 and Q3=9Q_3 = 9Q3​=9, so the box holds 777 of the 111111 values.
