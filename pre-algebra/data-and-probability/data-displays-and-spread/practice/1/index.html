Numerical Data Displays and Spread: Practice

Question 1 of 12
  1. 1

    A dot plot has 333 dots above the value 111, 555 dots above 222, and 222 dots above 333. How many values does the dot plot show?

    Answer choices for question 1

    Solution

    Correct answer: C

    Every dot is one value, so count all the dots, whichever value they sit above.

    3+5+2=103 + 5 + 2 = 103+5+2=10

    The 333 counts how many different values have dots, and the 555 is only the tallest stack.

  2. 2

    Which display shows every individual value of a numerical data set?

    Answer choices for question 2

    Solution

    Correct answer: A

    A dot plot puts one dot above the number line for each value, so each value can be read back from the picture.

    one dot=one value\text{one dot} = \text{one value}one dot=one value

    A histogram only counts how many values fall in each interval, and a box plot shows just five numbers. A circle graph shows shares of a whole, not the values themselves.

  3. 3

    Which of these is NOT one of the five numbers in a five-number summary?

    Answer choices for question 3

    Solution

    Correct answer: D

    The five-number summary lists, in order, the minimum, the first quartile, the median, the third quartile, and the maximum.

    min, Q1, median, Q3, max\text{min},\ Q_1,\ \text{median},\ Q_3,\ \text{max}min, Q1​, median, Q3​, max

    The mean is a useful center, but it is not one of the five.

  4. 4

    The sorted data 222, 444, 555, 777, 888, 101010, 121212 has median 777. What is the first quartile, Q1Q_1Q1​?

    Answer choices for question 4

    Solution

    Correct answer: B

    There are 777 values, an odd count, so the median 777 is left out of both halves. The lower half is the three values before it, 2,4,52, 4, 52,4,5.

    Q1=median of 2,4,5=4Q_1 = \text{median of } 2, 4, 5 = 4Q1​=median of 2,4,5=4

  5. 5

    The sorted data 222, 444, 555, 777, 888, 101010, 121212 has median 777. What is the third quartile, Q3Q_3Q3​?

    Answer choices for question 5

    Solution

    Correct answer: D

    With 777 values the median 777 is left out, so the upper half is the three values after it, 8,10,128, 10, 128,10,12.

    Q3=median of 8,10,12=10Q_3 = \text{median of } 8, 10, 12 = 10Q3​=median of 8,10,12=10

    The maximum, 121212, is the end of the data, not its third quartile.

  6. 6

    A data set has Q1=12Q_1 = 12Q1​=12 and Q3=20Q_3 = 20Q3​=20. What is its interquartile range?

    Answer choices for question 6

    Solution

    Correct answer: B

    The interquartile range is the distance from the first quartile to the third quartile, so subtract.

    IQR=Q3−Q1=20−12=8\text{IQR} = Q_3 - Q_1 = 20 - 12 = 8IQR=Q3​−Q1​=20−12=8

    Adding the quartiles, 323232, does not measure a distance at all.

  7. 7

    In a box plot, what does the line drawn across the inside of the box mark?

    Answer choices for question 7

    Solution

    Correct answer: A

    A box plot draws the five-number summary. The box runs from Q1Q_1Q1​ to Q3Q_3Q3​, and the line inside it marks the middle number of the five.

    Q1≤median≤Q3Q_1 \le \text{median} \le Q_3Q1​≤median≤Q3​

    The mean and the mode are not part of a box plot, and Q1Q_1Q1​ is the left edge of the box.

  8. 8

    A histogram's bars touch each other, while a bar graph's bars sit apart. Why do a histogram's bars touch?

    Answer choices for question 8

    Solution

    Correct answer: C

    A histogram's horizontal axis is a number line cut into equal intervals. Each interval begins where the one before it ends, so the bars meet.

    0 to 9,10 to 19,20 to 290 \text{ to } 9,\quad 10 \text{ to } 19,\quad 20 \text{ to } 290 to 9,10 to 19,20 to 29

    A bar graph's bars stand for separate categories, which have no fixed order, so they are drawn apart.

  9. 9

    A data set has the five-number summary 4,9,13,17,254, 9, 13, 17, 254,9,13,17,25. What is its interquartile range?

    Answer choices for question 9

    Solution

    Correct answer: D

    In a five-number summary the second number is Q1Q_1Q1​ and the fourth is Q3Q_3Q3​.

    IQR=17−9=8\text{IQR} = 17 - 9 = 8IQR=17−9=8

    The range is 25−4=2125 - 4 = 2125−4=21, which uses the two ends instead of the quartiles.

  10. 10

    A histogram of whole-number data uses the intervals 000 to 444, 555 to 999, and 101010 to 141414. Which bar counts the value 101010?

    Answer choices for question 10

    Solution

    Correct answer: A

    Each whole number belongs to exactly one interval. The interval 555 to 999 stops at 999, and the next one starts at 101010.

    10≤10≤1410 \le 10 \le 1410≤10≤14

    So the value 101010 is counted once, in the 101010 to 141414 bar.

  11. 11

    A data set has 404040 values, and no two of them are equal. Roughly what fraction of the values lie inside the box of its box plot?

    Answer choices for question 11

    Solution

    Correct answer: C

    The box runs from Q1Q_1Q1​ to Q3Q_3Q3​, which cut the sorted list at about one quarter and three quarters of the way along. With no repeated values, the values between them are about the middle half of the list.

    34−14=12\tfrac34 - \tfrac14 = \tfrac1243​−41​=21​

    Repeated values can change this: a value repeated at a quartile sits on the edge of the box, and then the box can hold many more than half.

  12. 12

    Using this lesson's method, what is the five-number summary of 111, 333, 444, 666, 888, 999, 101010?

    Answer choices for question 12

    Solution

    Correct answer: B

    The data is sorted and has 777 values, so the median is the 444th value, 666, and it is left out of both halves.

    The lower half 1,3,41, 3, 41,3,4 has middle value 333, and the upper half 8,9,108, 9, 108,9,10 has middle value 999.

    1, 3, 6, 9, 101,\ 3,\ 6,\ 9,\ 101, 3, 6, 9, 10

    Keeping the 666 in both halves would give 3.53.53.5 and 8.58.58.5, which is a different method from this course's.
