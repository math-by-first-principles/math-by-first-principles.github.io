Functions and Models: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Function and graph
A function assigns exactly one output to each allowed input. Its graph consists exactly of the points (x,f(x))(x,f(x))(x,f(x)) for xxx in its domain; function notation names an output, not multiplication.
Domain and range
The domain contains allowed inputs; the range contains attained outputs. A formula's natural real domain can be narrowed by a declared restriction or a model's context.
Interval notation
Brackets include endpoints; parentheses exclude them. Infinity always takes a parenthesis. A union ∪\cup∪ joins sets; isolated values do not fill the gaps between them.
Zeros and intercepts
A zero is an allowed input satisfying f(x)=0f(x)=0f(x)=0, giving a horizontal-axis intercept. The vertical intercept is (0,f(0))(0,f(0))(0,f(0)) when zero is allowed.
Increasing and decreasing
On an increasing interval, any x1<x2x_1<x_2x1​<x2​ give f(x1)<f(x2)f(x_1)<f(x_2)f(x1​)<f(x2​); decreasing reverses the output inequality. Output sign and direction of change are separate.
Piecewise function
Input conditions select different rules for one function. Every input in the domain must receive one output; overlapping rules must agree at every shared input.
Polynomial degree
The largest exponent with nonzero coefficient after combining terms. A nonzero constant has degree zero; the zero polynomial has no degree in this convention.
One-to-one function
Different inputs give different outputs. Strict increase or strict decrease throughout the domain guarantees this; a finite table describes only its specified inputs.
Inverse function f−1f^{-1}f−1
Returns each attained output to its unique original input. Its graph reflects the original graph across y=xy=xy=x. It differs from the reciprocal 1/f1/f1/f.
Period
A positive input shift preserving the domain and repeating every output. The fundamental period is the smallest such shift.
Reference and coterminal angles
A non-axis terminal side has an acute reference angle to the horizontal axis. Coterminal angles reach the same unit-circle point and differ by an integer multiple of 2π2\pi2π.
Natural logarithm
ln⁡x=log⁡ex\ln x=\log_e xlnx=loge​x, where e≈2.71828e\approx2.71828e≈2.71828 is constant. Its argument must be positive; its output can be any real number.
Exact and approximate values
An exact form retains the value without rounding. Use ≈\approx≈ for rounded values and round only the final report.

Problem types, step by step

Find a domain and range

  1. Intersect all original denominator, root, logarithm, declared-domain, and contextual restrictions. Arcsine/arccosine arguments must lie in [−1,1][-1,1][−1,1]; tangent arguments must avoid π/2+nπ\pi/2+n\piπ/2+nπ for every integer nnn. Inverse-function inputs must belong to the original function's actual range.
  2. Collect outputs actually attained at allowed inputs, including interior turning points and isolated points. Check whether an excluded point's height occurs elsewhere.

e.g. Find the real domain of ln⁡(89−∣x∣)\ln(89-|x|)ln(89−∣x∣): (−89,89)(-89,89)(−89,89).

Evaluate and read a piecewise function

  1. Select the rule whose input condition includes the requested input, checking equality signs.
  2. Evaluate that rule. For a range, find each piece's output set with endpoint membership, then take their union.

Choose a function family or model

  1. Equal additions over equal input steps suggest linear behavior; repeated factors suggest exponential behavior; a fixed product suggests a reciprocal model.
  2. For f(x)=axpf(x)=ax^pf(x)=axp, use f(cx)=cpf(x)f(cx)=c^pf(x)f(cx)=cpf(x) for c>0c>0c>0, with x,cxx,cxx,cx in the original domain.
  3. Logarithmic outputs name exponents; bounded repetition suggests sine/cosine.
  4. Check all readings, physical assumptions, and the domain. Finite data do not prove the rule elsewhere. Over step hhh, an exponential ratio is bhb^hbh, not necessarily bbb.

Transform points, domains, and ranges

  1. Factor the inside expression into b(x−h)b(x-h)b(x−h) and solve b(x−h)=ub(x-h)=ub(x−h)=u for each old input uuu.
  2. Apply v↦av+kv\mapsto av+kv↦av+k to its paired output. Transform domain and range endpoints, reversing their order for negative factors while keeping each endpoint's inclusion.

Build a combination or composition

  1. Distinguish shared-input arithmetic from sequential composition; for models, match output and next-input units.
  2. Substitute whole expressions with parentheses, then check each original stage before simplifying. Transfer piecewise branch conditions through the inner function.
  3. Decompose from the innermost operation outward; choices need not be unique.
  4. Temperature conversion CCC followed by response RRR uses R∘CR\circ CR∘C. The reverse may fail units even when numerical substitution exists.

Solve exponential or logarithmic equations

  1. For logarithms, require every original argument to be positive. For exponentials, isolate the exponential factor; a repeated exponential expression may be a useful positive substitution.
  2. Use valid logarithm laws or convert to exponential form, solve, and check all candidates in the original equation. Keep exact logarithmic values until approximating.

Fit an exponential model and solve a target

  1. Use positive output ratios at distinct times and their actual time separation to find bbb or kkk, then use a reading to find the initial value.
  2. Set the output equal to the positive target and isolate the exponential. Take logarithms, keeping the target-to-initial ratio dimensionless; handle a constant model separately.
  3. Check the time unit and model interval. For whole-period observations, check neighboring allowed times to locate the first one meeting the target.

Find a restricted inverse

  1. Verify one-to-one behavior on the stated domain and find the actual range.
  2. Solve y=f(x)y=f(x)y=f(x) for the old input, choosing any root sign from the original restriction. Exchange domain and range.
  3. Check both return identities on their respective domains; an inverse formula's larger natural domain does not enlarge the inverse.

Evaluate trig and inverse-trig compositions

  1. Work from the inside outward, checking each domain and using radians unless another unit is stated.
  2. For an inverse trig value, choose the angle with the required trig value inside its own principal range.
  3. For a different trig function after an inverse, use the unit-circle identity or a triangle and choose signs from the principal range.

e.g. Evaluate cos⁡(arcsin⁡(−11/61))\cos(\arcsin(-11/61))cos(arcsin(−11/61)) exactly: 60/6160/6160/61.

Exam traps

  • Trap Canceling a factor or multiplying by zero restores an undefined input

    Fix Keep the original domain. Removing a graph point removes its output from the range only if no other allowed input attains it.

  • Trap Using a formula outside the stated model domain

    Fix Even if the formula evaluates, a value outside the stated domain is not a model prediction.

  • Trap Reading a viewing window or a few measurements as the whole function

    Fix Use only the supplied information. Connecting readings, interpolating, and extrapolating require a model assumption.

  • Trap A positive secant slope proves increase throughout the interval

    Fix It compares endpoint outputs only. Zero average rate likewise need not mean a constant function; combine unequal intervals using net changes and total duration.

  • Trap Classifying from degree, symmetry, or growth alone

    Fix Inspect the whole formula. Polynomial degree alone does not imply symmetry; a fixed power differs from a variable exponent. A polynomial is also rational.

  • Trap Reading a horizontal shift before factoring

    Fix Read af(b(x−h))+kaf(b(x-h))+kaf(b(x−h))+k by factoring first: old input uuu becomes u/b+hu/b+hu/b+h (b≠0b\ne0b=0). Construct a formula from verbal transformations by applying them in their stated order.

  • Trap Splitting a logarithm of a sum or of negative factors

    Fix There is no sum law. Product and quotient laws require the separate arguments to be positive, even when their product or quotient is positive.

  • Trap Replacing a logarithm of a square by twice the logarithm without its domain

    Fix For allowed base bbb, log⁡b(u2)=2log⁡b∣u∣\log_b(u^2)=2\log_b|u|logb​(u2)=2logb​∣u∣ for real u≠0u\ne0u=0. Writing 2log⁡bu2\log_b u2logb​u requires u>0u>0u>0.

  • Trap Calling kkk the exact fractional change in A0ektA_0e^{kt}A0​ekt

    Fix The per-unit factor is eke^kek, and fractional change is ek−1e^k-1ek−1. Positive exponential decay never reaches zero at a finite allowed time.

  • Trap Treating inverse notation as a reciprocal

    Fix f−1f^{-1}f−1 reverses the function; 1/f1/f1/f takes reciprocals. Similarly, sin⁡−1\sin^{-1}sin−1 denotes arcsine, while 1/sin⁡θ1/\sin\theta1/sinθ is a reciprocal, defined where sine is nonzero.

  • Trap Canceling trig and inverse trig in either order

    Fix Trig after its inverse recovers only an allowed inverse input. The reverse order returns the original angle only in that inverse's principal range; tangent must also be defined. Else find the inner value and select the principal angle.
