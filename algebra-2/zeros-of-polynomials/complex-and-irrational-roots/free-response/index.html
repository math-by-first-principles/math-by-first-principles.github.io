    Worked solution

    Part A

    The converse asks a root list to control the coefficients, and the quickest way to break a claim of that shape is a nonzero constant multiple: multiplying by a nonzero constant ccc changes every coefficient while leaving every root where it was, since c p(r)=0c\,p(r) = 0cp(r)=0 happens precisely when p(r)=0p(r) = 0p(r)=0.

    Start from a real cubic whose nonreal roots already pair and whose roots are easy to read:

    (x−4)(x2+9)=x3−4x2+9x−36(x - 4)(x^2 + 9) = x^3 - 4x^2 + 9x - 36(x−4)(x2+9)=x3−4x2+9x−36

    g(x)=−i(x−4)(x2+9)=−ix3+4ix2−9ix+36ig(x) = -i(x - 4)(x^2 + 9) = -ix^3 + 4ix^2 - 9ix + 36ig(x)=−i(x−4)(x2+9)=−ix3+4ix2−9ix+36i

    g(3i)=−i (3i−4)((3i)2+9)=−i (3i−4)(0)=0g(3i) = -i\,(3i - 4)\big((3i)^2 + 9\big) = -i\,(3i - 4)(0) = 0g(3i)=−i(3i−4)((3i)2+9)=−i(3i−4)(0)=0

    Part B

    Read the root list with its multiplicities, which is exactly what the factored form is telling you: 4i4i4i occurs once, −4i-4i−4i occurs twice, and the degree is 333 in total.

    Suppose, for contradiction, that q=c rq = c\,rq=cr for some nonzero constant ccc and some polynomial rrr with real coefficients. Dividing by ccc changes neither where a polynomial vanishes nor how many times a linear factor divides it, so rrr has precisely the same roots as qqq with precisely the same multiplicities: 4i4i4i once and −4i-4i−4i twice.

    But a polynomial with real coefficients cannot list a conjugate pair unevenly. Its nonreal roots all come from real quadratic factors (x−z)(x−z‾)(x - z)(x - \overline{z})(x−z)(x−z), and every appearance of such a factor supplies one copy of zzz and one copy of z‾\overline{z}z, so the two finish with the same multiplicity:

    multiplicity of 4i = multiplicity of −4i\text{multiplicity of } 4i \ = \ \text{multiplicity of } -4imultiplicity of 4i = multiplicity of −4i

    Here those multiplicities would have to be 111 and 222. No such rrr exists, so qqq is not a nonzero constant times a polynomial with real coefficients.

    Notice how narrowly this misses. The two nonreal roots of qqq genuinely are conjugates of each other, so the root list passes any inspection that reads only the values. What it fails is the count, and the count is not a technicality: it is the difference between a matched pair and an unmatched leftover.

    p(x)=a r(x),a≠0,p(x) = a\,r(x), \qquad a \neq 0,p(x)=ar(x),a=0,

    The equal multiplicities were spent at exactly one step: the matching.
