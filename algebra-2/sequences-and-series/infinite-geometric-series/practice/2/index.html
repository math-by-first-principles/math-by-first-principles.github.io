    What is the value of ∑n=1∞5⋅2 1−n\displaystyle\sum_{n=1}^{\infty} 5 \cdot 2^{\,1-n}n=1∑∞​5⋅21−n?

    Answer choices for question 2

    Solution

    Correct answer: B

    Write out the first terms. At n=1n = 1n=1 the exponent is 000, giving 555; at n=2n = 2n=2 it is −1-1−1, giving 5⋅2−1=525 \cdot 2^{-1} = \tfrac525⋅2−1=25​; at n=3n = 3n=3 it is −2-2−2, giving 54\tfrac5445​. Each term is half the one before, so a=5a = 5a=5 and r=12r = \tfrac12r=21​.

    S=51−12=512=10S = \frac{5}{1 - \tfrac12} = \frac{5}{\tfrac12} = 10S=1−21​5​=21​5​=10

    A negative exponent means a reciprocal, so 2 1−n2^{\,1-n}21−n shrinks as nnn grows, which is what makes this converge.

    For exactly which values of xxx does the series 1+x+x2+x3+⋯1 + x + x^2 + x^3 + \cdots1+x+x2+x3+⋯ converge?

    Answer choices for question 3

    Solution

    Correct answer: A

    The series is geometric with first term 111 (which is not zero, so the criterion applies) and common ratio xxx. It converges if and only if the ratio is smaller than 111 in size.

    ∣x∣<1⟺−1<x<1|x| < 1 \quad\Longleftrightarrow\quad -1 < x < 1∣x∣<1⟺−1<x<1

    Negative values of xxx are allowed: at x=−12x = -\tfrac12x=−21​ the series is 1−12+14−⋯1 - \tfrac12 + \tfrac14 - \cdots1−21​+41​−⋯, which converges to 23\tfrac2332​. That is why 0<x<10 < x < 10<x<1 is too small an answer, since it misses every negative xxx that works. At x=0x = 0x=0 the series is 1+0+0+⋯=11 + 0 + 0 + \cdots = 11+0+0+⋯=1, which converges too.

    Solution

    A ball is dropped from a height of 202020 feet. After each bounce it rises to 34\tfrac3443​ of the height it fell from. What is the total of all the rebound heights (the height reached after the first bounce, plus after the second, and so on forever)?

    Answer choices for question 6

    Solution

    Correct answer: D

    The first rebound height is 34\tfrac3443​ of the 202020-foot drop, and every later rebound is 34\tfrac3443​ of the one before it.

    a=20⋅34=15,r=34a = 20 \cdot \tfrac34 = 15, \qquad r = \tfrac34a=20⋅43​=15,r=43​

    The rebound heights therefore form the geometric series 15+454+⋯15 + \tfrac{45}{4} + \cdots15+445​+⋯, and since ∣34∣<1\left|\tfrac34\right| < 1​43​​<1 it converges.

    S=151−34=1514=60S = \frac{15}{1 - \tfrac34} = \frac{15}{\tfrac14} = 60S=1−43​15​=41​15​=60

    The original 202020-foot drop is not a rebound, so it is not part of this sum. The trap is to use a=20a = 20a=20, which would give 808080.

    What is the value of ∑n=1∞(23) n\displaystyle\sum_{n=1}^{\infty} \left(\tfrac23\right)^{\,n}n=1∑∞​(32​)n?

    Answer choices for question 7

    Solution

    Correct answer: B

    The exponent is nnn, not n−1n - 1n−1, so the first term is not 111. Substituting n=1n = 1n=1 gives 23\tfrac2332​, and n=2n = 2n=2 gives 49\tfrac4994​, so a=23a = \tfrac23a=32​ and r=23r = \tfrac23r=32​.

    S=231−23=2313=2S = \frac{\tfrac23}{1 - \tfrac23} = \frac{\tfrac23}{\tfrac13} = 2S=1−32​32​​=31​32​​=2

    Carelessly using a=1a = 1a=1 would give 333, which is the sum of the series that starts one term earlier, at n=0n = 0n=0. Always read the first term off the index.

  8. 8

    The series 12+12r+12r2+⋯12 + 12r + 12r^2 + \cdots12+12r+12r2+⋯ converges to 888. What is rrr?

    Answer choices for question 8

    Solution

    Correct answer: C

    Put a=12a = 12a=12 and S=8S = 8S=8 into the sum formula and solve for rrr.

    8=121−r  ⟹  1−r=128=32  ⟹  r=1−32=−128 = \frac{12}{1-r} \;\Longrightarrow\; 1 - r = \frac{12}{8} = \frac32 \;\Longrightarrow\; r = 1 - \frac32 = -\frac128=1−r12​⟹1−r=812​=23​⟹r=1−23​=−21​

    A negative ratio makes sense here, because the sum 888 is smaller than the first term 121212, so the later terms must be pulling the total down. Its size is 12<1\tfrac12 < 121​<1, so the series does converge.

  11. 11

    Which statement about the series 2+2+2+2+⋯2 + 2 + 2 + 2 + \cdots2+2+2+2+⋯ is true?

    Answer choices for question 11

    Solution

    Correct answer: A

    This is a geometric series with a=2a = 2a=2 and r=1r = 1r=1, and the sum formula is unavailable, because it would divide by 1−r=01 - r = 01−r=0. Go back to the partial sums instead.

    Sn=2+2+⋯+2⏟n terms=2nS_n = \underbrace{2 + 2 + \cdots + 2}_{n \text{ terms}} = 2nSn​=n terms2+2+⋯+2​​=2n

    Those values 2,4,6,8,…2, 4, 6, 8, \ldots2,4,6,8,… pass every bound, so they close in on no number at all and the series diverges. This is the running-away kind of divergence, not the hopping kind, which is what r=−1r = -1r=−1 would produce.
