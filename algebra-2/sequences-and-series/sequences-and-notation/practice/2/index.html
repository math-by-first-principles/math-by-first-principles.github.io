    The sequence an=n2−6n+12a_n = n^2 - 6n + 12an​=n2−6n+12 is defined for n≥1n \ge 1n≥1. What is its smallest term?

    Answer choices for question 1

    Solution

    Correct answer: D

    Complete the square to see where the rule bottoms out.

    an=n2−6n+12=(n−3)2+3a_n = n^2 - 6n + 12 = (n - 3)^2 + 3an​=n2−6n+12=(n−3)2+3

    The square (n−3)2(n-3)^2(n−3)2 is never negative, so an≥3a_n \ge 3an​≥3, with equality exactly when n=3n = 3n=3. Since 333 is a positive integer it is a legal index, so the smallest term really is attained: a3=3a_3 = 3a3​=3. (Checking by hand, the terms open 7, 4, 3, 4, 7,…7,\ 4,\ 3,\ 4,\ 7, \ldots7, 4, 3, 4, 7,…)

    How many terms are in the sum ∑k=417k\displaystyle\sum_{k=4}^{17} kk=4∑17​k?

    Answer choices for question 2

    Solution

    Correct answer: A

    Both limits are included, so subtracting them counts the steps between them and you need one more term than that.

    17−4+1=1417 - 4 + 1 = 1417−4+1=14

    The index runs 4,5,6,…,174, 5, 6, \ldots, 174,5,6,…,17, which is 141414 values. Answering 131313 is the classic off-by-one.

    A sequence has a1=2a_1 = 2a1​=2 and an=3an−1−1a_n = 3a_{n-1} - 1an​=3an−1​−1 for n≥2n \ge 2n≥2. What is a4a_4a4​?

    Answer choices for question 4

    Solution

    Correct answer: B

    Climb from the seed, applying the whole rule (multiply by 333, then subtract 111) at every step.

    a2=3(2)−1=5,a3=3(5)−1=14a_2 = 3(2) - 1 = 5, \qquad a_3 = 3(5) - 1 = 14a2​=3(2)−1=5,a3​=3(5)−1=14

    Stopping at a3=14a_3 = 14a3​=14 is the common slip here.

    Evaluate ∑k=14(−1)kk\displaystyle\sum_{k=1}^{4} (-1)^k kk=1∑4​(−1)kk.

    Answer choices for question 6

    Solution

    Correct answer: D

    The factor (−1)k(-1)^k(−1)k is −1-1−1 at odd indices and +1+1+1 at even ones, so the signs alternate starting with a minus.

    ∑k=14(−1)kk=−1+2−3+4=2\sum_{k=1}^{4} (-1)^k k = -1 + 2 - 3 + 4 = 2∑k=14​(−1)kk=−1+2−3+4=2

    Dropping the sign factor would give 101010, and starting with a plus instead of a minus would give −2-2−2.

  7. 7

    A sequence begins at a1=4a_1 = 4a1​=4, and every term after that is 333 more than the term before it. Which explicit rule defines the same sequence?

    Answer choices for question 7

    Solution

    Correct answer: A

    The stated rule pins the sequence down without any guesswork: start at 444 and add 333 each time, giving 4, 7, 10, 134,\ 7,\ 10,\ 134, 7, 10, 13. Now test each candidate against those terms, since an explicit rule has to match at every index, not just the first.

    a1=3(1)+1=4,a2=3(2)+1=7,a3=3(3)+1=10a_1 = 3(1) + 1 = 4, \qquad a_2 = 3(2) + 1 = 7, \qquad a_3 = 3(3) + 1 = 10a1​=3(1)+1=4,a2​=3(2)+1=7,a3​=3(3)+1=10

    The rule an=4na_n = 4nan​=4n gets the first term right and then gives 888 instead of 777; the rule an=n+3a_n = n + 3an​=n+3 gives 4,5,64, 5, 64,5,6; and the rule an=4n−1a_n = 4n - 1an​=4n−1 gives 3,7,113, 7, 113,7,11. Only 3n+13n + 13n+1 matches all the way along.

  8. 8

    Which statement about the graph of the sequence an=n2+1a_n = n^2 + 1an​=n2+1 is correct?

    Answer choices for question 8

    Solution

    Correct answer: B

    The graph of a sequence is the set of points (n,an)(n, a_n)(n,an​), and only positive integers are legal inputs.

    (1,2),(2,5),(3,10),(4,17),…(1, 2), \quad (2, 5), \quad (3, 10), \quad (4, 17), \ldots(1,2),(2,5),(3,10),(4,17),…

    There is no point above n=2.5n = 2.5n=2.5, because a2.5a_{2.5}a2.5​ is undefined, so the graph is a scatter of isolated dots. Joining them into a curve would invent values the sequence does not have.

  9. 9

    A finite sequence runs from a5a_5a5​ through a12a_{12}a12​. How many terms does it have?

    Answer choices for question 9

    Solution

    Correct answer: C

    Both ends are included, so count the indices 5,6,7,…,125, 6, 7, \ldots, 125,6,7,…,12 the same way you count terms in a sum.

    12−5+1=812 - 5 + 1 = 812−5+1=8

    Subtracting alone gives 777, which counts the steps from a5a_5a5​ to a12a_{12}a12​, not the terms.

    Answer choices for question 10

    Solution

    Correct answer: B

    Each term is a perfect square, and the numbers being squared run 111 through 666, so the summand is k2k^2k2 with the index from 111 to 666.

    ∑k=16k2=1+4+9+16+25+36=91\sum_{k=1}^{6} k^2 = 1 + 4 + 9 + 16 + 25 + 36 = 91∑k=16​k2=1+4+9+16+25+36=91

    The limits 111 to 555 drop the last term (555555), the limits 222 to 666 drop the first (909090), and cubing gives 441441441.

    Evaluate ∑k=394\displaystyle\sum_{k=3}^{9} 4k=3∑9​4.

    Answer choices for question 11

    Solution

    Correct answer: C

    The summand does not mention kkk, so every term is 444. What the index decides is how many terms there are.

    9−3+1=7 terms⟹∑k=394=7×4=289 - 3 + 1 = 7 \text{ terms} \quad \Longrightarrow \quad \sum_{k=3}^{9} 4 = 7 \times 4 = 289−3+1=7 terms⟹∑k=39​4=7×4=28

    Counting 9−3=69 - 3 = 69−3=6 terms instead would give 242424.

  12. 12

    For the sequence an=(n−1)(n−2)a_n = (n-1)(n-2)an​=(n−1)(n−2), what is the smallest index nnn with an≠0a_n \ne 0an​=0?

    Answer choices for question 12

    Solution

    Correct answer: A

    A product is zero exactly when one of its factors is zero, so test the indices in order.

    a1=(0)(−1)=0,a2=(1)(0)=0,a3=(2)(1)=2a_1 = (0)(-1) = 0, \qquad a_2 = (1)(0) = 0, \qquad a_3 = (2)(1) = 2a1​=(0)(−1)=0,a2​=(1)(0)=0,a3​=(2)(1)=2

    The first two terms vanish and the third does not, so the smallest such index is n=3n = 3n=3. The question asks for the index, not the term 222.
