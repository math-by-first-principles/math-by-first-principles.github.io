  3. 3

    A sequence has a1=1a_1 = 1a1​=1 and an=an−1+(2n−1)a_n = a_{n-1} + (2n - 1)an​=an−1​+(2n−1) for n≥2n \ge 2n≥2. What is a6a_6a6​?

    Answer choices for question 3

    Solution

    Correct answer: B

    The rule adds the next odd number each time, so climb the ladder from the seed.

    a2=1+3=4,a3=4+5=9,a4=9+7=16a_2 = 1 + 3 = 4, \qquad a_3 = 4 + 5 = 9, \qquad a_4 = 9 + 7 = 16a2​=1+3=4,a3​=4+5=9,a4​=9+7=16

    Continuing to the sixth term,

    a5=16+9=25,a6=25+11=36.a_5 = 16 + 9 = 25, \qquad a_6 = 25 + 11 = 36.a5​=16+9=25,a6​=25+11=36.

    The terms are the perfect squares, so the explicit rule here is an=n2a_n = n^2an​=n2. Compare that with the lesson, which ran this same step rule from the seed a1=2a_1 = 2a1​=2 and landed on an=n2+1a_n = n^2 + 1an​=n2+1. Same step rule, different seed, and every single term shifts by one. The seed is not decoration: it is half the definition.

    A sequence has a1=2a_1 = 2a1​=2 and an=an−1+3a_n = a_{n-1} + 3an​=an−1​+3 for n≥2n \ge 2n≥2. Which explicit rule defines the same sequence?

    Answer choices for question 4

    Solution

    Correct answer: D

    Generate the terms first, then test the candidates against them.

    a1=2,a2=5,a3=8,a4=11a_1 = 2, \quad a_2 = 5, \quad a_3 = 8, \quad a_4 = 11a1​=2,a2​=5,a3​=8,a4​=11

    The rule an=3n−1a_n = 3n - 1an​=3n−1 gives 2,5,8,112, 5, 8, 112,5,8,11, so it matches. It also obeys the same step rule, since (3n−1)−(3(n−1)−1)=3(3n - 1) - \big(3(n-1) - 1\big) = 3(3n−1)−(3(n−1)−1)=3, and it starts at the same seed, so the two definitions agree at every index. The rule 3n+23n + 23n+2 starts at 555, the rule 2n+12n + 12n+1 starts at 333, and 3n3n3n starts at 333.

    Solution

    Correct answer: A

    At k=1k = 1k=1 the exponent k+1=2k + 1 = 2k+1=2 is even, so the first sign is positive, and the signs then alternate.

    1−2+3−4+5−61 - 2 + 3 - 4 + 5 - 61−2+3−4+5−6

    Pairing the terms makes the arithmetic quick: each pair contributes −1-1−1.

    (1−2)+(3−4)+(5−6)=−1−1−1=−3(1 - 2) + (3 - 4) + (5 - 6) = -1 - 1 - 1 = -3(1−2)+(3−4)+(5−6)=−1−1−1=−3

    A sequence obeys an=an−1+an−2a_n = a_{n-1} + a_{n-2}an​=an−1​+an−2​ for n≥3n \ge 3n≥3, and it is known that a3=7a_3 = 7a3​=7 and a4=11a_4 = 11a4​=11. What is a1a_1a1​?

    Answer choices for question 10

    Solution

    Correct answer: D

    A recursion can be run backwards as easily as forwards. Apply the rule at n=4n = 4n=4 first.

    a4=a3+a2  ⟹  11=7+a2  ⟹  a2=4a_4 = a_3 + a_2 \;\Longrightarrow\; 11 = 7 + a_2 \;\Longrightarrow\; a_2 = 4a4​=a3​+a2​⟹11=7+a2​⟹a2​=4

    Now apply it at n=3n = 3n=3.

    a3=a2+a1  ⟹  7=4+a1  ⟹  a1=3a_3 = a_2 + a_1 \;\Longrightarrow\; 7 = 4 + a_1 \;\Longrightarrow\; a_1 = 3a3​=a2​+a1​⟹7=4+a1​⟹a1​=3

    The sequence is 3, 4, 7, 11,…3,\ 4,\ 7,\ 11, \ldots3, 4, 7, 11,…, which checks out.
