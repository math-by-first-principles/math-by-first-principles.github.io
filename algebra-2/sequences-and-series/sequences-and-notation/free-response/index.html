  1. Problem 1 A centered index

    A finite sequence is given by an=∣n∣+2a_n=|n|+2an​=∣n∣+2 for the integer indices −2,−1,0,1,2-2,-1,0,1,2−2,−1,0,1,2. Find a0a_0a0​.

    1. Hint 1

      The subscript is the input to the rule.

    2. Hint 2

      The absolute value of zero is zero.

    Answer

    a0=2a_0=2a0​=2.

    Full solution

    The index zero is explicitly included, so substitute it into the rule.

    a0=∣0∣+2a_0=|0|+2a0​=∣0∣+2

    Thus a0=2a_0=2a0​=2.

    The input is 000, while the term it names is 222.

    Answer

    a0=2a_0=2a0​=2.

    Key idea

    An index identifies a term but need not equal that term's value.

  2. Problem 2 A finite sum

    Evaluate ∑k=03(2k+(−1)k)\sum_{k=0}^3(2^k+(-1)^k)∑k=03​(2k+(−1)k).

    1. Hint 1

      Both limits are included, so there are four summands.

    2. Hint 2

      Evaluate the two powers at each of the four integer indices.

    Answer

    151515.

    Full solution

    The summands at k=0,1,2,3k=0,1,2,3k=0,1,2,3 are 2,1,5,72,1,5,72,1,5,7, respectively.

    ∑k=03(2k+(−1)k)=15\sum_{k=0}^3(2^k+(-1)^k)=15k=0∑3​(2k+(−1)k)=15

    This is four evaluations, including the one at zero.

    Answer

    151515.

    Key idea

    Sigma notation instructs you to evaluate the entire summand at every included integer index.

  3. Problem 3 Three starting terms

    A sequence has a1=2a_1=2a1​=2, a2=1a_2=1a2​=1, and a3=4a_3=4a3​=4. For n≥4n\ge4n≥4, its rule is an=an−1+an−3a_n=a_{n-1}+a_{n-3}an​=an−1​+an−3​. Find a4a_4a4​.

    1. Hint 1

      Substitute the index four into each subscript of the rule.

    2. Hint 2

      The terms required are those at indices 333 and 111.

    Answer

    a4=6a_4=6a4​=6.

    Full solution

    At n=4n=4n=4, the recursion requires a3a_3a3​ and a1a_1a1​, both of which are supplied.

    a4=a3+a1a_4=a_3+a_1a4​=a3​+a1​

    Therefore a4=4+2=6a_4=4+2=6a4​=4+2=6.

    The unused seed a2a_2a2​ will be needed when computing a5a_5a5​.

    Answer

    a4=6a_4=6a4​=6.

    Key idea

    A recursion may reach past the immediately preceding term, so its subscripts must be followed carefully.

  5. Problem 5 An incomplete rule

    A proposed sequence has a1=1a_1=1a1​=1 and a3=5a_3=5a3​=5, with an=an−2+2an−3a_n=a_{n-2}+2a_{n-3}an​=an−2​+2an−3​ for n≥4n\ge4n≥4. Identify the missing seed. Show that choosing it as 111 or 333 produces different values of a5a_5a5​.

    1. Hint 1

      A rule beginning at index four does not determine all of its first three terms.

    2. Hint 2

      Compute a4a_4a4​ and a5a_5a5​, tracking which starting terms each one uses.

    Answer

    The missing seed is a2a_2a2​; a5=7a_5=7a5​=7 if a2=1a_2=1a2​=1, and a5=11a_5=11a5​=11 if a2=3a_2=3a2​=3.

    Full solution

    The missing initial term is a2a_2a2​.

    The rule gives a4=a2+2a1a_4=a_2+2a_1a4​=a2​+2a1​, which is a2+2a_2+2a2​+2, so even a4a_4a4​ depends on that choice.

    At the next step,

    a5=a3+2a2a_5=a_3+2a_2a5​=a3​+2a2​

    which is 5+2a25+2a_25+2a2​.

    The two proposed seeds give 777 and 111111, showing that the incomplete specification does not define one sequence.

    Answer

    The missing seed is a2a_2a2​; a5=7a_5=7a5​=7 if a2=1a_2=1a2​=1, and a5=11a_5=11a5​=11 if a2=3a_2=3a2​=3.

    Key idea

    This additive rule starts at index four and reaches back three steps, so all three of its first terms must be given before it defines one sequence.

  6. Problem 6 Two ways to generate

    For integers n≥0n\ge0n≥0, let cn=2n−1c_n=2^n-1cn​=2n−1. Write a recursive rule using only cn−1c_{n-1}cn−1​ and constants, including its seed and valid starting index. Find c4c_4c4​.

    1. Hint 1

      An explicit rule and a recursive definition must produce the same term at every allowed index.

    2. Hint 2

      Substitute n−1n-1n−1 into the explicit formula to express the preceding term.

    3. Hint 3

      Use 2n=2⋅2n−12^n=2\cdot2^{n-1}2n=2⋅2n−1 and compare the constant terms.

    Answer

    c0=0c_0=0c0​=0; cn=2cn−1+1c_n=2c_{n-1}+1cn​=2cn−1​+1 for n≥1n\ge1n≥1; c4=15c_4=15c4​=15.

    Full solution

    The explicit rule gives c0=0c_0=0c0​=0.

    Also

    2cn−1+1=2n−12c_{n-1}+1=2^n-12cn−1​+1=2n−1

    so cn=2cn−1+1c_n=2c_{n-1}+1cn​=2cn−1​+1 for n≥1n\ge1n≥1.

    The recursion produces 0,1,3,7,150,1,3,7,150,1,3,7,15 through index four.

    The explicit check 24−1=152^4-1=1524−1=15 agrees.

    Answer

    c0=0c_0=0c0​=0; cn=2cn−1+1c_n=2c_{n-1}+1cn​=2cn−1​+1 for n≥1n\ge1n≥1; c4=15c_4=15c4​=15.

    Key idea

    When the next value can be written through the preceding one, as here, an explicit rule becomes a recursion with a seed and a starting index.

  7. Problem 7 A shifted index

    Four sensor readings are r6=7r_6=7r6​=7, r7=−4r_7=-4r7​=−4, r8=2r_8=2r8​=2 and r9=−8r_9=-8r9​=−8. Write their total in sigma notation with index kkk running from 000 through 333, then evaluate it.

    1. Hint 1

      The summation index is a counter and need not equal a reading's subscript.

    2. Hint 2

      Choose a subscript expression that gives six at index zero and nine at index three.

    Answer

    ∑k=03rk+6=−3\sum_{k=0}^3 r_{k+6}=-3∑k=03​rk+6​=−3; the reversed form ∑k=03r9−k\sum_{k=0}^3 r_{9-k}∑k=03​r9−k​ is also valid.

    Full solution

    The subscript k+6k+6k+6 runs through 6,7,8,96,7,8,96,7,8,9 as kkk runs from 000 to 333, so the total is

    ∑k=03rk+6.\sum_{k=0}^3 r_{k+6}.k=0∑3​rk+6​.

    Substituting the recorded values gives 7−4+2−87-4+2-87−4+2−8, which is −3-3−3.

    Listing the readings in reverse order, as ∑k=03r9−k\sum_{k=0}^3 r_{9-k}∑k=03​r9−k​, gives the same total.

    Answer

    ∑k=03rk+6=−3\sum_{k=0}^3 r_{k+6}=-3∑k=03​rk+6​=−3; the reversed form ∑k=03r9−k\sum_{k=0}^3 r_{9-k}∑k=03​r9−k​ is also valid.

  8. Problem 8 A renaming claim

    For a fixed real number mmm, a student writes ∑k=02(m+k)=∑j=02(m+j)\sum_{k=0}^2(m+k)=\sum_{j=0}^2(m+j)∑k=02​(m+k)=∑j=02​(m+j). Is that true for every mmm? Evaluate both sums in terms of mmm to justify your answer.

    1. Hint 1

      The index changes name but still takes the same three values.

    2. Hint 2

      The letter mmm remains fixed while the temporary index runs through zero, one, and two.

    Answer

    Yes; both sums equal 3m+33m+33m+3.

    Full solution

    Each sum adds mmm, m+1m+1m+1, and m+2m+2m+2.

    Therefore

    m+(m+1)+(m+2)=3m+3m+(m+1)+(m+2)=3m+3m+(m+1)+(m+2)=3m+3

    The names kkk and jjj disappear after evaluation; neither replaces the fixed parameter mmm.

    Answer

    Yes; both sums equal 3m+33m+33m+3.

    Key idea

    A fresh summation-index name changes no summands and therefore changes no sum.

  9. Problem 9 A claimed last index

    A finite sequence starts at index 444 and has 777 terms. A student says its last term is a11a_{11}a11​. Is that correct? State its last index and explain.

    1. Hint 1

      The first index already names one of the terms.

    2. Hint 2

      There are six steps between the first and seventh terms.

    Answer

    No; the last index is 101010.

    Full solution

    The seven indices are 4,5,6,7,8,9,104,5,6,7,8,9,104,5,6,7,8,9,10.

    Equivalently,

    4+(7−1)=104+(7-1)=104+(7−1)=10

    Index 111111 would introduce an eighth term, so it is outside the stated finite domain.

    Answer

    No; the last index is 101010.

    Key idea

    A run of k terms spans k minus one steps between its first and last indices.

    1. Hint 1

    2. Hint 2

    Answer

    No; a2=a3=5a_2=a_3=5a2​=a3​=5. The domain is {1,2,3,…}\{1,2,3,\ldots\}{1,2,3,…}, and the sequence is infinite.

    Full solution

    At index two, a2=2+62a_2=2+\frac62a2​=2+26​, which is 555, and at index three, a3=3+63a_3=3+\frac63a3​=3+36​, also 555.

    Different inputs may share an output; every positive integer still receives exactly one value, so the rule defines a sequence.

    The domain contains every positive integer, so the sequence is infinite.

    Answer

    No; a2=a3=5a_2=a_3=5a2​=a3​=5. The domain is {1,2,3,…}\{1,2,3,\ldots\}{1,2,3,…}, and the sequence is infinite.

    Key idea

    Different indices may name equal terms without violating the definition of a sequence.
