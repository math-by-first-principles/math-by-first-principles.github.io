    A ball rolling down a ramp travels 444 cm in the first second, and in each second after that it travels 666 cm more than in the second before. How far does it travel in the first 101010 seconds altogether?

    Answer choices for question 1

    Solution

    Correct answer: A

    The per-second distances form an arithmetic sequence with a1=4a_1 = 4a1​=4 and d=6d = 6d=6. Reaching the 10th second takes 999 steps, not 101010.

    a10=4+9⋅6=58 cma_{10} = 4 + 9 \cdot 6 = 58 \text{ cm}a10​=4+9⋅6=58 cm

    Now add the ten distances.

    S10=102(4+58)=5⋅62=310 cmS_{10} = \frac{10}{2}(4 + 58) = 5 \cdot 62 = 310 \text{ cm}S10​=210​(4+58)=5⋅62=310 cm

    Taking ten steps instead of nine gives the wrong last term 646464 and the wrong total 340340340; forgetting the half gives 620620620.

    Solution

    Correct answer: C

    The terms 2k−12k - 12k−1 step by 222, but the sum starts at k=5k = 5k=5, so find the two ends first.

    2(5)−1=9,2(30)−1=592(5) - 1 = 9, \qquad 2(30) - 1 = 592(5)−1=9,2(30)−1=59

    What is the sum of all the integers from −12-12−12 to 404040 inclusive?

    Answer choices for question 3

    Solution

    Correct answer: D

    The integers from −12-12−12 to 404040 are arithmetic with d=1d = 1d=1, so count them before adding.

    n=40−(−12)1+1=52+1=53n = \frac{40 - (-12)}{1} + 1 = 52 + 1 = 53n=140−(−12)​+1=52+1=53

    Now apply the sum.

    A second route confirms it: everything from −12-12−12 to 121212 cancels in pairs, leaving 13+14+⋯+40=282(13+40)=74213 + 14 + \cdots + 40 = \frac{28}{2}(13 + 40) = 74213+14+⋯+40=228​(13+40)=742.

  4. 4

    A stack of logs has 252525 logs in the bottom row, 242424 in the next row up, and so on, with 101010 logs in the top row. How many logs are in the stack?

    Answer choices for question 4

    Solution

    Correct answer: D

    The rows hold 25,24,…,1025, 24, \ldots, 1025,24,…,10 logs, an arithmetic sequence with d=−1d = -1d=−1. Count the rows first.

    n=10−25−1+1=15+1=16n = \frac{10 - 25}{-1} + 1 = 15 + 1 = 16n=−110−25​+1=15+1=16

    Now add the sixteen rows.

    S16=162(25+10)=8⋅35=280S_{16} = \frac{16}{2}(25 + 10) = 8 \cdot 35 = 280S16​=216​(25+10)=8⋅35=280

    Using 151515 rows (forgetting the +1+1+1) would give 262.5262.5262.5, not even a whole number of logs, which is a useful signal that the count was wrong.

    The first 151515 terms of an arithmetic sequence add to 000, and a1=−14a_1 = -14a1​=−14. What is ddd?

    Answer choices for question 5

    Solution

    Correct answer: B

    No last term is given, so use the form of the sum built from a1a_1a1​ and ddd.

    S15=152(2(−14)+14d)=15(−14+7d)=0S_{15} = \frac{15}{2}\big(2(-14) + 14d\big) = 15(-14 + 7d) = 0S15​=215​(2(−14)+14d)=15(−14+7d)=0

    A product is zero only when a factor is, and 15≠015 \neq 015=0, so the bracket must vanish.

    −14+7d=0  ⇒  d=2-14 + 7d = 0 \;\Rightarrow\; d = 2−14+7d=0⇒d=2

    The sequence is then −14,−12,…,12,14-14, -12, \ldots, 12, 14−14,−12,…,12,14, symmetric about its middle term a8=0a_8 = 0a8​=0, which is exactly why the total cancels.

  6. 6

    The first nnn odd numbers add up to 400400400. What is nnn?

    Answer choices for question 6

    Solution

    Correct answer: A

    The first nnn odd numbers are 1,3,5,…,2n−11, 3, 5, \ldots, 2n - 11,3,5,…,2n−1, an arithmetic sequence with d=2d = 2d=2. Apply the sum.

    Sn=n2(1+(2n−1))=n2(2n)=n2S_n = \frac{n}{2}\big(1 + (2n - 1)\big) = \frac{n}{2}(2n) = n^2Sn​=2n​(1+(2n−1))=2n​(2n)=n2

    So the sum of the first nnn odd numbers is always a perfect square. Set it equal to 400400400.

    n2=400  ⇒  n=20n^2 = 400 \;\Rightarrow\; n = 20n2=400⇒n=20

    A count cannot be negative, so n=−20n = -20n=−20 is discarded.

  7. 7

    Two arithmetic sequences share the same common difference. The first has a1=5a_1 = 5a1​=5 and a20=62a_{20} = 62a20​=62; the second has b1=12b_1 = 12b1​=12. What is b20b_{20}b20​?

    Answer choices for question 7

    Solution

    Correct answer: B

    Recover the shared common difference from the sequence you know completely. From the 1st term to the 20th is 191919 steps.

    d=62−519=3d = \frac{62 - 5}{19} = 3d=1962−5​=3

    Now run the second sequence out to its 20th term with that same ddd.

    b20=12+19⋅3=12+57=69b_{20} = 12 + 19 \cdot 3 = 12 + 57 = 69b20​=12+19⋅3=12+57=69

    There is a shortcut worth seeing: the second sequence starts 777 above the first and climbs at the same rate, so it stays exactly 777 above it forever, and 62+7=6962 + 7 = 6962+7=69.

    The three angles of a triangle form an arithmetic sequence, and the smallest is 40∘40^\circ40∘. What is the largest?

    Answer choices for question 8

    Solution

    Correct answer: D

    Name the angles m−dm - dm−d, mmm, and m+dm + dm+d, centring them on the middle one. Their sum collapses to 3m3m3m, and a triangle's angles total 180∘180^\circ180∘.

    3m=180∘  ⇒  m=60∘3m = 180^\circ \;\Rightarrow\; m = 60^\circ3m=180∘⇒m=60∘

    The middle angle is 60∘60^\circ60∘ whatever ddd turns out to be. The smallest angle is 40∘40^\circ40∘, so d=20∘d = 20^\circd=20∘, and the largest is 60∘+20∘60^\circ + 20^\circ60∘+20∘.

    40∘+60∘+80∘=180∘40^\circ + 60^\circ + 80^\circ = 180^\circ40∘+60∘+80∘=180∘

    The largest angle is 80∘80^\circ80∘.

  10. 10

    An arithmetic sequence has 111111 terms that add to 231231231. What is its 6th term?

    Answer choices for question 10

    Solution

    Correct answer: A

    The number of terms is odd, so the middle term (the 6th of 111111) is the average of the first and last, and the sum is the number of terms times that average.

    S11=112(a1+a11)=11⋅a6S_{11} = \frac{11}{2}(a_1 + a_{11}) = 11 \cdot a_6S11​=211​(a1​+a11​)=11⋅a6​

    Now divide.

    a6=23111=21a_6 = \frac{231}{11} = 21a6​=11231​=21

    The common difference is never needed, so the 6th term is fully determined by the total alone.

    One arithmetic sequence starts at 777 with common difference 444. Another starts at 105105105 with common difference −3-3−3. For which nnn do the two sequences have the same nnnth term?

    Answer choices for question 12

    Solution

    Correct answer: B

    Write each nnnth term and simplify.

    an=7+(n−1)4=4n+3,bn=105+(n−1)(−3)=108−3na_n = 7 + (n-1)4 = 4n + 3, \qquad b_n = 105 + (n-1)(-3) = 108 - 3nan​=7+(n−1)4=4n+3,bn​=105+(n−1)(−3)=108−3n

    Now set them equal and solve.

    4n+3=108−3n  ⇒  7n=105  ⇒  n=154n + 3 = 108 - 3n \;\Rightarrow\; 7n = 105 \;\Rightarrow\; n = 154n+3=108−3n⇒7n=105⇒n=15

    Both sequences hit 636363 at their 15th term: 4(15)+3=634(15) + 3 = 634(15)+3=63 and 108−3(15)=63108 - 3(15) = 63108−3(15)=63.
