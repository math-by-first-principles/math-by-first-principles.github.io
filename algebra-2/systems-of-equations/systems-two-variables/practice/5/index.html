    For which value of kkk does the system 2x+ky=62x + ky = 62x+ky=6 and x+2y=3x + 2y = 3x+2y=3 have infinitely many solutions?

    Answer choices for question 2

    Solution

    Correct answer: A

    For the same line, the first equation must be twice the second: 2(x+2y=3)2(x + 2y = 3)2(x+2y=3) is 2x+4y=62x + 4y = 62x+4y=6.

  3. 3

    A puzzle says a pair of numbers satisfies both x+y=10x + y = 10x+y=10 and 2x+2y=202x + 2y = 202x+2y=20. How many such pairs are there?

    Answer choices for question 3

    Solution

    Correct answer: D

    The second equation is just twice the first, so it says nothing new; both describe the line x+y=10x + y = 10x+y=10.

    2x+2y=20 → ÷2  x+y=102x + 2y = 20 \ \xrightarrow{\ \div 2\ }\ x + y = 102x+2y=20  ÷2 ​ x+y=10

    Every pair on that line works, so there are infinitely many.

  8. 8

    The system x+2y=4x + 2y = 4x+2y=4 and 2x+4y=82x + 4y = 82x+4y=8 is graphed. What do you see?

    Answer choices for question 8

    Solution

    Correct answer: B

    The second equation is twice the first, so both plot the same line.

    2x+4y=8 → ÷2  x+2y=42x + 4y = 8 \ \xrightarrow{\ \div 2\ }\ x + 2y = 42x+4y=8  ÷2 ​ x+2y=4
