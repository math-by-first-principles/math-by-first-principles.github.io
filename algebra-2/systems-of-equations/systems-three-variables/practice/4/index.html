  1. 1

    Solve x+y+z=2x + y + z = 2x+y+z=2, x−y+2z=5x - y + 2z = 5x−y+2z=5, 2x+y−z=22x + y - z = 22x+y−z=2. What is xxx?

    Answer choices for question 1

    Solution

    Correct answer: A

    Subtract the first equation from the second: −2y+z=3-2y + z = 3−2y+z=3. Subtract twice the first from the third: −y−3z=−2-y - 3z = -2−y−3z=−2, that is y+3z=2y + 3z = 2y+3z=2. Solving this pair gives y=−1y = -1y=−1, z=1z = 1z=1.

    x=2−y−z=2−(−1)−1=2x = 2 - y - z = 2 - (-1) - 1 = 2x=2−y−z=2−(−1)−1=2

    The solution is (2,−1,1)(2, -1, 1)(2,−1,1).

  2. 2

    Elimination reduces a system to 0=40 = 40=4. What is the solution set?

    Answer choices for question 2

    Solution

    Correct answer: B

    The row 0=40 = 40=4 can never be satisfied, so no triple solves the system.

    0=4 is false ⇒ empty solution set0 = 4 \text{ is false} \ \Rightarrow \ \text{empty solution set}0=4 is false ⇒ empty solution set

    The system is inconsistent.

  3. 3

    The equations 2x−y+z=32x - y + z = 32x−y+z=3 and 4x−2y+2z=m4x - 2y + 2z = m4x−2y+2z=m share all their solutions for which value of mmm?

    Answer choices for question 3

    Solution

    Correct answer: D

    The second left side is twice the first, so the equations coincide only when the right side doubles too.

    m=2(3)=6m = 2(3) = 6m=2(3)=6

    Any other mmm makes them parallel and inconsistent.

  4. 4

    Three planes meet each other pairwise in three different parallel lines, with no point common to all three. The system is:

    Answer choices for question 4

    Solution

    Correct answer: C

    No point lies on all three planes at once, since the pairwise intersection lines never coincide.

    no common point ⇒ no solution\text{no common point} \ \Rightarrow \ \text{no solution}no common point ⇒ no solution

    Elimination exposes it as a false row.

  5. 5

    Find a nonzero solution of the homogeneous system x+y+z=0x + y + z = 0x+y+z=0, x−y+z=0x - y + z = 0x−y+z=0.

    Answer choices for question 5

    Solution

    Correct answer: B

    Subtracting the equations gives 2y=02y = 02y=0, so y=0y = 0y=0; adding them gives 2x+2z=02x + 2z = 02x+2z=0, so x=−zx = -zx=−z.

    (x,y,z)=(1,0,−1)(x, y, z) = (1, 0, -1)(x,y,z)=(1,0,−1)

    Check: 1+0−1=01 + 0 - 1 = 01+0−1=0 and 1−0−1=01 - 0 - 1 = 01−0−1=0, both hold.

  6. 6

    A system's solution set is the entire plane 2x+y−z=42x + y - z = 42x+y−z=4. How many of the three original equations were independent?

    Answer choices for question 6

    Solution

    Correct answer: D

    A whole plane of solutions means two free variables, so only one real constraint survived.

    3−r=2 ⇒ r=13 - r = 2 \ \Rightarrow \ r = 13−r=2 ⇒ r=1

    Exactly one independent equation remains; the other two are multiples of it.

  7. 7

    Which pair of equations is inconsistent (no common solution)?

    Answer choices for question 7

    Solution

    Correct answer: B

    Two equations with the same left side but different right sides can never both hold.

    x+y+z=1 and x+y+z=2 ⇒ 1=2, impossiblex + y + z = 1 \text{ and } x + y + z = 2 \ \Rightarrow \ 1 = 2, \text{ impossible}x+y+z=1 and x+y+z=2 ⇒ 1=2, impossible

    The other pairs describe planes that do intersect.

  8. 8

    Which triple satisfies all of x+y+z=6x + y + z = 6x+y+z=6, 2x+y−z=22x + y - z = 22x+y−z=2, x−y+2z=7x - y + 2z = 7x−y+2z=7?

    Answer choices for question 8

    Solution

    Correct answer: C

    Test each triple in all three equations. Only one satisfies every one.

    2+1+3=6,2(2)+1−3=2,2−1+2(3)=72 + 1 + 3 = 6, \quad 2(2) + 1 - 3 = 2, \quad 2 - 1 + 2(3) = 72+1+3=6,2(2)+1−3=2,2−1+2(3)=7

    So (2,1,3)(2, 1, 3)(2,1,3) works; each other triple fails the second equation.

  9. 9

    How many solutions does the single equation x−y+4z=8x - y + 4z = 8x−y+4z=8 in three unknowns have?

    Answer choices for question 9

    Solution

    Correct answer: A

    One equation in three unknowns leaves two degrees of freedom.

    x=8+y−4z,y and z freex = 8 + y - 4z, \quad y \text{ and } z \text{ free}x=8+y−4z,y and z free

    Two free variables give a whole plane of solutions.

  10. 10

    Three numbers sum to 121212. The first plus the third is 888, and the second is 333 less than the third. What is the third number?

    Answer choices for question 10

    Solution

    Correct answer: C

    Let the numbers be xxx, yyy, zzz. Then x+y+z=12x + y + z = 12x+y+z=12 and x+z=8x + z = 8x+z=8 give y=4y = 4y=4. Since y=z−3y = z - 3y=z−3, the third number is z=y+3=7z = y + 3 = 7z=y+3=7.

    z=4+3=7z = 4 + 3 = 7z=4+3=7

    Then x=8−z=1x = 8 - z = 1x=8−z=1, so the numbers are 111, 444, 777.

  11. 11

    Three numbers sum to 121212, the first plus the third is 888, and the second is 333 less than the third. What is the first number?

    Answer choices for question 11

    Solution

    Correct answer: A

    The sum x+y+z=12x + y + z = 12x+y+z=12 together with x+z=8x + z = 8x+z=8 gives y=4y = 4y=4, and y=z−3y = z - 3y=z−3 gives z=7z = 7z=7. Now use x+z=8x + z = 8x+z=8.

    x=8−7=1x = 8 - 7 = 1x=8−7=1

    The numbers are 111, 444, 777.

  12. 12

    Which of these is NOT a possible solution set for three linear equations in three unknowns?

    Answer choices for question 12

    Solution

    Correct answer: D

    The classification allows a point, a line, a plane, or the empty set, nothing else.

    possible:point, line, plane, empty\text{possible} : \text{point},\ \text{line},\ \text{plane},\ \text{empty}possible:point, line, plane, empty

    A single free variable already gives infinitely many points, so exactly two points can never occur.
