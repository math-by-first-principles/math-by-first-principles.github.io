Radicals and Rational Exponents: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Index and radicand
In an\sqrt[n]{a}na​ the integer n≥2n \ge 2n≥2 is the index and aaa the radicand; a square root is n=2n = 2n=2, with the index left unwritten.
Principal root
What an\sqrt[n]{a}na​ names: for a≥0a \ge 0a≥0, the nonnegative real whose nnn-th power is aaa; for a<0a < 0a<0, the one (negative) real root when nnn is odd, and nothing real when nnn is even.
Like radicals
Two radical terms with the same index and the same radicand, judged only in simplest form. 2\sqrt22​ and 3\sqrt33​ are unlike; so are 2\sqrt22​ and 23\sqrt[3]{2}32​.
Simplest radical form
No perfect nnn-th power factor left under the radical, no radical in a denominator, and no common factor between the index and the exponents inside.
Radical conjugate α∗\alpha^{*}α∗
The partner of α=a+bd\alpha = a + b\sqrt dα=a+bd​ with the sign of the surd term alone flipped: α∗=a−bd\alpha^{*} = a - b\sqrt dα∗=a−bd​.
Canonical form p+qdp + q\sqrt dp+qd​
The unique way to write such a number with p,qp, qp,q rational; two expressions are the same number exactly when both parts match.
Radical equation
An equation with the unknown under a radical or carrying a fractional exponent, so it cannot be freed by adding or dividing.
Extraneous root
A candidate satisfying the equation you produced but not the equation you started with.

Formulas and theorems

  • Index parity: when a root is real

    n odd: an is real for every real an even: an is real only for a≥0\begin{gathered} n \text{ odd:}\ \sqrt[n]{a}\ \text{is real for every real } a \\ n \text{ even:}\ \sqrt[n]{a}\ \text{is real only for } a \ge 0 \end{gathered}n odd: na​ is real for every real an even: na​ is real only for a≥0​

    Use when Integer n≥2n \ge 2n≥2, over the reals. An even-index radical is never negative; an odd-index one carries its radicand's sign. "No real value" is not "meaningless": complex nnn-th roots exist, but this chapter fixes no convention for choosing one, apart from the single case −1=i\sqrt{-1} = i−1​=i.

  • Root of a matching power

    n even: ann=∣a∣n odd: ann=a\begin{gathered} n \text{ even:}\ \sqrt[n]{a^{n}} = \lvert a \rvert \\ n \text{ odd:}\ \sqrt[n]{a^{n}} = a \end{gathered}n even: nan​=∣a∣n odd: nan​=a​

    Use when Every real aaa; x2=x\sqrt{x^2} = xx2​=x exactly when x≥0x \ge 0x≥0. Bars go on exactly when the exponent leaving an even root is odd.

    e.g. x6=∣x∣3\sqrt{x^6} = \lvert x \rvert^3x6​=∣x∣3, while x4=x2\sqrt{x^4} = x^2x4​=x2 and x33=x\sqrt[3]{x^3} = x3x3​=x need none.

  • Product rule

    abn=an bn\sqrt[n]{ab} = \sqrt[n]{a}\,\sqrt[n]{b}nab​=na​nb​

    Use when a≥0a \ge 0a≥0 and b≥0b \ge 0b≥0 for even nnn; all real a,ba, ba,b for odd nnn. With BOTH radicands negative under a SQUARE root it fails by a factor of −1-1−1: convert to iii form first, then multiply.

  • Quotient rule

    abn=anbn\sqrt[n]{\frac{a}{b}} = \frac{\sqrt[n]{a}}{\sqrt[n]{b}}nba​​=nb​na​​

    Use when a≥0a \ge 0a≥0 and b>0b > 0b>0 for even nnn; any real aaa and nonzero real bbb for odd nnn. Read right to left to collapse an awkward quotient.

    e.g. 982=49=7\dfrac{\sqrt{98}}{\sqrt2} = \sqrt{49} = 72​98​​=49​=7.

  • Rational exponents

    a1/n=anam/n=(an)m=amn\begin{gathered} a^{1/n} = \sqrt[n]{a} \\ a^{m/n} = \left(\sqrt[n]{a}\right)^{m} = \sqrt[n]{a^{m}} \end{gathered}a1/n=na​am/n=(na​)m=nam​​

    Use when a>0a > 0a>0, mmm an integer, nnn a positive integer. Both routes then agree, whatever fraction is written for the exponent; take the root first for smaller arithmetic. For a<0a < 0a<0 with m/nm/nm/n in lowest terms, only the root-then-power route is licensed, and it is real exactly when nnn is odd: (−8)1/3=−2(-8)^{1/3} = -2(−8)1/3=−2, but (−16)5/2(-16)^{5/2}(−16)5/2 has no real value.

    e.g. 32−2/5=1(325)2=1432^{-2/5} = \dfrac{1}{\left(\sqrt[5]{32}\right)^{2}} = \dfrac1432−2/5=(532​)21​=41​.

  • Exponent laws at rational exponents

    aras=ar+s,aras=ar−s(ar)s=ars,(ab)r=arbra−r=1ar\begin{gathered} a^{r}a^{s} = a^{r+s}, \quad \frac{a^{r}}{a^{s}} = a^{r-s} \\ \left(a^{r}\right)^{s} = a^{rs}, \quad (ab)^{r} = a^{r}b^{r} \\ a^{-r} = \frac{1}{a^{r}} \end{gathered}aras=ar+s,asar​=ar−s(ar)s=ars,(ab)r=arbra−r=ar1​​

    Use when Bases a,b>0a, b > 0a,b>0, exponents r,sr, sr,s rational. A negative exponent takes a reciprocal, never a sign. None is guaranteed for a negative base.

  • Collecting like radicals

    ckn+dkn=(c+d)knc\sqrt[n]{k} + d\sqrt[n]{k} = (c + d)\sqrt[n]{k}cnk​+dnk​=(c+d)nk​

    Use when Same index and same radicand, both terms already in simplest form. The radicand is the unit and never changes as you count more of it.

  • Conjugate product

    (a+bd)(a−bd)=a2−b2d(m+n)(m−n)=m−n\begin{gathered} (a + b\sqrt d)(a - b\sqrt d) = a^2 - b^2 d \\ (\sqrt m + \sqrt n)(\sqrt m - \sqrt n) = m - n \end{gathered}(a+bd​)(a−bd​)=a2−b2d(m​+n​)(m​−n​)=m−n​

    Use when a,ba, ba,b rational and ddd a positive non-square for the first; m,n≥0m, n \ge 0m,n≥0 with m≠nm \neq nm=n for the second. Dividing by it needs a2≠b2da^2 \neq b^2 da2=b2d, automatic once d\sqrt dd​ is irrational and a,ba, ba,b are not both zero.

    e.g. (3+22)(3−22)=9−4(2)=1(3 + 2\sqrt2)(3 - 2\sqrt2) = 9 - 4(2) = 1(3+22​)(3−22​)=9−4(2)=1.

  • Clearing a single radical

    1an=a n−1na\frac{1}{\sqrt[n]{a}} = \frac{\sqrt[n]{a^{\,n-1}}}{a}na​1​=anan−1​​

    Use when a>0a > 0a>0. Multiply by whatever power fills the root up to a whole one, less than an−1a^{n-1}an−1 when the radicand is itself a power.

    e.g. 93=32/3\sqrt[3]{9} = 3^{2/3}39​=32/3 needs only 33\sqrt[3]{3}33​, so 693=233\dfrac{6}{\sqrt[3]{9}} = 2\sqrt[3]{3}39​6​=233​.

  • Cube-root multipliers

    (x+y)(x2−xy+y2)=x3+y3(x−y)(x2+xy+y2)=x3−y3\begin{gathered} (x + y)(x^2 - xy + y^2) = x^3 + y^3 \\ (x - y)(x^2 + xy + y^2) = x^3 - y^3 \end{gathered}(x+y)(x2−xy+y2)=x3+y3(x−y)(x2+xy+y2)=x3−y3​

    Use when Any reals, used with xxx or yyy a cube root. For a+bd3a + b\sqrt[3]{d}a+b3d​ the product is a3+b3da^3 + b^3 da3+b3d, nonzero whenever d3\sqrt[3]{d}3d​ is irrational and the rationals a,ba, ba,b are not both zero.

    e.g. (53−1)(253+53+1)=5−1=4\left(\sqrt[3]{5} - 1\right)\left(\sqrt[3]{25} + \sqrt[3]{5} + 1\right) = 5 - 1 = 4(35​−1)(325​+35​+1)=5−1=4.

  • What raising both sides does

    A2=B2  ⟺  A=B or A=−Ba3=b3  ⟺  a=b\begin{gathered} A^2 = B^2 \iff A = B \ \text{or} \ A = -B \\ a^3 = b^3 \iff a = b \end{gathered}A2=B2⟺A=B or A=−Ba3=b3⟺a=b​
    Text description

    Squaring reflects the line x minus 5 in the x-axis, and the square-root curve meets that mirror line at x = 2, the extraneous root, while the true solution x = 9 sits on the original line.

    Use when All four letters real. An even power glues an equation to its sign-flipped twin, so solutions are gained but never lost, and the extraneous ones are the twin's. An odd power is reversible.

  • Rationalizing a numerator

    n+1−n=1n+1+n\sqrt{n+1} - \sqrt{n} = \frac{1}{\sqrt{n+1} + \sqrt{n}}n+1​−n​=n+1​+n​1​

    Use when n≥0n \ge 0n≥0. Trades a difference of near-equal roots for a division that crude bounds pin tightly.

    e.g. 101−10=1101+10\sqrt{101} - 10 = \dfrac{1}{\sqrt{101} + 10}101​−10=101​+101​, and 20<101+10<20.120 < \sqrt{101} + 10 < 20.120<101​+10<20.1 pins it between 120.1\tfrac{1}{20.1}20.11​ and 120\tfrac{1}{20}201​.

Problem types, step by step

Write a radical in simplest form

  1. Check the index's parity: an even index needs a nonnegative radicand.
  2. Factor the radicand into perfect nnn-th powers times a remainder, by prime factorization when the largest is not obvious.
  3. Take one factor out per group of nnn equal ones; for a variable, divide its inside exponent by nnn.
  4. Attach absolute-value bars to any factor leaving an EVEN root with an odd exponent, unless the domain already forces that variable nonnegative.
  5. If the index and the inside exponents share a factor, convert to a rational exponent, reduce, then convert back.

e.g. 72=62\sqrt{72} = 6\sqrt272​=62​, −54a43=−3a2a3\sqrt[3]{-54a^4} = -3a\sqrt[3]{2a}3−54a4​=−3a32a​, and 86=23/6=2\sqrt[6]{8} = 2^{3/6} = \sqrt268​=23/6=2​.

Add or subtract radical terms

  1. Put every term in simplest form first; unlike-looking radicands often share a unit.
  2. Group terms with the same index AND the same radicand.
  3. Add coefficients within each group, leaving the radical untouched.
  4. Leave unlike groups side by side; they do not combine.

e.g. 50+18−8=52+32−22=62\sqrt{50} + \sqrt{18} - \sqrt8 = 5\sqrt2 + 3\sqrt2 - 2\sqrt2 = 6\sqrt250​+18​−8​=52​+32​−22​=62​.

Multiply or expand radical expressions

  1. At a shared index, multiply coefficients with coefficients and radicands with radicands.
  2. For a binomial times a binomial, expand every term against every term, then collect like radicals.
  3. Use (a)2=a\left(\sqrt a\right)^2 = a(a​)2=a wherever a radical meets its twin.
  4. Simplify last: a product of two unsimplifiable radicals can hide a perfect power.

e.g. (26)(310)=660=1215(2\sqrt6)(3\sqrt{10}) = 6\sqrt{60} = 12\sqrt{15}(26​)(310​)=660​=1215​.

Evaluate a rational power

  1. Deal with a negative exponent first: take a reciprocal, or flip a fractional base.
  2. Read the exponent's denominator as the index and its numerator as the power.
  3. Take the root first, then raise to the power.
  4. Sanity-check the size: an exponent between 000 and 111 shrinks a base larger than 111.

e.g. (278)−2/3=(827)2/3=(23)2=49\left(\tfrac{27}{8}\right)^{-2/3} = \left(\tfrac{8}{27}\right)^{2/3} = \left(\tfrac23\right)^2 = \tfrac49(827​)−2/3=(278​)2/3=(32​)2=94​.

Combine radicals of different indices

  1. Rewrite each factor as a rational power of its base.
  2. Add the exponents over their common denominator, the common index the radicals lacked.
  3. Convert back to one radical, pulling out any whole power the exponent exceeds.

e.g. 93⋅3=32/3+1/2=37/6=336\sqrt[3]{9}\cdot\sqrt3 = 3^{2/3 + 1/2} = 3^{7/6} = 3\sqrt[6]{3}39​⋅3​=32/3+1/2=37/6=363​.

Rationalize a denominator

  1. One radical term: multiply by the power that completes the root, a23\sqrt[3]{a^2}3a2​ for a3\sqrt[3]{a}3a​.
  2. A square-root binomial: multiply by the same two terms with the middle sign flipped, landing a2−b2da^2 - b^2 da2−b2d downstairs.
  3. A cube-root binomial: a sign flip leaves a radical, so use the three-term multiplier x2∓xy+y2x^2 \mp xy + y^2x2∓xy+y2 instead.
  4. Multiply the NUMERATOR by that same factor, expand, and reduce to lowest terms.

e.g. 45−7=4(5+7)18=10+279\dfrac{4}{5 - \sqrt7} = \dfrac{4(5 + \sqrt7)}{18} = \dfrac{10 + 2\sqrt7}{9}5−7​4​=184(5+7​)​=910+27​​.

Solve a radical equation

  1. Isolate one radical on its own side.
  2. Raise both sides to the power matching that radical's index.
  3. If a radical survives, which with two radicals it usually does, isolate it and raise again.
  4. Solve the radical-free equation for the candidate list, complete but possibly long.
  5. Substitute EVERY candidate into the ORIGINAL equation, keeping only those making both sides agree in sign as well as size.

e.g. x+7=x−5\sqrt{x+7} = x-5x+7​=x−5 gives x2−11x+18=0x^2 - 11x + 18 = 0x2−11x+18=0, and of x=9x = 9x=9 (4=44 = 44=4) and x=2x = 2x=2 (3≠−33 \neq -33=−3) only x=9x = 9x=9 survives.

Solve by substituting for the inner root of a rational power

  1. Name the inner root u=(x−c)1/nu = (x - c)^{1/n}u=(x−c)1/n; because uuu is a principal root, u≥0u \ge 0u≥0 for an even nnn.
  2. Rewrite the equation in uuu alone, so (x−c)m/n=k(x-c)^{m/n} = k(x−c)m/n=k becomes um=ku^m = kum=k.
  3. Solve for uuu. For an even nnn, discard any negative solution; with u≥0u \ge 0u≥0 and k<0k < 0k<0 there is no solution. For an odd nnn, a negative uuu is a valid principal root and stays in play.
  4. Undo the substitution, solve for xxx, and check each value in the original.

e.g. (x−4)3/2=27(x-4)^{3/2} = 27(x−4)3/2=27: u=(x−4)1/2u = (x-4)^{1/2}u=(x−4)1/2 gives u3=27u^3 = 27u3=27, so u=3u = 3u=3, and x−4=9x - 4 = 9x−4=9 gives x=13x = 13x=13.

Exam traps

  • Trap Writing x2=x\sqrt{x^2} = xx2​=x, which at x=−3x = -3x=−3 reports −3-3−3 while (−3)2=9=3\sqrt{(-3)^2} = \sqrt9 = 3(−3)2​=9​=3.

    Fix x2=∣x∣\sqrt{x^2} = \lvert x \rvertx2​=∣x∣ for every real xxx, and the two agree exactly when x≥0x \ge 0x≥0.

  • Trap Barring every extracted root, turning x33\sqrt[3]{x^3}3x3​ into ∣x∣\lvert x \rvert∣x∣ and x4\sqrt{x^4}x4​ into ∣x2∣\lvert x^2 \rvert∣x2∣.

    Fix Bars belong only where an odd exponent leaves an even root with the variable unrestricted. x33=x\sqrt[3]{x^3} = x3x3​=x; at x=−1x = -1x=−1 bars would flip its sign.

  • Trap Merging two negative radicands, giving −4⋅−9=36=6\sqrt{-4}\cdot\sqrt{-9} = \sqrt{36} = 6−4​⋅−9​=36​=6.

    Fix The value is −6-6−6. Convert each radical to iii form first: (2i)(3i)=6i2=−6(2i)(3i) = 6i^2 = -6(2i)(3i)=6i2=−6.

  • Trap Writing a+b=a+b\sqrt a + \sqrt b = \sqrt{a+b}a​+b​=a+b​, so 9+16\sqrt9 + \sqrt{16}9​+16​ comes out as 25=5\sqrt{25} = 525​=5.

    Fix It is 3+4=73 + 4 = 73+4=7, and the rule holds only when aaa or bbb is 000. Squaring the left leaves a cross term 2ab2\sqrt{ab}2ab​ the false rule discards.

  • Trap Filtering radical-equation candidates by a domain check, so x=2x = 2x=2 passes in x+7=x−5\sqrt{x+7} = x-5x+7​=x−5 because its radicand is 999.

    Fix That check belongs to rational equations. The original gives 3≠−33 \neq -33=−3, so x=2x = 2x=2 is extraneous despite lying inside the domain.

  • Trap Squaring 3x+1−2=3\sqrt{3x+1} - 2 = 33x+1​−2=3 as it stands, or stopping after one squaring when two radicals were present.

    Fix Isolate before raising, or the cross term −43x+1-4\sqrt{3x+1}−43x+1​ frees nothing; then isolate and raise again for each radical that survives.

  • Trap Flipping the sign at a cube root: (1+23)(1−23)=1−43(1 + \sqrt[3]{2})(1 - \sqrt[3]{2}) = 1 - \sqrt[3]{4}(1+32​)(1−32​)=1−34​.

    Fix That swaps one radical for another. A cube root has two irrational powers, so use 1−23+431 - \sqrt[3]{2} + \sqrt[3]{4}1−32​+34​, whose product is 333.

  • Trap Leaving the coefficient unsquared, making (3+22)(3−22)(3 + 2\sqrt2)(3 - 2\sqrt2)(3+22​)(3−22​) into 9−2=79 - 2 = 79−2=7.

    Fix The product is a2−b2d=9−4(2)=1a^2 - b^2 d = 9 - 4(2) = 1a2−b2d=9−4(2)=1. The coefficient is squared along with the radical.

  • Trap Running the exponent laws over a negative base, as in (−8)2/6=((−8)2)1/6=2(-8)^{2/6} = \left((-8)^2\right)^{1/6} = 2(−8)2/6=((−8)2)1/6=2.

    Fix Reducing the exponent first gives the real value (−8)1/3=−2(-8)^{1/3} = -2(−8)1/3=−2. Pulling the base through the outer power needs a>0a > 0a>0, and −8-8−8 does not qualify, which is why that route lands on the wrong number instead.

  • Trap Adding or multiplying indices for a product of different-index radicals, so 23⋅26\sqrt[3]{2}\cdot\sqrt[6]{2}32​⋅62​ becomes 29\sqrt[9]{2}92​.

    Fix The EXPONENTS add, not the indices: 21/3⋅21/6=21/2=22^{1/3}\cdot2^{1/6} = 2^{1/2} = \sqrt221/3⋅21/6=21/2=2​.

  • Trap Stopping the moment a denominator turns rational, leaving 4(5+7)18\dfrac{4(5+\sqrt7)}{18}184(5+7​)​.

    Fix Numerator and denominator still share a factor of 222, so the finished answer is 10+279\dfrac{10 + 2\sqrt7}{9}910+27​​.

  • Trap Rejecting a negative candidate on sight, or refusing a negative right-hand side at an odd index.

    Fix A negative xxx is fine while every radicand stays nonnegative, and x=−1x = -1x=−1 solves 2x+3−x+1=1\sqrt{2x+3} - \sqrt{x+1} = 12x+3​−x+1​=1. Only an even root set equal to a negative is impossible.
