    How many real solutions does x+5=x−1\sqrt{x + 5} = x - 1x+5​=x−1 have?

    Answer choices for question 4

    Solution

    Correct answer: C

    Square both sides and solve the quadratic that appears.

    x+5=x2−2x+1  ⟹  x2−3x−4=0  ⟹  (x−4)(x+1)=0x + 5 = x^2 - 2x + 1 \;\Longrightarrow\; x^2 - 3x - 4 = 0 \;\Longrightarrow\; (x - 4)(x + 1) = 0x+5=x2−2x+1⟹x2−3x−4=0⟹(x−4)(x+1)=0

    The candidates are x=4x = 4x=4 and x=−1x = -1x=−1, but the count of candidates is not the count of solutions.

    Check x=4x = 4x=4: the left side is 9=3\sqrt{9} = 39​=3 and the right side is 333, so it survives. Check x=−1x = -1x=−1: the left side is 4=2\sqrt{4} = 24​=2 and the right side is −2-2−2, so it is extraneous. Exactly one candidate survives, so the equation has exactly one solution.

    Solve x2+3x3=4x+63\sqrt[3]{x^2 + 3x} = \sqrt[3]{4x + 6}3x2+3x​=34x+6​.

    Answer choices for question 5

    Solution

    Correct answer: A

    Cubing both sides is reversible, so the cubed equation says exactly what the original says.

    x2+3x=4x+6  ⟹  x2−x−6=0  ⟹  (x−3)(x+2)=0x^2 + 3x = 4x + 6 \;\Longrightarrow\; x^2 - x - 6 = 0 \;\Longrightarrow\; (x - 3)(x + 2) = 0x2+3x=4x+6⟹x2−x−6=0⟹(x−3)(x+2)=0

    Check x=3x = 3x=3: both radicands equal 181818, so both sides are 183\sqrt[3]{18}318​.

    Check x=−2x = -2x=−2: both radicands equal −2-2−2, so both sides are −23\sqrt[3]{-2}3−2​, which is a perfectly good real number because a cube root accepts negative inputs. Both candidates are genuine solutions, and no check could have rejected either, since cubing manufactures no extraneous roots.
