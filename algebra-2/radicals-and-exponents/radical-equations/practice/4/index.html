  1. 1

    Solve 4x+5=x\sqrt{4x + 5} = x4x+5​=x.

    Answer choices for question 1

    Solution

    Correct answer: B

    Square both sides and factor the quadratic.

    4x+5=x2  ⟹  x2−4x−5=0  ⟹  (x−5)(x+1)=04x + 5 = x^2 \;\Longrightarrow\; x^2 - 4x - 5 = 0 \;\Longrightarrow\; (x - 5)(x + 1) = 04x+5=x2⟹x2−4x−5=0⟹(x−5)(x+1)=0

    Check x=5x = 5x=5: the left side is 25=5\sqrt{25} = 525​=5 and the right side is 555, so it survives.

    Check x=−1x = -1x=−1: the left side is 1=1\sqrt{1} = 11​=1 and the right side is −1-1−1, so it is extraneous. A principal square root cannot be negative, so any candidate that makes the right side negative is doomed. Only x=5x = 5x=5 solves the equation.

    Solve x−4+x+4=4\sqrt{x - 4} + \sqrt{x + 4} = 4x−4​+x+4​=4.

    Answer choices for question 2

    Solution

    Correct answer: C

    Isolate one radical and square both sides.

    x+4=4−x−4  ⟹  x+4=16−8x−4+(x−4)\sqrt{x + 4} = 4 - \sqrt{x - 4} \;\Longrightarrow\; x + 4 = 16 - 8\sqrt{x - 4} + (x - 4)x+4​=4−x−4​⟹x+4=16−8x−4​+(x−4)

    The xxx cancels, leaving 8x−4=88\sqrt{x - 4} = 88x−4​=8, so x−4=1\sqrt{x - 4} = 1x−4​=1 and x−4=1x - 4 = 1x−4=1, giving x=5x = 5x=5.

    Check in the original: 1+9=1+3=4\sqrt{1} + \sqrt{9} = 1 + 3 = 41​+9​=1+3=4, which is correct. So x=5x = 5x=5.

  3. 3

    Solve x−x−5=1\sqrt{x} - \sqrt{x - 5} = 1x​−x−5​=1.

    Answer choices for question 3

    Solution

    Correct answer: A

    Isolate one radical and square.

    x=1+x−5  ⟹  x=1+2x−5+(x−5)\sqrt{x} = 1 + \sqrt{x - 5} \;\Longrightarrow\; x = 1 + 2\sqrt{x - 5} + (x - 5)x​=1+x−5​⟹x=1+2x−5​+(x−5)

    The xxx cancels, leaving 4=2x−54 = 2\sqrt{x - 5}4=2x−5​, so x−5=2\sqrt{x - 5} = 2x−5​=2 and x−5=4x - 5 = 4x−5=4, giving x=9x = 9x=9.

    Check in the original: 9−4=3−2=1\sqrt{9} - \sqrt{4} = 3 - 2 = 19​−4​=3−2=1, which is correct. So x=9x = 9x=9.

  4. 4

    Solve (3x−2)1/2=x−2(3x - 2)^{1/2} = x - 2(3x−2)1/2=x−2.

    Answer choices for question 4

    Solution

    Correct answer: A

    The exponent 12\tfrac{1}{2}21​ is a square root, so raise both sides to the power 222.

    3x−2=x2−4x+4  ⟹  x2−7x+6=0  ⟹  (x−1)(x−6)=03x - 2 = x^2 - 4x + 4 \;\Longrightarrow\; x^2 - 7x + 6 = 0 \;\Longrightarrow\; (x - 1)(x - 6) = 03x−2=x2−4x+4⟹x2−7x+6=0⟹(x−1)(x−6)=0

    Check x=6x = 6x=6: the left side is (16)1/2=4(16)^{1/2} = 4(16)1/2=4 and the right side is 444, so it survives.

    Check x=1x = 1x=1: the left side is (1)1/2=1(1)^{1/2} = 1(1)1/2=1 and the right side is −1-1−1, so it is extraneous. Only x=6x = 6x=6 solves the equation.

  5. 5

    Solve (x+7)3/2=27(x + 7)^{3/2} = 27(x+7)3/2=27.

    Answer choices for question 5

    Solution

    Correct answer: B

    Split the exponent instead of guessing. Write (x+7)3/2=[(x+7)1/2]3(x + 7)^{3/2} = \left[(x + 7)^{1/2}\right]^3(x+7)3/2=[(x+7)1/2]3 and let u=(x+7)1/2u = (x + 7)^{1/2}u=(x+7)1/2, so that u≥0u \ge 0u≥0.

    u3=27  ⟹  u=3u^3 = 27 \;\Longrightarrow\; u = 3u3=27⟹u=3

    Cubing is reversible, so u=3u = 3u=3 is the only possibility. Then (x+7)1/2=3(x + 7)^{1/2} = 3(x+7)1/2=3 gives x+7=9x + 7 = 9x+7=9, so x=2x = 2x=2.

    Check in the original: (2+7)3/2=93/2=(9)3=27(2 + 7)^{3/2} = 9^{3/2} = \left(\sqrt{9}\right)^3 = 27(2+7)3/2=93/2=(9​)3=27, which is correct.

  6. 6

    Solve (x−3)3/2=−8(x - 3)^{3/2} = -8(x−3)3/2=−8.

    Answer choices for question 6

    Solution

    Correct answer: D

    Read the left side before computing anything. Write it as [(x−3)1/2]3\left[(x - 3)^{1/2}\right]^3[(x−3)1/2]3 and set u=(x−3)1/2u = (x - 3)^{1/2}u=(x−3)1/2, a principal square root, so u≥0u \ge 0u≥0 wherever it is defined.

    u≥0  ⟹  u3≥0u \ge 0 \;\Longrightarrow\; u^3 \ge 0u≥0⟹u3≥0

    A non-negative number cubed is non-negative, so the left side can never equal −8-8−8. The equation has no solution.

    The tempting candidate x=7x = 7x=7 fails, since (7−3)3/2=43/2=8(7 - 3)^{3/2} = 4^{3/2} = 8(7−3)3/2=43/2=8, which is +8+8+8 and not −8-8−8; and values like x=−1x = -1x=−1 do not even give a real left side.

    Solve x2−5=x−5\sqrt{x^2 - 5} = x - 5x2−5​=x−5.

    Answer choices for question 7

    Solution

    Correct answer: D

    Square both sides. Once again the x2x^2x2 terms cancel.

    x2−5=x2−10x+25  ⟹  10x=30  ⟹  x=3x^2 - 5 = x^2 - 10x + 25 \;\Longrightarrow\; 10x = 30 \;\Longrightarrow\; x = 3x2−5=x2−10x+25⟹10x=30⟹x=3

    Check the only candidate in the original. The left side is 9−5=4=2\sqrt{9 - 5} = \sqrt{4} = 29−5​=4​=2 and the right side is 3−5=−23 - 5 = -23−5=−2.

    2≠−22 \ne -22=−2

    The candidate is extraneous, so the equation has no solution. Its radicand is 444, which is positive, so x=3x = 3x=3 is squarely inside the domain: this is a failure of sign, and a domain check would have missed it entirely.

  8. 8

    Solve x+74=−2\sqrt[4]{x + 7} = -24x+7​=−2.

    Answer choices for question 8

    Solution

    Correct answer: C

    The index 444 is even, so this is a principal root and it is never negative, exactly like a square root. A cube root would have been fine here, but a fourth root is not.

    Raise both sides to the fourth power to see what the algebra offers:

    x+7=(−2)4=16  ⟹  x=9x + 7 = (-2)^4 = 16 \;\Longrightarrow\; x = 9x+7=(−2)4=16⟹x=9

    Check x=9x = 9x=9 in the original: 164=2\sqrt[4]{16} = 2416​=2, not −2-2−2. The candidate is extraneous, and the equation has no solution.

    Squaring both sides of 6−x=x\sqrt{6 - x} = x6−x​=x produces the candidates x=2x = 2x=2 and x=−3x = -3x=−3. Which of them is extraneous?

    Answer choices for question 9

    Solution

    Correct answer: B

    Substitute each candidate into the original equation.

    At x=2x = 2x=2 the left side is 4=2\sqrt{4} = 24​=2 and the right side is 222, so this candidate is genuine.

    At x=−3x = -3x=−3 the left side is 9=3\sqrt{9} = 39​=3 and the right side is −3-3−3:

    3≠−33 \ne -33=−3

    So x=−3x = -3x=−3 is extraneous. It is inside the domain, since its radicand 999 is positive; it is really a solution of the twin equation 6−x=−x\sqrt{6 - x} = -x6−x​=−x, which squaring folded into the problem.

  10. 10

    While solving a radical equation you obtain a candidate that lies inside the domain of every radical in the equation. What may you conclude?

    Answer choices for question 10

    Solution

    Correct answer: D

    Being in the domain only means both sides are defined; it says nothing about whether they are equal.

    x+7=x−5   at x=2:9=3,2−5=−3\sqrt{x + 7} = x - 5 \;\text{ at } x = 2: \quad \sqrt{9} = 3, \quad 2 - 5 = -3x+7​=x−5 at x=2:9​=3,2−5=−3

    The radicand is 999, so x=2x = 2x=2 is inside the domain, yet the two sides come out 333 and −3-3−3. Squaring cannot tell those apart, which is how the candidate arose in the first place. Isolating the radical first is good technique but changes nothing about this, so the only safe conclusion is that the candidate must be substituted into the original equation.
