    Rationalize the denominator of 11+23\dfrac{1}{1 + \sqrt[3]{2}}1+32​1​.

    Answer choices for question 1

    Solution

    Correct answer: B

    A sign flip fails here: (1+23)(1−23)=1−43(1 + \sqrt[3]{2})(1 - \sqrt[3]{2}) = 1 - \sqrt[3]{4}(1+32​)(1−32​)=1−34​, still irrational. Use the sum-of-cubes multiplier x2−xy+y2x^2 - xy + y^2x2−xy+y2 with x=1x = 1x=1 and y=23y = \sqrt[3]{2}y=32​, which is 1−23+431 - \sqrt[3]{2} + \sqrt[3]{4}1−32​+34​.

    (1+23)(1−23+43)=13+(23)3=1+2=3\left(1 + \sqrt[3]{2}\right)\left(1 - \sqrt[3]{2} + \sqrt[3]{4}\right) = 1^3 + \left(\sqrt[3]{2}\right)^3 = 1 + 2 = 3(1+32​)(1−32​+34​)=13+(32​)3=1+2=3

    So the answer is 1−23+433\frac{1 - \sqrt[3]{2} + \sqrt[3]{4}}{3}31−32​+34​​. The minus sign in the middle of the multiplier is what makes every intermediate term cancel; using all plus signs would leave radicals behind.
