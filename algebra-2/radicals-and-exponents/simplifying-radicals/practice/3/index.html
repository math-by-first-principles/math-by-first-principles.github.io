    Write 72x3y2\sqrt{72x^3y^2}72x3y2​ in simplest radical form, assuming the expression names a real number.

    Answer choices for question 1

    Solution

    Correct answer: D

    Settle the domain first. The factor y2y^2y2 is never negative, so the sign of the radicand is decided by x3x^3x3: provided y≠0y \ne 0y=0, the expression is real exactly when x≥0x \ge 0x≥0. (If y=0y = 0y=0 the radicand is 000 whatever xxx is, a degenerate case with nothing to simplify, so assume y≠0y \ne 0y=0.) Note that yyy itself is not restricted in sign: it may be negative.

    Now extract the perfect squares, using 72=36⋅272 = 36 \cdot 272=36⋅2 and x3=x2⋅xx^3 = x^2 \cdot xx3=x2⋅x.

    72x3y2=36 x2 y2 2x=6 ∣x∣ ∣y∣ 2x\sqrt{72x^3y^2} = \sqrt{36}\,\sqrt{x^2}\,\sqrt{y^2}\,\sqrt{2x} = 6\,|x|\,|y|\,\sqrt{2x}72x3y2​=36​x2​y2​2x​=6∣x∣∣y∣2x​

    The domain gives x≥0x \ge 0x≥0, so ∣x∣=x|x| = x∣x∣=x and those bars come off. Nothing pins down the sign of yyy, so its bars must stay.

    72x3y2=6x∣y∣2x\sqrt{72x^3y^2} = 6x|y|\sqrt{2x}72x3y2​=6x∣y∣2x​

    Test x=2x = 2x=2, y=−1y = -1y=−1: the original is 576=24\sqrt{576} = 24576​=24, and 6(2)∣−1∣4=246(2)|-1|\sqrt{4} = 246(2)∣−1∣4​=24 agrees, while the bar-free 6xy2x6xy\sqrt{2x}6xy2x​ would give −24-24−24, a value no square root can take.

  2. 2

    Which statement about the identity ab=a b\sqrt{ab} = \sqrt{a}\,\sqrt{b}ab​=a​b​ (for real aaa and bbb) is true?

    Answer choices for question 2

    Solution

    Correct answer: C

    Test the cases. If aaa and bbb are both non-negative, the rule is a theorem and always holds. If exactly one is negative, say a=−ma = -ma=−m with m>0m > 0m>0 and b≥0b \ge 0b≥0, then ab=imb=imb\sqrt{a}\sqrt{b} = i\sqrt{m}\sqrt{b} = i\sqrt{mb}a​b​=im​b​=imb​, and ab=−mb=imb\sqrt{ab} = \sqrt{-mb} = i\sqrt{mb}ab​=−mb​=imb​, so the two sides agree.

    If both are negative, a=−ma = -ma=−m and b=−nb = -nb=−n with m,n>0m, n > 0m,n>0, the two sides differ by a sign:

    a b=(im)(in)=−mn,ab=mn\sqrt{a}\,\sqrt{b} = (i\sqrt m)(i\sqrt n) = -\sqrt{mn}, \qquad \sqrt{ab} = \sqrt{mn}a​b​=(im​)(in​)=−mn​,ab​=mn​

    So the failure happens exactly in the both-negative case. "Whenever aaa is negative" is too strong (a=−4a = -4a=−4, b=9b = 9b=9 works fine), and "ab<0ab < 0ab<0" is wrong in both directions: that same a=−4,b=9a = -4, b = 9a=−4,b=9 has ab<0ab < 0ab<0 yet the rule holds, while a=b=−1a = b = -1a=b=−1 has ab>0ab > 0ab>0 and the rule fails.

  3. 3

    Simplify 54x36x\dfrac{\sqrt{54x^3}}{\sqrt{6x}}6x​54x3​​, where x>0x > 0x>0.

    Answer choices for question 3

    Solution

    Correct answer: B

    Both radicands are positive because x>0x > 0x>0, so the quotient rule applies and the two radicals can be combined into one.

    54x36x=54x36x=9x2\frac{\sqrt{54x^3}}{\sqrt{6x}} = \sqrt{\frac{54x^3}{6x}} = \sqrt{9x^2}6x​54x3​​=6x54x3​​=9x2​

    Now take the root:

    9x2=3∣x∣=3x\sqrt{9x^2} = 3|x| = 3x9x2​=3∣x∣=3x

    The bars come off because the problem gives x>0x > 0x>0. Dividing inside the radical first is what makes this quick: the messy radicands cancel into a perfect square.

  4. 4

    Write x⋅x3\sqrt{x} \cdot \sqrt[3]{x}x​⋅3x​ as a single radical, where x≥0x \ge 0x≥0.

    Answer choices for question 4

    Solution

    Correct answer: A

    Different indices cannot be combined directly, so convert both radicals to rational exponents, where the exponent rules do the work.

    x⋅x3=x1/2⋅x1/3=x1/2+1/3\sqrt{x}\cdot\sqrt[3]{x} = x^{1/2} \cdot x^{1/3} = x^{1/2 + 1/3}x​⋅3x​=x1/2⋅x1/3=x1/2+1/3

    Add the fractions over the common denominator 666:

    12+13=36+26=56⟹x5/6=x56\frac{1}{2} + \frac{1}{3} = \frac{3}{6} + \frac{2}{6} = \frac{5}{6} \quad\Longrightarrow\quad x^{5/6} = \sqrt[6]{x^5}21​+31​=63​+62​=65​⟹x5/6=6x5​

    The index is the denominator (666) and the power is the numerator (555). Since 555 and 666 share no common factor, this is already in simplest form.

  5. 5

    Evaluate −5⋅−5\sqrt{-5} \cdot \sqrt{-5}−5​⋅−5​.

    Answer choices for question 5

    Solution

    Correct answer: D

    Two negative radicands, so convert to iii form before multiplying. Never combine them under one radical.

    −5⋅−5=(i5)(i5)=i2(5)2=(−1)(5)=−5\sqrt{-5}\cdot\sqrt{-5} = \left(i\sqrt5\right)\left(i\sqrt5\right) = i^2\left(\sqrt5\right)^2 = (-1)(5) = -5−5​⋅−5​=(i5​)(i5​)=i2(5​)2=(−1)(5)=−5

    The trap answer is 555, from writing (−5)(−5)=25=5\sqrt{(-5)(-5)} = \sqrt{25} = 5(−5)(−5)​=25​=5. The product rule needs non-negative radicands; here it lands on the wrong square root of 252525, missing by a factor of −1-1−1.

  6. 6

    Simplify (x−4)2\sqrt{(x - 4)^2}(x−4)2​, given that x<4x < 4x<4.

    Answer choices for question 6

    Solution

    Correct answer: B

    The identity is u2=∣u∣\sqrt{u^2} = |u|u2​=∣u∣, so with u=x−4u = x - 4u=x−4,

    (x−4)2=∣x−4∣.\sqrt{(x-4)^2} = |x - 4|.(x−4)2​=∣x−4∣.

    Now resolve the absolute value using the hypothesis. Since x<4x < 4x<4, the quantity x−4x - 4x−4 is negative, and the absolute value of a negative number is its opposite.

    ∣x−4∣=−(x−4)=4−x|x - 4| = -(x - 4) = 4 - x∣x−4∣=−(x−4)=4−x

    Sanity check at x=1x = 1x=1: the original is (−3)2=3\sqrt{(-3)^2} = 3(−3)2​=3, and 4−x=34 - x = 34−x=3 agrees, while x−4=−3x - 4 = -3x−4=−3 has the wrong sign.

  7. 7

    Simplify 25(x+1)2\sqrt{25(x + 1)^2}25(x+1)2​, where xxx may be any real number.

    Answer choices for question 7

    Solution

    Correct answer: C

    The radicand is a product of two non-negative factors, so split it and take each root.

    25(x+1)2=25 (x+1)2=5 ∣x+1∣\sqrt{25(x+1)^2} = \sqrt{25}\,\sqrt{(x+1)^2} = 5\,|x + 1|25(x+1)2​=25​(x+1)2​=5∣x+1∣

    The bars must survive: xxx is unrestricted, so x+1x + 1x+1 can be negative (take x=−3x = -3x=−3), while the square root cannot. Test x=−3x = -3x=−3: the original is 25⋅4=10\sqrt{25 \cdot 4} = 1025⋅4​=10, and 5∣−2∣=105|-2| = 105∣−2∣=10 agrees, while 5(x+1)=−105(x+1) = -105(x+1)=−10 does not. Note also that the bars go around the whole binomial, not just the xxx.

    Solution

    (−x)+x=0(-x) + x = 0(−x)+x=0

    Simplify −32x105\sqrt[5]{-32x^{10}}5−32x10​, where xxx may be any real number.

    Answer choices for question 9

    Solution

    Correct answer: A

    The index is 555, which is odd, so a negative radicand is allowed and no bars are needed. Write the radicand as a perfect fifth power.

    −32x10=(−2)5(x2)5=(−2x2)5-32x^{10} = (-2)^5\left(x^2\right)^5 = \left(-2x^2\right)^5−32x10=(−2)5(x2)5=(−2x2)5

    The fifth root undoes the fifth power exactly:

    −32x105=−2x2\sqrt[5]{-32x^{10}} = -2x^25−32x10​=−2x2

    Check: (−2x2)5=−32x10(-2x^2)^5 = -32x^{10}(−2x2)5=−32x10. Note the answer is negative for every x≠0x \ne 0x=0, which is fine, because an odd root is allowed to be negative.

  10. 10

    For which of these values of xxx is the statement x2=x\sqrt{x^2} = xx2​=x false?

    Answer choices for question 10

    Solution

    Correct answer: A

    Since x2=∣x∣\sqrt{x^2} = |x|x2​=∣x∣, the statement x2=x\sqrt{x^2} = xx2​=x says ∣x∣=x|x| = x∣x∣=x, which holds exactly when x≥0x \ge 0x≥0. So it fails precisely for negative xxx.

    (−5)2=25=5≠−5\sqrt{(-5)^2} = \sqrt{25} = 5 \ne -5(−5)2​=25​=5=−5

    The other three values are non-negative, so the statement is true for each of them (for instance 02=0\sqrt{0^2} = 002​=0 and 252=25\sqrt{25^2} = 25252​=25).

    Evaluate 643\sqrt[3]{\sqrt{64}}364​​.

    Answer choices for question 11

    Solution

    Correct answer: B

    Work from the inside out. The inner radical is a plain square root.

    64=8\sqrt{64} = 864​=8

    Now take the cube root of that:

    83=2\sqrt[3]{8} = 238​=2

    Rational exponents give the same answer in one line, and they explain why nesting the roots multiplies the indices: (641/2)1/3=641/6=2\left(64^{1/2}\right)^{1/3} = 64^{1/6} = 2(641/2)1/3=641/6=2, since 26=642^6 = 6426=64.

    If a<0a < 0a<0, which expression equals a2\sqrt{a^2}a2​?

    Answer choices for question 12

    Solution

    Correct answer: C

    The identity gives a2=∣a∣\sqrt{a^2} = |a|a2​=∣a∣ for every real aaa. Now use the hypothesis to unpack the absolute value.

    a<0⟹∣a∣=−aa < 0 \quad\Longrightarrow\quad |a| = -aa<0⟹∣a∣=−a

    So a2=−a\sqrt{a^2} = -aa2​=−a. This looks negative but is not: aaa is negative, so −a-a−a is positive, exactly as a square root must be. Check at a=−6a = -6a=−6: 36=6\sqrt{36} = 636​=6, and −a=6-a = 6−a=6.
