  1. 1

    Evaluate 64\sqrt{64}64​.

    Answer choices for question 1

    Solution

    Correct answer: C

    The radical sign asks for the principal square root: the one non-negative number whose square is 646464.

    82=64and8≥08^2 = 64 \quad\text{and}\quad 8 \ge 082=64and8≥0

    So 64=8\sqrt{64} = 864​=8. It is true that (−8)2=64(-8)^2 = 64(−8)2=64 as well, but −8-8−8 is negative, so it is not what the symbol names. Halving 646464 gives 323232, which is a different operation entirely.

  2. 2

    Evaluate 121\sqrt{121}121​.

    Answer choices for question 2

    Solution

    Correct answer: A

    Look for the non-negative number that squares to 121121121.

    112=12111^2 = 121112=121

    So 121=11\sqrt{121} = 11121​=11. The symbol returns a single value, so ±11\pm 11±11 is not an answer to this question.

  3. 3

    How many real solutions does the equation x2=25x^2 = 25x2=25 have?

    Answer choices for question 3

    Solution

    Correct answer: B

    Squaring destroys sign, so a positive number is the square of two different reals.

    52=25and(−5)2=255^2 = 25 \quad\text{and}\quad (-5)^2 = 2552=25and(−5)2=25

    The equation has two solutions, x=5x = 5x=5 and x=−5x = -5x=−5. Keep this apart from the value of the symbol 25\sqrt{25}25​, which is 555 alone.

  4. 4

    Evaluate −36-\sqrt{36}−36​.

    Answer choices for question 4

    Solution

    Correct answer: D

    Work from the inside out. The radical gives the principal root, and the minus sign in front then negates it.

    −36=−(6)=−6-\sqrt{36} = -(6) = -6−36​=−(6)=−6

    This is how the negative square root of 363636 is written: the symbol itself is always non-negative, so the sign is applied outside it.

  5. 5

    Evaluate −1253\sqrt[3]{-125}3−125​.

    Answer choices for question 5

    Solution

    Correct answer: C

    The index is odd, so a negative radicand is allowed and the root carries the sign of the radicand.

    (−5)3=(−5)(−5)(−5)=−125(-5)^3 = (-5)(-5)(-5) = -125(−5)3=(−5)(−5)(−5)=−125

    So −1253=−5\sqrt[3]{-125} = -53−125​=−5. Odd roots of negative numbers are perfectly real; it is even roots that reject a negative radicand.

  6. 6

    Which of these is not a real number?

    Answer choices for question 6

    Solution

    Correct answer: D

    An even power of a real number is never negative, so an even root cannot accept a negative radicand over the reals.

    r2≥0  for every real r,  so no real r has r2=−4r^2 \ge 0 \ \text{ for every real } r, \ \text{ so no real } r \text{ has } r^2 = -4r2≥0  for every real r,  so no real r has r2=−4

    So −4\sqrt{-4}−4​ is not real (it is the complex number 2i2i2i). The other three are fine: 16=4\sqrt{16} = 416​=4, and the odd roots −83=−2\sqrt[3]{-8} = -23−8​=−2 and −325=−2\sqrt[5]{-32} = -25−32​=−2 happily take negative radicands.

  7. 7

    Write 50\sqrt{50}50​ in simplest radical form.

    Answer choices for question 7

    Solution

    Correct answer: B

    Find the largest perfect square that divides 505050. That is 252525, since 50=25⋅250 = 25 \cdot 250=25⋅2.

    50=25⋅2=25 2=52\sqrt{50} = \sqrt{25 \cdot 2} = \sqrt{25}\,\sqrt{2} = 5\sqrt{2}50​=25⋅2​=25​2​=52​

    Only the 25\sqrt{25}25​ leaves the radical, as the number 555; the 252525 itself does not come out. A quick check: 52≈7.075\sqrt{2} \approx 7.0752​≈7.07, and 7.072≈507.07^2 \approx 507.072≈50.

  8. 8

    Evaluate 9+16\sqrt{9 + 16}9+16​.

    Answer choices for question 8

    Solution

    Correct answer: C

    The radicand is a sum, so add before taking the root.

    9+16=25=5\sqrt{9 + 16} = \sqrt{25} = 59+16​=25​=5

    The tempting wrong answer is 777, which comes from splitting the radical over the sum as 9+16=3+4\sqrt{9} + \sqrt{16} = 3 + 49​+16​=3+4. There is no such rule: radicals distribute over products and quotients, never over sums.

  9. 9

    Evaluate 1681\sqrt{\dfrac{16}{81}}8116​​.

    Answer choices for question 9

    Solution

    Correct answer: A

    The quotient rule splits a root over a fraction, since 16≥016 \ge 016≥0 and 81>081 > 081>0.

    1681=1681=49\sqrt{\frac{16}{81}} = \frac{\sqrt{16}}{\sqrt{81}} = \frac{4}{9}8116​​=81​16​​=94​

    Both the numerator and the denominator are perfect squares, so the radical disappears completely.

  10. 10

    Write 75\sqrt{75}75​ in simplest radical form.

    Answer choices for question 10

    Solution

    Correct answer: D

    The largest perfect square dividing 757575 is 252525, since 75=25⋅375 = 25 \cdot 375=25⋅3.

    75=25 3=53\sqrt{75} = \sqrt{25}\,\sqrt{3} = 5\sqrt{3}75​=25​3​=53​

    The 333 stays inside because it has no square factor. Note that 75\sqrt{75}75​ is not 151515: squaring 151515 gives 225225225, not 757575.

  11. 11

    Write 12\sqrt{12}12​ in simplest radical form.

    Answer choices for question 11

    Solution

    Correct answer: A

    Split off the largest perfect square factor: 12=4⋅312 = 4 \cdot 312=4⋅3.

    12=4 3=23\sqrt{12} = \sqrt{4}\,\sqrt{3} = 2\sqrt{3}12​=4​3​=23​

    Only the perfect square comes out, and it comes out as its root, 222.

  12. 12

    In the expression 74\sqrt[4]{7}47​, what is the index?

    Answer choices for question 12

    Solution

    Correct answer: B

    The small number in the crook of the radical sign is the index, and the number underneath is the radicand.

    74:index=4,radicand=7\sqrt[4]{7}: \quad \text{index} = 4, \quad \text{radicand} = 747​:index=4,radicand=7

    The index says which power to undo, so 74\sqrt[4]{7}47​ is the non-negative number whose fourth power is 777. An index of 222 is the square-root case, and it is the one index that is left unwritten.
