  1. 1

    Solve 5x+1=605^{x+1} = 605x+1=60, rounding to three decimal places.

    Answer choices for question 1

    Solution

    Correct answer: D

    Take the common logarithm of both sides and use the power rule.

    (x+1)log⁡5=log⁡60  ⟹  x+1=log⁡60log⁡5≈1.778150.69897≈2.54396(x + 1)\log 5 = \log 60 \;\Longrightarrow\; x + 1 = \frac{\log 60}{\log 5} \approx \frac{1.77815}{0.69897} \approx 2.54396(x+1)log5=log60⟹x+1=log5log60​≈0.698971.77815​≈2.54396

    Now subtract 111, which is the step most often forgotten. To three decimal places, x≈1.544x \approx 1.544x≈1.544.

  2. 2

    Solve 3⋅4x=483 \cdot 4^x = 483⋅4x=48.

    Answer choices for question 2

    Solution

    Correct answer: A

    Isolate the power first by dividing both sides by the coefficient 333.

    4x=16=42  ⟹  x=24^x = 16 = 4^2 \;\Longrightarrow\; x = 24x=16=42⟹x=2

    Dividing before matching bases is what keeps the coefficient from tangling with the exponent.

  3. 3

    Solve log⁡2x+log⁡2(x−6)=4\log_2 x + \log_2(x - 6) = 4log2​x+log2​(x−6)=4.

    Answer choices for question 3

    Solution

    Correct answer: C

    The two arguments force x>0x > 0x>0 and x−6>0x - 6 > 0x−6>0, so the domain is x>6x > 6x>6. Combine with the product rule and convert to exponential form.

    log⁡2(x(x−6))=4  ⟹  x(x−6)=24=16\log_2\big(x(x-6)\big) = 4 \;\Longrightarrow\; x(x - 6) = 2^4 = 16log2​(x(x−6))=4⟹x(x−6)=24=16

    That gives x2−6x−16=0x^2 - 6x - 16 = 0x2−6x−16=0, so (x−8)(x+2)=0(x - 8)(x + 2) = 0(x−8)(x+2)=0 and the candidates are x=8x = 8x=8 and x=−2x = -2x=−2.

    Only x=8x = 8x=8 lies in the domain, and it checks out, since log⁡28+log⁡22=3+1=4\log_2 8 + \log_2 2 = 3 + 1 = 4log2​8+log2​2=3+1=4. The candidate x=−2x = -2x=−2 makes both arguments negative, which the combined equation tolerates and the original one does not, so it is extraneous.

  4. 4

    Solve log⁡5(x+3)+log⁡5(x−1)=1\log_5(x + 3) + \log_5(x - 1) = 1log5​(x+3)+log5​(x−1)=1.

    Answer choices for question 4

    Solution

    Correct answer: B

    The arguments require x+3>0x + 3 > 0x+3>0 and x−1>0x - 1 > 0x−1>0, so the domain is x>1x > 1x>1. Combine and convert.

    (x+3)(x−1)=51=5  ⟹  x2+2x−8=0  ⟹  (x+4)(x−2)=0(x + 3)(x - 1) = 5^1 = 5 \;\Longrightarrow\; x^2 + 2x - 8 = 0 \;\Longrightarrow\; (x + 4)(x - 2) = 0(x+3)(x−1)=51=5⟹x2+2x−8=0⟹(x+4)(x−2)=0

    The candidates are x=2x = 2x=2 and x=−4x = -4x=−4. Only x=2x = 2x=2 is in the domain, and it checks out, since log⁡55+log⁡51=1+0=1\log_5 5 + \log_5 1 = 1 + 0 = 1log5​5+log5​1=1+0=1. At x=−4x = -4x=−4 both arguments are negative, so that root was manufactured by the combining step.

  5. 5

    Solve log⁡x49=2\log_x 49 = 2logx​49=2 for the base xxx.

    Answer choices for question 5

    Solution

    Correct answer: A

    Convert to exponential form. The statement says that the exponent 222 on the base xxx produces 494949.

    x2=49  ⟹  x=7  or  x=−7x^2 = 49 \;\Longrightarrow\; x = 7 \ \text{ or } \ x = -7x2=49⟹x=7  or  x=−7

    A logarithm base must be positive and different from 111, so x=−7x = -7x=−7 is not allowed and the only solution is x=7x = 7x=7.

    Solve log⁡2(3x−2)=3\log_2(3x - 2) = 3log2​(3x−2)=3.

    Answer choices for question 6

    Solution

    Correct answer: B

    Convert to exponential form and solve the linear equation.

    3x−2=23=8  ⟹  3x=10  ⟹  x=1033x - 2 = 2^3 = 8 \;\Longrightarrow\; 3x = 10 \;\Longrightarrow\; x = \frac{10}{3}3x−2=23=8⟹3x=10⟹x=310​

    The argument is 8>08 > 08>0, which is guaranteed here, because 232^323 is positive.

  7. 7

    Solve log⁡4x=12\log_4 x = \frac{1}{2}log4​x=21​.

    Answer choices for question 7

    Solution

    Correct answer: C

    Convert to exponential form. A one-half power is a square root.

    x=41/2=4=2x = 4^{1/2} = \sqrt{4} = 2x=41/2=4​=2

    Checking, log⁡42=12\log_4 2 = \frac12log4​2=21​, because 41/2=24^{1/2} = 241/2=2.

  8. 8

    Solve log⁡3(x+6)−log⁡3x=2\log_3(x + 6) - \log_3 x = 2log3​(x+6)−log3​x=2.

    Answer choices for question 8

    Solution

    Correct answer: D

    The arguments require x>0x > 0x>0 (which also makes x+6>0x + 6 > 0x+6>0). Use the quotient rule, then convert.

    log⁡3x+6x=2  ⟹  x+6x=32=9  ⟹  x+6=9x  ⟹  x=34\log_3\frac{x + 6}{x} = 2 \;\Longrightarrow\; \frac{x + 6}{x} = 3^2 = 9 \;\Longrightarrow\; x + 6 = 9x \;\Longrightarrow\; x = \frac{3}{4}log3​xx+6​=2⟹xx+6​=32=9⟹x+6=9x⟹x=43​

    That value is positive, so it passes the domain test. Checking, x+6x=27/43/4=9\frac{x+6}{x} = \frac{27/4}{3/4} = 9xx+6​=3/427/4​=9, and log⁡39=2\log_3 9 = 2log3​9=2.

  9. 9

    Solve 3x=−93^x = -93x=−9.

    Answer choices for question 9

    Solution

    Correct answer: B

    An exponential with a positive base is positive for every real input, so 3x3^x3x can never be negative.

    3x>0  for every real x,  while  −9<03^x > 0 \ \text{ for every real } x, \ \text{ while } \ -9 < 03x>0  for every real x,  while  −9<0

    There is nothing to solve, and log⁡3(−9)\log_3(-9)log3​(−9) is not a number, so writing it down does not name an answer. The equation has no solution. (The value x=−2x = -2x=−2 gives 3−2=193^{-2} = \frac193−2=91​, which is positive, not −9-9−9.)

  10. 10

    Solve log⁡2(x−1)=log⁡2(6−2x)\log_2(x - 1) = \log_2(6 - 2x)log2​(x−1)=log2​(6−2x).

    Answer choices for question 10

    Solution

    Correct answer: C

    The base is the same on both sides and log⁡2\log_2log2​ is one-to-one, so set the arguments equal.

    x−1=6−2x  ⟹  3x=7  ⟹  x=73x - 1 = 6 - 2x \;\Longrightarrow\; 3x = 7 \;\Longrightarrow\; x = \frac{7}{3}x−1=6−2x⟹3x=7⟹x=37​

    Now test the candidate, because equating arguments is a step that can add roots. At x=73x = \frac73x=37​ the arguments are x−1=43>0x - 1 = \frac43 > 0x−1=34​>0 and 6−2x=43>06 - 2x = \frac43 > 06−2x=34​>0, both positive, so this one is genuine.

  11. 11

    Solve (12)x=8\left(\frac{1}{2}\right)^x = 8(21​)x=8.

    Answer choices for question 11

    Solution

    Correct answer: A

    Write the base 12\frac1221​ as a power of 222, since 12=2−1\frac12 = 2^{-1}21​=2−1.

    (2−1)x=23  ⟹  2−x=23  ⟹  −x=3  ⟹  x=−3\left(2^{-1}\right)^x = 2^3 \;\Longrightarrow\; 2^{-x} = 2^3 \;\Longrightarrow\; -x = 3 \;\Longrightarrow\; x = -3(2−1)x=23⟹2−x=23⟹−x=3⟹x=−3

    Checking, (12)−3=23=8\left(\frac12\right)^{-3} = 2^3 = 8(21​)−3=23=8. A base smaller than 111 needs a negative exponent to grow.

  12. 12

    Solve log⁡(x2)=2\log\left(x^2\right) = 2log(x2)=2, where log⁡\loglog is the common (base 101010) logarithm.

    Answer choices for question 12

    Solution

    Correct answer: D

    Convert to exponential form. The argument here is x2x^2x2, not xxx.

    x2=102=100  ⟹  x=10  or  x=−10x^2 = 10^2 = 100 \;\Longrightarrow\; x = 10 \ \text{ or } \ x = -10x2=102=100⟹x=10  or  x=−10

    Both values are genuine. The domain test asks whether the argument is positive, not whether xxx is, and (−10)2=100>0(-10)^2 = 100 > 0(−10)2=100>0 passes.

    Rewriting log⁡(x2)\log(x^2)log(x2) as 2log⁡x2\log x2logx is what tempts people to lose the negative root, but that rewrite is only valid when x>0x > 0x>0.
