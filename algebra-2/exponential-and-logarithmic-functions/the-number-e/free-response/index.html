    For positive integers nnn, let Cn=(1+1n)nC_n=(1+\frac1n)^nCn​=(1+n1​)n. A student argues: each CnC_nCn​ is a fraction and eee is irrational, so Cn<eC_n<eCn​<e for every nnn. Is that reasoning sufficient? Name the facts from this lesson that do establish Cn<eC_n<eCn​<e.
