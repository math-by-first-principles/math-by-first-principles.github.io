    Solution

    Correct answer: C

    Rewrite 2x2^{x}2x using base eee.

    Answer choices for question 11

    Solution

    Correct answer: D

    Any positive base can be written as a power of eee, since eln⁡a=ae^{\ln a} = aelna=a. Start with 2=eln⁡22 = e^{\ln 2}2=eln2.

    2x=(eln⁡2)x=exln⁡22^{x} = \left(e^{\ln 2}\right)^{x} = e^{x\ln 2}2x=(eln2)x=exln2

    The power-of-a-power law multiplies the exponents. This is why every exponential function can be written with base eee, which is what makes eee the standard base for growth models.
