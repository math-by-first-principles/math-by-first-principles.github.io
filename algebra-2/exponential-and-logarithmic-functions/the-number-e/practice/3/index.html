    Solve ln⁡(x+3)+ln⁡x=ln⁡10\ln(x + 3) + \ln x = \ln 10ln(x+3)+lnx=ln10.

    Answer choices for question 1

    Solution

    Correct answer: C

    Combine the left side with the product rule, then compare the inputs, since a logarithm is one-to-one.

    ln⁡(x(x+3))=ln⁡10  ⟹  x2+3x=10\ln\left(x(x + 3)\right) = \ln 10 \;\Longrightarrow\; x^{2} + 3x = 10ln(x(x+3))=ln10⟹x2+3x=10

    x2+3x−10=0  ⟹  (x+5)(x−2)=0x^{2} + 3x - 10 = 0 \;\Longrightarrow\; (x + 5)(x - 2) = 0x2+3x−10=0⟹(x+5)(x−2)=0

    The candidates are x=2x = 2x=2 and x=−5x = -5x=−5, but ln⁡x\ln xlnx requires x>0x > 0x>0, so x=−5x = -5x=−5 is not in the domain and is rejected. Checking the survivor: ln⁡5+ln⁡2=ln⁡10\ln 5 + \ln 2 = \ln 10ln5+ln2=ln10, which is true.

    Under continuous compounding at rate rrr, the doubling time is which expression?

    Answer choices for question 3

    Solution

    Correct answer: B

    Set the final amount to twice the principal and divide it out, so the answer cannot depend on how much was invested.

    Pert=2P  ⟹  ert=2  ⟹  rt=ln⁡2Pe^{rt} = 2P \;\Longrightarrow\; e^{rt} = 2 \;\Longrightarrow\; rt = \ln 2Pert=2P⟹ert=2⟹rt=ln2

    Since ln⁡2≈0.693\ln 2 \approx 0.693ln2≈0.693, this is close to the familiar rule of thumb that divides 0.720.720.72 by the rate, but ln⁡2r\frac{\ln 2}{r}rln2​ is the exact answer.

  6. 6

    Which statement about (1+1n)n\left(1 + \frac{1}{n}\right)^{n}(1+n1​)n is true?

    Answer choices for question 6

    Solution

    Correct answer: C

    Two facts govern the expression: the values increase with nnn, and they never reach 333. Together they force the values to close in on a single number, which is eee.

    2=(1+11)1<⋯<(1+1365)365≈2.714567<e<32 = \left(1 + \tfrac{1}{1}\right)^{1} < \cdots < \left(1 + \tfrac{1}{365}\right)^{365} \approx 2.714567 < e < 32=(1+11​)1<⋯<(1+3651​)365≈2.714567<e<3

    No finite nnn reaches eee exactly, so it does not equal eee at n=1000n = 1000n=1000. And it does not shrink toward 111: the base does shrink toward 111, but the exponent grows at the same time, and the growth of the exponent wins.

  12. 12

    Which statement about the natural logarithm is FALSE?

    Answer choices for question 12

    Solution

    Correct answer: D

    There is no rule that breaks up the logarithm of a sum, and multiplying logarithms is never the result of any property. Test it with x=y=1x = y = 1x=y=1.

    ln⁡(1+1)=ln⁡2≈0.693(ln⁡1)(ln⁡1)=0⋅0=0\ln(1 + 1) = \ln 2 \approx 0.693 \qquad (\ln 1)(\ln 1) = 0 \cdot 0 = 0ln(1+1)=ln2≈0.693(ln1)(ln1)=0⋅0=0

    Since 0.693≠00.693 \neq 00.693=0, the claim is false. The other three are all true: the domain of ln⁡\lnln is the positive numbers, ln⁡e=1\ln e = 1lne=1 because e1=ee^{1} = ee1=e, and the product rule holds for every base, eee included.
