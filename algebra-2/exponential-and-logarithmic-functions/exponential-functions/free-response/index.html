  1. Problem 1 Three powers

    Evaluate 160+16−1+161/216^0+16^{-1}+16^{1/2}160+16−1+161/2.

    1. Hint 1

      Zero, negative, and fractional exponents each have a meaning fixed by the exponent laws.

    2. Hint 2

      The three terms become 111, the reciprocal of 161616, and its positive square root.

    Answer

    8116\frac{81}{16}1681​.

    Full solution

    The base is positive, so each rule applies.

    160+16−1+161/2=1+116+4\begin{aligned}&16^0+16^{-1}+16^{1/2}\\&=1+\frac1{16}+4\end{aligned}​160+16−1+161/2=1+161​+4​

    Adding with denominator 161616 gives 8116\frac{81}{16}1681​.

    Answer

    8116\frac{81}{16}1681​.

    Key idea

    Exponent rules determine zero, negative, and fractional powers of a positive base.

  2. Problem 2 A fractional input

    1. Hint 1

      Substitute the input into the whole exponent.

    2. Hint 2

    Answer

    13\frac1331​.

    Full solution

    The exponent is 2(−16)=−132(-\frac16)=-\frac132(−61​)=−31​.

    f(−16)=27−1/3f(-\tfrac16)=27^{-1/3}f(−61​)=27−1/3

    Key idea

    A coefficient in an exponent acts on the input before the power is evaluated.

  3. Problem 3 A combined output

    Answer

    Full solution

    Collect the common exponential factor.

    5⋅4x=805\cdot4^x=805⋅4x=80

    Divide by 555, giving 4x=164^x=164x=16.

    Since 16=4216=4^216=42 and base 444 is one-to-one, x=2x=2x=2.

    Answer

    x=2x=2x=2.

    Key idea

    Like exponential terms can be collected before applying the one-to-one property.

  4. Problem 4 An incomplete record

    A record has inputs −1,0,1,2-1,0,1,2−1,0,1,2 and outputs 12,6,m,3212,6,m,\frac3212,6,m,23​, in that order. Find mmm and a rule f(x)=abxf(x)=ab^xf(x)=abx that fits every entry. Show that the neighboring output ratios agree.

    1. Hint 1

      The inputs are equally spaced, so an exponential requires equal ratios.

    2. Hint 2

      The ratio from the first known output to the next fixes the missing output.

    Answer

    m=3m=3m=3; f(x)=6(12)xf(x)=6(\frac12)^xf(x)=6(21​)x; each ratio is 12\frac1221​.

    Full solution

    The known first ratio is

    6/12=12.6/12=\frac12.6/12=21​.

    Thus

    m=6⋅12m=6\cdot\frac12m=6⋅21​

    so m=3m=3m=3.

    The remaining ratios are 3/6=123/6=\frac123/6=21​ and

    (32)/3=12.(\frac32)/3=\frac12.(23​)/3=21​.

    The output at zero is 666, so a=6a=6a=6, and the unit-step ratio gives b=12b=\frac12b=21​.

    The rule gives 12,6,3,3212,6,3,\frac3212,6,3,23​ at the four inputs.

    Answer

    m=3m=3m=3; f(x)=6(12)xf(x)=6(\frac12)^xf(x)=6(21​)x; each ratio is 12\frac1221​.

    Key idea

    In an exponential table with equally spaced inputs, a missing interior output must keep the common ratio at both of its neighboring steps.

  6. Problem 6 A smaller input step

    f(x)=10⋅9x.f(x)=10\cdot9^x.f(x)=10⋅9x.

  8. Problem 8 Choosing a parameter

    A designer proposes f(x)=(c−2)xf(x)=(c-2)^xf(x)=(c−2)x as a nonconstant real exponential defined for every real xxx. Which real values of ccc are allowed? Explain why the excluded boundary and constant cases fail.

    1. Hint 1

      Check the base, which is the entire expression c−2c-2c−2.

    2. Hint 2

      Test the base at a fractional input and at a negative input, and consider what base 1 does.

    Answer

    c>2c>2c>2 and c≠3c\ne3c=3.

    Full solution

    The base condition c−2>0c-2>0c−2>0 gives c>2c>2c>2.

    The exclusion of base one gives c≠3c\ne3c=3.

    c−2≠1c-2\ne1c−2=1

    If c<2c<2c<2, the input x=12x=\frac12x=21​ asks for (c−2)1/2(c-2)^{1/2}(c−2)1/2, the square root of a negative number, which is not real.

    If c=2c=2c=2, the input −1-1−1 demands division by zero.

    If c=3c=3c=3, every output is 111, so the function is constant.

    Answer

    c>2c>2c>2 and c≠3c\ne3c=3.

  10. Problem 10 One base, three behaviors

    For a real constant ccc, let Hc(x)=(c−1)⋅13x+cH_c(x)=(c-1)\cdot13^x+cHc​(x)=(c−1)⋅13x+c. A student claims every such graph increases because 13>113>113>1. Classify the direction and range of HcH_cHc​ for every ccc, and decide whether the claim is correct.

    1. Hint 1

      The sign of the coefficient of 13x13^x13x decides the direction.

    2. Hint 2

      Consider separately a positive, a negative, and a zero coefficient.

    Answer

    The claim is false. For c>1c>1c>1: increasing, range y>cy>cy>c. For c<1c<1c<1: decreasing, range y<cy<cy<c. For c=1c=1c=1: constant, range {1}\{1\}{1}.

    Full solution

    The term 13x13^x13x is positive and increasing, and takes every positive value.

    Multiplying it by c−1c-1c−1 keeps it increasing when c−1>0c-1>0c−1>0, reverses it when c−1<0c-1<0c−1<0, and makes it zero when c=1c=1c=1.

    If c>1c>1c>1, then (c−1)13x(c-1)13^x(c−1)13x takes every positive value, so HcH_cHc​ increases with range y>cy>cy>c.

    If c<1c<1c<1, it takes every negative value, so HcH_cHc​ decreases with range y<cy<cy<c.

    If c=1c=1c=1, then H1(x)=1H_1(x)=1H1​(x)=1 for every xxx, a constant function with range {1}\{1\}{1}.

    So the base alone does not decide the direction: the sign of the coefficient does, and the claim fails for every c<1c<1c<1 and at c=1c=1c=1.

    Answer

    The claim is false. For c>1c>1c>1: increasing, range y>cy>cy>c. For c<1c<1c<1: decreasing, range y<cy<cy<c. For c=1c=1c=1: constant, range {1}\{1\}{1}.

    For abx+kab^x+kabx+k with b>1b>1b>1, the graph increases when a>0a>0a>0, decreases when a<0a<0a<0, and is constant when a=0a=0a=0.
