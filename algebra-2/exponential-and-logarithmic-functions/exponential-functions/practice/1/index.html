  1. 1

    Which of these is an exponential function?

    Answer choices for question 1

    Solution

    Correct answer: B

    An exponential function has the variable in the exponent and a fixed number as the base.

    f(x)=5x(variable exponent, fixed base 5)f(x) = 5^{x} \quad \text{(variable exponent, fixed base } 5)f(x)=5x(variable exponent, fixed base 5)

    In x5x^{5}x5 and x1/5x^{1/5}x1/5 the variable is the base and the exponent is fixed, so those are power functions, and 5x5x5x is linear.

    If g(x)=7xg(x) = 7^{x}g(x)=7x, what is g(0)g(0)g(0)?

    Answer choices for question 3

    Solution

    Correct answer: A

    The law of exponents forces the value at 000. Split 111 as 1+01 + 01+0.

    7=71=71+0=71⋅70=7⋅707 = 7^{1} = 7^{1+0} = 7^{1} \cdot 7^{0} = 7 \cdot 7^{0}7=71=71+0=71⋅70=7⋅70

    Dividing both sides by 777 gives 70=17^{0} = 170=1. Every exponential passes through (0,1)(0, 1)(0,1), whatever its base.

  6. 6

    What is the range of f(x)=4xf(x) = 4^{x}f(x)=4x?

    Answer choices for question 6

    Solution

    Correct answer: B

    Every value of an exponential is a square, since halving the input and applying the law of exponents gives

    4x=(4x/2)2>0.4^{x} = \left(4^{x/2}\right)^{2} > 0.4x=(4x/2)2>0.

    So the output is never negative and never zero, while the unbroken curve climbs from values near 000 to values as large as you like. The range is every positive real number.

    Which expression equals (12)x\left(\tfrac{1}{2}\right)^{x}(21​)x?

    Answer choices for question 8

    Solution

    Correct answer: D

    Write the base as a power of 222 and use the rule for a power of a power.

    (12)x=(2−1)x=2−x\left(\tfrac{1}{2}\right)^{x} = \left(2^{-1}\right)^{x} = 2^{-x}(21​)x=(2−1)x=2−x

    So halving repeatedly is the same as doubling backwards, which is why the two graphs are mirror images across the yyy-axis.

    Solution

    The base of an exponential function must be positive. For f(x)=(−4)xf(x) = (-4)^{x}f(x)=(−4)x, which input has no real output?

    Answer choices for question 12

    Solution

    Correct answer: D

    An exponent of 12\tfrac1221​ asks for a square root, and squaring a real number can never give a negative result.

    (−4)1/2=−4is not a real number(-4)^{1/2} = \sqrt{-4} \quad \text{is not a real number}(−4)1/2=−4​is not a real number

    The other inputs are fine: (−4)2=16(-4)^{2} = 16(−4)2=16, (−4)3=−64(-4)^{3} = -64(−4)3=−64, and (−4)0=1(-4)^{0} = 1(−4)0=1. A negative base leaves a hole at every fraction with an even denominator, which is why bases must be positive.
