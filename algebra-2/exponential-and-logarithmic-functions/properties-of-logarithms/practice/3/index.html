    Solution

    The power rule now brings each exponent to the front.

    Solution

    Solution

    The denominator is easy: b=b1/2\sqrt{b} = b^{1/2}b​=b1/2, so log⁡bb=12\log_b \sqrt{b} = \tfrac{1}{2}logb​b​=21​.

    =0.612=1.2= \frac{0.6}{\tfrac{1}{2}} = 1.2=21​0.6​=1.2

    Shrinking the base makes the logarithm larger, which fits: it takes a bigger exponent on b\sqrt{b}b​ than on bbb to reach the same number.

    Simplify b 2log⁡b3b^{\,2\log_b 3}b2logb​3 for a valid base bbb.

    Answer choices for question 8

    Solution

    Correct answer: A

    Fold the coefficient back inside the logarithm with the power rule before doing anything else.

    2log⁡b3=log⁡b ⁣(32)=log⁡b92\log_b 3 = \log_b\!\left(3^2\right) = \log_b 92logb​3=logb​(32)=logb​9

    Now the exponential and the logarithm are inverses, so they cancel.

    b log⁡b9=9b^{\,\log_b 9} = 9blogb​9=9

    The answer does not depend on bbb at all, which is the signature of an inverse pair undoing each other.
