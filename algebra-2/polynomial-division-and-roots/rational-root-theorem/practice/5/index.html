    Factor P(x)=2x3−9x2+10x−3P(x) = 2x^3 - 9x^2 + 10x - 3P(x)=2x3−9x2+10x−3 completely.

    Answer choices for question 1

    Solution

    Correct answer: D

    The candidates are ±1,±3,±12,±32\pm 1, \pm 3, \pm\tfrac{1}{2}, \pm\tfrac{3}{2}±1,±3,±21​,±23​. Test x=1x = 1x=1: P(1)=2−9+10−3=0P(1) = 2 - 9 + 10 - 3 = 0P(1)=2−9+10−3=0, a root. Synthetic division by 111 on 2,−9,10,−32, -9, 10, -32,−9,10,−3 gives the quotient row 2,−7,32, -7, 32,−7,3.

    P(x)=(x−1)(2x2−7x+3)=(x−1)(2x−1)(x−3)P(x) = (x - 1)\left(2x^2 - 7x + 3\right) = (x - 1)(2x - 1)(x - 3)P(x)=(x−1)(2x2−7x+3)=(x−1)(2x−1)(x−3)

    The factorization of the quadratic checks out: (2x−1)(x−3)=2x2−7x+3(2x - 1)(x - 3) = 2x^2 - 7x + 3(2x−1)(x−3)=2x2−7x+3. The roots are 1,12,31, \tfrac{1}{2}, 31,21​,3.

  2. 2

    Find all roots of P(x)=x3−x2−8x+12P(x) = x^3 - x^2 - 8x + 12P(x)=x3−x2−8x+12.

    Answer choices for question 2

    Solution

    Correct answer: B

    Test x=2x = 2x=2: P(2)=8−4−16+12=0P(2) = 8 - 4 - 16 + 12 = 0P(2)=8−4−16+12=0, a root. Synthetic division by 222 on 1,−1,−8,121, -1, -8, 121,−1,−8,12 gives the quotient row 1,1,−61, 1, -61,1,−6.

    P(x)=(x−2)(x2+x−6)=(x−2)(x−2)(x+3)=(x−2)2(x+3)P(x) = (x - 2)\left(x^2 + x - 6\right) = (x - 2)(x - 2)(x + 3) = (x - 2)^2(x + 3)P(x)=(x−2)(x2+x−6)=(x−2)(x−2)(x+3)=(x−2)2(x+3)

    The root 222 appears again in the quotient, so it is a double root; the remaining root is −3-3−3. Re-testing a successful candidate on the quotient is what catches repeated roots.

  3. 3

    Find all RATIONAL roots of P(x)=x4−2x3−x+2P(x) = x^4 - 2x^3 - x + 2P(x)=x4−2x3−x+2.

    Answer choices for question 3

    Solution

    Correct answer: B

    Factor by grouping.

    x4−2x3−x+2=x3(x−2)−(x−2)=(x−2)(x3−1)=(x−2)(x−1)(x2+x+1)x^4 - 2x^3 - x + 2 = x^3(x - 2) - (x - 2) = (x - 2)\left(x^3 - 1\right) = (x - 2)(x - 1)\left(x^2 + x + 1\right)x4−2x3−x+2=x3(x−2)−(x−2)=(x−2)(x3−1)=(x−2)(x−1)(x2+x+1)

    The rational roots are 222 and 111. The factor x2+x+1x^2 + x + 1x2+x+1 has discriminant 1−4=−3<01 - 4 = -3 < 01−4=−3<0, so its two roots are nonreal (not irrational real numbers). A direct check also rules out −1-1−1: P(−1)=1+2+1+2=6P(-1) = 1 + 2 + 1 + 2 = 6P(−1)=1+2+1+2=6.

    Solution

    So 32\tfrac{3}{2}23​ is excluded. The other three pass both checks: 43\tfrac{4}{3}34​ (4∣44 \mid 44∣4, 3∣63 \mid 63∣6), −16-\tfrac{1}{6}−61​ (1∣41 \mid 41∣4, 6∣66 \mid 66∣6), and 23\tfrac{2}{3}32​ (2∣42 \mid 42∣4, 3∣63 \mid 63∣6).

    What is the complete factorization of P(x)=3x3−5x2+5x−2P(x) = 3x^3 - 5x^2 + 5x - 2P(x)=3x3−5x2+5x−2 over the real numbers?

    Answer choices for question 5

    Solution

    Correct answer: C

    Testing the candidates finds P(23)=89−209+309−189=0P\left(\tfrac{2}{3}\right) = \tfrac{8}{9} - \tfrac{20}{9} + \tfrac{30}{9} - \tfrac{18}{9} = 0P(32​)=98​−920​+930​−918​=0. Synthetic division by 23\tfrac{2}{3}32​ on 3,−5,5,−23, -5, 5, -23,−5,5,−2 gives the quotient row 3,−3,33, -3, 33,−3,3, so

    P(x)=(x−23)(3x2−3x+3)=(3x−2)(x2−x+1)P(x) = \left(x - \tfrac{2}{3}\right)\left(3x^2 - 3x + 3\right) = (3x - 2)\left(x^2 - x + 1\right)P(x)=(x−32​)(3x2−3x+3)=(3x−2)(x2−x+1)

    after pulling the factor 333 out of the quadratic. The discriminant of x2−x+1x^2 - x + 1x2−x+1 is −3<0-3 < 0−3<0, so it does not factor further over the reals. Expanding confirms (3x−2)(x2−x+1)=3x3−5x2+5x−2(3x - 2)(x^2 - x + 1) = 3x^3 - 5x^2 + 5x - 2(3x−2)(x2−x+1)=3x3−5x2+5x−2.

  6. 6

    Which argument correctly proves that 10\sqrt{10}10​ is irrational?

    Answer choices for question 6

    Solution

    Correct answer: A

    The polynomial x2−10x^2 - 10x2−10 is monic with integer coefficients, so any rational root is an integer dividing 101010. Testing (signs vanish on squaring):

    1−10=−9,4−10=−6,25−10=15,100−10=901 - 10 = -9, \quad 4 - 10 = -6, \quad 25 - 10 = 15, \quad 100 - 10 = 901−10=−9,4−10=−6,25−10=15,100−10=90

    No candidate works, so x2−10x^2 - 10x2−10 has no rational roots; since 10\sqrt{10}10​ is one of its roots, 10\sqrt{10}10​ is irrational. The other options are wrong: 10\sqrt{10}10​ is not a root of x2+10x^2 + 10x2+10, the last-digit claim proves nothing, and P(10)=90≠0P(10) = 90 \ne 0P(10)=90=0.

  8. 8

    For P(x)=x4+x3+x2+x+1P(x) = x^4 + x^3 + x^2 + x + 1P(x)=x4+x3+x2+x+1, what do the theorem's candidates reveal?

    Answer choices for question 8

    Solution

    Correct answer: B

    The polynomial is monic with constant term 111, so the entire candidate list is ±1\pm 1±1. Test both:

    P(1)=1+1+1+1+1=5,P(−1)=1−1+1−1+1=1P(1) = 1 + 1 + 1 + 1 + 1 = 5, \qquad P(-1) = 1 - 1 + 1 - 1 + 1 = 1P(1)=1+1+1+1+1=5,P(−1)=1−1+1−1+1=1

    Neither is zero, so the quartic has no rational roots at all. Two evaluations settled the question for every rational number, which is the theorem at its most efficient. (The theorem applies to any degree; nothing is special about quartics.)

    Which statement about P(x)=x3+x−10P(x) = x^3 + x - 10P(x)=x3+x−10 is correct?

    Answer choices for question 9

    Solution

    Correct answer: D

    The candidates are ±1,±2,±5,±10\pm 1, \pm 2, \pm 5, \pm 10±1,±2,±5,±10. Testing x=2x = 2x=2:

    P(2)=8+2−10=0P(2) = 8 + 2 - 10 = 0P(2)=8+2−10=0

    so 222 is a root, and dividing gives P(x)=(x−2)(x2+2x+5)P(x) = (x - 2)(x^2 + 2x + 5)P(x)=(x−2)(x2+2x+5), whose quadratic factor has discriminant 4−20=−16<04 - 20 = -16 < 04−20=−16<0: the other two roots are nonreal. In particular P(5)=125+5−10=120≠0P(5) = 125 + 5 - 10 = 120 \ne 0P(5)=125+5−10=120=0, so 555 is a candidate that fails, exactly the converse error the theorem never licenses.

  10. 10

    Find all three roots of P(x)=x3+x2−2P(x) = x^3 + x^2 - 2P(x)=x3+x2−2.

    Answer choices for question 10

    Solution

    Correct answer: C

    The candidates are ±1,±2\pm 1, \pm 2±1,±2. Test x=1x = 1x=1: P(1)=1+1−2=0P(1) = 1 + 1 - 2 = 0P(1)=1+1−2=0, a root. Synthetic division by 111 on 1,1,0,−21, 1, 0, -21,1,0,−2 gives the quotient row 1,2,21, 2, 21,2,2.

    P(x)=(x−1)(x2+2x+2)P(x) = (x - 1)\left(x^2 + 2x + 2\right)P(x)=(x−1)(x2+2x+2)

    The quadratic's discriminant is 4−8=−44 - 8 = -44−8=−4, so the quadratic formula gives x=−1±ix = -1 \pm ix=−1±i. The only rational root is 111; the conjugate pair could never appear on the candidate list.

    Every candidate list contains each of its values together with its negative. For any integer-coefficient polynomial with nonzero constant term, what is the sum of ALL the candidates on its list?

    Answer choices for question 12

    Solution

    Correct answer: C

    The list is built as ±pq\pm\tfrac{p}{q}±qp​ over all valid ppp and qqq: whenever a number is on the list, so is its negative.

    pq+(−pq)=0\tfrac{p}{q} + \left(-\tfrac{p}{q}\right) = 0qp​+(−qp​)=0

    Pairing each candidate with its negative cancels the entire sum to 000, for every polynomial. The sum carries no information; only testing individual candidates does.
