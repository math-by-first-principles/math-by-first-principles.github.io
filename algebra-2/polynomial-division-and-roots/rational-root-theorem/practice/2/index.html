    Which of these candidates is actually a root of P(x)=x3+x2−5x+3P(x) = x^3 + x^2 - 5x + 3P(x)=x3+x2−5x+3?

    Answer choices for question 1

    Solution

    Correct answer: D

    The polynomial is monic with constant term 333, so the candidates are ±1,±3\pm 1, \pm 3±1,±3. Note that 555 is not even a candidate, since 5∤35 \nmid 35∤3. Test x=1x = 1x=1:

    P(1)=1+1−5+3=0P(1) = 1 + 1 - 5 + 3 = 0P(1)=1+1−5+3=0

    So 111 is a root. Checking the others: P(3)=27+9−15+3=24P(3) = 27 + 9 - 15 + 3 = 24P(3)=27+9−15+3=24 and P(−1)=−1+1+5+3=8P(-1) = -1 + 1 + 5 + 3 = 8P(−1)=−1+1+5+3=8, so neither is a root. (In fact P(x)=(x−1)2(x+3)P(x) = (x - 1)^2(x + 3)P(x)=(x−1)2(x+3).)

  2. 2

    Find all rational roots of P(x)=x4−5x2+4P(x) = x^4 - 5x^2 + 4P(x)=x4−5x2+4.

    Answer choices for question 2

    Solution

    Correct answer: A

    Treat it as a quadratic in x2x^2x2.

    x4−5x2+4=(x2−1)(x2−4)=(x−1)(x+1)(x−2)(x+2)x^4 - 5x^2 + 4 = \left(x^2 - 1\right)\left(x^2 - 4\right) = (x-1)(x+1)(x-2)(x+2)x4−5x2+4=(x2−1)(x2−4)=(x−1)(x+1)(x−2)(x+2)

    The four roots are ±1\pm 1±1 and ±2\pm 2±2, all rational and all on the candidate list built from the constant term 444. The candidates ±4\pm 4±4 are on the list too, but they fail the test.

  3. 3

    What is the only rational root of P(x)=x3+2x2+2x+4P(x) = x^3 + 2x^2 + 2x + 4P(x)=x3+2x2+2x+4?

    Answer choices for question 3

    Solution

    Correct answer: B

    Factor by grouping.

    x3+2x2+2x+4=x2(x+2)+2(x+2)=(x+2)(x2+2)x^3 + 2x^2 + 2x + 4 = x^2(x + 2) + 2(x + 2) = (x + 2)\left(x^2 + 2\right)x3+2x2+2x+4=x2(x+2)+2(x+2)=(x+2)(x2+2)

    The factor x+2x + 2x+2 gives the root −2-2−2. The factor x2+2x^2 + 2x2+2 is never zero for real xxx (its roots are ±i2\pm i\sqrt{2}±i2​), so −2-2−2 is the only rational root. Direct checks agree: P(−1)=3P(-1) = 3P(−1)=3, P(2)=24P(2) = 24P(2)=24, P(−4)=−36P(-4) = -36P(−4)=−36.

  4. 4

    The polynomial P(x)=x3−4x2+4xP(x) = x^3 - 4x^2 + 4xP(x)=x3−4x2+4x has constant term 000. What is the correct way to find its rational roots?

    Answer choices for question 4

    Solution

    Correct answer: A

    When a0=0a_0 = 0a0​=0, the condition p∣0p \mid 0p∣0 is satisfied by every integer, so the theorem filters nothing. Factor out the largest power of xxx first.

    x3−4x2+4x=x(x2−4x+4)=x(x−2)2x^3 - 4x^2 + 4x = x\left(x^2 - 4x + 4\right) = x(x - 2)^2x3−4x2+4x=x(x2−4x+4)=x(x−2)2

    The roots are x=0x = 0x=0 and x=2x = 2x=2 (a double root). Testing only ±1,±2,±4\pm 1, \pm 2, \pm 4±1,±2,±4 on the original polynomial would find 222 but miss the root 000.

  5. 5

    Find all roots of P(x)=4x3−4x2−x+1P(x) = 4x^3 - 4x^2 - x + 1P(x)=4x3−4x2−x+1.

    Answer choices for question 5

    Solution

    Correct answer: D

    Factor by grouping.

    4x3−4x2−x+1=4x2(x−1)−(x−1)=(x−1)(4x2−1)4x^3 - 4x^2 - x + 1 = 4x^2(x - 1) - (x - 1) = (x - 1)\left(4x^2 - 1\right)4x3−4x2−x+1=4x2(x−1)−(x−1)=(x−1)(4x2−1)

    Since 4x2−1=(2x−1)(2x+1)4x^2 - 1 = (2x - 1)(2x + 1)4x2−1=(2x−1)(2x+1), the roots are x=1x = 1x=1, x=12x = \tfrac{1}{2}x=21​, and x=−12x = -\tfrac{1}{2}x=−21​. All three sit on the candidate list ±1,±12,±14\pm 1, \pm\tfrac{1}{2}, \pm\tfrac{1}{4}±1,±21​,±41​.

  6. 6

    For which polynomial does the Rational Root Theorem NOT rule out x=34x = \tfrac{3}{4}x=43​ as a possible root?

    Answer choices for question 6

    Solution

    Correct answer: C

    For 34\tfrac{3}{4}43​ to survive the filter, the numerator 333 must divide the constant term and the denominator 444 must divide the leading coefficient.

    8x3−2x+3:  3∣3 ✓4∣8 ✓8x^3 - 2x + 3\text{: } \ 3 \mid 3 \ \checkmark \quad 4 \mid 8 \ \checkmark8x3−2x+3:  3∣3 ✓4∣8 ✓

    The others fail: 4x3+x−44x^3 + x - 44x3+x−4 has constant −4-4−4 with 3∤43 \nmid 43∤4; 3x3+x+83x^3 + x + 83x3+x+8 has 3∤83 \nmid 83∤8 and 4∤34 \nmid 34∤3; 6x2+x−36x^2 + x - 36x2+x−3 has 4∤64 \nmid 64∤6. Surviving the filter only makes 34\tfrac{3}{4}43​ a candidate; testing would still be required.

  7. 7

    The candidate list for P(x)=2x2−x−1P(x) = 2x^2 - x - 1P(x)=2x2−x−1 is ±1,±12\pm 1, \pm\tfrac{1}{2}±1,±21​. Which candidates are actual roots?

    Answer choices for question 7

    Solution

    Correct answer: A

    Factor the quadratic.

    2x2−x−1=(2x+1)(x−1)2x^2 - x - 1 = (2x + 1)(x - 1)2x2−x−1=(2x+1)(x−1)

    Setting each factor to zero gives x=−12x = -\tfrac{1}{2}x=−21​ and x=1x = 1x=1. The other two candidates fail: P(−1)=2+1−1=2P(-1) = 2 + 1 - 1 = 2P(−1)=2+1−1=2 and P(12)=12−12−1=−1P\left(\tfrac{1}{2}\right) = \tfrac{1}{2} - \tfrac{1}{2} - 1 = -1P(21​)=21​−21​−1=−1.

  8. 8

    A cubic with integer coefficients has leading coefficient 111 and constant term 777. What is its complete candidate list?

    Answer choices for question 8

    Solution

    Correct answer: B

    Monic means q=1q = 1q=1, so every candidate is an integer dividing 777. Since 777 is prime, its positive divisors are just 111 and 777, and each carries both signs.

    ±1, ±7\pm 1, \ \pm 7±1, ±7

    Forgetting the negative candidates is a common slip; roots are often negative.

  9. 9

    The equation x2−12x−12=0x^2 - \tfrac{1}{2}x - \tfrac{1}{2} = 0x2−21​x−21​=0 has fractional coefficients. What should you do before applying the theorem?

    Answer choices for question 9

    Solution

    Correct answer: C

    The theorem requires integer coefficients, and multiplying an equation by a nonzero constant changes no roots.

    2(x2−12x−12)=2x2−x−1=(2x+1)(x−1)2\left(x^2 - \tfrac{1}{2}x - \tfrac{1}{2}\right) = 2x^2 - x - 1 = (2x + 1)(x - 1)2(x2−21​x−21​)=2x2−x−1=(2x+1)(x−1)

    Now the theorem applies, and the roots 111 and −12-\tfrac{1}{2}−21​ both appear on its candidate list. Rounding coefficients would change the equation entirely.

  11. 11

    The other two roots of 2x3−x2−6x+32x^3 - x^2 - 6x + 32x3−x2−6x+3 are not rational. What are they, and why can the theorem not list them?

    Answer choices for question 11

    Solution

    Correct answer: D

    From the factorization (2x−1)(x2−3)(2x - 1)(x^2 - 3)(2x−1)(x2−3), the remaining roots satisfy x2=3x^2 = 3x2=3.

    x=±3x = \pm\sqrt{3}x=±3​

    These are irrational. The candidate list is built entirely from fractions ±pq\pm\tfrac{p}{q}±qp​, so an irrational root can never appear on it; the theorem is structurally blind to such roots.
