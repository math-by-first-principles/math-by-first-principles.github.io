    The cubic x3−6x2+11x−6x^3 - 6x^2 + 11x - 6x3−6x2+11x−6 has 111 as a zero. What is the quotient when it is divided by x−1x - 1x−1?

    Answer choices for question 1

    Solution

    Correct answer: B

    Synthetic division by c=1c = 1c=1 on the row 1,−6,11,−61, -6, 11, -61,−6,11,−6 brings down 111, then computes −6+1=−5-6 + 1 = -5−6+1=−5, then 11+(−5)=611 + (-5) = 611+(−5)=6, then −6+6=0-6 + 6 = 0−6+6=0.

    x3−6x2+11x−6=(x−1)(x2−5x+6)x^3 - 6x^2 + 11x - 6 = (x - 1)\left(x^2 - 5x + 6\right)x3−6x2+11x−6=(x−1)(x2−5x+6)

    The final 000 confirms that 111 really is a zero, and the other entries are the quotient's coefficients.

  2. 2

    The cubic x3−13x+12x^3 - 13x + 12x3−13x+12 has 111 as a zero. Which is its complete factorization?

    Answer choices for question 2

    Solution

    Correct answer: A

    Write the missing power explicitly: the synthetic row is 1,0,−13,121, 0, -13, 121,0,−13,12. Dividing by c=1c = 1c=1 gives 111, then 0+1=10 + 1 = 10+1=1, then −13+1=−12-13 + 1 = -12−13+1=−12, then 12+(−12)=012 + (-12) = 012+(−12)=0, so the quotient is x2+x−12x^2 + x - 12x2+x−12.

    x2+x−12=(x+4)(x−3)x^2 + x - 12 = (x + 4)(x - 3)x2+x−12=(x+4)(x−3)

    The complete factorization is (x−1)(x+4)(x−3)(x - 1)(x + 4)(x - 3)(x−1)(x+4)(x−3), with zeros 111, −4-4−4, and 333.

    For which value of kkk is x+1x + 1x+1 a factor of 2x3+kx2−5x+22x^3 + kx^2 - 5x + 22x3+kx2−5x+2?

    Answer choices for question 3

    Solution

    Correct answer: D

    The factor x+1x + 1x+1 vanishes at x=−1x = -1x=−1, so require P(−1)=0P(-1) = 0P(−1)=0.

    P(−1)=−2+k+5+2=k+5=0P(-1) = -2 + k + 5 + 2 = k + 5 = 0P(−1)=−2+k+5+2=k+5=0

    So k=−5k = -5k=−5. Watch the signs when substituting −1-1−1: the odd powers flip sign, so 2(−1)3=−22(-1)^3 = -22(−1)3=−2 and −5(−1)=+5-5(-1) = +5−5(−1)=+5.

  4. 4

    Which is the monic cubic with zeros −2-2−2, 111, and 444, in expanded form?

    Answer choices for question 4

    Solution

    Correct answer: B

    Multiply the three factors (x+2)(x−1)(x−4)(x + 2)(x - 1)(x - 4)(x+2)(x−1)(x−4) in stages. First (x+2)(x−1)=x2+x−2(x + 2)(x - 1) = x^2 + x - 2(x+2)(x−1)=x2+x−2, then

    (x2+x−2)(x−4)=x3−4x2+x2−4x−2x+8=x3−3x2−6x+8\left(x^2 + x - 2\right)(x - 4) = x^3 - 4x^2 + x^2 - 4x - 2x + 8 = x^3 - 3x^2 - 6x + 8(x2+x−2)(x−4)=x3−4x2+x2−4x−2x+8=x3−3x2−6x+8

    A check at x=1x = 1x=1 gives 1−3−6+8=01 - 3 - 6 + 8 = 01−3−6+8=0, confirming one of the prescribed zeros.

  5. 5

    A cubic has zeros −1-1−1, 222, and 555, and its graph passes through (0,30)(0, 30)(0,30). What is its leading coefficient aaa?

    Answer choices for question 5

    Solution

    Correct answer: A

    The zeros force the shape P(x)=a(x+1)(x−2)(x−5)P(x) = a(x + 1)(x - 2)(x - 5)P(x)=a(x+1)(x−2)(x−5), and the point pins down aaa. Substitute x=0x = 0x=0:

    P(0)=a(1)(−2)(−5)=10a=30P(0) = a(1)(-2)(-5) = 10a = 30P(0)=a(1)(−2)(−5)=10a=30

    So a=3a = 3a=3. Roots alone determine a polynomial only up to this constant; the extra point is what selects it.

    Which of the following is NOT a factor of x3−2x2−5x+6x^3 - 2x^2 - 5x + 6x3−2x2−5x+6?

    Answer choices for question 6

    Solution

    Correct answer: C

    Evaluate the polynomial at each candidate's root. At x=2x = 2x=2:

    P(2)=8−8−10+6=−4≠0P(2) = 8 - 8 - 10 + 6 = -4 \neq 0P(2)=8−8−10+6=−4=0

    So x−2x - 2x−2 is not a factor. The other three all pass the test: P(1)=0P(1) = 0P(1)=0, P(−2)=0P(-2) = 0P(−2)=0, and P(3)=0P(3) = 0P(3)=0, which matches the factorization (x−1)(x+2)(x−3)(x - 1)(x + 2)(x - 3)(x−1)(x+2)(x−3).

  7. 7

    Which is the monic quartic with zeros 111, −1-1−1, 222, and −2-2−2, in expanded form?

    Answer choices for question 7

    Solution

    Correct answer: D

    Pair each zero with its negative, since each pair multiplies into a difference of squares.

    (x−1)(x+1)=x2−1,(x−2)(x+2)=x2−4(x - 1)(x + 1) = x^2 - 1, \qquad (x - 2)(x + 2) = x^2 - 4(x−1)(x+1)=x2−1,(x−2)(x+2)=x2−4

    Then (x2−1)(x2−4)=x4−5x2+4\left(x^2 - 1\right)\left(x^2 - 4\right) = x^4 - 5x^2 + 4(x2−1)(x2−4)=x4−5x2+4. Checking x=2x = 2x=2: 16−20+4=016 - 20 + 4 = 016−20+4=0, as required.

    For what value of kkk is x+3x + 3x+3 a factor of x3−4x+kx^3 - 4x + kx3−4x+k?

    Answer choices for question 8

    Solution

    Correct answer: C

    Set the value at x=−3x = -3x=−3 equal to zero.

    P(−3)=−27+12+k=k−15=0P(-3) = -27 + 12 + k = k - 15 = 0P(−3)=−27+12+k=k−15=0

    So k=15k = 15k=15. The cube of −3-3−3 is −27-27−27, and −4(−3)=+12-4(-3) = +12−4(−3)=+12; sign slips on those two terms are the usual source of wrong answers here.

  9. 9

    A monic quadratic with real coefficients has 3i3i3i as a zero. Which is it?

    Answer choices for question 9

    Solution

    Correct answer: B

    Real coefficients force the conjugate −3i-3i−3i to be the other zero, so the factors are x−3ix - 3ix−3i and x+3ix + 3ix+3i.

    (x−3i)(x+3i)=x2−(3i)2=x2+9(x - 3i)(x + 3i) = x^2 - (3i)^2 = x^2 + 9(x−3i)(x+3i)=x2−(3i)2=x2+9

    The conjugate pair multiplies into a real quadratic with no real roots; x2−9x^2 - 9x2−9 has zeros ±3\pm 3±3, which are real and different.

    Which is the monic cubic with real coefficients whose zeros include 222 and iii, in expanded form?

    Answer choices for question 10

    Solution

    Correct answer: C

    Real coefficients force −i-i−i to join iii, and the conjugate pair multiplies into a real quadratic.

    (x−i)(x+i)=x2+1(x - i)(x + i) = x^2 + 1(x−i)(x+i)=x2+1

    Attaching the real root's factor gives (x−2)(x2+1)=x3−2x2+x−2(x - 2)\left(x^2 + 1\right) = x^3 - 2x^2 + x - 2(x−2)(x2+1)=x3−2x2+x−2. Check at x=2x = 2x=2: 8−8+2−2=08 - 8 + 2 - 2 = 08−8+2−2=0.

    The cubic x3−2x2−11x+12x^3 - 2x^2 - 11x + 12x3−2x2−11x+12 has zeros 111, 444, and −3-3−3. Which is its complete factorization?

    Answer choices for question 12

    Solution

    Correct answer: D

    Convert each zero to its factor by flipping the sign: zeros 111, 444, −3-3−3 give factors x−1x - 1x−1, x−4x - 4x−4, x+3x + 3x+3.

    x3−2x2−11x+12=(x−1)(x−4)(x+3)x^3 - 2x^2 - 11x + 12 = (x - 1)(x - 4)(x + 3)x3−2x2−11x+12=(x−1)(x−4)(x+3)

    A quick multiplication check of the constant term: (−1)(−4)(3)=12(-1)(-4)(3) = 12(−1)(−4)(3)=12, matching the polynomial.
