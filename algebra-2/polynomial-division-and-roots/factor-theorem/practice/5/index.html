    For which real values of kkk is x−2x - 2x−2 a factor of x3+kx2−2kx−8x^3 + kx^2 - 2kx - 8x3+kx2−2kx−8?

    Answer choices for question 1

    Solution

    Correct answer: C

    Apply the factor theorem and watch what happens to kkk.

    P(2)=8+4k−4k−8=0P(2) = 8 + 4k - 4k - 8 = 0P(2)=8+4k−4k−8=0

    The kkk terms cancel identically, so P(2)=0P(2) = 0P(2)=0 no matter what kkk is, and x−2x - 2x−2 is a factor for every real kkk. The polynomial family is built so that the parameter never disturbs the root at 222.

    Suppose P(x)=(x−3) Q(x)P(x) = (x - 3)\,Q(x)P(x)=(x−3)Q(x) and P(7)=28P(7) = 28P(7)=28. What is Q(7)Q(7)Q(7)?

    Answer choices for question 2

    Solution

    Correct answer: C

    Evaluate the factorization at x=7x = 7x=7 and solve for the unknown value.

    28=P(7)=(7−3) Q(7)=4 Q(7)28 = P(7) = (7 - 3)\,Q(7) = 4\,Q(7)28=P(7)=(7−3)Q(7)=4Q(7)

    So Q(7)=7Q(7) = 7Q(7)=7. The identity holds at every input, not just at the root, so it can be read as an equation about values.

    Given that P(x)=x3−7x+6=(x−2) Q(x)P(x) = x^3 - 7x + 6 = (x - 2)\,Q(x)P(x)=x3−7x+6=(x−2)Q(x), find Q(1)Q(1)Q(1) without computing Q(x)Q(x)Q(x).

    Answer choices for question 3

    Solution

    Correct answer: D

    Evaluate the identity at x=1x = 1x=1, using P(1)=1−7+6=0P(1) = 1 - 7 + 6 = 0P(1)=1−7+6=0.

    0=P(1)=(1−2) Q(1)=−Q(1)0 = P(1) = (1 - 2)\,Q(1) = -Q(1)0=P(1)=(1−2)Q(1)=−Q(1)

    So Q(1)=0Q(1) = 0Q(1)=0. The reasoning is the peeling argument in miniature: a root of PPP that is not the root already peeled must live inside the quotient. (Indeed Q(x)=x2+2x−3=(x+3)(x−1)Q(x) = x^2 + 2x - 3 = (x + 3)(x - 1)Q(x)=x2+2x−3=(x+3)(x−1).)

  4. 4

    Is x+1x + 1x+1 a factor of x99+1x^{99} + 1x99+1?

    Answer choices for question 4

    Solution

    Correct answer: A

    Evaluate at x=−1x = -1x=−1, the root of the candidate factor. Since 999999 is odd, (−1)99=−1(-1)^{99} = -1(−1)99=−1.

    (−1)99+1=−1+1=0(-1)^{99} + 1 = -1 + 1 = 0(−1)99+1=−1+1=0

    So x+1x + 1x+1 is a factor of x99+1x^{99} + 1x99+1. The same argument shows x+1x + 1x+1 divides xn+1x^n + 1xn+1 for every odd nnn.

  5. 5

    For which value of kkk is x−kx - kx−k a factor of x3−kx2−4x+4x^3 - kx^2 - 4x + 4x3−kx2−4x+4?

    Answer choices for question 5

    Solution

    Correct answer: B

    Here the unknown appears in both the polynomial and the factor, but the test is the same: substitute x=kx = kx=k.

    P(k)=k3−k⋅k2−4k+4=−4k+4=0P(k) = k^3 - k \cdot k^2 - 4k + 4 = -4k + 4 = 0P(k)=k3−k⋅k2−4k+4=−4k+4=0

    The cubic terms cancel, leaving k=1k = 1k=1. Check: x3−x2−4x+4x^3 - x^2 - 4x + 4x3−x2−4x+4 at x=1x = 1x=1 is 1−1−4+4=01 - 1 - 4 + 4 = 01−1−4+4=0.

    A cubic P(x)P(x)P(x) has zeros −3-3−3, 222, and 555, and P(0)=60P(0) = 60P(0)=60. What is P(1)P(1)P(1)?

    Answer choices for question 6

    Solution

    Correct answer: B

    The zeros give P(x)=a(x+3)(x−2)(x−5)P(x) = a(x + 3)(x - 2)(x - 5)P(x)=a(x+3)(x−2)(x−5), and P(0)P(0)P(0) finds the scale.

    P(0)=a (3)(−2)(−5)=30a=60⟹a=2P(0) = a\,(3)(-2)(-5) = 30a = 60 \quad\Longrightarrow\quad a = 2P(0)=a(3)(−2)(−5)=30a=60⟹a=2

    Then P(1)=2 (4)(−1)(−4)=32P(1) = 2\,(4)(-1)(-4) = 32P(1)=2(4)(−1)(−4)=32.

  7. 7

    Which polynomial has exactly the same zeros as P(x)=(x−1)(x−2)P(x) = (x - 1)(x - 2)P(x)=(x−1)(x−2)?

    Answer choices for question 7

    Solution

    Correct answer: A

    Multiplying a polynomial by a nonzero constant changes none of its zeros, since 5≠05 \neq 05=0 contributes no root.

    5(x−1)(x−2)=0  ⟺  x=1 or x=25(x - 1)(x - 2) = 0 \iff x = 1 \text{ or } x = 25(x−1)(x−2)=0⟺x=1 or x=2

    The others differ: (x+1)(x+2)(x + 1)(x + 2)(x+1)(x+2) and x2+3x+2x^2 + 3x + 2x2+3x+2 both vanish at −1-1−1 and −2-2−2, and the cubic option has the extra zero 333. This is why a zero list alone never picks out one polynomial: it is only when a polynomial of degree nnn carries nnn different zeros, as this one does, that they pin it down, and even then a constant factor stays free.

    Find aaa and bbb so that x−1x - 1x−1 and x+1x + 1x+1 are both factors of ax3+bx2−3x+5ax^3 + bx^2 - 3x + 5ax3+bx2−3x+5.

    Answer choices for question 8

    Solution

    Correct answer: B

    Two factors give two equations. From P(1)=0P(1) = 0P(1)=0: a+b−3+5=0a + b - 3 + 5 = 0a+b−3+5=0, so a+b=−2a + b = -2a+b=−2. From P(−1)=0P(-1) = 0P(−1)=0: −a+b+3+5=0-a + b + 3 + 5 = 0−a+b+3+5=0, so −a+b=−8-a + b = -8−a+b=−8. Subtract the second equation from the first:

    2a=6⟹a=3,b=−52a = 6 \quad\Longrightarrow\quad a = 3, \qquad b = -52a=6⟹a=3,b=−5

    Check both: 3−5−3+5=03 - 5 - 3 + 5 = 03−5−3+5=0 and −3−5+3+5=0-3 - 5 + 3 + 5 = 0−3−5+3+5=0.

  10. 10

    Can x3−5x+cx^3 - 5x + cx3−5x+c have four distinct real zeros for some choice of the constant ccc?

    Answer choices for question 10

    Solution

    Correct answer: A

    Each distinct zero peels off a linear factor and drops the degree by one, so a degree-333 polynomial cannot absorb four peels.

    P(x)=(x−r1)(x−r2)(x−r3)(x−r4) Q(x)⟹deg⁡P≥4P(x) = (x - r_1)(x - r_2)(x - r_3)(x - r_4)\,Q(x) \quad\Longrightarrow\quad \deg P \geq 4P(x)=(x−r1​)(x−r2​)(x−r3​)(x−r4​)Q(x)⟹degP≥4

    No constant ccc can change the degree, so four distinct zeros are impossible. The last option overreaches in the other direction: a cubic can have three real zeros, for example x3−xx^3 - xx3−x.

  11. 11

    A degree-333 polynomial has zeros −1-1−1, 111, and 222, and satisfies P(3)=16P(3) = 16P(3)=16. What is its leading coefficient aaa?

    Answer choices for question 11

    Solution

    Correct answer: C

    Three distinct zeros of a cubic force the form P(x)=a(x+1)(x−1)(x−2)P(x) = a(x + 1)(x - 1)(x - 2)P(x)=a(x+1)(x−1)(x−2). Evaluate at x=3x = 3x=3:

    P(3)=a (4)(2)(1)=8a=16P(3) = a\,(4)(2)(1) = 8a = 16P(3)=a(4)(2)(1)=8a=16

    So a=2a = 2a=2. The zeros fixed the shape; the one extra data point fixed the scale.

  12. 12

    A cubic with real coefficients has iii as one of its zeros. Which number must also be one of its zeros?

    Answer choices for question 12

    Solution

    Correct answer: D

    Nonreal zeros of real-coefficient polynomials arrive in conjugate pairs, because conjugating the equation P(i)=0P(i) = 0P(i)=0 leaves the real coefficients fixed.

    P(i)=0⟹P(i‾)=P(−i)=0P(i) = 0 \quad\Longrightarrow\quad P\left(\overline{i}\right) = P(-i) = 0P(i)=0⟹P(i)=P(−i)=0

    So −i-i−i must be a zero. Nothing forces any particular real number to be the third zero; that one is free.
