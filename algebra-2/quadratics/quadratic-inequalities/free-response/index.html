  1. Problem 1 A squared threshold

    Solve 2(x−1)2+3<112(x-1)^2+3<112(x−1)2+3<11, giving the answer in interval notation.

    1. Hint 1

      Isolate the square to see how far the input may be from its center.

    2. Hint 2

      The strict symbol excludes the two boundary distances.

    Answer

    (−1,3)(-1,3)(−1,3).

    Full solution

    (x−1)2<4−2<x−1x−1<2\begin{aligned} (x-1)^2&<4 \\ -2&<x-1 \\ x-1&<2 \end{aligned}(x−1)2−2x−1​<4<x−1<2​

    A real number's square is less than 444 exactly when the number lies strictly between −2-2−2 and 222.

    Adding 111 throughout translates this to −1<x<3-1<x<3−1<x<3.

    At either endpoint the original left side is 111111, which is excluded.

    Answer

    (−1,3)(-1,3)(−1,3).

    Key idea

    Requiring a square to be less than a positive bound keeps its base strictly between the negative and positive square roots of that bound.

  3. Problem 3 At the highest value

    Solve −3(x+1)2+4≥4-3(x+1)^2+4\ge4−3(x+1)2+4≥4 over the reals.

    1. Hint 1

      Consider the possible signs of a square and how a negative multiplier changes them.

    2. Hint 2

      A nonnegative square can have a nonpositive value only at zero.

    Answer

    {−1}\{-1\}{−1}.

    Full solution

    Subtract 444 and divide by −3-3−3, reversing the inequality.

    (x+1)2≤0(x+1)^2\le0(x+1)2≤0

    A square is nonnegative, so it must equal zero.

    Thus x=−1x=-1x=−1, which makes the original expression exactly 444.

    Answer

    {−1}\{-1\}{−1}.

    Key idea

    At a quadratic’s maximum, an at-least-maximum condition can accept just its vertex input.

  4. Problem 4 Two operating limits

    A machine setting satisfies 0≤x≤50\le x\le50≤x≤5. Its output is Q(x)=x(8−x)Q(x)=x(8-x)Q(x)=x(8−x) units, and operation requires Q(x)≥12Q(x)\ge12Q(x)≥12. Find all allowed settings.

    1. Hint 1

      Solve the output condition, then intersect with the setting domain.

    2. Hint 2

      The quadratic boundary equation has two roots, but the domain may trim the resulting interval.

    Answer

    [2,5][2,5][2,5].

    Full solution

    The output condition rearranges to

    x2−8x+12≤0(x−2)(x−6)≤0\begin{aligned} x^2-8x+12&\le0 \\ (x-2)(x-6)&\le0 \end{aligned}x2−8x+12(x−2)(x−6)​≤0≤0​

    The upward quadratic (x−2)(x−6)(x-2)(x-6)(x−2)(x−6) is negative between its roots and zero at them, so the non-strict inequality holds on [2,6][2,6][2,6].

    Intersecting with the declared domain [0,5][0,5][0,5] leaves [2,5][2,5][2,5].

    At x=2x=2x=2, output is 121212; at x=5x=5x=5, it is 151515, so both retained endpoints are allowed.

    Answer

    [2,5][2,5][2,5].

    Key idea

    A quadratic threshold must be intersected with a model’s permitted input domain.

  5. Problem 5 Reading a level from a graph

    The figure shows y=f(x)y=f(x)y=f(x) and the horizontal line y=4y=4y=4. Read the solution set of f(x)<4f(x)<4f(x)<4 in interval notation.

    Text description of this figure

    A grid with the horizontal axis running from negative 5 to 3 and the vertical axis running from negative 1 to 10, gridlines and number labels at every whole number. A single smooth upward opening curve, labeled f, enters through the top edge on the left, descends to its lowest point on the horizontal axis, and rises back up to leave through the top edge on the right. A dashed horizontal line, labeled y equals 4, crosses the full width of the grid, and the curve crosses this line at two points that are not marked.

    1. Hint 1

      Compare the curve’s height with the horizontal reference line.

    2. Hint 2

      The crossings with that line set the excluded endpoints.

    Answer

    (−3,1)(-3,1)(−3,1).

    Full solution

    The curve meets the reference line at horizontal coordinates −3-3−3 and 111.

    Between them it lies below the line; outside them it lies above.

    The strict inequality excludes the two crossing inputs, so the interval is (−3,1)(-3,1)(−3,1).

    Answer

    (−3,1)(-3,1)(−3,1).

    Key idea

    A function inequality with a nonzero threshold compares a graph with a horizontal line.

  6. Problem 6 A vertical adjustment

    For real ccc, determine when 2x2+4x+c<02x^2+4x+c<02x2+4x+c<0 has no real solution. Explain using the lowest value of the expression.

    1. Hint 1

      Rewrite the varying terms as a positive multiple of a square.

    2. Hint 2

      The strict inequality requires the minimum to lie below zero.

    Answer

    c≥2c\ge2c≥2.

    Full solution

    Completing the square gives

    2(x+1)2+c−22(x+1)^2+c-22(x+1)2+c−2

    Its minimum is c−2c-2c−2.

    If c≥2c\ge2c≥2, every value is at least zero and the strict inequality has no solution.

    If c<2c<2c<2, the input x=−1x=-1x=−1 makes the expression negative.

    Thus the condition is exactly c≥2c\ge2c≥2.

    Answer

    c≥2c\ge2c≥2.

    Key idea

    A strict negative-value request is impossible exactly when an upward quadratic’s minimum is at least zero.

  8. Problem 8 One sample on an interval

    A quadratic fff has no zero in (1,4)(1,4)(1,4), and f(2)<0f(2)<0f(2)<0. A student says f(3)f(3)f(3) must also be negative. Is that conclusion valid? Explain.

    1. Hint 1

      A quadratic’s sign can change only at a zero.

    2. Hint 2

      The two tested inputs lie in the same interval without a zero.

    Answer

    Yes; f(3)<0f(3)<0f(3)<0.

    Full solution

    The inputs 222 and 333 lie inside (1,4)(1,4)(1,4).

    A sign change between them would require a root somewhere in that interval, contrary to the hypothesis.

    The sign therefore stays negative throughout the interval, and in particular at 333.

    Answer

    Yes; f(3)<0f(3)<0f(3)<0.

    Key idea

    A quadratic keeps a fixed sign on an interval containing none of its zeros.

  10. Problem 10 One inequality implies another

    A quadratic fff has positive leading coefficient and negative discriminant. Is f(x)+2>0f(x)+2>0f(x)+2>0 true for every real xxx? Justify.

    Full solution

    The original quadratic has no real zero and opens upward, so it is positive everywhere.

    In vertex form its height is

    −Δ/(4a)>0.-\Delta/(4a)>0.−Δ/(4a)>0.

    Adding 222 gives

    f(x)+2>2f(x)+2>2f(x)+2>2

    Thus the requested strict inequality holds for every real input.

    Adding a positive constant to an everywhere-positive quadratic preserves strict positivity.
