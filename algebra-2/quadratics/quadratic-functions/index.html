Quadratic Functions and Parabolas

Intuition

In Algebra I you already factored quadratics, sketched parabolas, and perhaps met the quadratic formula, so this chapter does not start from zero. It starts from a change of viewpoint. A quadratic function is one object that can be written in three interchangeable costumes, standard form ax2+bx+cax^2 + bx + cax2+bx+c, vertex form a(x−h)2+ka(x - h)^2 + ka(x−h)2+k, and factored form a(x−r1)(x−r2)a(x - r_1)(x - r_2)a(x−r1​)(x−r2​). For instance, x2−2x−3x^2 - 2x - 3x2−2x−3 is the very same function as (x−1)2−4(x - 1)^2 - 4(x−1)2−4 and as (x−3)(x+1)(x - 3)(x + 1)(x−3)(x+1): the algebra looks different each time, but the graph does not move. Each of those three costumes answers a different question instantly while hiding the others. Choosing a form is choosing which question you get to answer without work. Every technique in this chapter, factoring, completing the square, even the quadratic formula itself, is nothing more than a procedure for changing costume. This opening lesson defines the object and ties every parabola back to the single parent y=x2y = x^2y=x2, using the transformation machinery you built in Functions and Their Graphs. Then it earns its keep: it digs the axis of symmetry of ax2+bx+cax^2 + bx + cax2+bx+c out of symmetry alone, quoting no formula from anywhere.

Learning goals

  • Define a quadratic by a≠0a \ne 0a=0 and name its parabola
  • Read vertex form as the parent y=x2y = x^2y=x2 transformed
  • Take ccc and the end behavior from standard form
  • Derive the axis x=−b2ax = -\tfrac{b}{2a}x=−2ab​ from symmetry alone
  • Locate the zeros on factored form, bisected by the axis
  • Move between standard, vertex, and factored form for one quadratic

What makes a function quadratic

A quadratic function is a function of the form

f(x)=ax2+bx+c,a≠0,f(x) = ax^2 + bx + c, \qquad a \ne 0,f(x)=ax2+bx+c,a=0,

where aaa, bbb, and ccc are real constants: aaa is the leading coefficient, bbb the linear coefficient, and ccc the constant term. Squaring, multiplying by a constant, and adding accept every real input, so the domain is all real numbers. The graph of a quadratic function is called a parabola.

The condition a≠0a \ne 0a=0 is not decoration. Set a=0a = 0a=0 and the rule collapses to f(x)=bx+cf(x) = bx + cf(x)=bx+c: if b≠0b \ne 0b=0 that is a straight, tilted line, with no bend, no highest or lowest point, and no vertical mirror; if b=0b = 0b=0 too, it is a flat horizontal line. Either way, the bend that makes a parabola a parabola is gone. Everything this chapter studies lives in the x2x^2x2 term. The other two coefficients are optional in a way aaa is not: f(x)=x2f(x) = x^2f(x)=x2 has b=c=0b = c = 0b=c=0 and is still the most important quadratic of all.

There is a precise sense in which quadratics are the simplest functions after linear ones. A linear function changes by equal amounts over equal steps: each step of 111 in the input adds the same bbb to the output. For f(x)=x2f(x) = x^2f(x)=x2 the outputs at x=0,1,2,3,4x = 0, 1, 2, 3, 4x=0,1,2,3,4 are 0,1,4,9,160, 1, 4, 9, 160,1,4,9,16, and the jumps between them are 1,3,5,71, 3, 5, 71,3,5,7: not constant, but growing by the same 222 each time. That is no accident of these five values, because

(x+1)2−x2=2x+1,(x + 1)^2 - x^2 = 2x + 1,(x+1)2−x2=2x+1,

so the jump is itself a linear function of xxx. The same computation on a general quadratic gives f(x+1)−f(x)=2ax+a+bf(x + 1) - f(x) = 2ax + a + bf(x+1)−f(x)=2ax+a+b, again linear. A linear function has constant jumps; a quadratic has linear jumps. Quadratics are what you get when you let the rate of change itself change, but only in the plainest possible way. The steady growth of those jumps is exactly the bend you see in a parabola.

One more piece of vocabulary before we begin. This lesson is about the quadratic function, the input-output object with a graph. Asking which inputs produce one prescribed output, that is, solving a quadratic equation, begins in the next lesson. Today we learn everything a parabola will tell us without solving anything.

The parent of every parabola

Transformations of Graphs had one message: complicated graphs are simple graphs moved around, and everything about the copy is readable from the original plus the move. For parabolas the original is p(x)=x2p(x) = x^2p(x)=x2, the parent parabola, so before transforming it you should know it completely.

Three properties of the parent parabola#

Write p(x)=x2p(x) = x^2p(x)=x2.

It is symmetric across the yyy-axis. For every input, p(−x)=(−x)2=x2=p(x)p(-x) = (-x)^2 = x^2 = p(x)p(−x)=(−x)2=x2=p(x): reflecting the input changes no output. In the language of Transformations of Graphs, the inside reflection x↦−xx \mapsto -xx↦−x is a transformation that does nothing to this graph. Consequently the yyy-axis is a mirror line of the parabola, and ppp is an even function.

Its lowest point is the origin. A square is never negative: if x≥0x \ge 0x≥0 then x⋅x≥0x \cdot x \ge 0x⋅x≥0, and if x<0x < 0x<0 then x⋅xx \cdot xx⋅x is a product of two negative numbers, hence positive. So p(x)≥0=p(0)p(x) \ge 0 = p(0)p(x)≥0=p(0) for every xxx, with equality exactly when x=0x = 0x=0. The point (0,0)(0, 0)(0,0) is on the graph and nothing on the graph is lower. This turning point is the vertex, and it sits on the mirror line.

Its range is [0,∞)[0, \infty)[0,∞), and heights rise steadily away from the vertex. No negative number is an output, and every c≥0c \ge 0c≥0 is one, since p(c)=cp(\sqrt{c}) = cp(c​)=c. Moreover, if 0≤s<t0 \le s < t0≤s<t then t2−s2=(t−s)(t+s)>0t^2 - s^2 = (t - s)(t + s) > 0t2−s2=(t−s)(t+s)>0, so on the right half of the parabola the heights increase strictly. By the mirror symmetry established above, the heights increase equally strictly as you move leftward from the vertex. Each positive height is therefore reached exactly once on each side of the mirror, a small fact that will carry this lesson’s main theorem.

∎

Vertex form is a transformation in disguise

Now dress the parent. Take constants a≠0a \ne 0a=0, hhh, and kkk, and build

The claim worth testing here is the one this section makes about the range. What standard form shows at a glance

Multiply a vertex form out and you always land back in standard form: expanding a(x−h)2+ka(x - h)^2 + ka(x−h)2+k gives ax2−2ahx+(ah2+k)ax^2 - 2ahx + (ah^2 + k)ax2−2ahx+(ah2+k), an ax2+bx+cax^2 + bx + cax2+bx+c. Standard form is the costume quadratics usually arrive in, so it is worth knowing exactly what it offers for free, and what it hides.

Two features are free. First, the yyy-intercept: f(0)=a⋅0+b⋅0+c=cf(0) = a \cdot 0 + b \cdot 0 + c = cf(0)=a⋅0+b⋅0+c=c, so the graph crosses the yyy-axis at height ccc, no work required. Second, the end behavior. For x≠0x \ne 0x=0, factor out the highest power, exactly as the Graphs of Functions lesson taught:

f(x)=x2(a+bx+cx2).f(x) = x^2\left(a + \frac{b}{x} + \frac{c}{x^2}\right).f(x)=x2(a+xb​+x2c​).

Far from the origin the fractions bx\tfrac{b}{x}xb​ and cx2\tfrac{c}{x^2}x2c​ shrink toward 000, so the bracket gets closer and closer to aaa while x2x^2x2 is enormous and positive. The outputs therefore take the sign of aaa and grow without bound: when a>0a > 0a>0 both ends of the parabola point up, and when a<0a < 0a<0 both ends point down. One sign settles the whole large-scale picture.

What standard form hides is everything about the middle: where the turning point sits, how low or high the graph reaches, whether it ever meets the xxx-axis. The vertex is simply not visible in ax2+bx+cax^2 + bx + cax2+bx+c. The surprise of the next section is that symmetry digs it out anyway.

The axis of symmetry, from symmetry alone

Every parabola you have ever drawn has an evident vertical mirror, and for vertex form we just proved it: the mirror is x=hx = hx=h. But a quadratic handed to you as f(x)=ax2+bx+cf(x) = ax^2 + bx + cf(x)=ax2+bx+c names no hhh. Later in this chapter, Completing the Square converts standard form into vertex form outright. Remarkably, you do not have to wait for it: two cheap evaluations and one symmetry principle locate the mirror exactly.

Two inputs that must share an output#

Let f(x)=ax2+bx+cf(x) = ax^2 + bx + cf(x)=ax2+bx+c with a≠0a \ne 0a=0, and suppose for the moment that b≠0b \ne 0b=0.

Factored form shows the zeros: substituting x=r1x = r_1x=r1​ or x=r2x = r_2x=r2​ makes a factor vanish, so f(r1)=f(r2)=0f(r_1) = f(r_2) = 0f(r1​)=f(r2​)=0 and the graph meets the xxx-axis at exactly those inputs. Reading zeros off a factored form that is handed to you is mere evaluation; producing the factored form yourself is the next lesson’s work. Factored form also controls the sign of fff between and beyond the zeros, which is what Quadratic Inequalities will exploit.

The three forms are not equally available. Every quadratic has a standard form, and Completing the Square will prove every quadratic has a vertex form. But the factored form exists over the real numbers only when the parabola actually meets the xxx-axis. A parabola that opens upward with its vertex above the axis, such as one with range [4,∞)[4, \infty)[4,∞), never reaches height 000. Such a parabola has no real zeros, and that is a complete, honest answer. The Quadratic Formula lesson builds the discriminant, the single number that decides in advance which situation you are in. And chapter 5 enlarges the number system so that the equation ax2+bx+c=0ax^2 + bx + c = 0ax2+bx+c=0 still has solutions in that case, even though the graph itself never crosses the xxx-axis.

Notice also what symmetry says about factored form: the two zeros are a pair of inputs sharing the output 000, so the axis of symmetry must cut their midpoint, x=r1+r22x = \tfrac{r_1 + r_2}{2}x=2r1​+r2​​. Read backward, the coefficients remember the zeros, which is the seed of the Sum and Product of Roots lesson closing this chapter.

The rest of this chapter turns these forms into each other: factoring and completing the square each convert standard form into one of the others, and the quadratic formula runs that second conversion once, for every quadratic, which is why it is a theorem rather than a recipe.

Common mistakes

Common mistakes

  • Reading hhh with the wrong sign. y=(x+4)2−1y = (x + 4)^2 - 1y=(x+4)2−1 matches the template as x−(−4)x - (-4)x−(−4), so its vertex is (−4,−1)(-4, -1)(−4,−1), not (4,−1)(4, -1)(4,−1). Inside changes run backward, exactly as in Transformations of Graphs.
  • Calling ccc the vertex height. ccc is the yyy-intercept, the output at 000. The vertex height is f(−b2a)f\left(-\tfrac{b}{2a}\right)f(−2ab​), a different number unless b=0b = 0b=0.
  • Dropping a sign in x=−b2ax = -\tfrac{b}{2a}x=−2ab​. For f(x)=2x2−8x+3f(x) = 2x^2 - 8x + 3f(x)=2x2−8x+3 the coefficient is b=−8b = -8b=−8, so the axis is x=−−84=2x = -\tfrac{-8}{4} = 2x=−4−8​=2: the formula’s minus and the coefficient’s minus both count.
  • Claiming the range is all real numbers. A quadratic’s outputs are bounded on one side, [k,∞)[k, \infty)[k,∞) or (−∞,k](-\infty, k](−∞,k]. Only the domain is all reals.
  • Assuming every parabola crosses the xxx-axis. A parabola opening upward with vertex above the axis never meets it: no real zeros. Two, one, or zero meeting points are all possible.
  • Treating a=0a = 0a=0 as a quadratic. f(x)=0⋅x2+3x−1f(x) = 0 \cdot x^2 + 3x - 1f(x)=0⋅x2+3x−1 is linear, and every statement in this chapter presumes the x2x^2x2 term is really there.
  • Letting the sign of aaa move the graph up or down. The sign of aaa chooses which way the parabola opens and which end of the range is closed. Vertical position is the business of kkk, or of ccc at the intercept.

Key takeaways

  • A quadratic function is f(x)=ax2+bx+cf(x) = ax^2 + bx + cf(x)=ax2+bx+c with a≠0a \ne 0a=0; its graph is a parabola and its domain is all real numbers. Its jumps f(x+1)−f(x)=2ax+a+bf(x + 1) - f(x) = 2ax + a + bf(x+1)−f(x)=2ax+a+b are linear, making quadratics the simplest non-linear polynomials.
  • The parent y=x2y = x^2y=x2 is even, has vertex (0,0)(0, 0)(0,0), and has range [0,∞)[0, \infty)[0,∞), with heights rising strictly on each side of the mirror.
  • Vertex form a(x−h)2+ka(x - h)^2 + ka(x−h)2+k is the parent transformed: vertex (h,k)(h, k)(h,k), axis x=hx = hx=h, range [k,∞)[k, \infty)[k,∞) for a>0a > 0a>0 and (−∞,k](-\infty, k](−∞,k] for a<0a < 0a<0, all with no computation.
  • Standard form shows the yyy-intercept c=f(0)c = f(0)c=f(0) and the end behavior at sight: both ends up when a>0a > 0a>0, both down when a<0a < 0a<0.
  • The axis from standard form is x=−b2ax = -\tfrac{b}{2a}x=−2ab​, found by symmetry: f(0)=f(−ba)=cf(0) = f\left(-\tfrac{b}{a}\right) = cf(0)=f(−ab​)=c, so the mirror stands midway between those inputs. Evaluating fff there gives the vertex and the range.
  • Factored form a(x−r1)(x−r2)a(x - r_1)(x - r_2)a(x−r1​)(x−r2​) displays the zeros, and the axis bisects them at x=r1+r22x = \tfrac{r_1 + r_2}{2}x=2r1​+r2​​; over the reals this form exists only when the parabola meets the xxx-axis.
  • Standard, vertex, and factored form all describe the same function, and aaa is shared by every one of them. The rest of this chapter is about converting between them.

A bit of history (optional)

For centuries, ships at sea steered by books of numbers, and those books were full of mistakes.

Tables of logarithms and star positions were computed by hand, copied by hand, then set in type by hand. Each of those stages could drop a digit. A dropped digit could put a vessel on a reef. In 1822 the English mathematician Charles Babbage proposed the obvious cure. Build a machine that calculates the table and prints it, so that no human hand ever touches a number.

His design turns on a fact this lesson opened with. List the squares 0,1,4,9,160, 1, 4, 9, 160,1,4,9,16 and look at the gaps between them: 1,3,5,71, 3, 5, 71,3,5,7. The outputs do not climb evenly, but the gaps do, rising by a constant 222 at every step. So the next square is two additions away, with no multiplication anywhere, and the same trick walks a table of any quadratic forward forever.

That is the whole principle of the machine he called the Difference Engine, and it is also why a quadratic is the simplest curve that bends. A linear function has constant jumps. A quadratic has jumps that are themselves linear, so the jumps between its jumps settle down to a single number. Babbage never finished building it. A working engine was assembled from his drawings in 1991, and it does its arithmetic exactly the way you did yours.
