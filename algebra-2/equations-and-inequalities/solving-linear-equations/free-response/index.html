    1. Two moves, one guarantee . Foundational, 11 points. Question 1 of 5.

    Foundational 11 pts

    This lesson calls one operation always safe and another safe everywhere except at a single number. This question checks both claims, one on a plain constant and the other on an equation built with a variable denominator, to see exactly where the second guarantee runs out and whether that matters here.

    1. A
      Part A.

      Multiplying both sides of an equation by −9-9−9 is one of the two moves this lesson calls always safe. Say which operation undoes it, and explain in one or two sentences why the guarantee never fails, whatever equation it is applied to.

      Justify your claim State the claim, then give the reason it has to be true. 3 points

    2. B
      Part B.

      Solve 3x+2x+8=−4x+8\dfrac{3x+2}{x+8} = \dfrac{-4}{x+8}x+83x+2​=x+8−4​ by multiplying both sides by x+8x+8x+8. Report the value that must be excluded from the domain before you clear anything, the candidate the cleared equation produces, and whether that candidate still needs to be checked against the excluded value before it can be reported as a solution.

      Solve and show your work Write each step out, and end with the value and its units. 4 points

    3. C
      Part C.

      Explain why the multiplication used in part B is reversible at every value except the excluded value found there, and use that reasoning to decide whether the candidate from part B is a genuine solution of the original equation or must be discarded.

      Carry your own answer forward Use the excluded value and the candidate you found in part B, whatever they turned out to be, and reason from where the multiplication stops being reversible relative to your own candidate.

      Justify your claim State the claim, then give the reason it has to be true. 4 points

    The answer

    Part A

    Dividing both sides by −9-9−9 undoes it. The guarantee never fails because −9-9−9 is a fixed nonzero number for every equation, so the reverse division is always legal.

    Part B

    Excluded value x=−8x = -8x=−8; the cleared equation gives the candidate x=−2x = -2x=−2.

    Part C

    Reversible for every x≠−8x \neq -8x=−8, since dividing back by x+8x+8x+8 undoes it there; it only fails at x=−8x=-8x=−8. The candidate from part B is not that excluded value, so it genuinely solves the original equation.

    Worked solution

    Part A

    Multiplying both sides by −9-9−9 is undone by dividing both sides by −9-9−9.

    −9⋅A=−9⋅B⟹−9A−9=−9B−9-9 \cdot A = -9 \cdot B \quad\Longrightarrow\quad \dfrac{-9A}{-9} = \dfrac{-9B}{-9}−9⋅A=−9⋅B⟹−9−9A​=−9−9B​

    Because −9-9−9 never changes and is never zero, that division is legal no matter which equation the multiplication started from, so every solution that survives the multiplication survives the division straight back. Nothing about the equation itself, its degree, or its variable ever affects this: the number multiplied by is fixed in advance and it is not zero, and that is the entire guarantee.

    Part B

    The denominator x+8x+8x+8 is zero at x=−8x=-8x=−8, so that value is excluded before any clearing.

    Multiply both sides by x+8x+8x+8; the denominator cancels on each side.

    3x+2=−43x + 2 = -43x+2=−4

    Solve the resulting linear equation.

    3x=−6,x=−2.3x = -6, \qquad x = -2.3x=−6,x=−2.

    The one candidate is x=−2x=-2x=−2.

    Part C

    Multiplying both sides by x+8x+8x+8 is undone by dividing both sides by x+8x+8x+8, and that division is legal at every xxx for which x+8≠0x+8 \neq 0x+8=0, that is every x≠−8x \neq -8x=−8.

    (x+8)≠0  ⟺  x≠−8(x+8) \neq 0 \iff x \neq -8(x+8)=0⟺x=−8

    At every such xxx the step is reversible, so it cannot add or lose a solution there: whatever satisfied the original equation still satisfies the cleared one, and whatever satisfies the cleared one still satisfies the original.

    The candidate found in part B is x=−2x=-2x=−2, and −2≠−8-2 \neq -8−2=−8, so it falls exactly among the values where the step is trustworthy. Nothing about the reasoning above depended on how the numbers 333, 222, and −4-4−4 were chosen, only on the fact that the multiplier x+8x+8x+8 is not zero there. So x=−2x=-2x=−2 is a genuine solution of the original equation, not a number that only appears to solve it because the denominators were cleared.

    In one line

    Dividing by −9-9−9 undoes multiplying by it, and the guarantee holds because −9-9−9 is fixed and nonzero, whatever equation it multiplies. In 3x+2x+8=−4x+8\dfrac{3x+2}{x+8} = \dfrac{-4}{x+8}x+83x+2​=x+8−4​, the excluded value is x=−8x=-8x=−8 and clearing the denominator gives the candidate x=−2x=-2x=−2.     Hints

    Answer and solution

    The answer

    Part A

    The equation reduces to 0x=00x = 00x=0; the solution set is R\mathbb{R}R.

    Part B

    The equation reduces to the false statement −8=5-8 = 5−8=5; the solution set is ∅\varnothing∅.

    Part C

    Every linear equation reduces to ax=bax=bax=b. If a≠0a \neq 0a=0 there is exactly one solution b/ab/ab/a; if a=0a=0a=0 the equation is entirely constant, giving every real number when b=0b=0b=0 or none when b≠0b \neq 0b=0. No branch produces exactly two solutions, and the changed constant is exactly what moves bbb between those branches.

    Worked solution

    Part A

    Distribute and combine like terms on the left.

    8(x−1)−2x=8x−8−2x=6x−88(x-1) - 2x = 8x - 8 - 2x = 6x - 88(x−1)−2x=8x−8−2x=6x−8

    The equation now reads 6x−8=6x−86x - 8 = 6x - 86x−8=6x−8. Subtract 6x6x6x from both sides.

    −8=−8-8 = -8−8=−8

    That is true for every xxx, so the reduced form is 0x=00x = 00x=0 and the equation is an identity: the solution set is R\mathbb{R}R.

    Part B

    Distribute and combine like terms on the left exactly as before.

    8(x−1)−2x=6x−88(x-1) - 2x = 6x - 88(x−1)−2x=6x−8

    The equation now reads 6x−8=6x+56x - 8 = 6x + 56x−8=6x+5. Subtract 6x6x6x from both sides.

    −8=5-8 = 5−8=5

    That is false for every xxx, so the equation is a contradiction and the solution set is ∅\varnothing∅.

    Part C

    Every linear equation reachable by distributing and combining like terms reduces to the form ax=bax=bax=b for fixed numbers aaa and bbb, exactly as parts A and B did.

    If a≠0a \neq 0a=0, dividing both sides by aaa is legal and gives

    x=ba,x = \dfrac{b}{a},x=ab​,

    a single number, so the solution set has exactly one member.

    If a=0a = 0a=0, the equation reads 0⋅x=b0 \cdot x = b0⋅x=b, which is really just the numeric statement 0=b0 = b0=b with no xxx left in it at all. Either b=0b = 0b=0, in which case the statement is true for every real number and the solution set is R\mathbb{R}R, or b≠0b \neq 0b=0, in which case the statement is false for every real number and the solution set is ∅\varnothing∅.

    Those are the only two possibilities once a=0a=0a=0, and together with the single-solution case they exhaust every value aaa could take: aaa is either zero or it is not, with nothing in between. A solution set of exactly one member, or of every real number, or of none, are the only outcomes this covers, and none of them has exactly two members.

    a=0, b=0 ⇒ R,a=0, b=13 ⇒ ∅a = 0,\ b = 0 \ \Rightarrow\ \mathbb{R}, \qquad a = 0,\ b = 13 \ \Rightarrow\ \varnothinga=0, b=0 ⇒ R,a=0, b=13 ⇒ ∅

    That is why part A, where the constants reduced to a=0a=0a=0 and b=0b=0b=0, gave every real number, while part B, where they reduced to a=0a=0a=0 and b=13b=13b=13, gave none. The left side never changed between the two parts, so the coefficient aaa stayed fixed at 000 in both; only the constant on the right did, and once a=0a=0a=0 is already fixed, that single changed constant is exactly what decides between the two branches still available, the identity and the contradiction outcomes, since the variable term has already canceled.

    In one line

    8(x−1)−2x=6x−88(x-1)-2x = 6x-88(x−1)−2x=6x−8 reduces to 0x=00x=00x=0, an identity with solution set R\mathbb{R}R. Changing only the right side to 6x+56x+56x+5 reduces instead to the false statement 0x=130x=130x=13, a contradiction with solution set ∅\varnothing∅. Every linear equation reduces to ax=bax=bax=b: exactly one solution when a≠0a \neq 0a=0, all of R\mathbb{R}R when a=b=0a=b=0a=b=0, and ∅\varnothing∅ when a=0a=0a=0, b≠0b \neq 0b=0; those three exhaust every case, so no linear equation can have a solution set of exactly two numbers.

    The answer

    Part A

    Excluded: x=−1x=-1x=−1 and x=3x=3x=3, since each makes one of the two denominators zero.

    Part B

    The cleared equation gives x=−9x=-9x=−9, which is not on the excluded list, so it is a genuine solution.

    Worked solution

    Part A

    A fraction is undefined exactly where its denominator is zero, so set each denominator to zero on its own.

    x+1=0 ⇒ x=−1,x−3=0 ⇒ x=3x + 1 = 0 \ \Rightarrow\ x = -1, \qquad x - 3 = 0 \ \Rightarrow\ x = 3x+1=0 ⇒ x=−1,x−3=0 ⇒ x=3

    Both x=−1x=-1x=−1 and x=3x=3x=3 are excluded from the domain before any clearing takes place: at x=−1x=-1x=−1 the left side 4x+1\frac{4}{x+1}x+14​ is undefined, and at x=3x=3x=3 the right side 6x−3\frac{6}{x-3}x−36​ is undefined, so at each of these two values the equation as a whole has no comparison to make.

    Part B

    Multiply both sides by (x+1)(x−3)(x+1)(x-3)(x+1)(x−3); each denominator cancels against its own factor.

    4(x−3)=6(x+1)4(x-3) = 6(x+1)4(x−3)=6(x+1)

    Distribute and collect the variable on one side.

    4x−12=6x+6,−18=2x,x=−9.4x - 12 = 6x + 6, \qquad -18 = 2x, \qquad x = -9.4x−12=6x+6,−18=2x,x=−9.

    The value x=−9x=-9x=−9 does not appear on the excluded list {−1,3}\{-1, 3\}{−1,3} from part A, so nothing rules it out. Checking in the original equation, the left side is 4−9+1=−12\dfrac{4}{-9+1} = -\dfrac{1}{2}−9+14​=−21​ and the right side is 6−9−3=−12\dfrac{6}{-9-3} = -\dfrac{1}{2}−9−36​=−21​, which agree, so x=−9x=-9x=−9 is a genuine solution and the solution set is {−9}\{-9\}{−9}.

    Part C

    The excluded values found in part A, x=−1x=-1x=−1 and x=3x=3x=3, do not depend on which numbers sit in the numerators; they come only from where the two denominators x+1x+1x+1 and x−3x-3x−3 are zero, which never changes across equations sharing those denominators.

    If clearing produced the single candidate x=−1x=-1x=−1, that candidate would be exactly one of the excluded values. A candidate on the excluded list is never a solution of the original equation, however cleanly it emerged from the cleared one, because the original is undefined there. This hypothetical stipulates that clearing produces exactly that one candidate (a cleared linear equation need not always land on a single candidate; the previous question's pair showed a cleared equation can instead be an identity or a contradiction), so here, once the single candidate x=−1x=-1x=−1 is discarded, there is nothing left to replace it with.

    x=−1∈{−1,3} ⇒ discardedx = -1 \in \{-1, 3\} \ \Rightarrow\ \text{discarded}x=−1∈{−1,3} ⇒ discarded

    The solution set of that equation would therefore be ∅\varnothing∅, for the same reason the opening example of this lesson had none: the one number the algebra points to is precisely the number the domain forbids.

    Part A

    Substitute x=−6x=-6x=−6 into the original equation and evaluate the denominator on each side.

    x+6=−6+6=0x + 6 = -6 + 6 = 0x+6=−6+6=0

    Nothing is wrong with solving 2x+7=−52x+7=-52x+7=−5; that gives x=−6x=-6x=−6 correctly, and no arithmetic anywhere in the student's work is mistaken.

    Part C

    The cleared equation 2x+7=−52x+7=-52x+7=−5 gives the single candidate x=−6x=-6x=−6.

    2x+7=−5⟹x=−62x + 7 = -5 \quad\Longrightarrow\quad x = -62x+7=−5⟹x=−6

    The check that settles this in general needs nothing beyond what parts A and B already used. Whenever a step clears a denominator by multiplying by an expression that can be zero, list the values making that expression zero before solving, then compare every candidate the cleared equation produces against that list. A candidate that appears on the list is extraneous and must be discarded however cleanly the arithmetic that produced it. A candidate that does not appear on the list still has to be confirmed in the equation as originally written, since the check that matters is always the original, never a line written after the denominators were cleared.
