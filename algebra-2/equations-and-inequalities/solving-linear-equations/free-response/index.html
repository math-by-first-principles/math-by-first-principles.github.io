  1. Problem 1 Testing a ticket

    A number ticket shows −2-2−2. Does it satisfy x−13+2=1\frac{x-1}{3}+2=13x−1​+2=1?

    1. Hint 1

      An equation accepts a number when both sides have the same value.

    2. Hint 2

      Replace the entire x−1x-1x−1 by −2−1-2-1−2−1 before dividing.

    Answer

    Yes.

    Full solution

    Substitute the ticket value into the left side.

    −2−13+2=−1+2=1\begin{aligned}\frac{-2-1}{3}+2&=-1+2\\&=1\end{aligned}3−2−1​+2​=−1+2=1​

    The right side is also 111, so the ticket satisfies the equation.

    Answer

    Yes.

    Key idea

    Test a proposed solution by evaluating both sides of the original equation.

  3. Problem 3 The folded expression

    Classify 2[3x−(x−4)]=4(x+2)2[3x-(x-4)]=4(x+2)2[3x−(x−4)]=4(x+2) as conditional, an identity, or a contradiction.

    1. Hint 1

      Compare the simplified expressions before trying to isolate a number.

    2. Hint 2

      First simplify 3x−(x−4)3x-(x-4)3x−(x−4), including the sign before the parentheses.

    Answer

    Identity; solution set R\mathbb RR.

    Full solution

    Simplifying the left side gives

    2[3x−(x−4)]=2(2x+4)=4x+8\begin{aligned}2[3x-(x-4)]&=2(2x+4)\\&=4x+8\end{aligned}2[3x−(x−4)]​=2(2x+4)=4x+8​

    The right side also expands to 4x+84x+84x+8.

    Subtracting it from both sides leaves 0=00=00=0, so every real number works.

    Answer

    Identity; solution set R\mathbb RR.

    Key idea

    An identity can be hidden by different arrangements of the same expression.

  4. Problem 4 Two packing records

    Two records describe the same number of cards. One says three packets of xxx cards plus four loose cards. The other says two packets of x+5x+5x+5 cards minus three damaged cards. Find xxx and check that it is a possible whole-number packet size.

    1. Hint 1

      The two records count the same total.

    2. Hint 2

      Translate the first record as 3x+43x+43x+4 and expand the second total.

    Answer

    x=3x=3x=3 cards per packet; both records give 131313 cards.

    Full solution

    Equate the recorded totals.

    3x+4=2(x+5)−33x+4=2x+7x=3\begin{aligned}3x+4&=2(x+5)-3\\3x+4&=2x+7\\x&=3\end{aligned}3x+43x+4x​=2(x+5)−3=2x+7=3​

    Three is a positive whole number.

    The first total is 3(3)+4=133(3)+4=133(3)+4=13 cards and the second is 2(3+5)−3=132(3+5)-3=132(3+5)−3=13 cards.

    Answer

    x=3x=3x=3 cards per packet; both records give 131313 cards.

    Key idea

    Two descriptions of one total produce an equation whose solution must also fit the context.

  5. Problem 5 A ratio balance

  6. Problem 6 A missing entry

    A balance record reads 5(x−2)+7=2(x+1)+3x+c5(x-2)+7=2(x+1)+3x+c5(x−2)+7=2(x+1)+3x+c, where ccc is a fixed real number. Find the value of ccc that makes the record true for every real xxx.

    1. Hint 1

      An identity must have matching constants as well as matching variable terms.

    2. Hint 2

      Expand both sides and compare what remains after subtracting 5x5x5x.

    Answer

    c=−5c=-5c=−5.

    Full solution

    The two sides simplify as follows.

    5x−3=5x+2+c−3=2+cc=−5\begin{aligned}5x-3&=5x+2+c\\-3&=2+c\\c&=-5\end{aligned}5x−3−3c​=5x+2+c=2+c=−5​

    With this value both sides equal 5x−35x-35x−3 for every real xxx.

    Answer

    c=−5c=-5c=−5.

    Key idea

    When variable coefficients already match, matching the constants creates an identity.

  8. Problem 8 The same addition

    A solver adds x2+1x^2+1x2+1 to both sides of a linear equation and says the new equation has exactly the original solutions. Is that claim correct? Explain.

    1. Hint 1

      Judge the operation by its effect on the solution set, not by how complicated it looks.

    2. Hint 2

      Ask whether the added expression exists for every real input and can be subtracted back.

    Answer

    Yes, the equations are equivalent.

    Full solution

    The expression x2+1x^2+1x2+1 is defined for every real xxx.

    If the original sides are LLL and RRR, the new equation is

    L+(x2+1)=R+(x2+1).L+(x^2+1)=R+(x^2+1).L+(x2+1)=R+(x2+1).

    Subtracting x2+1x^2+1x2+1 from both sides restores L=RL=RL=R.

    Both steps preserve equality, so neither gains nor loses a solution.

    Answer

    Yes, the equations are equivalent.

    Key idea

    Adding an expression defined throughout the domain preserves the solution set even if the written equation looks more complicated.

  9. Problem 9 Two identical stamps

    A solver multiplies both sides of x+3=8x+3=8x+3=8 by x−5x-5x−5 and says that every multiplication by a variable expression must introduce an extra solution. Decide whether that happened here and explain.

    1. Hint 1

      The zero of the multiplier is the only place a new solution could appear.

    2. Hint 2

      Compare that zero with the solution of the original equation.

    Answer

    No extra solution; both equations have solution set {5}\{5\}{5}.

    Full solution

    The original gives x=5x=5x=5.

    The multiplied equation reduces to

    (x+3)(x−5)=8(x−5)(x−5)2=0\begin{aligned}(x+3)(x-5)&=8(x-5)\\(x-5)^2&=0\end{aligned}(x+3)(x−5)(x−5)2​=8(x−5)=0​

    This also holds exactly at x=5x=5x=5.

    The multiplier vanishes at a value that was already a solution, so this particular step adds nothing.

    It has no general guarantee of safety.

    Answer

    No extra solution; both equations have solution set {5}\{5\}{5}.

    Key idea

    A step that can add solutions does not necessarily add one in every equation.

  10. Problem 10 A fractional report

    The equation x+1x+1=2x+22x+2\frac{x+1}{x+1}=\frac{2x+2}{2x+2}x+1x+1​=2x+22x+2​ is reported as true for every real xxx. Is the report accurate? Give the exact solution set and explain.

    1. Hint 1

      An input must belong to the original domain before it can satisfy the equation.

    2. Hint 2

      Find where either denominator is zero, then compare the fractions elsewhere.

    Answer

    No; solution set R∖{−1}\mathbb R\setminus\{-1\}R∖{−1}.

    Full solution

    Both denominators vanish at x=−1x=-1x=−1, so exclude that value.

    For every other real input, each numerator equals its denominator.

    x+1x+1=1\frac{x+1}{x+1}=1x+1x+1​=1

    The other fraction is also 111, so every allowed input solves the equation.

    It is an identity on its domain, which omits −1-1−1.

    Answer

    No; solution set R∖{−1}\mathbb R\setminus\{-1\}R∖{−1}.

    Key idea

    A canceled fraction retains the domain restriction of its original denominator.
