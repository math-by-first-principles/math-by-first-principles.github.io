Solving Linear Equations

Intuition

You can already solve 3x+5=173x + 5 = 173x+5=17 in your sleep: subtract 555, divide by 333, and out comes x=4x = 4x=4. So why give solving a whole lesson of its own? Because no one ever told you why those moves deserve to be trusted, or what exactly they protect. Watch what happens when the protection fails. The equation xx−2=2x−2\frac{x}{x-2} = \frac{2}{x-2}x−2x​=x−22​ looks harmless, and multiplying both sides by x−2x - 2x−2 gives x=2x = 2x=2. But x=2x = 2x=2 makes the original denominators zero, so it is not a solution at all. Somewhere in that one clean step, a lie crept in. This lesson is about what solving really does (it tracks a set of numbers), which steps keep that set honest, and which steps quietly corrupt it.

Learning goals

  • Treat an equation as a condition each number passes or fails
  • Classify it as conditional, an identity, or a contradiction
  • Distinguish a reversible step from one needing a check
  • Reduce every linear equation to ax=bax = bax=b
  • List excluded values before clearing denominators

An equation is a condition, not a statement

Read 3x+5=173x + 5 = 173x+5=17 literally and it looks like a claim: three times something, plus five, equals seventeen. But the something is unknown, so the claim is not yet true or false. It becomes a definite claim only once you choose a value for xxx. Put x=4x = 4x=4 into it and you get 17=1717 = 1717=17, which is true. Put x=1x = 1x=1 into it and you get 8=178 = 178=17, which is false. An equation in xxx is therefore not a single statement at all. It is a condition on xxx, a test that each number where the equation is defined either passes or fails. Every equation in this lesson is defined for all real numbers until fractions with xxx in a denominator show up later on, so for now “each number where it is defined” simply means “each real number.” Once denominators enter, that phrase will start to matter.

The numbers that pass are the only thing solving is ever after. The solution set of an equation is the set of all numbers, from wherever it is defined, that make it true. We write it with set braces, so the solution set of 3x+5=173x + 5 = 173x+5=17 is {4}\{4\}{4}, the set whose only member is 444. Two symbols will recur. The symbol R\mathbb{R}R stands for the set of all real numbers, every number on the number line. The symbol ∅\varnothing∅ stands for the empty set, the set with no members at all, which is what we write when nothing passes the test.

Sorting equations by their solution set gives exactly three kinds.

An equation is conditional when it is true for some values in its domain but not others, so its solution set is neither empty nor the whole domain. Every equation you ever solved for a numerical answer was conditional. For instance 3x+5=173x + 5 = 173x+5=17 is conditional, with solution set {4}\{4\}{4}.

An equation is an identity when it is true for every value in its domain, so its solution set is the whole domain. For an equation defined everywhere, that means solution set R\mathbb{R}R: for instance 2(x+1)=2x+22(x + 1) = 2x + 22(x+1)=2x+2 holds no matter what xxx is, because the two sides are the same expression written two ways. Later in this lesson you will meet equations whose domain is missing a point, where being an identity means holding at every value the domain does include, not at that missing point.

An equation is a contradiction when it is true for no value in its domain, so its solution set is ∅\varnothing∅. For instance x=x+1x = x + 1x=x+1 can never hold, since a number cannot equal one more than itself.

This reframes what the word solve means. To solve an equation is to describe its solution set, not merely to “find xxx.” For a conditional equation with a single solution the two sound identical, and writing x=4x = 4x=4 is a fine shorthand for “the solution set is {4}\{4\}{4}.” But for an identity the honest answer is “every value in its domain” (which so far in this lesson means every real number, until denominators enter and shrink the domain), and for a contradiction it is “no solution, ∅\varnothing∅.” An equation with no single number to report still has an answer. The answer is a description of the set.

Equivalent equations and the one safe move

Solving works by replacing a hard equation with an easier one that has the same solution set, then repeating until the set can be read off at a glance. Two equations are equivalent when they have exactly the same solution set. The equation x=4x = 4x=4 is equivalent to 3x+5=173x + 5 = 173x+5=17 because both have solution set {4}\{4\}{4}. The whole job of solving is to travel from 3x+5=173x + 5 = 173x+5=17 to x=4x = 4x=4 through a chain of equivalent equations.

So the central question of this entire chapter is narrow and precise: which operations on an equation are guaranteed to produce an equivalent one? The answer is a single word, reversible. A step you can undo is guaranteed to produce an equivalent equation, and here is why that one word carries the guarantee.

Why a reversible step preserves the solution set#

Suppose an operation turns an equation AAA into an equation BBB, and suppose that same operation can be undone by a reverse step that turns BBB back into AAA. Take any solution sss of AAA. Doing the same thing to two equal numbers leaves them equal, so applying the operation keeps the equation true at sss, which means sss is also a solution of BBB. Every solution of AAA therefore survives into BBB.

Now run the reverse step. It turns BBB back into AAA by the same kind of move, so by the identical reasoning every solution of BBB is a solution of AAA. Neither equation has a solution the other lacks, so their solution sets are equal and the two equations are equivalent.

The reverse step did real work in that argument. Without it we could only conclude that every solution of AAA carries into BBB, and BBB might still carry extra solutions that AAA never had. Reversibility is exactly the guarantee that no extras appear and that nothing is left behind.

∎

Two familiar moves are reversible for every real number, so both are always safe. Adding the same quantity to both sides is undone by subtracting it, as long as the quantity is defined for every xxx. Adding a constant like 555, or a whole expression like 3x3x3x, is fine, because 555 and 3x3x3x are defined for every real number and can be subtracted straight back. (Adding something like 1x\frac{1}{x}x1​ would not qualify, since it is undefined at x=0x = 0x=0.) Multiplying both sides by the same nonzero constant is undone by dividing by it, and dividing by a nonzero constant is undone by multiplying. The word nonzero is the whole point: multiplying both sides by 000 turns every equation into 0=00 = 00=0, which is true for all xxx. The new equation 0=00 = 00=0 keeps no record of where you started, so the step cannot be reversed.

The trouble starts when the thing you multiply or divide by is not a constant but an expression that can equal zero. Then the step is reversible for most values of xxx but not all, and the exceptions are exactly the solutions that get gained or lost.

Multiplying both sides by an expression that can be zero can add solutions. Multiply both sides of an equation by x−2x - 2x−2. Wherever x−2≠0x - 2 \neq 0x−2=0 the step is reversible, since you can divide by x−2x - 2x−2 to undo it, so those solutions stay safe. But at x=2x = 2x=2 the multiplier is zero, and the new equation reads 0=00 = 00=0 there whether or not x=2x = 2x=2 solved the original. So x=2x = 2x=2 can slip into the new solution set without belonging to the old one. A value that solves the new equation but not the original is called extraneous, and it is always found among the zeros of whatever you multiplied by.

Dividing both sides by an expression that can be zero can destroy solutions. Consider x2=xx^2 = xx2=x. Its solution set is {0,1}\{0, 1\}{0,1}, because x2=xx^2 = xx2=x means x2−x=0x^2 - x = 0x2−x=0, that is x(x−1)=0x(x - 1) = 0x(x−1)=0, which holds exactly when x=0x = 0x=0 or x=1x = 1x=1. Now divide both sides of x2=xx^2 = xx2=x by xxx. You get x=1x = 1x=1, whose solution set is just {1}\{1\}{1}. The solution x=0x = 0x=0 has vanished, and no wonder: dividing by xxx is legal only when x≠0x \neq 0x=0, so the step quietly threw away the very value it could not handle. A solution removed by an illegal step is a lost solution.

A reversible step always preserves the solution set exactly, which is the guarantee just proved. A step you cannot undo is not automatically wrong; it is merely not guaranteed to be safe. That missing guarantee is why a step that might add extra solutions needs its candidates checked against the original equation at the end rather than trusted. A step that might lose a solution needs a different fix, since a lost solution never shows up as a candidate to check in the first place. When a step you cannot undo does change the solution set, there are only two ways the set can change, and they are mirror images. Multiplying by something that is zero at a point, where the inverse fails, can add an extraneous solution there. Dividing by something that is zero at a point, where the step itself is illegal, can lose a solution there. Added roots and lost roots are the only changes a step can make, so every safe-solving rule you meet is really a way of ruling one of them out.

Check your understanding

A student solves x2=4xx^2 = 4xx2=4x by dividing both sides by xxx, gets x=4x = 4x=4, and reports that as the only solution. Which solution did that step destroy?

Answer choices

Never divide by a quantity that can be zero. Move everything to one side and factor instead.

x2−4x=0⇒x(x−4)=0x^2 - 4x = 0 \quad\Rightarrow\quad x(x - 4) = 0x2−4x=0⇒x(x−4)=0

The product is zero when x=0x = 0x=0 or x=4x = 4x=4, so the full solution set is {0,4}\{0, 4\}{0,4}. Dividing by xxx assumed x≠0x \neq 0x=0, which silently discarded x=0x = 0x=0.

Every linear equation becomes ax = b

A linear equation in one variable is one where the variable appears only to the first power on each side, never squared, never multiplied by itself, and never hidden inside a denominator or a root. Two different kinds of safe move turn every linear equation into the single form ax=bax = bax=b. Distributing across parentheses and combining like terms are rewrites of a single side: they replace an expression by an equal one, justified by the distributive law and by arithmetic. Both rewrites are safe because after the rewrite the two sides still name the same number for every xxx, so the solution set cannot change. Moving a variable term or a constant to the other side is the second kind. That move adds the same expression to both sides, a reversible operation of the sort proved safe above. Both kinds preserve the solution set, for these two different reasons. Whatever tangle you start with, they collect it into

ax=b,ax = b,ax=b,

where aaa and bbb are specific real numbers. This single form settles the equation completely, and there are exactly three cases according to whether aaa is zero.

The three cases of ax=bax = bax=b#

Start from ax=bax = bax=b with aaa and bbb fixed real numbers.

If a≠0a \neq 0a=0, divide both sides by aaa. This is a safe move because aaa is a nonzero constant, and it gives the single value x=bax = \frac{b}{a}x=ab​. The solution set is {ba}\left\{\frac{b}{a}\right\}{ab​}, exactly one number, so the equation is conditional.

If a=0a = 0a=0 and b≠0b \neq 0b=0, the equation reads 0⋅x=b0 \cdot x = b0⋅x=b, that is 0=b0 = b0=b with bbb not zero. The left side is 000 for every xxx, so it never equals the nonzero bbb, and no value of xxx works. The solution set is ∅\varnothing∅, so the equation is a contradiction.

If a=0a = 0a=0 and b=0b = 0b=0, the equation reads 0⋅x=00 \cdot x = 00⋅x=0, that is 0=00 = 00=0. This is true for every xxx, so the solution set is all of R\mathbb{R}R, and the equation is an identity.

Those three cases are exhaustive, because either a=0a = 0a=0 or it is not, and when it is zero either b=0b = 0b=0 or it is not. So a linear equation always has exactly one solution, or no solution, or every real number as a solution. It can never have exactly two. This is the same three-way split as before, conditional, contradiction, or identity, now read straight off the two numbers aaa and bbb.

∎

Reducing to ax=bax = bax=b is not busywork. It is the whole classification packed into two letters. The next lesson lets aaa and bbb be built from other letters, solving a formula for one of its variables. The only real question is then which of these three cases you land in as those letters change.

Worked example 1 Solve 4(x−1)+6=2x+34(x - 1) + 6 = 2x + 34(x−1)+6=2x+3

Distribute and combine like terms on the left:

4x−4+6=2x+3,so4x+2=2x+3.4x - 4 + 6 = 2x + 3, \qquad\text{so}\qquad 4x + 2 = 2x + 3.4x−4+6=2x+3,so4x+2=2x+3.

Subtract 2x2x2x from both sides and then subtract 222, collecting the equation into the form ax=bax = bax=b:

2x+2=3,2x=1.2x + 2 = 3, \qquad 2x = 1.2x+2=3,2x=1.

Here a=2a = 2a=2, which is nonzero, so divide by it:

x=12.x = \frac{1}{2}.x=21​.

The equation is conditional, with the single solution 12\frac{1}{2}21​, so the solution set is {12}\left\{\frac{1}{2}\right\}{21​}.

5x−3x+6=2x+1.5x - 3x + 6 = 2x + 1.5x−3x+6=2x+1.

2x+6=2x+1.2x + 6 = 2x + 1.2x+6=2x+1.

6=1.6 = 1.6=1.

This is the case a=0a = 0a=0, b≠0b \neq 0b=0: the reduced form is 0⋅x=−50 \cdot x = -50⋅x=−5. No value of xxx can make 666 equal 111, so the solution set is ∅\varnothing∅ and the equation is a contradiction.

Worked example 3 Solve 3(2x−1)=6x−33(2x - 1) = 6x - 33(2x−1)=6x−3

Distribute on the left:

6x−3=6x−3.6x - 3 = 6x - 3.6x−3=6x−3.

The two sides are identical. Subtract 6x6x6x from both sides and then add 333:

This is the case a=0a = 0a=0, b=0b = 0b=0: the reduced form is 0⋅x=00 \cdot x = 00⋅x=0, true for every real number. The solution set is all of R\mathbb{R}R, and the equation is an identity. Notice that a single true line like 0=00 = 00=0 reports infinitely many solutions, while a single false line like 6=16 = 16=1 reports none. The reduced form tells you which.

4x+7=4x+7⇒7=74x + 7 = 4x + 7 \quad\Rightarrow\quad 7 = 74x+7=4x+7⇒7=7

That is true for every value of xxx, the case a=0a = 0a=0 and b=0b = 0b=0, so the equation is an identity and the solution set is R\mathbb{R}R.

Clearing denominators changes the domain

Equations with the variable in a denominator are solved by multiplying both sides by the least common denominator to clear the fractions. That is convenient, but look at what kind of move it is. The denominators can be zero, so multiplying by them is the very “multiply by an expression that can be zero” step that adds extraneous solutions. Clearing denominators is the single most common place extraneous roots appear.

The fix is to respect the domain of the original equation. A fraction is undefined when its denominator is zero, so any value that makes a denominator zero is excluded. An excluded value is not eligible to be a solution, no matter what the algebra says later. Excluded is not the same as failing: a value the equation is not even defined at is not tested at all, so it cannot make the equation true or false. This is where the domain from the three cases stops being all of R\mathbb{R}R by default. An equation whose domain skips a point can still be an identity on that domain, as long as it holds at every value the domain does include. The discipline is short. First, before clearing anything, list the excluded values. Then clear the denominators and solve the resulting equation. Finally, check each candidate against the excluded list and throw out any that appears there, because those are extraneous.

Return to the equation that opened the lesson, xx−2=2x−2\frac{x}{x - 2} = \frac{2}{x - 2}x−2x​=x−22​. The denominator x−2x - 2x−2 is zero at x=2x = 2x=2, so x=2x = 2x=2 is excluded from the domain before we touch the algebra. Multiplying both sides by x−2x - 2x−2 gives x=2x = 2x=2, the one candidate. But 222 is exactly the excluded value, so it is extraneous and gets discarded. Nothing survives, and the solution set is ∅\varnothing∅. The equation genuinely has no solution: for every xxx where the two sides are even defined, the only way they could be equal forces x=2x = 2x=2, which is not allowed. That clean step x=2x = 2x=2 was true only about the cleared equation, not the original, and the domain is what told them apart.

Worked example 4 Solve 5x=3x−2\dfrac{5}{x} = \dfrac{3}{x - 2}x5​=x−23​

Two denominators can be zero, xxx at x=0x = 0x=0 and x−2x - 2x−2 at x=2x = 2x=2, so exclude x=0x = 0x=0 and x=2x = 2x=2 before clearing.

Multiply both sides by the least common denominator x(x−2)x(x - 2)x(x−2). On the left the xxx cancels, and on the right the x−2x - 2x−2 cancels:

5(x−2)=3x.5(x - 2) = 3x.5(x−2)=3x.

Distribute and solve:

5x−10=3x,2x=10,x=5.5x - 10 = 3x, \qquad 2x = 10, \qquad x = 5.5x−10=3x,2x=10,x=5.

The candidate x=5x = 5x=5 is not on the excluded list, so it survives. Check it in the original: the left side is 55=1\frac{5}{5} = 155​=1 and the right side is 35−2=33=1\frac{3}{5 - 2} = \frac{3}{3} = 15−23​=33​=1, which agree. The solution set is {5}\{5\}{5}.

Worked example 5 Solve x2−4x−2=x+2\dfrac{x^2 - 4}{x - 2} = x + 2x−2x2−4​=x+2

The denominator x−2x - 2x−2 is zero at x=2x = 2x=2, so exclude x=2x = 2x=2 before clearing.

Multiply both sides by x−2x - 2x−2. On the left the denominator cancels and leaves the numerator, and on the right the factor x−2x - 2x−2 appears:

x2−4=(x+2)(x−2).x^2 - 4 = (x + 2)(x - 2).x2−4=(x+2)(x−2).

The right side expands to x2−4x^2 - 4x2−4, so the equation reduces to 0=00 = 00=0, true for every xxx:

x2−4=x2−4.x^2 - 4 = x^2 - 4.x2−4=x2−4.

The cleared equation is an identity, true for every real number. The original equation is undefined at x=2x = 2x=2, so it cannot be true there, but it is true at every other real number, every value where it is even defined. That makes the original an identity on its domain: the solution set is R\mathbb{R}R with the single point 222 removed, all of the domain and nothing less.

x+4=0  ⇒  x=−4,x−1=0  ⇒  x=1x + 4 = 0 \;\Rightarrow\; x = -4, \qquad x - 1 = 0 \;\Rightarrow\; x = 1x+4=0⇒x=−4,x−1=0⇒x=1

Common mistakes

Common mistakes

  • Reporting x=cx = cx=c when the answer is a whole set. An identity’s answer is “every value in its domain” (all of R\mathbb{R}R for a linear equation with no denominator, or R\mathbb{R}R with any excluded points removed once denominators are involved), and a contradiction’s answer is “no solution.” Reaching 0=00 = 00=0 or 0=50 = 50=5 is not a dead end; it is the answer, telling you the solution set is the whole domain or ∅\varnothing∅.
  • Dividing both sides by a variable. Dividing by xxx, or by any expression that can be zero, can destroy a solution. From x2=xx^2 = xx2=x, dividing by xxx loses x=0x = 0x=0. Move everything to one side and factor instead.
  • Clearing denominators without checking. Multiplying by the least common denominator can introduce extraneous roots, and the cleared equation is exactly where they hide. List the excluded values first, then confirm each candidate in the original equation and discard any that lands on the excluded list.
  • Treating “multiply by zero” as harmless. Multiplying both sides by 000 collapses any equation to 0=00 = 00=0 and loses all information. The safe multiply and divide moves both require a nonzero factor.

Key takeaways

  • An equation in xxx is a condition each number in its domain passes or fails. The equation’s solution set is the set of numbers that pass, and to solve is to describe that set.
  • Every equation is conditional (some but not all domain values solve it), an identity (the solution set is the whole domain, which is R\mathbb{R}R unless denominators exclude points), or a contradiction (solution set ∅\varnothing∅).
  • Two equations are equivalent when they share a solution set. A reversible step always produces an equivalent equation. A step you cannot undo may add extraneous candidates, which must be checked against the original equation, or it may lose a solution outright, which checking cannot recover.
  • Adding any expression defined for all xxx, or multiplying or dividing by a nonzero constant, is reversible and safe. But multiplying by an expression that can be zero can add extraneous roots, and dividing by such an expression can lose roots.
  • Every linear equation reduces to ax=bax = bax=b: one solution x=bax = \frac{b}{a}x=ab​ when a≠0a \neq 0a=0, no solution when a=0a = 0a=0 and b≠0b \neq 0b=0, and all of R\mathbb{R}R when a=0a = 0a=0 and b=0b = 0b=0.
  • Clearing denominators multiplies by a quantity that can be zero, so list the excluded values first, solve, then discard any candidate equal to one of them.

A bit of history (optional)

Ask an ancient scribe how to solve a problem and you were usually shown one problem. The best of those traditions did carry a general recipe, buried inside the worked cases. But a textbook was still a shelf of examples. A reader learned by matching a new question to an old one. When nothing on the shelf matched, you were stuck.

Around the year 820820820 a scholar named al-Khwarizmi wrote a book about equations with a different ambition. He did not want a longer shelf. He wanted a procedure: a fixed run of moves that any equation of a given shape could be poured into, ending in the same dependable verdict every time. Its Arabic title named the key move al-jabr, restoring a term to the other side of an equation, and Latin readers mangled that word into ours: algebra.

Al-Khwarizmi also wrote a separate book about arithmetic with Hindu-Arabic numerals. It was that later book, not the one about equations, whose Latin translation mangled his own name, Algoritmi, into another ordinary English word, algorithm. So our word for a step-by-step method really is a man’s name, borrowed from his arithmetic rather than his algebra. The fit is not an accident, though: the book that sorted equations into types and gave every type a fixed procedure was doing exactly what an algorithm does, long before the word for one existed.

That ambition is this lesson. Whatever tangle you are handed, it is pushed into the single form ax=bax = bax=b, and the three verdicts then read straight off aaa and bbb. You are not matching your question against a remembered example. You are running a procedure, and every step in it was chosen for one reason: it leaves the solution set exactly as it found it.
