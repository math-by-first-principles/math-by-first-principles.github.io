Absolute Value Equations and Inequalities

Intuition

This chapter has been one argument the whole way through, and every lesson pinned down a different reason you get forced into a case analysis. In the first lesson the culprit was an expression that might vanish: multiplying by it can add a root, dividing by it can lose one. In the second it was a coefficient you could not inspect, a parameter hiding whether you were even allowed to divide. In the third it was a multiplier whose sign was unknown, since an inequality carries an order and a negative multiplier flips it. This lesson closes the argument with the cleanest reason of all. The absolute value is defined by cases: the rule ∣x∣=x\lvert x \rvert = x∣x∣=x when x≥0x \ge 0x≥0 and ∣x∣=−x\lvert x \rvert = -x∣x∣=−x when x<0x < 0x<0 is a fork in the road built into the symbol. So every equation and inequality containing the bars inherits that fork. You will not be surprised, then, that solving ∣X∣=Y\lvert X \rvert = Y∣X∣=Y honestly needs a split, or that the split can hand you candidates that do not actually solve the equation. What may surprise you is that this lesson also holds a split that needs no such check at all. Splitting ∣X∣=∣Y∣\lvert X \rvert = \lvert Y \rvert∣X∣=∣Y∣ collapses its two cases back into a single true statement with nothing extra to verify, unlike the split of ∣X∣=Y\lvert X \rvert = Y∣X∣=Y, and it is worth the wait.

Learning goals

  • Read the definition as a case split, and x2\sqrt{x^2}x2​ as ∣x∣\lvert x \rvert∣x∣
  • Require Y≥0Y \ge 0Y≥0 when solving ∣X∣=Y\lvert X \rvert = Y∣X∣=Y
  • Split ∣X∣=∣Y∣\lvert X \rvert = \lvert Y \rvert∣X∣=∣Y∣ with no check needed
  • Turn a band or two rays out of an inequality
  • Use breakpoints to solve a sum of two absolute values

The definition is a case split

You already met the absolute value as distance from zero: ∣x∣\lvert x \rvert∣x∣ is the length you get by dropping a number’s sign, so ∣5∣=5\lvert 5 \rvert = 5∣5∣=5 and ∣−5∣=5\lvert -5 \rvert = 5∣−5∣=5. That picture is the right intuition, and this lesson leans on the exact rule behind it, the piecewise definition

∣x∣={xif x≥0,−xif x<0.\lvert x \rvert = \begin{cases} x & \text{if } x \ge 0, \\ -x & \text{if } x < 0. \end{cases}∣x∣={x−x​if x≥0,if x<0.​

Read it as an instruction that branches. To evaluate ∣x∣\lvert x \rvert∣x∣ you first ask a yes-or-no question about xxx, is it nonnegative, and only then do you know which formula applies. The bars do not evaluate in one step the way adding or squaring does; they are a hidden if. Every difficulty in this lesson traces back to that one fact. When the quantity inside the bars contains an unknown, you cannot answer the branching question in advance. So you are forced to carry both branches until something later settles which one you are in.

There is a second way to write the same rule, with no visible cases at all, and it will earn its keep when we set two absolute values equal. For every real number xxx,

∣x∣=x2.\lvert x \rvert = \sqrt{x^2}.∣x∣=x2​.

Squaring throws away the sign of xxx, and the square root symbol, which always returns the nonnegative root, hands back the size without it.

Why ∣x∣=x2\lvert x \rvert = \sqrt{x^2}∣x∣=x2​#

The square root symbol is defined to return the nonnegative number whose square is its input. So x2\sqrt{x^2}x2​ is, by definition, the nonnegative number whose square is x2x^2x2. The claim is that ∣x∣\lvert x \rvert∣x∣ is exactly that number, and two facts settle it. First, ∣x∣\lvert x \rvert∣x∣ squares to x2x^2x2, since ∣x∣2=x2\lvert x \rvert^2 = x^2∣x∣2=x2 whether xxx is positive or negative. Second, ∣x∣≥0\lvert x \rvert \ge 0∣x∣≥0 by the meaning of distance. There is only one nonnegative number whose square is x2x^2x2, so ∣x∣\lvert x \rvert∣x∣ must be it, that is ∣x∣=x2\lvert x \rvert = \sqrt{x^2}∣x∣=x2​.

The two cases of the definition confirm the same thing, and the second case is where intuition slips. When x≥0x \ge 0x≥0, we have x2=x\sqrt{x^2} = xx2​=x, which agrees with ∣x∣=x\lvert x \rvert = x∣x∣=x. When x<0x < 0x<0, the number −x-x−x is positive and squares to x2x^2x2, so x2=−x\sqrt{x^2} = -xx2​=−x, which agrees with ∣x∣=−x\lvert x \rvert = -x∣x∣=−x. The two branches of the piecewise rule are precisely the two ways x2\sqrt{x^2}x2​ can resolve.

This is the source of a stubborn error. Writing x2=x\sqrt{x^2} = xx2​=x is correct only when x≥0x \ge 0x≥0; for a negative xxx it reports the wrong sign, claiming a negative value for a root that is always nonnegative. With x=−5x = -5x=−5 it would give 25=−5\sqrt{25} = -525​=−5, which is false, since 25=5\sqrt{25} = 525​=5. The honest identity carries the bars, x2=∣x∣\sqrt{x^2} = \lvert x \rvertx2​=∣x∣, and those bars are the case split of this section wearing a different costume.

∎

When the right side carries the unknown

Solving ∣X∣=c\lvert X \rvert = c∣X∣=c for a number ccc was a one-glance affair: you check the sign of ccc once. A positive ccc splits into X=cX = cX=c or X=−cX = -cX=−c, the value c=0c = 0c=0 gives the single solution X=0X = 0X=0, and a negative ccc gives none. Now let the right side be an expression YYY that contains the unknown, as in ∣x−1∣=2x−4\lvert x - 1 \rvert = 2x - 4∣x−1∣=2x−4. That single up-front check is gone, because the sign of YYY depends on the very xxx you are solving for. Splitting anyway is where solutions get manufactured.

Passing from ∣X∣=Y\lvert X \rvert = Y∣X∣=Y to ”X=YX = YX=Y or X=−YX = -YX=−Y” looks like the same safe move, but it is not an equivalence. The left side ∣X∣\lvert X \rvert∣X∣ can never be negative, so the original equation secretly demands Y≥0Y \ge 0Y≥0 as well, and nothing in the two split equations remembers that demand. Dropping it is exactly a non-reversible step of the kind the first lesson warned about. You can travel forward from ∣X∣=Y\lvert X \rvert = Y∣X∣=Y to the pair of equations, but you cannot travel back. The return trip fails because a solution of X=−YX = -YX=−Y at a place where YYY is negative satisfies the split without satisfying the original. The step can add solutions the equation never had. The honest statement keeps the dropped condition in plain sight:

∣X∣=Y⟺Y≥0  and  (X=Y  or  X=−Y).\lvert X \rvert = Y \quad\Longleftrightarrow\quad Y \ge 0 \ \text{ and } \ \bigl(X = Y \ \text{ or } \ X = -Y\bigr).∣X∣=Y⟺Y≥0  and  (X=Y  or  X=−Y).

Why the condition Y≥0Y \ge 0Y≥0 cannot be dropped#

Read the equivalence in both directions at a value of xxx, with XXX and YYY standing for the two sides evaluated there.

Forward. Suppose ∣X∣=Y\lvert X \rvert = Y∣X∣=Y. The left side is an absolute value, so Y=∣X∣≥0Y = \lvert X \rvert \ge 0Y=∣X∣≥0, which gives the condition Y≥0Y \ge 0Y≥0 for free. And ∣X∣=Y\lvert X \rvert = Y∣X∣=Y with Y≥0Y \ge 0Y≥0 says XXX is a number whose distance from zero is YYY, and the only candidates are YYY and −Y-Y−Y, the same number when Y=0Y = 0Y=0, so X=YX = YX=Y or X=−YX = -YX=−Y either way. The right side holds.

Backward. Suppose Y≥0Y \ge 0Y≥0 and either X=YX = YX=Y or X=−YX = -YX=−Y. If X=YX = YX=Y then ∣X∣=∣Y∣=Y\lvert X \rvert = \lvert Y \rvert = Y∣X∣=∣Y∣=Y, the last step because Y≥0Y \ge 0Y≥0. If X=−YX = -YX=−Y then ∣X∣=∣−Y∣=∣Y∣=Y\lvert X \rvert = \lvert -Y \rvert = \lvert Y \rvert = Y∣X∣=∣−Y∣=∣Y∣=Y again. Either way ∣X∣=Y\lvert X \rvert = Y∣X∣=Y, the original.

The backward direction is where Y≥0Y \ge 0Y≥0 does its work, and dropping it breaks the argument. Suppose YYY were negative and X=−YX = -YX=−Y. Then ∣X∣=∣Y∣=−Y\lvert X \rvert = \lvert Y \rvert = -Y∣X∣=∣Y∣=−Y, a positive number, while YYY itself is negative, so ∣X∣=Y\lvert X \rvert = Y∣X∣=Y is false. That is precisely a candidate the bare split accepts and the original rejects. So the split without its side condition is a one-way street. The way to make it safe is to solve as usual, and then keep only the candidates for which Y≥0Y \ge 0Y≥0.

∎

In practice this means the same discipline as clearing denominators in the first lesson. Run the convenient non-reversible step, then check each candidate in the original and discard the extraneous ones. Substituting into the original is the surest check, but testing Y≥0Y \ge 0Y≥0 is faster and catches exactly the same failures.

Worked example 1 Solve ∣x−1∣=2x−4\lvert x - 1 \rvert = 2x - 4∣x−1∣=2x−4

Here X=x−1X = x - 1X=x−1 and Y=2x−4Y = 2x - 4Y=2x−4. Split into the two cases, treating each result as a candidate until the condition Y≥0Y \ge 0Y≥0 is checked.

Case X=YX = YX=Y:

x−1=2x−4⟹3=x,x=3.x - 1 = 2x - 4 \quad\Longrightarrow\quad 3 = x, \qquad x = 3.x−1=2x−4⟹3=x,x=3.

Case X=−YX = -YX=−Y:

x−1=−(2x−4)=−2x+4⟹3x=5,x=53.x - 1 = -(2x - 4) = -2x + 4 \quad\Longrightarrow\quad 3x = 5, \qquad x = \tfrac{5}{3}.x−1=−(2x−4)=−2x+4⟹3x=5,x=35​.

Now test each against Y=2x−4≥0Y = 2x - 4 \ge 0Y=2x−4≥0. At x=3x = 3x=3 the right side is 2(3)−4=22(3) - 4 = 22(3)−4=2, which is nonnegative, and ∣3−1∣=2\lvert 3 - 1 \rvert = 2∣3−1∣=2 checks, so x=3x = 3x=3 is a genuine solution. At x=53x = \frac{5}{3}x=35​ the right side is 2⋅53−4=103−123=−232 \cdot \frac{5}{3} - 4 = \frac{10}{3} - \frac{12}{3} = -\frac{2}{3}2⋅35​−4=310​−312​=−32​, which is negative, so this candidate is extraneous. The original would read ∣53−1∣=−23\lvert \frac{5}{3} - 1 \rvert = -\frac{2}{3}∣35​−1∣=−32​, an absolute value equal to a negative number, which is impossible.

candidates x=3, 53;solution set {3}.\text{candidates } x = 3, \ \tfrac{5}{3}; \qquad \text{solution set } \{3\}.candidates x=3, 35​;solution set {3}.

The algebra offered two candidates and the check kept one. Skipping the check would have reported the false solution 53\frac{5}{3}35​.

Worked example 2 Solve ∣2x+1∣=x−3\lvert 2x + 1 \rvert = x - 3∣2x+1∣=x−3

Split with X=2x+1X = 2x + 1X=2x+1 and Y=x−3Y = x - 3Y=x−3.

Case X=YX = YX=Y:

2x+1=x−3⟹x=−4.2x + 1 = x - 3 \quad\Longrightarrow\quad x = -4.2x+1=x−3⟹x=−4.

Case X=−YX = -YX=−Y:

2x+1=−(x−3)=−x+3⟹3x=2,x=23.2x + 1 = -(x - 3) = -x + 3 \quad\Longrightarrow\quad 3x = 2, \qquad x = \tfrac{2}{3}.2x+1=−(x−3)=−x+3⟹3x=2,x=32​.

Check each against Y=x−3≥0Y = x - 3 \ge 0Y=x−3≥0. At x=−4x = -4x=−4 the right side is −4−3=−7<0-4 - 3 = -7 < 0−4−3=−7<0, extraneous. At x=23x = \frac{2}{3}x=32​ the right side is 23−3=−73<0\frac{2}{3} - 3 = -\frac{7}{3} < 032​−3=−37​<0, also extraneous. Both candidates fail.

solution set ∅.\text{solution set } \varnothing.solution set ∅.

This one unsettles people. Both cases were solved correctly, each produced a clean number, and yet the equation has no solution at all. The reason is visible without any of the algebra: the right side x−3x - 3x−3 must be nonnegative for the equation to stand. So only x≥3x \ge 3x≥3 is even eligible, and neither candidate reached that far. When a required condition like Y≥0Y \ge 0Y≥0 looks hard to satisfy, expect an empty answer.

x=54: 3x=154≥0✓x=−52: 3x=−152<0×x = \tfrac{5}{4}:\ 3x = \tfrac{15}{4} \ge 0 \quad\checkmark \qquad x = -\tfrac{5}{2}:\ 3x = -\tfrac{15}{2} < 0 \quad\timesx=45​: 3x=415​≥0✓x=−25​: 3x=−215​<0×

Setting two absolute values equal

Now put an absolute value on the right as well, ∣X∣=∣Y∣\lvert X \rvert = \lvert Y \rvert∣X∣=∣Y∣. After a chapter spent exposing splits that quietly fail, this is the one that does not. Here the case split is a true equivalence with no side condition attached, and so is the shortcut that replaces it:

∣X∣=∣Y∣⟺X=Y  or  X=−Y⟺X2=Y2.\lvert X \rvert = \lvert Y \rvert \quad\Longleftrightarrow\quad X = Y \ \text{ or } \ X = -Y \quad\Longleftrightarrow\quad X^2 = Y^2.∣X∣=∣Y∣⟺X=Y  or  X=−Y⟺X2=Y2.

The side condition disappears for one plain reason: both sides are absolute values, hence both nonnegative from the start, so there is no hidden demand like Y≥0Y \ge 0Y≥0 left to forget. The very step that was dangerous a moment ago, squaring, becomes exact.

Why ∣X∣=∣Y∣\lvert X \rvert = \lvert Y \rvert∣X∣=∣Y∣ is equivalent to X2=Y2X^2 = Y^2X2=Y2#

Read the chain in two hops and confirm each hop is reversible.

First hop: ∣X∣=∣Y∣\lvert X \rvert = \lvert Y \rvert∣X∣=∣Y∣ is equivalent to X2=Y2X^2 = Y^2X2=Y2. Both ∣X∣\lvert X \rvert∣X∣ and ∣Y∣\lvert Y \rvert∣Y∣ are nonnegative, and on nonnegative numbers squaring is one-to-one, undone by the nonnegative square root, so for such numbers a=ba = ba=b holds exactly when a2=b2a^2 = b^2a2=b2. Squaring both sides of ∣X∣=∣Y∣\lvert X \rvert = \lvert Y \rvert∣X∣=∣Y∣ gives ∣X∣2=∣Y∣2\lvert X \rvert^2 = \lvert Y \rvert^2∣X∣2=∣Y∣2, that is X2=Y2X^2 = Y^2X2=Y2. Conversely, taking the nonnegative square root of X2=Y2X^2 = Y^2X2=Y2 gives X2=Y2\sqrt{X^2} = \sqrt{Y^2}X2​=Y2​, that is ∣X∣=∣Y∣\lvert X \rvert = \lvert Y \rvert∣X∣=∣Y∣ by the identity of the first section. Neither direction leaks.

Second hop: X2=Y2X^2 = Y^2X2=Y2 is equivalent to X=YX = YX=Y or X=−YX = -YX=−Y. Move everything to one side and factor the difference of squares:

X2−Y2=0⟺(X−Y)(X+Y)=0.X^2 - Y^2 = 0 \quad\Longleftrightarrow\quad (X - Y)(X + Y) = 0.X2−Y2=0⟺(X−Y)(X+Y)=0.

A product is zero exactly when one of its factors is zero, so this holds precisely when X−Y=0X - Y = 0X−Y=0 or X+Y=0X + Y = 0X+Y=0, that is X=YX = YX=Y or X=−YX = -YX=−Y. Every step is an equivalence, so the full chain is one.

Set this beside the first lesson. Squaring an ordinary equation is a textbook non-reversible step, the kind that breeds extraneous roots, because two numbers with equal squares need not be equal. What rescues it here is that the quantities being squared, ∣X∣\lvert X \rvert∣X∣ and ∣Y∣\lvert Y \rvert∣Y∣, are already known to be nonnegative. And on the nonnegative numbers, equal squares really do force equal values. The equivalence is not luck; it is bought by the nonnegativity the bars guarantee.

∎

Worked example 3 Solve ∣2x−1∣=∣x+4∣\lvert 2x - 1 \rvert = \lvert x + 4 \rvert∣2x−1∣=∣x+4∣

Because both sides are absolute values, split with no check needed. Set the insides equal, then set one equal to the other’s opposite.

Case X=YX = YX=Y:

2x−1=x+4⟹x=5.2x - 1 = x + 4 \quad\Longrightarrow\quad x = 5.2x−1=x+4⟹x=5.

Case X=−YX = -YX=−Y:

2x−1=−(x+4)=−x−4⟹3x=−3,x=−1.2x - 1 = -(x + 4) = -x - 4 \quad\Longrightarrow\quad 3x = -3, \qquad x = -1.2x−1=−(x+4)=−x−4⟹3x=−3,x=−1.

Both are genuine, so the solution set is {−1,5}\{-1, 5\}{−1,5}. Nothing is discarded, because setting two absolute values equal carries no side condition.

The squaring route lands in the same place. From ∣2x−1∣=∣x+4∣\lvert 2x - 1 \rvert = \lvert x + 4 \rvert∣2x−1∣=∣x+4∣, square both sides:

(2x−1)2=(x+4)2⟹4x2−4x+1=x2+8x+16.(2x - 1)^2 = (x + 4)^2 \quad\Longrightarrow\quad 4x^2 - 4x + 1 = x^2 + 8x + 16.(2x−1)2=(x+4)2⟹4x2−4x+1=x2+8x+16.

Collect on one side and simplify:

3x2−12x−15=0⟹x2−4x−5=0⟹(x−5)(x+1)=0,3x^2 - 12x - 15 = 0 \quad\Longrightarrow\quad x^2 - 4x - 5 = 0 \quad\Longrightarrow\quad (x - 5)(x + 1) = 0,3x2−12x−15=0⟹x2−4x−5=0⟹(x−5)(x+1)=0,

so x=5x = 5x=5 or x=−1x = -1x=−1, exactly the two solutions from the case split. Squaring was safe here for the reason just proved, not by accident.

Inequalities, read as distance

The two absolute value inequalities are already familiar, and the distance meaning is what makes them memorable instead of memorized. The statement ∣X∣<c\lvert X \rvert < c∣X∣<c says XXX lies within ccc of zero, so it is trapped in a band. The statement ∣X∣>c\lvert X \rvert > c∣X∣>c, by contrast, says XXX lies farther than ccc from zero, so it splits into two rays:

∣X∣<c  ⟺  −c<X<c,\lvert X \rvert < c \iff -c < X < c,∣X∣<c⟺−c<X<c, ∣X∣>c  ⟺  X<−c  or  X>c.\lvert X \rvert > c \iff X < -c \ \text{ or } \ X > c.∣X∣>c⟺X<−c  or  X>c.

Try both forms on an ordinary positive ccc first, one for the band and one for the rays, before pushing ccc to its boundary and past it.

Worked example 4 Read ∣x−4∣≤3\lvert x - 4 \rvert \le 3∣x−4∣≤3 as a distance

The quantity ∣x−4∣\lvert x - 4 \rvert∣x−4∣ is the distance from xxx to 444, so ∣x−4∣≤3\lvert x - 4 \rvert \le 3∣x−4∣≤3 says xxx is within 333 of 444. The numbers within 333 of 444 run from 4−3=14 - 3 = 14−3=1 up to 4+3=74 + 3 = 74+3=7:

−3≤x−4≤3⟹1≤x≤7,-3 \le x - 4 \le 3 \quad\Longrightarrow\quad 1 \le x \le 7,−3≤x−4≤3⟹1≤x≤7,

the interval [1,7][1, 7][1,7], centered at 444 with radius 333. Reading a band this way, as a center and a radius, is quicker than solving and it makes the answer easy to picture. In symbols, for c≥0c \ge 0c≥0, ∣x−a∣≤c\lvert x - a \rvert \le c∣x−a∣≤c is the closed interval [a−c,a+c][a - c, a + c][a−c,a+c], every point no more than ccc from aaa (at c=0c = 0c=0 that interval collapses to the single point aaa). The strict version ∣x−a∣<c\lvert x - a \rvert < c∣x−a∣<c is the open interval (a−c,a+c)(a - c, a + c)(a−c,a+c) for c>0c > 0c>0, the same band without its two endpoints; at c≤0c \le 0c≤0 no distance can be less than ccc, so the solution set is ∅\varnothing∅ instead of an interval.

Worked example 5 Solve a farther-than inequality, ∣x−7∣>4\lvert x - 7 \rvert > 4∣x−7∣>4

The quantity ∣x−7∣\lvert x - 7 \rvert∣x−7∣ is the distance from xxx to 777, so ∣x−7∣>4\lvert x - 7 \rvert > 4∣x−7∣>4 says xxx lies farther than 444 from 777. That sends xxx onto two rays, one below 7−4=37 - 4 = 37−4=3 and one above 7+4=117 + 4 = 117+4=11:

x−7<−4  or  x−7>4⟹x<3  or  x>11.x - 7 < -4 \ \text{ or } \ x - 7 > 4 \quad\Longrightarrow\quad x < 3 \ \text{ or } \ x > 11.x−7<−4  or  x−7>4⟹x<3  or  x>11.

The solution set is (−∞,3)∪(11,∞)(-\infty, 3) \cup (11, \infty)(−∞,3)∪(11,∞), every point outside the band that the inequality ∣x−7∣≤4\lvert x - 7 \rvert \le 4∣x−7∣≤4 would have trapped. In symbols, ∣x−a∣>c\lvert x - a \rvert > c∣x−a∣>c is every point more than ccc from aaa, the two rays x<a−cx < a - cx<a−c and x>a+cx > a + cx>a+c.

Both equivalences hold for every real ccc, not only for the positive values you just used. That is exactly why reciting them fails while reading them does not: you have to see what each one says once ccc reaches zero and turns negative.

Take ∣X∣<c\lvert X \rvert < c∣X∣<c when c≤0c \le 0c≤0. A distance cannot be less than a nonpositive number, because distances start at 000: if c=0c = 0c=0 the demand ∣X∣<0\lvert X \rvert < 0∣X∣<0 is impossible, and for c<0c < 0c<0 it is more impossible still. So ∣X∣<c\lvert X \rvert < c∣X∣<c has solution set ∅\varnothing∅ whenever c≤0c \le 0c≤0, with no band to draw. The template −c<X<c-c < X < c−c<X<c needs no special case: at c=0c = 0c=0 it degenerates to 0<X<00 < X < 00<X<0, already empty, and for c<0c < 0c<0 it reads with −c>c-c > c−c>c, ends crossed, empty again. The formula still tells the truth, but only if you read a crossed band as empty rather than as a slip of the pen.

Take ∣X∣>c\lvert X \rvert > c∣X∣>c when c<0c < 0c<0. Every distance is at least 000, which already exceeds any negative ccc, so ∣X∣>c\lvert X \rvert > c∣X∣>c holds for every real number and the solution set is all of R\mathbb{R}R. Two boundary readings deserve their own names. The inequality ∣X∣>0\lvert X \rvert > 0∣X∣>0 holds for every XXX except the single place where the distance is 000, so it describes all xxx with X≠0X \neq 0X=0. And ∣X∣≥0\lvert X \rvert \ge 0∣X∣≥0 excludes nothing at all, holding for every real number, since a distance is always at least zero. These are not trick questions; they are the honest values of the formula at and beyond its boundary. A solver who only remembers “band or two rays” will misreport every one of these honest values.

Worked example 6 Three inequalities at or past the boundary

Read each by distance rather than by a template.

The inequality ∣3x−5∣<−2\lvert 3x - 5 \rvert < -2∣3x−5∣<−2 asks an absolute value to fall below −2-2−2. It never can, so no xxx works and the solution set is ∅\varnothing∅.

The inequality ∣4−7x∣>−1\lvert 4 - 7x \rvert > -1∣4−7x∣>−1 asks an absolute value to exceed −1-1−1. It always does, since it is at least 000, so every xxx works and the solution set is all of R\mathbb{R}R.

The inequality ∣x−6∣>0\lvert x - 6 \rvert > 0∣x−6∣>0 asks the distance from xxx to 666 to be strictly positive. That holds for every xxx except x=6x = 6x=6, where the distance is zero, so the solution set is every real number but 666:

∣x−6∣>0⟺x≠6⟺(−∞,6)∪(6,∞).\lvert x - 6 \rvert > 0 \quad\Longleftrightarrow\quad x \neq 6 \quad\Longleftrightarrow\quad (-\infty, 6) \cup (6, \infty).∣x−6∣>0⟺x=6⟺(−∞,6)∪(6,∞).

None of these needed a case split or a band. Checking the sign of the right side, the same reflex from solving ∣X∣=c\lvert X \rvert = c∣X∣=c, settled all three at a glance.

Check your understanding

Which of these has solution set ∅\varnothing∅, no band and no rays at all: ∣x−2∣<0\lvert x - 2 \rvert < 0∣x−2∣<0, ∣x−2∣>0\lvert x - 2 \rvert > 0∣x−2∣>0, or ∣x−2∣>−3\lvert x - 2 \rvert > -3∣x−2∣>−3?

Answer choices

A distance can never be less than 000, so ∣x−2∣<0\lvert x - 2 \rvert < 0∣x−2∣<0 demands the impossible and its solution set is ∅\varnothing∅. The inequality ∣x−2∣>0\lvert x - 2 \rvert > 0∣x−2∣>0 instead holds for every xxx except x=2x = 2x=2, two open rays separated only by that missing point, (−∞,2)∪(2,∞)(-\infty, 2) \cup (2, \infty)(−∞,2)∪(2,∞), and ∣x−2∣>−3\lvert x - 2 \rvert > -3∣x−2∣>−3 holds for every real xxx, since a distance is always at least 000, which already exceeds −3-3−3.

The capstone, a sum of two absolute values

Everything in this chapter has been preparing you for a problem with two absolute values added together, like

∣x−3∣+∣x+1∣=6.\lvert x - 3 \rvert + \lvert x + 1 \rvert = 6.∣x−3∣+∣x+1∣=6.

No single split unlocks it, because two independent bars fork independently. The method is to find the breakpoints, the values where each inside expression changes sign. You then use those breakpoints to cut the number line into intervals on which every bar resolves to one definite formula. Here x−3x - 3x−3 changes sign at x=3x = 3x=3 and x+1x + 1x+1 changes sign at x=−1x = -1x=−1, so the breakpoints −1-1−1 and 333 split the line into three intervals. On each one, both absolute values become ordinary linear expressions, and the equation becomes an ordinary linear equation. The one catch is that a root counts only if it lands inside the interval that produced it.

Worked example 7 Solve ∣x−3∣+∣x+1∣=6\lvert x - 3 \rvert + \lvert x + 1 \rvert = 6∣x−3∣+∣x+1∣=6 by breakpoints

The breakpoints −1-1−1 and 333 give three intervals. On each, resolve the two bars with the piecewise definition, then solve the linear equation.

Interval x<−1x < -1x<−1. Here x−3<0x - 3 < 0x−3<0 so ∣x−3∣=3−x\lvert x - 3 \rvert = 3 - x∣x−3∣=3−x, and x+1<0x + 1 < 0x+1<0 so ∣x+1∣=−x−1\lvert x + 1 \rvert = -x - 1∣x+1∣=−x−1. The equation becomes

(3−x)+(−x−1)=6⟹2−2x=6⟹x=−2.(3 - x) + (-x - 1) = 6 \quad\Longrightarrow\quad 2 - 2x = 6 \quad\Longrightarrow\quad x = -2.(3−x)+(−x−1)=6⟹2−2x=6⟹x=−2.

Since −2<−1-2 < -1−2<−1, the root lies in this interval, so keep it.

Interval −1≤x≤3-1 \le x \le 3−1≤x≤3. Here x+1≥0x + 1 \ge 0x+1≥0 so ∣x+1∣=x+1\lvert x + 1 \rvert = x + 1∣x+1∣=x+1, while x−3≤0x - 3 \le 0x−3≤0 so ∣x−3∣=3−x\lvert x - 3 \rvert = 3 - x∣x−3∣=3−x. The equation becomes

(3−x)+(x+1)=6⟹4=6,(3 - x) + (x + 1) = 6 \quad\Longrightarrow\quad 4 = 6,(3−x)+(x+1)=6⟹4=6,

which is false. The variable cancelled and left a contradiction, so this interval contributes no solution.

Interval x>3x > 3x>3. Here both insides are positive, ∣x−3∣=x−3\lvert x - 3 \rvert = x - 3∣x−3∣=x−3 and ∣x+1∣=x+1\lvert x + 1 \rvert = x + 1∣x+1∣=x+1, so

(x−3)+(x+1)=6⟹2x−2=6⟹x=4.(x - 3) + (x + 1) = 6 \quad\Longrightarrow\quad 2x - 2 = 6 \quad\Longrightarrow\quad x = 4.(x−3)+(x+1)=6⟹2x−2=6⟹x=4.

Since 4>34 > 34>3, the root lies in this interval, so keep it.

Collecting the survivors, the solution set is {−2,4}\{-2, 4\}{−2,4}. The discarded middle interval was not a failure of the algebra; it was the method telling you the sum can never reach 666 there.

That middle interval rewards a second look, because geometry explains it fully. Read ∣x−3∣\lvert x - 3 \rvert∣x−3∣ as the distance from xxx to 333 and ∣x+1∣\lvert x + 1 \rvert∣x+1∣ as the distance from xxx to −1-1−1. The left side is then the total distance from xxx to the two fixed anchors 333 and −1-1−1. So the equation asks which points have distances to 333 and to −1-1−1 that add up to 666. The two anchors are 444 apart. For any xxx between them the two distances simply split that gap, so their sum is exactly 444 wherever xxx falls in the middle. That constant sum is why the middle interval produced the flat statement 4=64 = 64=6 and no solution. To reach a sum of 666 you must step outside the anchors. Each unit you travel beyond an endpoint adds 111 to each of the two distances, and hence 222 to the sum. Starting from 444, you need 222 more, so you step exactly 111 unit past an end. One unit left of −1-1−1 lands on −2-2−2, and one unit right of 333 lands on 444. The algebra and the picture agree, and the picture explains why the answer had to be symmetric about 111, the midpoint of the anchors.

Worked example 8 When the target equals the gap, ∣x−2∣+∣x+4∣=6\lvert x - 2 \rvert + \lvert x + 4 \rvert = 6∣x−2∣+∣x+4∣=6

The breakpoints are −4-4−4 and 222, and the two anchors are 666 apart, the same as the number on the right. Walk the three intervals.

Interval x<−4x < -4x<−4. Both insides are negative, so (2−x)+(−x−4)=6(2 - x) + (-x - 4) = 6(2−x)+(−x−4)=6 gives −2x−2=6-2x - 2 = 6−2x−2=6, hence x=−4x = -4x=−4. But −4-4−4 is not strictly less than −4-4−4, so it sits on the boundary rather than inside this interval; hold it for the next case.

Interval −4≤x≤2-4 \le x \le 2−4≤x≤2. Here ∣x−2∣=2−x\lvert x - 2 \rvert = 2 - x∣x−2∣=2−x and ∣x+4∣=x+4\lvert x + 4 \rvert = x + 4∣x+4∣=x+4, so

(2−x)+(x+4)=6⟹6=6,(2 - x) + (x + 4) = 6 \quad\Longrightarrow\quad 6 = 6,(2−x)+(x+4)=6⟹6=6,

true for every xxx in the interval. The entire interval [−4,2][-4, 2][−4,2] solves the equation.

Interval x>2x > 2x>2. Both insides are positive, so (x−2)+(x+4)=6(x - 2) + (x + 4) = 6(x−2)+(x+4)=6 gives 2x+2=62x + 2 = 62x+2=6, hence x=2x = 2x=2, again a boundary point already contained in [−4,2][-4, 2][−4,2].

The solution set is the whole interval [−4,2][-4, 2][−4,2]. Geometry says the same thing instantly: the anchors are 666 apart, so between them the two distances always sum to 666, matching the target exactly. So every point between the two anchors is a solution of the equation. When the number on the right equals the gap between the anchors, the answer is not two points but the entire segment joining them.

These two examples map out every possibility for ∣x−p∣+∣x−q∣=d\lvert x - p \rvert + \lvert x - q \rvert = d∣x−p∣+∣x−q∣=d, with ppp and qqq the anchors and g=∣p−q∣g = \lvert p - q \rvertg=∣p−q∣ the gap between them. Between the anchors the sum is always ggg, and it grows as you move outside, so three cases exhaust it. If d<gd < gd<g the sum never dips low enough and there is no solution. If d=gd = gd=g the sum equals ddd across the whole middle segment, giving the interval between the anchors. If d>gd > gd>g there are exactly two solutions, one step outside each anchor and symmetric about the midpoint. You can read off which case you are in before solving, just by comparing the target ddd with the gap ggg.

Check your understanding

For ∣x−5∣+∣x+1∣=d\lvert x - 5 \rvert + \lvert x + 1 \rvert = d∣x−5∣+∣x+1∣=d, the anchors are 555 and −1-1−1. For which value of ddd does the equation have infinitely many solutions?

Answer choices

Between the two anchors the two distances always add to the gap between them.

g=∣5−(−1)∣=6g = \lvert 5 - (-1) \rvert = 6g=∣5−(−1)∣=6

When the target ddd equals the gap g=6g = 6g=6, every point of the segment [−1,5][-1, 5][−1,5] has distance-sum exactly 666, so there are infinitely many solutions, the whole interval. A larger ddd such as 121212 gives two isolated solutions, and a smaller ddd such as 444 gives none.

Common mistakes

Common mistakes

  • Splitting ∣X∣=Y\lvert X \rvert = Y∣X∣=Y and reporting both cases without checking Y≥0Y \ge 0Y≥0. The plain split into X=YX = YX=Y or X=−YX = -YX=−Y drops the demand that the right side be nonnegative, so it can add roots the original never had. Treat each result as a candidate and confirm it in the original equation.
  • Reading x2\sqrt{x^2}x2​ as xxx. The identity is x2=∣x∣\sqrt{x^2} = \lvert x \rvertx2​=∣x∣, which equals xxx only when x≥0x \ge 0x≥0; for x=−5x = -5x=−5 it gives 555, not −5-5−5. The square root symbol always returns the nonnegative root.
  • Attaching a check to ∣X∣=∣Y∣\lvert X \rvert = \lvert Y \rvert∣X∣=∣Y∣. There is no side condition here, since both sides are already nonnegative, so every case-solution is genuine and squaring to X2=Y2X^2 = Y^2X2=Y2 is exact rather than a source of extraneous roots.
  • Trusting an inequality template without reading what it says. Both equivalences hold for every real ccc: the band ∣X∣<c  ⟺  −c<X<c\lvert X \rvert < c \iff -c < X < c∣X∣<c⟺−c<X<c simply reads as empty when c≤0c \le 0c≤0, since its ends cross. The two rays ∣X∣>c  ⟺  X<−c\lvert X \rvert > c \iff X < -c∣X∣>c⟺X<−c or X>cX > cX>c together cover the whole line when c<0c < 0c<0. The templates need no side condition; the fragile one is the equation ∣X∣=c\lvert X \rvert = c∣X∣=c, which does need c≥0c \ge 0c≥0. The reason is that at c=−3c = -3c=−3 the naive split would report X=3X = 3X=3 and X=−3X = -3X=−3 for an equation with no solution.
  • Mishandling the strict-zero cases. The inequality ∣X∣>0\lvert X \rvert > 0∣X∣>0 excludes exactly the point where X=0X = 0X=0 (not every xxx, and not none), while ∣X∣≥0\lvert X \rvert \ge 0∣X∣≥0 is true for every real number.
  • Keeping a root that falls outside its interval. In a sum of absolute values, each interval’s linear equation is valid only on that interval, so a root outside the interval that produced it must be discarded. An interval whose equation reduces to a true statement instead contributes all of its points.

Key takeaways

  • The definition ∣x∣=x\lvert x \rvert = x∣x∣=x for x≥0x \ge 0x≥0 and ∣x∣=−x\lvert x \rvert = -x∣x∣=−x for x<0x < 0x<0 is a case split, and the same rule is ∣x∣=x2\lvert x \rvert = \sqrt{x^2}∣x∣=x2​; the identity x2=∣x∣\sqrt{x^2} = \lvert x \rvertx2​=∣x∣, not xxx, is that split in another form.
  • ∣X∣=Y\lvert X \rvert = Y∣X∣=Y is equivalent to Y≥0Y \ge 0Y≥0 and (X=YX = YX=Y or X=−YX = -YX=−Y). The bare split is a non-reversible step that drops Y≥0Y \ge 0Y≥0, so its candidates must be checked, exactly like clearing denominators in the first lesson.
  • ∣X∣=∣Y∣\lvert X \rvert = \lvert Y \rvert∣X∣=∣Y∣ is equivalent to X=YX = YX=Y or X=−YX = -YX=−Y, and to X2=Y2X^2 = Y^2X2=Y2; this split is a genuine biconditional needing no check, and squaring is exact here because both sides are already nonnegative.
  • ∣X∣<c  ⟺  −c<X<c\lvert X \rvert < c \iff -c < X < c∣X∣<c⟺−c<X<c and ∣X∣>c  ⟺  X<−c\lvert X \rvert > c \iff X < -c∣X∣>c⟺X<−c or X>cX > cX>c hold for every real ccc: the band just reads as empty when c≤0c \le 0c≤0 and the rays cover all of R\mathbb{R}R when c<0c < 0c<0.   • ∣X∣>0\lvert X \rvert > 0∣X∣>0 holds exactly when X≠0X \neq 0X=0, and ∣X∣≥0\lvert X \rvert \ge 0∣X∣≥0 holds for every real number; for c>0c > 0c>0, read ∣x−a∣<c\lvert x - a \rvert < c∣x−a∣<c as ”xxx within ccc of aaa”, the open interval (a−c,a+c)(a - c, a + c)(a−c,a+c), and read ∣x−a∣≤c\lvert x - a \rvert \le c∣x−a∣≤c as the closed interval [a−c,a+c][a - c, a + c][a−c,a+c].
  • A sum ∣x−p∣+∣x−q∣=d\lvert x - p \rvert + \lvert x - q \rvert = d∣x−p∣+∣x−q∣=d is solved by the breakpoints ppp and qqq: on each interval every bar resolves to a sign. A bit of history (optional)

The size of a thing, with its direction thrown away, is an old idea carrying a young name. For centuries there was only a phrase for it: the value of the number, taken without regard to its sign. That is bearable once. It is a burden on every line of an argument.

The word arrived from an unexpected direction. It was minted for complex numbers, not for the plain numbers on the line. In 180618061806 Jean-Robert Argand, writing in French, called the length of the arrow that stands for a complex number its module. An arrow carries both a heading and a length, and he wanted a word for the length by itself. English took the term sixty years later, in its Latin form modulus, in 186618661866. The two upright bars came separately, from Karl Weierstrass in 184118411841.

So the vocabulary travelled backwards. It was coined for arrows in a plane, then handed down to the ordinary numbers, where an arrow’s length becomes plain distance from zero.

That is why the distance reading in this lesson is not a friendly simplification laid over the algebra. Reading ∣x−4∣≤3\lvert x - 4 \rvert \le 3∣x−4∣≤3 as ”xxx sits within 333 of 444” is the older meaning of the word, not a picture drawn beside it. So is reading a sum of two bars as a total distance to two anchors. Distance is the thing the name was made to say.
