    Find the median of 121212, 555, 999, 202020, 777.

    Answer choices for question 1

    Solution

    Correct answer: A

    The median is the middle value of the sorted data, so sort first.

    5,  7,  9,  12,  205, \; 7, \; 9, \; 12, \; 205,7,9,12,20

    There are five values, an odd count, so a single value sits in the middle: the third one.

    median=9\text{median} = 9median=9

    The value 10.610.610.6 is the mean of this data, which is a different summary and a different question.

  2. 2

    Find the median of 999, 222, 151515, 666.

    Answer choices for question 2

    Solution

    Correct answer: C

    Sort the values before touching the middle.

    2,  6,  9,  152, \; 6, \; 9, \; 152,6,9,15

    The count is even, so no single value is in the middle. Average the two middle values, 666 and 999.

    median=6+92=7.5\text{median} = \frac{6 + 9}{2} = 7.5median=26+9​=7.5

    Averaging the middle two of the unsorted list would give 2+152=8.5\frac{2 + 15}{2} = 8.522+15​=8.5, which is the trap here. The median is defined on the sorted order.

  3. 3

    Find the range of 141414, 222222, 999, 313131, 181818.

    Answer choices for question 3

    Solution

    Correct answer: D

    The range is the distance from the smallest value to the largest, so identify both ends. The maximum is 313131 and the minimum is 999.

    range=max−min=31−9=22\text{range} = \text{max} - \text{min} = 31 - 9 = 22range=max−min=31−9=22

    The range measures spread, not center. Note that it is built from only the two most extreme values, which is exactly what makes it fragile.

    Answer choices for question 5

    Solution

    Correct answer: C

    The interquartile range is the width of the box, which runs from Q1Q_1Q1​ to Q3Q_3Q3​.

    IQR=Q3−Q1=31−18=13\text{IQR} = Q_3 - Q_1 = 31 - 18 = 13IQR=Q3​−Q1​=31−18=13

    The five values 111, 333, 444, 555, 777 are a sample drawn from a larger population. Find the sample variance s2s^2s2.

    Answer choices for question 6

    Solution

    Correct answer: B

    The sample mean is xˉ=1+3+4+5+75=205=4\bar{x} = \frac{1 + 3 + 4 + 5 + 7}{5} = \frac{20}{5} = 4xˉ=51+3+4+5+7​=520​=4, so the deviations are −3,−1,0,1,3-3, -1, 0, 1, 3−3,−1,0,1,3 and their squares add to

    These values are a sample, not a whole population, so divide by n−1=4n - 1 = 4n−1=4.

  7. 7

    Which quantity does the mean xˉ\bar{x}xˉ make as small as possible?

    Answer choices for question 7

    Solution

    Correct answer: A

    Expanding the total squared distance shows it is a quadratic in the guess ccc.

    S(c)=∑(xi−c)2=nc2−2c∑xi+∑xi2S(c) = \sum (x_i - c)^2 = nc^2 - 2c\sum x_i + \sum x_i^2S(c)=∑(xi​−c)2=nc2−2c∑xi​+∑xi2​

    The leading coefficient nnn is positive, so this parabola opens upward and its minimum sits at the vertex.

    c=2∑xi2n=1n∑xi=xˉc = \frac{2\sum x_i}{2n} = \frac{1}{n}\sum x_i = \bar{x}c=2n2∑xi​​=n1​∑xi​=xˉ

    So the mean is the unique minimizer of the total squared distance. The total absolute distance is minimized by the median instead, which is a different optimization problem with a different champion.

  8. 8

    Which quantity does the median make as small as possible?

    Answer choices for question 8

    Solution

    Correct answer: D

    Pair the sorted values from the outside in, the smallest with the largest and so on. For a pair a≤ba \le ba≤b, any guess ccc lying between them gives

    ∣a−c∣+∣b−c∣=(c−a)+(b−c)=b−a,\lvert a - c\rvert + \lvert b - c\rvert = (c - a) + (b - c) = b - a,∣a−c∣+∣b−c∣=(c−a)+(b−c)=b−a,

    the fixed gap between the partners, while a guess outside the pair gives strictly more. So each pair is happiest when ccc sits between its two members, and the only point inside every pair at once is the middle of the data.

    That makes the median the minimizer of the total absolute distance. The total squared distance is the mean's problem, not the median's.

    Four numbers have a mean of 151515. Three of them are 101010, 141414, and 202020. What is the fourth number?

    Answer choices for question 9

    Solution

    Correct answer: A

    The mean fixes the total, so find the total the four numbers must have.

    sum=4×15=60\text{sum} = 4 \times 15 = 60sum=4×15=60

    The three known values contribute 10+14+20=4410 + 14 + 20 = 4410+14+20=44, so the missing value is whatever is left over.

    60−44=1660 - 44 = 1660−44=16

    Check it: 10+14+20+164=604=15\frac{10 + 14 + 20 + 16}{4} = \frac{60}{4} = 15410+14+20+16​=460​=15, as required.

    In a box plot, roughly how much of the data lies inside the box, between Q1Q_1Q1​ and Q3Q_3Q3​?

    Answer choices for question 10

    Solution

    Correct answer: C

    The median cuts the sorted data in half. Q1Q_1Q1​ is the median of the lower half, so roughly a quarter of the data sits below it, and Q3Q_3Q3​ is the median of the upper half, so roughly a quarter sits above it.

    That leaves the middle for the box.

    1−14−14=121 - \tfrac{1}{4} - \tfrac{1}{4} = \tfrac{1}{2}1−41​−41​=21​

    The box holds the middle half of the data, which is why its width, the IQR, is a measure of spread that ignores the extremes on both ends.

    A data set has Q1=20Q_1 = 20Q1​=20 and Q3=32Q_3 = 32Q3​=32. By Tukey's 1.5×IQR1.5 \times \text{IQR}1.5×IQR convention, which of these values is an outlier?

    Solution
