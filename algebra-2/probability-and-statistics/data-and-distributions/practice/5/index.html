    A population of 666 values has ∑xi=48\sum x_i = 48∑xi​=48 and ∑xi2=408\sum x_i^2 = 408∑xi2​=408. Find the population variance σ2\sigma^2σ2.

    Answer choices for question 1

    Solution

    Correct answer: C

    The mean comes straight from the first sum.

    μ=486=8\mu = \frac{48}{6} = 8μ=648​=8

    Completing the square in the earlier proof left the identity ∑(xi−μ)2=∑xi2−nμ2\sum (x_i - \mu)^2 = \sum x_i^2 - n\mu^2∑(xi​−μ)2=∑xi2​−nμ2, which lets you get the sum of squared deviations without listing the data.

    ∑(xi−μ)2=408−6(82)=408−384=24\sum (x_i - \mu)^2 = 408 - 6(8^2) = 408 - 384 = 24∑(xi​−μ)2=408−6(82)=408−384=24

    These are the whole population, so divide by N=6N = 6N=6.

    σ2=246=4\sigma^2 = \frac{24}{6} = 4σ2=624​=4

    Dividing by n−1=5n - 1 = 5n−1=5 would give the sample variance 4.84.84.8, and stopping at 242424 reports the sum of squared deviations rather than its average.

  2. 2

    The data 10,11,12,48,49,5010, 11, 12, 48, 49, 5010,11,12,48,49,50 has mean 303030 and median 303030. Which statement is true?

    Answer choices for question 2

    Solution

    Correct answer: D

    Check the two centers. The total is 180180180, so the mean is 1806=30\frac{180}{6} = 306180​=30, and the median averages the third and fourth sorted values.

    median=12+482=30\text{median} = \frac{12 + 48}{2} = 30median=212+48​=30

    They agree perfectly, and yet the nearest actual data values are 121212 and 484848. The distribution is bimodal: two tight clusters with a wide empty gap between them, and both centers land in that gap.

    The data is not skewed at all, in fact it is symmetric about 303030, and its standard deviation is far from zero since the values are spread widely. This is the case where no single center is honest, and the right response is to report the two groups separately.

  3. 3

    The data 4,8,10,12,164, 8, 10, 12, 164,8,10,12,16 has mean 101010. What sixth value must be added so that the mean of all six values is still 101010?

    Answer choices for question 3

    Solution

    Correct answer: D

    For six values to have a mean of 101010, their total must be

    6×10=60.6 \times 10 = 60.6×10=60.

    The five existing values already total 4+8+10+12+16=504 + 8 + 10 + 12 + 16 = 504+8+10+12+16=50, so the new value must supply the difference.

    60−50=1060 - 50 = 1060−50=10

    The value that leaves the mean alone is the mean itself, which makes sense from the balance argument: a point sitting exactly at the balance point adds no turning force to either side. Notice, though, that it does change the population variance, since it adds a zero deviation to the pile while increasing the count.

    Solution

    The five known values contribute 11+13+14+18+20=7611 + 13 + 14 + 18 + 20 = 7611+13+14+18+20=76, so the missing value must make up the difference.

    90−76=1490 - 76 = 1490−76=14

    It is tempting to guess 151515, the mean itself, but that would only be right if the five known values already averaged 151515, and they do not: they average 765=15.2\frac{76}{5} = 15.2576​=15.2, slightly high, so the sixth value has to pull the mean back down.

  5. 5

    A data set has a standard deviation of exactly 000. What must be true?

    Answer choices for question 5

    Solution

    Correct answer: A

    The variance is an average of squared deviations, and a square is never negative. For that average to be 000, every single term must be 000.

    (xi−xˉ)2=0for every i  ⟹  xi=xˉfor every i(x_i - \bar{x})^2 = 0 \quad \text{for every } i \;\Longrightarrow\; x_i = \bar{x} \quad \text{for every } i(xi​−xˉ)2=0for every i⟹xi​=xˉfor every i

    So every value equals the mean, which means all the values are identical. The data set 7,7,7,77, 7, 7, 77,7,7,7 has standard deviation 000, and its mean and median are both 777, not 000.

    That same example rules out the claim that the data must contain exactly one value: a lone value does have zero spread, but it is not the only kind of data set that does.

    Which single number ccc minimizes the total absolute distance ∑∣xi−c∣\sum \lvert x_i - c \rvert∑∣xi​−c∣ for the data 3,8,10,10,143, 8, 10, 10, 143,8,10,10,14?

    Answer choices for question 6

    Solution

    Correct answer: C

    Total absolute distance is the median's problem, not the mean's. The data is already sorted and has an odd count, so the median is the single middle value, the third one.

    median=10\text{median} = 10median=10

    Check it against its nearest rival, the mean, which is 3+8+10+10+145=455=9\frac{3 + 8 + 10 + 10 + 14}{5} = \frac{45}{5} = 953+8+10+10+14​=545​=9. At c=10c = 10c=10 the total absolute distance is

    7+2+0+0+4=13,7 + 2 + 0 + 0 + 4 = 13,7+2+0+0+4=13,

    while at c=9c = 9c=9 it is 6+1+1+1+5=146 + 1 + 1 + 1 + 5 = 146+1+1+1+5=14, which is worse. With an odd count the median is the unique minimizer, so no other value can tie it.

  8. 8

    For a data set of 555 values that are not all equal, the sample variance is how many times the population variance?

    Answer choices for question 8

    Solution

    Correct answer: A

    Both start from the same sum of squared deviations. Call it QQQ, so that the two variances differ only in their divisor.

    σ2=Qn=Q5,s2=Qn−1=Q4\sigma^2 = \frac{Q}{n} = \frac{Q}{5}, \qquad s^2 = \frac{Q}{n-1} = \frac{Q}{4}σ2=nQ​=5Q​,s2=n−1Q​=4Q​

    Because the values are not all equal, Q>0Q > 0Q>0, so dividing one variance by the other is legitimate. The sum QQQ cancels and only the divisors survive.

    s2σ2=nn−1=54=1.25\frac{s^2}{\sigma^2} = \frac{n}{n-1} = \frac{5}{4} = 1.25σ2s2​=n−1n​=45​=1.25

    The sample variance is always the larger, and the ratio nn−1\frac{n}{n-1}n−1n​ shrinks toward 111 as nnn grows. With 555 values the correction inflates the answer by a full 252525 percent, while with 500500500 values it changes almost nothing.

    The "not all equal" condition is doing real work. If all five values were identical then Q=0Q = 0Q=0, both variances would be 000, and they really would be equal, with no ratio to speak of.

  9. 9

    Which statement about skew is correct?

    Answer choices for question 9

    Solution

    Correct answer: B

    The mean feels the size of every value in a long tail, while the median only counts how many values are out there, so a right tail usually drags the mean above the median. That signal is reliable enough to be a good skew detector, which is why a gap between the two is worth investigating.

    But it is not a theorem, and the word "always" is what breaks the other options. Statisticians have constructed data sets with a long right tail whose mean nonetheless falls below the median.

    The claim that the mean and median agree only for symmetric data fails too, because equality does not force symmetry. The data 0,2,4,4,100, 2, 4, 4, 100,2,4,4,10 has

    xˉ=205=4andmedian=4,\bar{x} = \frac{20}{5} = 4 \qquad \text{and} \qquad \text{median} = 4,xˉ=520​=4andmedian=4,

    yet it is plainly not symmetric about 444.

  10. 10

    A data set has median 121212 and IQR 555. Every value is transformed by y=2x+3y = 2x + 3y=2x+3. What are the new median and IQR?

    Answer choices for question 10

    Solution

    Correct answer: B

    Doubling and shifting is an increasing transformation, so it does not reorder the data. Whichever value was in the middle before is still in the middle, and it simply gets transformed.

    new median=2(12)+3=27\text{new median} = 2(12) + 3 = 27new median=2(12)+3=27

    The quartiles transform the same way, so

    new IQR=(2Q3+3)−(2Q1+3)=2(Q3−Q1)=2(5)=10.\text{new IQR} = (2Q_3 + 3) - (2Q_1 + 3) = 2(Q_3 - Q_1) = 2(5) = 10.new IQR=(2Q3​+3)−(2Q1​+3)=2(Q3​−Q1​)=2(5)=10.

    The +3+3+3 cancels in the subtraction, which is the point: adding a constant slides the data without stretching it, so it moves the center but leaves every measure of spread alone. Only the factor of 222 affects the IQR.

    A sample of 444 values has sample variance s2=10s^2 = 10s2=10. What is ∑(xi−xˉ)2\sum (x_i - \bar{x})^2∑(xi​−xˉ)2?

    Answer choices for question 11

    Solution

    Correct answer: D

    The sample variance divides the sum of squared deviations by n−1n - 1n−1, so run that definition backwards.

    s2=∑(xi−xˉ)2n−1  ⟹  ∑(xi−xˉ)2=s2×(n−1)s^2 = \frac{\sum (x_i - \bar{x})^2}{n - 1} \;\Longrightarrow\; \sum (x_i - \bar{x})^2 = s^2 \times (n - 1)s2=n−1∑(xi​−xˉ)2​⟹∑(xi​−xˉ)2=s2×(n−1)

    With n=4n = 4n=4 the divisor is 333, not 444.

    ∑(xi−xˉ)2=10×3=30\sum (x_i - \bar{x})^2 = 10 \times 3 = 30∑(xi​−xˉ)2=10×3=30

    Multiplying by n=4n = 4n=4 gives 404040, which is what you would get if this were a population variance. The divisor is the only thing separating the two, so it has to be read off the wording of the question.

  12. 12

    The data 4,6,7,9,10,12,13,15,16,284, 6, 7, 9, 10, 12, 13, 15, 16, 284,6,7,9,10,12,13,15,16,28 has mean 121212 and median 111111, and 282828 is an outlier by the 1.5×IQR1.5 \times \text{IQR}1.5×IQR rule. Which conclusion is best supported?

    Answer choices for question 12

    Solution

    Correct answer: C

    The mean sits above the median, and the one extreme value is far out on the high side, so the long tail runs to the right.

    xˉ=12>11=median\bar{x} = 12 > 11 = \text{median}xˉ=12>11=median

    That is the standard signature of right skew. The outlier at 282828 is exactly what is doing it: it contributes its full size to the mean, but to the median it is just one more value on the high side.

    So the median is the safer summary of a typical value here, and the mean is the one being dragged. Reporting the mean would not be wrong arithmetic, it would be a misleading description, which is the distinction the whole lesson turns on.
