    Solution

    Correct answer: A

    There are 121212 values, an even count, so cut the sorted list straight down the middle into two halves of six.

    The lower half is 8,10,12,15,18,208, 10, 12, 15, 18, 208,10,12,15,18,20 and the upper half is 22,25,27,30,33,4022, 25, 27, 30, 33, 4022,25,27,30,33,40. The third quartile is the median of that upper half, and since the half has an even count, average its two middle values, 272727 and 303030.

  4. 4

    A data set of n=5n = 5n=5 values has ∑(xi−xˉ)2=40\sum (x_i - \bar{x})^2 = 40∑(xi​−xˉ)2=40. By how much does its sample variance exceed its population variance?

    Answer choices for question 4

    Solution

    Correct answer: B

    Both formulas start from the same sum of squared deviations, 404040. Only the divisor differs.

    σ2=40n=405=8,s2=40n−1=404=10\sigma^2 = \frac{40}{n} = \frac{40}{5} = 8, \qquad s^2 = \frac{40}{n - 1} = \frac{40}{4} = 10σ2=n40​=540​=8,s2=n−140​=440​=10

    Subtracting gives the gap.

    10−8=210 - 8 = 210−8=2

    The sample version is always the larger of the two, because dividing by the smaller number n−1n - 1n−1 inflates the answer. That inflation is deliberate: deviations measured from the sample's own mean are guaranteed to come out too small, since the sample mean is the value that makes them as small as they can be.

    Set A is 18,20,2218, 20, 2218,20,22 and set B is 14,20,2614, 20, 2614,20,26. Which has the larger population standard deviation?

    Answer choices for question 5

    Solution

    Correct answer: D

    Both sets have the same mean, 202020, so compare their deviations directly.

    For set A the deviations are −2,0,2-2, 0, 2−2,0,2 and for set B they are −6,0,6-6, 0, 6−6,0,6. Square and average each list.

    σA2=4+0+43=83,σB2=36+0+363=24\sigma_A^2 = \frac{4 + 0 + 4}{3} = \frac{8}{3}, \qquad \sigma_B^2 = \frac{36 + 0 + 36}{3} = 24σA2​=34+0+4​=38​,σB2​=336+0+36​=24

    Set B's variance is nine times set A's, so its standard deviation is three times as large. Equal centers say nothing about spread, which is exactly why a mean on its own is never a summary of a data set.

  6. 6

    Group A has 333 values with a mean of 121212. Group B has 555 values with a mean of 202020. What is the mean of all 888 values together?

    Answer choices for question 6

    Solution

    Correct answer: B

    You cannot average the two means directly, because they summarize different numbers of values. Recover the totals first, using the fact that a total is the count times the mean.

    totalA=3×12=36,totalB=5×20=100\text{total}_A = 3 \times 12 = 36, \qquad \text{total}_B = 5 \times 20 = 100totalA​=3×12=36,totalB​=5×20=100

    Now pool everything and divide by the combined count.

    xˉ=36+1003+5=1368=17\bar{x} = \frac{36 + 100}{3 + 5} = \frac{136}{8} = 17xˉ=3+536+100​=8136​=17

    Averaging 121212 and 202020 naively gives 161616, which is the trap. The true mean is pulled toward 202020 because group B has more values, and the correct calculation weights each group by its size.

    For the data 1,4,6,91, 4, 6, 91,4,6,9, which values of ccc minimize the total absolute distance ∑∣xi−c∣\sum \lvert x_i - c \rvert∑∣xi​−c∣?

    Answer choices for question 8

    Solution

    Correct answer: C

    Pair the values from the outside in: (1,9)(1, 9)(1,9) and (4,6)(4, 6)(4,6). Any guess ccc lying between a pair's two members contributes exactly that pair's gap, and any guess outside it contributes more.

    So the outer pair wants 1≤c≤91 \le c \le 91≤c≤9 and the inner pair wants 4≤c≤64 \le c \le 64≤c≤6. Both are satisfied at once precisely on the inner interval, where the total is the sum of the gaps.

    (9−1)+(6−4)=10(9 - 1) + (6 - 4) = 10(9−1)+(6−4)=10

    Test it: at c=5c = 5c=5 the total is 4+1+1+4=104 + 1 + 1 + 4 = 104+1+1+4=10, and at c=4c = 4c=4 it is 3+0+2+5=103 + 0 + 2 + 5 = 103+0+2+5=10, the same. At c=3c = 3c=3 it is 2+1+3+6=122 + 1 + 3 + 6 = 122+1+3+6=12, which is worse.

    With an even count the minimizer is not unique. Every value between the two middle values ties, and the median, 555, is simply the midpoint of that winning interval.

  9. 9

    Which of these can be read directly off a box plot?

    Answer choices for question 9

    Solution

    Correct answer: D

    A box plot draws exactly five numbers: the minimum, Q1Q_1Q1​, the median, Q3Q_3Q3​, and the maximum. The line inside the box is the median, so it can be read straight off the picture.

    The other three cannot. The mean and the standard deviation depend on the sizes of every individual value, and a box plot has thrown those away. The count is invisible too: the same box plot could summarize 202020 values or 20,00020{,}00020,000.

    This is the honest cost of a box plot. It shows you the order structure of the data, and nothing else.

  11. 11

    You add one more value to an existing data set. Which of these can never decrease, no matter what value you add?

    Answer choices for question 11

    Solution

    Correct answer: B

    The range is max−min\text{max} - \text{min}max−min. A new value can only push the maximum up or leave it alone, and can only push the minimum down or leave it alone, so

    new range≥old range\text{new range} \ge \text{old range}new range≥old range

    always. The range grows or stays put, and never shrinks.

    Each of the others can fall. Adding a value below everything else drags the mean down, and it drags the median down too.

    Even the IQR can shrink. Take 10,20,60,100,11010, 20, 60, 100, 11010,20,60,100,110 and use this lesson's convention for an odd count, leaving the middle value out of both halves. The halves are 10,2010, 2010,20 and 100,110100, 110100,110, so Q1=15Q_1 = 15Q1​=15 and Q3=105Q_3 = 105Q3​=105, giving an IQR of 909090. Now add one value, 555555.

    10,  20,  55,  60,  100,  11010, \; 20, \; 55, \; 60, \; 100, \; 11010,20,55,60,100,110

    The halves are now 10,20,5510, 20, 5510,20,55 and 60,100,11060, 100, 11060,100,110, so Q1=20Q_1 = 20Q1​=20 and Q3=100Q_3 = 100Q3​=100, and the IQR has fallen to 808080.

  12. 12

    Commute times in a town cluster tightly near 101010 minutes and near 505050 minutes, with almost nobody in between. The mean and the median are both about 303030 minutes. What is the honest thing to report?

    Answer choices for question 12

    Solution

    Correct answer: D

    The distribution is bimodal: it has two separate peaks, which almost always means two different groups have been mixed together, here the people who walk and the people who drive.

    Both centers land at about 303030 minutes, in the empty valley between the peaks. That value is arithmetically correct and describes nobody's morning, since essentially no one commutes for 303030 minutes.

    When a distribution has two peaks, the fix is not to hunt for a better center. It is to split the data and report each group, which is why looking at the shape has to come before computing any summary at all.
