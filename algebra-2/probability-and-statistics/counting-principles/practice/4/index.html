  1. 1

    How many distinguishable arrangements are there of the letters in PEPPER?

    Answer choices for question 1

    Solution

    Correct answer: C

    The word has 666 letters: three P's, two E's, and one R.

    Tagged letters would give 6!=7206! = 7206!=720 arrangements, and each actual word is produced 3! 2! 1!=123!\,2!\,1! = 123!2!1!=12 times.

    6!3! 2! 1!=72012=60\frac{6!}{3!\,2!\,1!} = \frac{720}{12} = 603!2!1!6!​=12720​=60

    Divide by the factorials of the repeat counts. Dividing by 3×2=63 \times 2 = 63×2=6 instead would leave 120120120, which is not a count of anything.

  2. 2

    A pizza shop offers 101010 toppings. How many pizzas can be made using exactly 333 different toppings?

    Answer choices for question 2

    Solution

    Correct answer: A

    The toppings all go on the same pizza, so the order in which they are named changes nothing. This is an unordered choice of 333 from 101010.

    (103)=10×9×83×2×1=7206=120\binom{10}{3} = \frac{10 \times 9 \times 8}{3 \times 2 \times 1} = \frac{720}{6} = 120(310​)=3×2×110×9×8​=6720​=120

    The value 720720720 is P(10,3)P(10,3)P(10,3), which would treat mushroom-onion-pepper as different from pepper-onion-mushroom.

  3. 3

    A committee of 444 is chosen from 999 people, and one of the four is then named chair. In how many ways can this be done?

    Answer choices for question 3

    Solution

    Correct answer: B

    Build it in two stages. Choose the committee, which is unordered, and then choose the chair from within it.

    (94)=126,then 4 ways to name the chair\binom{9}{4} = 126, \qquad \text{then } 4 \text{ ways to name the chair}(49​)=126,then 4 ways to name the chair

    The second stage offers 444 choices whichever committee was formed, so the stages multiply.

    126×4=504126 \times 4 = 504126×4=504

    Building it the other way round confirms the answer: pick the chair first (999 ways), then the other three members from the remaining 888 people ((83)=56\binom{8}{3} = 56(38​)=56 ways), giving 9×56=5049 \times 56 = 5049×56=504.

  4. 4

    How many strings of 444 letters from the 262626-letter alphabet have no repeated letter and begin with a vowel (A, E, I, O, or U)?

    Answer choices for question 4

    Solution

    Correct answer: A

    Handle the restricted position first. The opening letter must be one of the 555 vowels.

    After that letter is used, no repeats are allowed, so the remaining three positions draw from the 252525 unused letters with shrinking counts.

    5×25×24×23=5×13,800=69,0005 \times 25 \times 24 \times 23 = 5 \times 13{,}800 = 69{,}0005×25×24×23=5×13,800=69,000

    The value 87,880=5×26387{,}880 = 5 \times 26^387,880=5×263 would allow the vowel to appear again later, which the no-repeat rule forbids.

    Answer choices for question 5

    Solution

    Correct answer: C

    The element 111 is forced in, so it is not a decision at all. The only freedom left is what to do with the other 777 elements, each of which is independently either in the subset or out of it.

    27=1282^7 = 12827=128

    A cleaner way to see it: exactly half of all 28=2562^8 = 25628=256 subsets contain the element 111, because removing or adding 111 pairs off the subsets that contain it with the subsets that do not.

  6. 6

    Eight points lie on a circle. How many triangles have all three vertices among these points?

    Answer choices for question 6

    Solution

    Correct answer: D

    Every choice of three of the points really does give a triangle, because a line meets a circle at most twice, so no three of the points can be collinear.

    A triangle is decided entirely by the set of three vertices it uses, and naming those vertices in a different order gives the same triangle. So the order does not matter.

    (83)=8×7×63×2×1=3366=56\binom{8}{3} = \frac{8 \times 7 \times 6}{3 \times 2 \times 1} = \frac{336}{6} = 56(38​)=3×2×18×7×6​=6336​=56

    The value 336=P(8,3)336 = P(8,3)336=P(8,3) counts ordered triples of vertices, and each triangle appears in 3!=63! = 63!=6 of them, which is exactly the factor that the division removes.

    How many distinguishable arrangements are there of the letters in GEOMETRY?

    Answer choices for question 7

    Solution

    Correct answer: B

    The word has 888 letters, and the only repeat is the letter E, which appears twice. Every other letter (G, O, M, T, R, Y) appears once.

    Tagged letters would give 8!=40,3208! = 40{,}3208!=40,320 arrangements, and each actual word is produced 2!2!2! times, once for each order of the two E's.

    8!2!=40,3202=20,160\frac{8!}{2!} = \frac{40{,}320}{2} = 20{,}1602!8!​=240,320​=20,160

  8. 8

    A committee of 444 is chosen from 555 boys and 444 girls. How many committees contain at least 222 girls?

    Answer choices for question 8

    Solution

    Correct answer: B

    There are 999 people in all, so the total number of committees is (94)=126\binom{9}{4} = 126(49​)=126. Count the committees you do not want, which have fewer than 222 girls.

    With no girls, all four seats go to boys: (54)=5\binom{5}{4} = 5(45​)=5. With exactly one girl, choose her and then three boys: (41)×(53)=4×10=40\binom{4}{1} \times \binom{5}{3} = 4 \times 10 = 40(14​)×(35​)=4×10=40.

    5+40=455 + 40 = 455+40=45

    Subtract the unwanted committees from the total.

    126−45=81126 - 45 = 81126−45=81

    A direct count agrees: (42)(52)+(43)(51)+(44)(50)=60+20+1=81\binom{4}{2}\binom{5}{2} + \binom{4}{3}\binom{5}{1} + \binom{4}{4}\binom{5}{0} = 60 + 20 + 1 = 81(24​)(25​)+(34​)(15​)+(44​)(05​)=60+20+1=81.

  9. 9

    How many distinguishable arrangements of the letters in CIRCLE have the two C's NOT next to each other?

    Answer choices for question 9

    Solution

    Correct answer: D

    Count all the arrangements, then remove the ones where the C's touch. The word has 666 letters with the C repeated twice, so all arrangements number

    6!2!=7202=360.\frac{6!}{2!} = \frac{720}{2} = 360.2!6!​=2720​=360.

    For the arrangements with the C's together, glue them into a block. That leaves 555 objects (the CC block plus I, R, L, E), all different, so there are 5!=1205! = 1205!=120 of them. No internal factor is needed, since the two C's are identical.

    360−120=240360 - 120 = 240360−120=240

  10. 10

    In how many distinguishable ways can 333 identical red flags and 222 identical blue flags be arranged in a row on a pole?

    Answer choices for question 10

    Solution

    Correct answer: A

    There are 555 flags with two types, three of one colour and two of the other. Use the repeated-object formula.

    5!3! 2!=1206×2=10\frac{5!}{3!\,2!} = \frac{120}{6 \times 2} = 103!2!5!​=6×2120​=10

    Seeing it as a choice makes it even clearer: the arrangement is decided entirely by which 222 of the 555 positions hold the blue flags, and (52)=10\binom{5}{2} = 10(25​)=10. With only two types, the arrangement formula and the binomial coefficient are the same number.

  11. 11

    How many 333-digit numbers have digits that are in strictly increasing order, such as 259259259 or 147147147?

    Answer choices for question 11

    Solution

    Correct answer: D

    A digit 000 can never appear, because in an increasing number it would have to come first, and a 333-digit number cannot start with 000. So the three digits are chosen from 111 through 999.

    Once a set of three different digits is chosen, exactly one of its 3!=63! = 63!=6 orderings is increasing, so each set gives exactly one number. Choosing the set is all the work there is.

    (93)=9×8×73×2×1=5046=84\binom{9}{3} = \frac{9 \times 8 \times 7}{3 \times 2 \times 1} = \frac{504}{6} = 84(39​)=3×2×19×8×7​=6504​=84

    The value 504=P(9,3)504 = P(9,3)504=P(9,3) counts all the orderings, but only one ordering per set is increasing, which is exactly the division being performed.

  12. 12

    A robot walks on a street grid from one corner to another, moving only right or up. Every route consists of 444 moves right and 333 moves up, in some order. How many routes are there?

    Answer choices for question 12

    Solution

    Correct answer: C

    A route is completely described by the order of its 777 moves, four of them R and three of them U, so a route is an arrangement of the letters RRRRUUU.

    The moves of each type are identical, so use the repeated-object formula.

    7!4! 3!=5,04024×6=5,040144=35\frac{7!}{4!\,3!} = \frac{5{,}040}{24 \times 6} = \frac{5{,}040}{144} = 354!3!7!​=24×65,040​=1445,040​=35

    Equivalently, a route is decided by choosing which 333 of the 777 moves are the up moves, and (73)=35\binom{7}{3} = 35(37​)=35. The two views agree, as they must, since arranging two kinds of object is the same as choosing the positions of one of them.
