  1. 1

    A normal distribution has mean μ=60\mu = 60μ=60. About which value is its density curve symmetric?

    Answer choices for question 1

    Solution

    Correct answer: D

    A normal curve is symmetric about its mean, which is also where its peak sits.

    axis of symmetry: x=μ=60\text{axis of symmetry: } x = \mu = 60axis of symmetry: x=μ=60

    The value 000 is the centre of the standard normal curve, the one whose mean has already been subtracted off. This distribution has not been standardized, so its centre is still 606060.

    According to the 68-95-99.7 rule, about what percent of a normal distribution lies within 222 standard deviations of the mean?

    Answer choices for question 2

    Solution

    Correct answer: A

    Read the middle number of the rule, which is the one attached to two standard deviations.

    P(μ−2σ<X<μ+2σ)≈95%P(\mu - 2\sigma < X < \mu + 2\sigma) \approx 95\%P(μ−2σ<X<μ+2σ)≈95%

    The figure 34%34\%34% is half of the 68%68\%68% band, the area from the mean out to one standard deviation on a single side.

  3. 3

    The standard normal table lists Φ(z)\Phi(z)Φ(z). Which area does that value give?

    Answer choices for question 3

    Solution

    Correct answer: C

    The table is built to record cumulative area, accumulated from the far left up to the value zzz.

    Φ(z)=P(Z<z)\Phi(z) = P(Z < z)Φ(z)=P(Z<z)

    So the table entry is the area to the left of zzz. Everything else is derived from that by subtraction: the area to the right is 1−Φ(z)1 - \Phi(z)1−Φ(z), and the height of the curve is not an area and so is never a probability at all.

  5. 5

    A distribution has μ=20\mu = 20μ=20 and σ=3\sigma = 3σ=3. Which value has a z-score of 222?

    Answer choices for question 5

    Solution

    Correct answer: B

    A z-score of 222 means "two standard deviations above the mean", so start at the mean and walk two standard deviations.

    x=μ+zσ=20+2(3)=26x = \mu + z\sigma = 20 + 2(3) = 26x=μ+zσ=20+2(3)=26

    The value 232323 is only one standard deviation up, and 404040 comes from doubling the mean, which has nothing to do with the spread.

  6. 6

    A distribution has μ=100\mu = 100μ=100 and σ=12\sigma = 12σ=12. What is the z-score of the value x=88x = 88x=88?

    Answer choices for question 6

    Solution

    Correct answer: B

    Subtract the mean first, keeping the sign, then divide by the standard deviation.

    z=88−10012=−1212=−1z = \frac{88 - 100}{12} = \frac{-12}{12} = -1z=1288−100​=12−12​=−1

    The value sits below the mean, so its z-score must be negative. Dropping the minus sign gives 111, which would place the value at 112112112 instead, on the wrong side of the curve.

  7. 7

    XXX is continuous. How do P(X<12)P(X < 12)P(X<12) and P(X≤12)P(X \le 12)P(X≤12) compare?

    Answer choices for question 7

    Solution

    Correct answer: D

    The two events differ only by the single outcome X=12X = 12X=12, and for a continuous quantity a single outcome has zero area and therefore zero probability.

    P(X≤12)=P(X<12)+P(X=12)=P(X<12)+0P(X \le 12) = P(X < 12) + P(X = 12) = P(X < 12) + 0P(X≤12)=P(X<12)+P(X=12)=P(X<12)+0

    So the two probabilities are equal, and the endpoint can be included or excluded freely. This is a genuine difference from discrete probability, where the two do differ whenever 121212 is a possible outcome, because there the outcome X=12X = 12X=12 carries real weight.

    According to the 68-95-99.7 rule, about what percent of a normal distribution lies within 333 standard deviations of the mean?

    Answer choices for question 8

    Solution

    Correct answer: B

    Read the last number of the rule, the one attached to three standard deviations.

    P(μ−3σ<X<μ+3σ)≈99.7%P(\mu - 3\sigma < X < \mu + 3\sigma) \approx 99.7\%P(μ−3σ<X<μ+3σ)≈99.7%

    It is close to everything but not quite everything: about 0.3%0.3\%0.3% of the distribution still lies further out than three standard deviations. The normal curve never actually reaches zero, so 100%100\%100% is wrong no matter how far out you go.

    Solution

    In the standard form φ(z)=12πe−z2/2\varphi(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2}φ(z)=2π​1​e−z2/2, the exponent −z2/2-z^2/2−z2/2 is largest when z2z^2z2 is smallest, and z2z^2z2 is smallest at z=0z = 0z=0, the centre.

    peak at z=0  ⟺  peak at x=μ\text{peak at } z = 0 \;\Longleftrightarrow\; \text{peak at } x = \mupeak at z=0⟺peak at x=μ

    Since z=0z = 0z=0 means x=μx = \mux=μ, the peak of any normal curve sits at its mean. It is only at x=0x = 0x=0 when the mean happens to be 000, which is true of the standard curve and of no other.

  11. 11

    Using the standard normal table, find P(0<Z<1)P(0 < Z < 1)P(0<Z<1).

    Answer choices for question 11

    Solution

    Correct answer: C

    For an area between two values, take the area to the left of the upper value and remove the area to the left of the lower one.

    P(0<Z<1)=Φ(1)−Φ(0)=0.8413−0.5000=0.3413P(0 < Z < 1) = \Phi(1) - \Phi(0) = 0.8413 - 0.5000 = 0.3413P(0<Z<1)=Φ(1)−Φ(0)=0.8413−0.5000=0.3413

    The entry 0.84130.84130.8413 still includes the whole left half of the curve, which this question does not want, and 0.68260.68260.6826 is the full band from −1-1−1 to 111, which is twice as wide as the one asked for.

  12. 12

    A measurement has a z-score of −2-2−2. What does that tell you?

    Answer choices for question 12

    Solution

    Correct answer: A

    The z-score is a distance measured in standard deviations, not in the original units, and its sign records the direction.

    z=x−μσ=−2  ⟺  x=μ−2σz = \frac{x - \mu}{\sigma} = -2 \;\Longleftrightarrow\; x = \mu - 2\sigmaz=σx−μ​=−2⟺x=μ−2σ

    So the value sits two standard deviations below the mean. Reading it as "222 units below" throws away the division by σ\sigmaσ, which is the whole point of standardizing.
