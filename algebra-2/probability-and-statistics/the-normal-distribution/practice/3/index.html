  6. 6

    Why are the values of Φ(z)\Phi(z)Φ(z) read from a table instead of being computed from a formula?

    Answer choices for question 6

    Solution

    Correct answer: A

    The curve itself has a perfectly good formula, φ(z)=12πe−z2/2\varphi(z) = \frac{1}{\sqrt{2\pi}} e^{-z^2/2}φ(z)=2π​1​e−z2/2, so the difficulty is not in describing it. The difficulty is in finding the area underneath it.

    no elementary function has e−z2/2 as its rate of change\text{no elementary function has } e^{-z^2/2} \text{ as its rate of change}no elementary function has e−z2/2 as its rate of change

    That is a theorem, not a gap in anyone's cleverness: no combination of powers, roots, exponentials, logarithms and trigonometric functions produces the area. So the areas are computed numerically, once, by adding up enormous numbers of very thin strips, and the results are recorded in a table.

    Standardizing has already removed μ\muμ and σ\sigmaσ from the picture, so the standard curve's areas are the same for every data set.

  9. 9

    For a continuous distribution, P(X=3)=0P(X = 3) = 0P(X=3)=0. Which statement explains this correctly?

    Answer choices for question 9

    Solution

    Correct answer: C

    For a continuous quantity, probability is defined as area under the density curve, and the region standing above one single point is infinitely thin.

    width 0  ⟹  area 0  ⟹  P(X=3)=0\text{width } 0 \;\Longrightarrow\; \text{area } 0 \;\Longrightarrow\; P(X = 3) = 0width 0⟹area 0⟹P(X=3)=0

    Probability zero is not the same as impossible: the curve is perfectly positive at x=3x = 3x=3, so values land near 333 all the time, and a measurement must land somewhere. What is impossible is landing on a value with infinitely many specified decimal places, which is what "exactly 333" demands. The height of the curve at 333 is not zero, and 333 may sit anywhere relative to the mean.

  12. 12

    A financial model assumes daily stock returns are normally distributed. In practice, extreme crashes happen far more often than the model predicts. What does this show?

    Answer choices for question 12

    Solution

    Correct answer: C

    The mathematics of the normal curve is not in question. What is in question is whether the curve fits the data, and here it does not.

    beyond 3σ under a normal curve: about 0.3% of the time\text{beyond } 3\sigma \text{ under a normal curve: about } 0.3\% \text{ of the time}beyond 3σ under a normal curve: about 0.3% of the time

    Real market returns produce far more of these extreme days than a bell curve allows, so the distribution has heavier tails than the normal. A model that assumes normality will therefore price a crash as a once-in-millennia event and be wrong.

    The Central Limit Theorem is untouched by this: it says that sums of many independent small effects tend to normality, and market moves on a crash day are anything but independent.
