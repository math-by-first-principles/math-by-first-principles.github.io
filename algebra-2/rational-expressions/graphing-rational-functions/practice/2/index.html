    Where is the hole in the graph of f(x)=x2−x−12x2−9f(x) = \dfrac{x^2-x-12}{x^2-9}f(x)=x2−9x2−x−12​?

    Answer choices for question 1

    Solution

    Correct answer: B

    Factor both parts completely.

    f(x)=(x−4)(x+3)(x−3)(x+3)f(x) = \frac{(x-4)(x+3)}{(x-3)(x+3)}f(x)=(x−3)(x+3)(x−4)(x+3)​

    The factor (x+3)(x+3)(x+3) appears once on top and once on the bottom, so it cancels completely and x=−3x=-3x=−3 is a hole. The height of the hole is the value of the simplified expression there.

    −3−4−3−3=−7−6=76\frac{-3-4}{-3-3} = \frac{-7}{-6} = \frac{7}{6}−3−3−3−4​=−6−7​=67​

    So the hole is at (−3,76)\left(-3, \frac 76\right)(−3,67​).

  2. 2

    What are the vertical asymptotes of f(x)=x2−x−12x2−9f(x) = \dfrac{x^2-x-12}{x^2-9}f(x)=x2−9x2−x−12​?

    Answer choices for question 2

    Solution

    Correct answer: D

    The original denominator (x−3)(x+3)(x-3)(x+3)(x−3)(x+3) is zero at x=3x=3x=3 and x=−3x=-3x=−3, so both are excluded from the domain. Which of them gives an asymptote depends on what cancels.

    f(x)=(x−4)(x+3)(x−3)(x+3)=x−4x−3(x≠3,  x≠−3)f(x) = \frac{(x-4)(x+3)}{(x-3)(x+3)} = \frac{x-4}{x-3} \qquad (x \neq 3,\; x \neq -3)f(x)=(x−3)(x+3)(x−4)(x+3)​=x−3x−4​(x=3,x=−3)

    The factor (x+3)(x+3)(x+3) cancelled completely, so x=−3x=-3x=−3 is a hole, not an asymptote. The factor (x−3)(x-3)(x−3) survives in the denominator, so the only vertical asymptote is x=3x=3x=3.

  3. 3

    What does the graph of f(x)=x−2(x−2)2(x+1)f(x) = \dfrac{x-2}{(x-2)^2(x+1)}f(x)=(x−2)2(x+1)x−2​ have at x=2x=2x=2?

    Answer choices for question 3

    Solution

    Correct answer: D

    This is the trap the lesson warns about: the factor (x−2)(x-2)(x−2) does appear in the numerator, but appearing is not enough. Count the copies, one on top and two on the bottom, and cancel.

    f(x)=x−2(x−2)2(x+1)=1(x−2)(x+1)(x≠2,  x≠−1)f(x) = \frac{x-2}{(x-2)^2(x+1)} = \frac{1}{(x-2)(x+1)} \qquad (x \neq 2,\; x \neq -1)f(x)=(x−2)2(x+1)x−2​=(x−2)(x+1)1​(x=2,x=−1)

    One copy of (x−2)(x-2)(x−2) is still sitting in the denominator, so the values still blow up near x=2x=2x=2. The factor did not cancel completely, so x=2x=2x=2 is a vertical asymptote, not a hole.

  4. 4

    Where does the graph of f(x)=3x2+2x2+1f(x) = \dfrac{3x^2+2}{x^2+1}f(x)=x2+13x2+2​ cross its horizontal asymptote?

    Answer choices for question 4

    Solution

    Correct answer: B

    The degrees tie, so the horizontal asymptote is the ratio of the leading coefficients, y=3y = 3y=3. To find a crossing, set the function equal to 333 and clear the denominator (which is never zero, so no solutions are lost).

    3x2+2=3(x2+1)  ⟹  3x2+2=3x2+3  ⟹  2=33x^2 + 2 = 3(x^2+1) \;\Longrightarrow\; 3x^2 + 2 = 3x^2 + 3 \;\Longrightarrow\; 2 = 33x2+2=3(x2+1)⟹3x2+2=3x2+3⟹2=3

    That is false for every xxx, so the equation has no solutions and the graph never meets y=3y=3y=3. A curve is allowed to cross a horizontal asymptote, but this particular one does not.

  5. 5

    Where does the graph of f(x)=x2+2xx2+4f(x) = \dfrac{x^2+2x}{x^2+4}f(x)=x2+4x2+2x​ cross its horizontal asymptote?

    Answer choices for question 5

    Solution

    Correct answer: C

    The degrees tie and both leading coefficients are 111, so the horizontal asymptote is y=1y=1y=1. Set the function equal to 111 and clear the denominator.

    x2+2x=x2+4  ⟹  2x=4  ⟹  x=2x^2 + 2x = x^2 + 4 \;\Longrightarrow\; 2x = 4 \;\Longrightarrow\; x = 2x2+2x=x2+4⟹2x=4⟹x=2

    Check it: f(2)=4+44+4=1f(2) = \frac{4+4}{4+4} = 1f(2)=4+44+4​=1, so the curve really does pass through (2,1)(2,1)(2,1), a point on the asymptote. The point (0,0)(0,0)(0,0) is on the graph, but it is not on the line y=1y=1y=1.

  6. 6

    What are the xxx-intercepts of f(x)=x2−4x2−x−2f(x) = \dfrac{x^2-4}{x^2-x-2}f(x)=x2−x−2x2−4​?

    Answer choices for question 6

    Solution

    Correct answer: A

    Factor and cancel first, because a zero of the numerator only counts if it is still in the domain.

    f(x)=(x−2)(x+2)(x−2)(x+1)=x+2x+1(x≠2,  x≠−1)f(x) = \frac{(x-2)(x+2)}{(x-2)(x+1)} = \frac{x+2}{x+1} \qquad (x \neq 2,\; x \neq -1)f(x)=(x−2)(x+1)(x−2)(x+2)​=x+1x+2​(x=2,x=−1)

    The original denominator excludes x=2x=2x=2, so x=2x=2x=2 can never be an xxx-intercept even though it is a zero of the original numerator: it is a hole, at height 2+22+1=43\frac{2+2}{2+1} = \frac 432+12+2​=34​. The surviving numerator is zero at x=−2x=-2x=−2, which is in the domain, so the only xxx-intercept is (−2,0)(-2,0)(−2,0).

  7. 7

    Which statement is true of the graph of f(x)=2x−6x2−9f(x) = \dfrac{2x-6}{x^2-9}f(x)=x2−92x−6​?

    Answer choices for question 7

    Solution

    Correct answer: C

    Factor the top and the bottom.

    f(x)=2(x−3)(x−3)(x+3)=2x+3(x≠3,  x≠−3)f(x) = \frac{2(x-3)}{(x-3)(x+3)} = \frac{2}{x+3} \qquad (x \neq 3,\; x \neq -3)f(x)=(x−3)(x+3)2(x−3)​=x+32​(x=3,x=−3)

    The factor (x−3)(x-3)(x−3) cancels completely, so x=3x=3x=3 is a hole, at height 23+3=13\frac{2}{3+3} = \frac 133+32​=31​. The factor (x+3)(x+3)(x+3) survives, so x=−3x=-3x=−3 is a vertical asymptote. Note that x=3x=3x=3 is not an xxx-intercept: it is not in the domain at all.

  8. 8

    What is the oblique asymptote of f(x)=3x2−2x+1x+2f(x) = \dfrac{3x^2-2x+1}{x+2}f(x)=x+23x2−2x+1​?

    Answer choices for question 8

    Solution

    Correct answer: A

    Divide 3x2−2x+13x^2-2x+13x2−2x+1 by x+2x+2x+2. The first step gives 3x3x3x, since 3x(x+2)=3x2+6x3x(x+2) = 3x^2+6x3x(x+2)=3x2+6x, and subtracting leaves −8x+1-8x+1−8x+1. The next step gives −8-8−8, since −8(x+2)=−8x−16-8(x+2) = -8x-16−8(x+2)=−8x−16, and subtracting leaves the remainder 171717.

    f(x)=3x−8+17x+2f(x) = 3x - 8 + \frac{17}{x+2}f(x)=3x−8+x+217​

    Check by multiplying back: (3x−8)(x+2)+17=3x2−2x−16+17=3x2−2x+1(3x-8)(x+2) + 17 = 3x^2-2x-16+17 = 3x^2-2x+1(3x−8)(x+2)+17=3x2−2x−16+17=3x2−2x+1. The correction term dies away far out, so the oblique asymptote is y=3x−8y = 3x-8y=3x−8.

  9. 9

    How many vertical asymptotes does the graph of f(x)=x2−1x3−xf(x) = \dfrac{x^2-1}{x^3-x}f(x)=x3−xx2−1​ have?

    Answer choices for question 9

    Solution

    Correct answer: C

    Factor everything. The denominator is x3−x=x(x−1)(x+1)x^3 - x = x(x-1)(x+1)x3−x=x(x−1)(x+1) and the numerator is (x−1)(x+1)(x-1)(x+1)(x−1)(x+1), so the domain excludes 000, 111, and −1-1−1.

    f(x)=(x−1)(x+1)x(x−1)(x+1)=1x(x≠0,  x≠1,  x≠−1)f(x) = \frac{(x-1)(x+1)}{x(x-1)(x+1)} = \frac{1}{x} \qquad (x \neq 0,\; x \neq 1,\; x \neq -1)f(x)=x(x−1)(x+1)(x−1)(x+1)​=x1​(x=0,x=1,x=−1)

    Both (x−1)(x-1)(x−1) and (x+1)(x+1)(x+1) cancel completely, so x=1x=1x=1 and x=−1x=-1x=−1 are holes (at heights 111 and −1-1−1). Only the factor xxx survives in the denominator, so there is exactly one vertical asymptote, x=0x=0x=0.

  10. 10

    Which line does the graph of f(x)=x2+1x−1f(x) = \dfrac{x^2+1}{x-1}f(x)=x−1x2+1​ approach far out?

    Answer choices for question 10

    Solution

    Correct answer: B

    The numerator has degree 222 and the denominator degree 111, so expect an oblique asymptote and divide. Dividing x2+1x^2+1x2+1 by x−1x-1x−1 gives quotient x+1x+1x+1 and remainder 222, since (x+1)(x−1)+2=x2−1+2=x2+1(x+1)(x-1) + 2 = x^2 - 1 + 2 = x^2+1(x+1)(x−1)+2=x2−1+2=x2+1.

    f(x)=x+1+2x−1f(x) = x + 1 + \frac{2}{x-1}f(x)=x+1+x−12​

    The correction 2x−1\frac{2}{x-1}x−12​ shrinks toward nothing as xxx runs off in either direction, so the curve settles onto the line y=x+1y = x+1y=x+1.

  11. 11

    What is the complete solution set of f(x)>0f(x) > 0f(x)>0 for f(x)=x+4x−2f(x) = \dfrac{x+4}{x-2}f(x)=x−2x+4​?

    Answer choices for question 11

    Solution

    Correct answer: D

    The sign can change only at the zero of the numerator, x=−4x=-4x=−4, and at the vertical asymptote, x=2x=2x=2. Test one point in each of the three intervals they create.

    f(−5)=−1−7>0,f(0)=4−2<0,f(3)=71>0f(-5) = \frac{-1}{-7} > 0, \qquad f(0) = \frac{4}{-2} < 0, \qquad f(3) = \frac{7}{1} > 0f(−5)=−7−1​>0,f(0)=−24​<0,f(3)=17​>0

    The function is positive on the outer two intervals, so the complete solution set is x<−4x < -4x<−4 or x>2x > 2x>2. Naming only one of them leaves out half the answer.

  12. 12

    Which function has a vertical asymptote at x=3x=3x=3, a hole at x=−1x=-1x=−1, and the horizontal asymptote y=0y=0y=0?

    Answer choices for question 12

    Solution

    Correct answer: A

    Build the features one at a time. A hole at x=−1x=-1x=−1 needs (x+1)(x+1)(x+1) to cancel completely, and a vertical asymptote at x=3x=3x=3 needs (x−3)(x-3)(x−3) to survive.

    x+1(x+1)(x−3)=1x−3(x≠−1,  x≠3)\frac{x+1}{(x+1)(x-3)} = \frac{1}{x-3} \qquad (x \neq -1,\; x \neq 3)(x+1)(x−3)x+1​=x−31​(x=−1,x=3)

    That leaves degree 111 underneath and degree 000 on top, so the horizontal asymptote is y=0y=0y=0, as required. The second choice cancels (x−3)(x-3)(x−3) instead, swapping the two features; the third leaves a copy of (x+1)(x+1)(x+1) downstairs, so x=−1x=-1x=−1 becomes a second asymptote; and the fourth has no common factor at all, so it has no hole and no horizontal asymptote.
