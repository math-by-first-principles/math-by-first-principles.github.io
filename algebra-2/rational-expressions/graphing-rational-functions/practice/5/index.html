    What does the graph of f(x)=x3−xx2−1f(x) = \dfrac{x^3-x}{x^2-1}f(x)=x2−1x3−x​ look like?

    Answer choices for question 1

    Solution

    Correct answer: D

    Factor everything. The numerator is x(x−1)(x+1)x(x-1)(x+1)x(x−1)(x+1) and the denominator is (x−1)(x+1)(x-1)(x+1)(x−1)(x+1), so the domain excludes x=1x=1x=1 and x=−1x=-1x=−1.

    f(x)=x(x−1)(x+1)(x−1)(x+1)=x(x≠1,  x≠−1)f(x) = \frac{x(x-1)(x+1)}{(x-1)(x+1)} = x \qquad (x \neq 1,\; x \neq -1)f(x)=(x−1)(x+1)x(x−1)(x+1)​=x(x=1,x=−1)

    Both denominator factors cancel completely, so neither excluded input gives a vertical asymptote. The graph is the line y=xy=xy=x with two points punched out, at the heights the line reaches there: (1,1)(1,1)(1,1) and (−1,−1)(-1,-1)(−1,−1).

  2. 2

    What is the xxx-intercept of f(x)=2x2+3x−2x2+2xf(x) = \dfrac{2x^2+3x-2}{x^2+2x}f(x)=x2+2x2x2+3x−2​?

    Answer choices for question 2

    Solution

    Correct answer: D

    Factor and cancel first, because a zero of the original numerator counts only if it is still in the domain.

    f(x)=(2x−1)(x+2)x(x+2)=2x−1x(x≠0,  x≠−2)f(x) = \frac{(2x-1)(x+2)}{x(x+2)} = \frac{2x-1}{x} \qquad (x \neq 0,\; x \neq -2)f(x)=x(x+2)(2x−1)(x+2)​=x2x−1​(x=0,x=−2)

    The value x=−2x=-2x=−2 is a zero of the original numerator, but it is excluded from the domain, so it is a hole rather than an intercept. The surviving numerator gives the intercept.

    2x−1=0  ⟹  x=122x - 1 = 0 \;\Longrightarrow\; x = \frac122x−1=0⟹x=21​

    So the xxx-intercept is (12,0)\left(\frac12, 0\right)(21​,0).

  3. 3

    Where does the graph of f(x)=x3+8x2+4f(x) = \dfrac{x^3+8}{x^2+4}f(x)=x2+4x3+8​ meet its oblique asymptote?

    Answer choices for question 3

    Solution

    Correct answer: B

    Divide. Dividing x3+8x^3+8x3+8 by x2+4x^2+4x2+4 gives quotient xxx with remainder 8−4x8-4x8−4x, since x(x2+4)=x3+4xx(x^2+4) = x^3+4xx(x2+4)=x3+4x and (x3+8)−(x3+4x)=8−4x(x^3+8) - (x^3+4x) = 8-4x(x3+8)−(x3+4x)=8−4x.

    f(x)=x+8−4xx2+4f(x) = x + \frac{8-4x}{x^2+4}f(x)=x+x2+48−4x​

    So the oblique asymptote is y=xy=xy=x, and the curve meets it exactly where the correction term is zero, which happens where the remainder is zero.

    8−4x=0  ⟹  x=28 - 4x = 0 \;\Longrightarrow\; x = 28−4x=0⟹x=2

    Check it: f(2)=8+84+4=2f(2) = \frac{8+8}{4+4} = 2f(2)=4+48+8​=2, and the line y=xy=xy=x is also at height 222 there, so the crossing point is (2,2)(2,2)(2,2). A constant remainder could never vanish, but this remainder is linear, so it can.

  4. 4

    Which function has the horizontal asymptote y=0y=0y=0, a vertical asymptote at x=5x=5x=5, and passes through (0,1)(0,1)(0,1)?

    Answer choices for question 4

    Solution

    Correct answer: A

    A horizontal asymptote y=0y=0y=0 needs the denominator's degree to beat the numerator's, and a vertical asymptote at x=5x=5x=5 needs the factor (x−5)(x-5)(x−5) downstairs, so the function looks like cx−5\frac{c}{x-5}x−5c​ for some nonzero constant ccc. The point (0,1)(0,1)(0,1) pins down ccc.

    c0−5=1  ⟹  c=−5\frac{c}{0-5} = 1 \;\Longrightarrow\; c = -50−5c​=1⟹c=−5

    So f(x)=−5x−5f(x) = \frac{-5}{x-5}f(x)=x−5−5​, and indeed f(0)=−5−5=1f(0) = \frac{-5}{-5} = 1f(0)=−5−5​=1. The second choice passes through (0,−1)(0,-1)(0,−1), the third has the horizontal asymptote y=1y=1y=1 (its degrees tie), and the fourth has its vertical asymptote at x=−5x=-5x=−5.

  5. 5

    Which features does the graph of f(x)=2x2+5x−3x2+x−6f(x) = \dfrac{2x^2+5x-3}{x^2+x-6}f(x)=x2+x−62x2+5x−3​ have?

    Answer choices for question 5

    Solution

    Correct answer: B

    Factor both parts: the numerator is (2x−1)(x+3)(2x-1)(x+3)(2x−1)(x+3) and the denominator is (x+3)(x−2)(x+3)(x-2)(x+3)(x−2), so the domain excludes −3-3−3 and 222.

    f(x)=(2x−1)(x+3)(x+3)(x−2)=2x−1x−2(x≠−3,  x≠2)f(x) = \frac{(2x-1)(x+3)}{(x+3)(x-2)} = \frac{2x-1}{x-2} \qquad (x \neq -3,\; x \neq 2)f(x)=(x+3)(x−2)(2x−1)(x+3)​=x−22x−1​(x=−3,x=2)

    The factor (x+3)(x+3)(x+3) cancels completely, so x=−3x=-3x=−3 is a hole, at height 2(−3)−1−3−2=−7−5=75\frac{2(-3)-1}{-3-2} = \frac{-7}{-5} = \frac 75−3−22(−3)−1​=−5−7​=57​. The factor (x−2)(x-2)(x−2) survives, so x=2x=2x=2 is a vertical asymptote. The degrees tie in the original (222 and 222), so the horizontal asymptote is the ratio of leading coefficients, 21=2\frac 21 = 212​=2.

  6. 6

    Where does the graph of f(x)=2x3+x2−1x2+1f(x) = \dfrac{2x^3+x^2-1}{x^2+1}f(x)=x2+12x3+x2−1​ meet its oblique asymptote?

    Answer choices for question 6

    Solution

    Correct answer: B

    From the division, f(x)=2x+1+−2x−2x2+1f(x) = 2x + 1 + \frac{-2x-2}{x^2+1}f(x)=2x+1+x2+1−2x−2​, so the curve sits exactly one correction term away from the line y=2x+1y = 2x+1y=2x+1. It meets the line where that correction is zero, which is where the remainder is zero.

    −2x−2=0  ⟹  x=−1-2x - 2 = 0 \;\Longrightarrow\; x = -1−2x−2=0⟹x=−1

    Check it: f(−1)=−2+1−11+1=−22=−1f(-1) = \frac{-2+1-1}{1+1} = \frac{-2}{2} = -1f(−1)=1+1−2+1−1​=2−2​=−1, and the line y=2x+1y=2x+1y=2x+1 is also at −1-1−1 there, so the crossing point is (−1,−1)(-1,-1)(−1,−1). The point (0,1)(0,1)(0,1) lies on the line but not on the curve, since f(0)=−1f(0) = -1f(0)=−1.

    How many times does the graph of f(x)=x2−3xx2+1f(x) = \dfrac{x^2-3x}{x^2+1}f(x)=x2+1x2−3x​ cross its horizontal asymptote?

    Answer choices for question 7

    Solution

    Correct answer: C

    The degrees tie and both leading coefficients are 111, so the horizontal asymptote is y=1y=1y=1. Set the function equal to 111 and clear the denominator, which is never zero.

    x2−3x=x2+1  ⟹  −3x=1  ⟹  x=−13x^2 - 3x = x^2 + 1 \;\Longrightarrow\; -3x = 1 \;\Longrightarrow\; x = -\frac{1}{3}x2−3x=x2+1⟹−3x=1⟹x=−31​

    The quadratic terms cancel, which is what always happens when the degrees tie, so what is left is linear and has exactly one solution. Check it: at x=−13x=-\frac13x=−31​ the numerator is 19+1=109\frac19 + 1 = \frac{10}{9}91​+1=910​ and the denominator is 19+1=109\frac19 + 1 = \frac{10}{9}91​+1=910​, so f(−13)=1f\left(-\frac13\right) = 1f(−31​)=1.

    What are the asymptotes of f(x)=3x2+6xx2−4f(x) = \dfrac{3x^2+6x}{x^2-4}f(x)=x2−43x2+6x​?

    Answer choices for question 8

    Solution

    Correct answer: D

    Factor both parts. The numerator is 3x(x+2)3x(x+2)3x(x+2) and the denominator is (x−2)(x+2)(x-2)(x+2)(x−2)(x+2), so the domain excludes 222 and −2-2−2.

    f(x)=3x(x+2)(x−2)(x+2)=3xx−2(x≠2,  x≠−2)f(x) = \frac{3x(x+2)}{(x-2)(x+2)} = \frac{3x}{x-2} \qquad (x \neq 2,\; x \neq -2)f(x)=(x−2)(x+2)3x(x+2)​=x−23x​(x=2,x=−2)

    The factor (x+2)(x+2)(x+2) cancels completely, so x=−2x=-2x=−2 is a hole (at height 3(−2)−2−2=32\frac{3(-2)}{-2-2} = \frac32−2−23(−2)​=23​), not an asymptote. Only x=2x=2x=2 is a vertical asymptote. The degrees tie in the original, so the horizontal asymptote is the ratio of the leading coefficients, 31=3\frac 31 = 313​=3.

  9. 9

    Which statement about the end behavior of f(x)=x4+1x2−1f(x) = \dfrac{x^4+1}{x^2-1}f(x)=x2−1x4+1​ is true?

    Answer choices for question 9

    Solution

    Correct answer: A

    Compare the degrees: 444 on top against 222 on the bottom. The top outgrows the bottom, so there is no horizontal asymptote, and the gap is two rather than one, so the quotient of the division is not linear and there is no oblique asymptote either.

    x4+1x2−1=x2+1+2x2−1\frac{x^4+1}{x^2-1} = x^2 + 1 + \frac{2}{x^2-1}x2−1x4+1​=x2+1+x2−12​

    (Check by multiplying back: (x2+1)(x2−1)+2=x4−1+2=x4+1(x^2+1)(x^2-1) + 2 = x^4 - 1 + 2 = x^4+1(x2+1)(x2−1)+2=x4−1+2=x4+1.) The curve does follow something far out, but it is the parabola y=x2+1y = x^2+1y=x2+1, not a straight line.

    Where does the graph of f(x)=4x2+xx2−1f(x) = \dfrac{4x^2+x}{x^2-1}f(x)=x2−14x2+x​ cross its horizontal asymptote?

    Answer choices for question 10

    Solution

    Correct answer: A

    The degrees tie, so the horizontal asymptote is the ratio of the leading coefficients, y=4y = 4y=4. Set the function equal to 444 and clear the denominator (its zeros, x=±1x = \pm 1x=±1, are not in the domain, so watch for them at the end).

    4x2+x=4(x2−1)  ⟹  4x2+x=4x2−4  ⟹  x=−44x^2 + x = 4(x^2-1) \;\Longrightarrow\; 4x^2 + x = 4x^2 - 4 \;\Longrightarrow\; x = -44x2+x=4(x2−1)⟹4x2+x=4x2−4⟹x=−4

    The quadratic terms cancel, leaving a linear equation, and x=−4x=-4x=−4 is safely in the domain. Check it: f(−4)=64−416−1=6015=4f(-4) = \frac{64-4}{16-1} = \frac{60}{15} = 4f(−4)=16−164−4​=1560​=4, so the crossing point is (−4,4)(-4,4)(−4,4). The origin is on the graph, but it is not on the line y=4y=4y=4.

    For which value of ccc does the graph of f(x)=x2+cx−3f(x) = \dfrac{x^2+c}{x-3}f(x)=x−3x2+c​ have a hole?

    Answer choices for question 11

    Solution

    Correct answer: C

    A hole needs the denominator's factor (x−3)(x-3)(x−3) to cancel, so (x−3)(x-3)(x−3) must divide the numerator. By the factor theorem, that means the numerator must be zero at x=3x=3x=3.

    32+c=0  ⟹  c=−93^2 + c = 0 \;\Longrightarrow\; c = -932+c=0⟹c=−9

    Check it: with c=−9c=-9c=−9 the function is x2−9x−3=(x−3)(x+3)x−3=x+3\frac{x^2-9}{x-3} = \frac{(x-3)(x+3)}{x-3} = x+3x−3x2−9​=x−3(x−3)(x+3)​=x+3 for x≠3x \neq 3x=3, the line y=x+3y=x+3y=x+3 with a hole at (3,6)(3,6)(3,6). For any other ccc the numerator is nonzero at x=3x=3x=3, so the factor stays in the denominator and x=3x=3x=3 is a vertical asymptote.
