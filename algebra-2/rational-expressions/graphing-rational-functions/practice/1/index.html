    What is the domain of f(x)=1x−7f(x) = \dfrac{1}{x-7}f(x)=x−71​?

    Answer choices for question 1

    Solution

    Correct answer: C

    The domain of a rational function drops exactly the inputs that make the denominator zero, because division by zero has no value.

    x−7=0  ⟹  x=7x - 7 = 0 \;\Longrightarrow\; x = 7x−7=0⟹x=7

    Every other real number gives an honest output, so the domain is all real xxx except x=7x = 7x=7.

  2. 2

    What is the vertical asymptote of f(x)=3x+4f(x) = \dfrac{3}{x+4}f(x)=x+43​?

    Answer choices for question 2

    Solution

    Correct answer: A

    Find the zero of the denominator first.

    x+4=0  ⟹  x=−4x + 4 = 0 \;\Longrightarrow\; x = -4x+4=0⟹x=−4

    Now check whether the factor (x+4)(x+4)(x+4) cancels. The numerator is the constant 333, which has no factor of (x+4)(x+4)(x+4), so nothing cancels and the factor stays in the denominator. The values therefore blow up near x=−4x=-4x=−4, giving a vertical asymptote at x=−4x = -4x=−4.

  3. 3

    What is the xxx-intercept of f(x)=x−4x+1f(x) = \dfrac{x-4}{x+1}f(x)=x+1x−4​?

    Answer choices for question 3

    Solution

    Correct answer: B

    A fraction equals zero exactly when its numerator is zero and its denominator is not, so set the numerator to zero.

    x−4=0  ⟹  x=4x - 4 = 0 \;\Longrightarrow\; x = 4x−4=0⟹x=4

    At x=4x=4x=4 the denominator is 555, not 000, so x=4x=4x=4 is in the domain and the xxx-intercept is (4,0)(4,0)(4,0). The value x=−1x=-1x=−1 is the vertical asymptote, not an intercept.

  4. 4

    What is the domain of f(x)=x+2x2−9f(x) = \dfrac{x+2}{x^2-9}f(x)=x2−9x+2​?

    Answer choices for question 4

    Solution

    Correct answer: A

    Factor the denominator and set each factor to zero.

    x2−9=(x−3)(x+3)=0  ⟹  x=3 or x=−3x^2 - 9 = (x-3)(x+3) = 0 \;\Longrightarrow\; x = 3 \text{ or } x = -3x2−9=(x−3)(x+3)=0⟹x=3 or x=−3

    Both values are excluded. The zero of the numerator, x=−2x=-2x=−2, is perfectly legal: it is where the graph crosses the xxx-axis.

    What are the vertical asymptotes of f(x)=x+1(x−2)(x+5)f(x) = \dfrac{x+1}{(x-2)(x+5)}f(x)=(x−2)(x+5)x+1​?

    Answer choices for question 5

    Solution

    Correct answer: B

    The denominator is zero when x−2=0x-2 = 0x−2=0 or x+5=0x+5 = 0x+5=0, so the excluded inputs are x=2x=2x=2 and x=−5x=-5x=−5.

    (x−2)(x+5)=0  ⟹  x=2 or x=−5(x-2)(x+5) = 0 \;\Longrightarrow\; x = 2 \text{ or } x = -5(x−2)(x+5)=0⟹x=2 or x=−5

    Neither factor appears in the numerator x+1x+1x+1, so neither cancels, and both excluded inputs give vertical asymptotes. The value x=−1x=-1x=−1 is the xxx-intercept, not an asymptote.

    Where is the hole in the graph of f(x)=x2−4x−2f(x) = \dfrac{x^2-4}{x-2}f(x)=x−2x2−4​?

    Answer choices for question 7

    Solution

    Correct answer: C

    The denominator is zero at x=2x=2x=2, so that input is out of the domain. Factor the numerator and cancel.

    f(x)=(x−2)(x+2)x−2=x+2(x≠2)f(x) = \frac{(x-2)(x+2)}{x-2} = x+2 \qquad (x \neq 2)f(x)=x−2(x−2)(x+2)​=x+2(x=2)

    The factor (x−2)(x-2)(x−2) cancels completely, so the graph is the line y=x+2y = x+2y=x+2 with one point missing. The missing point sits at the height the line reaches there, 2+2=42 + 2 = 42+2=4, so the hole is at (2,4)(2,4)(2,4).

    What happens to f(x)=5x−2f(x) = \dfrac{5}{x-2}f(x)=x−25​ as xxx grows very large?

    Answer choices for question 8

    Solution

    Correct answer: C

    The numerator is stuck at 555 while the denominator grows without limit, so the fraction is a fixed amount split into more and more pieces.

    f(1000)=5998≈0.005,f(1,000,000)≈0.000005f(1000) = \frac{5}{998} \approx 0.005, \qquad f(1{,}000{,}000) \approx 0.000005f(1000)=9985​≈0.005,f(1,000,000)≈0.000005

    The values shrink toward 000 without ever reaching it, so y=0y=0y=0 is the horizontal asymptote. The degree comparison says the same thing: 0<10 < 10<1, so the asymptote is y=0y=0y=0.

    What does the graph of f(x)=x+3(x+3)(x−1)f(x) = \dfrac{x+3}{(x+3)(x-1)}f(x)=(x+3)(x−1)x+3​ have at x=−3x = -3x=−3?

    Answer choices for question 9

    Solution

    Correct answer: D

    The original denominator is zero at x=−3x=-3x=−3, so that input is out of the domain no matter what happens next. Now count copies of (x+3)(x+3)(x+3): one on top, one on the bottom, so it cancels completely.

    f(x)=1x−1(x≠−3,  x≠1)f(x) = \frac{1}{x-1} \qquad (x \neq -3,\; x \neq 1)f(x)=x−11​(x=−3,x=1)

    Nothing is left in the denominator to make the values blow up, so the graph is the ordinary curve y=1x−1y = \frac{1}{x-1}y=x−11​ with the single point at x=−3x=-3x=−3 removed. That point sits at height 1−3−1=−14\frac{1}{-3-1} = -\frac14−3−11​=−41​, so the hole is at (−3,−14)\left(-3,-\frac14\right)(−3,−41​).

    What is the horizontal asymptote of f(x)=x2+2xx+1f(x) = \dfrac{x^2+2x}{x+1}f(x)=x+1x2+2x​?

    Answer choices for question 10

    Solution

    Correct answer: A

    Compare the degrees before anything else: the numerator has degree 222 and the denominator degree 111, so the top outgrows the bottom.

    x2+2xx+1=x+2 1+1x \frac{x^2+2x}{x+1} = \frac{x + 2}{\,1 + \dfrac{1}{x}\,}x+1x2+2x​=1+x1​x+2​

    Dividing top and bottom by xxx leaves an xxx upstairs, so the values grow without bound and no horizontal line can catch them. (This graph does have an oblique asymptote, but that is a slanted line, not a horizontal one.)

  11. 11

    What does the graph of f(x)=x−6x−6f(x) = \dfrac{x-6}{x-6}f(x)=x−6x−6​ look like?

    Answer choices for question 11

    Solution

    Correct answer: D

    The denominator is zero at x=6x=6x=6, so x=6x=6x=6 is out of the domain. Everywhere else the fraction is a nonzero number divided by itself.

    f(x)=x−6x−6=1(x≠6)f(x) = \frac{x-6}{x-6} = 1 \qquad (x \neq 6)f(x)=x−6x−6​=1(x=6)

    The factor cancels completely, so the graph is the horizontal line y=1y=1y=1 with the single point (6,1)(6,1)(6,1) punched out. Cancelling preserved the value but did not restore the lost input.
