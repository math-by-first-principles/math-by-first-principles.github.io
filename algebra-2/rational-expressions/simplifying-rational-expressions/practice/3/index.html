    Simplify x3+x2−4x−4x2−4\dfrac{x^3+x^2-4x-4}{x^2-4}x2−4x3+x2−4x−4​.

    Answer choices for question 1

    Solution

    Correct answer: B

    Factor the numerator by grouping the first two terms and the last two.

    x3+x2−4x−4=x2(x+1)−4(x+1)=(x+1)(x2−4)=(x+1)(x−2)(x+2)x^3+x^2-4x-4 = x^2(x+1) - 4(x+1) = (x+1)(x^2-4) = (x+1)(x-2)(x+2)x3+x2−4x−4=x2(x+1)−4(x+1)=(x+1)(x2−4)=(x+1)(x−2)(x+2)

    The denominator is (x−2)(x+2)(x-2)(x+2)(x−2)(x+2), zero at x=2x=2x=2 and x=−2x=-2x=−2, so both values are excluded before anything is cancelled.

    (x+1)(x−2)(x+2)(x−2)(x+2)=x+1(x≠2 and x≠−2)\frac{(x+1)(x-2)(x+2)}{(x-2)(x+2)} = x+1 \qquad (x \neq 2 \text{ and } x \neq -2)(x−2)(x+2)(x+1)(x−2)(x+2)​=x+1(x=2 and x=−2)

    Both restrictions vanished from view, so both must be written down. Check at x=0x=0x=0: the original is −4−4=1\frac{-4}{-4}=1−4−4​=1, and x+1x+1x+1 gives 111.

  2. 2

    What is the sum of all the excluded values of x+72x2−5x−3\dfrac{x+7}{2x^2-5x-3}2x2−5x−3x+7​?

    Answer choices for question 2

    Solution

    Correct answer: A

    The excluded values are the zeros of the denominator, so factor it.

    2x2−5x−3=(2x+1)(x−3)2x^2-5x-3 = (2x+1)(x-3)2x2−5x−3=(2x+1)(x−3)

    Setting each factor to zero gives x=−12x=-\tfrac{1}{2}x=−21​ and x=3x=3x=3, so those two are excluded. Add them.

    −12+3=52-\frac{1}{2} + 3 = \frac{5}{2}−21​+3=25​

    Vieta's formulas give the same total without factoring: the roots of ax2+bx+cax^2+bx+cax2+bx+c sum to −ba=−−52=52-\frac{b}{a} = -\frac{-5}{2} = \frac{5}{2}−ab​=−2−5​=25​.

  3. 3

    Simplify 2x3−x2−8x+4x2−4\dfrac{2x^3-x^2-8x+4}{x^2-4}x2−42x3−x2−8x+4​.

    Answer choices for question 3

    Solution

    Correct answer: A

    Group the numerator in pairs and pull out the common factor from each pair.

    2x3−x2−8x+4=x2(2x−1)−4(2x−1)=(2x−1)(x2−4)2x^3-x^2-8x+4 = x^2(2x-1) - 4(2x-1) = (2x-1)(x^2-4)2x3−x2−8x+4=x2(2x−1)−4(2x−1)=(2x−1)(x2−4)

    The denominator is x2−4=(x−2)(x+2)x^2-4 = (x-2)(x+2)x2−4=(x−2)(x+2), zero at x=2x=2x=2 and x=−2x=-2x=−2, so both are excluded.

    (2x−1)(x2−4)x2−4=2x−1(x≠2 and x≠−2)\frac{(2x-1)(x^2-4)}{x^2-4} = 2x-1 \qquad (x \neq 2 \text{ and } x \neq -2)x2−4(2x−1)(x2−4)​=2x−1(x=2 and x=−2)

    Check at x=0x=0x=0: the original is 4−4=−1\frac{4}{-4} = -1−44​=−1, and 2(0)−1=−12(0)-1 = -12(0)−1=−1 agrees.

  4. 4

    For which values of xxx is the statement x3−8x−2=x2+2x+4\dfrac{x^3-8}{x-2} = x^2+2x+4x−2x3−8​=x2+2x+4 true?

    Answer choices for question 4

    Solution

    Correct answer: C

    Since 23−8=02^3-8=023−8=0, the Factor Theorem says x−2x-2x−2 divides x3−8x^3-8x3−8, and dividing gives

    x3−8=(x−2)(x2+2x+4).x^3-8 = (x-2)(x^2+2x+4).x3−8=(x−2)(x2+2x+4).

    The only zero of the denominator is x=2x=2x=2, so that is the only excluded value. For every other xxx the factor x−2x-2x−2 is nonzero and cancels, leaving x2+2x+4x^2+2x+4x2+2x+4.

    At x=2x=2x=2 the left side is 00\frac{0}{0}00​, undefined, while the right side is 4+4+4=124+4+4=124+4+4=12. So the statement is true for every real number except x=2x=2x=2. Nothing excludes x=−2x=-2x=−2: there the original is −16−4=4\frac{-16}{-4}=4−4−16​=4, which matches 4−4+4=44-4+4=44−4+4=4.

  5. 5

    What are the excluded values of x2−1x3−2x2−x+2\dfrac{x^2-1}{x^3-2x^2-x+2}x3−2x2−x+2x2−1​?

    Answer choices for question 5

    Solution

    Correct answer: D

    Factor the denominator by grouping.

    x3−2x2−x+2=x2(x−2)−1(x−2)=(x−2)(x2−1)=(x−2)(x−1)(x+1)x^3-2x^2-x+2 = x^2(x-2) - 1(x-2) = (x-2)(x^2-1) = (x-2)(x-1)(x+1)x3−2x2−x+2=x2(x−2)−1(x−2)=(x−2)(x2−1)=(x−2)(x−1)(x+1)

    The denominator is zero at x=2x=2x=2, x=1x=1x=1, and x=−1x=-1x=−1, so all three values are excluded.

    It is tempting to keep only x=2x=2x=2, because the factors x−1x-1x−1 and x+1x+1x+1 also appear in the numerator and will cancel. They still make the original denominator zero, and the original is what defines the domain. Cancelling later cannot un-forbid an input.

  6. 6

    Simplify x2−1x3−2x2−x+2\dfrac{x^2-1}{x^3-2x^2-x+2}x3−2x2−x+2x2−1​.

    Answer choices for question 6

    Solution

    Correct answer: D

    From the grouping above, the denominator is (x−2)(x−1)(x+1)(x-2)(x-1)(x+1)(x−2)(x−1)(x+1), so the excluded values are x=2x=2x=2, x=1x=1x=1 and x=−1x=-1x=−1. The numerator is (x−1)(x+1)(x-1)(x+1)(x−1)(x+1).

    (x−1)(x+1)(x−2)(x−1)(x+1)=1x−2(x≠2,  x≠1,  x≠−1)\frac{(x-1)(x+1)}{(x-2)(x-1)(x+1)} = \frac{1}{x-2} \qquad (x \neq 2,\; x \neq 1,\; x \neq -1)(x−2)(x−1)(x+1)(x−1)(x+1)​=x−21​(x=2,x=1,x=−1)

    Both cancelled factors take their restrictions out of sight. The form 1x−2\frac{1}{x-2}x−21​ is perfectly well defined at x=1x=1x=1 and x=−1x=-1x=−1, but the original is not, so all three restrictions belong in the answer.

    Check at x=0x=0x=0: the original is −12=−12\frac{-1}{2} = -\frac{1}{2}2−1​=−21​, and 10−2=−12\frac{1}{0-2} = -\frac{1}{2}0−21​=−21​ agrees.

  7. 7

    The expression x2+bx+cx−4\dfrac{x^2+bx+c}{x-4}x−4x2+bx+c​ simplifies to x+3x+3x+3 for every x≠4x \neq 4x=4. What are bbb and ccc?

    Answer choices for question 7

    Solution

    Correct answer: B

    If the quotient reduces to x+3x+3x+3 after cancelling x−4x-4x−4, then the numerator must be the product of x−4x-4x−4 and x+3x+3x+3. Multiply them out.

    (x−4)(x+3)=x2+3x−4x−12=x2−x−12(x-4)(x+3) = x^2+3x-4x-12 = x^2-x-12(x−4)(x+3)=x2+3x−4x−12=x2−x−12

    Matching coefficients with x2+bx+cx^2+bx+cx2+bx+c gives b=−1b=-1b=−1 and c=−12c=-12c=−12.

    Check: x2−x−12x−4=(x−4)(x+3)x−4=x+3\frac{x^2-x-12}{x-4} = \frac{(x-4)(x+3)}{x-4} = x+3x−4x2−x−12​=x−4(x−4)(x+3)​=x+3 for x≠4x \neq 4x=4, as required.

  8. 8

    For how many real values of xxx is x2−4x2+4\dfrac{x^2-4}{x^2+4}x2+4x2−4​ undefined?

    Answer choices for question 8

    Solution

    Correct answer: D

    The expression is undefined exactly where the denominator is zero, so solve x2+4=0x^2+4=0x2+4=0.

    x2=−4x^2 = -4x2=−4

    No real number has a negative square, so the denominator is never zero and the expression is defined at every real number. The answer is zero values.

    The zeros of the numerator, x=2x=2x=2 and x=−2x=-2x=−2, do not make the expression undefined; there it simply equals 08=0\frac{0}{8}=080​=0.

  9. 9

    Which equation is true for every xxx in the domain of its left-hand side?

    Answer choices for question 9

    Solution

    Correct answer: C

    Only a common factor cancels, so factor before deciding.

    x2−4xx−4=x(x−4)x−4=x(x≠4)\frac{x^2-4x}{x-4} = \frac{x(x-4)}{x-4} = x \qquad (x \neq 4)x−4x2−4x​=x−4x(x−4)​=x(x=4)

    That one is a genuine cancellation, and it holds at every xxx in the domain.

    The others cancel terms, which is not a rule. In x+77\frac{x+7}{7}7x+7​ the 777 on top is added, not multiplying, and at x=1x=1x=1 the value is 87\frac{8}{7}78​, not 111. Likewise x2+99\frac{x^2+9}{9}9x2+9​ at x=1x=1x=1 is 109\frac{10}{9}910​, not 111. And x+3x+3x+3 is not a factor of x2+9x^2+9x2+9, since (−3)2+9=18≠0(-3)^2+9 = 18 \neq 0(−3)2+9=18=0; at x=1x=1x=1 the quotient is 104\frac{10}{4}410​, while x+3=4x+3=4x+3=4.

  10. 10

    Simplify 3x2−5x−2x3−8\dfrac{3x^2-5x-2}{x^3-8}x3−83x2−5x−2​.

    Answer choices for question 10

    Solution

    Correct answer: B

    The denominator has 222 as a root, since 23−8=02^3-8=023−8=0, so by the Factor Theorem x−2x-2x−2 divides it, and dividing gives x3−8=(x−2)(x2+2x+4)x^3-8 = (x-2)(x^2+2x+4)x3−8=(x−2)(x2+2x+4).

    The quadratic x2+2x+4x^2+2x+4x2+2x+4 has discriminant 22−4(1)(4)=−122^2-4(1)(4) = -1222−4(1)(4)=−12, which is negative, so it has no real zeros. The only excluded value is therefore x=2x=2x=2.

    Factor the numerator as (3x+1)(x−2)(3x+1)(x-2)(3x+1)(x−2), which you can check by expanding: 3x2−6x+x−2=3x2−5x−23x^2-6x+x-2 = 3x^2-5x-23x2−6x+x−2=3x2−5x−2.

    (3x+1)(x−2)(x−2)(x2+2x+4)=3x+1x2+2x+4(x≠2)\frac{(3x+1)(x-2)}{(x-2)(x^2+2x+4)} = \frac{3x+1}{x^2+2x+4} \qquad (x \neq 2)(x−2)(x2+2x+4)(3x+1)(x−2)​=x2+2x+43x+1​(x=2)

    Check at x=1x=1x=1: the original is −4−7=47\frac{-4}{-7} = \frac{4}{7}−7−4​=74​, and 47\frac{4}{7}74​ agrees.

    What is the value of x2−7x+12x2−9\dfrac{x^2-7x+12}{x^2-9}x2−9x2−7x+12​ at x=4x=4x=4?

    Answer choices for question 11

    Solution

    Correct answer: A

    First check whether x=4x=4x=4 is in the domain, by testing the denominator there.

    42−9=7≠04^2-9 = 7 \neq 042−9=7=0

    It is nonzero, so x=4x=4x=4 is allowed. Now evaluate the numerator: 42−7(4)+12=16−28+12=04^2-7(4)+12 = 16-28+12 = 042−7(4)+12=16−28+12=0.

    07=0\frac{0}{7} = 070​=0

    A zero on top is not a problem; only a zero on the bottom is. The expression simplifies to x−4x+3\frac{x-4}{x+3}x+3x−4​ for x≠3x \neq 3x=3 and x≠−3x \neq -3x=−3, and that form also gives 07=0\frac{0}{7} = 070​=0 at x=4x=4x=4.

    For which value of kkk does x2−kx−5\dfrac{x^2-k}{x-5}x−5x2−k​ simplify to x+5x+5x+5 for every x≠5x \neq 5x=5?

    Answer choices for question 12

    Solution

    Correct answer: C

    For x−5x-5x−5 to cancel and leave x+5x+5x+5, the numerator must be the product (x−5)(x+5)(x-5)(x+5)(x−5)(x+5).

    (x−5)(x+5)=x2−25(x-5)(x+5) = x^2-25(x−5)(x+5)=x2−25

    Matching this with x2−kx^2-kx2−k gives −k=−25-k = -25−k=−25, so k=25k=25k=25.

    Check: x2−25x−5=(x−5)(x+5)x−5=x+5\frac{x^2-25}{x-5} = \frac{(x-5)(x+5)}{x-5} = x+5x−5x2−25​=x−5(x−5)(x+5)​=x+5 for x≠5x \neq 5x=5, exactly as required.
