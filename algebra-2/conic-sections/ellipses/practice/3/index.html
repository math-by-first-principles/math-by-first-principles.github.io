    An ellipse has a string length (constant focal sum) of 2a2a2a, and its foci are 2c2c2c apart. Why must a>ca > ca>c?

    Answer choices for question 3

    Solution

    Correct answer: A

    Travelling from one focus out to a point PPP and back to the other focus can never be shorter than going straight between the foci.

    PF1+PF2≥F1F2⟹2a≥2cPF_1 + PF_2 \ge F_1F_2 \quad\Longrightarrow\quad 2a \ge 2cPF1​+PF2​≥F1​F2​⟹2a≥2c

    Equality happens only when PPP lies on the segment between the foci, and in that case the whole curve collapses to that segment. A genuine ellipse therefore needs the strict inequality a>ca > ca>c, which is also exactly what makes b2=a2−c2b^2 = a^2 - c^2b2=a2−c2 positive.

    An ellipse has foci (1,2)(1, 2)(1,2) and (9,2)(9, 2)(9,2) and passes through (5,5)(5, 5)(5,5). Find its equation.

    Answer choices for question 5

    Solution

    Correct answer: B

    The center is the midpoint of the foci, (5,2)(5, 2)(5,2), and since the foci share a yyy-coordinate the major axis is horizontal with c=4c = 4c=4. Use the definition to get aaa: add the distances from (5,5)(5, 5)(5,5) to the two foci.

    (5−1)2+(5−2)2+(5−9)2+(5−2)2=5+5=10=2a\sqrt{(5-1)^2 + (5-2)^2} + \sqrt{(5-9)^2 + (5-2)^2} = 5 + 5 = 10 = 2a(5−1)2+(5−2)2​+(5−9)2+(5−2)2​=5+5=10=2a

    So a=5a = 5a=5 and b2=a2−c2=25−16=9b^2 = a^2 - c^2 = 25 - 16 = 9b2=a2−c2=25−16=9, giving (x−5)225+(y−2)29=1\frac{(x - 5)^2}{25} + \frac{(y - 2)^2}{9} = 125(x−5)2​+9(y−2)2​=1. The given point is the co-vertex, which is why each focal distance came out equal to aaa.     Solution

    The condition 2a=2(2b)2a = 2(2b)2a=2(2b) means a=2ba = 2ba=2b. Put that into the right triangle relation.

    c2=a2−b2=4b2−b2=3b2⇒c=b3c^2 = a^2 - b^2 = 4b^2 - b^2 = 3b^2 \quad\Rightarrow\quad c = b\sqrt{3}c2=a2−b2=4b2−b2=3b2⇒c=b3​

    Which statement about the eccentricity eee of an ellipse is FALSE?

    Answer choices for question 11

    Solution

    Correct answer: C

    Every ellipse satisfies a>c≥0a > c \ge 0a>c≥0, so dividing by aaa gives

    0≤e=ca<1.0 \le e = \frac{c}{a} < 1.0≤e=ac​<1.

    The eccentricity can get as close to 111 as you like, which flattens the curve, but it never reaches 111: that would need c=ac = ac=a, and then b2=a2−c2=0b^2 = a^2 - c^2 = 0b2=a2−c2=0 and the curve would collapse to the segment between the foci. The other three statements are all true, since e=0e = 0e=0 forces c=0c = 0c=0, which merges the foci and makes a=ba = ba=b, a circle.
