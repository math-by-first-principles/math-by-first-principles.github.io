    Part C

    The claim confuses a number with a piece of notation, so the first move is to recall what the definition actually says. A complex number written in standard form a+bia + bia+bi, with aaa and bbb real, is a real number exactly when its imaginary part bbb is 000. That is a statement about a value, and it says nothing whatever about which symbols were used to write the number down.

    So the claim is refuted by any number written with an iii whose imaginary part turns out to be zero, and such numbers are not rare. Take any real ccc and any real ddd, and use the defining property i2=−1i^2 = -1i2=−1:

    c+d i2=c+d(−1)=(c−d)+0i.c + d\,i^2 = c + d(-1) = (c - d) + 0i.c+di2=c+d(−1)=(c−d)+0i.

    i34=−1i^{34} = -1i34=−1

    is one of them.

The test is always the same, and it is applied to the standard form: a complex number is real exactly when its imaginary part is 000.

    Worked solution

    Part A

    Everything in this question rests on one small computation, so do it first. Squaring i2i^2i2 gives i4i^4i4, and the defining property supplies the value twice over:

    i4=(i2)2=(−1)2=1.i^4 = \left(i^2\right)^2 = (-1)^2 = 1.i4=(i2)2=(−1)2=1.

    That single equation is what makes large exponents cheap: a factor of i4i^4i4 can be inserted or removed at will, because it is a factor of 111. So break each exponent into as many fours as it will hold, and see what is left over.

    For 614614614, taking out as many fours as it will hold leaves 222 behind, since 614=4⋅153+2614 = 4 \cdot 153 + 2614=4⋅153+2:

    i614=(i4)153⋅i2=1153⋅i2=−1.i^{614} = \left(i^4\right)^{153} \cdot i^2 = 1^{153} \cdot i^2 = -1.i614=(i4)153⋅i2=1153⋅i2=−1.

    i83=(i4)20⋅i3=120⋅i3=−i.i^{83} = \left(i^4\right)^{20} \cdot i^3 = 1^{20} \cdot i^3 = -i.i83=(i4)20⋅i3=120⋅i3=−i.

    Part B

    Both descriptions come from the same fact: ini^nin depends only on the remainder rrr of nnn on division by 444, and the four possible remainders give the four values

    i0=1,i1=i,i2=−1,i3=−i.i^0 = 1, \quad i^1 = i, \quad i^2 = -1, \quad i^3 = -i.i0=1,i1=i,i2=−1,i3=−i.

    Of those four numbers, 111 and −1-1−1 are real, while iii and −i-i−i are not (a real number cannot have a negative square, and both of these square to −1-1−1). So ini^nin is real exactly when rrr is 000 or 222, and those are precisely the even exponents:

    n=4q  or  n=4q+2  ⟺  n is even.n = 4q \ \text{ or } \ n = 4q + 2 \iff n \ \text{is even}.n=4q  or  n=4q+2⟺n is even.

    Neither description leaves anything out, and the reason is the division algorithm rather than good luck: every positive integer leaves one of the four remainders 000, 111, 222, 333, and each remainder has been accounted for. Even does not mean 111: an even exponent gives 111 or −1-1−1 according to which of the two even remainders it leaves, and only the multiples of 444 give 111.

    Part C

    An "exactly when" claim is two claims, and they need separate arguments.

    Equal remainders give equal powers. Write m=4q+rm = 4q + rm=4q+r and n=4p+rn = 4p + rn=4p+r with the same remainder rrr. Using i4=1i^4 = 1i4=1:

    im=(i4)qir=ir,in=(i4)pir=ir.i^m = \left(i^4\right)^q i^r = i^r, \qquad i^n = \left(i^4\right)^p i^r = i^r.im=(i4)qir=ir,in=(i4)pir=ir.

    Both reduce to the same number iri^rir, so im=ini^m = i^nim=in.

    First, 1≠−11 \neq -11=−1, since these are real numbers already known to be different.     i2=−1,(−i)2=i2=−1,i^2 = -1, \qquad (-i)^2 = i^2 = -1,i2=−1,(−i)2=i2=−1,

    and no real number has a negative square. So neither of them can equal the real numbers 111 or −1-1−1. All four are distinct, so ir≠isi^r \neq i^sir=is and therefore im≠ini^m \neq i^nim=in.

    Both directions hold, so the biconditional stands. It is worth seeing what the second direction buys you: without it, you would know that the cycle repeats, but not that it never repeats sooner. It is the distinctness of the four values that makes 444 the true period rather than merely a period.
