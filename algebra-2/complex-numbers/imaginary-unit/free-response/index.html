  2. Problem 2 A position in a cycle

    What is the smallest integer nnn greater than 303030 for which in=−ii^n=-iin=−i?

    2. Hint 2

    Answer

    Full solution

    31=4(7)+331=4(7)+331=4(7)+3

    Answer

    n=31n=31n=31.

  3. Problem 3 Two real entries

    Write the ordered pair consisting of the real part first and the imaginary part second for −3+i5-\sqrt3+\frac{i}{5}−3​+5i​.

    1. Hint 1

      Each entry is a real number, even though the original number is complex.

    2. Hint 2

      The coefficient multiplying iii is the imaginary part.

    Answer

    (−3,15)(-\sqrt3,\frac15)(−3​,51​).

    Full solution

    Standard form separates the two real coefficients.

    z=−3+(15)iz=-\sqrt3+\left(\frac15\right)iz=−3​+(51​)i

    Thus the real part is −3-\sqrt3−3​ and the imaginary part is 15\frac1551​; reconstructing from that pair returns the given number.

    Answer

    (−3,15)(-\sqrt3,\frac15)(−3​,51​).

    Key idea

    The imaginary part is the real coefficient of iii, not the whole imaginary term.

  4. Problem 4 Two labels for one number

    1. Hint 1

    Full solution

    The real parts require u=2u=2u=2.

    At this value the imaginary coefficient is

    u2−6=4−6u^2-6=4-6u2−6=4−6

    This is −2-2−2, as required.

    Answer

    Yes; u=2u=2u=2.

    Key idea

    A proposed equality of complex numbers must pass both part checks with the same parameters.

  7. Problem 7 An equation record

    A record lists the equations 3t=23t=23t=2 and s2=−3s^2=-3s2=−3. Solve both, taking ttt rational and sss complex, and explain how each equation illustrates an enlargement beyond a smaller familiar number system.

    1. Hint 1

      An equation may fail in one number system while succeeding in a larger one.

    2. Hint 2

      Ask whether the first equation has an integer solution and whether the second has a real one.

    Answer

    t=23t=\frac23t=32​; s=±i3s=\pm i\sqrt3s=±i3​. Integers enlarge to rationals; reals enlarge to complex numbers.

    Full solution

    t=23t=\frac23t=32​

    This rational value solves an equation with no integer solution.

    For the second equation,

    s=±i3s=\pm i\sqrt3s=±i3​

    Each candidate squares to −3-3−3, while a real square is at least zero.

    The first enlargement supplies fractions and the second supplies nonreal numbers, while the arithmetic laws continue to hold.

    Answer

    t=23t=\frac23t=32​; s=±i3s=\pm i\sqrt3s=±i3​. Integers enlarge to rationals; reals enlarge to complex numbers.

    Key idea

    Enlarging a number system supplies solutions without discarding the smaller system or its arithmetic.

    Answer

    Key idea

    Adding a multiple of four to an exponent preserves its power of iii.

  10. Problem 10 A pair of settings

    The labels (v−1)+(v+1)i(v-1)+(v+1)i(v−1)+(v+1)i and 2+7i2+7i2+7i are proposed for the same real value of vvv. Determine whether some real value of vvv makes them equal, and justify your decision.

    1. Hint 1

    Answer

    Full solution

    Matching real parts gives v−1=2v-1=2v−1=2, so v=3v=3v=3.

    Matching imaginary parts gives v+1=7v+1=7v+1=7, so v=6v=6v=6.

    Since 3≠63\ne63=6, no real value of vvv satisfies both conditions at once, so the labels can never represent the same complex number.

    Key idea

    Two labels agree only when a single value satisfies both the real-part and imaginary-part conditions at once.
