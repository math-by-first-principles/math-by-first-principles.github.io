  1. Problem 1 Four allowed points

    The grid is provided for a function with domain {−2,0,1,3}\{-2,0,1,3\}{−2,0,1,3} and rule f(x)=2−∣x∣f(x)=2-\lvert x\rvertf(x)=2−∣x∣. Draw its entire graph.

    Text description of this figure

    A grid with the horizontal axis labeled x running from -3 to 4 and the vertical axis labeled y running from -2 to 3, gridlines and number labels at every whole number, and the origin labeled 0. No point or curve is drawn.

    1. Hint 1

      The graph has one point for each declared input.

    2. Hint 2

      Evaluate the rule at the four inputs; the domain contains no values between them.

    Answer

    The four points (−2,0)(-2,0)(−2,0), (0,2)(0,2)(0,2), (1,1)(1,1)(1,1), and (3,−1)(3,-1)(3,−1), with no connecting lines.

    Full solution

    Compute the outputs.

    f(−2)=0f(0)=2f(1)=1f(3)=−1\begin{aligned}f(-2)&=0\\f(0)&=2\\f(1)&=1\\f(3)&=-1\end{aligned}f(−2)f(0)f(1)f(3)​=0=2=1=−1​

    Plot these four ordered pairs.

    Do not connect them: any connecting segment would add inputs absent from the declared domain.

    Answer

    The four points (−2,0)(-2,0)(−2,0), (0,2)(0,2)(0,2), (1,1)(1,1)(1,1), and (3,−1)(3,-1)(3,−1), with no connecting lines.

    Key idea

    A graph contains exactly the pairs allowed by both the rule and its declared domain.

  2. Problem 2 A product of factors

    Find all real zeros of f(x)=(x2+4)(2x−1)(x+2)2f(x)=(x^2+4)(2x-1)(x+2)^2f(x)=(x2+4)(2x−1)(x+2)2.

    1. Hint 1

      A product is zero when one of its factors is zero.

    2. Hint 2

      One factor is positive for every real input, while the other two can vanish.

    Answer

    x=−2x=-2x=−2 and x=12x=\frac12x=21​.

    Full solution

    The factor x2+4x^2+4x2+4 is at least 444, so it has no real zero.

    The other factors give

    2x−1=0x=12\begin{aligned}2x-1&=0\\x&=\frac12\end{aligned}2x−1x​=0=21​​

    and (x+2)2=0(x+2)^2=0(x+2)2=0, so x=−2x=-2x=−2.

    Each reported input makes a factor vanish, and there are no other ways for the product to be zero.

    Answer

    x=−2x=-2x=−2 and x=12x=\frac12x=21​.

    Key idea

    A factor that is strictly positive introduces no real zero into a product.

  3. Problem 3 A magnitude ratio

    On the domain x≠0x\ne0x=0, classify f(x)=∣x∣xf(x)=\frac{\lvert x\rvert}{x}f(x)=x∣x∣​ as even, odd, or neither by examining f(−x)f(-x)f(−x).

    1. Hint 1

      The domain must include the opposite of every allowed input.

    2. Hint 2

      Changing xxx to −x-x−x leaves its magnitude unchanged and changes the denominator sign.

    Answer

    Odd, and not even.

    Full solution

    The domain is symmetric about zero.

    For an allowed input,

    f(−x)=∣x∣−x=−f(x)\begin{aligned}f(-x)&=\frac{\lvert x\rvert}{-x}\\&=-f(x)\end{aligned}f(−x)​=−x∣x∣​=−f(x)​

    Thus the function is odd.

    It is not even because f(1)=1f(1)=1f(1)=1 and f(−1)=−1f(-1)=-1f(−1)=−1.

    Answer

    Odd, and not even.

    Key idea

    Test symmetry by replacing the full input, including its appearances inside other operations.

  4. Problem 4 A table that does not pin down the graph

    Let f(x)=x2f(x)=x^2f(x)=x2 for all real xxx. Give a rule g(x)g(x)g(x), different from f(x)f(x)f(x) for at least one input, that agrees with fff at x=0x=0x=0, x=2x=2x=2, and x=4x=4x=4. Then explain why matching fff at these three inputs cannot force g=fg=fg=f everywhere.

    1. Hint 1

      A factor built from the three sample points is zero at each one, so adding any multiple of it to fff leaves those three outputs unchanged.

    2. Hint 2

      Multiply that factor by any nonzero constant and add the result to fff.

    Answer

    For example, g(x)=x2+x(x−2)(x−4)g(x)=x^2+x(x-2)(x-4)g(x)=x2+x(x−2)(x−4); it agrees with fff at 0,2,40,2,40,2,4, but g(1)=4≠1=f(1)g(1)=4\ne1=f(1)g(1)=4=1=f(1).

    Full solution

    Let p(x)=x(x−2)(x−4)p(x)=x(x-2)(x-4)p(x)=x(x−2)(x−4), which is 000 at each sample point since one factor vanishes there.

    Adding any multiple of ppp to fff changes nothing at 0,2,40,2,40,2,4:

    g(0)=f(0)+p(0)=0+0=0,g(2)=f(2)+p(2)=4+0=4,g(4)=f(4)+p(4)=16+0=16.\begin{aligned}g(0)&=f(0)+p(0)=0+0=0,\\g(2)&=f(2)+p(2)=4+0=4,\\g(4)&=f(4)+p(4)=16+0=16.\end{aligned}g(0)g(2)g(4)​=f(0)+p(0)=0+0=0,=f(2)+p(2)=4+0=4,=f(4)+p(4)=16+0=16.​

    Away from the sample points ppp is nonzero, so ggg and fff can differ there: g(1)=1+(1)(−1)(−3)=4g(1)=1+(1)(-1)(-3)=4g(1)=1+(1)(−1)(−3)=4, while f(1)=1f(1)=1f(1)=1.

    A finite table of three matching outputs is satisfied by infinitely many different choices of the added constant, so it cannot pin down a single function.

    Answer

    For example, g(x)=x2+x(x−2)(x−4)g(x)=x^2+x(x-2)(x-4)g(x)=x2+x(x−2)(x−4); it agrees with fff at 0,2,40,2,40,2,4, but g(1)=4≠1=f(1)g(1)=4\ne1=f(1)g(1)=4=1=f(1).

    A finite table of outputs is satisfied by infinitely many different functions, so only a rule proven from its structure determines a graph.

  5. Problem 5 A replaced point

    A function on R\mathbb RR follows f(x)=2x+1f(x)=2x+1f(x)=2x+1 for x≠−1x\ne-1x=−1, but has f(−1)=−2f(-1)=-2f(−1)=−2. Draw the graph on the provided grid, and give the point removed from the line and the full range.

    Text description of this figure

    A grid with the horizontal axis labeled x running from -4 to 3 and the vertical axis labeled y running from -5 to 5, gridlines and number labels at every whole number, and the origin labeled 0. No point or curve is drawn.

    1. Hint 1

      The exceptional input replaces one point of the line with another point.

    2. Hint 2

      Find the usual line height at x=−1x=-1x=−1, then check whether its replacement height occurs elsewhere.

    Answer

    Line y=2x+1y=2x+1y=2x+1 with an open point at (−1,−1)(-1,-1)(−1,−1) and filled point at (−1,−2)(-1,-2)(−1,−2); range R∖{−1}\mathbb R\setminus\{-1\}R∖{−1}.

    Full solution

    The usual line would have height

    2(−1)+1=−12(-1)+1=-12(−1)+1=−1

    at input −1-1−1, but this point is removed.

    Place a filled point at the declared value (−1,−2)(-1,-2)(−1,−2) instead.

    Every other line height remains, and height −2-2−2 already occurs on the line at

    x=−32.x=-\frac32.x=−23​.

    The line produces height −1-1−1 only at the excluded line input −1-1−1, so the range is every real value except −1-1−1.

    Answer

    Line y=2x+1y=2x+1y=2x+1 with an open point at (−1,−1)(-1,-1)(−1,−1) and filled point at (−1,−2)(-1,-2)(−1,−2); range R∖{−1}\mathbb R\setminus\{-1\}R∖{−1}.

    Key idea

    A special value in a piecewise rule can replace a point without removing that input from the domain.

  6. Problem 6 Far from the center

    Let f(x)=−2x5+x3f(x)=-2x^5+x^3f(x)=−2x5+x3 for real xxx. Describe both ends of its graph. Justify your conclusion by taking out the highest power and bounding the remaining factor when ∣x∣≥1\lvert x\rvert\ge1∣x∣≥1.

    1. Hint 1

      A highest-power factor separates growth from a smaller correction.

    2. Hint 2

      For ∣x∣≥1\lvert x\rvert\ge1∣x∣≥1, the correction 1/x21/x^21/x2 lies between 000 and 111.

    Answer

    The left end rises without bound; the right end falls without bound.

    Full solution

    For x≠0x\ne0x=0,

    f(x)=x5(−2+1x2).f(x)=x^5\left(-2+\frac1{x^2}\right).f(x)=x5(−2+x21​).

    When ∣x∣≥1\lvert x\rvert\ge1∣x∣≥1, the factor in parentheses is at most −1-1−1 and greater than −2-2−2.

    Thus f(x)f(x)f(x) has the opposite sign to x5x^5x5 and magnitude at least ∣x∣5\lvert x\rvert^5∣x∣5.

    This magnitude grows beyond any bound: the far-left values are positive and the far-right values are negative.

    Answer

    The left end rises without bound; the right end falls without bound.

    Key idea

    A bounded nonzero correction factor preserves the growth and fixes the sign supplied by the highest power.

  7. Problem 7 A curve with a coefficient

    The graph shows f(x)=a(x+1)2(x−2)f(x)=a(x+1)^2(x-2)f(x)=a(x+1)2(x−2) for a nonzero real constant aaa. Read enough information to determine aaa, then explain whether the graph crosses or touches the horizontal axis at each zero.

    Text description of this figure

    A grid with the horizontal axis labeled x running from -3 to 3 and the vertical axis labeled y running from -5 to 6, gridlines and number labels at every whole number, and the origin labeled 0. A single smooth curve enters through the top edge of the grid a little to the left of x = -2, descends to a local low point near (-1, 0), rises to a local high point near (1, 4), then descends again and leaves through the bottom edge a little to the right of x = 2. The curve passes through (0, 2). No point is marked, no formula is written, and the curve is not labeled.

    1. Hint 1

      One readable nonzero output determines the remaining constant.

    2. Hint 2

      Use the height at input 000, then examine the powers of the two factors.

    Answer

    a=−1a=-1a=−1; touches at x=−1x=-1x=−1 and crosses at x=2x=2x=2.

    Full solution

    The graph has height 222 at input 000.

    Substitute this point into the rule.

    2=a(1)2(−2)a=−1\begin{aligned}2&=a(1)^2(-2)\\a&=-1\end{aligned}2a​=a(1)2(−2)=−1​

    The zero at −1-1−1 has even multiplicity 222, so the sign does not change there and the graph touches.

    The zero at 222 has odd multiplicity 111, so the sign changes and the graph crosses.

    The constant −1-1−1 reverses the overall signs but not these crossing decisions.

    Answer

    a=−1a=-1a=−1; touches at x=−1x=-1x=−1 and crosses at x=2x=2x=2.

    Key idea

    A point can determine an unknown coefficient while factor powers determine local crossing behavior.

  8. Problem 8 An unrecorded output

    A function has declared domain {−1,0,1}\{-1,0,1\}{−1,0,1} and codomain {0,1}\{0,1\}{0,1}. The only recorded outputs are f(−1)=0f(-1)=0f(−1)=0 and f(1)=1f(1)=1f(1)=1. A student says there are exactly two possible complete graphs. Is that correct? Explain.

    1. Hint 1

      The recorded values already fix two of the three graph points.

    2. Hint 2

      Only one input remains, and its output must lie in the two-element codomain.

    Answer

    Yes; the remaining point is either (0,0)(0,0)(0,0) or (0,1)(0,1)(0,1).

    Full solution

    Every graph must contain (−1,0)(-1,0)(−1,0) and (1,1)(1,1)(1,1).

    The only undecided input is 000, and its output must be 000 or 111.

    Thus there are exactly two possible remaining pairs, (0,0)(0,0)(0,0) and (0,1)(0,1)(0,1).

    Each completes a valid function, and the declared domain has no other inputs to choose.

    Answer

    Yes; the remaining point is either (0,0)(0,0)(0,0) or (0,1)(0,1)(0,1).

    Key idea

    A finite table can determine nearly all of a function when its declared domain is also finite.

  10. Problem 10 A restricted picture

    The formula f(x)=x2+2f(x)=x^2+2f(x)=x2+2 is assigned the domain [−2,3][-2,3][−2,3]. A student says its graph is symmetric across the vertical axis because replacing xxx by −x-x−x leaves the formula unchanged. Is the conclusion correct for this declared graph?

    1. Hint 1

      A graph includes its domain, not just its formula.

    2. Hint 2

      Check whether the domain contains the opposite of its largest input.

    Answer

    No; (3,11)(3,11)(3,11) is present but its reflection (−3,11)(-3,11)(−3,11) is absent.

    Full solution

    The formula does satisfy

    (−x)2+2=x2+2.(-x)^2+2=x^2+2.(−x)2+2=x2+2.

    However, 333 is allowed and −3-3−3 is not.

    Thus the graph contains (3,11)(3,11)(3,11) but not (−3,11)(-3,11)(−3,11), so reflection does not preserve this declared graph.

    The symmetric-domain requirement fails.

    Answer

    No; (3,11)(3,11)(3,11) is present but its reflection (−3,11)(-3,11)(−3,11) is absent.

    Key idea

    An unchanged formula does not establish graph symmetry when the declared domain lacks that symmetry.
