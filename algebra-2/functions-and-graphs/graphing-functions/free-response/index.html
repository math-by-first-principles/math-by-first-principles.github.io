    Worked solution

    Part A

    A product is 000 exactly when one of its factors is 000, so set each factor to 000 in turn.

    x+3=0⇒x=−3,(x−5)2=0⇒x=5.x + 3 = 0 \Rightarrow x = -3, \qquad (x - 5)^2 = 0 \Rightarrow x = 5.x+3=0⇒x=−3,(x−5)2=0⇒x=5.

    The third factor never reaches 000, and no solving is needed to see it. A square is never negative, so adding 444 leaves a total that cannot fall below 444:

    x2+4≥4>0for every real x.x^2 + 4 \ge 4 > 0 \quad \text{for every real } x.x2+4≥4>0for every real x.

    The only zeros are therefore −3-3−3 and 555. The factor x2+4x^2 + 4x2+4 can be set aside for the rest of the question: with no root it never splits an interval, and being always positive it never changes a sign.

    Part B

    The zeros −3-3−3 and 555 cut the line into three intervals. A linear factor changes sign only at its own root, and no root lies strictly inside any of these intervals, so every factor holds one fixed sign across each of them.

    Two of the three factors are settled once and for all. The factor (x−5)2(x - 5)^2(x−5)2 is a square, so it is positive at every input except 555, and x2+4x^2 + 4x2+4 is positive everywhere by part A. Only (x+3)(x + 3)(x+3) ever turns negative.

    For x<−3x < -3x<−3, that one factor is negative and the other two are positive:

    (−)(+)(+)=−,so f<0 on x<−3.(-)(+)(+) = -, \qquad \text{so } f < 0 \text{ on } x < -3.(−)(+)(+)=−,so f<0 on x<−3.

    For −3<x<5-3 < x < 5−3<x<5, and again for x>5x > 5x>5, the factor (x+3)(x + 3)(x+3) has turned positive while the other two are unchanged:

    (+)(+)(+)=+,so f>0 on −3<x<5 and on x>5.(+)(+)(+) = +, \qquad \text{so } f > 0 \text{ on } -3 < x < 5 \text{ and on } x > 5.(+)(+)(+)=+,so f>0 on −3<x<5 and on x>5.

    Every verdict came from multiplying three signs. Nothing was read off a curve, and no input was substituted.

    Part C

    Compare the two factors that vanish, one zero at a time.

    At x=−3x = -3x=−3 the responsible factor is (x+3)(x + 3)(x+3), to the first power. It is negative for x<−3x < -3x<−3 and positive for x>−3x > -3x>−3, while the other two factors keep their signs across −3-3−3, so the product's sign is different on the two sides:

    (−)(+)(+)=−⟶(+)(+)(+)=+.(-)(+)(+) = - \quad \longrightarrow \quad (+)(+)(+) = +.(−)(+)(+)=−⟶(+)(+)(+)=+.

    A function that is negative just to the left of a zero and positive just to the right sits on opposite sides of the axis there, so its graph crosses.

    At x=5x = 5x=5 the responsible factor is (x−5)2(x - 5)^2(x−5)2, an even power. A square is never negative, so

    (x−5)2>0for every x≠5,(x - 5)^2 > 0 \quad \text{for every } x \ne 5,(x−5)2>0for every x=5,

    and this factor contributes a +++ on both sides of 555. The other factors also keep their signs across 555, so the product is positive on both sides: the graph reaches the axis at (5,0)(5, 0)(5,0) and returns to the side it came from. It touches rather than crosses.

    Notice what the argument never used. At no point did it claim that a curve has to pass through zero in order to change sides. The sign on each side was computed from the factors, and the crossing is the conclusion drawn from those two computed signs, not the reason for them.

    In one line

    Reasoning 11 pts

    The answer

    Part A

    At each sampled input one factor of the product is 000, so ggg returns 777 and 131313 for every ccc. Away from those two inputs, g(x)−(2x+3)=c(x−2)(x−5)g(x) - (2x + 3) = c(x - 2)(x - 5)g(x)−(2x+3)=c(x−2)(x−5) is a product of three nonzero numbers when c≠0c \ne 0c=0, so it is never 000 there.

    Part C

    The reason is true but does not support the conclusion. The two rows determine a unique LINE through the two points; they never establish that fff is a line, and among all functions infinitely many fit the same two rows.

    Worked solution

    Part A

    Evaluate ggg at the two sampled inputs. Each time one factor of the product is 000, so the whole product drops out and only the line's value survives.

    g(2)=7+c(0)(−3)=7,g(5)=13+c(3)(0)=13.g(2) = 7 + c(0)(-3) = 7, \qquad g(5) = 13 + c(3)(0) = 13.g(2)=7+c(0)(−3)=7,g(5)=13+c(3)(0)=13.

    Neither result mentions ccc at all, so every choice of ccc produces a function matching both rows.

    Now compare ggg with the line away from those inputs. Subtracting the line from ggg leaves exactly the added product:

    g(x)−(2x+3)=c(x−2)(x−5).g(x) - (2x + 3) = c(x - 2)(x - 5).g(x)−(2x+3)=c(x−2)(x−5).

    Take any input other than 222 and 555. Then x−2≠0x - 2 \ne 0x−2=0 and x−5≠0x - 5 \ne 0x−5=0, and if c≠0c \ne 0c=0 the right side is a product of three nonzero numbers. A product of nonzero numbers is never 000, so

    g(x)≠2x+3for every x≠2,5.g(x) \ne 2x + 3 \qquad \text{for every } x \ne 2, 5.g(x)=2x+3for every x=2,5.

    Different nonzero constants ccc give different functions by the same subtraction, so the two table rows are shared not by one function but by infinitely many.

    Part B

    Expand the product first, then collect like terms.

    g(x)=2x+3+(x−2)(x−5)=2x+3+x2−7x+10.g(x) = 2x + 3 + (x - 2)(x - 5) = 2x + 3 + x^2 - 7x + 10.g(x)=2x+3+(x−2)(x−5)=2x+3+x2−7x+10.

    The two rules agree exactly on the table and sit 101010 apart at an input the table never reached. A quadratic and a line are not remotely the same shape, and yet these two rows cannot tell them apart.

    Part C

    Separate two different claims that the classmate has run together with the word so.

    The first claim is about lines: given two points with different first coordinates, exactly one line passes through both. That is correct, and here it really does single 2x+32x + 32x+3 out.

    The second claim is about fff: that fff is a line. Nothing in the table says so. The table reports two values and stops, and part A built, for every constant ccc, a different function returning those same two values:

Uniqueness inside a family of functions is not uniqueness among all functions, and it is the second that would be needed to name fff. This is why a plotted table is a starting point rather than evidence: the features of a graph have to be proved from a rule, and here no rule has been established.

    Worked solution

    Part A

    An input is excluded exactly when it makes the denominator 000, so factor the denominator and set each factor to 000. Two numbers multiplying to 121212 and adding to 777 are 333 and 444:

    x2−7x+12=(x−3)(x−4).x^2 - 7x + 12 = (x - 3)(x - 4).x2−7x+12=(x−3)(x−4).

    Part C

    The algebra is sound. The shared factor really does cancel, and at every input fff accepts, the two formulas return the same number.

    at x=4:x2x−3 returns 16,f returns nothing.\text{at } x = 4: \quad \frac{x^2}{x - 3} \ \text{returns } 16, \qquad f \ \text{returns nothing.}at x=4:x−3x2​ returns 16,f returns nothing.
