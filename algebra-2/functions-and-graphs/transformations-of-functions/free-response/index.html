    Worked solution

    Part A

    The height 888 belongs to the input 111 of fff, so on the new graph it reappears at whichever xxx makes the inside equal 111.

    x+5=1 ⟹ x=−4x + 5 = 1 \ \Longrightarrow\ x = -4x+5=1 ⟹ x=−4

    The outside 555 is added to whatever height fff returns, so that height becomes 8+5=138 + 5 = 138+5=13. The single point the given fact determines is (−4,13)(-4, 13)(−4,13).

    Part B

    Read what the rule actually computes at the input 111.

    f(1+5)+5=f(6)+5f(1 + 5) + 5 = f(6) + 5f(1+5)+5=f(6)+5

    The inside carries the input 111 to the input 666 of fff, and nothing at all is known about fff there. The given fact is about the input 111 of fff, which the new rule reaches from a different place, so that fact settles the height somewhere else rather than here. One further value, f(6)f(6)f(6), would settle this one.

    Part C

    The two 555s are applied at different moments. The outside 555 meets a number fff has already produced, so it does exactly what it says: every height gains 555.

    The inside 555 meets xxx before fff has run, so it changes the question rather than the answer. To find where an old input uuu reappears, ask which xxx makes the inside equal uuu, and answering that means solving for xxx.
