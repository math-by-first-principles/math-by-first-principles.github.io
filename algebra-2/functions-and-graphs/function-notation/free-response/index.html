    Part C

    Three different objects hide behind one letter.

    fff is the function itself: the rule together with the set of inputs it accepts. It is not a single output number. That does not make it untouchable: expressions like 2f2f2f and f+5f + 5f+5 do have a meaning, the pointwise one, and wherever that reading is defined what they name is another function, the rule sending xxx to 2f(x)2f(x)2f(x) or to f(x)+5f(x) + 5f(x)+5.     f( □ )=(□+3)2.f(\,\square\,) = (\square + 3)^2.f(□)=(□+3)2.

    either way. Same domain, same codomain, same value at every input, so it is the same function. Only the writing changed, which is why the input letter is safe to rename whenever another letter is more convenient.

    Worked solution

    Part A

    Expand each of the three values, keeping every input wrapped in parentheses while it is substituted:

    f(a+b)=3(a+b)2−2(a+b)=3a2+6ab+3b2−2a−2b.f(a + b) = 3(a + b)^2 - 2(a + b) = 3a^2 + 6ab + 3b^2 - 2a - 2b.f(a+b)=3(a+b)2−2(a+b)=3a2+6ab+3b2−2a−2b.

    f(a+b)−f(a)−f(b)=6ab.f(a + b) - f(a) - f(b) = 6ab.f(a+b)−f(a)−f(b)=6ab.

    The linear part −2x-2x−2x cancels on its own, which is the lesson's result about f(x)=mxf(x) = mxf(x)=mx showing up inside a larger rule. The squared part is what opens the gap.

    For a specific failure, take a=2a = 2a=2 and b=5b = 5b=5:

    f(7)=133,f(2)+f(5)=8+65=73,f(7) = 133, \qquad f(2) + f(5) = 8 + 65 = 73,f(7)=133,f(2)+f(5)=8+65=73,

    Finally, additivity holds at exactly the pairs where the surviving term is zero. A product of two real numbers is zero exactly when one of the factors is zero, so

    6ab=0  ⟺  a=0  or  b=0.6ab = 0 \iff a = 0 \ \text{ or } \ b = 0.6ab=0⟺a=0  or  b=0.

    So the identity does hold at infinitely many pairs, and every one of them contains a zero. No pair of nonzero numbers satisfies it, which is why finding a few pairs that work would be no evidence at all.

    Part B

    If x<0x < 0x<0, the constant has to be split as well, because k=0k = 0k=0 would send kxkxkx to 000, and the definition hands 000 to its first branch, not its second. Take k=0k = 0k=0 first: then kx=0kx = 0kx=0, so

    g(kx)=−(kx)=k(−x)=k∣x∣=k g(x).g(kx) = -(kx) = k(-x) = k\lvert x \rvert = k\,g(x).g(kx)=−(kx)=k(−x)=k∣x∣=kg(x).

    A negative constant breaks it. Take k=−1k = -1k=−1 and x=6x = 6x=6:

    Part C

    Putting x=1x = 1x=1 converts a statement about constants into a statement about inputs:

    f(k⋅1)=k f(1),that isf(k)=f(1) k.f(k \cdot 1) = k\,f(1), \qquad \text{that is} \qquad f(k) = f(1)\,k.f(k⋅1)=kf(1),that isf(k)=f(1)k.

    The repair is not unique. Extending the second case to 1≤x≤51 \le x \le 51≤x≤5 instead also changes one condition, also covers every real number, and also creates no conflict, since the third case still starts strictly above 555.

    Part C

    Overlap is not the test; disagreement on an overlap is. First find where both conditions of zzz hold: x≤1x \le 1x≤1 and x≥0x \ge 0x≥0 hold together at exactly the inputs with 0≤x≤10 \le x \le 10≤x≤1, a whole interval rather than a single point.

    Now compare the formulas there. At x=0x = 0x=0,

    7−2(0)=7,(0)2+4=4.7 - 2(0) = 7, \qquad (0)^2 + 4 = 4.7−2(0)=7,(0)2+4=4.

    The list says that z(0)z(0)z(0) is 777, and it also says that z(0)z(0)z(0) is 444. A function pairs each input with exactly one output, so this list has not defined anything at x=0x = 0x=0; it has given two competing definitions, and the same happens at every input of the shared interval where the formulas disagree.

    That is precisely what does not happen in www. Its first two cases also overlap, but only at the single input x=1x = 1x=1, and both cases return 555 there, so the two routes deliver the same output and every input still has exactly one. Whether an overlap is fatal depends on the values the overlapping cases produce, never on the bare fact that they overlap.

    Repairing zzz takes the same kind of edit as repairing www: one of the two conditions has to give up the disputed interval. Requiring x>1x > 1x>1 for the second case, for instance, leaves every input claimed by exactly one case.

    In one line

    At x=1x = 1x=1 both cases of www give 555, so that input receives the single output w(1)=5w(1) = 5w(1)=5.
