  1. Problem 1 An input fraction

    Let f(t)=t(3−t)f(t)=t(3-t)f(t)=t(3−t) for real ttt. Evaluate f(12)f(\frac12)f(21​).

    1. Hint 1

      The full fraction goes into every occurrence of the argument.

    2. Hint 2

      Compute the difference inside the parentheses before multiplying.

    Answer

    f(12)=54f(\frac12)=\frac54f(21​)=45​.

    Full solution

    Substitute the same input into both slots.

    f(12)=12(3−12)=12⋅52=54\begin{aligned}f(\tfrac12)&=\tfrac12(3-\tfrac12)\\&=\tfrac12\cdot\tfrac52\\&=\tfrac54\end{aligned}f(21​)​=21​(3−21​)=21​⋅25​=45​​

    Answer

    f(12)=54f(\frac12)=\frac54f(21​)=45​.

    Key idea

    Every occurrence of a function argument receives the same complete input.

  2. Problem 2 A selected branch

    A function on R\mathbb RR is given by p(t)=2−tp(t)=2-tp(t)=2−t when t≤−1t\le-1t≤−1, and p(t)=t(t+1)p(t)=t(t+1)p(t)=t(t+1) when t>−1t>-1t>−1. Find p(−1)p(-1)p(−1).

    1. Hint 1

      The branch condition is decided before evaluating its formula.

    2. Hint 2

      The equality sign tells which rule includes the boundary input.

    Answer

    p(−1)=3p(-1)=3p(−1)=3.

    Full solution

    The input −1-1−1 satisfies t≤−1t\le-1t≤−1, so use the first rule.

    p(−1)=2−(−1)=3\begin{aligned}p(-1)&=2-(-1)\\&=3\end{aligned}p(−1)​=2−(−1)=3​

    The second branch excludes −1-1−1 and contributes no alternative output.

    Answer

    p(−1)=3p(-1)=3p(−1)=3.

    Key idea

    A piecewise boundary belongs to the case whose inequality includes it.

    Parentheses keep a compound input intact in every slot of a rule.

  5. Problem 5 Two nearby inputs

    Let f(x)=x(4−x)f(x)=x(4-x)f(x)=x(4−x) for all real xxx. For real h≠0h\ne0h=0, simplify f(x+h)−f(x)h\frac{f(x+h)-f(x)}hhf(x+h)−f(x)​ and state what it measures on the graph.

    Expand the shifted output:

    f(x+h)=(x+h)(4−x−h).f(x+h)=(x+h)(4-x-h).f(x+h)=(x+h)(4−x−h).

    Multiplying out gives

    4x−x2−2xh+4h−h24x-x^2-2xh+4h-h^24x−x2−2xh+4h−h2

    Subtracting f(x)=4x−x2f(x)=4x-x^2f(x)=4x−x2 leaves 4h−2xh−h24h-2xh-h^24h−2xh−h2, which factors, since hhh divides every term, as

    h(4−2x−h)h(4-2x-h)h(4−2x−h)

    The horizontal change between the graph points is hhh and the vertical change is the numerator, so the quotient is the secant slope, or average rate of change.

  6. Problem 6 A hidden input name

    A function FFF on R\mathbb RR satisfies F(2t−1)=t2−tF(2t-1)=t^2-tF(2t−1)=t2−t for every real ttt. Find a formula for F(u)F(u)F(u) as a polynomial in uuu.

    1. Hint 1

      The slot inside FFF holds the whole expression 2t−12t-12t−1, not the bare variable ttt; find the value of ttt that makes that expression equal an arbitrary uuu.

    2. Hint 2

      Set u=2t−1u=2t-1u=2t−1 and solve for ttt, then substitute that expression into t2−tt^2-tt2−t.

    Answer

    F(u)=u2−14F(u)=\frac{u^2-1}{4}F(u)=4u2−1​.

    Full solution

    Set u=2t−1u=2t-1u=2t−1, so

    t=u+12.t=\frac{u+1}{2}.t=2u+1​.

    F(u)=(u+1)24−u+12=u2−14\begin{aligned}F(u)&=\frac{(u+1)^2}{4}-\frac{u+1}{2}\\&=\frac{u^2-1}{4}\end{aligned}F(u)​=4(u+1)2​−2u+1​=4u2−1​​

    Every real uuu comes from exactly one real ttt, so this defines the formula on the full domain.

  7. Problem 7 A naming decision

    Two devices define functions on D={−1,0,1}D=\{-1,0,1\}D={−1,0,1}. The first uses f(t)=t2+tf(t)=t^2+tf(t)=t2+t with codomain {0,2}\{0,2\}{0,2}; the second uses g(u)=u(u+1)g(u)=u(u+1)g(u)=u(u+1) with codomain {0,1,2}\{0,1,2\}{0,1,2}. Decide whether they are equal functions, and give one change to the second device data that would make them equal.

    1. Hint 1

      Equality involves the declared sets as well as the computed outputs.

    2. Hint 2

      Expand the second rule and compare the two codomains.

    Answer

    They are different; change the second codomain to {0,2}\{0,2\}{0,2}.

    Full solution

    The rules give the same outputs since

    u(u+1)=u2+u.u(u+1)=u^2+u.u(u+1)=u2+u.

    Both domains are DDD, but their declared codomains differ.

    On DDD, the output set is {0,2}\{0,2\}{0,2}, so replacing the second codomain by {0,2}\{0,2\}{0,2} is valid and makes the domains, codomains, and all outputs match.

    Answer

    They are different; change the second codomain to {0,2}\{0,2\}{0,2}.

    Key idea

    Equivalent formulas and matching domains still need matching codomains for equality of functions.

    But the two proposed rules give 888 and 555 at input 000.

    Answer

    Not justified; for example f(x)=x+8f(x)=x+8f(x)=x+8 and g(x)=2x+5g(x)=2x+5g(x)=2x+5 both give 111111 at 333 and differ elsewhere.

  9. Problem 9 A claim about combining inputs

    Let f(x)=∣x∣f(x)=\lvert x\rvertf(x)=∣x∣ for real xxx. A student claims f(a+b)=f(a)+f(b)f(a+b)=f(a)+f(b)f(a+b)=f(a)+f(b) for all real a,ba,ba,b. Assess the claim with one pair for which it fails and one pair for which it holds.

  10. Problem 10 A scaled argument

    For f(x)=−32xf(x)=-\frac32xf(x)=−23​x on R\mathbb RR, a student claims f(kx)=kf(x)f(kx)=kf(x)f(kx)=kf(x) for every real k,xk,xk,x. Is the claim correct? Prove the verdict directly from the rule.

    1. Hint 1

    2. Hint 2

      Compare the two products using associativity and commutativity of multiplication.

    Answer

    Yes; f(kx)=kf(x)f(kx)=kf(x)f(kx)=kf(x) for every real k,xk,xk,x.

    Full solution

    Substitution gives

    f(kx)=−32(kx).f(kx)=-\frac32(kx).f(kx)=−23​(kx).

    Associativity and commutativity rewrite this as k(−32x)k(-\frac32x)k(−23​x), which is kf(x)kf(x)kf(x).

    Both expressions are defined for every real k,xk,xk,x, so the equality holds throughout the stated domain.

    Answer

    Yes; f(kx)=kf(x)f(kx)=kf(x)f(kx)=kf(x) for every real k,xk,xk,x.

    Key idea

    A constant multiple of the input respects scaling because real multiplication is associative and commutative.
