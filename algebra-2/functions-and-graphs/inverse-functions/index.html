Inverse Functions

Intuition

Take f(x)=2x+1f(x) = 2x + 1f(x)=2x+1. Put in 333 and get 777. Now subtract 111, then divide by 222: 777 turns back into 333, two steps that exactly undo fff‘s two steps. A function that does this for fff, always turning fff‘s output back into fff‘s input, is called an inverse of fff.

Not every function can be undone this way. Squaring turns both 333 and −3-3−3 into 999, so the output 999 alone does not say which input made it. Once that sign is gone, no rule can bring it back. This lesson asks exactly which functions can be undone, and it turns out the answer hinges on one word: both. An inverse has to undo fff in both directions, not just one, and telling those two cases apart is the whole lesson.

There is also a structural reason to care. The previous lesson looked at functions that map a set back into itself, like f∘ff \circ ff∘f, and showed that composing such functions is associative and has an identity, id⁡(x)=x\operatorname{id}(x) = xid(x)=x, two of the three things a group needs. The missing third is an inverse for every element, which is why composing functions from a set to itself only makes a monoid rather than a group. This lesson supplies that missing piece for the functions that have one.

Learning goals

  • Verify a candidate inverse by checking that both compositions equal the identity
  • Explain why a function has at most one inverse
  • Decide whether a function is invertible by testing whether it is one-to-one
  • Find an inverse algebraically and state its domain and range
  • Justify why restricting a domain to create an inverse is a choice, not a fixed repair
  • Connect the horizontal line test to swapping each pair (a,b)(a, b)(a,b) into (b,a)(b, a)(b,a)

An inverse must undo f from both sides

Give the idea its definition. A function ggg is an inverse of fff when composing the two in either order returns the identity:

g∘f=id⁡  on dom⁡fandf∘g=id⁡  on dom⁡g.g \circ f = \operatorname{id} \ \text{ on } \operatorname{dom} f \qquad\text{and}\qquad f \circ g = \operatorname{id} \ \text{ on } \operatorname{dom} g.g∘f=id  on domfandf∘g=id  on domg.

Read both halves. The first, g(f(x))=xg(f(x)) = xg(f(x))=x for every xxx in the domain of fff, says ggg undoes fff: feed xxx through fff and ggg brings it back. The second, f(g(x))=xf(g(x)) = xf(g(x))=x for every xxx in the domain of ggg, says fff undoes ggg the same way. Reversing has to work in both directions, and we insist on both because one alone can hold while the other fails. The example that shows this is the heart of the lesson.

Worked example 1 One side is not enough

Let f(x)=x2f(x) = x^2f(x)=x2 with domain all real numbers, and let g(x)=xg(x) = \sqrt{x}g(x)=x​ with domain x≥0x \ge 0x≥0. Test both compositions.

(g∘f)(x)=g(x2)=x2=∣x∣.(g \circ f)(x) = g(x^2) = \sqrt{x^2} = |x|.(g∘f)(x)=g(x2)=x2​=∣x∣.

This equals xxx when x≥0x \ge 0x≥0, but for x<0x < 0x<0 it gives −x-x−x, not xxx. For instance (g∘f)(−3)=9=3≠−3(g \circ f)(-3) = \sqrt{9} = 3 \ne -3(g∘f)(−3)=9​=3=−3. Answer choices

An inverse must satisfy both g∘f=id⁡g \circ f = \operatorname{id}g∘f=id and f∘g=id⁡f \circ g = \operatorname{id}f∘g=id. Here only the second holds.

(g∘f)(x)=x2=∣x∣(g \circ f)(x) = \sqrt{x^2} = |x|(g∘f)(x)=x2​=∣x∣

For x<0x < 0x<0 this is −x≠x-x \ne x−x=x, so ggg fails to undo fff on the negative inputs, and ggg is not an inverse of fff at all.

The uniqueness fact, that a function cannot have two different inverses, is a statement about functions that already have one; it never promises that an inverse exists in the first place. Since f(x)=x2f(x) = x^2f(x)=x2 on all reals fails the two-sided test no matter what ggg is tried, fff simply has no inverse here, and there is nothing for uniqueness to protect.

When both sides do hold, the verification is a short two-part check, and skipping either part is the most common way to get an inverse wrong.

There is only one inverse

Because the definition is two-sided, a function cannot have two different inverses. Here is why: suppose ggg and hhh both undid fff from both directions. Take any output bbb of fff. Since hhh is an inverse, f(h(b))=bf(h(b)) = bf(h(b))=b; feed that into ggg, and since ggg undoes fff, g(f(h(b)))=h(b)g(f(h(b))) = h(b)g(f(h(b)))=h(b). But the left side is also g(b)g(b)g(b), because f(h(b))=bf(h(b)) = bf(h(b))=b. So g(b)=h(b)g(b) = h(b)g(b)=h(b) for every bbb: ggg and hhh agree everywhere, which makes them the same function. Because there is at most one inverse, we may speak of the inverse of fff and give it the name f−1f^{-1}f−1.

What justifies reading the same expression both ways?

Answer choices

Associativity says g∘(f∘h)g \circ (f \circ h)g∘(f∘h) and (g∘f)∘h(g \circ f) \circ h(g∘f)∘h are the same function, so applying that function to bbb gives one value no matter how you group the three applications.

Which functions can be inverted

Not every function has an inverse; Worked Example 1 already met one that does not. The question is which do, and the answer is the cleanest statement in the chapter, provided we say one thing about the codomain out loud and then never forget it.

Throughout the rest of this lesson, take a function’s codomain to be its range, the set of values it actually outputs. A function is one-to-one when different inputs always give different outputs, equivalently when f(a)=f(b)f(a) = f(b)f(a)=f(b) forces a=ba = ba=b. With the codomain fixed as the range, invertibility and one-to-oneness are the same condition.

Here is why. Draw an arrow from each input to the output it produces. If fff is one-to-one, no two arrows point at the same output, so every output in the range has exactly one arrow pointing at it. Reverse every arrow and you get a new set of arrows, one leaving each output and landing back on the input it came from, and that is a function: it is f−1f^{-1}f−1. If instead two arrows had pointed at the same output, reversing them would leave that output with two arrows going out to two different inputs, which is not a function at all, since a function may only give one answer per input. So the reversed arrows form a function exactly when the original arrows never collided, which is exactly one-to-one.

The arrows above give the idea. The Go deeper section turns it into a proof: it builds the inverse explicitly out of one-to-oneness, and separately shows that having any inverse at all forces one-to-oneness.

See the full argument

The codomain hypothesis is not decoration, and dropping it is the classic way this statement turns false. If the codomain is left larger than the range, some declared output is never actually produced, and no ggg can satisfy f∘g=id⁡f \circ g = \operatorname{id}f∘g=id there. That is because f(g(b))f(g(b))f(g(b)) is always a genuine output of fff, and it can never equal a value that fff misses. With a larger codomain the correct condition is that fff be both one-to-one and onto, that is a bijection. Taking the codomain to be the range is exactly what makes “onto” automatic, and that leaves one-to-one as the only thing to check. Whenever this lesson says “invertible” it means “one-to-one, as a map onto its range.”

Swapping pairs is what inverting really does

Take the three pairs (1,4),(2,7),(3,10)(1, 4), (2, 7), (3, 10)(1,4),(2,7),(3,10), the input-output pairs of some function fff. Swap every pair’s coordinates and you get (4,1),(7,2),(10,3)(4, 1), (7, 2), (10, 3)(4,1),(7,2),(10,3): the same information, read backward, output first. Every input of fff becomes an output, and every output becomes an input. That swapped set of pairs is exactly f−1f^{-1}f−1, when it is a function at all.

Now try it on a function that is not one-to-one: (−2,4)(-2, 4)(−2,4) and (2,4)(2, 4)(2,4). Swapping gives (4,−2)(4, -2)(4,−2) and (4,2)(4, 2)(4,2), two different pairs that start with the same first number, 444. A function may only give one answer per input, so this swapped set is not a function; there is no way to know whether 444 should go back to −2-2−2 or to 222. A repeated output is exactly what breaks the swap.

This connects to a claim from the first lesson of this chapter, Relations and Functions: swapping the two variables reflects the whole picture across y=xy = xy=x, and the horizontal line test is the vertical line test asked about the swapped picture. Both claims are now proven at once. A function fff is, underneath, its set of pairs (a,f(a))(a, f(a))(a,f(a)). Swapping every pair gives the inverse relation, and that swapped set is a function of its first coordinate exactly when no two of fff‘s pairs share a second coordinate, that is, exactly when fff is one-to-one, which on a graph is the horizontal line test. So the swapped relation is a function precisely when fff passes the horizontal line test, and only then is there an inverse function f−1f^{-1}f−1.

Being a function was never a property of a curve alone; it was a property of a curve together with a choice of input. Inverting changes that choice, feeding in what used to come out. So “can fff be undone” and “does fff pass the horizontal line test” are the same question asked two ways.

Restricting the domain is a real choice

Worked Example 1 showed that f(x)=x2f(x) = x^2f(x)=x2 on all real numbers has no inverse, because it fails the horizontal line test: f(−2)=f(2)=4f(-2) = f(2) = 4f(−2)=f(2)=4. The standard repair is to shrink the domain until the rule becomes one-to-one. It is worth being honest about what that move is. You are not fixing fff; by the equality test of the Function Notation lesson, a rule together with a smaller domain is a different function. Restricting the domain replaces the function that had no inverse with a neighbouring one that does.

The inverse is f−1(x)=x−3f^{-1}(x) = x - 3f−1(x)=x−3, and by the swap its domain is 3≤x≤83 \le x \le 83≤x≤8, the range fff just had, while its own range is 0≤y≤50 \le y \le 50≤y≤5, the domain fff just had. Inverting does not merely flip a formula; it swaps the two sets a function lives between, and the domain is genuine data, carried along with the rule.

Check your understanding

Let f(x)=2x−1f(x) = 2x - 1f(x)=2x−1 on the domain 1≤x≤41 \le x \le 41≤x≤4, so its range is 1≤y≤71 \le y \le 71≤y≤7. What are the domain AND range of f−1f^{-1}f−1?

Reading the inverse off the graph

The coordinate swap has a picture. A point (a,b)(a, b)(a,b) lies on the graph of fff exactly when b=f(a)b = f(a)b=f(a), and that is exactly when (b,a)(b, a)(b,a) lies on the graph of f−1f^{-1}f−1. So the graph of f−1f^{-1}f−1 is the set of points (b,a)(b, a)(b,a) as (a,b)(a, b)(a,b) runs over the graph of fff. The map that sends every point (a,b)(a, b)(a,b) to (b,a)(b, a)(b,a) is reflection in the line y=xy = xy=x: it fixes that line and exchanges the horizontal and vertical directions. Therefore the graph of f−1f^{-1}f−1 is the mirror image of the graph of fff across y=xy = xy=x. That is not by decree but because inverting is swapping coordinates, and swapping coordinates is that reflection.

Reflection across y=xy = xy=x also preserves a graph’s direction: if fff is increasing, so is f−1f^{-1}f−1, and if fff is decreasing, so is f−1f^{-1}f−1. Here is why: “increasing” means that whenever the input goes up, the output goes up too, so an input-step and its matching output-step always point the same way. Swapping coordinates swaps which one you call the input, but it cannot flip just one of the two steps, so they still point the same way after the swap. A rising curve reflects to a rising curve, and a falling one to a falling one.

The Go deeper section shows this holds for every increasing function, not just the ones you can see on a graph: a rising curve always reflects to a rising curve, and a falling curve always reflects to a falling one, with no exceptions.

See the full argument

That mirror is a reliable way to picture an inverse, with one caution. It is tempting to think the two graphs can only meet on the line y=xy = xy=x, since that is where the mirror itself sits. That is not true in general: the reflection carries the two graphs into each other, so wherever they cross, the crossings mirror each other too, but a set can mirror itself without lying entirely on the mirror line. What is always true is narrower: if f(a)=af(a) = af(a)=a for some input aaa, then aaa is a fixed point, (a,a)(a, a)(a,a) sits on y=xy = xy=x, and since f−1(a)=af^{-1}(a) = af−1(a)=a too, that point lies on both graphs. So every fixed point is a common point on y=xy = xy=x, but a common point off y=xy = xy=x can still happen, as the next example shows.

Worked example 6 Where f(x)=−x3f(x) = -x^3f(x)=−x3 meets its inverse

The function f(x)=−x3f(x) = -x^3f(x)=−x3 on all real numbers is one-to-one, and its inverse is f−1(x)=−x3f^{-1}(x) = -\sqrt[3]{x}f−1(x)=−3x​, the negative of the real cube root. Find every point the two graphs share.

A shared point is an xxx with f(x)=f−1(x)f(x) = f^{-1}(x)f(x)=f−1(x), so set the two rules equal:

−x3=−x3⟹x3=x3.-x^3 = -\sqrt[3]{x} \quad\Longrightarrow\quad x^3 = \sqrt[3]{x}.−x3=−3x​⟹x3=3x​.

The solutions are x=0x = 0x=0 and x8=1x^8 = 1x8=1, that is x=1x = 1x=1 and x=−1x = -1x=−1. Read off the meeting points: at x=0x = 0x=0 the graphs meet at (0,0)(0, 0)(0,0), which lies on y=xy = xy=x; at x=1x = 1x=1 they meet at (1,−1)(1, -1)(1,−1); and at x=−1x = -1x=−1 they meet at (−1,1)(-1, 1)(−1,1). Two of the three meeting points, (1,−1)(1, -1)(1,−1) and (−1,1)(-1, 1)(−1,1), are not on y=xy = xy=x: the claim that intersections can happen only on y=xy = xy=x is false in general, even though it happens to be true whenever fff is increasing, since f(x)=−x3f(x) = -x^3f(x)=−x3 is decreasing.

Common mistakes

Common mistakes

  • Checking only one composition. g∘f=id⁡g \circ f = \operatorname{id}g∘f=id does not force f∘g=id⁡f \circ g = \operatorname{id}f∘g=id. For f(x)=x2f(x) = x^2f(x)=x2 and g(x)=xg(x) = \sqrt{x}g(x)=x​, f∘gf \circ gf∘g is the identity on x≥0x \ge 0x≥0 but g∘f=∣x∣g \circ f = |x|g∘f=∣x∣, so ggg is not an inverse. Always verify both sides.
  • Stating “invertible exactly when one-to-one” with no codomain. The clean biconditional needs the codomain taken to be the range. If the codomain is larger, you also need fff onto, that is a bijection; one-to-one alone is not enough.
  • Reading f−1f^{-1}f−1 as 1f\dfrac{1}{f}f1​. The superscript marks the compositional inverse, never the reciprocal. For f(x)=x+3f(x) = x + 3f(x)=x+3, f−1(x)=x−3f^{-1}(x) = x - 3f−1(x)=x−3, while (f(x))−1=1x+3\bigl(f(x)\bigr)^{-1} = \dfrac{1}{x + 3}(f(x))−1=x+31​ is a different function.
  • Believing the graphs meet only on y=xy = xy=x. They can cross off it: f(x)=−x3f(x) = -x^3f(x)=−x3 meets its inverse at (1,−1)(1, -1)(1,−1) and (−1,1)(-1, 1)(−1,1). The one-way statement that does hold is that if f(a)=af(a) = af(a)=a, then (a,a)(a, a)(a,a) lies on both graphs and on y=xy = xy=x. The reverse fails, as (1,−1)(1, -1)(1,−1) shows, so a shared point need not sit on y=xy = xy=x.
  • Treating a domain restriction as unique. The rule x2x^2x2 is made one-to-one on x≥0x \ge 0x≥0 (inverse x\sqrt{x}x​) or on x≤0x \le 0x≤0 (inverse −x-\sqrt{x}−x​); both are valid, so a restriction is a choice, not “the” restriction.
  • Trusting a simplified formula over the domain. (g∘f)(x)(g \circ f)(x)(g∘f)(x) may reduce to xxx yet fail to be the identity, because the composition can carry a smaller domain than R\mathbb{R}R. For instance (x)2(\sqrt{x})^2(x​)2 reduces to xxx, but it is the identity only on x≥0x \ge 0x≥0, not on all of R\mathbb{R}R; the inverse must match domains, not just formulas.

Key takeaways

  • ggg is the inverse of fff when both g∘f=id⁡g \circ f = \operatorname{id}g∘f=id on dom⁡f\operatorname{dom} fdomf and f∘g=id⁡f \circ g = \operatorname{id}f∘g=id on dom⁡g\operatorname{dom} gdomg. A one-sided inverse is not an inverse.
  • The inverse is unique: two functions that both undid fff from both directions would have to agree everywhere, which is why we may write f−1f^{-1}f−1; the superscript means the compositional inverse, never 1f\dfrac{1}{f}f1​.
  • With a function’s codomain taken to be its range, fff has an inverse exactly when it is one-to-one; with a larger codomain the condition is one-to-one and onto, a bijection.
  • Inverting swaps the ordered pairs (a,b)↦(b,a)(a, b) \mapsto (b, a)(a,b)↦(b,a), so the swapped relation is a function precisely when fff passes the horizontal line test.
  • Domain and range trade places: dom⁡f−1=range⁡f\operatorname{dom} f^{-1} = \operatorname{range} fdomf−1=rangef and range⁡f−1=dom⁡f\operatorname{range} f^{-1} = \operatorname{dom} frangef−1=domf.
  • The graph of f−1f^{-1}f−1 is the reflection of the graph of fff across y=xy = xy=x, and the two can meet off that line; only f(a)=af(a) = af(a)=a forces a common point onto y=xy = xy=x.
  • Restricting the domain to gain an inverse produces a different function, and the restriction is a choice (both x≥0x \ge 0x≥0 and x≤0x \le 0x≤0 work for x2x^2x2), not a unique repair.

Why an inverse can never have a rival

The main lesson gives the reason in plain words. Here is the formal version, which pins down exactly where the previous lesson’s associative law is needed.

The inverse is unique#

Suppose ggg and hhh are both inverses of fff. Write AAA for the domain of fff and BBB for its range, so fff sends AAA to BBB while ggg and hhh send BBB back to AAA. Being inverses means g∘f=id⁡Ag \circ f = \operatorname{id}_Ag∘f=idA​ and f∘g=id⁡Bf \circ g = \operatorname{id}_Bf∘g=idB​, and likewise h∘f=id⁡Ah \circ f = \operatorname{id}_Ah∘f=idA​ and f∘h=id⁡Bf \circ h = \operatorname{id}_Bf∘h=idB​.

Now run a single chain and justify each step:

g=g∘id⁡B=g∘(f∘h)=(g∘f)∘h=id⁡A∘h=h.g = g \circ \operatorname{id}_B = g \circ (f \circ h) = (g \circ f) \circ h = \operatorname{id}_A \circ h = h.g=g∘idB​=g∘(f∘h)=(g∘f)∘h=idA​∘h=h.

The first equality composes ggg with the identity on BBB, its own domain, which changes nothing. The second replaces id⁡B\operatorname{id}_BidB​ by f∘hf \circ hf∘h, equal to it because hhh is an inverse of fff. The third is the associative law from the previous lesson, and it is the one place the whole argument rests on it. The fourth uses g∘f=id⁡Ag \circ f = \operatorname{id}_Ag∘f=idA​, and the last drops the identity on AAA. So g=hg = hg=h: any two inverses of fff are the same function. Notice that associativity is not a decoration here. Without it the middle step would fail, and the phrase “the inverse” would not even be well defined.

∎

Proving invertible means one-to-one, in both directions

Take fff with domain AAA and codomain its range B=f(A)B = f(A)B=f(A), so every element of BBB equals f(a)f(a)f(a) for at least one a∈Aa \in Aa∈A.

Why reflecting across y = x preserves direction

The main lesson states this fact. Here is a proof that it holds for every increasing function, not just the ones a picture happens to show.

A rising graph reflects to a rising graph, and by the same argument a falling one reflects to a falling one.

A bit of history (optional)

Mathematics sometimes gets a definition right by accident, and notices only years later.

Heinrich Weber, a German mathematician, wrote down axioms for a group in 1882. He asked for three things. Combining two elements must give a third element of the system. The combining must be associative. And you may cancel from either side: from ab=acab = acab=ac it follows that b=cb = cb=c, and from ba=caba = caba=ca it also follows that b=cb = cb=c. Nowhere did he ask that inverses exist. His definition was correct anyway, because every group he had in mind was finite. On a finite set, cancellation quietly delivers the inverses for nothing.

The reason is a counting argument. Combining with a fixed element aaa is itself a map from the set to itself, sending each xxx to axaxax, and cancellation says that map never sends two inputs to one output. On a finite set, a map from a set to itself that never sends two inputs to one output must reach every element: its outputs are all different, so there are as many of them as there are elements, and nothing is left over to be missed. A one-sided inverse for a map of a finite set to itself is therefore two-sided already. The gap this lesson warns about cannot open there.

The functions here live where that argument collapses. On the whole real line, squaring sends two inputs to one output and still leaves outputs unused. That is why the square root undoes it from one side and fails from the other. Weber came to see this himself. His textbook of 1895 says that the infinite case must ask for inverses outright. That demand is the pair of compositions this lesson made you check by hand.
