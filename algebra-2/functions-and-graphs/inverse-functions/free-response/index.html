    1. Two candidates for undoing the same function . Foundational, 10 points. Question 1 of 5.

    Foundational 10 pts

    Let f(x)=5∣x∣+2f(x) = 5\lvert x \rvert + 2f(x)=5∣x∣+2, with domain all real numbers.     The answer

    Part A

    (f∘g)(x)=x(f \circ g)(x) = x(f∘g)(x)=x and (f∘h)(x)=x(f \circ h)(x) = x(f∘h)(x)=x, both for every x≥2x \ge 2x≥2.

    Part B

    (g∘f)(x)=∣x∣(g \circ f)(x) = \lvert x \rvert(g∘f)(x)=∣x∣ and (h∘f)(x)=−∣x∣(h \circ f)(x) = -\lvert x \rvert(h∘f)(x)=−∣x∣. At x=−4x = -4x=−4 the first returns 444 and the second returns −4-4−4; at x=4x = 4x=4 the first returns 444 and the second returns −4-4−4. So each rule returns the input at one of the two places and not at the other.

    Part C

    No rule can. Since f(−4)=f(4)=22f(-4) = f(4) = 22f(−4)=f(4)=22, a rule undoing fff in that order would have to send 222222 to −4-4−4 and to 444 at once, and no function assigns two outputs to one input.     Part A

    Substitute each candidate into fff and settle the sign inside the bars on the domain x≥2x \ge 2x≥2.

    For ggg, the quantity x−25\dfrac{x - 2}{5}5x−2​ is nonnegative there, so the bars come off unchanged:

    5∣x−25∣+2=(x−2)+2=x5 \left\lvert \frac{x - 2}{5} \right\rvert + 2 = (x - 2) + 2 = x5​5x−2​​+2=(x−2)+2=x

    Part B

    Part C

    Answer and solution

    The answer

    Part A

    g=hg = hg=h. Inserting the identity on BBB, replacing it by f∘hf \circ hf∘h, regrouping, and then using g∘f=id⁡Ag \circ f = \operatorname{id}_Ag∘f=idA​ collapses the chain, so the left undoer and the right undoer are the same rule.

    Part B

    It has none. A left undoer would equal each of the two right undoers by part A, which forces those two to be equal to each other and contradicts their disagreeing at an input. So a function with two different right undoers has no left undoer at all.

    Part C

    It uses only the two hypotheses, the identity on each set, and the associative law. So it settles uniqueness for every fff at once: at most one rule undoes fff from both sides. It settles nothing about existence, which is where being one-to-one and the choice of codomain do their work.

    Worked solution

    Part A

    Start at ggg and insert the identity on BBB, the set ggg takes its inputs from, which changes nothing. Then replace that identity by f∘hf \circ hf∘h, equal to it because hhh undoes fff from the right:

    g=g∘id⁡B=g∘(f∘h)g = g \circ \operatorname{id}_B = g \circ (f \circ h)g=g∘idB​=g∘(f∘h)

    Now regroup the triple composition and finish:

    g∘(f∘h)=(g∘f)∘h=id⁡A∘h=hg \circ (f \circ h) = (g \circ f) \circ h = \operatorname{id}_A \circ h = hg∘(f∘h)=(g∘f)∘h=idA​∘h=h

    The regrouping is the associative law, and it is the one link in the chain that uses it; delete associativity and the argument stops there with no route to hhh. The next link uses the other hypothesis, g∘f=id⁡Ag \circ f = \operatorname{id}_Ag∘f=idA​, and the last drops the identity on AAA, the set hhh delivers its outputs to. Reading the chain end to end gives g=hg = hg=h: a rule undoing fff from the left and a rule undoing it from the right cannot be two different rules.

    Part B

    Name the two right undoers h1h_1h1​ and h2h_2h2​, with h1(b)≠h2(b)h_1(b) \ne h_2(b)h1​(b)=h2​(b) at some input bbb. Suppose the function also had a left undoer ggg. Part A compares one left undoer with one right undoer and says they coincide, and nothing stops running that comparison twice, once against each:

    g=h1andg=h2g = h_1 \quad \text{and} \quad g = h_2g=h1​andg=h2​

    Two rules equal to the same rule are equal to each other, so h1=h2h_1 = h_2h1​=h2​ and in particular h1(b)=h2(b)h_1(b) = h_2(b)h1​(b)=h2​(b).     So one-sided undoers can multiply, but only while the other side stays empty. The moment a function has an undoer on each side, part A collapses every one of them into a single rule, and that rule is what earns the name f−1f^{-1}f−1.

    Part C

    Audit the chain link by link and list what each one consumes: the identity on BBB and on AAA, the hypothesis f∘h=id⁡Bf \circ h = \operatorname{id}_Bf∘h=idB​, the hypothesis g∘f=id⁡Ag \circ f = \operatorname{id}_Ag∘f=idA​, and the regrouping

    g∘(f∘h)=(g∘f)∘hg \circ (f \circ h) = (g \circ f) \circ hg∘(f∘h)=(g∘f)∘h

That is exactly why the conclusion is available for every fff at once, and it is a conclusion about counting rather than about construction: there is at most one two-sided undoer, so the symbol f−1f^{-1}f−1 names something definite whenever it names anything at all.

    What the chain cannot do is produce that rule. Nothing in it says an undoer exists, and a function with no undoer on either side satisfies the statement with nothing to check. Existence is a separate question, settled by whether the outputs of fff come from single inputs and whether fff reaches every value it has been declared to reach.

    In one line

    The chain g=g∘id⁡B=g∘(f∘h)=(g∘f)∘h=id⁡A∘h=hg = g \circ \operatorname{id}_B = g \circ (f \circ h) = (g \circ f) \circ h = \operatorname{id}_A \circ h = hg=g∘idB​=g∘(f∘h)=(g∘f)∘h=idA​∘h=h shows that a left undoer and a right undoer of the same fff are the same rule, with the regrouping step supplied by associativity.
