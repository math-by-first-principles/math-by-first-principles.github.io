    On which domain, the largest interval that contains x=5x = 5x=5, is f(x)=(x−3)2f(x) = (x - 3)^2f(x)=(x−3)2 one-to-one?

    Answer choices for question 1

    Solution

    Correct answer: B

    The parabola has its vertex at x=3x = 3x=3 and is one-to-one on each side of it.

    a,b≥3,  (a−3)2=(b−3)2  ⇒  a=ba, b \ge 3, \; (a-3)^2 = (b-3)^2 \;\Rightarrow\; a = ba,b≥3,(a−3)2=(b−3)2⇒a=b

    The largest interval that stays on one side and still contains 555 is x≥3x \ge 3x≥3.

  11. 11

    Why is 'the domain is part of the function's data' the reason clearing denominators in Chapter 1 could create extraneous roots?

    Answer choices for question 11

    Solution

    Correct answer: A

    The domain is fixed before any algebra, so values that make a denominator zero are barred from the start.

    x=2 excluded  ⇒  any candidate x=2 is extraneousx = 2 \text{ excluded} \;\Rightarrow\; \text{any candidate } x = 2 \text{ is extraneous}x=2 excluded⇒any candidate x=2 is extraneous

    Clearing denominators can produce such a candidate, but the domain, part of the problem's data, rules it out.
