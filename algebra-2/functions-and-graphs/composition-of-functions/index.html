Composition of Functions

Intuition

Let fff add 111 to its input and let ggg square its input. Start with 222: fff turns it into 333, and then ggg turns that 333 into 999. Two functions run one after another, first fff and then ggg, and together they act like a single new function that sends 222 straight to 999. Chaining functions this way is called composition. This lesson is about the function that chaining builds: how to read its notation, how to find its domain, and how to take it apart again.

Learning goals

  • Compute g∘fg \circ fg∘f, reading it right to left with fff acting first
  • Decide whether g∘fg \circ fg∘f equals f∘gf \circ gf∘g for a given pair
  • Find the domain of g∘fg \circ fg∘f from the range of fff
  • Decompose a function as g∘fg \circ fg∘f, knowing the split is a choice
  • Write f2f^2f2 for f∘ff \circ ff∘f, never for the squared output

Reading a composition right to left

Give the chaining its symbol. The composition of fff and ggg, written g∘fg \circ fg∘f, is the function

(g∘f)(x)=g(f(x)).(g \circ f)(x) = g(f(x)).(g∘f)(x)=g(f(x)).

Check it against the numbers above: with f(x)=x+1f(x) = x + 1f(x)=x+1 and g(x)=x2g(x) = x^2g(x)=x2,

(g∘f)(2)=g(f(2))=g(3)=9,(g \circ f)(2) = g(f(2)) = g(3) = 9,(g∘f)(2)=g(f(2))=g(3)=9,

exactly the 2→3→92 \to 3 \to 92→3→9 chain from the opening. You feed xxx to fff, and then feed the result f(x)f(x)f(x) to ggg; the circle is the operation sign, exactly as +++ is the sign for addition.

The one thing to fix in your reading, because it causes more confusion than anything else in this lesson, is the order. In g∘fg \circ fg∘f the function on the right, fff, acts first, and the function on the left, ggg, acts second. The notation runs right to left, opposite to the way you read a sentence. The reason is built into the definition: g(f(x))g(f(x))g(f(x)) has fff in the inner parentheses, and the inner operation always happens before the outer one. So g∘fg \circ fg∘f means “do fff, then ggg,” never “do ggg, then fff.”

Worked example 1 Both orders of the same two functions

Let f(x)=x+1f(x) = x + 1f(x)=x+1 and g(x)=x2g(x) = x^2g(x)=x2. Compute g∘fg \circ fg∘f and f∘gf \circ gf∘g, keeping track of which function acts first.

For g∘fg \circ fg∘f, the inner function is fff, so substitute f(x)=x+1f(x) = x + 1f(x)=x+1 into ggg:

(g∘f)(x)=g(f(x))=(x+1)2=x2+2x+1.(g \circ f)(x) = g(f(x)) = (x + 1)^2 = x^2 + 2x + 1.(g∘f)(x)=g(f(x))=(x+1)2=x2+2x+1.

For f∘gf \circ gf∘g, the inner function is now ggg, so substitute g(x)=x2g(x) = x^2g(x)=x2 into fff:

(f∘g)(x)=f(g(x))=x2+1.(f \circ g)(x) = f(g(x)) = x^2 + 1.(f∘g)(x)=f(g(x))=x2+1.

The two results, x2+2x+1x^2 + 2x + 1x2+2x+1 and x2+1x^2 + 1x2+1, are different functions. Swapping the order changed the answer, which is the first sign that composition, unlike addition, does not always let you reverse the two inputs.

Order matters, but not always

The one law that addition has and composition often lacks is commutativity: for numbers, a+b=b+aa + b = b + aa+b=b+a always. For functions, g∘fg \circ fg∘f and f∘gf \circ gf∘g are usually different, and Worked Example 1 already showed why: running the same two machines in the opposite order gave x2+2x+1x^2 + 2x + 1x2+2x+1 instead of x2+1x^2 + 1x2+1. These differ by 2x2x2x, which is zero only at x=0x = 0x=0.

But “usually different” is not “never equal,” and the difference is worth stating exactly, because overshooting it is the classic error. Some pairs genuinely commute. Take the two translations f(x)=x+1f(x) = x + 1f(x)=x+1 and g(x)=x+2g(x) = x + 2g(x)=x+2. Then

(f∘g)(x)=(x+2)+1=x+3=(g∘f)(x),(f \circ g)(x) = (x + 2) + 1 = x + 3 = (g \circ f)(x),(f∘g)(x)=(x+2)+1=x+3=(g∘f)(x),

and the same works for any two translations f(x)=x+af(x) = x + af(x)=x+a and g(x)=x+bg(x) = x + bg(x)=x+b, since both orders give x+a+bx + a + bx+a+b and addition of the shifts does not care about order. So the correct statement names both cases: composition is not always commutative, but it is not never commutative either; commuting is the exception, not the rule.

Composition has two more things in common with addition, each worth a name. It is associative: for any three functions, grouping does not matter, (h∘g)∘f=h∘(g∘f)(h \circ g) \circ f = h \circ (g \circ f)(h∘g)∘f=h∘(g∘f), so you can write h∘g∘fh \circ g \circ fh∘g∘f with no parentheses.

The full proof unfolds both groupings until they collapse to the same expression, h(g(f(x)))h(g(f(x)))h(g(f(x))), and checks that both groupings also require the same domain and codomain.

And it has an identity: a function id⁡(x)=x\operatorname{id}(x) = xid(x)=x that changes nothing when composed with fff, the way 000 changes nothing under addition. The domain of a composition

Here is the idea the substitution procedure hides, and it is the most important thing in the lesson. When you build (g∘f)(x)=g(f(x))(g \circ f)(x) = g(f(x))(g∘f)(x)=g(f(x)), two things must be true for the answer to exist: fff must accept xxx, and ggg must accept the number f(x)f(x)f(x) that comes out.

The domain of g∘fg \circ fg∘f#

By definition (g∘f)(x)=g(f(x))(g \circ f)(x) = g(f(x))(g∘f)(x)=g(f(x)), so this value exists exactly when both steps inside it are legal. First f(x)f(x)f(x) must be defined, which requires x∈dom⁡fx \in \operatorname{dom} fx∈domf. Then ggg is applied to the number f(x)f(x)f(x), which is legal exactly when f(x)∈dom⁡gf(x) \in \operatorname{dom} gf(x)∈domg. So

dom⁡(g∘f)={ x∈dom⁡f:f(x)∈dom⁡g }.\operatorname{dom}(g \circ f) = \{\, x \in \operatorname{dom} f : f(x) \in \operatorname{dom} g \,\}.dom(g∘f)={x∈domf:f(x)∈domg}.

This is not dom⁡f∩dom⁡g\operatorname{dom} f \cap \operatorname{dom} gdomf∩domg. The second condition constrains f(x)f(x)f(x), an output of fff, so testing it needs the range of fff, not its domain. A value of xxx can lie in both dom⁡f\operatorname{dom} fdomf and dom⁡g\operatorname{dom} gdomg yet be excluded, because f(x)f(x)f(x) escapes dom⁡g\operatorname{dom} gdomg. Or it can lie outside dom⁡g\operatorname{dom} gdomg and still be fine, as long as x∈dom⁡fx \in \operatorname{dom} fx∈domf and f(x)∈dom⁡gf(x) \in \operatorname{dom} gf(x)∈domg.

Worked example 2 A square root inside a reciprocal

Let f(x)=xf(x) = \sqrt{x}f(x)=x​ and g(x)=1x−2g(x) = \dfrac{1}{x - 2}g(x)=x−21​. Find a formula for g∘fg \circ fg∘f and its domain.

The formula is a direct substitution:

(g∘f)(x)=g(x)=1x−2.(g \circ f)(x) = g(\sqrt{x}) = \frac{1}{\sqrt{x} - 2}.(g∘f)(x)=g(x​)=x​−21​.

Now the domain. First fff must accept xxx, and x\sqrt{x}x​ needs x≥0x \ge 0x≥0. Second ggg must accept the output x\sqrt{x}x​, and ggg rejects only the input 222, so we need x≠2\sqrt{x} \ne 2x​=2. Since x=2\sqrt{x} = 2x​=2 exactly when x=4x = 4x=4,

dom⁡(g∘f)={ x≥0 and x≠4 }.\operatorname{dom}(g \circ f) = \{\, x \ge 0 \text{ and } x \ne 4 \,\}.dom(g∘f)={x≥0 and x=4}.

Compare that with the wrong shortcut. The intersection dom⁡f∩dom⁡g\operatorname{dom} f \cap \operatorname{dom} gdomf∩domg would keep x=4x = 4x=4 and throw out x=2x = 2x=2, the value ggg forbids. The truth is the reverse: x=2x = 2x=2 is fine, because 2≠2\sqrt{2} \ne 22​=2, while x=4x = 4x=4 is excluded, because 4=2\sqrt{4} = 24​=2 is the one input ggg cannot take. The excluded input is found through the range of fff, not by intersecting the two domains.

Worked example 3 Same formula, smaller domain

Let f(x)=xf(x) = \sqrt{x}f(x)=x​ and g(x)=x2g(x) = x^2g(x)=x2. Find g∘fg \circ fg∘f, and check its domain before deciding whether it is an identity function.

Decomposing a function, and why the answer is not unique

Composition also runs backward as a question. Given a function hhh, can you write it as g∘fg \circ fg∘f for simpler pieces fff and ggg? This is decomposition, and it lets you see a complicated rule as a short pipeline of easy steps.

Take h(x)=3x+1h(x) = \sqrt{3x + 1}h(x)=3x+1​. The natural split peels off the outermost operation, the square root, and calls the inside a separate step: let f(x)=3x+1f(x) = 3x + 1f(x)=3x+1 and g(x)=xg(x) = \sqrt{x}g(x)=x​. Then

(g∘f)(x)=g(3x+1)=3x+1=h(x).(g \circ f)(x) = g(3x + 1) = \sqrt{3x + 1} = h(x).(g∘f)(x)=g(3x+1)=3x+1​=h(x).

But this is not the only way. A different split absorbs the 333 elsewhere: f(x)=3xf(x) = 3xf(x)=3x and g(x)=x+1g(x) = \sqrt{x + 1}g(x)=x+1​ also gives g(f(x))=3x+1=h(x)g(f(x)) = \sqrt{3x + 1} = h(x)g(f(x))=3x+1​=h(x). Both are correct, since each composes to hhh. So “decompose hhh” has more than one right answer. Among the valid splits there is usually a most natural one, peel off the outermost operation, but no split is the unique correct answer.

Composing a function with itself

Because composition is associative, composing a function with itself repeatedly is unambiguous, and it has its own notation. Write f2=f∘ff^2 = f \circ ff2=f∘f, the small superscript counting how many times fff is applied. Read f2(x)=f(f(x))f^2(x) = f(f(x))f2(x)=f(f(x)): apply fff, then apply fff again to the result.

Here is the notation warning. That superscript clashes with the other thing a superscript can mean, squaring the output, (f(x))2=f(x)⋅f(x)(f(x))^2 = f(x) \cdot f(x)(f(x))2=f(x)⋅f(x). The two are different functions. For f(x)=2x−1f(x) = 2x - 1f(x)=2x−1,

f2(x)=f(f(x))=2(2x−1)−1=4x−3,f^2(x) = f(f(x)) = 2(2x - 1) - 1 = 4x - 3,f2(x)=f(f(x))=2(2x−1)−1=4x−3,

while

(f(x))2=(2x−1)2=4x2−4x+1,(f(x))^2 = (2x - 1)^2 = 4x^2 - 4x + 1,(f(x))2=(2x−1)2=4x2−4x+1,

and these are different functions: one is linear, the other is not. Which meaning f2f^2f2 carries is a matter of convention, and this lesson uses f2f^2f2 for the composition f∘ff \circ ff∘f; when we mean the square of the output we write (f(x))2(f(x))^2(f(x))2. In this lesson’s convention, a superscript on a function’s name is about composition, not multiplication.

Transformations were compositions all along

The previous lesson wrote every transformed graph as y=a f(b(x−h))+ky = a\,f\big(b(x - h)\big) + ky=af(b(x−h))+k, split into an inside that acts on the input before fff and an outside that acts on fff‘s output afterward. Name those two pieces as functions, an input map and an output map. The transformed rule is then exactly a composition of three functions: input map, then fff, then output map. That is also why “stretch then shift” gave a different graph from “shift then stretch”: the two output maps did not commute, the same reason g∘f≠f∘gg \circ f \ne f \circ gg∘f=f∘g in general.

One more distinction is worth a sentence. Composition chains two functions, feeding one’s output into the other’s input; adding, subtracting, multiplying, or dividing two functions instead combines their outputs at the same input, (f+g)(x)=f(x)+g(x)(f + g)(x) = f(x) + g(x)(f+g)(x)=f(x)+g(x). Common mistakes

Common mistakes

  • Reading g∘fg \circ fg∘f left to right. In g∘fg \circ fg∘f the right function fff acts first, then ggg, so (g∘f)(x)=g(f(x))(g \circ f)(x) = g(f(x))(g∘f)(x)=g(f(x)) means “do fff, then ggg.” It is usually not the same as f∘gf \circ gf∘g.
  • Saying composition is never commutative. It is not always commutative, but it is not never commutative either: any two translations f(x)=x+af(x) = x + af(x)=x+a and g(x)=x+bg(x) = x + bg(x)=x+b give the same result in either order.
  • Using dom⁡f∩dom⁡g\operatorname{dom} f \cap \operatorname{dom} gdomf∩domg for the domain of g∘fg \circ fg∘f. The right set is {x∈dom⁡f:f(x)∈dom⁡g}\{x \in \operatorname{dom} f : f(x) \in \operatorname{dom} g\}{x∈domf:f(x)∈domg}, which depends on the range of fff, not the domain of ggg.
  • Trusting a simplified formula over the domain. For f(x)=xf(x) = \sqrt{x}f(x)=x​ and g(x)=x2g(x) = x^2g(x)=x2, (g∘f)(x)(g \circ f)(x)(g∘f)(x) simplifies to xxx, but its domain is x≥0x \ge 0x≥0, so it is id⁡[0,∞)\operatorname{id}_{[0,\infty)}id[0,∞)​, not id⁡R\operatorname{id}_{\mathbb{R}}idR​.
  • Assuming a function decomposes in only one way. h(x)=3x+1h(x) = \sqrt{3x + 1}h(x)=3x+1​ is g∘fg \circ fg∘f for more than one valid choice of fff and ggg.
  • Reading f2f^2f2 as the square of the output. In this lesson f2f^2f2 means f∘ff \circ ff∘f, so for f(x)=2x−1f(x) = 2x - 1f(x)=2x−1, f2(x)=4x−3f^2(x) = 4x - 3f2(x)=4x−3, not (2x−1)2(2x - 1)^2(2x−1)2.

Key takeaways

  • Composition g∘fg \circ fg∘f is defined by (g∘f)(x)=g(f(x))(g \circ f)(x) = g(f(x))(g∘f)(x)=g(f(x)) and reads right to left: fff acts first, then ggg.
  • Composition is not always commutative (g∘f≠f∘gg \circ f \ne f \circ gg∘f=f∘g in general), though it is associative and has an identity id⁡S\operatorname{id}_SidS​ on any set SSS.
  • The domain is dom⁡(g∘f)={x∈dom⁡f:f(x)∈dom⁡g}\operatorname{dom}(g \circ f) = \{x \in \operatorname{dom} f : f(x) \in \operatorname{dom} g\}dom(g∘f)={x∈domf:f(x)∈domg}, not dom⁡f∩dom⁡g\operatorname{dom} f \cap \operatorname{dom} gdomf∩domg: it needs the range of fff.

Why composition is associative

The main lesson states this fact. Here is the proof, which is also why an iterated composition like f∘f∘ff \circ f \circ ff∘f∘f needs no parentheses to say what it means.

Composition is associative#

Let fff, ggg, and hhh be functions, and consider the two ways to group their composition, (h∘g)∘f(h \circ g) \circ f(h∘g)∘f and h∘(g∘f)h \circ (g \circ f)h∘(g∘f). Two functions are equal exactly when they have the same domain, codomain, and values, the equality test from Function Notation, so we check the values, the domains, and the codomains.

For the values, apply each grouping to an input xxx and unfold the definition one step at a time. The left grouping gives

((h∘g)∘f)(x)=(h∘g)(f(x))=h(g(f(x))),\big((h \circ g) \circ f\big)(x) = (h \circ g)(f(x)) = h\big(g(f(x))\big),((h∘g)∘f)(x)=(h∘g)(f(x))=h(g(f(x))),

and the right grouping gives

(h∘(g∘f))(x)=h((g∘f)(x))=h(g(f(x))).\big(h \circ (g \circ f)\big)(x) = h\big((g \circ f)(x)\big) = h\big(g(f(x))\big).(h∘(g∘f))(x)=h((g∘f)(x))=h(g(f(x))).

Both collapse to the single expression h(g(f(x)))h(g(f(x)))h(g(f(x))), so the two functions agree wherever they are defined.

For the domains, read off what each grouping requires. Building h(g(f(x)))h(g(f(x)))h(g(f(x))) is legal exactly when x∈dom⁡fx \in \operatorname{dom} fx∈domf so that f(x)f(x)f(x) exists, then f(x)∈dom⁡gf(x) \in \operatorname{dom} gf(x)∈domg so that g(f(x))g(f(x))g(f(x)) exists, then g(f(x))∈dom⁡hg(f(x)) \in \operatorname{dom} hg(f(x))∈domh so that the outer hhh applies. These three conditions are the same for both groupings, so the two functions share the same domain. Both also share the same codomain, whatever codomain we declared for hhh, since both groupings end by applying hhh. By the equality test they are the same function.

∎

Because the grouping never matters, we drop the parentheses and write h∘g∘fh \circ g \circ fh∘g∘f.

The identity function, defined carefully

The main lesson uses the identity function informally. Here is why composing with it changes nothing, done carefully: the equality test demands the same domain, codomain, and values, not just a matching formula.

The identity function is neutral for composition#

Let f:A→Bf: A \to Bf:A→B be a function. For any set SSS, let id⁡S(x)=x\operatorname{id}_S(x) = xidS​(x)=x be the identity function on SSS, the function with domain SSS, codomain SSS, and rule “return the input unchanged.” We show f∘id⁡A=ff \circ \operatorname{id}_A = ff∘idA​=f and id⁡B∘f=f\operatorname{id}_B \circ f = fidB​∘f=f, taking the identity on the correct set each time.

For every x∈Ax \in Ax∈A,

(f∘id⁡A)(x)=f(id⁡A(x))=f(x),(f \circ \operatorname{id}_A)(x) = f(\operatorname{id}_A(x)) = f(x),(f∘idA​)(x)=f(idA​(x))=f(x),

and f∘id⁡Af \circ \operatorname{id}_Af∘idA​ has domain AAA and codomain BBB, matching fff exactly. So f∘id⁡A=ff \circ \operatorname{id}_A = ff∘idA​=f.

Likewise, for every x∈Ax \in Ax∈A,

(id⁡B∘f)(x)=id⁡B(f(x))=f(x),(\operatorname{id}_B \circ f)(x) = \operatorname{id}_B(f(x)) = f(x),(idB​∘f)(x)=idB​(f(x))=f(x),

since f(x)∈Bf(x) \in Bf(x)∈B, the domain of id⁡B\operatorname{id}_BidB​, so the composition is legal for every x∈Ax \in Ax∈A. And id⁡B∘f\operatorname{id}_B \circ fidB​∘f has domain AAA and codomain BBB, again matching fff. So id⁡B∘f=f\operatorname{id}_B \circ f = fidB​∘f=f.

The two sides are not symmetric. On the left, the identity’s codomain is forced: id⁡C∘f=f\operatorname{id}_C \circ f = fidC​∘f=f only when C=BC = BC=B exactly, since a composite’s codomain always matches its outer function’s, and that has to equal BBB. On the right, f∘id⁡A=ff \circ \operatorname{id}_A = ff∘idA​=f, and so does f∘id⁡Tf \circ \operatorname{id}_Tf∘idT​ for any set TTT that contains AAA. The domain of that composite is {x∈T:x∈A}=A\{x \in T : x \in A\} = A{x∈T:x∈A}=A either way, since fff‘s own domain restriction already confines things to AAA. So id⁡A\operatorname{id}_AidA​ is simply the smallest, most natural choice on that side, not the only one that works; the care that matters is on the left.

∎

Composition also has a name for what these two facts give it, together with the fact that it is not generally commutative. When fff, ggg, and hhh all map one fixed set XXX back into itself, composing any two of them gives another function X→XX \to XX→X, id⁡X\operatorname{id}_XidX​ serves as the identity, and composition of such functions is associative. Associative, with an identity, but not generally commutative and not guaranteed an inverse for every element: that structure is what algebraists call a monoid. The self-maps of XXX under composition form one such monoid. The missing piece, an inverse that undoes a function, is what the next lesson supplies for the functions that have one.

Writing a transformation as a composition

Write B(x)=b(x−h)B(x) = b(x - h)B(x)=b(x−h) for the input map and A(y)=ay+kA(y) = ay + kA(y)=ay+k for the output map, so BBB acts on the input before fff and AAA acts on fff‘s output afterward. Then

Reading right to left, BBB acts first, then fff, then AAA, exactly the story the previous lesson told: the inside happens before fff, and the outside after. Its rule that input maps “run backward because you solve for xxx” is also explained: in A∘f∘BA \circ f \circ BA∘f∘B the rightmost map BBB acts before fff. Combining functions without chaining them

Composition is not the only way to build a new function from two others. You can add, subtract, multiply, or divide two functions by combining their outputs at each input:

(f+g)(x)=f(x)+g(x),(fg)(x)=f(x) g(x),(fg)(x)=f(x)g(x).\begin{aligned} (f + g)(x) &= f(x) + g(x), \qquad (fg)(x) = f(x)\,g(x), \\ \left(\frac{f}{g}\right)(x) &= \frac{f(x)}{g(x)}. \end{aligned}(f+g)(x)(gf​)(x)​=f(x)+g(x),(fg)(x)=f(x)g(x),=g(x)f(x)​.​

These evaluate both functions at the same xxx and combine the two numbers, so both functions see the original input. Composition is different in kind: it chains them, feeding the output of one as the input of the other, so only fff sees xxx and ggg sees f(x)f(x)f(x). The domain rules differ to match. A sum or product is defined where both functions are, dom⁡f∩dom⁡g\operatorname{dom} f \cap \operatorname{dom} gdomf∩domg, the very intersection that is the wrong answer for composition. A bit of history (optional)

For most of the nineteenth century, mathematicians who studied groups only ever meant one thing: groups of permutations, the different ways to rearrange a list. Combining two rearrangements meant doing one after the other, which is composition and nothing else. Nobody thought of it as an example of something more general, because nothing else looked like it.

Arthur Cayley, an English mathematician who earned his living as a lawyer, changed that in 1854. His short papers on groups kept the laws an operation obeys and let go of the objects obeying them. In place of a recipe for shuffling a list, he printed a table of results. The same laws turned out to describe things with nothing else in common, such as square blocks of numbers under their own rule for multiplying.

This lesson takes the identical step with composition, a procedure you already knew. It names the laws that procedure obeys: associative, carrying an identity, and, among functions from one set to itself, not generally commutative.
