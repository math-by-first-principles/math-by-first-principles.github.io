    In △ABC≅△DEF\triangle ABC\cong\triangle DEF△ABC≅△DEF, which vertex is paired with B?

    Answer choices for question 1

    Solution

    Correct answer: C

    Read the same position in each name. BBB is second and EEE is second, so

    B↔E\begin{aligned} B&\leftrightarrow E \end{aligned}B​↔E​
  2. 2

    If △ABC≅△JKL\triangle ABC\cong\triangle JKL△ABC≅△JKL, which side corresponds to ACACAC?

    Answer choices for question 2

    Solution

    Correct answer: A

    The endpoints map as

    A↔JC↔L.\begin{aligned} A&\leftrightarrow J \\ C&\leftrightarrow L. \end{aligned}AC​↔J↔L.​

    Thus

    AC↔JL\begin{aligned} AC&\leftrightarrow JL \end{aligned}AC​↔JL​

  4. 4

    One actual triangle has side lengths 7, 10, and 12 cm. A second has side lengths 10, 12, and 7 cm. What establishes that they are congruent?

    Answer choices for question 4

    Solution

    Correct answer: B

    Pair equal lengths, regardless of how the lists are ordered. The three matches are

    7=710=1012=12\begin{aligned} 7&=7 \\ 10&=10 \\ 12&=12 \end{aligned}71012​=7=10=12​

    All three corresponding side pairs match, so SSS applies.

  5. 5

    How many corresponding parts are in the complete side-and-angle description of two congruent triangles?

    Answer choices for question 5

    Solution

    Correct answer: A

    Each triangle contributes three sides and three angles to the matching. The number of pairs is

    3+3=6\begin{aligned} 3+3&=6 \end{aligned}3+3​=6​
  6. 6

    Which description states what it means for two triangles to be congruent?

    Answer choices for question 6

    Solution

    Correct answer: C

    Congruence requires an exact rigid-motion match. Each distance is preserved, for example

    AB=A′B′\begin{aligned} AB&=A'B' \end{aligned}AB​=A′B′​

    A stretch can change size, and equal perimeters alone do not fix a triangle.

  7. 7

    A triangle is reflected across a line. How does its image compare with the original?

    Answer choices for question 7

    Solution

    Correct answer: B

    Reflection is a rigid motion. It preserves each distance, so every corresponding side satisfies

    AB=A′B′\begin{aligned} AB&=A'B' \end{aligned}AB​=A′B′​

    The reflection itself gives a mapping that establishes congruence.

  9. 9

    Which information is exactly what SSS requires?

    Answer choices for question 9

    Solution

    Correct answer: D

    SSS means Side-Side-Side. Use this ordered correspondence:

    ABC↔DEF\begin{aligned} ABC&\leftrightarrow DEF \end{aligned}ABC​↔DEF​

    The required side pairs are:

    AB=DEBC=EFAC=DF\begin{aligned} AB&=DE \\ BC&=EF \\ AC&=DF \end{aligned}ABBCAC​=DE=EF=DF​

  11. 11

    Two triangles have two pairs of equal corresponding side lengths. Is that enough information to use SSS?

    Answer choices for question 11

    Solution

    Correct answer: C

    The letters SSS represent three side matches. The number of side pairs still unchecked is

    3−2=1\begin{aligned} 3-2&=1 \end{aligned}3−2​=1​

    Two matching lengths leave the third pair unknown.

  12. 12

    Two corresponding base segments have equal nonzero lengths. Which steps can make them coincide with the endpoints matched?

    Answer choices for question 12

    Solution

    Correct answer: A

    After translation the first endpoints coincide. Rotation aligns the rays, and equal base lengths put the second endpoints together:

    AB=DE\begin{aligned} AB&=DE \end{aligned}AB​=DE​

    No resizing is needed.
