  9. Problem 9 Related statements about a pair

    The allowed objects are pairs of distinct lines in ordinary three-dimensional Euclidean space.

    Start with the true conditional, “If the lines are parallel, then they have no common point.” Write its converse, inverse, and contrapositive.

    State whether each resulting universal claim is true or false, and justify each decision without relying on measurements.

    1. Hint 1

      Keep the same allowed objects when changing the order or negating the two parts.

    2. Hint 2

      For claims involving lines with no common point, check whether a common plane has also been required.

    Answer

    Converse: if the lines have no common point, then they are parallel, false. Inverse: if the lines are not parallel, then they have a common point, false. Contrapositive: if the lines have a common point, then they are not parallel, true.

    Full solution

    The converse exchanges the parts.

    Skew lines are distinct and disjoint but not parallel, so they refute the converse.

    The inverse negates both parts without exchanging them.

    The same skew pair is not parallel yet has no common point, so it also refutes the inverse.

    The contrapositive exchanges and negates the parts.

    Parallel lines have no common point by definition, so lines with a common point cannot be parallel.

    This is also the logical form equivalent to the true original.

    Coplanarity is the condition that distinguishes a disjoint parallel pair from a disjoint skew pair.

    Answer

    Converse: if the lines have no common point, then they are parallel, false. Inverse: if the lines are not parallel, then they have a common point, false. Contrapositive: if the lines have a common point, then they are not parallel, true.

    Key idea

    Equivalent logical forms agree, while a missing geometric hypothesis can defeat both the converse and inverse.
