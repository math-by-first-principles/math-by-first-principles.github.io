  1. Problem 1 Supply the perpendicular corner

    The endpoints of ABABAB are (−7,1)(-7,1)(−7,1) and (−2,5)(-2,5)(−2,5). Name the corner HHH reached by moving horizontally from AAA and then vertically to BBB. Find both leg lengths and the exact length ABABAB.

    Text description of this figure

    Endpoints before the perpendicular corner is added. A is at (-7, 1); B is at (-2, 5). The axes use equal scales; the surrounding problem supplies the coordinates.

    1. Hint 1

      A horizontal move keeps the starting height; the vertical move uses the ending column.

    2. Hint 2

      Read the two gaps, then apply the right-triangle relation.

    Answer

    H=(−2,1)H=(-2,1)H=(−2,1); horizontal leg 555 units; vertical leg 444 units; AB=41AB=\sqrt{41}AB=41​ units.

    Full solution

    The corner uses B’s x-coordinate and A’s y-coordinate.

    H=(−2,1)H=(-2,1)H=(−2,1)

    The horizontal gap is ∣−2−(−7)∣=5|-2-(-7)|=5∣−2−(−7)∣=5 units.

    The vertical gap is ∣5−1∣=4|5-1|=4∣5−1∣=4 units.

    These legs are perpendicular, so

    AB2=52+42AB^2=5^2+4^2AB2=52+42

    Taking the nonnegative square root gives

    AB=41AB=\sqrt{41}AB=41​

    Answer

    H=(−2,1)H=(-2,1)H=(−2,1); horizontal leg 555 units; vertical leg 444 units; AB=41AB=\sqrt{41}AB=41​ units.

    Key idea

    A coordinate corner combines one endpoint’s height with the other endpoint’s horizontal position.

    The vertical sum is −3-3−3, so

    yM=−3/2y_M=-3/2yM​=−3/2

    Both coordinates are negative.

    The midpoint is left of the y-axis and below the x-axis.

    Fractional coordinates describe valid positions between grid intersections.

    Answer

  5. Problem 5 A cable and its center marker

    A straight cable joins positions AAA at (−3,2)(-3,2)(−3,2) and BBB at (5,7)(5,7)(5,7) on a plan. Each coordinate unit represents 2 meters. A marker is attached halfway along the cable. Find the exact cable length in meters and the marker’s coordinates on the plan.

    Text description of this figure

    The cable endpoints on the plan. A is at (-3, 2); B is at (5, 7). The axes use equal scales; the surrounding problem supplies the coordinates.

    1. Hint 1

      The plan uses a length scale, and the cable is a straight segment.

    2. Hint 2

      Use the coordinate gaps for the plan length, then convert units.

    3. Hint 3

      The marker is the segment’s midpoint.

    Answer

    Cable length 2892\sqrt{89}289​ meters; marker (1,9/2)(1,9/2)(1,9/2).

    Full solution

    The horizontal gap is 8 plan units and the vertical gap is 5.

    d2=82+52d^2=8^2+5^2d2=82+52

    Thus the plan length is 89\sqrt{89}89​ units.

    Each plan unit is 2 meters, so the cable length is 2892\sqrt{89}289​ meters.

    The midpoint averages the plan coordinates.

    xM=(−3+5)/2,xM=1,yM=(2+7)/2,yM=9/2.\begin{aligned}x_M&=(-3+5)/2,\\x_M&=1,\\y_M&=(2+7)/2,\\y_M&=9/2.\end{aligned}xM​xM​yM​yM​​=(−3+5)/2,=1,=(2+7)/2,=9/2.​

    Answer

    Cable length 2892\sqrt{89}289​ meters; marker (1,9/2)(1,9/2)(1,9/2).

    Key idea

    Convert the computed length using the plan scale while keeping the midpoint in the plan’s coordinate system.

  7. Problem 7 Check a proposed SSS order

  8. Problem 8 Every possible horizontal position

    One endpoint is AAA at (−2,−3)(-2,-3)(−2,−3). The other is BBB at (t,1)(t,1)(t,1) for a real number ttt. The segment length is 52\sqrt{52}52​ units. Find every possible BBB and the midpoint in each case.
