  1. Problem 1 A point crosses an axis

    Translate G(−7,2)G(-7,2)G(−7,2) by displacement (4,−6)(4,-6)(4,−6). Give the image coordinates and describe the travel using right, left, up, or down.

    1. Hint 1

      The displacement pair gives changes to the two coordinates.

    2. Hint 2

      Add the first entry to the horizontal coordinate and the second entry to the vertical coordinate.

    Answer

    G′(−3,−4)G'(-3,-4)G′(−3,−4); four units right and six units down.

    Full solution

    The horizontal change is positive 4, so move right.

    The new horizontal coordinate is

    −7+4=−3.-7+4=-3.−7+4=−3.

    The vertical change is negative 6, so move down.

    The new vertical coordinate is

    2−6=−4.2-6=-4.2−6=−4.

    Thus the image is G′(−3,−4)G'(-3,-4)G′(−3,−4).

    Answer

    G′(−3,−4)G'(-3,-4)G′(−3,−4); four units right and six units down.

    Key idea

    A displacement changes each coordinate separately, including when the point crosses an axis.

  2. Problem 2 Recover a common instruction

    A translation sends H(6,−5)H(6,-5)H(6,−5) to H′(2,3)H'(2,3)H′(2,3). Write its coordinate rule and describe the common horizontal and vertical changes.

    1. Hint 1

      Compare the destination with the start in each coordinate.

    2. Hint 2

      Each change is the image coordinate minus the corresponding starting coordinate.

    Answer

    (x,y)↦(x−4,y+8)(x,y)\mapsto(x-4,y+8)(x,y)↦(x−4,y+8); four units left and eight units up.

    Full solution

    For the horizontal change, subtract the start from the image:

    2−6=−4.2-6=-4.2−6=−4.

    For the vertical change, calculate

    3−(−5)=8.3-(-5)=8.3−(−5)=8.

    Every point receives these same changes.

    The rule is (x,y)↦(x−4,y+8)(x,y)\mapsto(x-4,y+8)(x,y)↦(x−4,y+8), four left and eight up.

    Answer

    (x,y)↦(x−4,y+8)(x,y)\mapsto(x-4,y+8)(x,y)↦(x−4,y+8); four units left and eight units up.

    Key idea

    One point-image pair fixes a translation because it fixes both coordinate changes.

  3. Problem 3 Draw the whole image

    Quadrilateral JKLMJKLMJKLM is the four-sided boundary joining J(−2,−3)J(-2,-3)J(−2,−3), K(2,−2)K(2,-2)K(2,−2), L(0,1)L(0,1)L(0,1), and M(−3,−1)M(-3,-1)M(−3,−1) in that order. Translate it two units right and three units up. Give every image vertex and draw the image on graph paper.

    Text description of this figure

    A unit grid shows the quadrilateral JKLM with vertices J at (negative 2, negative 3), K at (2, negative 2), L at (0, 1), and M at (negative 3, negative 1), connected in that order. No image is drawn.

    1. Hint 1

      A translation applies to every vertex, then to the sides between them.

    2. Hint 2

      Use displacement pair (2,3)(2,3)(2,3) at each vertex, and connect the resulting points in the original order.

    Answer

    J′(0,0)J'(0,0)J′(0,0), K′(4,1)K'(4,1)K′(4,1), L′(2,4)L'(2,4)L′(2,4), M′(−1,2)M'(-1,2)M′(−1,2); join J′K′L′M′J'K'L'M'J′K′L′M′ in that order.

    Full solution

    The horizontal rule is x′=x+2x'=x+2x′=x+2.

    The vertical rule is y′=y+3y'=y+3y′=y+3.

    For J, adding 2 to negative 2 and 3 to negative 3 gives J′(0,0)J'(0,0)J′(0,0).

    For K, the calculations are 2+2=42+2=42+2=4 and −2+3=1-2+3=1−2+3=1, so K′(4,1)K'(4,1)K′(4,1).

    For L, the calculations are 0+2=20+2=20+2=2 and 1+3=41+3=41+3=4, so L′(2,4)L'(2,4)L′(2,4).

    For M, the calculations are −3+2=−1-3+2=-1−3+2=−1 and −1+3=2-1+3=2−1+3=2, so M′(−1,2)M'(-1,2)M′(−1,2).

    Plot all four image vertices and join them in the order J′K′L′M′J'K'L'M'J′K′L′M′.

    The dashed boundary in the solution figure shows the resulting image.

    Answer

    J′(0,0)J'(0,0)J′(0,0), K′(4,1)K'(4,1)K′(4,1), L′(2,4)L'(2,4)L′(2,4), M′(−1,2)M'(-1,2)M′(−1,2); join J′K′L′M′J'K'L'M'J′K′L′M′ in that order.

    Key idea

    Translating every vertex and keeping the original connections describes the image of the whole polygon boundary.

  4. Problem 4 The starting points are missing

    A translation has rule (x,y)↦(x−4,y+5)(x,y)\mapsto(x-4,y+5)(x,y)↦(x−4,y+5). Find the missing preimages in both cases.

    Case A: the image is P′(−6,2)P'(-6,2)P′(−6,2).

    Case B: the image is Q′(−2,−1)Q'(-2,-1)Q′(−2,−1).

    1. Hint 1

      The missing starting coordinates must produce the given image coordinates under the rule.

    2. Hint 2

      For a starting horizontal coordinate, solve x−4=x′x-4=x'x−4=x′. For a starting vertical coordinate, solve y+5=y′y+5=y'y+5=y′.

    Answer

    Case A: P(−2,−3)P(-2,-3)P(−2,−3). Case B: Q(2,−6)Q(2,-6)Q(2,−6).

    Full solution

    Case A: solve x−4=−6x-4=-6x−4=−6 to get x=−2x=-2x=−2.

    Solve y+5=2y+5=2y+5=2 to get y=−3y=-3y=−3.

    Thus P=(−2,−3)P=(-2,-3)P=(−2,−3).

    Case A check: −2−4=−6-2-4=-6−2−4=−6 and −3+5=2-3+5=2−3+5=2, giving the required image.

    Case B: solve x−4=−2x-4=-2x−4=−2 to get x=2x=2x=2.

    Solve y+5=−1y+5=-1y+5=−1 to get y=−6y=-6y=−6.

    Thus Q=(2,−6)Q=(2,-6)Q=(2,−6).

    Case B check: 2−4=−22-4=-22−4=−2 and −6+5=−1-6+5=-1−6+5=−1.

    Answer

    Case A: P(−2,−3)P(-2,-3)P(−2,−3). Case B: Q(2,−6)Q(2,-6)Q(2,−6).

    Key idea

    A missing preimage can be found by solving the coordinate equations and checking the result in the stated rule.

  5. Problem 5 A stencil shifts on a drawing

    Coordinates on a design drawing are measured in millimeters. A rigid stencil slides without turning so that its reference mark at (8,−2)(8,-2)(8,−2) moves to (3,−1)(3,-1)(3,−1). A small hole in the stencil has center (6,3)(6,3)(6,3) before the slide. Find the new center. State the new length of a 12 mm edge and the new measure of a 65∘65^\circ65∘ corner.

    1. Hint 1

      The reference mark supplies the displacement for every point of the stencil.

    2. Hint 2

      Subtract the reference coordinates to find the two changes, apply them to the hole, and use rigid-motion preservation for the measurements.

    Answer

    Hole center (1,4)(1,4)(1,4); edge length 121212 mm; corner measure 65∘65^\circ65∘.

    Full solution

    The horizontal change is

    3−8=−5.3-8=-5.3−8=−5.

    The vertical change is

    −1−(−2)=1.-1-(-2)=1.−1−(−2)=1.

    The hole receives those same changes.

    Its new horizontal coordinate is 6−5=16-5=16−5=1, and its new vertical coordinate is 3+1=43+1=43+1=4, so its center is (1,4)(1,4)(1,4).

    A translation preserves distances within the stencil, so the edge remains 12 mm long.

    It also preserves angle measures, so the corner remains 65∘65^\circ65∘.

    Answer

    Hole center (1,4)(1,4)(1,4); edge length 121212 mm; corner measure 65∘65^\circ65∘.

    Key idea

    A reference point locates the slide, while preserved measurements describe the unchanged shape.

  6. Problem 6 Two preserved measurements

    A translation maps A,B,CA,B,CA,B,C to A′,B′,C′A',B',C'A′,B′,C′ respectively. Find the unknown and the preserved measurement in each case.

    Case A: AB=5p−7AB=5p-7AB=5p−7 cm and A′B′=3p+9A'B'=3p+9A′B′=3p+9 cm.

    Case B: m∠ABC=2q+11m\angle ABC=2q+11m∠ABC=2q+11 degrees and m∠A′B′C′=79∘m\angle A'B'C'=79^\circm∠A′B′C′=79∘.

    1. Hint 1

      Corresponding lengths are equal, and corresponding angle measures are equal.

    2. Hint 2

      Write one equation for each case. Solve it, then substitute to obtain the requested measurement.

    Answer

    Case A: p=8p=8p=8, length 333333 cm. Case B: q=34q=34q=34, angle measure 79∘79^\circ79∘.

    Full solution

    Case A: distance preservation gives

    5p−7=3p+9.5p-7=3p+9.5p−7=3p+9.

    Subtract 3p3p3p and add 7 to get

    2p=16.2p=16.2p=16.

    Thus p=8p=8p=8.

    Substitution gives

    5(8)−7=33,5(8)-7=33,5(8)−7=33,

    so both lengths are 33 cm.

    Case B: angle preservation directly gives

    2q+11=79.2q+11=79.2q+11=79.

    Subtract 11 to get 2q=682q=682q=68, so q=34q=34q=34.

    The angle measure is the given 79∘79^\circ79∘.

    Answer

    Case A: p=8p=8p=8, length 333333 cm. Case B: q=34q=34q=34, angle measure 79∘79^\circ79∘.

    Key idea

    Set corresponding measurements equal, then distinguish the unknown parameter from the geometric measurement.

  7. Problem 7 Parallel images and an old position

    The lines ℓ\ellℓ and mmm have equations y=−2y=-2y=−2 and y=3y=3y=3. Apply the translation (x,y)↦(x−4,y+5)(x,y)\mapsto(x-4,y+5)(x,y)↦(x−4,y+5). Give the equations of ℓ′\ell'ℓ′ and m′m'm′. Are the two image lines distinct and parallel? Explain why one image can occupy the old position of another line.

    1. Hint 1

      On each horizontal line, all points share one vertical coordinate.

    2. Hint 2

      Apply the vertical change to each fixed height. Keep track of which preimage line supplies each image.

    Answer

    ℓ′:y=3\ell':y=3ℓ′:y=3 and m′:y=8m':y=8m′:y=8; the images are distinct and parallel, and ℓ′\ell'ℓ′ occupies the old position of mmm.

    Full solution

    Every point of ℓ\ellℓ has vertical coordinate negative 2.

    After the slide, its height is

    −2+5=3.-2+5=3.−2+5=3.

    The horizontal change moves points along a horizontal line, so ℓ′\ell'ℓ′ is the entire line y=3y=3y=3.

    Every horizontal coordinate is reached.

    For m, the image height is

    3+5=8.3+5=8.3+5=8.

    Thus m′m'm′ is the entire line y=8y=8y=8.

    The two image heights differ by 5, so the image lines are distinct and parallel.

    The old line m was at height 3, which is where ℓ′\ell'ℓ′ now lies.

    Preservation compares the two images with each other; it does not require every image to avoid every preimage position.

    Answer

    ℓ′:y=3\ell':y=3ℓ′:y=3 and m′:y=8m':y=8m′:y=8; the images are distinct and parallel, and ℓ′\ell'ℓ′ occupies the old position of mmm.

    Key idea

    Track correspondence: distinct parallel image lines may still share positions with lines from the original figure.

  8. Problem 8 Construct a slide on paper

    Copy the broken line ABCABCABC onto paper with its right angle at B. Construct its image under a translation that moves every point 6 cm in the direction of the reference arrow. The arrow indicates direction only; the picture is not a centimeter scale. Label all three image points and state the image angle at B-prime. Explain what must agree in the three displacement arrows.

    Text description of this figure

    A broken line goes horizontally from A to B, then vertically down from B to C. A right-angle mark is at B. A separate reference arrow above points right and slightly upward. The diagram gives direction only, not a scale for the required six-centimeter travel.

    1. Hint 1

      The reference direction must be copied without turning at each starting vertex.

    2. Hint 2

      From each vertex, draw a parallel arrow pointing the same way, using your ruler to set the required travel length.

    Answer

    A correctly translated broken line A′B′C′A'B'C'A′B′C′; m∠A′B′C′=90∘m\angle A'B'C'=90^\circm∠A′B′C′=90∘. All three displacement arrows have length 6 cm and the given direction.

    Full solution

    From A, draw an arrow parallel to the reference arrow, pointing the same way, and make it 6 cm long.

    Its endpoint is A-prime.

    Repeat the identical direction and length from B and C to obtain B-prime and C-prime.

    The parallel construction from the preceding chapter can copy the direction.

    Connect A-prime to B-prime and B-prime to C-prime.

    Each point follows the same slide.

    Angle preservation keeps the right-angle opening, so

    m∠A′B′C′=90∘.m\angle A'B'C'=90^\circ.m∠A′B′C′=90∘.

    The three travel arrows must agree in both length and direction.

    Measuring only their lengths would not check the direction requirement.

    Answer

    A correctly translated broken line A′B′C′A'B'C'A′B′C′; m∠A′B′C′=90∘m\angle A'B'C'=90^\circm∠A′B′C′=90∘. All three displacement arrows have length 6 cm and the given direction.

    Key idea

    A paper translation copies one displacement from every point, regardless of the directions of the original sides.

  9. Problem 9 Is equal travel enough?

    A figure consists of two distinct points. Someone claims that any assignment moving both points equal distances must be a translation of that figure. Is the claim true? If not, give explicit coordinates for two starting points and their images, and explain why they refute the claim.

    1. Hint 1

      A translation controls direction as well as distance.

    2. Hint 2

      Consider two points that move equal distances toward each other along a number line.

    Answer

    False. For example, A(0,0)↦A′(1,0)A(0,0)\mapsto A'(1,0)A(0,0)↦A′(1,0) and B(3,0)↦B′(2,0)B(3,0)\mapsto B'(2,0)B(3,0)↦B′(2,0) give equal travel distances of 1 but opposite directions.

    Full solution

    Choose A at (0,0)(0,0)(0,0) and its image at (1,0)(1,0)(1,0).

    A travels one unit right.

    Choose B at (3,0)(3,0)(3,0) and its image at (2,0)(2,0)(2,0).

    B travels one unit left.

    Both travel distances are 1, satisfying the claim's assumption.

    Their displacement pairs are (1,0)(1,0)(1,0) and (−1,0)(-1,0)(−1,0), which differ.

    No translation can make both specified matches because a translation requires the same direction as well as the same distance.

    Answer

    False. For example, A(0,0)↦A′(1,0)A(0,0)\mapsto A'(1,0)A(0,0)↦A′(1,0) and B(3,0)↦B′(2,0)B(3,0)\mapsto B'(2,0)B(3,0)↦B′(2,0) give equal travel distances of 1 but opposite directions.

    Key idea

    A counterexample must satisfy the stated assumption while breaking the claimed conclusion.

  10. Problem 10 Reconstruct the missing map

    The following data come from one translation. Reconstruct its coordinate rule, find u and v, and verify all three specified matches. Then give the image of D(3,−1)D(3,-1)D(3,−1).

    Pair A: A(−4,3)↦A′(2,−2)A(-4,3)\mapsto A'(2,-2)A(−4,3)↦A′(2,−2).

    Pair B: B(u,0)↦B′(5,−5)B(u,0)\mapsto B'(5,-5)B(u,0)↦B′(5,−5).

    Pair C: C(1,v)↦C′(7,4)C(1,v)\mapsto C'(7,4)C(1,v)↦C′(7,4).

    1. Hint 1

      One complete point-image pair determines the common displacement.

    2. Hint 2

      Use Pair A to find the changes. Then each missing starting coordinate must produce its listed image under those changes.

    3. Hint 3

      Check both coordinates in Pairs B and C before applying the reconstructed rule to D.

    Answer

    (x,y)↦(x+6,y−5)(x,y)\mapsto(x+6,y-5)(x,y)↦(x+6,y−5); u=−1u=-1u=−1, v=9v=9v=9; all three pairs agree; D′(9,−6)D'(9,-6)D′(9,−6).

    Full solution

    Pair A gives horizontal change

    2−(−4)=6.2-(-4)=6.2−(−4)=6.

    Its vertical change is

    −2−3=−5.-2-3=-5.−2−3=−5.

    Therefore every image follows x′=x+6x'=x+6x′=x+6 and y′=y−5y'=y-5y′=y−5.

    Pair B needs u+6=5u+6=5u+6=5, so u=−1u=-1u=−1.

    Its vertical check is 0−5=−50-5=-50−5=−5, as required.

    Pair C needs v−5=4v-5=4v−5=4, so v=9v=9v=9.

    Its horizontal check is 1+6=71+6=71+6=7, as required.

    Check Pair A with the same rule: −4+6=2-4+6=2−4+6=2 and 3−5=−23-5=-23−5=−2.

    Each of the three specified matches agrees.

    For D, the new horizontal coordinate is 3+6=93+6=93+6=9.

    The new vertical coordinate is −1−5=−6-1-5=-6−1−5=−6.

    Thus D′(9,−6)D'(9,-6)D′(9,−6).

    Answer

    (x,y)↦(x+6,y−5)(x,y)\mapsto(x+6,y-5)(x,y)↦(x+6,y−5); u=−1u=-1u=−1, v=9v=9v=9; all three pairs agree; D′(9,−6)D'(9,-6)D′(9,−6).

    Key idea

    Reconstruct one common rule, use it to fill the missing data, and verify every supplied correspondence.
