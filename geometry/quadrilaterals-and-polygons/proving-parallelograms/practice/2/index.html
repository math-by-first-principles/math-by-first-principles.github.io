  1. 1

    Convex ABCDABCDABCD has side lengths in centimeters.

    AB=3x−2,CD=13,BC=x+1,AD=6.\begin{gathered} AB=3x-2,\\ CD=13,\\ BC=x+1,\\ AD=6. \end{gathered}AB=3x−2,CD=13,BC=x+1,AD=6.​

    Which value makes both opposite-side pairs congruent?

    Answer choices for question 1

    Solution

    Correct answer: C

    Check the first pair:

    3x−2=13,x=5.\begin{aligned} 3x-2&=13,\\ x&=5. \end{aligned}3x−2x​=13,=5.​

    The other pair requires

    x+1=6,x=5.\begin{aligned} x+1&=6,\\ x&=5. \end{aligned}x+1x​=6,=5.​

    Both pairs have positive equal lengths at that value.

  2. 2

    Convex ABCDABCDABCD has these side lengths in the same unit.

    AB=2x+1,CD=9,BC=x+3,AD=8.\begin{gathered} AB=2x+1,\\ CD=9,\\ BC=x+3,\\ AD=8. \end{gathered}AB=2x+1,CD=9,BC=x+3,AD=8.​

    Which value of xxx makes both opposite-side pairs congruent?

    Answer choices for question 2

    Solution

    Correct answer: A

    The first pair requires

    2x+1=9,2x+1=9,2x+1=9,

    so x=4x=4x=4. The second requires

    x+3=8,x+3=8,x+3=8,

    so x=5x=5x=5. One value cannot meet both requirements. The side test cannot be completed with these expressions.

  3. 3

    Diagonals ACACAC and BDBDBD of convex ABCDABCDABCD meet at EEE. Their parts have lengths in the same unit.

    AE=2x+3,EC=x+8,BE=y+1,ED=3y−7.\begin{gathered} AE=2x+3,\\ EC=x+8,\\ BE=y+1,\\ ED=3y-7. \end{gathered}AE=2x+3,EC=x+8,BE=y+1,ED=3y−7.​

    Which values make both diagonals bisect each other?

    Answer choices for question 3

    Solution

    Correct answer: B

    Compare parts on the same diagonal:

    2x+3=x+8,x=5.\begin{aligned} 2x+3&=x+8,\\ x&=5. \end{aligned}2x+3x​=x+8,=5.​

    For the other diagonal,

    y+1=3y−7,y=4.\begin{aligned} y+1&=3y-7,\\ y&=4. \end{aligned}y+1y​=3y−7,=4.​

    The resulting half-lengths are 131313 and 555, both positive.

    In convex ABCDABCDABCD, both opposite-angle pairs are congruent. Angle AAA measures (2x+10)∘(2x+10)^\circ(2x+10)∘ and angle CCC measures (4x−30)∘(4x-30)^\circ(4x−30)∘. What is the measure of angle BBB?

    Answer choices for question 4

    Solution

    Correct answer: D

    Set the opposite measures equal:

    2x+10=4x−30,x=20.\begin{aligned} 2x+10&=4x-30,\\ x&=20. \end{aligned}2x+10x​=4x−30,=20.​

    Thus angle AAA is 50∘50^\circ50∘. The complete opposite-angle test proves a parallelogram, so consecutive angles are supplementary:

    m∠B=180∘−50∘,m∠B=130∘.\begin{aligned}m\angle B&=180^\circ-50^\circ,\\m\angle B&=130^\circ.\end{aligned}m∠Bm∠B​=180∘−50∘,=130∘.​
  5. 5

    Convex ABCDABCDABCD has two side equalities.

    AB=CD,AD=BC.\begin{gathered} AB=CD,\\ AD=BC. \end{gathered}AB=CD,AD=BC.​

    After drawing diagonal BDBDBD, which ordered triangle correspondence is guaranteed by these matches and SSS?

    Answer choices for question 5

    Solution

    Correct answer: A

    Match ABABAB with CDCDCD, ADADAD with CBCBCB, and the common BDBDBD with DBDBDB. The vertex correspondence is A↔CA\leftrightarrow CA↔C, B↔DB\leftrightarrow DB↔D, and D↔BD\leftrightarrow BD↔B, giving the stated order.

    △ABD≅△CDB\triangle ABD\cong\triangle CDB△ABD≅△CDB

    Diagonals of convex ABCDABCDABCD bisect each other at EEE. Which reason proves △AEB≅△CED\triangle AEB\cong\triangle CED△AEB≅△CED?

    Answer choices for question 6

    Solution

    Correct answer: D

    The givens give two side matches.

    AE=EC,BE=ED.\begin{gathered} AE=EC,\\ BE=ED. \end{gathered}AE=EC,BE=ED.​

    Angles AEB,CEDAEB,CEDAEB,CED are vertical and lie between those side pairs. Thus SAS applies, without assuming parallel sides.

    △AEB≅△CED\triangle AEB\cong\triangle CED△AEB≅△CED

    In convex ABCDABCDABCD, angles A,CA,CA,C both measure ppp, and angles B,DB,DB,D both measure qqq. Which equation turns this evidence into supplementary consecutive angles?

    Answer choices for question 7

    Solution

    Correct answer: C

    The quadrilateral angle sum is

    2p+2q=360∘.2p+2q=360^\circ.2p+2q=360∘.

    Dividing by 222 gives p+q=180∘p+q=180^\circp+q=180∘. The common measures need not be equal.

  8. 8

    In the shown convex ABCDABCDABCD, the givens include a parallel pair and a congruent pair.

    AB∥CD,AD=BC.\begin{gathered} AB\parallel CD,\\ AD=BC. \end{gathered}AB∥CD,AD=BC.​

    Which fact proves that this particular quadrilateral is not a parallelogram?

    Answer choices for question 8

    Solution

    Correct answer: C

    Every parallelogram has congruent opposite sides. Here the parallel bases have lengths 121212 and 666, so they are unequal. The congruent sloping sides do not repair that failure.

  9. 9

    Diagonals of convex ABCDABCDABCD meet at EEE. The parts have lengths in the same unit.

    AE=6,EC=6,BE=5,ED=3.\begin{gathered} AE=6,\\ EC=6,\\ BE=5,\\ ED=3. \end{gathered}AE=6,EC=6,BE=5,ED=3.​

    Which conclusion is certain?

    Answer choices for question 9

    Solution

    Correct answer: B

    Although ACACAC is bisected, BEBEBE and EDEDED are unequal. Every parallelogram has both diagonals bisected. Failure of this necessary condition excludes a parallelogram.

  10. 10

    Convex ABCDABCDABCD has this evidence about one opposite-side pair.

    AB∥CD,AB=CD.\begin{gathered} AB\parallel CD,\\ AB=CD. \end{gathered}AB∥CD,AB=CD.​

    With diagonal ACACAC, which included-angle equality supports SAS for triangles BACBACBAC and DCADCADCA?

    Answer choices for question 10

    Solution

    Correct answer: A

    Transversal ACACAC crosses the given parallel lines AB,CDAB,CDAB,CD, so ∠BAC\angle BAC∠BAC and ∠DCA\angle DCA∠DCA are equal alternate interior angles. They lie between the given equal sides and the common diagonal. The other listed equalities cannot be assumed before proving the needed structure.

    ∠BAC≅∠DCA\angle BAC\cong\angle DCA∠BAC≅∠DCA

    In convex ABCDABCDABCD, diagonals meet at EEE. The parts have lengths in centimeters.

    AE=2,BE=2,EC=3,ED=3.\begin{gathered} AE=2,\\ BE=2,\\ EC=3,\\ ED=3. \end{gathered}AE=2,BE=2,EC=3,ED=3.​

    Which conclusion is justified?

    Answer choices for question 11

    Solution

    Correct answer: D

    The given pairs compare different diagonals. On ACACAC, its halves are 222 and 333, so it is not bisected. This violates a necessary parallelogram property, even though each whole diagonal is 555 cm.

  12. 12

    The diagonals of convex ABCDABCDABCD bisect each other at EEE. SAS gives two congruences.

    △AEB≅△CED,△BEC≅△DEA.\begin{gathered} \triangle AEB\cong\triangle CED,\\ \triangle BEC\cong\triangle DEA. \end{gathered}△AEB≅△CED,△BEC≅△DEA.​

    Which conclusion completes a valid side-based proof of a parallelogram?

    Answer choices for question 12

    Solution

    Correct answer: B

    Corresponding sides of the first congruence give AB=CDAB=CDAB=CD.

    Corresponding sides of the second give BC=ADBC=ADBC=AD.

    Both opposite-side pairs are congruent, so the previously proved side test establishes a parallelogram.
