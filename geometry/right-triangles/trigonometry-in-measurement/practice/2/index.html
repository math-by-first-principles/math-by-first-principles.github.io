    On level ground, an instrument 1.80 m above the base level sights the top of a vertical 16.0 m mast in the same vertical plane. The horizontal run is 25.0 m. Find the elevation angle to the nearest tenth of a degree.

    Answer choices for question 1

    Solution

    Correct answer: C

    Subtract instrument height to obtain the opposite leg.

    u=16.0−1.80.θ=tan⁡−1(14.2/25.0).θ≈29.6∘.\begin{aligned}u&=16.0-1.80.\\\theta&=\tan^{-1}(14.2/25.0).\\\theta&\approx29.6^\circ.\end{aligned}uθθ​=16.0−1.80.=tan−1(14.2/25.0).≈29.6∘.​

    An observer's ground point is 3.03.03.0 m above a vertical tower's base level. The eye is 2.02.02.0 m above that ground. The horizontal run to the tower is 30.030.030.0 m, and elevation is 24.0∘24.0^\circ24.0∘ in the common vertical plane. Find tower height to the nearest tenth.

    Solution

    H=3.0+2.0+30tan⁡24∘.H≈18.4 m.\begin{aligned}H&=3.0+2.0+30\tan24^\circ.\\H&\approx18.4\text{ m}.\end{aligned}HH​=3.0+2.0+30tan24∘.≈18.4 m.​

    From one station, an observer measures only elevation angles to the top and base of a vertical segment, both above the horizontal. No distance or length is known. Does this determine the segment’s length?

    Answer choices for question 7

    Solution

    Correct answer: B

    Let uuu and vvv be the two vertical rises above the eye and ddd the common horizontal run. Doubling all three lengths preserves both tangent ratios.

    2u2d=ud.2v2d=vd.\begin{aligned}\frac{2u}{2d}&=\frac ud.\\\frac{2v}{2d}&=\frac vd.\end{aligned}2d2u​2d2v​​=du​.=dv​.​

    The same two angles therefore permit a vertical segment twice as long.

    An eye sees the top of a vertical tower at elevation 27.0∘27.0^\circ27.0∘ and its base at depression 18.0∘18.0^\circ18.0∘. Both angles use the eye's horizontal in a common vertical plane. The horizontal run is 35.035.035.0 m. Find whole tower height to the nearest tenth.
