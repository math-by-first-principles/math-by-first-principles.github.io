Graphs and Transformations

▾

Progress can't be saved in this browser, so this lesson's status can't be set.

Intuition

A graph records many input-output pairs at once. If a rule changes, do we need to calculate every pair again? Often we can track what happens to a few key points and explain the entire new shape. The important question is whether the change acts on the input before the function runs or on the output afterward.

Learning goals

  • Recognize parent functions and connect their shapes with tables and formulas
  • Explain horizontal and vertical changes by tracking corresponding graph points
  • Construct transformed graphs while preserving domain and endpoint information
  • Classify symmetry using both the function rule and its domain
  • Identify intervals of change and local or global extrema from graphs

Familiar shapes as starting points

A parent function is a simple reference function from which we build related graphs. A parent is a starting choice, not a claim that every function belongs to one of a few families.

Compare absolute value and squaring at inputs 0,1,20,1,20,1,2. Their outputs are 0,1,20,1,20,1,2 and 0,1,40,1,40,1,4. Both graphs turn at the origin, but absolute value makes a corner with straight sides; squaring makes a smooth curve whose rise becomes steeper farther from the origin.

Change the output

Adding to a function’s output moves every point vertically. If f(2)=5f(2)=5f(2)=5, then f(2)+3=8f(2)+3=8f(2)+3=8: the input stays 222, while the height rises by 333. Multiplying the output by 222 would instead change the height from 555 to 101010.

Change the input

An inside change tells us which new input reaches an old one. Suppose the original graph has a point (6,3)(6,3)(6,3). In g(x)=f(2x)g(x)=f(2x)g(x)=f(2x), the old input 666 is reached when 2x=62x=62x=6, so the corresponding point is (3,3)(3,3)(3,3).

Track all the changes together

We can combine these moves without memorizing an order of verbal directions. Match the inside to the old input, then calculate the new output.

Read symmetry and change

A graph may match itself after a reflection. For f(x)=x2f(x)=x^2f(x)=x2, inputs −3-3−3 and 333 both give 999. In general, (−x)2=x2(-x)^2=x^2(−x)2=x2, so the graph mirrors across the yyy-axis. This is even symmetry: f(−x)=f(x)f(-x)=f(x)f(−x)=f(x) for every input in a domain symmetric about zero.

For f(x)=x3f(x)=x^3f(x)=x3, those inputs give −27-27−27 and 272727. The rule (−x)3=−x3(-x)^3=-x^3(−x)3=−x3 shows odd symmetry: f(−x)=−f(x)f(-x)=-f(x)f(−x)=−f(x). Each point (u,v)(u,v)(u,v) has partner (−u,−v)(-u,-v)(−u,−v), a half-turn about the origin.

Both definitions require that −x-x−x be allowed whenever xxx is allowed. The rule x2x^2x2 restricted to [0,3][0,3][0,3] is neither even nor odd: most of its reflected inputs are missing. The zero function on all real numbers is both even and odd. Other nonzero constant functions on all real numbers are even but not odd.

Check your understanding

Which function is odd on its stated domain?

Answer choices

Cubing gives f(−x)=−f(x)f(-x)=-f(x)f(−x)=−f(x), and the real-number domain contains both xxx and −x-x−x. Restricting to [0,5][0,5][0,5] removes that domain symmetry. Adding 111 destroys the equality.

To read change, move left to right. A function is increasing on an interval when every larger input there gives a larger output. It is decreasing when every larger input gives a smaller output. A constant interval has equal outputs, so it is neither strictly increasing nor strictly decreasing.

An output is a local maximum if it is at least as large as nearby outputs, and a local minimum if it is at most as large. Here we use these local terms at interior points of the domain. A global maximum or global minimum compares with every output in the domain, including any included endpoints. Together these are extrema. Name both the value and the input where it occurs.

Worked example 3 Separate the highest peak from a smaller peak

Problem. The entire graph below consists of straight segments through (−5,1)(-5,1)(−5,1), (−2,5)(-2,5)(−2,5), (1,−1)(1,-1)(1,−1), (4,3)(4,3)(4,3), and (6,0)(6,0)(6,0), all included.

Part B: State its local extrema.

Part C: State its global extrema.

Solution. Part A: The graph rises from input −5-5−5 to −2-2−2, falls to 111, rises to 444, and falls to 666. We report intervals between turning points using open endpoints:

  • Increasing on (−5,−2)(-5,-2)(−5,−2) and (1,4)(1,4)(1,4).
  • Decreasing on (−2,1)(-2,1)(−2,1) and (4,6)(4,6)(4,6).

Part B: The local maximum values are 555 at x=−2x=-2x=−2 and 333 at x=4x=4x=4. The local minimum value is −1-1−1 at x=1x=1x=1.

Part C: The global maximum is 555 at x=−2x=-2x=−2, and the global minimum is −1-1−1 at x=1x=1x=1. The smaller peak at x=4x=4x=4 is only a local maximum because another part of the graph is higher. Neither endpoint exceeds the highest peak or falls below the lowest valley.

The complete-graph condition matters. A table can show outputs increasing at its listed inputs while hiding a dip between them. A cropped graph can hide a higher peak. Without information about the missing intervals, report only what the data establish.

Choose a rule from graph features

Different parent families can fit the same few points. Choose a shape using information about the relationship, not just one convenient match.

Common mistakes

Common mistakes

  • Multiplying horizontal positions by the inside factor. Match the inside to the old input; f(2x)f(2x)f(2x) reaches an old input at half its former position.
  • Reading a shift before factoring. In f(3x−12)f(3x-12)f(3x−12), the inside is 3(x−4)3(x-4)3(x−4), so the horizontal shift is 444 after scaling.
  • Dropping domain restrictions. A transformed graph contains only images of original points, with the same endpoint inclusion.
  • Ignoring the domain in a symmetry test. The required partner input must exist before its output can be compared.
  • Calling every peak the global maximum. A local peak only wins against nearby points; a global claim needs the whole domain.

Key takeaways

  • Parent functions supply shapes and landmarks, while the domain tells you which part is present.
  • Match a transformed inside expression to an old input, then apply the outside changes to its output.
  • Track endpoints, corners, and other useful points to reconstruct a graph.
  • Check even and odd symmetry using the equation and a domain symmetric about zero.
  • Read change from left to right, and distinguish nearby extrema from those over the whole domain.

A bit of history (optional)

In 1637, René Descartes published La Géométrie as an appendix to his Discourse on Method. It asked readers to connect geometric constructions with algebraic equations. Descartes described giving names to known and unknown lengths, then expressing the relationships between them as equations.

The book was written for experienced mathematicians, not as a school introduction to graph paper. Its methods helped make it possible to study a geometric question through algebra, even when the resulting curve was harder to draw than a circle or a straight line.
