Functions: Chapter Review

A rapid review before the test: the chapter's vocabulary and notation, every formula with the conditions to use it, the standard problem types step by step, and the traps that cost points.

Vocabulary and notation

Relation and function
A relation pairs inputs with outputs. A function gives exactly one output for every allowed input; different inputs may share an output.
Function notation f(x)f(x)f(x)
The output of fff at input xxx, represented by the graph point (x,f(x))(x,f(x))(x,f(x)). Parentheses identify the input; they do not mean multiplication.
Independent and dependent quantities
The independent quantity is the model's input; the dependent quantity is its output. Interpret each with its stated units.
Domain and range
The domain contains allowed inputs; the range contains outputs actually attained. Specifying a different domain can change the range even when the formula stays the same.
Natural real and feasible domains
A natural real domain contains all real inputs where the formula is defined with real output. A feasible domain also meets the situation's conditions, such as positive lengths or whole-number counts.
Intervals and set notation
Brackets include finite endpoints; parentheses exclude them and always accompany infinity. Braces list individual values or describe them by a condition, as in {x∈R:x>c}\{x\in\mathbb R:x>c\}{x∈R:x>c}. A union ∪\cup∪ means either set; an intersection ∩\cap∩ means both. The empty set is ∅\varnothing∅.
Piecewise function
A rule using different formulas on specified input sets. Each declared input still needs one output, including every boundary input.
Parent function
A simple reference function whose shape and landmarks help construct related graphs.
Increasing, decreasing, constant
On an interval, increasing means every larger input has a larger output; decreasing means a smaller output. Constant means equal outputs, so neither strict description applies.
Local and global extrema
Local maxima and minima compare nearby outputs at interior domain points. Global extrema compare the whole domain. State an attained extreme value and where it occurs.
Composition and decomposition
Composition feeds one function's output into another. Decomposition expresses a rule as such a sequence of simpler functions.
One-to-one function
Different allowed inputs give different outputs, so each actual output identifies exactly one original input. A function strictly increasing or strictly decreasing over its entire specified domain is one-to-one.
Inverse function f−1f^{-1}f−1
The function that returns the original input from an output of a one-to-one function. Its domain is exactly the original range.

  • Vertical and horizontal line tests

Problem types, step by step

Evaluate a function or find an input

  1. Identify whether the given number is an input or a requested output.
  2. Read the matching table or graph coordinate, or replace the entire formula input with the given value or expression.
  3. For a piecewise rule, select its input condition first. When solving for an input, check each candidate against its branch and domain.
  4. Interpret the result with the model's input or output units.

e.g. For f(x)=4x−7f(x)=4x-7f(x)=4x−7 on R\mathbb RR, evaluate at t+2t+2t+2: f(t+2)=4t+1f(t+2)=4t+1f(t+2)=4t+1.

Find a natural or contextual domain

  1. Record denominator exclusions, even-root inequalities, and any declared domain.
  2. Keep inputs satisfying all conditions together. For a model, also apply positivity, count restrictions, or operating limits.
  3. Write the surviving set with correct endpoints, gaps, and infinity parentheses.

e.g. For f(x)=19−x/(x+3)f(x)=\sqrt{19-x}/(x+3)f(x)=19−x​/(x+3), find the natural domain: x≤19x\le19x≤19 with x≠−3x\ne-3x=−3.

Find the range on a specified domain

  1. Use only the allowed inputs. For a finite domain, evaluate each listed input; for pieces, handle each assigned input set separately.
  2. Find output bounds and possible gaps. Check interior low or high points as well as endpoints.
  3. Verify that no output lies outside the proposed set and that every claimed output is attained. Combine pieces without filling unsupported gaps.

Calculate and interpret an average rate

  1. Find the two endpoint outputs from the correct rule or representation.
  2. Find the output change. If only subinterval rates are supplied, multiply each rate by its input change and add the output changes.
  3. Divide by the matching total input change, keeping the subtraction order consistent.
  4. State output units per input unit and interpret the sign as net change. Do not infer constant change inside the interval.

e.g. Given m(2)=23m(2)=23m(2)=23 kg and m(7)=8m(7)=8m(7)=8 kg, with input in days, find the average rate: (8−23)/(7−2)=−3(8-23)/(7-2)=-3(8−23)/(7−2)=−3 kg/day.

Construct a transformed graph

  1. Identify the parent or supplied graph and retain its domain, endpoints, and shape.
  2. Factor the inside, then match it to each old input. Apply outside operations to the corresponding output.
  3. Place transformed landmarks in their new horizontal order and preserve open endpoints, holes, and connecting pieces.
  4. If a multiplier is unknown, substitute another given point into the appropriate corner or vertex form.

Describe symmetry, change, and extrema

  1. Check opposite-input membership before testing the even or odd equation.
  2. Read rising, falling, and constant portions from left to right. Report intervals using input values.
  3. Compare nearby interior outputs for local extrema and the whole domain for global extrema. Name both value and input; an excluded bound is not an attained extremum.

Combine two functions arithmetically

  1. Find the common original inputs; for a quotient, remove inputs where the denominator function outputs zero.
  2. Apply the requested operation to the complete outputs at the same input.
  3. Simplify while retaining every original restriction.

Compose functions and determine allowed inputs

  1. Identify the first action as the inner function; check intermediate quantities and units.
  2. Evaluate or substitute the entire inner output into the outer rule.
  3. Require the original input to enter the inner domain and its output to enter the outer domain.
  4. For a comparison of orders, repeat the process in the other order with its own restrictions.

e.g. For f(u)=u−4f(u)=u-4f(u)=u−4 and g(x)=3xg(x)=3xg(x)=3x on R\mathbb RR, compare at 666: f(g(6))=14f(g(6))=14f(g(6))=14 and g(f(6))=6g(f(6))=6g(f(6))=6.

Decompose a formula

  1. Choose a useful intermediate expression and define the inner function that produces it.
  2. Define the outer function as the remaining operation on that expression.
  3. Substitute back and verify that the composite has the original formula and exactly the intended domain.

e.g. Decompose H(x)=5x+12H(x)=\sqrt{5x+12}H(x)=5x+12​: choose g(x)=5x+12g(x)=5x+12g(x)=5x+12, f(u)=uf(u)=\sqrt uf(u)=u​; the composite requires x≥−12/5x\ge-12/5x≥−12/5.

Find and verify an inverse function

  1. Confirm one-to-one behavior on the given domain, or choose a suitable restricted branch when requested.
  2. Write u=f(x)u=f(x)u=f(x) and solve for the original input xxx. Select a root sign consistent with the original branch.
  3. Use the original range as the inverse domain and the original domain as its range. For pieces, use each piece's output set as its inverse input condition.
  4. Check both compositions for every input in their proper domains, including intermediate-value compatibility.

e.g. For f(x)=5x+4f(x)=5x+4f(x)=5x+4 on R\mathbb RR, find its inverse: f−1(u)=(u−4)/5f^{-1}(u)=(u-4)/5f−1(u)=(u−4)/5 on R\mathbb RR.

Exam traps

  • Trap Rejecting a function because an output repeats.

    Fix Repeated outputs are allowed for a function; they prevent one-to-one behavior when they come from different inputs.

  • Trap Treating f(a)f(a)f(a) as multiplication or as the equation f(x)=af(x)=af(x)=a.

    Fix The first requests the output at input aaa; the equation asks for inputs producing output aaa.

  • Trap Choosing a piecewise branch from its calculated output.

    Fix Choose from the input condition. Recheck branch membership for every solved candidate and include each declared boundary consistently.

  • Trap Extending a few samples into an entire graph.

    Fix Incomplete table samples alone do not determine unrecorded values, full range, or global extrema. Distinct sampled outputs alone do not establish one-to-one behavior beyond those inputs; repeated outputs from different inputs refute it. A complete finite-domain table determines its range, global extrema, and one-to-one behavior. Connect points only when the rule or graph description permits it.

  • Trap Equating zero average rate with a constant function.

    Fix Equal endpoint outputs establish zero net change. Intervening outputs may differ.

  • Trap Using or between restrictions that must all hold.

    Fix Keep the intersection of allowed inputs. Preserve original exclusions after cancellation, even if the new expression looks unrestricted.

  • Trap Copying an open graph point into a missing range value.

    Fix Check whether another included point reaches the same height. Conversely, never fill a gap in heights without points that produce them.

  • Trap Multiplying horizontal positions by the inside multiplier.

    Fix Solve the inside expression for the old input. Horizontal scaling uses 1/∣b∣1/|b|1/∣b∣; factor before identifying the shift.

  • Trap Calling a shifted or restricted parent even automatically.

    Fix Check symmetry about zero in both the domain and the actual rule. A vertical symmetry line elsewhere does not make a function even.

  • Trap Calling every peak a global maximum.

    Fix Compare with the whole stated domain, including included endpoints. An open upper bound need not be attained.

  • Trap Using the arithmetic-domain rule for composition.

    Fix Arithmetic needs both functions at the same input. Composition needs the inner output accepted by the outer function; also check units and order.

  • Trap Confusing inverse, reciprocal, and an unrestricted candidate formula.

    Fix An inverse recovers inputs; a reciprocal divides one by outputs. Keep the exact exchanged domains and verify both inverse compositions.

  • Trap Replacing x2\sqrt{x^2}x2​ with xxx on every real input.

    Fix Use ∣x∣\lvert x\rvert∣x∣. A parabola's chosen branch determines which square-root sign returns allowed original inputs.
