Inverse Functions

▾

Progress can't be saved in this browser, so this lesson's status can't be set.

Intuition

A function answers a forward question: what output comes from this input? Sometimes the useful question runs the other way. If a rule subtracts five and then doubles, an output of fourteen identifies the original input as twelve. But an output of nine from squaring could have come from either three or negative three. Recovering an input requires enough information to choose just one.

Learning goals

  • Decide whether a function is one-to-one using repeated outputs and horizontal lines
  • Interpret inverse notation and distinguish an inverse function from a reciprocal
  • Read inverse graphs by exchanging coordinates, domains, ranges, and endpoint inclusion
  • Find inverse formulas and verify both compositions on their proper domains
  • Choose a parabola branch and justify the sign of its inverse

Can an output identify its input?

Compare two complete tables. Both describe functions because each listed input has exactly one output.

InputOutput of fffOutput of rrr
−3-3−3222222
111666666
444999222

For fff, output 222 identifies input −3-3−3, output 666 identifies 111, and output 999 identifies 444. For rrr, output 222 leaves two possible original inputs. Reading that column backward would assign two outputs to one new input.

A function is one-to-one when different allowed inputs always produce different outputs. Equivalently, equal outputs must have come from the same input. A one-to-one function can be reversed on its actual range: every output has one original input, so the reversed rule is a function.

On a graph, repeated outputs appear as points at the same height. The horizontal-line test says that a function is one-to-one exactly when every horizontal line meets its entire graph at most once. Lines at heights outside the range meet it zero times, which is allowed. This test assumes the original relation is already a function; the vertical-line test answers that earlier question.

Exchange the coordinates of a graph

The table figure shows the point (2,−3)(2,-3)(2,−3) opposite (−3,2)(-3,2)(−3,2) across the diagonal y=xy=xy=x. Swapping coordinates reflects points across this line: horizontal distance becomes vertical distance and vice versa. The axes need equal unit scales for the picture to look like an ordinary mirror reflection.

For any one-to-one function, each point (a,b)(a,b)(a,b) on its graph becomes (b,a)(b,a)(b,a) on the inverse graph. A connected segment reflects to a connected segment; an isolated point stays isolated. An open endpoint stays open because swapping coordinates does not add a missing pair.

Check the whole round trip

An algebraic inverse is found by solving for the old input in terms of the old output. The equation supplies a candidate rule; the sets and the two compositions confirm what that rule actually reverses.

For example, f(x)=11−3xf(x)=11-3xf(x)=11−3x takes input 222 to output 555, and its inverse takes 555 back to 222. Going the other way, the inverse takes 888 to 111, and fff takes 111 back to 888. Example 2’s calculations extend both trips to every allowed input.

In general, if fff has domain DDD and range RRR, a candidate ggg must map RRR back to DDD and satisfy

g(f(x))=xfor every x∈D,g(f(x))=x\quad\text{for every }x\in D,g(f(x))=xfor every x∈D,

and, in the other direction,

f(g(u))=ufor every u∈R.f(g(u))=u\quad\text{for every }u\in R.f(g(u))=ufor every u∈R.

Checking a few values can expose an error, but passing a few checks does not establish these identities everywhere. Simplification also cannot restore an input that was excluded before the calculation.

Select a branch before reversing a parabola

Squaring on all real inputs loses the sign. The points (−2,4)(-2,4)(−2,4) and (2,4)(2,4)(2,4) reflect to (4,−2)(4,-2)(4,−2) and (4,2)(4,2)(4,2). The reflected relation then assigns two outputs to input 444, so it is not a function.

Restricting the original domain chooses which input to keep for each repeated output. This creates a different function with the same formula. Both nonnegative and nonpositive inputs can work for squaring, but they lead to different inverse functions.

Common mistakes

Common mistakes

  • Function versus one-to-one: one output per input makes a function; one original input per output allows its reversal.
  • Inverse versus reciprocal: f−1(u)f^{-1}(u)f−1(u) recovers an input, while 1/f(u)1/f(u)1/f(u) divides one by an output.
  • Lost restrictions: an inverse formula must use the original range as its domain, even if the expression accepts more numbers.
  • One composition: a successful round trip in one direction does not by itself verify the other direction on its full domain.
  • Square-root sign: x2=∣x∣\sqrt{x^2}=\lvert x\rvertx2​=∣x∣. A selected branch determines when this equals xxx or −x-x−x.

Key takeaways

  • A function is one-to-one when no two allowed inputs share an output.
  • Reverse a one-to-one function by recovering the input for each value in its actual range.
  • Exchange coordinates to reflect the graph across y=xy=xy=x; exchange domain and range too.
  • Solve for the old input, then verify both compositions with their domain restrictions.
  • Choose a one-to-one branch before reversing a parabola, and keep that choice in the inverse formula.

A bit of history (optional)

In the nineteenth century, Uranus was not moving quite as astronomers’ calculations predicted. The discrepancy offered a clue: perhaps the gravity of an unseen planet was disturbing its orbit. Urbain Le Verrier in France and John Couch Adams in England used that effect to predict where another planet might be.

Le Verrier sent his prediction to Johann Galle at the Berlin Observatory. In 1846, Galle found Neptune near the predicted position. The search began with the motion of a planet people could see and led to a planet they had not yet identified. NASA’s Jet Propulsion Laboratory recounts the discovery.
