    A function has domain D=(−6,2]∪{5}D=(-6,2]\cup\{5\}D=(−6,2]∪{5}. Describe all its allowed inputs using inequalities or an equality.

    The input −6-6−6 is excluded by the parenthesis.

    The input 000 lies inside the interval, and 222 is included by the bracket.

    The value 444 lies outside the interval and is not the separately listed value.

    The value 555 belongs because it is explicitly included in {5}\{5\}{5}.

    Answer

    The allowed inputs satisfy −6<x≤2-6<x\le2−6<x≤2 or x=5x=5x=5. The values 000, 222, and 555 belong; −6-6−6 and 444 do not.

  3. Problem 3 Follow the full graph

    The complete graph joins an open point at (−5,4)(-5,4)(−5,4) to a filled point at (1,−2)(1,-2)(1,−2), then to an open point at (4,1)(4,1)(4,1), using straight segments. It has no other points.

    Find the domain and range in interval notation. Explain why the two range endpoints use different symbols.

    Text description of this figure

    The entire graph consists of two segments, from open (-5,4) to filled (1,-2), then to open (4,1).

    1. Hint 1

      Read the horizontal inputs and vertical output heights separately.

    2. Hint 2

      Identify where the lowest height occurs. Then decide whether any included point reaches the highest indicated height.

    Answer

    Domain: (−5,4)(-5,4)(−5,4). Range: [−2,4)[-2,4)[−2,4); the lower output is included and the upper output is excluded.

    Full solution

    The segments supply a point for every input between −5-5−5 and 444.

    Both outer endpoints are open, and there are no other points at those inputs, so the domain is (−5,4)(-5,4)(−5,4).

    The lowest output is −2-2−2 at the filled point (1,−2)(1,-2)(1,−2), so it belongs to the range.

    The left segment covers every height from −2-2−2 included up to 444 excluded.

    The right segment adds no height outside that set.

    The only point drawn at height 444 is open.

    Therefore the range is [−2,4)[-2,4)[−2,4).

    Answer

    Domain: (−5,4)(-5,4)(−5,4). Range: [−2,4)[-2,4)[−2,4); the lower output is included and the upper output is excluded.

    Key idea

    An included interior point can determine a range endpoint even when both outer graph endpoints are open.

  6. Problem 6 Two separated input pieces

    A function has exactly the following two pieces.

    Piece A: p(x)=x+5p(x)=x+5p(x)=x+5 for −4≤x<−1-4\le x<-1−4≤x<−1.

    Piece B: p(x)=2xp(x)=2xp(x)=2x for 1≤x≤31\le x\le31≤x≤3.

    Find its domain and range. State whether 444 is in the range, and give an allowed input producing it if it is.

    1. Hint 1

      The domain combines the two stated input sets. Find the output set of each piece separately.

    2. Hint 2

      An output excluded from one piece may still occur in the other piece. Check the requested output in both rules.

    Answer

    Domain: [−4,−1)∪[1,3][-4,-1)\cup[1,3][−4,−1)∪[1,3]. Range: [1,6][1,6][1,6]. The output 444 occurs at x=2x=2x=2.

    Full solution

    Piece A: its allowed inputs are [−4,−1)[-4,-1)[−4,−1).

    Adding 555 gives the output interval [1,4)[1,4)[1,4).

    Piece B: its allowed inputs are [1,3][1,3][1,3].

    Multiplying by 222 gives the output interval [2,6][2,6][2,6].

    Combining the input sets gives domain [−4,−1)∪[1,3][-4,-1)\cup[1,3][−4,−1)∪[1,3].

    The output intervals overlap, so their union is the single interval [1,6][1,6][1,6].

    The output 444 is excluded from Piece A, but Piece B produces it at x=2x=2x=2.

    That input belongs to [1,3][1,3][1,3], so 444 is in the range.

    Answer

    Domain: [−4,−1)∪[1,3][-4,-1)\cup[1,3][−4,−1)∪[1,3]. Range: [1,6][1,6][1,6]. The output 444 occurs at x=2x=2x=2.
