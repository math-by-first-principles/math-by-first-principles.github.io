Domain and Range

▾

Progress can't be saved in this browser, so this lesson's status can't be set.

Intuition

A formula for the volume of a folded box may still produce a number after you choose a cut too large for the cardboard. The calculation can work even when the box cannot exist. Before using a function, ask two questions: which inputs belong, and which outputs can those inputs actually produce?

Learning goals

  • Express domains and ranges using intervals and set notation
  • Combine algebraic restrictions without losing excluded inputs
  • Read domains and ranges from graphs and piecewise rules
  • Justify a range using the formula and its specified domain
  • Distinguish a formula's natural domain from the feasible inputs of a model

Writing the inputs and outputs

The domain is the set of allowed inputs. The range is the set of outputs the function actually produces from that domain. A formula alone may not tell you which inputs were intended.

For example, a function pairs the inputs −2-2−2, 111, and 444 with the outputs 444, 111, and 161616. Its domain is {−2,1,4}\{-2,1,4\}{−2,1,4} and its range is {1,4,16}\{1,4,16\}{1,4,16}. Braces list the members of a set. There are no inputs between the listed ones unless the definition includes them.

An interval includes every real number between its bounds. The interval (−3,5](-3,5](−3,5] includes 000 and 4.94.94.9, excludes −3-3−3, and includes 555. A parenthesis excludes a finite endpoint; a square bracket includes it. An open dot on a number line excludes an endpoint, and a filled dot includes it.

Worked example 1 Three ways to describe the same set

Problem. A function allows every real input greater than −3-3−3 and no greater than 555.

Part A: Write its domain as an inequality.

Part B: Write it in interval notation.

Part C: Write it in set-builder notation.

Solution. Part A: The two conditions must hold together:

−3<x≤5.-3<x\le5.−3<x≤5.

Part B: The domain is (−3,5](-3,5](−3,5] in interval notation.

Part C: In set-builder notation, we describe the members by a condition:

{x∈R:−3<x≤5}.\{x\in\mathbb R:-3<x\le5\}.{x∈R:−3<x≤5}.

Read this as “the real numbers xxx such that −3<x≤5-3<x\le5−3<x≤5.” The symbol R\mathbb RR means the real numbers.

The symbol ∪\cup∪ means union: include the numbers in either set. For example, (−∞,−1)∪[2,∞)(-\infty,-1)\cup[2,\infty)(−∞,−1)∪[2,∞) describes inputs below −1-1−1 or at least 222. Infinity is not an endpoint you can include, so use parentheses beside ∞\infty∞ and −∞-\infty−∞. All real numbers form (−∞,∞)(-\infty,\infty)(−∞,∞).

A single value is written with braces, such as {6}\{6\}{6}. An empty set, with no values, is written ∅\varnothing∅. Use a finite list for a finite set, intervals for continuous stretches, and unions when there are gaps. The word “and” in restrictions means take their overlap, called their intersection.

Check your understanding

Which notation represents all real numbers at least −5-5−5 and less than 222?

Answer choices

At least includes −5-5−5, so use a bracket there. Less than excludes 222, so use a parenthesis there. The interval includes every real value between the endpoints; a two-element set would not.

Every restriction must hold

Unless a domain is specified, a formula’s natural real domain consists of all real inputs for which its calculation gives a real output. Here all functions are real-valued.

A denominator cannot be zero. For r(x)=1/(x+6)r(x)=1/(x+6)r(x)=1/(x+6), the input −6-6−6 would require division by zero, while every other real input is allowed. Thus its domain is (−∞,−6)∪(−6,∞)(-\infty,-6)\cup(-6,\infty)(−∞,−6)∪(−6,∞).

The expression inside an even root, called its radicand, must be nonnegative. For s(x)=x−7s(x)=\sqrt{x-7}s(x)=x−7​, the input 111111 works because 4=2\sqrt{4}=24​=2, while 333 would require a real square root of −4-4−4. Therefore x−7≥0x-7\ge0x−7≥0, giving the domain [7,∞)[7,\infty)[7,∞). Zero is allowed: 0=0\sqrt0=00​=0. Odd roots do not have this sign restriction; for example, −83=−2\sqrt[3]{-8}=-23−8​=−2.

When an even root is in a denominator, it must also be nonzero. The domain of 1/x−71/\sqrt{x-7}1/x−7​ is consequently (7,∞)(7,\infty)(7,∞).

Worked example 2 Combine a root condition with an exclusion

Problem. Consider the function

f(x)=11−xx−4.f(x)=\frac{\sqrt{11-x}}{x-4}.f(x)=x−411−x​​.

Part A: Find its natural real domain.

Part B: Decide whether 444 is an allowed input.

Part C: Decide whether 111111 is an allowed input.

Solution. Part A: The square root requires 11−x≥011-x\ge011−x≥0, so x≤11x\le11x≤11. The denominator requires x−4≠0x-4\ne0x−4=0, so x≠4x\ne4x=4.

An allowed input must pass both tests. Keep the numbers at most 111111, then remove 444:

(−∞,4)∪(4,11].(-\infty,4)\cup(4,11].(−∞,4)∪(4,11].

Part B: At x=4x=4x=4, the denominator is zero, so the function is undefined.

Part C: At x=11x=11x=11, the numerator is zero and the denominator is 777, so f(11)=0f(11)=0f(11)=0 is valid.

Keep restrictions from the original formula when you simplify. For example,

x2−25x−5=x+5(x≠5).\frac{x^2-25}{x-5}=x+5\qquad(x\ne5).x−5x2−25​=x+5(x=5).

Cancellation used division by x−5x-5x−5, which requires x≠5x\ne5x=5. The original function still excludes 555, even though the simpler expression could be evaluated there.

Check your understanding

What is the natural real domain of h(x)=1/9−3xh(x)=1/\sqrt{9-3x}h(x)=1/9−3x​?

Answer choices

The square root must be real and must not equal zero because it is a denominator. Its radicand must be positive. Solving 9−3x>09-3x>09−3x>0 gives x<3x<3x<3, with the inequality reversed when dividing by −3-3−3.

Reading a graph or a piecewise rule

On a graph, a domain value is an xxx-coordinate used by at least one point. A range value is a yyy-coordinate used by at least one point. Look across for inputs and up and down for outputs, including any gaps. A drawing’s window edge is not automatically the end of the function: use the stated domain, endpoints, and continuation arrows.

For a piecewise rule, use each formula only on the inputs assigned to it. Collect those inputs to get the domain. Work out each piece’s outputs, then combine them to get the range.

Worked example 3 A graph with a jump

Problem. The function below has exactly the two pieces shown.

Part A: Find its domain.

Part B: Find its range.

Part C: Decide whether 333 is in its range.

Part D: Decide whether 555 is in its range.

p(x)={2x+1,−2≤x<1,5,1≤x≤3.p(x)= \begin{cases} 2x+1,&-2\le x<1,\\ 5,&1\le x\le3. \end{cases}p(x)={2x+1,5,​−2≤x<1,1≤x≤3.​

Solution. Part A: The first piece uses [−2,1)[-2,1)[−2,1), and the second uses [1,3][1,3][1,3]. Together they cover every input from −2-2−2 through 333, including both ends. The domain is [−2,3][-2,3][−2,3].

Part B: For the first piece, p(−2)=−3p(-2)=-3p(−2)=−3. As xxx increases toward 111, the outputs increase toward 333, but do not reach it: the condition excludes x=1x=1x=1 from this piece. Its outputs are [−3,3)[-3,3)[−3,3).

The second piece always produces 555. It adds just {5}\{5\}{5}, not an interval of heights. Therefore the range is

[−3,3)∪{5}.[-3,3)\cup\{5\}.[−3,3)∪{5}.

Part C: The value 333 is not an output of either piece.

Part D: The value 555 is an output of the second. The range does not fill the gap between them.

An open circle removes one point, not necessarily a whole output value. If another point has the same height, that height still belongs to the range. Likewise, a different filled point with the same xxx-coordinate can keep that input in the domain.

Check your understanding

A graph consists of the segment y=xy=xy=x for 0<x<20<x<20<x<2 and the single point (3,2)(3,2)(3,2). Which domain and range are correct?

Answer choices

The segment uses inputs strictly between 000 and 222 and outputs strictly between 000 and 222. The isolated point adds input 333 and output 222. Thus the top output is included even though the segment itself has an open endpoint there.

Justifying a range from a formula

The domain tells you which substitutions to consider. For example, x2x^2x2 produces every nonnegative real number when xxx runs through all real numbers. If you restrict xxx to [2,4][2,4][2,4], its outputs instead run from 444 to 161616. Changing the allowed inputs can change the range.

To justify a proposed range, check both parts: no allowed input produces anything outside it, and every value inside it is actually produced. A few table entries alone cannot establish the whole range.

Worked example 4 The lowest output occurs inside the domain

Problem. Let q(x)=(x−2)2+3q(x)=(x-2)^2+3q(x)=(x−2)2+3 have domain [−1,4][-1,4][−1,4].

Part A: Find its range.

Part B: Give inputs producing its smallest and largest outputs.

Solution. Part A: On this domain, x−2x-2x−2 runs from −3-3−3 to 222. Its square can be 000, at x=2x=2x=2, and cannot exceed 999, reached at x=−1x=-1x=−1. Adding 333 gives the bounds 333 and 121212.

Every height between those bounds is attained. For any yyy between 333 and 121212, the number y−3\sqrt{y-3}y−3​ lies between 000 and 333. Choose

x=2−y−3.x=2-\sqrt{y-3}.x=2−y−3​.

This input lies in [−1,2][-1,2][−1,2], within the stated domain, and substitution gives q(x)=yq(x)=yq(x)=y. Thus the range is [3,12][3,12][3,12].

Part B: Its smallest output is q(2)=3q(2)=3q(2)=3; its largest is q(−1)=12q(-1)=12q(−1)=12.

Checking only the endpoints would give q(−1)=12q(-1)=12q(−1)=12 and q(4)=7q(4)=7q(4)=7, missing the minimum at the interior input 222.

Check your understanding

The function r(x)=x2+2r(x)=x^2+2r(x)=x2+2 has domain (−2,1](-2,1](−2,1]. What is its range?

Answer choices

The domain contains 000, so the minimum output 222 is attained. Its inputs have absolute value less than 222, so no output reaches 666. Every value from 222 up to, but not including, 666 occurs on the part of the domain between −2-2−2 and 000.

A formula can outlive its model

A contextual domain must respect the meaning of the quantities as well as the algebra. Counts may allow only whole numbers. A physical length may need to be positive. A stated operating interval may exclude otherwise valid inputs.

Worked example 5 Cutting a box from a sheet

Problem. A rectangular sheet measures 242424 centimeters by 161616 centimeters. Cut out a square of side sss centimeters from each corner and fold up the sides to make an open box with positive height, length, and width.

Part A: Write the volume formula and find its natural real domain.

Part B: Find the feasible domain for this box and compare it with the natural domain.

Solution. Part A: The height is sss, the base length is 24−2s24-2s24−2s, and the base width is 16−2s16-2s16−2s. Its volume formula is

V(s)=s(24−2s)(16−2s).V(s)=s(24-2s)(16-2s).V(s)=s(24−2s)(16−2s).

This polynomial can be evaluated for every real sss, so its natural real domain is R\mathbb RR.

Part B: For a physical box, all three dimensions must be positive:

s>0,24−2s>0,16−2s>0.\begin{aligned} s&>0,\\ 24-2s&>0,\\ 16-2s&>0. \end{aligned}s24−2s16−2s​>0,>0,>0.​

Together these give 0<s<80<s<80<s<8, so the feasible domain is (0,8)(0,8)(0,8), with sss measured in centimeters. At 000 there is no height; at 888 there is no base width.

Even a positive calculated volume is not enough. At s=13s=13s=13, the formula gives 260260260 cubic centimeters, but both base dimensions are negative. That number does not describe a box made from this sheet.

Positive height needs s>0s>0s>0. The two base dimensions need 26−2s>026-2s>026−2s>0 and 18−2s>018-2s>018−2s>0. The second condition is the tighter upper bound, s<9s<9s<9. Neither endpoint gives a box with all dimensions positive.

Common mistakes

Common mistakes

  • Domain versus range. Domain lists input values; range lists outputs actually attained.
  • Brackets at infinity. Infinity is not a real endpoint. Write a parenthesis beside either infinity symbol.
  • Combining restrictions with “or.” A formula’s input must pass every required condition, including restrictions in its original form.
  • Filling gaps in the range. A jump between heights does not produce the heights in between.
  • Ignoring the stated domain. Endpoint inclusion and contextual limits can change the range, even when the formula stays the same.

Key takeaways

  • Use intervals for stretches of real values and braces for individually listed values.
  • Find a natural domain by checking every operation; then apply any stated or contextual restriction.
  • Read a graph’s domain from its used horizontal coordinates and its range from its used vertical coordinates.
  • Justify both the bounds of a range and the fact that all claimed outputs are attained.
  • A model’s dimensions, units, and feasible inputs matter even when its formula returns a number.

A bit of history (optional)

Could the same function belong to two supposedly different kinds? Earlier mathematicians sometimes classified functions by whether they used one formula or several. In 1844, Augustin-Louis Cauchy pointed to a simple problem with that distinction.

Take the rule that gives xxx for nonnegative inputs and −x-x−x for negative inputs. It has two written cases. Yet the single expression x2\sqrt{x^2}x2​ gives exactly the same outputs for every real input. What looked like two different classes depended on how someone chose to write the rule.

This was one episode in a longer debate about functions and their representations. The MacTutor history of the function concept describes Cauchy’s example and the changing definitions around it.
