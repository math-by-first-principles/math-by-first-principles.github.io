    A table contains (0,6)(0,6)(0,6), (2,10)(2,10)(2,10), and (6,18)(6,18)(6,18). Which rule agrees with all three entries?

    Answer choices for question 4

    Solution

    Correct answer: B

    The entry at input 000 requires output 666. For the rule f(x)=2x+6f(x)=2x+6f(x)=2x+6, the other two entries give

    f(2)=2(2)+6=10f(2)=2(2)+6=10f(2)=2(2)+6=10
