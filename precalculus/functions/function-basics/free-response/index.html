  1. Problem 1 Read the pairing

    A function is given only on inputs −5-5−5, 000, 444, and 999. Its values are f(−5)=2f(-5)=2f(−5)=2, f(0)=6f(0)=6f(0)=6, f(4)=2f(4)=2f(4)=2, and f(9)=−1f(9)=-1f(9)=−1.

    A. Find f(4)f(4)f(4) and every input that produces output 222.

    B. Explain whether the repeated output 222 conflicts with the function requirement.

    1. Hint 1

      Read an entry from its input to its output.

    2. Hint 2

      Check whether any single input has two different outputs, rather than whether an output repeats.

    Answer

    A. f(4)=2f(4)=2f(4)=2; inputs −5-5−5 and 444 produce 222. B. There is no conflict.

    Full solution

    A.

    The entry for input 444 assigns output 222.

    The entry for input −5-5−5 also assigns output 222, and neither other input does.

    B.

    Each of the four allowed inputs has exactly one output.

    Sharing an output does not violate the requirement.

    Answer

    A. f(4)=2f(4)=2f(4)=2; inputs −5-5−5 and 444 produce 222. B. There is no conflict.

    Key idea

    A function restricts the number of outputs for each input, not the number of inputs that share an output.

    f(13)=5−1=4.f(\tfrac13)=5-1=4.f(31​)=5−1=4.

  3. Problem 3 The boundary choice

    A function uses q(t)=t+6q(t)=t+6q(t)=t+6 for t<−1t<-1t<−1 and q(t)=2−tq(t)=2-tq(t)=2−t for t≥−1t\ge-1t≥−1.

    A. Find q(−2)q(-2)q(−2).

    B. Suppose the conditions were changed to t≤−1t\le-1t≤−1 and t≥−1t\ge-1t≥−1, so both included t=−1t=-1t=−1. Would the revised rule still define a function? Compare the two candidate outputs at that input.

    C. Find q(3)q(3)q(3).

    1. Hint 1

      Select the branch for parts A and C by comparing the input with −1-1−1. For part B, consider the unique-output requirement.

    2. Hint 2

      In the revised conditions, substitute −1-1−1 into both formulas and compare their results.

    Answer

    A. 444. B. No; the revised rule would assign both 555 and 333 to input −1-1−1. C. −1-1−1.

    Full solution

    A.

    Because −2<−1-2<-1−2<−1, use the first branch:

    q(−2)=−2+6=4.q(-2)=-2+6=4.q(−2)=−2+6=4.

    B.

    Under the revised conditions, both formulas would apply at input −1-1−1.

    The first would give −1+6=5-1+6=5−1+6=5, while the second would give 2−(−1)=32-(-1)=32−(−1)=3.

    These different outputs for one input violate the function requirement.

    In the original rule, only the second condition includes −1-1−1, so the actual value is q(−1)=3q(-1)=3q(−1)=3.

    C.

    Since 3≥−13\ge-13≥−1, the second branch applies again:

    q(3)=2−3=−1.q(3)=2-3=-1.q(3)=2−3=−1.

    Answer

    A. 444. B. No; the revised rule would assign both 555 and 333 to input −1-1−1. C. −1-1−1.

    Key idea

    Overlapping branch conditions preserve a function only when they assign the same output at every shared input.

  4. Problem 4 Read between marked points

    The entire graph of ggg consists of straight segments joining (−3,−1)(-3,-1)(−3,−1), (−1,3)(-1,3)(−1,3), (2,3)(2,3)(2,3), and (5,0)(5,0)(5,0) in that order, with all endpoints included.

    A. Find g(−2)g(-2)g(−2) and g(4)g(4)g(4).

    B. Describe all inputs that produce output 333.

    Text description of this figure

    2. Hint 2

  5. Problem 5 Unequal input gaps

    A table gives F(2)=11F(2)=11F(2)=11, F(5)=17F(5)=17F(5)=17, and F(9)=13F(9)=13F(9)=13.

    A. Find the average rate from input 222 to input 555.

    B. Find the average rate from input 555 to input 999.

    C. Which interval has the greater magnitude of average rate?

    1. Hint 1

      Use the input gap belonging to each output change.

    2. Hint 2

      Compare the absolute values of the two rates after calculating them.

    Answer

    A. 222. B. −1-1−1. C. The interval from 222 to 555.

    Full solution

    A.

    The first output change is 17−11=617-11=617−11=6, over input change 5−2=35-2=35−2=3.

    Thus

    17−115−2=2.\frac{17-11}{5-2}=2.5−217−11​=2.

    B.

    The second output change is 13−17=−413-17=-413−17=−4, over input change 9−5=49-5=49−5=4.

    Thus

    13−179−5=−1.\frac{13-17}{9-5}=-1.9−513−17​=−1.

    C.

    The magnitudes are 222 and 111.

    The first interval has the greater magnitude, while the signs show opposite directions of net change.

    Answer

    A. 222. B. −1-1−1. C. The interval from 222 to 555.

    Key idea

    Output changes must be divided by their own input gaps before rates can be compared.

  6. Problem 6 A draining tank

    A tank initially holds 848484 liters and loses water at a constant rate of 666 liters per minute until it is empty. Let T(t)T(t)T(t) give its volume after ttt minutes. Use the model only from t=0t=0t=0 through t=14t=14t=14.

    A. Write a formula for TTT and identify the independent and dependent quantities.

    B. Find T(5)T(5)T(5).

    C. Find and interpret the average rate from minute 333 to minute 888.

    1. Hint 1

      Start with the initial volume and subtract the amount lost after t minutes.

    2. Hint 2

      For the rate, subtract the two volume readings and divide by the elapsed time.

    Answer

    A. T(t)=84−6tT(t)=84-6tT(t)=84−6t for 0≤t≤140\le t\le140≤t≤14; time is independent and volume is dependent. B. 545454 liters. C. −6-6−6 liters per minute, a decrease averaging 666 liters per minute.

    Full solution

    A.

    After ttt minutes, the tank has lost 6t6t6t liters.

    Its remaining volume is

    T(t)=84−6t.T(t)=84-6t.T(t)=84−6t.

    Time is the selected input; the model determines volume as its output.

    B.

    At five minutes,

    T(5)=84−30=54.T(5)=84-30=54.T(5)=84−30=54.

    The unit is liters.

    C.

    The endpoint volumes are T(3)=66T(3)=66T(3)=66 and T(8)=36T(8)=36T(8)=36 liters.

    Their average rate is

    36−668−3=−6.\frac{36-66}{8-3}=-6.8−336−66​=−6.

    Its units are liters per minute, and its negative sign records a decrease.

    Here the stated constant-rate assumption also tells us the loss rate is the same throughout the interval.

    That conclusion uses the model assumption, not merely the two endpoint readings.

    Answer

    A. T(t)=84−6tT(t)=84-6tT(t)=84−6t for 0≤t≤140\le t\le140≤t≤14; time is independent and volume is dependent. B. 545454 liters. C. −6-6−6 liters per minute, a decrease averaging 666 liters per minute.

    Key idea

    The meaning and units of a function come from the quantities the model connects.

  7. Problem 7 Can the entries be completed?

    A relation must include all three ordered pairs (a,2)(a,2)(a,2), (3,b)(3,b)(3,b), and (a,5)(a,5)(a,5), where the first coordinate is the input. Can any real values of aaa and bbb make it a function? Explain.

    1. Hint 1

      Check the entries that share the symbol a as their input.

    2. Hint 2

      Changing a moves both of those input labels together; it does not change their assigned outputs.

    Answer

    No real values of aaa and bbb work.

    Full solution

    The pairs (a,2)(a,2)(a,2) and (a,5)(a,5)(a,5) assign two different outputs to the same input aaa.

    Changing the value of aaa changes which input has the conflict, but leaves both assignments attached to it.

    Choosing bbb cannot remove either required pair.

    Therefore no choice of the two values can make this relation a function.

    Answer

    No real values of aaa and bbb work.

    Key idea

    When two required entries give different outputs to the same input, changing another entry cannot repair the conflict.

    ▾

  8. Problem 8 A rate across two branches

    A function uses r(x)=x+8r(x)=x+8r(x)=x+8 when x<1x<1x<1 and r(x)=x2+8r(x)=x^2+8r(x)=x2+8 when x≥1x\ge1x≥1.

    1. Hint 1

    2. Hint 2

      Compare the whole-interval average with the average from input 0 to input 1.

    Answer

    The second gives r(1)=9r(1)=9r(1)=9 and r(3)=17r(3)=17r(3)=17.

    B.

    Use the whole-interval endpoints:

    17−83−0=3.\frac{17-8}{3-0}=3.3−017−8​=3.

    C.

    From input 000 to input 111, the average rate is

    9−81−0=1.\frac{9-8}{1-0}=1.1−09−8​=1.

    Answer
