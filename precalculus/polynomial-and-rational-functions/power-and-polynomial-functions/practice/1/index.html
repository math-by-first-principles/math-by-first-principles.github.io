  1. 1

    Which rule is both a power function and a polynomial function on its natural real domain?

    Answer choices for question 1

    Solution

    Correct answer: B

    A power function uses one nonzero coefficient times a fixed power of the input. A polynomial requires every variable exponent to be a nonnegative integer.

    f(x)=−7x4f(x)=-7x^4f(x)=−7x4

    The exponent 4 satisfies both requirements. The sum has two terms, and the root and negative powers fail the polynomial requirement.

  2. 2

    Which rule is a power function but is not a polynomial function?

    Answer choices for question 2

    Solution

    Correct answer: D

    The fixed rational exponent gives one power function, but a polynomial's variable exponents must be nonnegative integers.

    25∉{0,1,2,…}\frac25\notin\{0,1,2,\ldots\}52​∈/{0,1,2,…}

    The polynomial sums are not single power functions; the integer power meets both classifications.

    What is the natural real domain of f(x)=−2x7/6f(x)=-2x^{7/6}f(x)=−2x7/6?

    Answer choices for question 3

    Solution

    Correct answer: A

    The reduced denominator is even, so its root requires a nonnegative input. The exponent is positive, so zero is allowed.

    f(0)=−2(0)=0f(0)=-2(0)=0f(0)=−2(0)=0

    The negative coefficient makes outputs negative when x>0x>0x>0 and leaves the zero output unchanged; it does not change the input restriction.

  6. 6

    Under this course's convention, what is the degree of the zero polynomial?

    Answer choices for question 6

    Solution

    Correct answer: D

    Degree is the largest exponent with a nonzero coefficient. The zero polynomial has no such term. A nonzero constant has degree zero, which is a separate case.

    At equally spaced inputs 0,1,2,30,1,2,30,1,2,3, a stated linear model has outputs 10,16,22,2810,16,22,2810,16,22,28. What is its output at input 444?

    Answer choices for question 10

    Solution

    Correct answer: A

    A linear rule has constant first differences at equal input steps. Every listed step adds 6.

    28+6=3428+6=3428+6=34

    The linear-model assumption justifies continuing the pattern; the four entries alone would not determine every future output.

    −9<−5<−1-9<-5<-1−9<−5<−1

    The first wrong pattern decreases, the positive pattern misses the sign condition, and constant slopes describe no strict bending pattern.

  12. 12

    What changes at an inflection point of a graph?

    Answer choices for question 12

    Solution

    Correct answer: C

    An inflection point is a point where concavity changes. For example, the cube bends down to the left of the origin and up to the right while continuing to increase. A zero output or a turning point alone is not the definition.
